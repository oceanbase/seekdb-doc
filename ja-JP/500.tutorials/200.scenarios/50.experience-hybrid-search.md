# ハイブリッド検索を体験する

このチュートリアルでは、seekdbのハイブリッド検索機能をすぐに使い始める方法を紹介します。ハイブリッド検索が、全文インデックスのキーワード検索とベクトルインデックスの意味検索の利点を同時に活用し、実際のアプリケーションでどのように役立つかを深く理解できます。

## 概要

ハイブリッド検索（Hybrid Search）は、ベクトルベースの意味検索と全文インデックスに基づくキーワード検索を組み合わせ、総合的なランキングにより正確で包括的な検索結果を提供します。ベクトル検索は意味的類似性に基づくマッチングに長けていますが、正確なキーワード、数字、固有名詞などのマッチング能力は弱いです。一方、全文検索はこの欠点を効果的に補うことができます。seekdbは[DBMS_HYBRID_SEARCH](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004020384)システムパッケージを通じてハイブリッド検索機能を提供し、以下のシナリオをサポートしています：

* ベクトル検索のみ：意味的類似性に基づいて関連コンテンツを検索します。意味検索やレコメンデーションシステムなどのシナリオに適しています。
* 全文検索のみ：キーワードマッチングに基づいてコンテンツを検索します。ドキュメント検索や製品検索などのシナリオに適しています。
* ハイブリッド検索：キーワードマッチングと意味理解を組み合わせることで、より正確で包括的な検索結果を提供します。

この機能は、インテリジェント検索、ドキュメント検索、製品推薦などのシナリオで広く利用されています。

## 前提条件

* 管理者から対応するデータベース接続文字列を取得し、以下のコマンドを実行してデータベースに接続します：
    ```shell
    - host: seekdb データベース接続IPアドレス。
    - port: seekdb データベース接続ポート。
    - database_name: アクセスするデータベース名。
    - user_name: データベースユーザー名。
    - password: データベースパスワード。
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```
* テストテーブルを作成し、そのテーブルにベクトルインデックスと全文インデックスを作成していること：
    :::collapse
    ```sql
    CREATE TABLE doc_table(
        c1 INT,
        vector VECTOR(3),
        query VARCHAR(255),
        content VARCHAR(255),
        VECTOR INDEX idx1(vector) WITH (distance=l2, type=hnsw, lib=vsag),
        FULLTEXT INDEX idx2(query),
        FULLTEXT INDEX idx3(content)
    );

    INSERT INTO doc_table VALUES
    (1, '[1,2,3]', "hello world", "oceanbase Elasticsearch database"),
    (2, '[1,2,1]', "hello world, what is your name", "oceanbase mysql database"),
    (3, '[1,1,1]', "hello world, how are you", "oceanbase oracle database"),
    (4, '[1,3,1]', "real world, where are you from", "postgres oracle database"),
    (5, '[1,3,2]', "real world, how old are you", "redis oracle database"),
    (6, '[2,1,1]', "hello world, where are you from", "starrocks oceanbase database");
    ```
    :::

## ステップ１：純粋ベクトル検索

ベクトル検索は、ベクトルの類似度を計算して意味的に関連するコンテンツを検索する手法であり、意味検索やレコメンデーションシステムなどのシナリオに適しています。

検索パラメータを設定し、ベクトル検索を使用して、クエリベクトル `[1,2,3]` と最も類似するレコードを検索します：

```sql
SET @parm = '{
    "knn" : {
        "field": "vector",
        "k": 3,
        "query_vector": [1,2,3]
    }
}';

SELECT JSON_PRETTY(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
```

実行結果は次のとおりです：

:::collapse

## ステップ2：純粋な全文検索

全文検索はキーワードマッチングによってコンテンツを検索し、ドキュメント検索や製品検索などのシナリオに適しています。

検索パラメータを設定し、全文検索を使用して `query` および `content` フィールドにキーワードが含まれるレコードを検索します：

```sql
SET @parm = '{
    "query": {
        "query_string": {
            "fields": ["query", "content"],
            "query": "hello oceanbase"
        }

}';

SELECT JSON_PRETTY(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
```

## ステップ3：ハイブリッド検索

ハイブリッド検索は、キーワードマッチングとセマンティック理解を組み合わせることで、より正確で包括的な検索結果を提供し、全文インデックスとベクトルインデックスの利点を同時に活用できます。

検索パラメータを設定して、全文検索とベクトル検索を同時に実行します：

```sql
SET @parm = '{
    "query": {
        "query_string": {
            "fields": ["query", "content"],
            "query": "hello oceanbase"
        }
    },
    "knn" : {
        "field": "vector",
        "k": 5,
        "query_vector": [1,2,3]
    }
}';

SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
```

## パラメータチューニング

ハイブリッド検索では、`boost`パラメータを使用して全文検索とベクトル検索の重み比率を調整し、検索結果を最適化できます。例えば、全文検索の重みを高めるには：

```sql
SET @parm = '{
    "query": {
        "query_string": {
            "fields": ["query", "content"],
            "query": "hello oceanbase",
            "boost": 2.0
        }
    },
    "knn" : {
        "field": "vector",
        "k": 5,
        "query_vector": [1,2,3],
        "boost": 1.0
    }
}';

SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
```

`boost`パラメータを調整することで、キーワード検索と意味検索の最終的なランキングにおける重みを制御できます。例えば、キーワードの一致に重点を置く場合は、`query_string`の`boost`値を高めることができます。意味的類似性に重点を置く場合は、`knn`の`boost`値を高めることができます。

## まとめ

このチュートリアルを通じて、seekdbのハイブリッド検索のコア機能を習得しました：

* 純粋なベクトル検索：意味的類似度により関連コンテンツを検索します。意味検索のシナリオに適しています。
* 純粋な全文検索：キーワード一致によりコンテンツを検索します。正確な検索のシナリオに適しています。
* ハイブリッド検索：キーワードと意味理解を組み合わせ、より包括的で正確な検索結果を提供します。

ハイブリッド検索機能は、大量の非構造化データを処理し、インテリジェントな検索および推薦システムを構築するための理想的な選択肢であり、検索結果の精度と包括性を大幅に向上させることができます。
