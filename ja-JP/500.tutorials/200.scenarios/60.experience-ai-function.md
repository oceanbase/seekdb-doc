# AI関数サービスを体験する

このチュートリアルでは、seekdb AI関数サービスの使い方をすぐにマスターできます。AIの能力を活用して実際のアプリケーションをどのように支援するかを深く理解し、わずか数分でAIネイティブデータベースの強力な機能を体験できます。

## 概要

AI関数はSQL式を通じて、AIモデルの機能をデータベース内のデータ処理に直接統合します。これにより、AI大規模モデルを用いたデータの抽出、分析、要約、保存などの操作が大幅に簡素化され、現在のデータベースおよびデータウェアハウス分野における重要な新機能となっています。seekdbは`DBMS_AI_SERVICE`パッケージを通じて包括的なAIモデルおよびエンドポイント管理を提供し、複数のAI関数式を組み込んでいます。また、ビューを通じてAIモデルの呼び出し状況を監視することもサポートしています。追加のコードを記述することなく、SQL内で直接AIモデルを呼び出すことができ、数分以内に`AI_COMPLETE`、`AI_EMBED`、`AI_RERANK`、`AI_PROMPT`の主要な関数を体験できます：

* `AI_EMBED`：埋め込みモデル（Embedding Model）を呼び出して、テキストデータをベクトルデータに変換します。
* `AI_COMPLETE`：指定されたテキストを生成する大規模モデルを呼び出し、プロンプトとデータ情報を処理し、処理結果を解析します。
* `AI_PROMPT`：プロンプトテンプレートと動的データをJSON形式で構成し、`AI_COMPLETE`関数内で`prompt`パラメータとして直接置き換えて使用できます。
* `AI_RERANK`：再ランキングモデル（Rerank Model）を呼び出し、プロンプトに基づいてテキストの類似度順に並べ替えます。

この機能は、テキスト生成、テキスト変換、テキストの再ランキングなどのシナリオに適用できます。

## 前提条件

* 管理者から対応するデータベース接続文字列を取得し、以下のコマンドを実行してデータベースに接続します。

    ```shell
    # host: seekdb データベース接続IPアドレス。
    # port: seekdb データベース接続ポート。
    # database_name: アクセスするデータベース名。
    # user_name: データベースユーザー名。
    # password: データベースパスワード。
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

* [AI関数呼び出し権限](../../200.develop/700.ai-function/100.ai-function-permission.md)が付与されていることを確認してください。各例の前には、モデルとエンドポイントの登録情報が完全に記載されており、そのままコピーして使用できます。

## ステップ1：AI_EMBEDを使用してベクトルを生成する

`AI_EMBED`は、テキストをベクトルに変換し、ベクトル検索に利用できます。これはベクトル検索の基本的なステップであり、テキストデータを高次元ベクトル表現に変換して類似度計算を可能にします。

### 単一行データの埋め込みを試す

```sql
SELECT AI_EMBED("ob_embed", "Hello world") AS embedding;
```

期待される戻り値はベクトル配列であり、例えば `[0.1, 0.2, 0.3]` のようになります。これにより、テーブル内のテキストを一括してベクトルに変換し、その後のベクトル検索に利用できます。

## ステップ2：AI_COMPLETEとAI_PROMPTを使用してテキストを生成する

```sql
SELECT AI_COMPLETE("ob_complete", AI_PROMPT('あなたのタスクは、提供されたテキストに対して感情分析を行い、その感情の傾向がポジティブかネガティブかを判断することです。
    以下が分析対象のテキストです：
    <text>
    {0}
    </text>
    判断基準は以下の通りです：
    テキストがポジティブな感情を表現している場合は1を出力し、ネガティブな感情を表現している場合は-1を出力します。他のものは出力しないでください。', '天気は本当にいいね。')) AS sentiment;
```

## ステップ4：総合的な応用：インテリジェントQ&Aシステムの構築

3つのAI関数を組み合わせて使用し、3ステップで簡単なインテリジェントQ&Aシステムを構築します。

### すべての必要なモデルとエンドポイントの登録

この例では、埋め込みモデル、テキスト生成モデル、および再ランキングモデルを同時に使用する必要があります。対応するモデルとエンドポイントが登録されていることを確認してください。具体的なステートメントについては、手順1、手順2、および手順3を参照してください。

:::info
前の手順で対応するモデルを既に登録済みの場合は、該当する登録手順をスキップし、次の手順に直接進んでください。
:::

### データの準備とベクトルの生成

```sql
CREATE TABLE knowledge_base (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(255),
    content TEXT,
    embedding TEXT
);

INSERT INTO knowledge_base (title, content) VALUES
    ('seekdb 簡介', 'seekdbは強力なデータベースシステムで、ベクトル検索とAI関数をサポートします。'),
    ('ベクトル検索', 'ベクトル検索は意味検索に使用され、類似したコンテンツを見つけることができます。'),
    ('AI関数', 'AI関数はSQL内で直接AIモデルを呼び出すことができます。');

UPDATE knowledge_base
SET embedding = AI_EMBED("ob_embed", content);
```

### ベクトル検索と再ランキング

```sql
SET @query = "ベクトル検索とは何ですか？";
SET @query_vector = AI_EMBED("ob_embed", @query);

-- 文字列配列形式のドキュメントリストを直接構築する
SET @candidate_docs = '["seekdbは強力なデータベースシステムで、ベクトル検索とAI関数をサポートします。", "ベクトル検索は意味検索に使用され、類似したコンテンツを見つけることができます。"]';

SELECT AI_RERANK("ob_rerank", @query, @candidate_docs) AS ranked_results;
```

実行結果は以下のとおりです。`index` がドキュメントのインデックス、`relevance_score` が関連性スコアです：

```sql
+-------------------------------------------------------------------------------------------------------------+
| ranked_results                                                                                              |
+-------------------------------------------------------------------------------------------------------------+
| [{"index": 1, "relevance_score": 0.9904329776763916}, {"index": 0, "relevance_score": 0.16993996500968933}] |
+-------------------------------------------------------------------------------------------------------------+
1 row in set
```

### 答案の生成

最初のステップでの質問検索と2番目のステップでの再ソートの結果に基づいて、答えを生成します。

```sql
SELECT AI_COMPLETE("ob_complete",
    AI_PROMPT('以下のドキュメントの内容に基づいて、ユーザーの質問に答えてください。
    ユーザーの質問：{0}

    関連ドキュメント：{1}

    上記のドキュメントの内容に基づいて、簡潔かつ正確にユーザーの質問に答えてください。', @query, CAST(JSON_EXTRACT(@candidate_docs, '$[1]') AS CHAR))) AS answer;
```

実行結果は次のとおりです：

:::collapse
```sql
+--------------------------------------------------------------------------------------------------------------------------------------------+
| answer                                                                                                                                     |
+--------------------------------------------------------------------------------------------------------------------------------------------+
| 根据提供的文档内容，向量搜索是一种用于语义搜索的技术，旨在通过比对向量数据来找到相似的内容。                                               |
+--------------------------------------------------------------------------------------------------------------------------------------------+
1 row in set
```
:::

これら3つのステップにより、seekdbデータベース内でベクトル化、検索、再ソート、答えの生成という完全なAIアプリケーションプロセスを迅速に完了できます。

## まとめ

このチュートリアルを通じて、seekdb AI関数サービスのコア機能を習得しました：

* AI_EMBED：テキストをベクトルに変換し、ベクトル検索のためのデータを準備します。
* AI_COMPLETE：SQL内でLLMを直接呼び出し、テキスト生成、翻訳、分析などの機能を実現します。
* AI_RERANK：検索結果の精度を最適化し、RAGアプリケーションの効果を向上させます。
