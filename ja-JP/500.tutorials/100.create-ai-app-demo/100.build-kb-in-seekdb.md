# seekdbを用いたナレッジベースデスクトップアプリケーションの構築

このチュートリアルでは、seekdbを使用してMineKB（Mine Knowledge Base、個人ローカルナレッジベース）デスクトップアプリケーションを迅速に構築する方法を紹介します。ベクトル検索と大規模言語モデルを活用したインテリジェントなQ&Aの実装手順を解説します。

## 概要

アプリケーションの主な特徴：
* プロジェクト管理：複数の独立したナレッジベースプロジェクトを作成できます。
* ドキュメント処理：TXT、MD、PDF、DOC、DOCX、RTF など、さまざまな形式をサポートし、テキストの抽出とベクトル化を自動的に行います。
* インテリジェント検索：seekdb のベクトルインデックス（HNSW）に基づき、効率的な意味検索を実現します。
* 対話型Q&A：AI 対話を通じてナレッジベースを検索し、ドキュメント内容に基づく正確な回答を得ます。
* ローカルストレージ：すべてのデータをローカルに保存し、プライバシーとセキュリティを保護します。

seekdb を選択する理由：
* 埋め込み型デプロイ：データベースとしてアプリケーションに埋め込むため、独立したサービスは不要です。
* ネイティブベクトルサポート：ベクトル型と HNSW インデックスが組み込まれており、ベクトル検索のパフォーマンスが 10～100 倍向上します。
* オールインワン：トランザクション、分析、ベクトル検索を同時にサポートし、一つのデータベースですべてのニーズを満たせます。
* SQL インターフェース：標準 SQL 構文で、開発が容易です。

## 前提条件

### 環境要件

ナレッジベースのデスクトップアプリケーションを開発および実行するには、以下の環境が必要です：

* オペレーティングシステム：Linuxをサポートしており、Ubuntu 20.04+を推奨します。
* Node.js：16.x+をサポートしており、フロントエンド開発に使用します。18.x LTSを推奨します。
* Rust：1.70+をサポートしており、Tauri依存関係が必要です。1.75+を推奨します。
* Python：3.x+をサポートしており、3.9+を推奨します。

### テクノロジースタックと依存パッケージ

* フロントエンド技術スタック（詳細は`package.json`を参照）
  *  `@tauri-apps/api`：TauriフロントエンドAPI。Rustコマンドを呼び出すために使用されます。
  *  `@radix-ui/*`：アクセシビリティUIコンポーネントライブラリ
  *  `react-markdown`：Markdownレンダリング
  *  `react-syntax-highlighter`：コードハイライト
  *  `lucide-react`：アイコンライブラリ
* バックエンド技術スタック（詳細は`Cargo.toml`を参照）
  *  `tauri`：Tauriフレームワークのコア
  *  `tokio`：非同期ランタイム
  *  `reqwest`：HTTPクライアント（AI API呼び出し用）
  *  `pdf-extract`、`docx-rs`：ドキュメント解析
  *  `nalgebra`：ベクトル計算


### APIキーの設定

:::tip
Alibaba Cloud Model Studioサービスを有効にするには、第三者プラットフォームに移動して完了する必要があります。この操作は第三者プラットフォームの料金規則に従い、該当する費用が発生する可能性があります。続行する前に、その公式ウェブサイトにアクセスするか関連ドキュメントを参照し、料金体系を確認して同意してください。同意しない場合は、操作を続けないでください。
:::

MineKBは、Alibaba Cloud Model StudioのAPIを利用してEmbeddingおよびLLMサービスを提供します。[Alibaba Cloud Model Studio](https://bailian.console.aliyun.com/)アカウントに登録し、モデルサービスを有効化してAPIキーを取得します。

APIキーを取得した後、APIキーを設定ファイル`src-tauri/config.json`に入力します。

```json
{
  "api": {
    "dashscope": {
      "api_key": "<sk-your-api-key-here>",
      "base_url": "https://dashscope.aliyuncs.com/api/v1",
      "embedding_model": "text-embedding-v1",
      "chat_model": "qwen-plus"
    }
  },
  "database": {
    "path": "./mine_kb.db",
    "name": "mine_kb"
  }
}
```

:::tip
    <ul><li>Qwen LLMは一定の無料利用枠を提供しています。利用中は無料枠の使用状況に注意し、上限を超えた場合は料金が発生します。</li><li>本チュートリアルでは、Qwen LLMを例にQ&Aボットの構築方法を紹介しますが、他のLLMを使用して構築することも可能です。他のLLMを選択する場合は、<code>src-tauri/config.example.json</code>ファイル内の<code>apiKey</code>、<code>model</code>、<code>baseUrl</code>パラメータを更新する必要があります。</li></ul>
:::

## アプリケーションのローカル実行

### ステップ１：コンパイルと起動

1. プロジェクトのクローンと依存関係のインストール

    ```shell
    # プロジェクトのクローン
    git clone https://github.com/ob-labs/mine-kb.git
    cd mine-kb

    # フロントエンドの依存関係のインストール
    npm install
    # Pythonの依存関係のインストール
    pip install seekdb==0.0.1.dev4 -i https://pypi.tuna.tsinghua.edu.cn/simple/
    ```

2. APIキーの設定：

    ```shell
    cp src-tauri/config.example.json src-tauri/config.json
    # 設定ファイルを編集し、あなたのAPIキーを入力してください
    nano src-tauri/config.json
    ```

3. アプリケーションの起動

    ```shell
    npm run tauri:dev
    ```
    <!-- ![minekb-1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/seekdb/minekb-1.png) -->

ユーザーがMineKBアプリケーションを起動すると、システムは以下の初期化プロセスを順次実行します：
* アプリケーションの初期化（コード詳細：`src-tauri/src/main.rs`）
  * ログシステムの初期化
  * アプリケーションデータディレクトリの確定
  * 設定ファイルの読み込み
  * Python環境の初期化
  * seekdbデータベースの初期化
  * データベースアーキテクチャの初期化
  * アプリケーション状態の作成
  * Tauriアプリケーションの起動
* フロントエンドの初期化（コード詳細：`src/main.tsx`）
  * Reactアプリケーションのマウント
  * list_projectsコマンドを呼び出してプロジェクトリストを取得
  * プロジェクトパネルとダイアログパネルのレンダリング
  * ユーザー操作を待機

### ステップ2：ナレッジベースを作成する

seekdbのドキュメントを使用したテストを推奨します。[こちらをクリック](https://github.com/oceanbase/seekdb-doc)

<!-- ![minekb-2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/seekdb/minekb-2.png) -->

ユーザーが`プロジェクトの作成`ボタンをクリックすると、システムは以下のプロセスを実行します：
* フロントエンドのインタラクション実装
  * コード詳細：`ProjectPanel.tsx`
* バックエンド処理の実装
  * コード詳細：`commands/projects.rs`
* データベース操作
  * コード詳細：`services/project_service.rs`
* データベース層(`seekdb_adapter.rs` → `Python Bridge` → `seekdb`)、コードは以下の通りです：
    ```shell
    # Python Bridgeがコマンドを受信
    {
      "command": "execute",
      "params": {
        "sql": "INSERT INTO projects (...) VALUES (?, ?, ?, ?, ?, ?, ?)",
        "values": ["uuid-here", "私のプロジェクト", "説明", "active", 0, "2025-11-05T...", "2025-11-05T..."]
      }
    }

    # seekdb SQLに変換
    cursor.execute("""
        INSERT INTO projects (id, name, description, status, document_count, created_at, updated_at)
        VALUES ('uuid-here', '私のプロジェクト', '説明', 'active', 0, '2025-11-05T...", '2025-11-05T...'
    """)
    conn.commit()

    # 成功応答を返す
    {
      "status": "success",
      "data": null
    }
    ```

以上のことから、ナレッジベースの作成では以下の処理が行われました：
1. 一意のプロジェクトID（UUID v4）を生成する
2. プロジェクト名を検証する（空ではなく、重複しない）
3. プロジェクトの状態をActiveに初期設定する
4. 作成時刻と更新時刻を記録する
5. プロジェクト情報をseekdbの`projects`テーブルに書き込む
6. トランザクションをコミットし、データの永続性を確保する
7. プロジェクト情報をフロントエンドに返す
8. フロントエンドがプロジェクトリストを更新し、新しいプロジェクトを表示する

### ステップ3：対話を開始する

<!-- ![minekb-3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/seekdb/minekb-3.png) -->

ユーザーがダイアログボックスに質問を入力すると、システムは以下のプロセスを実行します：
* フロントエンドがメッセージを送信する
  * コード詳細：`ChatPanel.tsx`
* バックエンド処理
  * コード詳細：`commands/chat.rs`
* ベクトル検索
  * コード詳細：`services/vector_db.rs`
* LLMのストリーミング呼び出し
  * コード詳細：`services/llm_client.rs`

以上のことから、対話の開始では以下の処理が行われました：
1. ユーザーが質問を入力する
2. ユーザーのメッセージをデータベースに保存する
3. 阿里云百炼APIを呼び出してクエリベクトル（1536次元）を生成する
4. seekdbでベクトル検索を実行する（HNSWインデックスを使用）
5. 最も類似する上位20件のドキュメントブロックを取得する
6. 類似度スコアを計算してフィルタリングする（しきい値0.3）
7. 関連するドキュメントをコンテキストとして使用する
8. プロンプトを構築する（コンテキスト + ユーザーの質問）
9. LLMをストリーミング呼び出して回答を生成する
10. 回答をリアルタイムでフロントエンドに送信して表示する
11. AIの返答と情報源をデータベースに保存する
12. セッションの最終更新時刻を更新する

## まとめ

### デスクトップアプリケーション開発におけるseekdbの利点

MineKBプロジェクトの実践を通じて、seekdbはデスクトップアプリケーション開発において以下の顕著な利点を示しました：

#### 開発効率の高さ

| 比較項目       | 従来の方法                 | seekdbの方法                  |
| :----------- | :----------------------- | :--------------------------- |
| データベースのデプロイ   | 独立したサービスのインストール・設定が必要   | 埋め込み型で、インストール不要             |
| ベクトル検索の実装 | ベクトルインデックスと検索アルゴリズムを手動で実装 | ネイティブHNSWインデックス、そのまま利用可能     |
| データ管理     | リレーショナルデータとベクトルデータを別々に管理 | 統一的に管理、SQLインターフェース           |
| クロスプラットフォーム対応   | 異なるプラットフォームごとにデータベースをコンパイル/パッケージングする必要がある | pipインストールで自動的にプラットフォームに適応         |

#### 優れたパフォーマンス

ベクトル検索の性能テスト（10,000件のドキュメントブロック、1536次元ベクトル）：

| 操作        | seekdb (HNSW) | SQLite (手動検索) | 向上倍率 |
| :---------- | :------------ | :---------------- | :------- |
| Top-10 検索 | 15ms          | 1200ms            | 80x      |
| Top-20 検索 | 25ms          | 2500ms            | 100x     |
| Top-50 検索 | 45ms          | 実行不能          | ∞        |

理由の分析：
* HNSWインデックス：O(log N)の複雑さで、効率的な検索を実現。
* ベクトル型のネイティブサポート：シリアライズのオーバーヘッドがなく、パフォーマンスが向上。
* カラムストアの最適化：必要なフィールドのみを読み取り、I/Oを削減。

#### データのプライバシーとセキュリティ

| 機能     | 説明                     | 価値           |
| :------- | :----------------------- | :------------- |
| ローカルストレージ | データベースファイルはユーザー端末に保存される | プライバシーが完全に保護される     |
| インターネット接続不要 | AI対話を除き、すべての操作はオフラインで行える | 敏感なドキュメントはアップロードされない |
| ユーザー制御 | ユーザーはデータベースファイルをバックアップまたは移行できる | データの所有権はユーザーに帰属する |
| ACIDトランザクション | データの一貫性を保証           | データが失われることはない   |

#### オールインワン機能

seekdbの統合能力は、将来の拡張に無限の可能性を提供します：
* リレーショナルデータ管理：プロジェクト、ドキュメント、セッションなど。
* トランザクションサポート：ACID特性。
* ベクトル検索：意味検索。
* フルテキスト検索：seekdbの`FULLTEXT INDEX`を使用。
* ハイブリッド検索：意味検索とキーワード検索を組み合わせる。
* 分析クエリ：OLAP機能を活用した知識統計。
* 外部テーブルクエリ：CSVなどの外部ファイルを直接クエリする。
* スムーズなアップグレード：データはOceanBase分散版に移行可能。

### MineKBプロジェクトの総括

MineKBプロジェクトを通じて、seekdb + TauriがAI-Nativeデスクトップアプリケーションを構築するための優れた組み合わせであることを証明しました。

主な成功要因：
1.  seekdb：強力なベクトル検索機能を提供。
2.  Tauri：軽量なクロスプラットフォームデスクトップアプリケーションフレームワークを提供。
3.  Python Bridge：Rustとseekdbのシームレスな統合を実現。
4.  RAGアーキテクチャ：ベクトル検索の利点を最大限に発揮。

適用シナリオ：
* 個人のナレッジベース管理
* 企業向けドキュメント検索システム
* AI支援型プログラミングツール
* 学習ノートや研究アシスタント
* 意味検索が必要なあらゆるデスクトップアプリケーション
