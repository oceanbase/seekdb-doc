# seekdbのマルチモーダル融合による文化観光アシスタントの構築

本記事では、seekdbのマルチモーダル融合技術を用いて、あなた専用のseekdb文化観光アシスタントを構築する方法を紹介します。

この例では、seekdbの空間データとベクトル検索のマルチモーダル融合を活用して、観光スポット推薦アプリケーションを構築します。このアプリケーションは、GISとベクトルデータを組み合わせて関連する観光スポットを検索でき、大規模言語モデルAgentのワークフローと連携することで、簡易旅行計画アシスタントを実現します。

## 技術原理

* 空間データ処理技術：GISシステムは、高精度な地理的位置情報と最適ルート計画を提供します。

* ベクトルデータ処理技術：事前学習済みモデル（BGE-m3）を用いて観光スポットの非構造化データをベクトル表現に変換し、seekdbのベクトル検索機能を活用して類似度検索を効率的に実行します。

* 大規模言語モデルAgent技術：インテリジェントな対話レベルでは、大規模言語モデルAgent技術を採用し、プロンプトエンジニアリングと組み合わせることでユーザーの意図理解と複数ラウンドの対話を実現し、複雑なタスクの分解と計画を可能にします。同時に、システムの対話体験を向上させ、お客様のニーズを正確に理解し、パーソナライズされたサービスを提供します。

* コンテンツベースの推薦アルゴリズム：協調フィルタリングとコンテンツベースの推薦アルゴリズムを組み合わせ、季節や評価などのコンテキスト情報を取り入れることで、パーソナライズされた推薦を実現します。

## 概念紹介

:::collapse

* マルチモーダル融合：マルチモーダル融合はseekdbの重要な機能です。本記事でのマルチモーダル融合は主にマルチモーダルデータのハイブリッド検索技術を指します。seekdbはベクトルデータ、空間データ、ドキュメントデータ、スカラーデータなどの型の融合クエリをサポートし、ベクトルインデックス、空間インデックス、全文インデックスなど多様なインデックスのサポートに基づき、より高性能なハイブリッド検索機能を提供します。

  <!-- ![マルチモーダル融合の概要図](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/cloud/tutorial/AI/%E6%96%87%E6%97%85%E5%B0%8F%E5%8A%A9%E6%89%8B%E5%A4%9A%E6%A8%A1%E8%9E%8D%E5%90%88%E7%A4%BA%E6%84%8F%E5%9B%BE-1.jpg) -->

* LLM（Large Language Model）：大規模言語モデル。大量のテキストデータを用いて訓練された深層学習モデルであり、自然言語テキストの生成や言語テキストの意味理解が可能です。大規模言語モデルは、テキスト分類、Q&A、対話など、多様な自然言語タスクを処理でき、人工知能への重要なアプローチです。

:::

## 前提条件

* seekdbが既にデプロイ済みであること。seekdbのデプロイに関する詳細は、[デプロイの概要](../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。

* データベースが既に作成済みであること。データベースの作成に関する詳細は、[データベースの作成](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971662)を参照してください。

* データベースでベクトル検索機能が有効になっていること。ベクトル検索機能の詳細については、[SQLを使用した迅速なベクトル検索](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002012934)を参照してください。

    ```shell
    ALTER SYSTEM SET ob_vector_memory_limit_percentage = 30;
    ```

* （推奨、必須ではない）[Python 3.10以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.10以降の環境を作成できます。具体的な方法については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    ```shell
    conda create -n obmms python=3.10 && conda activate obmms
    ```

* [Poetry](https://python-poetry.org/docs/)をインストールしてください。コマンドの例：

    ```shell
    python3 -m ensurepip
    python3 -m pip install poetry
    ```

* 対応するPythonパッケージをインストールしてください。コマンドの例：

    ```shell
    pip install python-dotenv tqdm streamlit pyobvector==0.2.16
    ```

## ステップ3：公開データセットをダウンロードする

Kaggleの[中国都市観光スポット詳細](https://www.kaggle.com/datasets/audreyhengruizhang/china-city-attraction-details)データセットのZIP圧縮ファイルをダウンロードします。

## ステップ4：あなたの文化観光アシスタントを構築する

### プロジェクトリポジトリのクローン

1. 最新のプロジェクトリポジトリをクローンします。

    ```shell
    git clone https://github.com/oceanbase-devhub/ob-multi-model-search-demo.git
    cd ob-multi-model-search-demo
    ```

2. ダウンロードした `archive` データセットのZIP圧縮ファイルを `ob-multi-model-search-demo` プロジェクトフォルダに移動し、`citydata` に名前を変更して解凍します。

    ```shell
    # archive.zipファイルの実際の保存パスに変更してください
    mv ./archive.zip ./citydata.zip
    unzip ./citydata.zip
    ```

### 依存関係のインストール

プロジェクトのルートディレクトリで、以下のコマンドを実行して依存関係をインストールします。

```shell
poetry install
```

### 環境変数の設定

`.env` ファイルに環境変数を設定します：

```shell
vim .env
```

`OB_` で始まる変数は、ご自身のデータベース接続情報に更新する必要があります。また、以下の変数を手動で追加する必要があります：`DASHSCOPE_API_KEY` をAlibaba Cloud Bailianコンソールから取得したAPIキー値に更新し、`AMAP_API_KEY` を高徳地図APIサービスから取得したAPIキー値に更新して、ファイルを保存します。

```text
# データベース接続文字列内のホストアドレス
OB_URL="******"   ## 形式：IP:<ポート番号>
OB_USER="******"  ## ユーザー名
OB_DB_NAME="******"  ## データベース名
# データベース接続文字列内のパスワード
OB_PWD="******"
# データベース接続文字列内のSSL CAファイルパス（オプション）。SSLリンク暗号化を使用しない場合は、このパラメータを削除する必要があります。
OB_DB_SSL_CA_PATH="******"

# LLM APIキーを手動で追加
DASHSCOPE_API_KEY="******"
# 高徳地図APIキーを手動で追加
AMAP_API_KEY="******"
```

### データのインポート

このステップでは、ダウンロードしたデータセットのデータをseekdbにインポートします。

:::tip

初回ビルド時は、データセットの一部（例えば、最初の文字がAの観光スポットのみを選択してインポートすることをお勧めします。全量インポートは時間がかかります。）

:::

```shell
python ./obmms/data/attraction_data_preprocessor.py
```

## トラブルシューティング

### 依存パッケージのインストール問題

#### Poetryのインストール失敗

`poetry install` コマンドが失敗した場合、以下の手順を試してください：

1. Poetryを最新バージョンに更新します：
   ```shell
   pip install --upgrade poetry
   ```

2. Poetryキャッシュをクリアします：
   ```shell
   poetry cache clear --all pypi
   ```

3. 依存関係を再インストールします：
   ```shell
   poetry install --no-cache
   ```

### 環境設定問題

#### Python環境が有効化されていない

:::warning

依存関係のインストールを行う前に、正しいPython環境（例：obmms conda環境）が有効化されていることを確認してください。

:::

正しいconda環境が有効化されていることを確認してください：

```shell
conda activate obmms
```

#### Pythonバージョンが互換性なし

Python 3.10以降のバージョンを使用していることを確認してください：

```shell
python --version
```

バージョンが低すぎる場合は、環境を再作成してください：

```shell
conda create -n obmms python=3.10
conda activate obmms
```

### データベース接続問題

データベース接続に問題が発生した場合、次のことを確認してください：

1. `.env` ファイル内のデータベース接続情報が正しいかどうか
2. seekdbが正常に実行されているかどうか
3. ネットワーク接続が正常であるかどうか
4. データベースユーザーの権限が十分であるかどうか

### その他のよくある質問

#### ポートが占有されている

Streamlit起動時にポートが占有されているというメッセージが表示された場合、別のポートを指定できます：

```shell
poetry run streamlit run ./ui.py --server.port 8502
```

#### メモリ不足

データインポート中にメモリ不足の問題が発生した場合、以下の方法があります：

1. バッチインポートするデータ量を減らす
2. システムメモリを増やす
3. seekdbのメモリ設定を調整する

#### APIキーの問題

以下の設定が正しく行われていることを確認してください：

1. 阿里云百炼APIキー（DASHSCOPE_API_KEY）
2. 高德地图APIキー（AMAP_API_KEY）

APIキーは`.env`ファイルで設定できます。
