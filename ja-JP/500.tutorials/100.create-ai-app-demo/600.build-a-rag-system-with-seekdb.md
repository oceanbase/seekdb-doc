# seekdbを使用してRAGを迅速に構築する

このチュートリアルでは、Markdownドキュメントをseekdbにインポートし、SDKを使用してハイブリッド検索ナレッジベースを構築し、StreamlitでRAGインターフェースを起動する方法を説明します。

## 前提条件

* 埋め込みseekdbがインストール済みであること。seekdbのインストールについては、[埋め込みモード](../../400.guides/400.deploy/600.python-seekdb.md)を参照してください。
* Python 3.11以降のバージョンがインストールされていること。
* uvがインストールされていること。インストールされていない場合は、以下のコマンドを参考にインストールしてください：

    ```shell
    curl -LsSf https://astral.sh/uv/install.sh | sh

    # またはpipでインストール
    pip install uv
    ```

## ステップ2：コードを取得する

```shell
git clone https://github.com/oceanbase/pyseekdb.git
```

## ステップ3：依存関係をインストールする

1. `pyseekdb/demo/rag`ディレクトリに移動します。

    ```shell
    cd pyseekdb/demo/rag
    ```

2. 依存関係をインストールします。

    * 基本インストール（defaultまたはapi embeddingタイプに適用）：

        ```shell
        uv sync
        ```

    * ローカルモデルサポートを含む場合（local embeddingタイプに適用）：

        ```shell
        uv sync --extra local
        ```

    :::info

    * localの追加依存関係には、sentence-transformersおよび関連依存関係（約2～3GB）が含まれます。

    * 中国本土にいる場合は、国内ミラーソースを使用してダウンロードを加速できます：

        基本インストール（Tsinghuaリポジトリ）：`uv sync --index-url https://pypi.tuna.tsinghua.edu.cn/simple`
        基本インストール（Alibabaリポジトリ）：`uv sync --index-url https://mirrors.aliyun.com/pypi/simple`
        ローカルモデル（Tsinghuaリポジトリ）：`uv sync --extra local --index-url https://pypi.tuna.tsinghua.edu.cn/simple`
        ローカルモデル（Alibabaリポジトリ）：`uv sync --extra local --index-url https://mirrors.aliyun.com/pypi/simple`

    :::

## ステップ4：環境変数の設定

1. 環境変数のテンプレートをコピーします。

    ```shell
    cp .env.example .env
    ```

2. `.env` ファイルを編集し、環境変数を設定します。

   当システムは3種類のEmbedding関数タイプをサポートしており、ニーズに応じて選択できます：

   * `default`（デフォルト、初心者に推奨）

     * pyseekdbが組み込んだ`DefaultEmbeddingFunction`（ONNXベース）を使用します。
     * 初回使用時にモデルが自動的にダウンロードされるため、APIキーの設定は不要です。
     * ローカル開発とテストに適しています。

   * `local`（ローカルモデル）

     * カスタムのsentence-transformersモデルを使用します。
     * sentence-transformersライブラリをインストールする必要があります。
     * モデル名とデバイス（CPU/GPU）を設定できます。

   * `api`（APIサービス）

     * OpenAI互換のEmbedding API（DashScope、OpenAIなど）を使用します。
     * APIキーとモデル名を設定する必要があります。
     * 本番環境に適しています。

以下では、Qwenを例に説明します（apiタイプを使用）：

```shell
# Embedding Functionタイプ：api, local, default
EMBEDDING_FUNCTION_TYPE=api

# LLM設定（回答生成用）
OPENAI_API_KEY=sk-your-dashscope-key
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
OPENAI_MODEL_NAME=qwen-plus

# Embedding API設定（EMBEDDING_FUNCTION_TYPE=apiの場合のみ必要）
EMBEDDING_API_KEY=sk-your-dashscope-key
EMBEDDING_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
EMBEDDING_MODEL_NAME=text-embedding-v4

# ローカルモデル設定（EMBEDDING_FUNCTION_TYPE=localの場合のみ必要）
SENTENCE_TRANSFORMERS_MODEL_NAME=all-mpnet-base-v2
SENTENCE_TRANSFORMERS_DEVICE=cpu

# seekdb設定
SEEKDB_DIR=./data/seekdb_rag
SEEKDB_NAME=test
COLLECTION_NAME=embeddings
```

パラメータ説明：

| 変数名 | 説明 | デフォルト値/例 | 必須 |
| --- | --- | --- | --- |
| EMBEDDING_FUNCTION_TYPE | Embedding関数タイプ | `default`（オプション：`api`, `local`, `default`） | 必須設定 |
| OPENAI_API_KEY | LLM APIキー（OpenAI、Qwenなどの互換サービスをサポート） | \- | 必須設定（回答生成に使用されます） |
| OPENAI_BASE_URL | LLM API基本URL | `https://dashscope.aliyuncs.com/compatible-mode/v1` | オプション |
| OPENAI_MODEL_NAME | 言語モデル名 | qwen-plus | オプション |
| EMBEDDING_API_KEY | Embedding APIキー | \- | `EMBEDDING_FUNCTION_TYPE=api` の場合は必須 |
| EMBEDDING_API_BASE_URL | Embedding API基本URL | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `EMBEDDING_FUNCTION_TYPE=api` の場合は必須 |
| EMBEDDING_MODEL_NAME | Embeddingモデル名 | text-embedding-v4 | `EMBEDDING_FUNCTION_TYPE=api` の場合は必須 |
| SENTENCE_TRANSFORMERS_MODEL_NAME | ローカルモデル名 | all-mpnet-base-v2 | `EMBEDDING_FUNCTION_TYPE=local` の場合は必須 |
| SENTENCE_TRANSFORMERS_DEVICE | 実行デバイス | cpu | `EMBEDDING_FUNCTION_TYPE=local` の場合は必須 |
| SEEKDB_DIR | seekdbデータベースディレクトリ | `./data/seekdb_rag` | オプション |
| SEEKDB_NAME | データベース名 | test | オプション |
| COLLECTION_NAME | 埋め込みテーブル名 | embeddings | オプション |

:::tip

* `default`タイプを使用する場合は、`EMBEDDING_FUNCTION_TYPE=default`とLLM関連の設定を行うだけで済みます。
* `api`タイプを使用する場合は、Embedding API関連の変数を追加で設定する必要があります。
* `local`タイプを使用する場合は、`sentence-transformers`ライブラリをインストールし、モデル名を設定できます。

:::

## ステップ5：データのインポート

pyseekdbのSDKドキュメントを例に説明しますが、ご自身のMarkdownドキュメントやディレクトリを使用することもできます。

データインポートスクリプトを実行します：

```shell
# 単一ファイルをインポートする場合
uv run python seekdb_insert.py ../../README.md

# またはディレクトリ内のすべてのMarkdownファイルをインポートする場合
uv run python seekdb_insert.py path/to/your_dir
```

インポートの説明：

このステップでは、システムは以下の操作を実行します：

* 指定されたMarkdownファイル、またはディレクトリ内のすべてのMarkdownファイルを読み込みます。
* ドキュメントを見出しでテキストブロックに分割します（# 分離子を使用）。
* `.env` ファイルで設定された `EMBEDDING_FUNCTION_TYPE` に基づいて、適切な埋め込み関数を選択します：
  * `default`: pyseekdbに組み込まれている `DefaultEmbeddingFunction` を使用します（初回使用時はモデルが自動的にダウンロードされます）。
  * `local`: カスタムのsentence-transformersモデルを使用します。
  * `api`: 設定されたEmbedding APIサービスを使用します。
* テキストの埋め込みベクトルを自動生成します。
* 埋め込みベクトルをseekdbデータベースに格納します。
* 失敗したドキュメントブロックを自動的にスキップし、バッチ処理の安定性を確保します。

## ステップ6：RAGの構築

Streamlitを使用してアプリケーションを起動します：

```shell
uv run streamlit run seekdb_app.py
```

次のように返されます：

```shell

Collecting usage statistics. To deactivate, set browser.gatherUsageStats to false.

  You can now view your Streamlit app in your browser.

  Local URL: http://localhost:8501
  Network URL: http://xxx.xxx.xxx.19:8501
  External URL: http://xxx.xxx.xxx.143:8501

```

起動後、ブラウザでRAGインターフェースにアクセスし、検索したいデータをクエリできます。

:::tip

uvパッケージマネージャーを使用する場合は、uv runプレフィックスを付けてコマンドを実行し、正しいPython環境と依存関係が使用されるようにしてください。

:::
