# ICU_VERSION

## 宣言

```sql
ICU_VERSION()
```

## 説明

この関数は、正規表現操作をサポートする ICU ライブラリのバージョンを返します。
seekdb は International Components for Unicode (ICU) を使用して正規表現のサポートを実装しており、ICU は完全な Unicode サポートとマルチバイト安全性を提供します。

## 例

```sql
SELECT ICU_VERSION();
+---------------+
| ICU_VERSION() |
+---------------+
| 69.1          |
+---------------+
1 row in set (0.001 sec)
```
