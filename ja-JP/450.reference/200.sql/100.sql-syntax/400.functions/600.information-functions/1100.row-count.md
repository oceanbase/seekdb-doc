# ROW_COUNT

## 宣言

```sql
ROW_COUNT()
```

## 説明

実行されたSQL文が影響を及ぼした行数を返します。

`ROW_COUNT` は文によって異なる値を返します：

* DDL文：`0` を返します。

* `SELECT` 以外のDML文：影響を受けた行数を返します。

  特に、`UPDATE` 文は実際に影響を受けた行数を返します。

* `SELECT` 文：`SELECT` 文の実行結果が集合である場合、`-1` を返します。`SELECT` 文が行の状態に影響を与えた場合、影響を受けた行数を返します。

  例えば、`SELECT .... INTO` 文は挿入された行数を返します。

## 例

```sql
INSERT INTO t VALUES(1),(2),(3);
Query OK, 3 rows affected (0.02 sec)
Records: 3  Duplicates: 0  Warnings: 0

SELECT ROW_COUNT();
+-------------+
| ROW_COUNT() |
+-------------+
|           3 |
+-------------+
1 row in set (0.001 sec)
```
