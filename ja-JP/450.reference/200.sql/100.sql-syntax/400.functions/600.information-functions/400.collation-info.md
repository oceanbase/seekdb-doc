# COLLATION

## 宣言

```sql
COLLATION(str)
```

## 説明

文字列 `str` の照合順序を返します。

`SHOW COLLATION` ステートメントを使用して、seekdbがサポートする照合順序を確認できます。

## 例

```sql
SELECT COLLATION("oceanbase");
+------------------------+
| COLLATION("oceanbase") |
+------------------------+
| utf8mb4_general_ci     |
+------------------------+
1 row in set (0.001 sec)

SELECT COLLATION("oceanbase" COLLATE utf8mb4_bin);
+--------------------------------------------+
| COLLATION("oceanbase" COLLATE utf8mb4_bin) |
+--------------------------------------------+
| utf8mb4_bin                                |
+--------------------------------------------+
1 row in set (0.001 sec)
```
