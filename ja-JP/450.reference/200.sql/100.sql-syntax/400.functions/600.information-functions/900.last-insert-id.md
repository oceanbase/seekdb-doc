# LAST_INSERT_ID

## 宣言

```sql
LAST_INSERT_ID()
```

## 説明

現在のセッションで最後に挿入された自動インクリメントフィールドの値を返します。

特に、最新の `INSERT` 文が複数のレコードを挿入した場合、`LAST_INSERT_ID()` は最初のレコードの自動インクリメントフィールドの値を返します。

## 例

```sql
CREATE TABLE t1(c1 INT,c2 INT AUTO_INCREMENT);
SELECT LAST_INSERT_ID();
+------------------+
| LAST_INSERT_ID() |
+------------------+
|                0 |
+------------------+
1 row in set (0.001 sec)
```
