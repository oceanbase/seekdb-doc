# VERSION

## 宣言

```sql
VERSION()
```

## 説明

現在のseekdbがMySQLと互換性のあるバージョン番号を返します。文字セットはutf8mb4です。

## 例

```sql
SELECT VERSION();
+----------------------------------+
| VERSION()                        |
+----------------------------------+
| 5.7.25-OceanBase SeekDB-v1.0.0.0 |
+----------------------------------+
1 row in set (0.001 sec)
```
