# CONNECTION_ID

## 宣言

```sql
CONNECTION_ID()
```

## 説明

この関数は、現在のセッションのクライアントセッションIDを返します。このIDは、クライアント内でのセッションの一意の識別子です。

## 例

現在のセッションのクライアントセッションIDを取得します。

```sql
SELECT CONNECTION_ID() AS Client_Session_ID;
```

戻り値は次のとおりです：

```shell
+-------------------+
| Client_Session_ID |
+-------------------+
|        3221488032 |
+-------------------+
1 row in set (0.001 sec)
```
