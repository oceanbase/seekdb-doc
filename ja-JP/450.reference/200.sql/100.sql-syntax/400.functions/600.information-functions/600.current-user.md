# CURRENT_USER

## 宣言

```sql
CURRENT_USER()
```

## 説明

seekdbは、ユーザー名とホスト名の組み合わせでログインアカウントを定義します。この関数は、utf8mb4文字セットを使用してログインアカウント名の文字列を返します。

seekdbにログインする際、seekdbはユーザー名とホスト名でマッチングを行います。例えば、`testUser@11.162.%.%` と `demoUser@11.162.%.%` の2つのユーザーを作成した場合、`mysql.USER` テーブルで以下のユーザーを検索できます：

```sql
SELECT USER,HOST FROM mysql.USER ORDER BY USER,HOST;
+------------+----------------+
| user       | host           |
+------------+----------------+
...
| testUser   | 11.162.%.%     |
| demoUser   | 11.162.%.%     |
...
+------------+----------------+
```

seekdbでは、異なるユーザー名とホスト名の組み合わせが異なる権限を持つことができ、マッチング時にも異なるユーザーとして認識されます。例えば、`'testUser'@'11.162.%.%'` に `SELECT` と `UPDATE` 権限を付与し、`'demoUser'@'11.162.%.%'` に `SELECT` 権限を付与することができます。

```sql
-- ユーザー 'testUser'@'11.162.%.%' に UPDATE、SELECT 権限を付与
GRANT UPDATE, SELECT ON *.* TO 'testUser'@'11.162.%.%' identified by '********';
-- ユーザーの関連権限を即座にリフレッシュして有効にする
FLUSH PRIVILEGES;
-- ユーザー 'demoUser'@'11.162.%.%' に UPDATE、SELECT 権限を付与
GRANT SELECT ON *.* TO 'demotUser'@'11.162.%.%' identified by '*******';
-- ユーザーの関連権限を即座にリフレッシュして有効にする
FLUSH PRIVILEGES;
```

`testUser` ユーザーでseekdbにログインした後、`CURRENT_USER()` を実行します。結果は以下のとおりです。

```sql
mysql -h11.162.xxx.xxx -P2881 -utestUser -p********

SELECT CURRENT_USER();
+---------------------+
| CURRENT_USER()      |
+---------------------+
| testUser@11.162.%.% |
+---------------------+
1 row in set (0.001 sec)
```

`testUser'@'11.162.%.%` を削除した後、再度 `testUser` ユーザーでseekdbに接続します。結果は以下のとおりです。

```sql
DROP USER DROP USER 'testUser'@'11.162.%.%';

mysql -h11.162.xxx.xxx -P2881 -utestUser -p*******

ERROR 1045 (42000): Access denied for user 'testUser'@'xxx.xxx.xxx.xxx' (using password: YES)
```

## 例

現在のデータベースのログインユーザーを確認します。

例：`demoUser` ユーザーでseekdbに接続します。結果は以下のとおりです。

```sql
mysql -h11.162.xxx.xxx -P2881 -udemoUser -p********

+---------------------+
| CURRENT_USER()      |
+---------------------+
| demoUser@11.162.%.% |
+---------------------+
1 row in set (0.000 sec)
```
