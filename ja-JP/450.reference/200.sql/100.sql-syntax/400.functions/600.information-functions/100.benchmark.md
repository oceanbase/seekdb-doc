# BENCHMARK

## 構文宣言

```sql
BENCHMARK(count,expr)
```

## 説明

`BENCHMARK()` 関数は、式 `expr` を `count` 回繰り返し実行して、結果として0を返します。不適切なパラメータが指定された場合は、`NULL` を返します。例えば、`NULL` 値や `count` が負の数値の場合です。

`expr` はスカラー式でなければなりません。`BENCHMARK()` はスカラー式の実行性能を測定するために使用できます。実行後のレポート時間はサーバー側のCPU時間ではなく、クライアント側の実行時間です。

## 例

```sql
SELECT BENCHMARK(100,AES_ENCRYPT('hello','world'));
+---------------------------------------------+
| BENCHMARK(100,AES_ENCRYPT('hello','world')) |
+---------------------------------------------+
|                                           0 |
+---------------------------------------------+
1 row in set (0.001 sec)
```
