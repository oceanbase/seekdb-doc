# DATABASE

## 宣言

```sql
DATABASE()
```

## 説明

現在のデータベース名を返します。文字セットはutf8mb4です。

`USE` ステートメントでデータベースが指定されていない場合、`NULL` を返します。

## 例

現在のデータベース名を返します。

```sql
SELECT DATABASE();
+------------+
| DATABASE() |
+------------+
| oceanbase  |
+------------+
1 row in set (0.001 sec)
```
