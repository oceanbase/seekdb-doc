# TOKENIZE

## 説明

この関数は、指定されたトークナイザーとJSON形式のパラメータに基づいて、テキストを分かち書きした結果を出力します。

## 構文

```sql
TOKENIZE('text', ['parser'], ['behavior_ctrl'])
```

## パラメータの説明

|    **フィールド**   | **説明** |
|---------------|----------|
| text          | テキストを表します。`TEXT`、`CHAR`、`VARCHAR` 型のデータをサポートします。|
| parser        | 分かち書き辞書の名前を表します。`BENG`（英語）、`NGRAM`（中国語）、`SPACE`（スペース）、`IK`（中国語）などの分かち書き辞書をサポートします。|
| behavior_ctrl | JSON形式でパラメータを指定します。オプションの構成パラメータは以下のとおりです：<ul><li>`stopwords`：スタップワードリストです。設定がない場合は、グローバルデフォルト設定に従い、グローバルスタップワードを適用します。空の場合は、空文字列として扱われます。</li><li>`case`：設定がない場合は、システムのデフォルト動作で処理されます。設定がある場合は、大文字/小文字を区別して処理されます。</li><li>`output`：以下の形式があります：<ul><li>`default`：単語素のみを含む出力 `json array, ["hello", "world", "english"]`。</li><li>`all`：`doc_len` と単語頻度を含む `json object`、例えば `{"doc_len":3, "tokens":["i":1, "love":1, "china":1]}`。</li><li>`additional-args`：特定の分かち書き辞書のパラメータ、例えば `ngram` の `["token_size:2"]`。</li></ul></li></ul>|

## 例

`TOKENIZE` 関数を使用して、文字列 `I Love China` を単語に分解し、区切り文字として `beng` を使用します。次に、`JSON` 形式のパラメータを使用して出力オプションを設定します。

```sql
SELECT TOKENIZE('I Love China','beng', '[{"output": "all"}]');
```

戻り値は次のとおりです：

```shell
+--------------------------------------------------------+
| TOKENIZE('I Love China','beng', '[{"output": "all"}]') |
+--------------------------------------------------------+
| {"tokens": [{"love": 1}, {"china": 1}], "doc_len": 2}  |
+--------------------------------------------------------+
1 row in set (0.001 sec)
```
