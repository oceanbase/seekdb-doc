# FORMAT_PICO_TIME

## 宣言

```sql
FORMAT_PICO_TIME(time_val)
```

## 説明

`FORMAT_PICO_TIME()`は、`time_val`を読みやすい形式に変換し、値と単位識別子からなる文字列を返します。結果は、Performance Schemaの遅延または待機時間（ピコ秒単位）を表します。この文字列のバイト数は小数点以下2桁に四捨五入され、少なくとも3つの有効数字を含みます。1ナノ秒未満の時間は整数として表され、四捨五入は行われません。

`time_val`が`NULL`の場合、この関数は`NULL`を返します。

単位識別子は`time_val`パラメータのサイズに応じて異なり、次の表のとおりです。

| **パラメータ値** | **結果単位** | **単位識別子** |
| --- | --- | --- |
| **最大 10<sup>3</sup> − 1** | picoseconds | ps |
| **最大 10<sup>6</sup> − 1** | nanoseconds | ns |
| **最大 10<sup>9</sup> − 1** | microseconds | us |
| **最大 10<sup>12</sup> − 1** | milliseconds | ms |
| **最大 60×10<sup>12</sup> − 1** | seconds | s |
| **最大 3.6×10<sup>15</sup> − 1** | minutes | min |
| **最大 8.64×10<sup>16</sup> − 1** | hours | h |
| **8.64×10<sup>16</sup> 以上** | days | d |

## 例

```sql
SELECT FORMAT_PICO_TIME(2401), FORMAT_PICO_TIME(188732396662000);
+------------------------+-----------------------------------+
| FORMAT_PICO_TIME(2401) | FORMAT_PICO_TIME(188732396662000) |
+------------------------+-----------------------------------+
| 2.40 ns                | 3.15 min                          |
+------------------------+-----------------------------------+
1 row in set (0.001 sec)
```
