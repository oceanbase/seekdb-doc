# マッピング関数の概要

マッピング関数は、seekdbシステムが提供する、マッピングデータを処理するために特化した関数群です。これらの関数により、ユーザーは複雑なマッピングクエリや分析を実行できます。

以下は、seekdbのマッピング関数とその用途の概要です：

## マッピング関数の種類

| マッピング関数タイプ                               | 説明                                                                |
|------------------------------------------|--------------------------------------------------------------------|
| [マッピングコンストラクタ](200.map-constructor-functions.md) | 新しいマッピングデータ型を構築するために使用される関数。 |
| [マッピング判断関数](300.map-decision-functions.md) | 入力されたマッピングデータに対して論理判断を行い、ブール値を返す関数。 |
| [マッピング操作関数](600.map-manipulation-functions.md)  | キーの抽出や値の抽出など、入力されたマッピングデータに対する基本的な操作を行い、操作後のマッピングデータを返す関数。 |

## マッピング関数一覧

seekdbが現在サポートしているすべてのマッピング関数は以下のとおりです：

| 関数タイプ | 関数名 | 説明 |
|---------|---------|------|
| [マッピング構造関数](200.map-constructor-functions.md) | map | マッピングデータを構築するために使用されます。 |
| [演算子](200.map-constructor-functions.md)  | {} | マッピングデータを構築するために使用されます。 |
| [演算子](300.map-decision-functions.md)  | =/!= | 2つのマッピングデータが等しいかどうかを判断します。 |
| [マッピング操作関数](600.map-manipulation-functions.md) | map_keys | マッピングデータのキーのリストを取得します。 |
| [マッピング操作関数](600.map-manipulation-functions.md) | map_values | マッピングデータの値のリストを取得します。 |
