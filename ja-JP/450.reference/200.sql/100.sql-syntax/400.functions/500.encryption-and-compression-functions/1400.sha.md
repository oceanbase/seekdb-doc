# SHA

## 宣言

```sql
SHA(str)
```

## 説明

指定された文字列のSHA-1 160ビットハッシュを計算し、返します。この値は40文字の16進数で表される文字列として返されます。`SHA1()` 関数と同等です。

## 例

```sql
SELECT SHA('OB');
+------------------------------------------+
| SHA('OB')                                |
+------------------------------------------+
| 29a6de2fd8618f31afb281a608c57995b7eb105d |
+------------------------------------------+
1 row in set (0.001 sec)
```
