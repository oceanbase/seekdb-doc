# MD5

## 宣言

```javascript
MD5(str)
```

## 説明

文字列のMD5 128ビットチェックサムを返します。

戻り値は32ビット16進数で表される文字列です。`str`が`NULL`の場合は`NULL`を返します。

## 例

```javascript
SELECT MD5(1);
+----------------------------------+
| MD5(1)                           |
+----------------------------------+
| c4ca4238a0b923820dcc509a6f75849b |
+----------------------------------+
1 row in set (0.001 sec)
```
