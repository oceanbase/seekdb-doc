# RANDOM_BYTES

## 宣言

```sql
RANDOM_BYTES(len)
```

## 説明

len バイトの長さを持つランダムなバイナリ文字列を返します。len の有効な値は [1～1024] です。

## 例

```sql
SELECT RANDOM_BYTES(2);
+-----------------+
| RANDOM_BYTES(2) |
+-----------------+
| H              |
+-----------------+
1 row in set (0.001 sec)
```
