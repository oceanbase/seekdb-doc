# SHA1

## 宣言

```sql
SHA1(str)
```

## 説明

指定された文字列のSHA-1 160ビットハッシュ値を計算し、40文字の16進数で表される文字列として返します。`SHA()` 関数と同等です。

## 例

```sql
SELECT SHA1('OB');
+------------------------------------------+
| SHA1('OB')                               |
+------------------------------------------+
| 29a6de2fd8618f31afb281a608c57995b7eb105d |
+------------------------------------------+
1 row in set (0.001 sec)
```
