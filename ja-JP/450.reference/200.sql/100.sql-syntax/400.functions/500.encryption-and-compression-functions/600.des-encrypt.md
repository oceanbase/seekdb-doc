# DES_ENCRYPT

## 宣言

```sql
DES_ENCRYPT(str[,{key_num|key_str}])
```

## 説明

この機能は、seekdbがSSLをサポートするよう設定されている場合にのみ有効です。

`key_str`パラメータは、`str`を暗号化するための暗号鍵を渡すために使用されます。このパラメータが指定されていない場合、DESキー ファイル内の最初のキーが使用されます。`key_num`パラメータの値は、DESキー ファイル内のキー番号（0から9）です。

戻り値の文字列はバイナリ文字列であり、最初の文字は`CHAR(128 | key_num)`です。エラー発生時、`DES_ENCRYPT()`は`NULL`を返します。128は暗号鍵を容易に識別するためのものです。文字列キーを使用する場合、`key_num`は127となります。

結果の文字列長は以下の式で計算されます：

```sql
new_len = orig_len + (8 - (orig_len % 8)) + 1
```

DESキー ファイル内の各行の形式は`key_num des_key_str_`です。各`key_num`値は0から9の範囲内の数字でなければなりません。ファイル内の行は任意の順序で配置できます。`des_key_str`は情報を暗号化するための文字列です。数字とキーの間には少なくとも1つのスペースが必要です。`DES_ENCRYPT()`に対してキーパラメータを指定しなかった場合、最初のキーがデフォルトキーとして使用されます。

:::info

seekdbの現在のバージョンでは、`--des_key_file`を使用してDESキー ファイルを編集することはサポートされていないため、現在の`DES_ENCRYPT()`および`DES_DECRYPT()`がキー ファイルから読み取るキーは、MySQL 8.0のデフォルトキー ファイルと同じです。

:::
