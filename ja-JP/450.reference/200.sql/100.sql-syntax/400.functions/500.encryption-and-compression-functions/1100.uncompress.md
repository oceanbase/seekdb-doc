# UNCOMPRESS

## 宣言

```sql
UNCOMPRESS(str)
```

## 説明

[COMPRESS()](../500.encryption-and-compression-functions/300.compress.md) 関数で圧縮された文字列を解凍します。

## 例

```sql
SELECT UNCOMPRESS(COMPRESS('abc'));
+-----------------------------+
| UNCOMPRESS(COMPRESS('abc')) |
+-----------------------------+
| abc                         |
+-----------------------------+
1 row in set (0.001 sec)
```
