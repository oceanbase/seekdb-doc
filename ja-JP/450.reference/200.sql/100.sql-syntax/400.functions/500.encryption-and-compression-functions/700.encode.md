# ENCODE

## 宣言

```sql
ENCODE(str,pass_str)
```

## 説明

`ENCODE()`は、`pass_str`をパスワードとして文字列を暗号化します。戻り値は、`str`の長さと同じ長さのバイナリ文字列です。この結果を復号化するには、`DECODE()`を使用してください。

## 例

`ENCODE()`を使用する際は、リスクを軽減するためにソルト値を必ず使用してください。

```sql
SELECT ENCODE('text', CONCAT('ob_random_salt','ob_secret_password'))
+---------------------------------------------------------------+
| ENCODE('text', CONCAT('ob_random_salt','ob_secret_password')) |
+---------------------------------------------------------------+
5+                                                          |
+---------------------------------------------------------------+
1 row in set (0.001 sec)
```
