# COMPRESS

## 宣言

```sql
COMPRESS(str)
```

## 説明

文字列を圧縮し、その結果をバイナリ文字列として返します。[UNCOMPRESS](../500.encryption-and-compression-functions/1100.uncompress.md) 関数を使用して結果を解凍できます。

## 例

```sql
SELECT COMPRESS('abc');
+-----------------+
| COMPRESS('abc') |
+-----------------+
|    x?KLJ M'  |
+-----------------+
1 row in set (0.001 sec)
```
