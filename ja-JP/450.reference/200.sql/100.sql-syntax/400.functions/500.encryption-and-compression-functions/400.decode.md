# DECODE

## 宣言

```sql
DECODE(crypt_str,pass_str)
```

## 説明

`DECODE()`は、`pass_str`をパスワードとして使用し、暗号化された文字列`crypt_str`を復号化して、復号化後の文字列を返します。

## 例

```sql
SELECT DECODE(ENCODE('secret','cry'), 'cry');
+---------------------------------------+
| DECODE(ENCODE('secret','cry'), 'cry') |
+---------------------------------------+
| secret                                |
+---------------------------------------+
1 row in set (0.001 sec)
```
