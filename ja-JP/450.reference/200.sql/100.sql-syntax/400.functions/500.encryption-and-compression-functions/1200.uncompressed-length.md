# UNCOMPRESSED_LENGTH

## 宣言

```sql
UNCOMPRESSED_LENGTH(str)
```

## 説明

[COMPRESS()](../500.encryption-and-compression-functions/300.compress.md) 関数で圧縮する前の文字列の長さを返します。

## 例

```sql
SELECT UNCOMPRESSED_LENGTH(COMPRESS('abc'));
+--------------------------------------+
| UNCOMPRESSED_LENGTH(COMPRESS('abc')) |
+--------------------------------------+
|                                    3 |
+--------------------------------------+
1 row in set (0.001 sec)
```
