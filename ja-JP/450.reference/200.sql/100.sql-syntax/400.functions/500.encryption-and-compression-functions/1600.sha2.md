# SHA2

## 宣言

```sql
SHA2(str,len)
```

## 説明

この関数は、指定された文字列のSHA-2ハッシュを計算して返します。対応するアルゴリズムは、SHA-224、SHA-256、SHA-384、およびSHA-512です。`str` はハッシュ化する平文文字列であり、`len` は結果の必要なビット長を示します。その値は224、256、384、512、または0（256に相当）でなければなりません。

## 例

```sql
SELECT SHA2('OB',224);
+----------------------------------------------------------+
| SHA2('OB',224)                                           |
+----------------------------------------------------------+
| 00ac28313083c3a30fa0c671f01829ff0fd3253938d0c0225c4c670e |
+----------------------------------------------------------+
1 row in set (0.001 sec)
```
