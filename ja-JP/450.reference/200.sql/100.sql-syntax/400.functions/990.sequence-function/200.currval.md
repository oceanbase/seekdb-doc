# CURRVAL(SEQ) 関数

`CURRVAL(SEQ)` 関数は、シーケンスの現在値を返します。

## 使用例

`CURRVAL` を使用するには、まずシーケンスを作成する必要があります。以下は、シーケンスの作成と `CURRVAL` の使用手順と例です。

**ステップ１：シーケンスを作成する**

```shell
CREATE SEQUENCE students_seq；
```

**ステップ２：NEXTVAL を使用して新しいデータを挿入する**

```shell
INSERT INTO students (id, name) VALUES (students_seq.NEXTVAL, 'John Doe');
```

**ステップ３：CURRVAL を使用して現在値を取得する**

```shell
SELECT currval('students_seq');
```
