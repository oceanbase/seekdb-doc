# NEXTVAL(SEQ) 関数

`NEXTVAL(SEQ)` はシーケンス関数であり、指定されたシーケンスの次の値を取得し、シーケンスをインクリメントします。

## 使用例

`NEXTVAL` を使用するには、まずシーケンスを作成する必要があります。以下はシーケンスの作成と `NEXTVAL` の使用手順と例です。

### シーケンスの作成

```shell
CREATE SEQUENCE my_seq
    START WITH 1
    INCREMENT BY 1
    MINVALUE 1
    MAXVALUE 999999;
```

ここで：

* `START`：開始値を表します。
* `INCREMENT`：ステップサイズを表します。
* `MINVALUE`：最小値を表します。
* `MAXVALUE`：最大値を表します。

### シーケンスの使用

* シーケンス値の単独取得

    ```shell
    SELECT NEXTVAL(my_seq);
    +---------+
    | NEXTVAL |
    +---------+
    |       1 |
    +---------+
    1 row in set (0.001 sec) (0.015 sec)
    ```

* データ挿入時のシーケンスの使用

    ```shell
    INSERT INTO users (id, name) VALUES (NEXTVAL(my_seq), 'John');
    ```
