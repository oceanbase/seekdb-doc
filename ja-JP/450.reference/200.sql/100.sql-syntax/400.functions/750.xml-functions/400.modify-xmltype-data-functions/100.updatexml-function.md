# UPDATEXML

## 説明

この関数は、XML文字列内の指定されたパスのノードコンテンツを更新するために使用します。

## 構文

```sql
UPDATEXML(xml_target, xpath_expr, new_xml)
```

## パラメータ説明

:::info

`xml_target` のうち `xpath_expr` で指定された部分を `new_xml` に置き換えます。`xpath_expr` が結果をマッチングしない場合、または複数の結果をマッチングした場合は、`xml_target` の元の結果を返します。

:::

| **フィールド** | **説明** |
| -------- | -------- |
| xml_target | 指定するXML文字列。XMLドキュメントまたはXMLフラグメントのいずれかです。|
| xpath_expr | 更新対象ノードのパス(XPath)式を指定します。|
| new_xml | ノードを置き換えるための新しいXMLフラグメントを指定します。|

## 戻り値タイプ

戻り値タイプは `LONGTEXT` です。

## 例

* `UPDATEXML` 関数を使用して、XML文字列内の `</a>` ノードを `<x>carrot</x>` ノードに置き換え、更新後のXML文字列を返します。`<a/><b/>` は、`<a>` と `<b>` の2つのノードを含むルートノードを表します。

  ```shell
  SELECT UPDATEXML('<a/><b/>', '/a', '<x>carrot</x>');
  ```

  実行結果は次のとおりです：

  ```shell
  +----------------------------------------------+
  | UPDATEXML('<a/><b/>', '/a', '<x>carrot</x>') |
  +----------------------------------------------+
  | <x>carrot</x><b></b>                         |
  +----------------------------------------------+
  1 row in set (0.001 sec)
  ```

* `UPDATEXML` 関数を使用して、XML文字列内の `root` ノードの下の `a` ノードを `<b>bbb</b>` ノードに置き換え、更新後のXML文字列を返します。

  ```shell
  SELECT UPDATEXML('<root><a>aaa</a></root>', '/root/a', '<b>bbb</b>');
  ```

  実行結果は次のとおりです：

  ```shell
  +---------------------------------------------------------------+
  | UPDATEXML('<root><a>aaa</a></root>', '/root/a', '<b>bbb</b>') |
  +---------------------------------------------------------------+
  | <root><b>bbb</b></root>                                       |
  +---------------------------------------------------------------+
  1 row in set (0.001 sec)
  ```
