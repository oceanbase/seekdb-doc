# XML関数の概要

seekdbの現在のバージョンでサポートされているXML関数は、次の表のとおりです。

| **関数名** | **説明** |
| ------------ | -------- |
| [EXTRACTVALUE](300.querying-xmltype-data-functions/100.extractvalue-function.md) | XPath式に一致する要素の最初のテキストノードのテキストを返します。 |
| [UPDATEXML](400.modify-xmltype-data-functions/100.updatexml-function.md) | XML文字列内で指定されたパスのノード内容を更新するために使用されます。|
