# UUID

## 宣言

```sql
uuid()
```

## 説明

グローバルに一意のIDを生成します。

## 例

```sql
SELECT UUID();
+--------------------------------------+
| UUID()                               |
+--------------------------------------+
| eef95d17-e944-11eb-824a-ca1fa9040697 |
+--------------------------------------+
1 row in set (0.001 sec)
```
