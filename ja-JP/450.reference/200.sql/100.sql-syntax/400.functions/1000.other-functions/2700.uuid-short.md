# UUID_SHORT

## 宣言

```sql
UUID_SHORT()
```

## 説明

64ビットの符号なし整数形式で「短い」ユニークIDを返します。

以下の条件を満たす場合、`UUID_SHORT()` の戻り値は一意であることが保証されます：

* 現在のサーバーの `server_id` 値が0から255の範囲内にあり、かつソースサーバーとレプリカサーバーのグループ内で一意であること。`server_id` の総数が256を超える場合、生成される「短い」ユニークIDは空間的な一意性を保証できませんが、この関数はエラーを返しません。

* seekdbの再起動中は、サーバーホストのシステム時刻を設定しないこと。

* seekdbの再起動中は、1秒あたり平均して `UUID_SHORT()` を1600万回未満呼び出すこと。

`UUID_SHORT()` の戻り値の構造は以下のとおりです：

```sql
(server_id & 255) << 56
+ (server_startup_time_in_seconds << 24)
+ incremented_variable++;
```

## 例

```sql
SELECT UUID_SHORT();
+-----------------------+
|          UUID_SHORT() |
+-----------------------+
| 92395783831158784 |
+-----------------------+
1 row in set (0.001 sec)
```
