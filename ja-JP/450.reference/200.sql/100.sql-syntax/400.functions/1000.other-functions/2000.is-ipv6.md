# IS_IPV6

## 宣言

```sql
IS_IPV6(expr)
```

## 説明

パラメータ `expr` が有効なIPv6アドレス文字列である場合は1を返し、そうでない場合は0を返します。この関数は、IPv4アドレスを有効なIPv6アドレスとして扱いません。

指定されたパラメータについて、`IS_IPV6()` が1を返した場合、`INET6_ATON()` は `NULL` 以外を返します。

## 例

```sql
SELECT IS_IPV6('10.x.x.x'), IS_IPV6('::1');
+---------------------+----------------+
| IS_IPV6('10.x.x.x') | IS_IPV6('::1') |
+---------------------+----------------+
|                   0 |              1 |
+---------------------+----------------+
1 row in set (0.001 sec)
```
