# IS_UUID

## 宣言

```sql
IS_UUID(string_uuid)
```

## 説明

パラメータが有効なUUID文字列形式である場合は1を返し、有効なUUIDでない場合は0を返します。パラメータが`NULL`の場合は`NULL`を返します。
「有効」とは、その値が解析可能な形式であることを意味します。つまり、正しい長さを持ち、許可された文字（16進数を表すアルファベット、およびオプションのハイフンと角括弧）のみを含む必要があります。以下の形式が最も一般的です：

```sql
aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee
```

以下の形式も許可されています：

```sql
aaaaaaaabbbbccccddddeeeeeeeeeeee
{aaaaaaaa-bbbb-cccc-dddd-eeeeeeeeeeee}
```
