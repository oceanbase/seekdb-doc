# INET_ATON

## 宣言

```sql
INET_ATON(expr)
```

## 説明

IPv4ネットワークアドレスを文字列として表現し、ネットワークバイト順序（ビッグエンディアン）でアドレス値を表す整数を返します。パラメータが無効な場合は`NULL`を返します。

  :::tip

  `INT UNSIGNED`型の列を使用して`INET_ATON()`で生成された値を格納してください。符号付きの`INT`型は使用できません。符号付きの列を使用すると、IPアドレスの最初の8ビットが127より大きい場合、対応する値を正しく格納できません。

  :::

## 例

```sql
SELECT INET_ATON('1.1.1.1');
+----------------------+
|  INET_ATON('1.1.1.1') |
+----------------------+
|             16843009 |
+----------------------+
1 row in set (0.001 sec)
```
