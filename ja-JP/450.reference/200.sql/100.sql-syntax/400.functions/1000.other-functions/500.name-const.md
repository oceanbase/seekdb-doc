# NAME_CONST

## 宣言

```sql
NAME_CONST(name,value)
```

## 説明

この関数は、定義された値を返します。パラメータ `value` は定数でなければなりません。

`NAME_CONST()` は、生成される結果セットの列に指定された名前を付与します。

## 例

```sql
SELECT NAME_CONST('my_id', 101);
+-------+
| my_id |
+-------+
|   101 |
+-------+
1 row in set (0.001 sec)
```

上記の例と全く同じ結果を得るには、簡単なエイリアスを設定することもできます。例：

```sql
SELECT 101 AS my_id;
```
