# INET_NTOA

## 宣言

```sql
INET_NTOA(expr)
```

## 説明

ネットワークバイト順に表現されたIPv4アドレスの数値を、ピリオド「.」で区切られたIPアドレス文字列として返します。パラメータが無効な場合は`NULL`を返します。

## 例

```sql
SELECT INET_NTOA(16843009);
+---------------------+
| INET_NTOA(16843009) |
+---------------------+
| 1.1.1.1             |
+---------------------+
1 row in set (0.001 sec)
```
