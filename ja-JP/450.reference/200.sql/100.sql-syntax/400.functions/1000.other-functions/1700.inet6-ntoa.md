# INET6_NTOA

## 宣言

```sql
INET6_NTOA(expr)
```

## 説明

数値形式で表されたIPv6またはIPv4のネットワークアドレスを、接続文字セットの文字として使用できるバイナリ文字列に変換して返します。パラメータが有効なアドレスでない場合は`NULL`を返します。

`INET6_NTOA()`には、以下の特性があります：

* システム関数を使用せずに変換を実行するため、出力文字列はプラットフォームに依存しません。

* 返される文字列の最大長は39（4 × 8 + 7）です。

* 返される文字列では、小文字がIPv6アドレスを表すために使用されます。

## 例

```sql
SELECT INET6_NTOA(INET6_ATON('fdfe::5a55:caff:fefa:9089'));
+------------------------------------------------------------+
|  INET6_NTOA(INET6_ATON('fdfe::5a55:caff:fefa:9089')) |
+------------------------------------------------------------+
|                            fdfe::5a55:caff:fefa:9089 |
+------------------------------------------------------------+
1 row in set (0.001 sec)
```
