# STDDEV

## 宣言

```sql
STDDEV(expr)
```

## 説明

`expr` 式の母集団標準偏差を返します。行がマッチしない場合、この関数は `NULL` を返します。

この関数は `STDDEV_POP()` のエイリアスです。

## 例
