# MAX

## 宣言

```sql
MAX([DISTINCT | ALL] expr)
```

## 説明

指定されたデータの中から最大値を返します。

`MAX()` の引数には文字列を指定でき、その場合は最大の文字列値を返します。`DISTINCT` キーワードは異なる値のみを計算することを示し、デフォルトは `ALL` です。

## 例

テーブル `a` に `id=1,num=10`、`id=2,num=20`、`id=3,num=30` の3行のデータがあると仮定します。これらのうち `num` の最大値を取得します。

```sql
SELECT MAX(num) FROM a;
+-----------------+
| MAX(num)        |
+-----------------+
|              30 |
+-----------------+
1 row in set (0.001 sec)
```
