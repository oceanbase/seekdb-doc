# STDDEV_SAMP

## 宣言

```sql
STDDEV_SAMP(expr)
```

## 説明

`expr` の標本標準偏差を返します。この関数は、`VAR_SAMP()` 関数の結果の平方根を返します。`VAR_SAMP()` 関数の詳細については、[VAR_SAMP](../300.aggregate-function/1700.var-samp-agg.md) を参照してください。

マッチする行が見つからない場合、この関数は `NULL` を返します。
