# JSON_ARRAY

## 説明

この関数は、入力された（空の場合もある）値のリストに基づいて、それらの値を含むJSON配列を返します。

## 構文

```sql
JSON_ARRAY([val[, val] ...])
```

## 説明

パラメータ `val` は入力された値を表します。

## 例

```sql
SELECT JSON_ARRAY(1, "abcd", NULL, TRUE, CURTIME(),'[a,b,c]','{"d":100}');
+---------------------------------------------------------------------+
| JSON_ARRAY(1, "abcd", NULL, TRUE, CURTIME(),'[a,b,c]','{"d":100}')   |
+---------------------------------------------------------------------+
| [1, "abcd", null, true, "21:49:37.000000", "[a,b,c]", "{\"d\":100}"] |
+---------------------------------------------------------------------+
1 row in set (0.001 sec)

SELECT JSON_ARRAY(NULL);
+------------------+
| JSON_ARRAY(NULL) |
+------------------+
| [null]           |
+------------------+
1 row in set (0.001 sec)

SELECT JSON_ARRAY();
+--------------+
| JSON_ARRAY() |
+--------------+
| []           |
+--------------+
1 row in set (0.001 sec)
```
