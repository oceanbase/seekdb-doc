# JSON_TYPE

## 説明

この関数は、JSON値の型を表すutf8mb4文字列を返します。

## 構文

```sql
JSON_TYPE(json_val)
```

## 説明

パラメータ `json_val` は、オブジェクト、配列、またはスカラータイプにすることができます。

パラメータが `NULL` の場合、`NULL` を返します。パラメータが有効なJSON値でない場合、エラーが発生します。

## 例

```sql
SET @jn = '{"a": [10, true]}';
Query OK, 0 rows affected (0.000 sec)

SELECT JSON_TYPE(JSON_EXTRACT(@jn, '$.a'));
+-------------------------------------+
| JSON_TYPE(JSON_EXTRACT(@jn, '$.a')) |
+-------------------------------------+
| ARRAY                               |
+-------------------------------------+

SELECT JSON_TYPE(JSON_EXTRACT(@jn, '$.a[0]'));
+----------------------------------------+
| JSON_TYPE(JSON_EXTRACT(@jn, '$.a[0]')) |
+----------------------------------------+
| INTEGER                                |
+----------------------------------------+
1 row in set (0.001 sec)

SELECT JSON_TYPE(JSON_EXTRACT(@jn, '$.a[1]'));
+----------------------------------------+
| JSON_TYPE(JSON_EXTRACT(@jn, '$.a[1]')) |

| JSON_TYPE(NULL) |

ERROR 3146 (22032): Invalid data type for JSON data in argument 1
to function json_type; a JSON string or JSON type is required.
```
