# JSON_VALID

## 説明

この関数は、入力値が有効なJSONかどうかを判断します。有効なJSONの場合は1を返し、そうでない場合は0を返します。

## 構文

```sql
JSON_VALID(val)
```

## 説明

パラメータ `val` は入力値です。パラメータが `NULL` の場合、`NULL` を返します。

## 例

```sql
SELECT JSON_VALID('{"a": 1}');
+------------------------+
| JSON_VALID('{"a": 1}') |
+------------------------+
|                      1 |
+------------------------+
1 row in set (0.001 sec)

SELECT JSON_VALID('oceanbase'), JSON_VALID('"oceanbase"');
+-------------------------+---------------------------+
| JSON_VALID('oceanbase') | JSON_VALID('"oceanbase"') |
+-------------------------+---------------------------+
|                       0 |                         1 |
+-------------------------+---------------------------+
1 row in set (0.001 sec)
```
