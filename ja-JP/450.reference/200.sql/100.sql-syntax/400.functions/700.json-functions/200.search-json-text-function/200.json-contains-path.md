# JSON_CONTAINS_PATH

## 説明

この関数は、1つまたは複数の指定されたパスが対象のJSONドキュメントに含まれているかどうかを検証します。対象のJSONドキュメントに含まれている場合、この関数は1を返し、そうでない場合は0を返します。

## 構文

```sql
JSON_CONTAINS_PATH(json_doc, one_or_all, path[, path] ...)
```

## 説明

パラメータ `json_doc` はJSONドキュメントを指定するために使用され、`path` はパスパラメータです。いずれかのパラメータが `NULL` の場合、`NULL` を返します。

`one_or_all` パラメータの選択可能な値は以下のとおりです：

* `'one'`：ドキュメントに少なくとも1つのパスが存在する場合は1を返し、そうでない場合は0を返します。

* `'all'`：ドキュメントにすべてのパスが存在する場合は1を返し、そうでない場合は0を返します。

以下の場合はエラーが発生します：

* `json_doc` パラメータが有効なJSONドキュメントではありません。

* 任意の `path` パラメータが有効なパス式ではありません。

* `one_or_all` パラメータが `'one'` または `'all'` 以外です。
