# JSON_SEARCH

## 説明

この関数は、JSONドキュメント内で指定された文字列のパスを返します。

## 構文

```sql
JSON_SEARCH(json_doc, one_or_all, search_str[, escape_char[, path] ...])
```

## 説明

パラメータ `json_doc` はJSONドキュメントを指定するために使用され、`search_str` は検索文字列のパラメータです。`escape_char` パラメータは定数式を指定し、`path` はパスのパラメータです。

いずれかのパラメータが `NULL` の場合、`NULL` を返します。ドキュメント内にパスが存在しない場合や指定された文字列が見つからない場合も、`NULL` を返します。

`one_or_all` パラメータの取り得る値は以下のとおりです：

* `'one'`：最初の一致後に検索を終了し、パス文字列を返します。

* `'all'`：検索結果としてすべての一致するパス文字列を返します。重複するパスは含まれません。複数の文字列がある場合、自動的に配列に格納されます。配列要素の順序は保証されません。

`search_str` パラメータにおいて、`%` と `_` の文字は `LIKE` 演算子と同じ役割を持ち、意味は以下のとおりです：

* `%` は任意の数の文字（0文字を含む）に一致します。

* `_` はちょうど1文字に一致します。

検索文字列内で `%` または `_` 文字を指定する場合は、その前にエスケープ文字を付加してください。`escape_char` パラメータが欠落しているか `NULL` の場合、エスケープ文字のデフォルト値は `\` です。それ以外の場合、`escape_char` は空の定数または文字でなければなりません。

データベースのエンコード値に関係なく、`search_str` と `path` は常に utf8mb4 文字列として扱われます。

以下の場合、エラーが発生します：

* `json_doc` パラメータが有効なJSONドキュメントではない場合。

* `path` パラメータが有効なパス式ではない場合。

* `one_or_all` パラメータが `'one'` または `'all'` 以外の場合。

* `escape_char` が定数式ではない場合。
