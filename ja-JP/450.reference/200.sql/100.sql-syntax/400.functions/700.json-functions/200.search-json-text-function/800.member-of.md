# MEMBER OF

## 説明

検索対象の要素がJSON配列のいずれかの要素と一致する場合、この関数は1を返し、一致しない場合は0を返します。

## 構文

```sql
value MEMBER OF(json_array)
```

## 説明

`value` が `json_array` の要素である場合は1を返し、そうでない場合は0を返します。

`value` はスカラーまたはJSONドキュメントでなければなりません。スカラーの場合、演算子はそれをJSON配列の要素と見なします。
