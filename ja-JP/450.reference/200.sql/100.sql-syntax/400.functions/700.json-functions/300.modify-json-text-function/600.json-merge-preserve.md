# JSON_MERGE_PRESERVE

## 説明

2つ以上のJSONドキュメントをマージし、マージ結果を返します。

## 構文

```sql
JSON_MERGE_PRESERVE(json_doc, json_doc[, json_doc] ...)
```

## 説明

パラメータ `json_doc` は、マージするJSONドキュメントを指定します。

いずれかのパラメータが `NULL` の場合、`NULL` を返します。いずれかのパラメータが有効なJSONドキュメントでない場合、エラーが発生します。

JSON_MERGE_PRESERVE() のマージルールは以下のとおりです：

* 隣接する配列は1つの配列にマージされます。

* 隣接するオブジェクトは1つのオブジェクトにマージされます。

* スカラー値は自動的に配列にラップされ、配列としてマージされます。

* オブジェクトを配列に自動的にラップすることで、隣接する配列とオブジェクトをマージします。

## 例

```sql
SELECT JSON_MERGE_PRESERVE('[1, 2, 3]', '[true, false]');
+---------------------------------------------------+
| JSON_MERGE_PRESERVE('[1, 2, 3]', '[true, false]') |
+---------------------------------------------------+
| [1, 2, 3, true, false]                            |
+---------------------------------------------------+
1 row in set (0.001 sec)

SELECT JSON_MERGE_PRESERVE('{"name": "apple"}', '{"id": 56}');
+--------------------------------------------------------+
| JSON_MERGE_PRESERVE('{"name": "apple"}', '{"id": 56}') |
+--------------------------------------------------------+
| {"id": 56, "name": "apple"}                            |
+--------------------------------------------------------+
1 row in set (0.001 sec)

SELECT JSON_MERGE_PRESERVE('1', 'true');
+----------------------------------+
| JSON_MERGE_PRESERVE('1', 'true') |
+----------------------------------+
| [1, true]                        |
+----------------------------------+
1 row in set (0.001 sec)

SELECT JSON_MERGE_PRESERVE('[1, 2, 3]', '{"id": 56}');
+------------------------------------------------+
| JSON_MERGE_PRESERVE('[1, 2, 3]', '{"id": 56}') |
+------------------------------------------------+
| [1, 2, 3, {"id": 56}]                          |
+------------------------------------------------+
1 row in set (0.001 sec)

SELECT JSON_MERGE_PRESERVE('{ "a": 1, "b": 2, "c": 5}',  '{ "a": 3, "c": 4 }');
+-------------------------------------------------------------------------+
| JSON_MERGE_PRESERVE('{ "a": 1, "b": 2, "c": 5}',  '{ "a": 3, "c": 4 }') |
+-------------------------------------------------------------------------+
| {"a": [1, 3], "b": 2, "c": [5, 4]}                                      |
+-------------------------------------------------------------------------+
1 row in set (0.001 sec)

SELECT JSON_MERGE_PRESERVE('{ "a": 1, "b": 2 }','{ "a": 3, "c": 4 }', '{ "a": 5, "d": 6 }');
+--------------------------------------------------------------------------------------+
| JSON_MERGE_PRESERVE('{ "a": 1, "b": 2 }','{ "a": 3, "c": 4 }', '{ "a": 5, "d": 6 }') |
+--------------------------------------------------------------------------------------+
| {"a": [1, 3, 5], "b": 2, "c": 4, "d": 6}                                             |
+--------------------------------------------------------------------------------------+
1 row in set (0.001 sec)
```
