# ビットマップ判断関数

ビットマップ判断関数は、入力されたビットマップデータに対して一定の判断を行い、ブール値を返します。seekdbが現在サポートしているビットマップ判断関数は、`rb_is_empty()`と`rb_contains()`です。

## rb_is_empty

`rb_is_empty()` 関数は、入力されたビットマップデータが空かどうかを判断します。構文は以下のとおりです：

```sql
rb_is_empty(rb)
```

戻り値 `1` は空を表し、`0` は非空を表します。

例：

```sql
SELECT rb_is_empty(rb_from_string(''));
+---------------------------------+
| rb_is_empty(rb_from_string('')) |
+---------------------------------+
|                               1 |
+---------------------------------+
1 row in set (0.001 sec)
```

```sql
SELECT rb_is_empty(rb_from_string('1,2,3'));
+--------------------------------------+
| rb_is_empty(rb_from_string('1,2,3')) |
+--------------------------------------+
|                                    0 |
+--------------------------------------+
1 row in set (0.001 sec)
```

## rb_contains

`rb_contains()` 関数には、2つの使い方があります。

* 入力された最初のビットマップデータ（`rb1`）が、2番目のビットマップデータ（`rb2`）を完全に含むかどうかを判断するために使用します。
* 入力されたビットマップデータに特定のオフセット（`offset`）が含まれているかどうかを判断するために使用します。

2つの使い方は、異なる構文で実現されています。詳細は以下のとおりです。

### 使い方1

`rb_contains()` 関数は、入力された最初のビットマップデータ（`rb1`）が、2番目のビットマップデータ（`rb2`）を完全に含むかどうかを判断するために使用できます。構文は以下のとおりです：

```sql
rb_contains(rb1, rb2)
```

詳細は以下のとおりです：

* 入力パラメータ `rb1` が計算の基準となり、入力パラメータ `rb2` が計算対象のビットマップデータとなります。つまり、`rb2` の各要素が `rb1` に含まれているかどうかをチェックします。
* パラメータ `rb1` と `rb2` の順序は結果に影響します。
* 結果 `1` は完全に含まれることを表し、`0` は完全には含まれないことを表します。

例：

```sql
SELECT rb_contains(rb_from_string('1,2,3,4,5'), rb_from_string('1,2,3,4'));
+---------------------------------------------------------------------+
| rb_contains(rb_from_string('1,2,3,4,5'), rb_from_string('1,2,3,4')) |
+---------------------------------------------------------------------+
|                                                                   1 |
+---------------------------------------------------------------------+
1 row in set (0.001 sec)
```

### 使い方2

`rb_contains()` 関数は、入力されたビットマップデータに特定のオフセット（`offset`）が含まれているかどうかを判断するために使用できます。構文は以下のとおりです：

```sql
rb_contains(rb, offset)
```

詳細は以下のとおりです：

* 入力パラメータ `rb` が計算の基準となり、ビットマップデータとなります。
* `offset` は整数である必要があり、その整数がビットマップデータ `rb` に存在するかどうかを判断するために使用されます。
* 結果 `1` は含まれることを表し、`0` は含まれないことを表します。

例：

```sql
SELECT rb_contains(rb_from_string('1,2,3,4,5'), 1);
+---------------------------------------------+
| rb_contains(rb_from_string('1,2,3,4,5'), 1) |
+---------------------------------------------+
|                                           1 |
+---------------------------------------------+
1 row in set (0.001 sec)
```

```sql
SELECT rb_contains(rb_from_string('1,2,3,4,6'), 5);
+---------------------------------------------+
| rb_contains(rb_from_string('1,2,3,4,6'), 5) |
+---------------------------------------------+
|                                           0 |
+---------------------------------------------+
1 row in set (0.001 sec)
```
