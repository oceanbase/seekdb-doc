# ビットマップコンストラクタ

ビットマップコンストラクタは、新しいビットマップデータ型を構築するために使用されます。seekdbが現在サポートしているビットマップ関数には、`rb_build()`、`rb_build_empty()`、`rb_build_varbinary()`、および `rb_from_string()` が含まれます。

  :::info

  可視化された16進数のクエリ結果を理解するために必要な注意事項については、[効率的な圧縮ビットマップ列の作成](../../100.basic-elements/100.data-type/1000.roaring-bitmap-data-type/200.create-roaring-bitmap-columns.md)を参照してください。

  :::

## rb_build

`rb_build()` 関数は、整数型の基本データ型を持つ配列データを効率的に圧縮されたビットマップデータ（RoaringBitmap）に変換するために使用されます。構文は以下のとおりです：

```sql
rb_build(arr)
```

入力パラメータの説明は以下のとおりです：

* `arr` に渡す型は配列型でなければなりません。

戻り値は、配列のすべての要素を含むRoaringBitmapです。

制約事項は以下のとおりです：

* 配列には空要素を含めることはできません。
* ネストされた配列の場合、各サブ配列の基本要素を再帰的に取り出し、Roaringbitmapに挿入します。
* Roaringbitmapは符号なし64ビット整数（uint64）と符号あり32ビット整数（int32）データの挿入をサポートしています。これは後述の `rb_from_string` の動作と一致しています。入力された符号あり32ビット整数の負の数は、まず符号なし32ビット整数に変換された後、RoaringBitmapに挿入されます。したがって、許容される整数の範囲は符号あり32ビット整数の最小値から符号なし64ビット整数の最大値、すなわち `[INT32_MIN, UINT64_MAX]` です。

例：

```sql
SELECT rb_to_string(rb_build([1.2]));
ERROR 5083 (22000): Invalid data type for the operation
```

```sql
SELECT rb_to_string(rb_build([0,1,2]));
+---------------------------------+
| rb_to_string(rb_build([0,1,2])) |
+---------------------------------+
| 0,1,2                           |
+---------------------------------+
1 row in set (0.001 sec)
```

```sql
SELECT rb_to_string(rb_build([[0,1],[2],[2,3]]));
+-------------------------------------------+
| rb_to_string(rb_build([[0,1],[2],[2,3]])) |
+-------------------------------------------+
| 0,1,2,3                                   |
+-------------------------------------------+
1 row in set (0.001 sec)
```

## rb_build_empty

`rb_build_empty()` 関数は、空のビットマップデータを構築するために使用されます。構文は以下のとおりです：

```sql
rb_build_empty()
```

この関数には入力パラメータは必要ありません。

例：

```sql
SELECT rb_build_empty();
+------------------------------------+
| rb_build_empty()                   |
+------------------------------------+
| 0x0100                             |
+------------------------------------+
1 row in set (0.001 sec)
```

```sql
SELECT rb_is_empty(rb_build_empty());
+-------------------------------+
| rb_is_empty(rb_build_empty()) |
+-------------------------------+
|                             1 |
+-------------------------------+
1 row in set (0.001 sec)
```

## rb_build_varbinary

`rb_build_varbinary()` 関数は、varbinaryを使用してビットマップデータを構築します。Varbinaryはseekdb専用の形式であり、version情報、type情報、dataなどの部分から構成されるバイナリ形式です。構文は以下のとおりです：

```sql
rb_build_varbinary(bin_str)
```

入力パラメータはvarbinary文字列です。

例：

```sql
SELECT rb_to_string(rb_build_varbinary(x'0100'));
+-------------------------------------------+
| rb_to_string(rb_build_varbinary(x'0100')) |
+-------------------------------------------+
|                                           |
+-------------------------------------------+
1 row in set (0.001 sec)
```

```sql
SELECT rb_to_string(rb_build_varbinary(x'0103020100000002000000'));
+-------------------------------------------------------------+
| rb_to_string(rb_build_varbinary(x'0103020100000002000000')) |
+-------------------------------------------------------------+
| 1,2                                                         |
+-------------------------------------------------------------+
1 row in set (0.001 sec)
```

## rb_from_string

`rb_from_string()` 関数は、特定の形式の文字列を使用してビットマップデータを構築します。文字列は、構築するビットマップデータの各要素をカンマで区切って表現し、例えば `1,2,3,4` のようになります。構文は以下のとおりです：

```sql
rb_from_string(str)
```

入力される文字列値はINT32とINT64の2種類の形式をサポートしており、seekdbがサポートする有効な値の範囲は `[0, UINT64_MAX]` です。ただし、PGとの互換性のため、`[INT32_MIN,0)` の範囲の負の整数の入力もサポートしています。出力時には負の整数はUINT32の値に変換して出力されます。例えば、入力が `-1` の場合、出力は `4294967295` となります。

例：

```sql
SELECT rb_from_string('1,2,3');
+--------------------------------------------------+
| rb_from_string('1,2,3')                          |
+--------------------------------------------------+
| 0x010303010000000200000003000000                 |
+--------------------------------------------------+
1 row in set (0.001 sec)
```

```sql
SELECT rb_to_string(rb_from_string('-1'));
+------------------------------------+
| rb_to_string(rb_from_string('-1')) |
+------------------------------------+
| 4294967295                         |
+------------------------------------+
1 row in set (0.001 sec)
```

## rb_select

ビットマップデータは、非負の整数の集合を格納します。`rb_select()` 関数は、指定された条件に基づいてビットマップデータの範囲を選択し、新しいビットマップデータとして保存してその値を返します。構文は以下のとおりです：

```sql
res_rb = rb_select(rb, limit [, offset] [, reverse] [, range_start] [, range_end])
```

パラメータの説明は以下のとおりです：

|  **パラメータ** | **データ型**  |  **デフォルト値** |  **説明** |  **必須** |
|---|---|---|---|---|
|  rb | RoaringBitmap |   | 入力するビットマップデータ。  | はい  |
|  limit | uint64 |   | 出力する要素数を制限します。  | はい  |
|  offset | uint64 |  0 | 出力開始位置のオフセット量。  | いいえ  |
|  reverse | bool |  false | 倒順で出力するかどうか。  | いいえ  |
|  range_start | uint64 | 0  | 出力範囲の開始値。  | いいえ  |
|  range_end | uint64 |  UINT64_MAX |  出力範囲の終了値。  | いいえ  |

計算の順序は以下のとおりです：

1. 範囲が指定されている場合、まず `[range_start,range_end)` の範囲内のすべての要素をフィルタリングします。

2. `reverse` が `false` の場合、値は昇順で選択されます。`true` の場合、降順で選択されます。`rb_select()` 関数は、reverseの方向に応じて、フィルタリングされた要素から出力の開始位置を計算します。

3. `offset` を計算します。

4. `limit` を計算します。最大で `limit` 個の範囲内のデータを出力します。範囲内のデータが `limit` より少ない場合は、範囲内のすべてのデータを出力します。

戻り値はビットマップデータ型です。

例：

`'10, 20, 30, 40, 50, 60, 70'` の最初の3つの値を返します：

```sql
SELECT rb_to_string(rb_select(rb_from_string('10, 20, 30, 40, 50, 60, 70'), 3));
+--------------------------------------------------------------------------+
| rb_to_string(rb_select(rb_from_string('10, 20, 30, 40, 50, 60, 70'), 3)) |
+--------------------------------------------------------------------------+
| 10,20,30                                                                 |
+--------------------------------------------------------------------------+
1 row in set (0.001 sec)
```

2つの値をオフセットして、`'1,2,3,4,5,6,7'` の最初の2つの値を返します：

```sql
SELECT rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 2, 2));
+----------------------------------------------------------------+
| rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 2, 2)) |
+----------------------------------------------------------------+
| 3,4                                                            |
+----------------------------------------------------------------+
1 row in set (0.001 sec)
```

[2, 6) の間から昇順で最初の2つの値を選択します：

```sql
SELECT rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 2, 0, false, 2, 6));
+-----------------------------------------------------------------------------+
| rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 2, 0, false, 2, 6)) |
+-----------------------------------------------------------------------------+
| 2,3                                                                         |
+-----------------------------------------------------------------------------+
1 row in set (0.001 sec)
```

範囲を [2, 6) に制限した上で、1つの値を降順にオフセットして結果を計算し、最終的に最初の2つの値を返します：

```sql
SELECT rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 2, 1, true, 2, 6));
+----------------------------------------------------------------------------+
| rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 2, 1, true, 2, 6)) |
+----------------------------------------------------------------------------+
| 3,4                                                                        |
+----------------------------------------------------------------------------+
1 row in set (0.001 sec)
```

範囲を [2, 6) に制限した上で、1つの値を昇順にオフセットして結果を計算し、最終的に最初の10個の値を返します（実際には3個の値が返されます）：

```sql
SELECT rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 10, 1, false, 2, 6));
+------------------------------------------------------------------------------+
| rb_to_string(rb_select(rb_from_string('1,2,3,4,5,6,7'), 10, 1, false, 2, 6)) |
+------------------------------------------------------------------------------+
| 3,4,5                                                                        |
+------------------------------------------------------------------------------+
1 row in set (0.001 sec)
```
