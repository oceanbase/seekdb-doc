# TO_CHAR(character)

## 説明

この関数は、文字型データを `VARCHAR` 型の文字列に変換します。

## 構文宣言

```sql
TO_CHAR(character)
```

## パラメータ説明

`character`：変換する文字型データを表します。

## 戻り値タイプ

* `VARCHAR` 型のデータを返します。
* `character` の値が `NULL` の場合、`NULL` を返します。

## 例

```sql
SELECT TO_CHAR('Hello, World!'), TO_CHAR(NULL);
```

実行結果は次のとおりです：

```shell
+--------------------------+---------------+
| TO_CHAR('Hello, World!') | TO_CHAR(NULL) |
+--------------------------+---------------+
| Hello, World!            |          NULL |
+--------------------------+---------------+
1 row in set (0.001 sec)
```
