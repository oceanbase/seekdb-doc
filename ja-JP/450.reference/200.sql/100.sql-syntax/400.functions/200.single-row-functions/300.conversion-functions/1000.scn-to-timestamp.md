# SCN_TO_TIMESTAMP

## 構文

```sql
SCN_TO_TIMESTAMP(number)
```

## 説明

`SCN_TO_TIMESTAMP()` 関数は、SCNをパラメータとして受け取り、そのSCNに関連付けられたタイムスタンプを返します。戻り値は `DATETIME` 型です。

## 例

```sql
SELECT MAX_SCN, SCN_TO_TIMESTAMP(MAX_SCN) FROM oceanbase.gv$ob_log_stat;
+---------------------+----------------------------+
| MAX_SCN             | SCN_TO_TIMESTAMP(MAX_SCN)  |
+---------------------+----------------------------+
| 1766126752210029000 | 2025-12-19 14:45:52.210029 |
+---------------------+----------------------------+
1 row in set (0.001 sec)
```

:::info

`oceanbase.gv$ob_log_stat` は、ログストリームのログ同期状態を表示する内部テーブルであり、その `max_scn` フィールドはSCN型です。このSCNをタイムスタンプに変換するには、`SCN_TO_TIMESTAMP()` 関数を使用します。

:::
