# DECODE_TRACE_ID

## 宣言

```sql
DECODE_TRACE_ID()
```

## 説明

`DECODE_TRACE_ID()` 関数は、trace_idを解析し、SQLリクエストの送信元サーバーのIPアドレスとポート番号を返します。関連情報はビュー[GV$OB_SQL_AUDIT](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002016019)でも確認できます。

## 例

```sql
SELECT DECODE_TRACE_ID(LAST_TRACE_ID());
```

実行結果は次のとおりです：

```shell
+----------------------------------+
| DECODE_TRACE_ID(LAST_TRACE_ID()) |
+----------------------------------+
| xxx.xx.xxx.xx1:2882              |
+----------------------------------+
1 row in set (0.000 sec)
```
