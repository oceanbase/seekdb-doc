# CEIL

## 宣言

```sql
CEIL(expr)
```

## 説明

`expr` 以上の最小の整数を返します。

比較演算をサポートしており、結果はBOOL型となり、数値型に変換されて処理されます。その結果、`1` (`TRUE`) または `0` (`FALSE`) が返されます。

入力が `NULL` の場合、戻り値は `NULL` です。

純粋な数字の文字列を入力した場合、自動的に数値型に変換できます。

戻り値はBIGINT型に変換されます。

## 例

```sql
SELECT CEIL(1.2), CEIL(-1.2), CEIL(1+1.5), CEIL(1=1),CEIL(1<1),CEIL(null);
+-----------+------------+-------------+-----------+-----------+------------+
| CEIL(1.2) | CEIL(-1.2) | CEIL(1+1.5) | CEIL(1=1) | CEIL(1<1) | CEIL(null) |
+-----------+------------+-------------+-----------+-----------+------------+
|         2 |         -1 |           3 |         1 |         0 |       NULL |
+-----------+------------+-------------+-----------+-----------+------------+
1 row in set (0.001 sec)

SELECT CEIL('2');

+-----------+

```
