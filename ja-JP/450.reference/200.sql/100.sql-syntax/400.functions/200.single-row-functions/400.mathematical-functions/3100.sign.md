# SIGN

## 宣言

```sql
SIGN(X)
```

## 説明

`SIGN(X)`は、パラメータの符号を返します。この符号は、`X`の値が負、ゼロ、または正によって決まります。浮動小数点数と16進数をサポートしています。戻り値は以下のとおりです：

* 負の値：`-1`

* ゼロ：`0`

* 正の値：`1`

この関数は比較演算をサポートしており、結果は数値型に変換されて処理されます。生成される結果は1(`TRUE`)または0 (`FALSE`)です。

入力が`NULL`の場合、戻り値は`NULL`です。

## 例

```sql
SELECT SIGN(-32), SIGN(0), SIGN(234);
+-----------+---------+-----------+
| SIGN(-32) | SIGN(0) | SIGN(234) |
+-----------+---------+-----------+
|        -1 |       0 |         1 |
+-----------+---------+-----------+
1 row in set (0.001 sec)

SELECT SIGN(NULL),SIGN(FALSE),SIGN(0X01);
+------------+-------------+------------+
| SIGN(NULL) | SIGN(FALSE) | SIGN(0X01) |
+------------+-------------+------------+
|       NULL |           0 |          1 |
+------------+-------------+------------+
1 row in set (0.001 sec)
```
