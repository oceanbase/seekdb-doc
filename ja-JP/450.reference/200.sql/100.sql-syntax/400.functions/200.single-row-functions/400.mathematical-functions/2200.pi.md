# PI

## 宣言

```sql
PI()
```

## 説明

`π` の値（円周率）を返します。

## 例

```sql
SELECT PI();
+----------+
| PI()     |
+----------+
| 3.141593 |
+----------+
1 row in set (0.000 sec)

SELECT ROUND(2*PI(),2);
+----------------+
| ROUND(2*PI(),2)|
+----------------+
| 6.28           |
+----------------+
1 row in set (0.001 sec)
```
