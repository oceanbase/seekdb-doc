# BIT_COUNT

## 宣言

```sql
BIT_COUNT(N)
```

## 説明

`N` を2進数に変換したときの `1` の個数を返します。`N` が `NULL` の場合は、`NULL` を返します。

## 例

```sql
SELECT BIT_COUNT(42), BIT_COUNT(b'1010');
+---------------+--------------------+
| BIT_COUNT(42) | BIT_COUNT(b'1010') |
+---------------+--------------------+
|             3 |                  2 |
+---------------+--------------------+
1 row in set (0.001 sec)
```
