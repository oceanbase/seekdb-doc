# LOG10

## 宣言

```sql
LOG10(X)
```

## 説明

10を底とした`X`の指数を返します。

## 例

```sql
SELECT LOG10(1000);
+-------------+
| LOG10(1000) |
+-------------+
|           3 |
+-------------+
1 row in set (0.001 sec)

SELECT LOG10(-1000);
+--------------+
| LOG10(-1000) |
+--------------+
|         NULL |
+--------------+
1 row in set, 1 warning (0.000 sec)
```
