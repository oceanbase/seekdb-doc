# LOG2

## 宣言

```sql
LOG2(X)
```

## 説明

2を底とする`X`の指数を返します。

## 例

```sql
SELECT LOG2(65536);
+-------------+
| LOG2(65536) |
+-------------+
|          16 |
+-------------+
1 row in set (0.001 sec)

SELECT LOG2(-65536);
+--------------+
| LOG2(-65536) |
+--------------+
|         NULL |
+--------------+
1 row in set, 1 warning (0.000 sec)
```
