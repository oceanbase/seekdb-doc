# MOD

## 宣言

```sql
MOD(N,M)
```

## 説明

剰余関数です。`MOD(N,M)`、`N % M`、`N MOD M` の3つの表記は等価です。

`MOD()` は小数部を持つ数値にも適用され、除算後の正確な余りを返します。

`N` または `M` のいずれか一方のパラメータが `NULL` の場合、戻り値は `NULL` になります。`M` が `0` の場合も `NULL` を返します。

## 例

```sql
SELECT MOD(29,19), 29 MOD 19, 29 % 19;
+------------+-----------+---------+
| MOD(29,19) | 29 MOD 19 | 29 % 19 |
+------------+-----------+---------+
|         10 |        10 |      10 |
+------------+-----------+---------+
1 row in set (0.001 sec)
```
