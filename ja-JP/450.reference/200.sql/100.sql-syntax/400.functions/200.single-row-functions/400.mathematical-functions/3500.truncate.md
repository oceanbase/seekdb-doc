# TRUNCATE

## 宣言

```sql
TRUNCATE(X,D)
```

## 説明

`X` を小数点以下 `D` 桁に切り捨てた結果を返します。`D` が `0` の場合は、`X` の整数部を返します。`D` が負の数の場合は、`X` の小数点より左側の `D` 桁分を `0` にします。

## 例

```sql
SELECT TRUNCATE(3.27,1);
+------------------+
| TRUNCATE(3.27,1) |
+------------------+
|              3.2 |
+------------------+
1 row in set (0.001 sec)

SELECT TRUNCATE(3.27,0);
+------------------+
| TRUNCATE(3.27,0) |
+------------------+
|                3 |
+------------------+
1 row in set (0.001 sec)

SELECT TRUNCATE(3.27,-1);
+-------------------+
| TRUNCATE(3.27,-1) |
+-------------------+
|                 0 |
+-------------------+
1 row in set (0.001 sec)
```
