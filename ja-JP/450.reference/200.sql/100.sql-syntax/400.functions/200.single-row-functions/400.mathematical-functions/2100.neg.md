# NEG

## 宣言

```sql
NEG(expr)
```

## 説明

補集合演算子。演算子に対して補集合演算を実行します。つまり、ゼロから演算子を引いた後、結果を演算子に代入します。

比較演算をサポートし、結果はBOOL値となります。この値は数値型に変換されて処理され、生成される結果は`1`(`TRUE`)または`0`(`FALSE`)となります。その後、この結果に対して補集合演算が実行されます。

## 例

```sql
SELECT NEG(1), NEG(1+1), NEG(2*3), NEG(1=1), NEG(5<1);
+--------+----------+----------+----------+----------+
| NEG(1) | NEG(1+1) | NEG(2*3) | NEG(1=1) | NEG(5<1) |
+--------+----------+----------+----------+----------+
|     -1 |       -2 |       -6 |       -1 |        0 |
+--------+----------+----------+----------+----------+
1 row in set (0.001 sec)
```
