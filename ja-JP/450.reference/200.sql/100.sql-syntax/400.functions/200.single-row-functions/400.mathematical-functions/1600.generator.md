# GENERATOR

## 宣言

```sql
GENERATOR(N)
```

## 説明

この関数はTable Functionフレームワークに組み込まれた関数であり、Table Function内から呼び出すことが可能で、最終的にN行のデータを返します。Nは0以上の64ビット正の整数です。

Table FunctionはSQL言語で使用される関数で、結果としてデータテーブルを返すことができます。従来のSQL関数がスカラー値しか返せないのとは異なり、Table Functionは複数行・複数列のデータセットを返すことができます。

`TABLE(GENERATOR(N))` は実際にはデータを生成するわけではなく、連続したN個の「行」を生成します。データを生成する必要がある場合は、`SELECT` の後に定数、変数、関数、UDFなどの具体的な式を追加する必要があります。`TABLE(GENERATOR(N))` は並列実行に利用できます。例えば、並列 `SELECT` や並列DMLなどです。ただし、`TABLE(GENERATOR(N))` が生成する行を読み取るスレッドは1つだけであり、`TABLE(GENERATOR(N))` を含むDFOの `DOP=1` となります。

## 例

以下の例は、`GENERATOR()` 関数を使用して条件に合致するランダムな数値を生成する方法です。

```shell
SELECT COUNT(*) FROM TABLE(GENERATOR(100000));
+----------+
| COUNT(*) |
+----------+
|   100000 |
+----------+
1 row in set (0.001 sec)

SELECT NORMAL(0, 1, RANDOM()) FROM TABLE(GENERATOR(5));
+------------------------+
| NORMAL(0, 1, RANDOM()) |
|------------------------|
|           0.227384164  |
|           0.9945290748 |
|          -0.2045078571 |
|          -1.594607893  |
|          -0.8213296842 |
+------------------------+
5 rows in set (0.001 sec)

SELECT RANDSTR(1, ZIPF(1, 5, RANDOM())) str FROM TABLE(GENERATOR(5));
+------------------------+
|                    str |
|------------------------|
|                     A  |
|                     D  |
|                     A  |
|                     A  |
|                     C  |
+------------------------+
5 rows in set (0.001 sec)
```
