# POWER

## 宣言

```sql
POWER(X,Y)
```

## 説明

`X` の `Y` 乗を返します。この関数は `POW()` のエイリアスです。

`X` または `Y` のいずれか一方のパラメータが `NULL` の場合、戻り値は `NULL` になります。

## 例

```sql
SELECT POWER(2,8);
+------------+
| POWER(2,8) |
+------------+
|        256 |
+------------+
1 row in set (0.001 sec)
```
