# CONV

## 宣言

```sql
CONV(N, from_base, to_base)
```

## 説明

異なる基数間で数値を変換します。戻り値は文字列で、`from_base` の基数から `to_base` の基数へと変換されたものです。

* 入力パラメータ `N` は整数または文字列にすることができます。最小基数は `2`、最大基数は `36` です。`to_base` が負数の場合、`N` は符号付き数と見なされます。それ以外の場合、`N` は符号なし数と見なされます。

* `from_base` が負数の場合、整数として処理され、符号は無視されます。

* `N` パラメータは int 型と文字列型の入力のみをサポートします。

* `from_base` および `to_base` パラメータは、10進数の int 型の入力のみをサポートし、その値の範囲は \[-36, -2\] U \[2, 36\] です。

不正な入力はエラーを引き起こします。不正な入力には以下のような場合が含まれます：

* `from_base` または `to_base` が有効な10進数の int 型の入力ではない場合。

* `from_base` または `to_base` が \[-36,-2\] ∪ \[2,36\] の値の範囲を超えている場合。

* `N` が有効な数値表現ではない場合。例えば、`0` ～ `9`、`a` ～ `z`、`A` ～ `Z` の文字範囲を超える値を指定した場合などです。

* `N` が `from_base` の基数の値の範囲を超えている場合。例えば、`from_base` が 2 で `N` の値が 3 の場合などです。

* `N` の値が `BIGINT` の最大表現範囲、すなわち \[-9223372036854775807, 9223372036854775807\] を超えている場合。

## 例

```sql
SELECT CONV(9223372036854775807,10,2);
+-----------------------------------------------------------------+
| CONV(9223372036854775807,10,2)                                  |
+-----------------------------------------------------------------+
| 111111111111111111111111111111111111111111111111111111111111111 |
+-----------------------------------------------------------------+
1 row in set (0.001 sec)

SELECT CONV('-acc',21,-7);
+--------------------+
| CONV('-acc',21,-7) |
+--------------------+
| -16425             |
+--------------------+
1 row in set (0.001 sec)
```
