# RANDOM

## 宣言

```sql
RANDOM(seed)
```

## 説明

この関数は、64ビットの整数型の擬似ランダム値を生成します。

* `seed` は整数型であり、異なる `seed` によって異なるランダム数列が生成されます。
* `RANDOM()` はMT19937擬似ランダム数生成アルゴリズムを使用しており、そのランダム空間は非常に大きく、2<sup>19937</sup> - 1 個のランダム要素を生成した後に初めて同じシーケンスが繰り返されます。

## 例

以下の例では、`RANDOM()` を使用してランダム数を生成します。

```shell
SELECT RANDOM(4) FROM TABLE(GENERATOR(3));
+---------------------+
| RANDOM(4)           |
+---------------------+
| 5267436225003336391 |
| -851690886662571060 |
| 1738617244330437274 |
+---------------------+
3 rows in set (0.001 sec)
```

以下の例では、`RANDOM()` の結果を分布関数のランダム入力として使用します。

```shell
SELECT UNIFORM(1, 100, RANDOM()) FROM TABLE(GENERATOR(4));
+---------------------------+
| UNIFORM(1, 100, RANDOM()) |
+---------------------------+
|                        66 |
|                        71 |
|                        52 |
|                        14 |
+---------------------------+
4 rows in set (0.001 sec)
```

以下の例は特別なケースであり、`RANDOM()` のパラメータに変数を指定すると、毎回 `seed` が再計算されます。

```shell
SELECT * FROM t1;
+------+
| c1   |
+------+
|    3 |
|    4 |
|    5 |
|    1 |
|    1 |
+------+
5 rows in set

SELECT t1.c1, RAND(t1.c1), RANDOM(t1.c1) FROM TABLE(GENERATOR(1)), t1;
+------+---------------------+----------------------+
| c1   | RAND(t1.c1)         | RANDOM(t1.c1)        |
+------+---------------------+----------------------+
|    3 |  0.9057697559760601 |  1084041170817055659 |
|    4 | 0.15595286540310166 |  5267436225003336391 |
|    5 | 0.40613597483014313 |  3192483991702052534 |
|    1 | 0.40540353712197724 | -6753783847308464280 |
|    1 | 0.40540353712197724 | -6753783847308464280 |
+------+---------------------+----------------------+
5 rows in set (0.001 sec)
```
