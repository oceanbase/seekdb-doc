# RADIANS

## 宣言

```sql
RADIANS(X)
```

## 説明

この関数は、角度をラジアンに変換し、`X` のラジアン値を返します。ここで、`π` ラジアンは `180` 度に等しいです。

## 例

```sql
SELECT RADIANS(-10), RADIANS(0), RADIANS(10), RADIANS(-0.5), RADIANS(0.5);
+----------------------+------------+---------------------+-----------------------+----------------------+
| RADIANS(-10)         | RADIANS(0) | RADIANS(10)         | RADIANS(-0.5)         | RADIANS(0.5)         |
+----------------------+------------+---------------------+-----------------------+----------------------+
| -0.17453292519943295 |          0 | 0.17453292519943295 | -0.008726646259971648 | 0.008726646259971648 |
+----------------------+------------+---------------------+-----------------------+----------------------+
1 row in set (0.001 sec)
```
