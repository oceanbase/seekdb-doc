# CEILING

## 宣言

```sql
CEILING(X)
```

## 説明

`X` 以上の最小の整数を返します。この関数は `CEIL()` のエイリアスです。

比較演算をサポートしており、結果はBOOL値となります。これは数値型に変換され、`1` (`TRUE`) または `0` (`FALSE`) を返します。

入力が `NULL` の場合、戻り値は `NULL` となります。

純粋な数字の文字列を入力した場合、自動的に数値型に変換できます。

戻り値は BIGINT 型に変換されます。

## 例

```sql
SELECT CEILING(1.23);
+---------------+
| CEILING(1.23) |
+---------------+
|             2 |
+---------------+
1 row in set (0.001 sec)

SELECT CEILING(-1.23);
+----------------+
| CEILING(-1.23) |
+----------------+
|             -1 |
+----------------+
1 row in set (0.001 sec)
```
