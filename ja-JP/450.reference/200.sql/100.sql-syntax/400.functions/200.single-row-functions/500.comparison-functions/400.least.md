# LEAST

## 宣言

```sql
LEAST(value1, ...)
```

## 説明

引数の最小値を返します。`GREATEST()` 関数の対義語です。

パラメータは少なくとも2つ必要です。パラメータに `NULL` が含まれる場合、戻り値は `NULL` になります。

パラメータに数値と文字が混在する場合、文字は暗黙的に数値型に変換されます。変換できない場合はエラーが発生します。

## 例

```javascript
SELECT LEAST(2, null), LEAST('2',4,9), LEAST('a','b','c'), LEAST('a',NULL,'c'), LEAST('2014-05-15','2014-06-01')\G
*************************** 1. row ***************************
                  LEAST(2, null): NULL
                  LEAST('2',4,9): 2
              LEAST('a','b','c'): a
             LEAST('a',NULL,'c'): NULL
LEAST('2014-05-15','2014-06-01'): 2014-05-15
1 row in set (0.001 sec)

SELECT LEAST(2);
ERROR 1582 (42000): Incorrect parameter count in the call to native function 'LEAST'
```
