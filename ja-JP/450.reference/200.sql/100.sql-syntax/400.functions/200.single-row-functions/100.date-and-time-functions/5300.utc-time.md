# UTC_TIME

## 宣言

```sql
UTC_TIME([fsp])
```

## 説明

現在のUTC時刻を`%H:%i:%s`形式で返します。

`fsp`パラメータは分秒の精度を指定するために使用され、有効な値は0から6の整数です。

## 例

```sql
SELECT UTC_TIME(), UTC_TIME() + 0, UTC_TIME() + 6;
+------------+----------------+----------------+
| UTC_TIME() | UTC_TIME() + 0 | UTC_TIME() + 6 |
+------------+----------------+----------------+
| 00:57:50   |           5750 |           5756 |
+------------+----------------+----------------+
1 row in set (0.001 sec)
```
