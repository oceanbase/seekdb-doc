# UNIX_TIMESTAMP

## 宣言

```sql
UNIX_TIMESTAMP()
UNIX_TIMESTAMP(date)
```

## 説明

* `date`パラメータを指定しない場合、現在時刻から `'1970-01-01 00:00:00'` までの秒数を返します。タイムゾーン情報を考慮する必要があります。

* `date`パラメータを指定した場合、指定された時刻から `'1970-01-01 00:00:00'` までの秒数を返します。タイムゾーン情報を考慮する必要があります。

:::info

この関数のパラメータは、`DATE`、`DATETIME`、`TIMESTAMP` 型の日付または時刻を指定できます。

:::

## 例

```javascript
SELECT UNIX_TIMESTAMP(), TIME_TO_USEC(NOW());
+------------------+---------------------+
| UNIX_TIMESTAMP() | TIME_TO_USEC(NOW()) |
+------------------+---------------------+
|       1525570561 |    1525570561000000 |
+------------------+---------------------+
1 row in set (0.001 sec)

SELECT UNIX_TIMESTAMP('1997-10-04 22:23:00');
+---------------------------------------+
| UNIX_TIMESTAMP('1997-10-04 22:23:00') |
+---------------------------------------+
|                             875974980 |
+---------------------------------------+
1 row in set (0.001 sec)
```
