# WEEK

## 宣言

```sql
WEEK(date[,mode])
```

## 説明

日付または日付時刻型の `date` が指定する週が年の中でどの位置にあるかを返します。

`mode` パラメータは、週数計算のロジックを決定するもので、その取り得る範囲と意味は次の表のとおりです。

| 値 | 月曜日 |  範囲   |        意味        |
|----|-------|-------|------------------|
| 0  | 日曜日   | 0\~53 | 最初の日曜日の週がその年の第1週です |
| 1  | 月曜日   | 0\~53 | 4日以上の週が含まれる場合、その週がその年の第1週です |
| 2  | 日曜日   | 1\~53 | 最初の日曜日の週がその年の第1週です |
| 3  | 月曜日   | 1\~53 | 4日以上の週が含まれる場合、その週がその年の第1週です |
| 4  | 日曜日   | 0\~53 | 4日以上の週が含まれる場合、その週がその年の第1週です |
| 5  | 月曜日   | 0\~53 | 最初の月曜日の週がその年の第1週です |
| 6  | 日曜日   | 1\~53 | 4日以上の週が含まれる場合、その週がその年の第1週です |
| 7  | 月曜日   | 1\~53 | 最初の月曜日の週がその年の第1週です |

  :::info

  指定した日付がその年の最初の日付の場合、この関数は前年の最終週を返す可能性があります。

  :::

## 例

```sql
SELECT WEEK('2021-01-01',0);
+----------------------+
| WEEK('2021-01-01',0) |
+----------------------+
|                    0 |
+----------------------+
1 row in set (0.001 sec)
```
