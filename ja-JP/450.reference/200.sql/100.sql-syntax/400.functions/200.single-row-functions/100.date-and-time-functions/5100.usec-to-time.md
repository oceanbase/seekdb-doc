# USEC_TO_TIME

`USEC_TO_TIME` 関数は、マイクロ秒数（usec）を TIMESTAMP 型の値に変換します。seekdb が使用するタイムゾーンは UTC（協定世界時）です。そのため、マイクロ秒数を TIMESTAMP に変換する際、システムはタイムゾーン情報を考慮します。タイムゾーン情報が設定されていない場合は、UTC タイムゾーンで計算されます。

## 関数構文

```sql
USEC_TO_TIME(usec)
```

## パラメータ説明

|パラメータ    | 説明  |
|-------|------|
|`usec` | `TIMESTAMP` 型の値に変換するマイクロ秒数。`usec` は `1970-01-01 00:00:00.000000` からのマイクロ秒数を表します。|

## 例

```sql
SELECT USEC_TO_TIME(1);
+----------------------------+
| USEC_TO_TIME(1)            |
+----------------------------+
| 1970-01-01 08:00:00.000001 |
+----------------------------+
1 row in set (0.001 sec)
```
