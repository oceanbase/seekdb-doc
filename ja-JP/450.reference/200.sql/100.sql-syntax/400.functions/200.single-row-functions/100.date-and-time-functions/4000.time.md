# TIME

## 宣言

```javascript
TIME(datetime)
```

## 説明

`TIME` 型で `datetime` の時刻情報を返します。

## 例

```javascript
SELECT TIME('2003-12-31 01:02:03');
+-----------------------------+
| TIME('2003-12-31 01:02:03') |
+-----------------------------+
| 01:02:03.000000             |
+-----------------------------+
1 row in set (0.000 sec)
```
