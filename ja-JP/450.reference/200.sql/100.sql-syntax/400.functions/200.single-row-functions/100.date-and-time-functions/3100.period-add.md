# PERIOD_ADD

## 宣言

```sql
PERIOD_ADD(P,N)
```

## 説明

期間 `P` に `N` ヶ月を加算します。ここで、`P` の形式は `YYMM` または `YYYYMM` です。

戻り値の形式は `YYYYMM` です。

  :::info

  パラメータ `P` は `DATE` 型、つまり日付以外の値ではなければなりません。

  :::

## 例

```sql
SELECT PERIOD_ADD(200801,2);
+----------------------+
| PERIOD_ADD(200801,2) |
+----------------------+
|               200803 |
+----------------------+
1 row in set (0.001 sec)
```
