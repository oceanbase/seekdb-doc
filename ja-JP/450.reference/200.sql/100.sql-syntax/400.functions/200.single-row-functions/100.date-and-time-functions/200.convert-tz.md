# CONVERT_TZ

## 宣言

```sql
CONVERT_TZ(dt,from_tz,to_tz)
```

## 説明

日付時刻値 `dt` を `from_tz` で指定されたタイムゾーンから `to_tz` で指定されたタイムゾーンに変換し、結果値を返します。`dt` パラメータが無効な場合は `NULL` を返します。

この値が `from_tz` から UTC に変換する際に `TIMESTAMP` 型のサポート範囲を超える場合は、変換は行われません。`TIMESTAMP` 型の範囲の詳細については、[DATE、DATETIME、TIMESTAMP型](../../../100.basic-elements/100.data-type/300.date-and-time-types/200.date-datetime-and-timestamp-types.md)を参照してください。

## 例

```sql
SELECT CONVERT_TZ('2014-01-01 12:00:00','+00:00','+8:00');
+----------------------------------------------------+
| CONVERT_TZ('2014-01-01 12:00:00','+00:00','+8:00') |
+----------------------------------------------------+
| 2014-01-01 20:00:00                                |
+----------------------------------------------------+
1 row in set (0.001 sec)
```
