# DAYOFYEAR

## 宣言

```sql
DAYOFYEAR(date)
```

## 説明

日付または時刻の日付 `date` が一年の中でどの位置にあるかを返します。

## 例

```sql
SELECT DAYOFYEAR('2021-07-15');
+-------------------------+
| DAYOFYEAR('2021-07-15') |
+-------------------------+
|                     196 |
+-------------------------+
1 row in set (0.001 sec)
```
