# STR_TO_DATE

## 宣言

```javascript
STR_TO_DATE(str, format)
```

## 説明

`format` を使用して、`str` を `DATETIME` 値、`DATE` 値、または `TIME` 値に変換します。戻り値の型は、`format` が日付時刻のどの部分を含むかによって決まります。

* `str` または `format` が `NULL` の場合、この関数は `NULL` を返します。

* `str` が有効な日付形式でない場合、戻り値は `sql_mode` の設定によって異なります：

  * `sql_mode` に `NO_ZERO_IN_DATE` が含まれている場合：`NULL` を返します。

  * `sql_mode` に `NO_ZERO_IN_DATE` が含まれていない場合：

    * `str` が INT 型であり、かつ `str` \< 0 の場合、`0000-00-00 00:00:00` を返し、Warning を表示します。

      ```sql
      SELECT STR_TO_DATE(-100,'%Y-%b-%D %r');
      +---------------------------------+
      | STR_TO_DATE(-100,'%Y-%b-%D %r') |
      +---------------------------------+
      | 0000-00-00 00:00:00             |
      +---------------------------------+
      1 row in set, 1 warning (0.001 sec)
      ```

    * `str` が INT 型であり、かつ 0 ≤ `str` ≤ 69 の場合、`NULL` を返し、Warning を表示します。

      ```sql
      SELECT STR_TO_DATE(0,'%Y-%b-%D %r');
      +------------------------------+
      | STR_TO_DATE(0,'%Y-%b-%D %r') |
      +------------------------------+
      | NULL                         |
      +------------------------------+
      1 row in set, 1 warning (0.000 sec)
      ```

    * `str` が INT 型であり、かつ 69 \< `str` ≤ 99 の場合、`NULL` を返し、Warning を表示します。

      ```sql
      SELECT STR_TO_DATE(88,'%Y-%b-%D %r');
      +-------------------------------+
      | STR_TO_DATE(88,'%Y-%b-%D %r') |
      +-------------------------------+
      | NULL                          |
      +-------------------------------+
      1 row in set, 1 warning (0.000 sec)
      ```

    * `str` が INT 型であり、かつ 100 \< `str` ≤ 9999 の場合、`NULL` を返し、Warning を表示します。

      ```sql
      SELECT STR_TO_DATE(2088,'%Y-%b-%D %r');
      +---------------------------------+
      | STR_TO_DATE(2088,'%Y-%b-%D %r') |
      +---------------------------------+
      | NULL             |
      +---------------------------------+
      1 row in set, 1 warning (0.000 sec)
      ```

    * `str` が INT 型であり、かつ `str` \> 10000 の場合、`NULL` を返し、Warning を表示します。

      ```sql
      SELECT STR_TO_DATE(10001,'%Y-%b-%D %r');
      +----------------------------------+
      | STR_TO_DATE(10001,'%Y-%b-%D %r') |
      +----------------------------------+
      | NULL                             |
      +----------------------------------+
      1 row in set, 1 warning (0.000 sec)
      ```

    * `str` が文字列の場合、文字列を可能な限り日付時刻に変換し、`1999-11-30 00:00:00` と `str` を組み合わせた日付時刻型を返します。日付時刻に変換できない場合は `NULL` を返します。

      ```sql
      SELECT STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r');
      +------------------------------------------------------+
      | STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r') |
      +------------------------------------------------------+
      | NULL                                                 |
      +------------------------------------------------------+
      1 row in set, 1 warning (0.001 sec)

      SELECT STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', 'a%Y-%b-%D %r');
      +-------------------------------------------------------+
      | STR_TO_DATE('a2014-Jan-1st 5:5:5 pm', 'a%Y-%b-%D %r') |
      +-------------------------------------------------------+
      | 2014-01-01 05:05:05                                   |
      +-------------------------------------------------------+
      1 row in set (0.001 sec)
      ```

    * `str` がその他の型の場合、`NULL` を返し、Warning を表示します。

      ```sql
      SELECT STR_TO_DATE(1.6,'%Y-%b-%D %r');
      +--------------------------------+
      | STR_TO_DATE(1.6,'%Y-%b-%D %r') |
      +--------------------------------+
      | NULL                           |
      +--------------------------------+
      1 row in set, 1 warning (0.001 sec)

      SELECT STR_TO_DATE(pi(),'%Y-%b-%D %r');
      +---------------------------------+
      | STR_TO_DATE(pi(),'%Y-%b-%D %r') |
      +---------------------------------+
      | NULL                            |
      +---------------------------------+
      1 row in set, 1 warning (0.001 sec)
      ```

`format` がサポートする形式については、[DATE_FORMAT](../100.date-and-time-functions/1000.date-format.md)を参照してください。

## 例

```javascript
SELECT STR_TO_DATE('2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r');
+-----------------------------------------------------+
| STR_TO_DATE('2014-Jan-1st 5:5:5 pm', '%Y-%b-%D %r') |
+-----------------------------------------------------+
| 2014-01-01 05:05:05                                 |
+-----------------------------------------------------+
1 row in set (0.000 sec)
```
