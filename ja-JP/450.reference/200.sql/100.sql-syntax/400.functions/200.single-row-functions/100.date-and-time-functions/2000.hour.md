# HOUR

## 宣言

```sql
HOUR(time)
```

## 説明

時間型 `time` の時刻の部分を返します。

## 例

```sql
SELECT HOUR('10:05:03');
+------------------+
| HOUR('10:05:03') |
+------------------+
|               10 |
+------------------+
1 row in set (0.001 sec)

SELECT HOUR('272:59:59');
+-------------------+
| HOUR('272:59:59') |
+-------------------+
|               272 |
+-------------------+
1 row in set (0.000 sec)
```
