# CURRENT_DATE

## 宣言

```sql
CURRENT_DATE()
CURRENT_DATE
```

## 説明

現在の日付を返します。時刻部分は含まれません。この関数は [CURDATE](../100.date-and-time-functions/300.curdate.md) のエイリアスです。

## 例

```javascript
SELECT CURRENT_DATE;
+--------------+
| CURRENT_DATE |
+--------------+
| 2025-12-17   |
+--------------+
1 row in set (0.001 sec)

SELECT CURRENT_DATE();
+----------------+
| CURRENT_DATE() |
+----------------+
| 2025-12-17     |
+----------------+
1 row in set (0.001 sec)
```
