# DAY

## 宣言

```sql
DAY(date)
```

## 説明

`date` の月の日付を返します。範囲は1から31です。`DAY()` は `DAYOFMONTH()` のシノニムです。

## 例

```sql
SELECT DAY('2008-12-31');
+--------------------------+
| DAY('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
1 row in set (0.001 sec)
```
