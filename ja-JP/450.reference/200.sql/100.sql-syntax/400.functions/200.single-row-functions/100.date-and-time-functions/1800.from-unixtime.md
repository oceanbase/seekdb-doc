# FROM_UNIXTIME

## 宣言

```javascript
FROM_UNIXTIME(unix_timestamp)
FROM_UNIXTIME(unix_timestamp, format)
```

## 説明

`FROM_UNIXTIME()` の戻り値は、以下のルールに従います：

* `format` パラメータを指定しない場合、タイムゾーンを考慮せずに `DATETIME` 型の値を返します。

* `format` パラメータを指定した場合、指定された形式の日付時刻文字列を返します。

`unix_timestamp` とはUNIXタイムスタンプであり、`1970-01-01 00:00:00` からの秒数です。

`format` でサポートされている形式の詳細については、[DATE_FORMAT](../100.date-and-time-functions/1000.date-format.md)を参照してください。

## 例

```javascript
SELECT FROM_UNIXTIME(UNIX_TIMESTAMP(), '%Y %D %M %h:%i:%s %x');
+---------------------------------------------------------+
| FROM_UNIXTIME(UNIX_TIMESTAMP(), '%Y %D %M %h:%i:%s %x') |
+---------------------------------------------------------+
| 2025 17th December 04:39:49 2025                        |
+---------------------------------------------------------+
1 row in set (0.001 sec)
```
