# CURTIME

## 宣言

```javascript
CURTIME(scale)
```

## 説明

日付部分を除いた現在時刻を返します。この関数は `CURRENT_TIME()` のエイリアスです。

`scale` はマイクロ秒の精度を表し、有効な値は `0` から `6` の整数です。デフォルト値は `0` です。

## 例

```sql
SELECT CURTIME(0);
+------------+
| CURTIME(0) |
+------------+
| 16:16:20   |
+------------+
1 row in set (0.001 sec)
```
