# TIMESTAMP

## 宣言

```sql
TIMESTAMP(expr)
TIMESTAMP(expr1,expr2)
```

## 説明

1つ目の宣言は、日付時刻式 `expr` の日付時刻値を返します。

2つ目の宣言は、日付時刻式 `expr1` と時刻式 `expr2` を加算し、日付時刻式を返します。`expr2` に日付が含まれる場合は、その日付の部分は無視され、時刻のみが取り出されます。

いずれかのパラメータが `NULL` の場合、この関数は `NULL` を返します。

## 例

```sql
SELECT TIMESTAMP('2020-12-31');
+----------------------------+
| TIMESTAMP('2020-12-31')    |
+----------------------------+
| 2020-12-31 00:00:00.000000 |
+----------------------------+
1 row in set (0.001 sec)

SELECT TIMESTAMP('2020-12-31 12:00:00','12:00:00');
+---------------------------------------------+
| TIMESTAMP('2020-12-31 12:00:00','12:00:00') |
+---------------------------------------------+
| 2021-01-01 00:00:00.000000                  |
+---------------------------------------------+
1 row in set (0.001 sec)
```
