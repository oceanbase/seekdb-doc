# WEEKOFYEAR

## 宣言

```sql
WEEKOFYEAR(date)
```

## 説明

日付または時刻の日付型 `date` が指定する週が年の中でどの位置にあるかを返します。

## 例

```sql
SELECT WEEKOFYEAR('2020-07-16');
+--------------------------+
| WEEKOFYEAR('2020-07-16') |
+--------------------------+
|                       29 |
+--------------------------+
1 row in set (0.001 sec)
```
