# CURRENT_TIMESTAMP

## 宣言

```javascript
CURRENT_TIMESTAMP([scale])
```

## 説明

現在のタイムゾーンの日付時刻を返します。

`scale` はマイクロ秒部分の精度を表し、有効な値は `0` から `6` の整数です。デフォルト値は `0` です。

## 例

```javascript
SELECT CURRENT_TIMESTAMP(6);
+----------------------------+
| CURRENT_TIMESTAMP(6)       |
+----------------------------+
| 2025-12-17 16:13:31.520977 |
+----------------------------+
1 row in set (0.001 sec)
```
