# QUARTER

## 宣言

```sql
QUARTER(date)
```

## 説明

指定された日付の四半期値を返します。値の範囲は \[1,4\] です。

## 例

```sql
SELECT QUARTER(NOW()), NOW();
+----------------+---------------------+
| QUARTER(NOW()) | NOW()               |
+----------------+---------------------+
|              4 | 2025-12-17 17:19:38 |
+----------------+---------------------+
1 row in set (0.001 sec)
```
