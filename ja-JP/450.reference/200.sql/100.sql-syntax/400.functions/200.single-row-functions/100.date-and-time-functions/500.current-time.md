# CURRENT_TIME

## 宣言

```javascript
CURRENT_TIME([scale])
```

## 説明

日付部分を除いた現在時刻を返します。

`scale`はマイクロ秒の精度を表し、有効な値は`0`から`6`の整数です。デフォルト値は`0`です。

## 例

```javascript
SELECT CURRENT_TIME(6);
+-----------------+
| CURRENT_TIME(6) |
+-----------------+
| 16:11:50.200872 |
+-----------------+
1 row in set (0.001 sec)
```
