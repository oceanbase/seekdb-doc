# DAYOFWEEK

## 宣言

```sql
DAYOFWEEK(date)
```

## 説明

日付または時刻の日付 `date` が週の中でどの位置にあるかを返します。日曜日から計算します。

## 例

```sql
SELECT DAYOFWEEK('2021-07-15');
+-------------------------+
| DAYOFWEEK('2021-07-15') |
+-------------------------+
|                       5 |
+-------------------------+
1 row in set (0.001 sec)
```
