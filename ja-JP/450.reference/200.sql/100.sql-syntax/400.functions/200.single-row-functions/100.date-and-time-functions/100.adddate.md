# ADDDATE

## 宣言

```sql
ADDDATE(date,INTERVAL expr unit)
ADDDATE(expr,days)
```

## 説明

この関数の最初の宣言は `DATE_ADD()` のシノニムです。`unit` パラメータの詳細については、[DATE_ADD](../100.date-and-time-functions/900.date-add.md)を参照してください。

この関数の2番目の宣言は、`days` で指定された日数を `expr` で指定された日付に加算するために使用されます。

## 例

```sql
SELECT ADDDATE('2021-08-01', INTERVAL 31 DAY);
+----------------------------------------+
| ADDDATE('2021-08-01', INTERVAL 31 DAY) |
+----------------------------------------+
| 2021-09-01                             |
+----------------------------------------+
1 row in set (0.001 sec)

SELECT ADDDATE('2021-08-01', 31);
+---------------------------+
| ADDDATE('2021-08-01', 31) |
+---------------------------+
| 2021-09-01                |
+---------------------------+
1 row in set (0.001 sec)
```
