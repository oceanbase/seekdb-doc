# DATEDIFF

## 宣言

```javascript
DATEDIFF(date1, date2)
```

## 説明

`date1` と `date2` の日数の差を返します。

計算ではパラメータの日付部分のみ使用され、時刻部分は無視されます。

## 例

```javascript
SELECT DATEDIFF('2015-06-19','1994-12-17');
+-------------------------------------+
| DATEDIFF('2015-06-19','1994-12-17') |
+-------------------------------------+
|                                7489 |
+-------------------------------------+
1 row in set (0.001 sec)
```
