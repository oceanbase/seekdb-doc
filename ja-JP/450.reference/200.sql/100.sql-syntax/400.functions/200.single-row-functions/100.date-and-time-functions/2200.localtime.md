# LOCALTIME

## 宣言

```sql
LOCALTIME
LOCALTIME([scale])
```

## 説明

現在の日付時刻を返します。`LOCALTIME` と `LOCALTIME()` は `NOW()` の同義語です。

`scale` はマイクロ秒部分の精度を表し、有効な値は `0` から `6` の整数です。デフォルト値は `0` です。

## 例

```sql
SELECT LOCALTIME(0);
+---------------------+
| LOCALTIME(0)        |
+---------------------+
| 2025-12-17 16:54:37 |
+---------------------+
1 row in set (0.001 sec)

SELECT LOCALTIME(6);
+----------------------------+
| LOCALTIME(6)               |
+----------------------------+
| 2025-12-17 16:55:25.584336 |
+----------------------------+
1 row in set (0.000 sec)
```
