# SEC_TO_TIME

## 宣言

```sql
SEC_TO_TIME(seconds)
```

## 説明

`seconds` を時間型に変換した結果を返します。結果の範囲は `TIME` データ型の範囲に限定されます。

## 例

```sql
SELECT SEC_TO_TIME(2378);
+-------------------+
| SEC_TO_TIME(2378) |
+-------------------+
| 00:39:38          |
+-------------------+
1 row in set (0.001 sec)

SELECT SEC_TO_TIME(2378) + 0;
+-----------------------+
| SEC_TO_TIME(2378) + 0 |
+-----------------------+
|                  3938 |
+-----------------------+
1 row in set (0.001 sec)
```
