# ADDTIME

## 宣言

```sql
ADDTIME(expr1,expr2)
```

## 説明

`expr1` は時刻または日付時刻式であり、`expr2` は時刻式です。`ADDTIME()` は `expr2` を `expr1` に加算して結果を返します。

## 例

```sql
SELECT ADDTIME('2022-09-08 23:59:59.999999', '1 1:1:1.000002');
+---------------------------------------------------------+
| ADDTIME('2022-09-08 23:59:59.999999', '1 1:1:1.000002') |
+---------------------------------------------------------+
| 2022-09-10 01:01:01.000001                              |
+---------------------------------------------------------+
1 row in set (0.001 sec)

SELECT ADDTIME('01:10:01.999999', '02:01:10.999998');
+-----------------------------------------------+
| ADDTIME('01:10:01.999999', '02:01:10.999998') |
+-----------------------------------------------+
| 03:11:12.999997                               |
+-----------------------------------------------+
1 row in set (0.000 sec)
```
