# TIME_TO_USEC

## 宣言

```javascript
TIME_TO_USEC(date)
```

## 説明

`date` の値を、タイムゾーン情報を考慮して `1970-01-01 00:00:00.000000` からのミリ秒数に変換します。

`date` は日付または日時を表すことができます。

## 例

```javascript
SELECT TIME_TO_USEC('2014-03-25'), TIME_TO_USEC(NOW());
+----------------------------+---------------------+
| TIME_TO_USEC('2014-03-25') | TIME_TO_USEC(NOW()) |
+----------------------------+---------------------+
|           1395676800000000 |    1765965060000000 |
+----------------------------+---------------------+
1 row in set (0.001 sec)
```
