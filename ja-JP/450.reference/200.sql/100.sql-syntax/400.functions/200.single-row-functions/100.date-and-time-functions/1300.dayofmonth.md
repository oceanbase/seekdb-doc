# DAYOFMONTH

## 宣言

```sql
DAYOFMONTH(date)
```

## 説明

日付または時刻の日付 `date` が月の中でどの位置にあるかを返します。

## 例

```sql
SELECT DAYOFMONTH('2008-12-31');
+--------------------------+
| DAYOFMONTH('2008-12-31') |
+--------------------------+
|                       31 |
+--------------------------+
1 row in set (0.001 sec)
```
