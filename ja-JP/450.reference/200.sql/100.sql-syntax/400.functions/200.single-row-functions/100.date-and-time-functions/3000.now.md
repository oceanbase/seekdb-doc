# NOW

## 宣言

```javascript
NOW([scale])
```

## 説明

現在時刻を返します。タイムゾーンの設定が考慮されます。この関数は `CURRENT_TIMESTAMP()` のエイリアスです。

`scale` はマイクロ秒の精度を表し、有効な値は `0` から `6` の整数です。デフォルト値は `0` です。

## 例

```sql
SELECT NOW(6);
+----------------------------+
| NOW(6)                     |
+----------------------------+
| 2025-12-17 17:13:38.244320 |
+----------------------------+
1 row in set (0.001 sec)
```
