# ORD

## 宣言

```sql
ORD(str)
```

## 説明

文字列の最も左側にある文字の文字コードを返します。単一バイトエンコーディングで、最も左側の文字が複数バイトエンコーディングの文字である場合、戻り値の計算ルールは以下のとおりです：

```sql
(1st byte code)
+ (2nd byte code * 256)
+ (3rd byte code * 256^2) ...
```

最も左側の文字が複数バイト文字でない場合、`ORD()` は `ASCII()` 関数と同じ値を返します。

## 例

```sql
SELECT ORD('中国');
+---------------+
| ORD('中国') |
+---------------+
|      14989485 |
+---------------+
1 row in set (0.001 sec)
```
