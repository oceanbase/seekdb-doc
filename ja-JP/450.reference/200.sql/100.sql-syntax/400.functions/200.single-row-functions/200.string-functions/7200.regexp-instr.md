# REGEXP_INSTR

## 宣言

```sql
REGEXP_INSTR(expr, pat [, pos [, occurrence [, return_option [, match_type ]]]])
```

## 説明

`expr` の中で、`pat` に一致する部分文字列の開始位置を返します。一致する部分文字列が存在しない場合は `0` を返し、`expr` または `pat` が `NULL` の場合も `NULL` を返します。戻り値の位置は `1` から始まります。

* `pos` は、`expr` の何番目の文字から検索を開始するかを示します。デフォルトは `1` です。

* `occurrence` は、`expr` 内で `pat` が何回目に現れる位置を示します。デフォルトは `1` です。

* `return_option` は戻り値のタイプを示します。デフォルトは `0` です。

  * `0` の場合、`REGEXP_INSTR()` は一致した最初の文字の位置を返します。

  * `1` の場合、`REGEXP_INSTR()` は一致した最後の文字の位置を返します。

* `match_type` は一致規則を示します。一致規則の詳細については、[REGEXP_LIKE](../200.string-functions/7300.regexp-like.md)を参照してください。
