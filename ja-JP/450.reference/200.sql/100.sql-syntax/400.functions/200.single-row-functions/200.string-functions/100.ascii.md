# ASCII

## 宣言

```sql
ASCII(str)
```

## 説明

文字列 `str` の最も左側の文字のASCIIコードを返します。

`str` が空文字列の場合、この関数は `0` を返します。`str` が `NULL` の場合、この関数は `NULL` を返します。

## 例

```sql
SELECT ASCII('');
+-----------+
| ASCII('') |
+-----------+
|         0 |
+-----------+
1 row in set (0.001 sec)

SELECT ASCII('oceanbase');
+--------------------+
| ASCII('oceanbase') |
+--------------------+
|                111 |
+--------------------+
1 row in set (0.000 sec)

SELECT ASCII('Oceanbase');
+--------------------+
| ASCII('Oceanbase') |
+--------------------+
|                 79 |
+--------------------+
1 row in set (0.000 sec)
```
