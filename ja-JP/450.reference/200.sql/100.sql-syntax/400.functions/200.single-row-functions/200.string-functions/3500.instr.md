# INSTR

## 宣言

```sql
INSTR(str,substr)
```

## 説明

文字列 `str` 内の部分文字列が最初に現れる位置を返します。これは、パラメータの順序が逆になっていない限り、`LOCATE()` の二重パラメータ形式と同じです。

## 例

```sql
SELECT INSTR('foobarbar', 'bar'), INSTR('xbar', 'foobar');
+---------------------------+-------------------------+
| INSTR('foobarbar', 'bar') | INSTR('xbar', 'foobar') |
+---------------------------+-------------------------+
|                         4 |                       0 |
+---------------------------+-------------------------+
1 row in set (0.001 sec)
```
