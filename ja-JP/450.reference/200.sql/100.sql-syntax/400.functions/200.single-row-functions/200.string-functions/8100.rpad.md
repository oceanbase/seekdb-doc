# RPAD

## 宣言

```sql
RPAD(str,len,padstr)
```

## 説明

文字列 `padstr` を用いて、文字列 `str` の右側を埋めて、長さが `len` になるようにします。

* `str` の長さが `len` より長い場合は、`str` の最初の `len` 文字を返します。

* `str` の長さが `len` より短く、`str` と `padstr` を連結した長さが `len` より長い場合は、連結後の最初の `len` 文字を返します。

* `str` の長さが `len` より短く、`str` と `padstr` を連結した長さが `len` より短い場合は、`str` と複数の `padstr` を繋げた文字列（全長が `len` 以上）の最初の `len` 文字を返します。

## 例

```sql
SELECT RPAD('hi',5,'?');
+------------------+
| RPAD('hi',5,'?') |
+------------------+
| hi???            |
+------------------+
1 row in set (0.001 sec)

SELECT RPAD('hi',1,'?');
+------------------+
| RPAD('hi',1,'?') |
+------------------+
| h                |
+------------------+
1 row in set (0.000 sec)
```
