# STRCMP

## 宣言

```sql
STRCMP(expr1,expr2)
```

## 説明

文字列 `expr1` と `expr2` が一致する場合、`0` を返します。`expr1` が `expr2` の部分文字列の場合、`-1` を返します。`expr2` が `expr1` の部分文字列の場合、`1` を返します。

## 例

```sql
SELECT STRCMP('text', 'text2');
+-------------------------+
| STRCMP('text', 'text2') |
+-------------------------+
|                      -1 |
+-------------------------+
1 row in set (0.001 sec)

SELECT STRCMP('text2', 'text');
+-------------------------+
| STRCMP('text2', 'text') |
+-------------------------+
|                       1 |
+-------------------------+
1 row in set (0.000 sec)

SELECT STRCMP('text', 'text');
+------------------------+
| STRCMP('text', 'text') |
+------------------------+
|                      0 |
+------------------------+
1 row in set (0.000 sec)
```
