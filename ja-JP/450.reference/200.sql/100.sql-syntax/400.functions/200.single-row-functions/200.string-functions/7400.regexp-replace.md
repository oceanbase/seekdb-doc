# REGEXP_REPLACE

## 宣言

```sql
REGEXP_REPLACE(expr, pat, repl[, pos[, occurrence[, match_type]]])
```

## 説明

文字列 `expr` 内で `pat` に一致する部分文字列を `repl` で指定された文字列に置き換え、置き換え後の文字列を返します。`expr`、`pat`、または `repl` が `NULL` の場合、この関数は `NULL` を返します。

* `pos` は、式 `expr` のいずれの文字から検索を開始するかを示します。デフォルトは `1` です。

* `occurrence` は、何番目の一致を `repl` に置き換えるかを示します。デフォルトは `0` で、すべての一致する部分文字列を置き換えることを意味します。

* `match_type` は、一致規則を示します。一致規則の詳細については、[REGEXP_LIKE](../200.string-functions/7300.regexp-like.md)を参照してください。

## 例

```sql
SELECT REGEXP_REPLACE('OceanBase', 'a', '2');
+---------------------------------------+
| REGEXP_REPLACE('OceanBase', 'a', '2') |
+---------------------------------------+
| Oce2nB2se                             |
+---------------------------------------+
1 row in set (0.001 sec)

SELECT REGEXP_REPLACE('OceanBase', 'a', '2',7);
+-----------------------------------------+
| REGEXP_REPLACE('OceanBase', 'a', '2',7) |
+-----------------------------------------+
| OceanB2se                               |
+-----------------------------------------+
1 row in set (0.001 sec)

SELECT REGEXP_REPLACE('OceanBase', 'a', '2',1,2);
+-------------------------------------------+
| REGEXP_REPLACE('OceanBase', 'a', '2',1,2) |
+-------------------------------------------+
| OceanB2se                                 |
+-------------------------------------------+
1 row in set (0.001 sec)
```
