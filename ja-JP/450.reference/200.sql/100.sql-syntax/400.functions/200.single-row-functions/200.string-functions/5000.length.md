# LENGTH

## 宣言

```sql
LENGTH(str)
```

## 説明

`str` のバイト長を返します。

複数バイトの文字は、複数の文字としてカウントされます。例えば、5つの2バイト文字を入力すると、`CHAR_LENGTH()` は `5` を返し、`LENGTH()` は `10` を返します。

## 例

```sql
SELECT LENGTH('中国'), LENGTH('hello');
+------------------+-----------------+
| LENGTH('中国') | LENGTH('hello') |
+------------------+-----------------+
|                6 |               5 |
+------------------+-----------------+
1 row in set (0.001 sec)
```
