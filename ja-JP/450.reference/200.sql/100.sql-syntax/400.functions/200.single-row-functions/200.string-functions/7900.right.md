# RIGHT

## 宣言

```sql
RIGHT(str,len)
```

## 説明

文字列 `str` の右側から `len` 文字を返します。`str` または `len` が `NULL` の場合、`NULL` を返します。

この関数はマルチバイトセーフです。

## 例

```sql
SELECT RIGHT('oceanbase',4);
+----------------------+
| RIGHT('oceanbase',4) |
+----------------------+
| base                 |
+----------------------+
1 row in set (0.001 sec)
```
