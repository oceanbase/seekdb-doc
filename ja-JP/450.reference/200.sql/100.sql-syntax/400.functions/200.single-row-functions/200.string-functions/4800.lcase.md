# LCASE

## 宣言

```sql
LCASE(str)
```

## 説明

文字列内の大文字を小文字に変換します。

この関数は `LOWER()` のシノニムです。

## 例

```sql
SELECT LCASE('OBCLIENTこんにちは！');
+----------------------------+
| LCASE('OBCLIENT您好！')    |
+----------------------------+
| obclient您好！             |
+----------------------------+
1 row in set (0.001 sec)
```
