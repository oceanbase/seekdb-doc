# CHAR

## 宣言

```sql
CHAR(value1,... [USING charset_name])
```

## 説明

各パラメータを整数に変換し、これらの整数のコード値に対応する文字で構成される文字列を返します。`NULL` 値は無視されます。

また、パラメータが255を超える場合、そのパラメータは複数の結果バイトに変換されます。例えば、`CHAR(256)` は `CHAR(1,0)` と等しく、`CHAR(256*256)` は `CHAR(1,0,0)` と等しくなります。

デフォルトでは、`CHAR()` が返す文字列の文字セットは `binary` です。`USING` 句を使用して、返す文字セットを指定できます。

```sql
 SELECT CHARSET(char('')), CHARSET(char('' USING utf8mb4));
+-------------------+---------------------------------+
| CHARSET(char('')) | CHARSET(char('' USING utf8mb4)) |
+-------------------+---------------------------------+
| binary            | utf8mb4                         |
+-------------------+---------------------------------+
1 row in set (0.001 sec)
```

返される値が指定された文字セットで無効な場合、`WARNING` ウォーニングがスローされます。特に、`sql_mode` が `STRICT_ALL_TABLES` または `STRICT_TRANS_TABLES` に設定されている場合、返される値が指定された文字セットで無効な場合は、`NULL` を返します。

`sql_mode` の詳細については、[sql_mode](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002016019)を参照してください。

```sql
SET SESSION sql_mode='STRICT_ALL_TABLES';
Query OK, 0 rows affected (0.000 sec)
SELECT CHAR(399 USING utf8);
+----------------------+
| CHAR(399 USING utf8) |
+----------------------+
| NULL                 |
+----------------------+
1 row in set, 1 warning (0.001 sec)
```

```sql
SELECT CHAR(79,99,101,97,110,66,97.4,115,'101');

```
