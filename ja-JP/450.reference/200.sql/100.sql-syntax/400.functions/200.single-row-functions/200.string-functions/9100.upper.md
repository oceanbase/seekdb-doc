# UPPER

## 宣言

```sql
UPPER(str)
```

## 説明

文字列 `str` の小文字を大文字に変換します。

## 例

```sql
SELECT UPPER('obclientこんにちは!');
+----------------------------+
| UPPER('obclient您好！')    |
+----------------------------+
| OBCLIENT您好！             |
+----------------------------+
1 row in set (0.001 sec)
```
