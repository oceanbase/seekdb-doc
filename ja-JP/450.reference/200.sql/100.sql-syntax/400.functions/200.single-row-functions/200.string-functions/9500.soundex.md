# SOUNDEX

## 宣言

```sql
SOUNDEX(str)
```

## 説明

入力された文字列を、その発音を表すコードに変換します。この関数は、データベースであいまい検索を行ったり、発音が似ている文字列を照合したりする際によく使用されます。

## 例

```sql
SELECT SOUNDEX('a');
+--------------+
| SOUNDEX('a') |
+--------------+
| A000         |
+--------------+
1 row in set (0.001 sec)
```
