# UCASE

## 宣言

```sql
UCASE(str)
```

## 説明

文字列 `str` の小文字を大文字に変換します。この関数は `UPPER()` 関数のシノニムです。

## 例

```sql
SELECT UCASE('obclientこんにちは！');
+----------------------------+
| UCASE('obclient您好！')    |
+----------------------------+
| OBCLIENT您好！             |
+----------------------------+
1 row in set (0.001 sec)
```
