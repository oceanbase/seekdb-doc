# LPAD

## 宣言

```sql
LPAD(str,len,padstr)
```

## 説明

文字列 `padstr` を使って、文字列 `str` の左側を `len` に達するまで埋めます。

`str` の長さが `len` より長い場合は、`str` の最初の `len` 文字を返します。`str` の長さが `len` より短く、かつ `padstr` と `str` を連結した長さが `len` より長い場合は、連結後の文字列の右側から `len` 文字目以降の部分を返します。

## 例

```sql
SELECT LPAD('Base',9,'Ocean');
+------------------------+
| LPAD('Base',9,'Ocean') |
+------------------------+
| OceanBase              |
+------------------------+
1 row in set (0.001 sec)

SELECT LPAD('Base',1,'Ocean');
+------------------------+
| LPAD('Base',1,'Ocean') |
+------------------------+
| B                      |
+------------------------+
1 row in set (0.000 sec)
```
