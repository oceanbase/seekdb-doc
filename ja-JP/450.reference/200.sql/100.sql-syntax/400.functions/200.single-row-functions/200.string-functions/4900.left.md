# LEFT

## 宣言

```sql
LEFT(str,len)
```

## 説明

文字列 `str` の左から `len` 文字を返します。`str` または `len` が `NULL` の場合、`NULL` を返します。

この関数はマルチバイトセーフです。

## 例

```sql
SELECT LEFT('oceanbase', 5);
+----------------------+
| LEFT('oceanbase', 5) |
+----------------------+
| ocean                |
+----------------------+
1 row in set (0.001 sec)
```
