# LOWER

## 宣言

```sql
LOWER(str)
```

## 説明

文字列内の大文字を小文字に変換します。

この関数は `LCASE()` の同義語です。

## 例

```sql
SELECT LOWER('OBCLIENTこんにちは！');
+-----------------------------+
| LOWER('OBCLIENT您好！') |
+-----------------------------+
| obclient您好！          |
+-----------------------------+
1 row in set (0.001 sec)
```
