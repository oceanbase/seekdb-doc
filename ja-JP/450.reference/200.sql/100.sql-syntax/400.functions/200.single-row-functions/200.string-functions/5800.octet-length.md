# OCTET_LENGTH

## 宣言

```sql
OCTET_LENGTH(str)
```

## 説明

`OCTET_LENGTH()`は`LENGTH()`のシノニムです。

## 例

```sql
SELECT OCTET_LENGTH('中国'), OCTET_LENGTH('hello');
+------------------------+-----------------------+
| OCTET_LENGTH('中国')   | OCTET_LENGTH('hello') |
+------------------------+-----------------------+
|                      6 |                     5 |
+------------------------+-----------------------+
1 row in set (0.001 sec)
```
