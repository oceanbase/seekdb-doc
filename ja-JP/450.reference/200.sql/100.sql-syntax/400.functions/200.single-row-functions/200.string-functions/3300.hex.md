# HEX

## 宣言

```sql
HEX(str)
```

## 説明

数値または文字列 `str` を16進数文字列に変換します。ここで、`str` の各文字の各バイトを2つの16進数に変換します。

数値型のパラメータ `N` の場合、`UNHEX(N)` は `HEX(N)` の逆演算ではありません。このような場合は、`CONV(HEX(N),16,10)` を使用することができます。

## 例

```sql
SELECT HEX(255), HEX('abc');
+----------+------------+
| HEX(255) | HEX('abc') |
+----------+------------+
| FF       | 616263     |
+----------+------------+
1 row in set (0.001 sec)
```
