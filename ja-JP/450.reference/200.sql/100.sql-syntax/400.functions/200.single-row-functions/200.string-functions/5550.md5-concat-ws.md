# MD5_CONCAT_WS

## 説明

この関数は、複数の文字列を `separator` で区切りながら結合して1つの文字列にするために使用されます。パラメータに `NULL` が含まれる場合、`replace_null_value` を使用して `NULL` を置き換えて結合し、その後、結合した文字列のMD5ハッシュ値を返します。

## 注意点

* この関数では、ハッシュ衝突が発生する可能性があり、異なる入力が同じ結果を返すことがあります。
* 入力列と重複しない値を `NULL` 値の置き換え値として指定し、可能な限り `NULL` に置き換えた後の結果が入力列の値と重複しないようにしてください。誤った使い方は以下のとおりです：

    ```sql
    MD5_CONCAT_WS('_', '@', 'a', NULL, 'b') = MD5('a_@_b')

    MD5_CONCAT_WS('_', '@', 'a', '@', 'b')  = MD5('a_@_b')
    ```

## 構文

```sql
MD5_CONCAT_WS(separator, replace_null_value, str1, ... , strN)
```

## パラメータの説明

* `separator`：文字列。各入力値を結合する際に使用する区切り文字です。
* `replace_null_value`：文字列。入力値が `NULL` の場合にこの値で置き換えます。
* `str1, ... , strN`：文字列リスト。結合する入力値（可変パラメータ）。

## 戻り値

結合後の文字列のMD5値（32ビット16進数）を返します。

:::tip

`separator` と `replace_null_value` の両方を指定する必要があり、そのうち一方が `NULL` の場合、関数は `NULL` を返します。
:::

## 例

1. テーブル `test_tbl1` を作成します。

    ```shell
    CREATE TABLE test_tbl1 (
        col1 INT PRIMARY KEY,
        col2 VARCHAR(20) NOT NULL,
        col3 VARCHAR(50)
        );
    ```

2. テストデータを挿入します。

    ```shell
    INSERT INTO test_tbl1 VALUES
        (1, 'A1', NULL),
        (2, 'A2', 'OceanBase'),
        (3, 'A3', 'DATABASE'),
        (4, 'A4', NULL),
        (5, 'A5', 'TABLEGROUP');
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 5 rows affected (0.002 sec)
    Records: 5  Duplicates: 0  Warnings: 0
    ```

3. テーブル `test_tbl1` の列 `col1`、`col2`、`col3` を `_` で連結して文字列を作成し、`NULL` 値は `@` に置き換えた後、MD5ハッシュ値を生成します。

    ```shell
    SELECT MD5_CONCAT_WS('_', '@', t1.col1, t1.col2, t1.col3)
        FROM test_tbl1 t1;
    ```

    実行結果は次のとおりです：

    ```shell
    +----------------------------------------------------+
    | MD5_CONCAT_WS('_', '@', t1.col1, t1.col2, t1.col3) |
    +----------------------------------------------------+
    | 7df704a058d6e9293f01ae16c5c01fef                   |
    | a7518a709f593d475604511ab528351d                   |
    | fcd7a30f8897edfaf2f725aafc6af30c                   |
    | 1ad84ebb99c253544f2341f9c2b5dd57                   |
    | 26bb87a94aad329bae3d9cfb10b5614c                   |
    +----------------------------------------------------+
    5 rows in set (0.001 sec)
    ```
