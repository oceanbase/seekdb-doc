# REGEXP

## 宣言

```sql
str [NOT] REGEXP | RLIKE pat
```

## 説明

正規表現によるマッチングです。パラメータに`NULL`が含まれる場合、`NULL`を返します。

## 例

```sql
SELECT
   1234 REGEXP 1,
   'hello' RLIKE 'h%'
   \G
*************************** 1. row ***************************
     1234 REGEXP 1: 1
'hello' RLIKE 'h%': 0
1 row in set (0.002 sec)
```
