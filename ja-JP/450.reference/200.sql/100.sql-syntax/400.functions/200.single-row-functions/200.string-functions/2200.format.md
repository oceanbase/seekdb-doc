# FORMAT

## 宣言

```sql
FORMAT(X,D)
```

## 説明

数値 `X` を `#,###,###.##` 形式にフォーマットし、`D` 桁小数まで四捨五入して文字列として返します。

整数部が3桁を超える場合、千の位の区切りにカンマ（,）を使用します。

`D` が0の場合、結果に小数点または小数部はありません。

## 例

```sql
SELECT FORMAT(12332.123456, 4) FROM DUAL;
+-------------------------+
| format(12332.123456, 4) |
+-------------------------+
| 12,332.1235             |
+-------------------------+
1 row in set (0.001 sec)

SELECT FORMAT(12332.1, 4) FROM DUAL;
+--------------------+
| format(12332.1, 4) |
+--------------------+
| 12,332.1000        |
+--------------------+
1 row in set (0.001 sec)

SELECT FORMAT(12332.2, 0) FROM DUAL;
+--------------------+
| format(12332.2, 0) |
+--------------------+
| 12,332             |
+--------------------+
1 row in set (0.000 sec)
```
