# REVERSE

## 宣言

```sql
REVERSE(str)
```

## 説明

文字列 `str` の逆順に並べ替えたものを返します。

この関数はマルチバイトセーフです。

## 例

```sql
SELECT REVERSE('oceanbase');
+----------------------+
| REVERSE('oceanbase') |
+----------------------+
| esabnaeco            |
+----------------------+
1 row in set (0.001 sec)

SELECT REVERSE(1000);
+---------------+
| REVERSE(1000) |
+---------------+
| 0001          |
+---------------+
1 row in set (0.001 sec)
```
