# IP2INT

## 宣言

```sql
IP2INT('ip_addr')
```

## 説明

IPアドレス `ip_addr` を整数に変換します。

入力されたIPが `s1.s2.s3.s4` の形式である場合、戻り値の計算規則は次のとおりです：

`s1` \* 2^24^ + `s2` \* 2^16^ + `s3` \* 2^8^+ `s4`

## 例

```sql
SELECT
   IP2INT('0.0.0.1'),
   HEX(IP2INT('0.0.0.1')),
   HEX(IP2INT('1.0.0.0'))
   \G
*************************** 1. row ***************************
     IP2INT('0.0.0.1'): 1
HEX(IP2INT('0.0.0.1')): 1
HEX(IP2INT('1.0.0.0')): 1000000
1 row in set (0.001 sec)
```
