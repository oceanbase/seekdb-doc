# NULLIF

## 宣言

```sql
NULLIF(expr1, expr2)
```

## 説明

`expr1` が `expr2` と等しい場合、戻り値は `NULL` となります。そうでない場合、戻り値は `expr1` となります。これは `CASE WHEN`

*`expr1 = expr2 THEN NULL ELSE expr1 END` と同じです。パラメータが等しくない場合、両方の式で求められる値は `expr1` になる点に注意してください。*

## 例

```sql
SELECT NULLIF('ABC', 123), NULLIF('123',123), NULLIF(NULL, 'abc');
+--------------------+-------------------+---------------------+
| NULLIF('ABC', 123) | NULLIF('123',123) | NULLIF(NULL, 'abc') |
+--------------------+-------------------+---------------------+
| ABC                | NULL              | NULL                |
+--------------------+-------------------+---------------------+
1 row in set (0.001 sec), 1 warning
```
