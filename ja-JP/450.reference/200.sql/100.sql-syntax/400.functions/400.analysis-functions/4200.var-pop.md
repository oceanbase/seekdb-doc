# VAR_POP

## 宣言

```sql
VAR_POP([ALL] expr) OVER over_clause
```

## 説明

`expr` 式の全体的な分散を返します。

行がマッチしない場合、この関数は `NULL` を返します。

## 例

```sql
CREATE TABLE EMPLOYEES (MANAGER_ID INT,LAST_NAME VARCHAR(50),HIREDATE VARCHAR(50),SALARY INT);

SELECT LAST_NAME,SALARY,VAR_POP(SALARY) OVER(ORDER BY HIREDATE) AS DEVISION FROM EMPLOYEES WHERE MANAGER_ID = 100;
```
