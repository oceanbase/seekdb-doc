# STDDEV_SAMP

## 宣言

```sql
STDDEV_SAMP([ ALL ] expr) OVER (analytic_clause)
```

## 説明

`expr` の標本標準偏差を返します。この関数は、**VAR_SAMP** 関数の結果の平方根を返します。

マッチする行が見つからない場合、この関数は `NULL` を返します。

## 例

```sql
CREATE TABLE EMPLOYEES (MANAGER_ID INT,LAST_NAME VARCHAR(50),HIREDATE VARCHAR(50),SALARY INT);

SELECT LAST_NAME,SALARY,STDDEV_SAMP(SALARY) OVER(ORDER BY HIREDATE) AS DEVISION FROM EMPLOYEES WHERE MANAGER_ID = 100;
```
