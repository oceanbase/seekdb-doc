# IS_USED_LOCK

## 説明

この関数は、文字列 `str` で名付けられたロックが現在どのセッションによっても使用されているかどうか（つまり、ロックが既に取得されているかどうか）を検出するために使用されます。

## 構文

```sql
IS_USED_LOCK('str')
```

## 説明

### パラメータの説明

`str`: チェック対象のロック名を指定します。文字列型です。

### 戻り値

* セッションIDを返す：ロックが使用されていることを示します。この番号は、そのロックを取得したクライアントセッションを表します。

* `NULL` を返す：ロックがどのセッションにも使用されていないことを示します。

## 例

`my_lock` という名前のロックがどのセッションによっても使用されているかどうかをチェックします。そして、使用者のセッションIDを返します。

```shell
SELECT IS_USED_LOCK('my_lock');
```

実行結果は次のとおりです：

```shell
+-------------------------+
| IS_USED_LOCK('my_lock') |
+-------------------------+
|              3221487701 |
+-------------------------+
1 row in set (0.001 sec)
```

戻り値 `3221487701` は、ロック `my_lock` がセッションID `3221487701` のセッションによって使用されていることを示しています。ビュー `oceanbase.GV$OB_PROCESSLIST` を使用して、このロックを占有するセッションの情報を照会できます。例：

```shell
SELECT * FROM oceanbase.GV$OB_PROCESSLIST WHERE ID = 3221487701\G
```
