# ロック関数の概要

seekdbは、ロックを操作するための関数をサポートしており、次の表のとおりです。

| **関数名** | **説明** |
|--------------|----------|
| [GET_LOCK](200.get-lock.md) | 名前付きロックを取得します。|
| [IS_FREE_LOCK](300.is-free-lock.md) | 指定されたロックが空いているかどうかを確認します。|
| [IS_USED_LOCK](400.is-used-lock.md) | 指定されたロックが使用中かどうかを確認します。|
| [RELEASE_ALL_LOCKS](500.release-all-locks.md) | 現在のセッションが保持しているすべてのロックを解放します。|
| [RELEASE_LOCK](600.release-lock.md) | 指定されたロックを解放します。|
