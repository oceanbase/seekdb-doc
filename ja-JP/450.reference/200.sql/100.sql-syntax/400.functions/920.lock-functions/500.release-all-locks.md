# RELEASE_ALL_LOCKS()

## 説明

この関数は、現在のセッションが保持しているすべての名前付きロックを解放し、成功したロックの解放数を返します。

## 構文

```sql
RELEASE_ALL_LOCKS()
```

## 説明

### パラメータの説明

パラメータはありません。

### 戻り値

成功して解放されたロックの数を返します。現在のセッションがロックを保持していない場合、戻り値は0です。

## 例

現在のセッションが保持するすべての名前付きロックを解放します。

```shell
SELECT RELEASE_ALL_LOCKS();
```

実行結果は次のとおりです：

```shell
+---------------------+
| RELEASE_ALL_LOCKS() |
+---------------------+
|                   1 |
+---------------------+
1 row in set (0.001 sec)
```

戻り値は1で、現在のセッションが保持していた1つの名前付きロックが成功裏に解放されたことを示しています。
