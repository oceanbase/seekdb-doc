# RELEASE_LOCK

## 説明

この関数は、現在のセッションが `GET_LOCK()` 関数を使用して取得した名前付きロック（`str` という名前のロック）を解放するために使用されます。

## 構文

```sql
RELEASE_LOCK('str')
```

## 説明

### パラメータの説明

`str`: 解放するロックの名前を指定します。文字列型です。

### 戻り値

* 1を返す：現在のセッションがそのロックを保持しており、ロックが正常に解放されたことを示します。
* 0を返す：現在のセッションがそのロックの所有者ではないか、ロックが現在のセッションによって解放されていないことを示します。
* `NULL` を返す：ロックが存在しないことを示します。つまり、`GET_LOCK()` でロックを取得していないか、そのロックは以前に解放されている可能性があります。

## 例

`my_lock` という名前のロックを解放します。

```shell
SELECT RELEASE_LOCK('my_lock');
```

戻り結果は次のとおりです：

```shell
+-------------------------+
| RELEASE_LOCK('my_lock') |
+-------------------------+
|                       0 |
+-------------------------+
1 row in set (0.001 sec)
```

戻り結果が0であることは、現在のセッションがロック `my_lock` の所有者ではなく、そのロックが現在のセッションによって解放されていないことを示します。
