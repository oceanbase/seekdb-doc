# ジオメトリ処理関数

空間演算関数は、空間幾何オブジェクトに対して様々な操作や変換を行うために使用されます。これには、形状の変更、幾何的関係の計算、空間クエリ、その他の種類の空間分析が含まれます。

seekdbが現在サポートしているジオメトリ処理関数には、`_ST_MakeValid()` があります。

## _ST_MakeValid

地理情報システム（GIS）では、空間データはしばしば特定の有効性基準を満たす必要があります。有効なポリゴンは単純で（自己交差せず）、正しく囲まれている（外側の輪郭は時計回り、内側の輪郭は反時計回り）ものである必要があります。一方、無効なポリゴンには、自己交差、輪郭の重複、穴の露出などの幾何学的誤りが含まれる可能性があります。

`_ST_MakeValid` 関数は、無効な幾何図形（例えばポリゴン）を修正し、有効な幾何図形にするために使用されます。また、`_ST_MakeValid` 関数は投影座標系のみをサポートし、地理座標系はサポートしていません。

- 投影座標系をサポート：この関数は、入力される幾何オブジェクトが地理座標系ではなく投影座標系を使用していることを想定しています。投影座標系は平面座標系であり、地上の位置は2つの座標で表されます。

- 地理座標系をサポートしない：地理座標系は地球の経緯度システムに基づいており、地球の曲率を考慮しています。`_ST_MakeValid` 関数は地理座標系をサポートしていないため、入力される幾何オブジェクトは経緯度に基づく座標であってはなりません。

構文は以下のとおりです：

```sql
_ST_MakeValid(geometry input)
```

パラメータの説明：

- `geometry input`: これは関数の入力パラメータで、修正が必要な幾何オブジェクトを表します。点（Point）、線（LineString）、ポリゴン（Polygon）など、任意のタイプの幾何図形を指定できます。

例：

```sql
select st_astext(_st_makevalid(st_geomfromtext('POLYGON((0 0,1 1,2 2,0 2,1 1,2 0,0 0))')));
```

この例では、まず `st_geomfromtext('POLYGON((0 0,1 1,2 2,0 2,1 1,2 0,0 0))')` がテキスト形式のポリゴンを幾何オブジェクトに変換します。テキスト文字列 `'POLYGON((0 0,1 1,2 2,0 2,1 1,2 0,0 0))'` はポリゴンの頂点座標のシーケンスを表しますが、このポリゴンは自己交差しているため無効です。

次に、`_st_makevalid(...)` 関数が、渡された無効なポリゴン幾何オブジェクトを修正し、有効なポリゴンに変換します。

最後に、`st.astext(...)` が修正後の幾何オブジェクトをWell-Known Text（WKT）形式に変換します。

戻り値は以下のとおりです：

```shell
+-------------------------------------------------------------------------------------+
| st_astext(_st_makevalid(st_geomfromtext('POLYGON((0 0,1 1,2 2,0 2,1 1,2 0,0 0))'))) |
+-------------------------------------------------------------------------------------+
| MULTIPOLYGON(((1 1,2 2,0 2,1 1)),((1 1,0 0,2 0,1 1)))                               |
+-------------------------------------------------------------------------------------+
1 row in set (0.001 sec)
```
