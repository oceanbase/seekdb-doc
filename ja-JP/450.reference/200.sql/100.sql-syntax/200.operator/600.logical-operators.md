# 論理演算子

seekdbは一般的な論理演算子をサポートしています。

## 論理演算子の概要

seekdbの現在のバージョンでサポートされている論理演算子の詳細は、次の表のとおりです。

|    演算子     | 演算子    | 意味    |
|------------|-----|------|
| `NOT`/`!`  | 一元  | 論理非  |
| `AND`/`&&` | 二項  | 論理積  |
| `OR`/`||`  | 二項  | 論理和  |
| `XOR`      | 複数元  | 論理排他和 |

## 説明

SQLでは、すべての論理演算子の結果は`TRUE`、`FALSE`、または`NULL (UNKNOWN)`です。seekdbでは、これらを1(`TRUE`)、0(`FALSE`)、`NULL`として実装し、0以外の非`NULL`値をすべて`TRUE`と評価します。

## 制限

`ANY`演算子は配列データ型でのみサポートされます。使用方法と例については、[配列判定関数](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001976559)を参照してください。

### NOT/!

演算子が0の場合、結果は1となります。演算子が0以外の場合、結果は0となり、`NOT NULL`は`NULL`を返します。

例：

```sql
SELECT NOT NULL;
+----------+
| NOT NULL |
+----------+
|     NULL |
+----------+
1 row in set (0.001 sec)

SELECT ! (1+1);
+---------+
| ! (1+1) |
+---------+
|       0 |
+---------+
1 row in set (0.001 sec)
```

### AND/\&\&

すべての演算子が0以外であり、かつ`NULL`ではない場合、結果は1となります。1つ以上の演算子が0の場合、結果は0となります。それ以外の場合は`NULL`を返します。

例：

```sql
SELECT 1 AND NULL;
+------------+
| 1 AND NULL |
+------------+
|       NULL |
+------------+
1 row in set (0.001 sec)

SELECT 0 AND NULL;
+------------+
| 0 AND NULL |
+------------+
|          0 |
+------------+
1 row in set (0.000 sec)
```

### OR/\|\|

2つの演算子がどちらも`NULL`ではない場合、いずれかの演算子が0以外の場合、結果は1となります。そうでない場合は0となります。`NULL`を含む演算子の場合、もう一方の演算子が0以外の場合、結果は1となります。そうでない場合は`NULL`を返します。両方の演算子が`NULL`の場合、結果は`NULL`となります。

例：

```sql
SELECT 0 OR NULL;
+-----------+
| 0 OR NULL |
+-----------+
|      NULL |
+-----------+
1 row in set (0.001 sec)

SELECT 1 OR NULL;
+-----------+
| 1 OR NULL |
+-----------+
|         1 |
+-----------+
1 row in set (0.000 sec)
```

### XOR

いずれかの演算子が`NULL`の場合、`NULL`を返します。`NULL`以外の演算子については、奇数個の演算子が0でない場合、結果は1となります。そうでない場合は0を返します。

例：

```sql
SELECT 1 XOR NULL;
+------------+
| 1 XOR NULL |
+------------+
|       NULL |
+------------+
1 row in set (0.001 sec)

SELECT 1 XOR 1 XOR 1;
+---------------+
| 1 XOR 1 XOR 1 |
+---------------+
|             1 |
+---------------+
1 row in set (0.001 sec)
```

  :::info

  `a XOR b`は数学的には`(a AND (NOT b)) OR ((NOT a) and b)`と等しくなります。

  :::
