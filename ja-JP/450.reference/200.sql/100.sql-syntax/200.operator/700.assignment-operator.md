# 赋値演算子

seekdbは一般的な代入演算子をサポートしています。

## 論理演算子の概要

| 演算子 | 演算子 |                         意味                         |
|-----|-----|----------------------------------------------------|
| :=  | 一元  | 演算子の右側の値を左側の変数に代入します                                   |
| =   | 一元  | 値の代入（`SET` ステートメントの一部、または `UPDATE` ステートメント内の `SET` 句の一部として使用されます） |

## 説明

### 赋値演算子 :=

`:=` の右辺には、リテラル、変数、またはクエリの結果などの有効な式を記述できます（ただし、その値がスカラーである必要があります）。同一の `SET` 文内で複数回の代入を実行することができます。同一の文内で複数回の代入を行うことも可能です。

`=` とは異なり、`:=` 演算子は比較演算子として解釈されることはありません。これは、`SET` 文だけでなく、任意の有効なSQL文で `:=` を使用して変数に値を代入できることを意味します。

例：

```sql
SELECT @var1 := 1, @var2;
+------------+-------+
| @var1 := 1 | @var2 |
+------------+-------+
|          1 | NULL  |
+------------+-------+
1 row in set (0.001 sec)

SELECT @var1:=COUNT(*) FROM t1;
+-----------------+
| @var1:=COUNT(*) |
+-----------------+
|               5 |
+-----------------+
1 row in set (0.004 sec)

SELECT @var1;
+-------+
| @var1 |
+-------+
|     5 |
+-------+
1 row in set (0.001 sec)
```

### 赋値演算子 =

`=` 演算子は、以下の2つの場合に代入を実行します：

* `SET` 文では、`=` は代入演算子と見なされ、演算子の右側の値を左側の変数に代入します。したがって、`SET` 文で使用する場合、`=` と `:=` の処理方法は同じです。

* `UPDATE` 文の `SET` 句では、`=` も代入演算子として機能します。この場合、`UPDATE` 文の `WHERE` 条件を満たすと、演算子の右側の値が左側の列に代入されます。`UPDATE` 文の同一の `SET` 句内で複数回の代入を行うことができます。

上記の2つの場合を除き、`=` は比較演算子と見なされます。

```sql
SELECT * FROM t1;
+------+------+
| c1   | c2   |
+------+------+
|    1 |    1 |
+------+------+
1 row in set (0.003 sec)

UPDATE t1 SET c1 = c1 + 1, c2 = c1;
Query OK, 1 row affected (0.003 sec)
Rows matched: 1  Changed: 1  Warnings: 0

SELECT * FROM t1;
+------+------+
| c1   | c2   |
+------+------+
|    2 |    2 |
+------+------+
1 row in set (0.002 sec)
```
