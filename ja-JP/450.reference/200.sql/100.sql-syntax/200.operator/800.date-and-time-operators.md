# 日付時刻演算子

seekdbは日付時刻演算子をサポートしており、指定された時刻・日付関数と同等の機能を提供します。

seekdbの現在のバージョンでサポートされている日付時刻演算子の詳細は、次の表のとおりです。

| 演算子 | 演算子 |                                                    意味                                                    |
|-----|-----|----------------------------------------------------------------------------------------------------------|
| `+` | 二項演算子 | 日付と時刻を足します。`DATE_ADD` 関数と同じです。[DATE_ADD](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001975960) を参照してください。 |
| `-` | 二項演算子 | 日付と時刻を引きます。`DATE_SUB` 関数と同じです。[DATE_SUB](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001975999) を参照してください。 |

例：

```javascript
SELECT '2008-12-31 23:59:59' + INTERVAL 1 SECOND;
+-------------------------------------------+
| '2008-12-31 23:59:59' + INTERVAL 1 SECOND |
+-------------------------------------------+
| 2009-01-01 00:00:00                       |
+-------------------------------------------+
1 row in set (0.001 sec)
```
