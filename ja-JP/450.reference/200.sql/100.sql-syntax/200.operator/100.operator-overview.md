# 演算子の概要

演算子は通常、オペランドやパラメータなどの単一のデータ項目を結合して結果を返すために使用されます。構文的には、演算子はオペランドの前、オペランドの後、または2つのオペランドの間に配置することができます。

一般的な演算子は、一元演算子と二元演算子に分類することもできます：

* 一元演算子

  一元演算子は、1つのオペランドに対してのみ演算を行います。一元演算子の一般的な書式は次のとおりです：

  ```sql
  演算子 オペランド
  ```

* 二元演算子

  二元演算子は、2つのオペランドに対して演算を行います。二元演算子の一般的な書式は次のとおりです：

  ```sql
  オペランド1 演算子 オペランド2
  ```

  :::info

  * その他の特殊な書式を持つ演算子は、2つ以上のオペランドを受け付けることができます。
  * 演算子に空オペランド`NULL`を提供した場合、結果は常にNULLになります。このルールに従わない唯一の例外は、文字連結演算子（||）です。

  :::
