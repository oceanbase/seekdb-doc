# 数値

数値には、十進数と十六進数の2種類があります。

## 十進数

十進数は、正確な数値（整数と固定小数点数）と浮動小数点数に分けられます。数値は、小数点 `.` を十進数の区切り文字として使用できますし、負の値を表すために前にマイナス記号 `-` を付けることもできます。

`DECIMAL` データ型は固定小数点数型であり、正確な計算を行います。`FLOAT` および `DOUBLE` データ型は浮動小数点数型であり、近似計算を行います。

:::info

`DECIMAL` 型はサイズ変更が可能です（例：`DECIMAL(10, 2)` を `DECIMAL(9, 2)` に変更する）。

:::

正確な数値には整数部または小数部、あるいはその両方があります。例：1、.2、3.4、-5、-6.78、+9.10。

近似値は科学記数法で表され、尾数と指数を持ちます。例：1.2E3、1.2E-3、-1.2E3、-1.2E-3。

見た目が似ている2つの数値は、異なる扱いを受ける場合があります。例えば、2.34 は正確な（固定小数点）数値であり、2.34E0 は近似値（浮動小数点）数値です。

## 十六進数

十六進数は整数値のみをサポートします。`X` または `0x` のプレフィックスで始まり、`A` から `F` までの英字を含むことができます。すべての英字は大文字と小文字を区別しません。

以下は有効な十六進数です：

```sql
X'01AF'
X'01af'
x'01AF'
x'01af'
0x01AF
0x01af
```

以下は無効な十六進数です：

```sql
X'0H'（H は十六進数ではありません）
```

`X` プレフィックスを使用する値は偶数文字数でなければならず、そうでない場合は構文エラーが発生します。この問題を回避するには、値を `0` で埋めてください。例：`X'0FFF'`。

`0x` プレフィックスを使用する値が奇数文字数の場合、余分な先頭 `0` があると見なされます。例えば、`0xaaF` は `0x0aaF` と解釈されます。

デフォルトでは、十六進数はバイナリ文字列であり、各16進数のペアが1文字を表します：

```sql
SELECT 0x5461626c65, CHARSET(0x5461626c65);
+--------------+-----------------------+
| 0x5461626c65 | CHARSET(0x5461626c65) |
+--------------+-----------------------+
| Table        | binary                |
+--------------+-----------------------+
1 row in set (0.001 sec)
```

空の十六進数値 (X' ') は、長さゼロのバイナリ文字列として計算されます。数値に変換して出力すると `0` になります：

```sql
SELECT X''+0;
+-------+
| X''+0 |
+-------+
|     0 |
+-------+
1 row in set (0.001 sec)
```

文字列や数値を十六進数形式の文字列に変換するには、`HEX()` 関数を使用します：

```sql
SELECT HEX('dog');
+------------+
| HEX('dog') |
+------------+
| 646F67     |
+------------+
1 row in set (0.001 sec)

SELECT X'646F67';
+-----------+
| X'646F67' |
+-----------+
| dog       |
+-----------+
1 row in set (0.001 sec)
```
