# リテラルの概要

リテラル（Literal）は、固定値を表現するために使用されます。

多くの関数やSQL文ではリテラルを指定する必要があり、リテラルは式や条件の一部としても使用できます。

seekdbは以下のリテラルをサポートしています：

* [文字列テキスト](../400.literal/200.string-literal.md)

* [数値](../400.literal/300.numeric-value.md)

* [日付時刻値](../400.literal/400.date-and-time.md)

* [ビット値](../400.literal/500.hexadecimal-numeric.md)

* [ブール値](../400.literal/600.boolean.md)

* [NULL値](../400.literal/700.null-value.md)
