# 概要

文字セットとは、記号とエンコーディングの集合です。照合順序とは、文字セット内の文字を比較するための一連のルールです。

seekdbは、文字セットと照合順序に関して以下の機能をサポートしています：

* さまざまな文字セットを使用して文字列を格納します。

* さまざまなソート規則を使用して文字列を比較します。

* 同一サーバー、同一データベース、または同一テーブル内で異なる文字セットや照合順序の文字列を混在させて使用できます。

* データベースレベル、テーブルレベル、列レベルで文字セットと照合順序の仕様を有効にできます。
