# 照合順序

seekdbのデフォルトの照合順序は`utf8mb4_general_ci`です。

seekdbが現在サポートしている照合順序は、次のテーブルのとおりです。

|--------------------|---------|-----------------------------------------------|

  :::info

  任意のUnicode文字セットについて、`xxx_general_ci`ソート規則を使用した操作は、`xxx_unicode_ci`ソート規則を使用した操作よりも高速です。

  照合順序の変更は、現在サポートされていません。

  :::

デフォルトでは、`SHOW COLLATION`ステートメントを使用して、利用可能なすべての照合順序を表示できます。

```shell
SHOW COLLATION;
```

照合順序には、一般的に以下の特徴があります：

* 二つの異なる文字セットが同じ照合順序を持つことはできません。

* 各文字セットにはデフォルトの照合順序があります。`SHOW CHARACTER SET`ステートメントは、各文字セットのデフォルトの照合順序を示します。`SHOW COLLATION`ステートメントには、各照合順序がその文字セットのデフォルト値かどうかを示す列があります（デフォルトの場合はYes、そうでない場合は空文字列）。

* 照合順序名は、関連する文字セット名で始まり、通常は他の照合順序の特徴を示す1つ以上の接尾辞が続きます。
