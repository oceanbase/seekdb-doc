# データベースレベルの文字セットと照合順序

各データベースには、デフォルトの文字セットとデフォルトの照合順序が設定されています。

## データベースの文字セットと照合順序の指定

`CREATE DATABASE` ステートメントは、データベースの文字セットと照合順序を指定するために使用され、構文は以下のとおりです：

```sql
CREATE DATABASE database_name
    [DEFAULT] CHARACTER SET [=] charset_name
    [[DEFAULT] COLLATE [=] collation_name]

ALTER DATABASE database_name
    [[DEFAULT] CHARACTER SET charset_name]
    [[DEFAULT] COLLATE collation_name]

```

ここで、`CHARACTER SET` 句と `COLLATE` 句を使用することで、同一の `CREATE DATABASE` 文内で異なる文字セットと照合順序を持つデータベースを作成できます。

データベースの文字セットの作成と変更の例を以下に示します：

```sql
/* ラテン文字セットのデータベースを直接作成 */
CREATE DATABASE latin1_db CHARSET latin1;

/* 既存のUTF-8データベースをラテン文字セットのデータベースに変更 */
CREATE DATABASE db CHARSET=utf8mb4;
ALTER DATABASE db CHARSET latin1;
```

## データベースの文字セットと照合順序の選択

`CREATE DATABASE` 文は、以下の方法でデータベースの文字セットと照合順序を選択します：

* `CHARACTER SET charset_name` と `COLLATE collation_name` の両方を指定した場合、文字セット `charset_name` と照合順序 `collation_name` を使用します。

* `CHARACTER SET charset_name` を指定したが `COLLATE` を指定しなかった場合、文字セット `charset_name` とそのデフォルトの照合順序を使用します。各文字セットのデフォルトの照合順序を確認するには、`SHOW CHARACTER SET` ステートメントを使用してください。

* `COLLATE collation_name` を指定したが `CHARACTER SET` を指定しなかった場合、`collation_name` に関連付けられた文字セットと指定された照合順序を使用します。

* `CHARACTER SET` と `COLLATE` のどちらも指定しなかった場合、サーバーの文字セットと照合順序を使用します。

デフォルトのデータベースの文字セットと照合順序は、`character_set_database` および `collation_database` システム変数の値によって決定されます。特定のデータベースのデフォルトの文字セットと照合順序を確認するには、以下のステートメントを使用してください：

```sql
USE database_name;
SELECT @@character_set_database, @@collation_database;
```

または：

```sql
SELECT DEFAULT_CHARACTER_SET_NAME, DEFAULT_COLLATION_NAME
FROM INFORMATION_SCHEMA.SCHEMATA WHERE SCHEMA_NAME = 'database_name';
```

例：

```sql
SET collation_database = 'latin1_swedish_ci';
Query OK, 0 rows affected (0.000 sec)
```
