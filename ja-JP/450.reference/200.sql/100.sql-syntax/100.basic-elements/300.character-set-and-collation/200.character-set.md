# 文字セット

seekdbのデフォルト文字セットは`utf8mb4`です。

seekdbが現在サポートしている文字セットは以下のとおりです：

* `binary`

* `gbk`

* `gb18030`

* `utf16`

* `utf8mb4`/`utf8mb3`

  :::info

  シームレスな移行をサポートするため、seekdbでは構文的に`UTF8`を`UTF8MB4`のシノニムと見なします。
  `utf8mb3`は`utf8mb4`のエイリアスです。

  :::

* `latin1`

* `gb2312`

* `gb18030_2022`

* `ascii`

* `tis620`

* `ujis`

* `euckr`

* `eucjpms`

* `cp932`

* `utf16le`

* `sjis`

* `dec8`

* `hkscs`

* `hkscs31`

* `big5`

* `cp850`

* `hp8`

* `macroman`

* `swe7`

seekdbの現在のバージョンでは、`gb18030`と`gb18030_2022`の暗黙的な変換はサポートされていません。ただし、ユーザーは`CONVERT`を使用して、`gb18030`文字列の文字セットを明示的に`gb18030_2022`に変換できます。この変換はUnicodeを経由せず、エンコーディングを保持する方法が採用されています。以下の例では、‘龴’のエンコーディングは変換前後でどちらも`0xFE59`であり、変化していません。

```shell
SELECT HEX(CONVERT(_gb18030 0xFE59 USING gb18030_2022)), HEX(CONVERT(_gb18030_2022 0xFE59 USING gb18030));
```

結果は次のとおりです：

```shell
+--------------------------------------------------+--------------------------------------------------+
| HEX(CONVERT(_gb18030 0xFE59 USING gb18030_2022)) | HEX(CONVERT(_gb18030_2022 0xFE59 USING gb18030)) |
+--------------------------------------------------+--------------------------------------------------+
| FE59                                             | FE59                                             |
+--------------------------------------------------+--------------------------------------------------+
1 row in set (0.001 sec)
```

## デフォルト以外の文字セットの指定

seekdbは、サーバーとの通信においてデフォルト以外の文字セットを指定することをサポートしています。例えば、`gbk` 文字セットを使用する場合、サーバーに接続した後、以下のステートメントを実行します：

```sql
SET NAMES gbk;
```

注意点として、`SET NAMES` ステートメントはクライアントが入力する文字のエンコーディングを変更しません。例えば、`SET NAMES` を使用してクライアントのエンコーディングを `gb18030_2022` に設定する前提として、クライアントが既に `gb18030_2022` エンコーディングを使用している必要があります。そうでない場合、文字化けが発生します。

```shell
/* クライアントはutf8mb4文字セットを使用し、デフォルトでutf8mb4文字セットのテーブルtを作成 */
CREATE TABLE t(c VARCHAR(100));
Query OK, 0 rows affected (0.069 sec)

/* utf8mb4エンコードの文字を挿入 */
INSERT INTO t VALUES ('文字セット');
Query OK, 1 row affected (0.003 sec)

/* 現在のセッションの文字セットを変更しますが、クライアントが実際に使用する文字セットは変更されません */
SET NAMES gb18030_2022;
Query OK, 0 rows affected (0.000 sec)

/* 依然としてutf8mb4エンコードで文字を挿入 */
INSERT INTO t VALUES ('文字セット');
Query OK, 1 row affected (0.002 sec)

/* テーブルtのデータをクエリしても文字化けは発生しません */
SELECT * FROM t;
+----------+
| c        |
+----------+
| 字符     |
| 字符     |
+----------+
2 rows in set (0.002 sec)

/* 現在のセッションの文字セットをutf8mb4に変更 */
SET NAMES utf8mb4;
Query OK, 0 rows affected (0.000 sec)

/* 再度テーブルtのデータをクエリします。2回目に挿入した文字は文字化けします */
SELECT * FROM t;
+--------------+
| c            |
+--------------+
| 瀛楃闆      |
| 瀛楃闆      |
+--------------+
2 rows in set (0.001 sec)
```
