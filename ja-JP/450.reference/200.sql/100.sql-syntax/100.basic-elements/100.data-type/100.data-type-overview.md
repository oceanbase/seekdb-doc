# データ型の概要

この章では、seekdb の現在のバージョンでサポートされている MySQL データ型とそのプロパティ、ストレージ要件などについて説明します。

seekdb の現在のバージョンがサポートするデータ型は以下の通りです：

* [数値型](200.numeric/100.numeric-type.md)

* [日付・時刻型](300.date-and-time-types/100.date-and-time-types.md)

* [文字列型](400.string/100.string-type-overview.md)

* [BLOB型](500.large-object/100.large-object-and-text-type-overview.md)

* [テキスト型](500.large-object/100.large-object-and-text-type-overview.md)

* [列挙型](../100.data-type/600.enum-type.md)

* [集合型](../100.data-type/700.set-type.md)

* [JSON データ型](800.json-formatted-data-type/100.json-formatted-data-types-of-syntax.md)

* [空間データ型](900.spatial-data-type/100.spatial-data-type-overview-of-syntax.md)

* [効率的圧縮ビットマップデータ型](1000.roaring-bitmap-data-type/100.roaring-bitmap-data-type-overview.md)

* [配列データ型](1200.array-data-type/100.array-data-type-overview.md)

* [マップデータ型](1300.map-data-type/100.map-data-type-overview.md)

seekdb は任意の2つ以上のデータ型を比較することができ、比較結果は以下のようになります：

* 非0 / `TRUE`

* 0 / `FALSE`

* `NULL`

比較するデータ型が一致しない場合、seekdb は関連するルールに基づいて比較用のデータ型を決定します。論理的には、比較に参加するすべてのデータは、比較操作を行う前にこのデータ型に変換する必要があります。比較対象がテキスト型の場合は、比較に使用する照合順序も決定する必要があります。

比較演算の変換ルールについては、[式評価における型変換](../200.expression/300.type-conversion-of-expression-evaluation.md)を参照してください。
