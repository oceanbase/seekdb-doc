# 文字列データ型の概要

seekdbがサポートする文字データ型は`CHAR`、`VARCHAR`、`BINARY`、および`VARBINARY`です。

seekdbの現在のバージョンでサポートされている一般的な文字列データ型とその関連情報は、次の表のとおりです。

|     型        | 長さの種類 |   最大長   |    文字セット    |
|-------------|------|----------|-----------|
| `CHAR`      | 固定長   | 256文字   | `UTF8MB4` |
| `VARCHAR`   | 可変長   | 262144文字 | `UTF8MB4` |
| `BINARY`    | 固定長   | 256バイト   | `BINARY`  |
| `VARBINARY` | 可変長   | 1048576バイト | `BINARY`  |

`CHAR`型では文字を長さの単位とし、`VARCHAR`型およびバイナリ文字列の`BINARY`型と`VARBINARY`型ではバイトを長さの単位とします。
