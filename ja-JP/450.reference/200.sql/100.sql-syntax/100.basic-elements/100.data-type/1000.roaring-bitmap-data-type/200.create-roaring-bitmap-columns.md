# 高効率圧縮ビットマップ列の作成

seekdbでは、`CREATE TABLE` または `ALTER TABLE` を使用して高効率圧縮ビットマップ列を作成できます。

## 注意事項

* 可視化されたクエリ結果を見るには、クライアントに接続する際に `--binary-as-hex` パラメータを追加し、バイナリ結果を16進数に変換する必要があります。

## 例

`CREATE TABLE` ステートメントを使用して、高効率圧縮ビットマップ列を含むテーブルを作成する構文例は以下のとおりです：

```sql
CREATE TABLE t1 (rb ROARINGBITMAP);
```

`ALTER TABLE` ステートメントを使用して、既存のテーブルに高効率圧縮ビットマップ列を追加または削除する構文例は以下のとおりです：

```sql
ALTER TABLE t1 ADD COLUMN rb2 ROARINGBITMAP;
ALTER TABLE t1 DROP COLUMN rb2;

```

高効率圧縮ビットマップ列にデフォルト値を設定する構文例は以下のとおりです：

```sql
ALTER TABLE t1 MODIFY COLUMN rb ROARINGBITMAP DEFAULT x'0100';
```

高効率圧縮ビットマップデータの書き込みとクエリの例は以下のとおりです：

```shell
// テストテーブルの作成
CREATE TABLE t2 (
    rb ROARINGBITMAP
);
          DESC t2;

// テストデータの挿入
INSERT INTO t2 VALUES (rb_from_string('1,2,3'));
          INSERT INTO t2 VALUES (x'0100');

// テストテーブルのクエリ
SELECT * FROM t2;
```

実行結果は次のとおりです：

```shell
+----------------------------------+
| rb                               |
+----------------------------------+
| 0x010303010000000200000003000000 |
| 0x0100                           |
+----------------------------------+
2 rows in set (0.002 sec)
```
