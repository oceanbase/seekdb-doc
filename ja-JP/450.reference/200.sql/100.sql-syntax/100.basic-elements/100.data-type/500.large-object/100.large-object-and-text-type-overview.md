# ラージオブジェクトとテキスト型の概要

seekdbがサポートするラージオブジェクトデータ型 `BLOB` とテキスト型 `TEXT` について説明します。

seekdbの現在のバージョンでサポートされているラージオブジェクトとテキスト型、および関連情報は次の表のとおりです。

|      型      | 長さ |   最大ストレージ長(バイト)   |    文字セット    |
|--------------|----|----------------|-----------|
| `TINYBLOB`   | 可変長 | 255          | `BINARY`  |
| `BLOB`       | 可変長 | 65535        | `BINARY`  |
| `MEDIUMBLOB` | 可変長 | 16777215     | `BINARY`  |
| `LONGBLOB`   | 可変長 | 536870910    | `BINARY`  |
| `TINYTEXT`   | 可変長 | 256          | `UTF8MB4` |
| `TEXT`       | 可変長 | 65535        | `UTF8MB4` |
| `MEDIUMTEXT` | 可変長 | 16777215     | `UTF8MB4` |
| `LONGTEXT`   | 可変長 | 536870910    | `UTF8MB4` |
| `STRING`     | 可変長 | 16777216     | `UTF8MB4` |

ほとんどの場合、`BLOB` 列は `VARBINARY` 列と見なし、`TEXT` 列は `VARCHAR` 列と見なすことができます。`BLOB` と `TEXT`/`STRING` は、以下の点で `VARBINARY` および `VARCHAR` とは異なります：

* `BLOB` 列と `TEXT` 列では、インデックスのプレフィックス長を指定する必要があります。`CHAR` 列と `VARCHAR` 列では、プレフィックス長はオプションです。

* `BLOB` 列と `TEXT`/`STRING` 列には `DEFAULT` 値を設定できません。
