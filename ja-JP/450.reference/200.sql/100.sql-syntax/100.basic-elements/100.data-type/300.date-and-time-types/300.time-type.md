# TIME型

`TIME`型は、1日の特定の時間を表すことができるほか、経過した時間や2つのイベント間の時間間隔（24時間を大幅に超える場合もある）を表すこともできます。

seekdbでは、文字列または数値を使用して`TIME`列に値を代入することができます。

`TIME`値の検索および表示形式は`'hh:mm:ss'`で、範囲は`'-838:59:59'`から`'838:59:59'`です。

`TIME`値の表示形式には、秒の小数部を含めた`'hh:mm:ss[.fraction]'`形式も使用でき、精度はマイクロ秒（6桁）まで達成できます。範囲は`'-838:59:59.000000'`から`'838:59:59.000000'`です。小数部は常に他の時間部と小数点で区切られなければならず、他の区切り文字は認識されません。

`TIME`の構文は以下のとおりです：

```sql
TIME[(fsp)]
```

オプションの`fsp`値は、小数部秒の精度を指定するために使用され、範囲は\[0,6\]です。0値は小数部がないことを意味します。省略した場合、デフォルトの精度は0です。
