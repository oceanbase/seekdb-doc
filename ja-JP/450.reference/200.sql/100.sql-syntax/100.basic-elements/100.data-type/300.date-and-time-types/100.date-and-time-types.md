# 日付・時刻型の概要

seekdbは、時間値を表すための日付および時刻データ型として、`DATE`、`TIME`、`DATETIME`、`TIMESTAMP`、`YEAR` をサポートしています。各型には有効値の範囲があり、表現できない無効値を指定するための「ゼロ」値も存在します。

seekdbの現在のバージョンでサポートされている日付・時刻型および関連情報は、次の表のとおりです。

|     データ型      |                形式                |             下限             |             上限             |     意味      |
|-------------|----------------------------------|----------------------------|----------------------------|-------------|
| `DATETIME`  | YYYY-MM-DD HH:MM:SS\[.fraction\] | 0000-00-00 00:00:00.000000 | 9999-12-31 23:59:59.999999 | 日付時刻（タイムゾーンを考慮しない） |
| `TIMESTAMP` | YYYY-MM-DD HH:MM:SS\[.fraction\] | 0000-00-00 00:00:00.000000 | 9999-12-31 23:59:59.999999 | 日付時刻（タイムゾーンを考慮する）  |
| `DATE`      | YYYY-MM-DD                       | 0000-00-00                 | 9999-12-31                 | 日付          |
| `TIME`      | HH:MM:SS\[.fraction\]            | -838:59:59.000000          | 838:59:59.000000           | 時刻          |
| `YEAR`      | YYYY                             | 1901                       | 2155                       | 年           |

`DATETIME`、`TIMESTAMP`、`TIME` の値域と精度はScaleに依存します。Scale属性は小数部の最大有効桁数を示し、最大値は6、デフォルト値は0です。
