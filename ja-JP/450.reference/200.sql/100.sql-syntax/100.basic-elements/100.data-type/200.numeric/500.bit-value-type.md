# BIT値型

`BIT` データ型は、ビット値を格納するために使用されます。

ビット値は `b'value'` の形式で指定します。`value` は0と1で表され、例えば、`b'111'` は7を表し、`b'10000000'` は128を表します。

構文は以下のとおりです：

```sql
BIT[(M)]
```

`M` は各値のビット数を表し、範囲は \[1，64\] です。`M` を省略した場合、デフォルトは1になります。

`BIT(M)` 列に値を挿入する際、挿入する値の長さが `M` より短い場合、左側に0が埋め込まれます。例えば、`b'101'` を `BIT(6)` に挿入すると、`b'000101'` を挿入したことと同じになります。
