# 固定小数点数型

固定小数点数型は、可変長の厳密な数値型であり、値の範囲と精度はPrecisionとScaleによって決まり、符号があるかどうかにも依存します。

`DECIMAL` は `NUMERIC` と同等です。構文は以下のとおりです：

```sql
DECIMAL[(M[,D])] [UNSIGNED] [ZEROFILL]
```

`M` は格納可能な総桁数（Precision）、`D` は小数点以下の桁数（Scale）を表します。小数点と負号 "-" は `M` には含まれません。`D` が0の場合、値に小数点または小数部はありません。整数部の最大有効桁数は `M` から `D` を引いた値、すなわちPrecisionからScaleを引いた値に等しくなります。`DECIMAL` 列に対するすべての基本的な演算（+、-、\*、/）は65ビットの精度を使用します。

`DECIMAL` の `M` の最大値は65、`D` の最大値は30です。`D` を省略した場合、デフォルトで0となります。`M` を省略した場合、デフォルトで10となります。

数値列に `ZEROFILL` を指定すると、seekdbはその列に `UNSIGNED` 属性を自動的に追加します。`UNSIGNED` を指定すると、負の値を格納することはできません。

例えば `DECIMAL(5,2)` の場合、整数部と小数部の最大有効桁数はそれぞれ3と2なので、値の範囲は \[-999.99, 999.99\] となります。`UNSIGNED` も同時に指定すると、値の範囲は \[0, 999.99\] となります。

以下の型も `DECIMAL` のシノニムです。その中で、`FIXED` は他のデータベースシステムとの互換性を持たせるために使用できます。

```sql
DEC[(M[,D])] [UNSIGNED] [ZEROFILL], NUMERIC[(M[,D])] [UNSIGNED] [ZEROFILL], FIXED[(M[,D])] [UNSIGNED] [ZEROFILL]
```
