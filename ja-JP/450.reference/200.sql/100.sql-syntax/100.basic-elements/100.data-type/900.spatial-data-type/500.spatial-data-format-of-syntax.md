# 空間データ形式

seekdbは、クエリ内の幾何オブジェクトを表すために、2つの標準的な空間データ形式をサポートしています。

* Well-Know Text Format（WKT）

* Well-Know Binary Format（WKB）

## WKT

WKTはEBNF（Extended Backus Naur Form）に基づいて定義されています。WKTはデータ形式（本記事ではWKT-Dataと呼ぶ）としても、GISにおけるSRSの定義（本記事ではWKT-SRSと略称する）としても使用できます。

### Point

Pointはカンマで区切りません。フォーマット例は以下のとおりです：

```sql
POINT(15 20)
```

以下の例では、`ST_X()` を使用してPointオブジェクトから `X` 座標を抽出します。最初の例では、`Point()` 関数を直接使用してオブジェクトを生成します。2番目の例では、`ST_GeomFromText()` でPointに変換されたWKT表現を使用します。

```sql
SELECT ST_X(Point(15, 20));
```

結果は次のとおりです：

```sql
+---------------------+
| ST_X(Point(15, 20)) |
+---------------------+
|                  15 |
+---------------------+
1 row in set (0.001 sec)
```

```sql
SELECT ST_X(ST_GeomFromText('POINT(15 20)'));
```

結果は次のとおりです：

```sql
+---------------------------------------+
| ST_X(ST_GeomFromText('POINT(15 20)')) |
+---------------------------------------+
|                                    15 |
+---------------------------------------+
1 row in set (0.001 sec)
```

### Line

Lineは複数の点で構成され、点と点の間はカンマで区切られます。フォーマット例は以下のとおりです：

```sql
LINESTRING(0 0, 10 10, 20 25, 50 60)
```

### Polygon

Polygonは、少なくとも1つの外側の輪郭線（閉じた線）と、複数の内側の輪郭線（閉じた線、0本でも可）で構成されます。フォーマット例は以下のとおりです：

```sql
POLYGON((0 0,10 0,10 10,0 10,0 0),(5 5,7 5,7 7,5 7, 5 5))
```

### MultiPoint

MultiPointは複数の点で構成され、線と似ていますが、意味は異なります。点が接続して線になる場合があり、点が離散してMultiPointになります。フォーマット例は以下のとおりです：

```sql
MULTIPOINT(0 0, 20 20, 60 60)
```

関数 `ST_MPointFromText()` および `ST_GeoFromText()` では、MultiPoint内の点を括弧で囲むことも有効です。フォーマット例は以下のとおりです：

```sql
ST_MPointFromText('MULTIPOINT (1 1, 2 2, 3 3)')
ST_MPointFromText('MULTIPOINT ((1 1), (2 2), (3 3))')
```

### MultiLineString

MultiLineStringは複数の線の集合です。フォーマット例は以下のとおりです：

```sql
MULTILINESTRING((10 10, 20 20), (15 15, 30 15))
```

### MultiPolygon

MultiPolygonは複数のPolygonの集合です。フォーマット例は以下のとおりです：

```sql
MULTIPOLYGON(((0 0,10 0,10 10,0 10,0 0)),((5 5,7 5,7 7,5 7, 5 5)))
```

### GeometryCollection

GeometryCollectionは、さまざまな基本型や集合型の集合にすることができます。

```sql
GEOMETRYCOLLECTION(POINT(10 10), POINT(30 30), LINESTRING(15 15, 20 20))
```

## WKB

WKBはOpenGIS仕様に基づいて開発されたもので、7種類のタイプ（Point、Linestring、Polygon、Multipoint、Multilinestring、Multipolygon、Geometrycollection）およびそれぞれの形式定義をサポートしています。

### Point

`POINT(1 -1)` を例にすると、書式は次の表のように定義されます。

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 01000000 |
| **X coordinate** | 8 bytes | double-precision | 000000000000F03F |
| **Y coordinate** | 8 bytes | double-precision | 000000000000F0BF |

### Linestring

`LINESTRING(1 -1, -1 1)` を例にすると、書式は次の表のように定義されます。`Num points` は2以上である必要があります。

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 02000000 |
| **Num points** | 4 bytes | unsigned int | 02000000 |
| **X coordinate** | 8 bytes | double-precision | 000000000000F03F |
| **Y coordinate** | 8 bytes | double-precision | 000000000000F0BF |
| **X coordinate** | 8 bytes | double-precision | 000000000000F0BF |
| **Y coordinate** | 8 bytes | double-precision | 000000000000F03F |

### Polygon

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 03000000 |
| **Num rings** | 4 bytes | unsigned int | 1以上 |
| **repeat ring** | - |- | - |

### MultiPoint

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 04000000 |
| **Num points** | 4 bytes | unsigned int | Num points >= 1が必要です |
| **repeat POINT** | - |-  | - |

### MultilineString

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 05000000 |
| **Num linestrings** | 4 bytes | unsigned int | 1以上 |
| **repeat LINESTRING** | - | - | - |

### MultiPolygon

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 06000000 |
| **Num polygons** | 4 bytes | unsigned int | 1以上 |
| **repeat POLYGON** | - | - | - |

### GeometryCollection

| **コンポーネント名** | **仕様** | **タイプ** | **値** |
| --- | --- | --- | --- |
| **Byte order** | 1 byte | unsigned int | 01 |
| **WKB type** | 4 bytes | unsigned int | 07000000 |
| **Num wkbs** | 4 bytes | unsigned int | - |
| **repeat WKB** | - | - | - |

:::info

* 空の値は、0個の要素が格納されていることを示すため、GeometryCollectionのみ許容されます。他の型では空にすることはできません。

* `LENGTH()` をGISオブジェクトに適用した場合、返されるのは格納されているバイナリデータの長さです。

:::

```sql
SET @g = ST_GeomFromText('POINT(1 -1)');
```

結果は次のとおりです：

```sql
Query OK, 0 rows affected (0.000 sec)
```

```sql
SELECT LENGTH(@g);
```

結果は次のとおりです：

```sql
+------------+
| LENGTH(@g) |
+------------+
|         25 |
+------------+
1 row in set (0.001 sec)
```

```sql
SELECT HEX(@g);
```

結果は次のとおりです：

```sql
+----------------------------------------------------+
| HEX(@g)                                            |
+----------------------------------------------------+
| 000000000101000000000000000000F03F000000000000F0BF |
+----------------------------------------------------+
1 row in set (0.001 sec)
```

## 構文と幾何学的有効性

### 構文の有効性

構文が有効であるためには、以下の条件を満たす必要があります：

* Linestringは少なくとも2つの点を含む必要があります。
* Polygonは少なくとも1つの輪を含む必要があります。
* Polygonは閉じた輪である必要があります（最初と最後の2つの点は同じである）。
* Polygonの輪は少なくとも4つの点を含む必要があります（最小の多角形は三角形であり、最初と最後の点は同じである）。
* GeometryCollection以外の集合型は空にすることはできません。

### 幾何学的有効性

幾何学的に有効であるためには、以下の条件を満たす必要があります：

* Polygonは自己と交差してはなりません。
* Polygonの外側の輪は内側の輪の外側に位置している必要があります。
* Multipolygonsには重なり合う多角形を含めることはできません。

ST_IsValid() 関数を使用すると、幾何オブジェクトの幾何学的有効性を明示的にチェックできます。

## GISインデックスの例

### 登録の例

```sql
// 変換関数とWKTをSQL文内に記述する
INSERT INTO geom VALUES (ST_GeomFromText('POINT(1 1)'));

// WKTをパラメータに記述する
SET @g = 'POINT(1 1)';
INSERT INTO geom VALUES (ST_GeomFromText(@g));

// 変換式を直接パラメータに記述する
SET @g = ST_GeomFromText('POINT(1 1)');
INSERT INTO geom VALUES (@g);

// 統一された変換関数を使用する
SET @g = 'LINESTRING(0 0,1 1,2 2)';
INSERT INTO geom VALUES (ST_GeomFromText(@g));

SET @g = 'POLYGON((0 0,10 0,10 10,0 10,0 0),(5 5,7 5,7 7,5 7, 5 5))';
INSERT INTO geom VALUES (ST_GeomFromText(@g));

SET @g ='GEOMETRYCOLLECTION(POINT(1 1),LINESTRING(0 0,1 1,2 2,3 3,4 4))';
INSERT INTO geom VALUES (ST_GeomFromText(@g));

// 型に基づく変換関数を使用する
SET @g = 'POINT(1 1)';
INSERT INTO geom VALUES (ST_PointFromText(@g));

SET @g = 'LINESTRING(0 0,1 1,2 2)';
INSERT INTO geom VALUES (ST_LineStringFromText(@g));

SET @g = 'POLYGON((0 0,10 0,10 10,0 10,0 0),(5 5,7 5,7 7,5 7, 5 5))';
INSERT INTO geom VALUES (ST_PolygonFromText(@g));

SET @g =
'GEOMETRYCOLLECTION(POINT(1 1),LINESTRING(0 0,1 1,2 2,3 3,4 4))';
INSERT INTO geom VALUES (ST_GeomCollFromText(@g));

// WKBに基づいて直接登録することもできます
INSERT INTO geom VALUES(ST_GeomFromWKB(X'0101000000000000000000F03F000000000000F03F'));
```

### クエリの例

```sql
// クエリしてWKTに変換して出力する
SELECT ST_AsText(g) FROM geom;

// クエリしてWKBに変換して出力する
SELECT ST_AsBinary(g) FROM geom;
```
