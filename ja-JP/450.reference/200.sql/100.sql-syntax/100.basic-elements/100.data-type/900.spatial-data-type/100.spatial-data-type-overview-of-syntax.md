# 空間データ型の概要

seekdbの地理情報システム（Geographic Information System、GIS）機能には、以下の空間データ型が含まれます：

* `GEOMETRY`

* `POINT`

* `LINESTRING`

* `POLYGON`

* `MULTIPOINT`

* `MULTILINESTRING`

* `MULTIPOLYGON`

* `GEOMETRYCOLLECTION`

その中で、`POINT`、`LINESTRING`、`POLYGON` の3つが最も基本的な型であり、単一の空間データを格納するために使用されます。これらはそれぞれ、空間データの集合を格納するための `MULTIPOINT`、`MULTILINESTRING`、`MULTIPOLYGON` の3つの集合型を拡張したものですが、指定された基本型の集合しか表現できません。`GEOMETRY` は仮想型であり、任意の基本型を表すことができます。また、`GEOMETRYCOLLECTION` は任意の `GEOMETRY` 型の集合です。
