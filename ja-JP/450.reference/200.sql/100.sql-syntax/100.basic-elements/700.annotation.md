# コメント

SQLステートメントとデータベースオブジェクトのコメント方法は異なります。

## SQLステートメントのコメント

通常のSQLステートメントについて、SEEKDBは以下の3種類のコメント方法をサポートしています：

* `#` から行末までで、1行をコメントできます。

* `--` から行末までで、1行をコメントできます。

* `/*` から `*/` までで、複数行をコメントできます。

  :::info

  SQLステートメントでは、ネストされたコメントはサポートされていません。

  :::

特に、SEEKDBは `/*！*/` 内のステートメントをSQLとして処理し、コメント内のステートメントを実行することをサポートしています。`/*！*/` 内に構文エラーが発生した場合、データベースはデフォルトでコメントとして処理します。

コメントの書式は以下のとおりです：

```sql
/*![バージョン番号を示す連続する数字文字] <スペース> <任意のSQLステートメント >*/
```

* 例1：テーブル `t1` にHashパーティションを作成し、パーティション数を `8` に設定します。

  ```sql
  CREATE TABLE t1 (c1 INT PRIMARY KEY, c2 INT) /*!50100
      PARTITION BY HASH(c1) PARTITIONS 8*/;
  Query OK, 0 rows affected (0.098 sec)
  ```

* 例2：`ENABLE KEYS` を使用して非一意インデックスを更新します。バッチ挿入時には `DISABLE KEYS` を使用して一時的に更新せず、すべてのインデックスの挿入が完了した後にインデックスを更新します。

  ```sql
  /*!ALTER TABLE t1 DISABLE KEYS */;
  Query OK, 0 rows affected (0.000 sec)

  /*!ALTER TABLE t1 ENABLE KEYS */;
  Query OK, 0 rows affected (0.000 sec)
  ```

* 例3：PLの `DROP IF EXISTS` 構文の実行をサポートします。

  ```sql
  /*!50003 DROP PROCEDURE IF EXISTS */;
  Query OK, 0 rows affected (0.000 sec)
  ```

## データベースオブジェクトのコメント

DDLステートメント内の `COMMENT` 句を使用して、データベースオブジェクトにコメントを指定できます。例：

```sql
CREATE TABLE tbl1(pk INT PRIMARY KEY COMMENT '主キー');
Query OK, 0 rows affected (0.073 sec)
```
