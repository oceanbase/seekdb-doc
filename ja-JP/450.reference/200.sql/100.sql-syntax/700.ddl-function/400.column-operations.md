# 列の操作

SEEKDBにおける列の操作には、末尾への列追加、末尾以外への列追加、列の削除、列名の変更、並べ替え、列型の変更、列のデフォルト値の管理、制約の管理、自動インクリメント列の値の変更が含まれます。

## 列の追加

SEEKDBにおける列の追加操作は、**末尾への列の追加** と **末尾以外への列の追加** に分かれており、以下にそれぞれ説明します。

### 表の末尾に列を追加する

テーブルの末尾に列を追加する構文は以下のとおりです：

```sql
ALTER TABLE table_name ADD COLUMN column_name data_type;
```

関連パラメータの説明は以下のとおりです：

* `table_name`：列を追加する対象のテーブル名を指定します。

* `column_name`：追加する列名を指定します。

* `data_type`：追加する列のデータ型を指定します。

ここでは、データベースにtbl1というテーブルが存在することを前提とし、tbl1の末尾に列`c1`を追加する例を挙げて、列追加ステートメントの実行方法を説明します。

1. テーブルtbl1のテーブル構造情報を確認する

   ```shell
   DESCRIBE tbl1;
   ```

   出力結果は以下のとおりで、このテーブルには`id`、`name`、`age`の3列が存在することがわかります。

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | name  | varchar(50) | NO   |     | NULL    |       |
   | age   | int(11)     | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

2. テーブルの末尾に列`c1`を追加し、その列のデータ型をINTと指定する

   ```shell
   ALTER TABLE tbl1 ADD COLUMN c1 INT;
   ```

3. 再度テーブルtbl1のテーブル構造情報を確認する

   ```shell
   DESCRIBE tbl1;
   ```

   出力結果は以下のとおりで、このテーブルの末尾に`c1`列が新たに追加されていることがわかります。

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | name  | varchar(50) | NO   |     | NULL    |       |
   | age   | int(11)     | YES  |     | NULL    |       |
   | c1    | int(11)     | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

### 末尾以外に列を追加する

テーブルの末尾以外に列を追加する構文は以下のとおりです：

```sql
ALTER TABLE table_name
    ADD COLUMN new_column_name data_type
    {FIRST | BEFORE | AFTER} column_name;
```

関連パラメータの説明は以下のとおりです：

* `table_name`：列を追加する対象のテーブル名を指定します。

* `new_column_name`：追加する列名を指定します。

* `data_type`：追加する列のデータ型を指定します。

* `FIRST | BEFORE | AFTER`：追加する列の位置を指定します。テーブルの先頭（`FIRST`）、`column_name` の前（`BEFORE`）、または `column_name` の後（`AFTER`）に追加できます。

  :::tip

  `FIRST` を使用して列をテーブルの先頭に追加する場合、`column_name` を設定する必要はありません。設定するとエラーが発生します。

  :::

* `column_name`：列を追加する位置に関連する列名を指定します。

データベースに tbl1 テーブルが存在することを前提とします。tbl1 テーブルの構造情報は以下のとおりです：

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

ここでは、tbl1 テーブルの先頭に `c1` 列を追加し、`name` 列の前に `c2` 列を追加し、`name` 列の後に `c3` 列を追加する例を用いて、列を追加するステートメントの実行方法を説明します。

1. tbl1 テーブルの先頭に `c1` 列を追加し、この列のデータ型を INT と指定します。

   ```shell
   ALTER TABLE tbl1 ADD COLUMN c1 INT FIRST;
   ```

2. tbl1 テーブルの name 列の前に `c2` 列を追加し、この列のデータ型を VARCHAR と指定します。

   ```shell
   ALTER TABLE tbl1 ADD COLUMN c2 VARCHAR(50) BEFORE name;
   ```

3. tbl1 テーブルの name 列の後に `c3` 列を追加し、この列のデータ型を VARCHAR と指定するとともに、この列が NULL であってはならない制約を設定します。

   ```shell
   ALTER TABLE tbl1 ADD COLUMN c3 VARCHAR(25) NOT NULL AFTER name;
   ```

4. 再度 tbl1 テーブルの構造情報を確認します。

   ```shell
   DESCRIBE tbl1;
   ```

   出力は以下のとおりです。

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | c1    | int(11)     | YES  |     | NULL    |       |
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | c2    | varchar(50) | YES  |     | NULL    |       |
   | name  | varchar(50) | NO   |     | NULL    |       |
   | c3    | varchar(25) | NO   |     | NULL    |       |
   | age   | int(11)     | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

## 列の削除

列を削除する構文は次のとおりです：

```sql
ALTER TABLE table_name DROP COLUMN column_name
```

ここで、`table_name` は削除対象の列が含まれるテーブル名を指定し、`column_name` は削除対象の列名を指定します。

データベースに tbl1 テーブルが存在する場合を想定します。tbl1 テーブルの構造情報は以下のとおりです：

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

ここでは、`name` 列を削除する例を挙げて、列削除ステートメントの実行方法を説明します。

```shell
ALTER TABLE tbl1 DROP COLUMN name;
```

削除後、再度 `DESCRIBE tbl1;` コマンドを実行して tbl1 テーブルの構造を確認すると、出力は以下のとおりで、テーブル tbl1 には `name` 列が存在しません。

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

### 複数列の削除

**構文は以下のとおりです：**

```sql
ALTER TABLE table_name DROP COLUMN column_name1, DROP COLUMN column_name2, ...;
```

単一列を削除する場合と同様に、`table_name` は削除対象の列が存在するテーブル名を指定し、`column_name` は削除対象の列名を指定します。
データベースに tbl1 テーブルが存在することを前提とします。tbl1 テーブルの構造情報は以下のとおりです：

```shell
+-------+--------------+------+------+---------+-------+
| FIELD | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
+-------+--------------+------+------+---------+-------+
| C1    | NUMBER(30)   | NO   | PRI  | NULL    | NULL  |
| C2    | VARCHAR(50) | YES  | NULL | NULL    | NULL  |
| C3    | NUMBER(30)   | YES  | NULL | NULL    | NULL  |
| C4    | NUMBER(30)   | YES  | NULL | NULL    | NULL  |
| C5    | NUMBER(30)   | YES  | NULL | NULL    | NULL  |
+-------+--------------+------+------+---------+-------+
```

ここでは、tbl1 テーブルの `C4` 列と `C5` 列を削除する例を挙げて、`ALTER TABLE table_name DROP COLUMN column_name1, column_name2, ...` を使用してテーブルから複数列を削除する方法を説明します。

```shell
ALTER TABLE tbl1 DROP COLUMN C4, DROP COLUMN C5;
```

再度 `DESCRIBE tbl1;` コマンドを実行して tbl1 テーブルの構造を確認すると、出力は以下のとおりで、テーブル tbl1 には `C4` 列と `C5` 列が存在しません。

```shell
+-------+--------------+------+------+---------+-------+
| FIELD | TYPE         | NULL | KEY  | DEFAULT | EXTRA |
+-------+--------------+------+------+---------+-------+
| C1    | NUMBER(30)   | NO   | PRI  | NULL    | NULL  |
| C2    | VARCHAR(50) | YES  | NULL | NULL    | NULL  |
| C3    | NUMBER(30)   | YES  | NULL | NULL    | NULL  |
+-------+--------------+------+------+---------+-------+
```

### 使われなくなった列のクリア

使われなくなった列をクリアする構文は以下のとおりです：

```sql
ALTER TABLE TABLE_NAME FORCE;
```

ここでは、tbl1 テーブルの `C2` 列、`C3` 列、`C4` 列、`C5` 列をクリアする例を挙げて、テーブル内の使われなくなった列をクリアする方法を説明します。

```shell
ALTER TABLE tbl1 FORCE;
```

## 列の名前変更

列の名前を変更する構文は以下の2種類です：

* 列の名前を変更しながらデータ型も変更する

  ```sql
  ALTER TABLE table_name CHANGE old_col_name new_col_name data_type;
  ```

  関連パラメータの説明は以下のとおりです：

  * `table_name`：名前を変更する列が含まれるテーブルの名前を指定します。

  * `old_col_name`：名前を変更する列の名前を指定します。

  * `new_col_name`：名前を変更後の列の名前を指定します。

  * `data_type`：名前を変更する列のデータ型を指定します。現在のデータ型を指定するか、他のデータ型に変更することもできます。サポートされているデータ型については、後述の[列の型の変更](#修改列类型)を参照してください。

* 列の名前のみを変更する

  ```sql
  ALTER TABLE table_name RENAME COLUMN old_col_name TO new_col_name
  ```

  関連パラメータの説明は以下のとおりです：

  * `table_name`：名前を変更する列が含まれるテーブルの名前を指定します。

  * `old_col_name`：名前を変更する列の名前を指定します。

  * `new_col_name`：名前を変更後の列の名前を指定します。

データベースにtbl1というテーブルが存在すると仮定します。tbl1のテーブル構造情報は以下のとおりです：

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

ここでは、`name` 列の名前を `c2` に変更し、`age` 列の名前を `c3` に変更し、さらに `age` 列のデータ型を VARCHAR に変更する例を用いて、列の名前を変更するステートメントの実行方法を説明します。

1. `name` 列の名前を `c2` に変更する

   ```shell
   ALTER TABLE tbl1 RENAME COLUMN name TO c2;
   ```

2. `age` 列の名前を `c3` に変更し、`age` 列のデータ型を VARCHAR に変更する

   ```shell
   ALTER TABLE tbl1 CHANGE age c3 VARCHAR(50);
   ```

3. 再度 `DESCRIBE tbl1;` コマンドを実行して、tbl1 テーブルのテーブル構造を確認する

   出力は以下のとおりです。tbl1 テーブルには `id`、`c2`、`c3` の3列しかなく、`c3` 列のデータ型は VARCHAR です。

   ```shell
   +-------+-------------+------+-----+---------+-------+
   | Field | Type        | Null | Key | Default | Extra |
   +-------+-------------+------+-----+---------+-------+
   | id    | int(11)     | NO   | PRI | NULL    |       |
   | c2    | varchar(50) | YES  |     | NULL    |       |
   | c3    | varchar(50) | YES  |     | NULL    |       |
   +-------+-------------+------+-----+---------+-------+
   ```

## リランキング

リランキングの構文は以下のとおりです：

```sql
ALTER TABLE table_name
    MODIFY [COLUMN] column_name data_type
    {FIRST | BEFORE | AFTER} column_name;
```

関連パラメータの説明は以下のとおりです：

* `table_name`：リランキング対象のテーブル名を指定します。

* `column_name`：リランキング対象の列名を指定します。

* `data_type`：リランキング対象のデータ型を指定します。現在のデータ型を指定することも、その列を他のデータ型に変更することもできます。サポートされているデータ型については、後述の[列の型の変更](#修改列类型)を参照してください。

* `FIRST | BEFORE | AFTER`：追加する列の位置を指定します。テーブルの先頭(`FIRST`)、`column_name` の前(`BEFORE`)、または `column_name` の後(`AFTER`)に追加できます。

  :::tip

  `FIRST` を使用して列をテーブルの先頭に追加する場合は、`column_name` を設定する必要はありません。設定するとエラーが発生します。

  :::

* `column_name`：リランキング位置に関連する列名を指定します。

データベースに tbl1 テーブルが存在すると仮定します。tbl1 テーブルの構造情報は以下のとおりです：

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

ここでは、`age` 列を `name` 列の前にリランキングし、`age` 列のデータ型を VARCHAR に変更する例を用いて、リランキングステートメントの使用方法を説明します。

```shell
ALTER TABLE tbl1 MODIFY COLUMN age VARCHAR(50) BEFORE name;
```

再度 `DESCRIBE tbl1;` コマンドを実行して tbl1 テーブルの構造を確認すると、出力は以下のとおりです。`age` 列が `name` 列の前に配置され、データ型は VARCHAR になっています。

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | NO   | PRI | NULL    |       |
| age   | varchar(50) | YES  |     | NULL    |       |
| name  | varchar(50) | NO   |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

## 列型の変更

seekdbがサポートする列型の変換は以下のとおりです：

* 文字列データ型の変換：`CHAR`、`VARCHAR`、`TINYTEXT`、`TEXT`、`LONGTEXT`

* 数値データ型の変換：`TINYINT`、`SMALLINT`、`MEDIUMINT`、`INT`、`BIGINT`

* バイナリデータ型の変換：`BINARY`、`VARBINARY`、`BLOB`、`TINYBLOB`、`MEDIUMBLOB`、`LONGBLOB`

* 精度を持つデータ型の精度変更：`VARCHAR`、`FLOAT`、`DOUBLE`、`DECIMAL`

* 精度を持つデータ型間の変換：`FLOAT`、`DOUBLE`、`DECIMAL`

* 異なるデータ型間の変換：`INT`、`VARCHAR`、`DOUBLE`、`FLOAT`、`DECIMAL`

seekdbに関連する列型の変更ルールについては、[列型の変更ルール](../700.ddl-function/900.column-type-change-rule.md)を参照してください。

列型を変更する構文は以下のとおりです：

```sql
ALTER TABLE table_name MODIFY [COLUMN] column_name data_type;
```

関連パラメータの説明は以下のとおりです：

* `table_name`：型を変更する列が存在するテーブル名を指定します。

* `column_name`：型を変更する列名を指定します。

* `data_type`：変更後のデータ型を指定します。

### 文字データ型間の変換例

以下に示すように、test01 テーブルを作成します：

```shell
CREATE TABLE test01 (c1 INT PRIMARY KEY, c2 CHAR(10), c3 CHAR(10));
```

test01 テーブルを例に、以下の例を組み合わせて、文字データ型の列のデータ型を変更し、長さを増やす方法を説明します。

* test01 テーブルの `c2` 列のデータ型を VARCHAR に変更し、長さを最大 20 文字に指定する

  ```shell
  ALTER TABLE test01 MODIFY c2 VARCHAR(20);
  ```

* test01 テーブルの `c2` 列のデータ型を VARCHAR に変更し、長さを最大 40 文字に指定する

  ```shell
  ALTER TABLE test01 MODIFY c2 VARCHAR(40);
  ```

* test01 テーブルの `c2` 列のデータ型を TINYTEXT に変更する

  ```shell
  ALTER TABLE test01 MODIFY c2 TINYTEXT;
  ```

* test01 テーブルの `c2` 列のデータ型を LONGTEXT に変更する

  ```shell
  ALTER TABLE test01 MODIFY c2 LONGTEXT;
  ```

* test01 テーブルの `c3` 列の長さを 20 文字に変更する

  ```shell
  ALTER TABLE test01 MODIFY c3 CHAR(20);
  ```

* test01 テーブルの `c3` 列のデータ型を VARCHAR に変更し、長さを最大 30 文字に指定する

  ```shell
  ALTER TABLE test01 MODIFY c3 VARCHAR(30);
  ```

### 数値データ型間の変換例

#### 整数型

以下に示すように、test02 テーブルを作成します：

test02 テーブルを例に、以下の例を組み合わせて、整数型の列のデータ型を変更し、長さを増やす方法を説明します。

  ```shell
  ALTER TABLE test02 MODIFY age SMALLINT;
  ```

* test02 テーブルの `age` 列のデータ型を INT に変更する

  ```shell
  ALTER TABLE test02 MODIFY age INT;
  ```

* test02 テーブルの `age` 列のデータ型を BIGGINT に変更する

  ```shell
  ALTER TABLE test02 MODIFY age BIGGINT;
  ```

#### 帯精度データ型

以下に示すように、test03 テーブルを作成します:

```shell
CREATE TABLE test03(c1 INT, c2 FLOAT(8,2), c3 FLOAT(8,2), UNIQUE(c2, c3));
```

test03 テーブルを例に、以下の例を組み合わせて、帯精度データ型の列のデータ型と長さを変更する方法を説明します。

* test03 テーブルの `c2` 列の数値桁数を 5 桁に変更する

  ```shell
  ALTER TABLE test03 MODIFY c2 FLOAT(5,2);
  ```

* test03 テーブルの `c2` 列のデータ型を DOUBLE に変更し、合計 10 桁を格納できるように設定する。そのうち小数部は 4 桁。

  ```shell
  ALTER TABLE test03 MODIFY c2 DOUBLE(10,4);
  ```

* test03 テーブルの `c2` 列のデータ型を DOUBLE に変更し、数値桁数を 5 桁に設定する。そのうち小数部は 2 桁。

  ```shell
  ALTER TABLE test03 MODIFY c2 DOUBLE(5,2);
  ```

* test03 テーブルの `c2` 列のデータ型を DECIMAL に変更し、合計 20 桁を格納できるように設定する。そのうち小数部は 4 桁。

  ```shell
  ALTER TABLE test03 MODIFY c2 DECIMAL(20, 4);
  ```

## 列のデフォルト値の管理

SEEKDBでは列のデフォルト値を変更または削除できます。このセクションでは、それぞれの操作方法について説明します。

### 列のデフォルト値を変更する

デフォルト値が設定されていない場合、列のデフォルト値は `NULL` です。列のデフォルト値を変更する構文は以下のとおりです：

```sql
ALTER TABLE table_name ALTER COLUMN column_name SET DEFAULT const_value;
```

関連パラメータの説明は以下のとおりです：

* `table_name`：デフォルト値を変更する列が含まれるテーブルの名前を指定します。

## 制約の管理

SEEKDBでは、テーブルに列制約を追加できます。例えば、既存の列を自動インクリメント列に変更したり、列がNULLを許容するかどうかを設定したり、列の一意性を指定したりすることができます。このセクションでは、それぞれの操作方法を紹介します。

制約を管理する構文は以下のとおりです：

```sql
ALTER TABLE table_name
    MODIFY [COLUMN] column_name data_type
    [AUTO_INCREMENT]
    [NULL | NOT NULL]
    [[PRIMARY] KEY]
    [UNIQUE [KEY]];
```

関連パラメータの説明は以下のとおりです：

* `table_name`：制約を追加する列が含まれるテーブル名を指定します。

* `column_name`：制約を追加する列名を指定します。

* `data_type`：変更対象の列のデータ型を指定します。現在のデータ型を指定することも、その列を他のデータ型に変更することもできます。サポートされているデータ型については、前述の[列の型の変更](#修改列类型)を参照してください。

* `AUTO_INCREMENT`：選択した列を自動インクリメント列に設定します。

* `NULL | NOT NULL`：選択した列がNULLを許容するかどうか（`NULL`）、またはNULLを許容しないかどうか（`NOT NULL`）を設定します。

* `[PRIMARY] KEY`：選択した列を主キーに設定します。

* `UNIQUE [KEY]`：選択した列の一意性を設定します。

データベースにtbl1というテーブルが存在すると仮定します。tbl1のテーブル構造情報は以下のとおりです：

```shell
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | int(11)     | YES  |     | NULL    |       |
| name  | varchar(50) | YES  |     | NULL    |       |
| age   | int(11)     | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
```

1. `id` 列を主キーに設定します。

   ```shell
   ALTER TABLE tbl1 MODIFY COLUMN id INT PRIMARY KEY;
   ```

2. `id` 列を自動インクリメント列に設定します。

   ```shell
   ALTER TABLE tbl1 MODIFY COLUMN id INT AUTO_INCREMENT;
   ```

3. `name` 列をNULLを許容しない列に設定します。

   ```shell
   ALTER TABLE tbl1 MODIFY COLUMN name VARCHAR(50) NOT NULL;
   ```

4. `age` 列を一意の列に設定します。

   ```shell
   ALTER TABLE tbl1 MODIFY COLUMN age INT UNIQUE;
   ```

5. 再度 `DESCRIBE tbl1;` コマンドを実行して、tbl1 テーブルのテーブル構造を確認します。

   ```shell
   +-------+-------------+------+-----+---------+----------------+
   | Field | Type        | Null | Key | Default | Extra          |
   +-------+-------------+------+-----+---------+----------------+
   | id    | int(11)     | NO   | PRI | NULL    | auto_increment |
   | name  | varchar(50) | NO   |     | NULL    |                |
   | age   | int(11)     | YES  | UNI | NULL    |                |
   +-------+-------------+------+-----+---------+----------------+
   ```

## 自動インクリメント列の値を変更する

自動インクリメント列の値を変更する構文は次のとおりです：

```sql
ALTER TABLE table_name [SET] AUTO_INCREMENT = next_value;
```

ここでは、データベースにtbl1というテーブルが存在することを前提とし、tbl1の自動インクリメント列の値を12に変更する例を挙げて説明します。

```shell
ALTER TABLE tbl1 AUTO_INCREMENT = 12;
```

変更後、tbl1テーブルの次の自動インクリメント値は12に設定されます。新規レコードを挿入する際、自動インクリメント列（例：`c1`）は12からインクリメントされます。
