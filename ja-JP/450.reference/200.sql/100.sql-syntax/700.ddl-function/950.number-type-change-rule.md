# NUMBER型の変換ルール

seekdbでは、`NUMBER`型の格納形式はすべて同じですが、値域の定義に基づいて、次の表のように4つの形式に分類できます。

| ストレージタイプ | seekdbのデフォルトの構文と格納ルール |
| --- | --- |
| 固定小数点数 `DECIMAL(M,D) = {10^{-D}*i &#124; i = 0,1,...,10^M-1}` ここで、Mは自然数、Dは整数 | <ul><li> DECIMAL = DECIMAL(10, 0)</li> <li>DECIMAL(M) = DECIMAL(M, 0)</li> <li>DECIMAL(M, D) の値の範囲は、0 \<=D\<=M\<=65 です </li></ul> |
| 無符号固定小数点数 DECIMAL(M,D) | <ul><li> DECIMAL</li> <li> DECIMAL(M)</li> <li> DECIMAL(M,D) </li> <li> UNSIGNEDプロパティをサポートします </li></ul>|
| 浮動小数点数 NUMBER | サポートされていません |

seekdbにおけるすべての`NUMBER`型間の変換ルールは、次の表のとおりです。表中の「-」は互換モードを跨ぐ場合を示します。

:::tip

符号なし固定小数点数は、seekdbにのみ存在します。

:::

| Instant変換を許可するか(From\\To)| 固定小数点数(M2,D2)| 無符号固定小数点数(M2,D2)| 浮動小数点数 NUMBER|
| --- | --- | --- | --- |
| 固定小数点数(M1,D1)| 変換条件： D1 \<= D2 かつ M1-D1 \<= M2-D2| 不可| 変換条件：M-D \<= 38|
| 無符号固定小数点数(M1,D1) UNSIGNED| 変換条件：D1 \<= D2 かつ M1-D1 \<= M2-D2| 変換条件：D1 \<= D2 かつ M1-D1 \<= M2-D2| -|
| 浮動小数点数 NUMBER| 不可| -| 可|
