# 主キーの操作

本記事では、SEEKDBにおける簡単な主キー操作について説明します。主キーの追加、変更、削除が含まれます。

## 主キーの追加

主キーを追加する構文は次のとおりです：

```sql
ALTER TABLE table_name ADD PRIMARY KEY (column_name);
```

ここで、`table_name` は主キーを追加するテーブルの名前を指定し、`column_name` は主キーがある列を指定します。詳細については、[ALTER TABLE](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974126)を参照してください。

ここでは、データベースにテーブルtbl1が既に存在することを前提とします。tbl1テーブルに主キーインデックスを追加し、そのインデックスをc1列に適用する実行例は以下のとおりです：

```shell
ALTER TABLE tbl1 ADD PRIMARY KEY(c1);
```

## 主キーの変更

主キーを変更する構文は次のとおりです：

```sql
ALTER TABLE table_name DROP PRIMARY KEY, ADD PRIMARY KEY (column_name);
```

ここで、`table_name` は主キーを変更する対象のテーブル名を指定し、`column_name` は変更後の主キーがある列を指定します。詳細については、[ALTER TABLE](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974126)を参照してください。

ここでは、データベースにテーブルtbl1が既に存在し、tbl1テーブルに主キーが存在することを前提とします。tbl1テーブルの主キーを変更し、それをc2列に適用する実行例は以下のとおりです：

```shell
ALTER TABLE tbl1 DROP PRIMARY KEY, ADD PRIMARY KEY(c2);
```

## 主キーの削除

主キーを削除する構文は次のとおりです：

```sql
ALTER TABLE table_name DROP PRIMARY KEY;
```

ここで、`table_name` は主キーを削除する対象のテーブル名を指定します。詳細については、[ALTER TABLE](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974126)を参照してください。

ここでは、データベースにテーブルtbl1が存在し、tbl1テーブルに主キーが存在することを前提とします。tbl1テーブルの主キーを削除する実行例は以下のとおりです：

```shell
ALTER TABLE tbl1 DROP PRIMARY KEY;
```
