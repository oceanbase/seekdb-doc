# DROP TABLE

## 説明

このステートメントは、SEEKDB内のテーブルを削除するために使用します。

## 構文

```sql
DROP {TABLE | TABLES} [TEMPORARY] [IF EXISTS]
table_name [,table_name]...
[RESTRICT | CASCADE]
```

## パラメータの説明

|       **パラメータ**        |       **説明**       |
|---------------------|--------|
| table_name          | 削除するテーブル名を指定します。複数のテーブルを削除する場合は、「,」で区切ります。                                                                      |
| TEMPORARY           | 一時テーブルを削除することを示します。 |
| IF EXISTS           | `IF EXISTS` を指定した場合、削除対象のテーブルが存在しなくてもエラーは報告されません。指定しない場合は、エラーが報告されます。                                                  |
| RESTRICT \| CASCADE | 他のデータベースからSEEKDBへの移行シナリオで使用されます。 <br />**説明**  現在のバージョンではこのパラメータはサポートされていません。指定された場合、解析されますが無視されます。 |

## 例

* `IF EXISTS` を指定して、テーブル `test1` を削除します。

  ```sql
  DROP TABLE IF EXISTS test1;
  Query OK, 0 rows affected (0.001 sec)
  ```

* `IF EXISTS` を指定して、テーブル `test1` と `test2` を同時に削除します。

  ```sql
  DROP TABLES IF EXISTS test1,test2;
  Query OK, 0 rows affected (0.001 sec)
  ```

* `IF EXISTS` を指定せずに複数のテーブルを削除する場合、いずれか一つのテーブルが存在しないとエラーが発生します。

  ```sql
  DROP TABLES test1,test2;
  ERROR 1051 (42S02): Unknown table 'test.test2'
  ```

* 一時テーブル `tset3` を削除します。

  ```sql
  DROP TEMPORARY TABLE test3;
  Query OK, 0 rows affected (0.001 sec)
  ```
