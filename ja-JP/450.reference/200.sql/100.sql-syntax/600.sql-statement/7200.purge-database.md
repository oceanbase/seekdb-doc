# PURGE

## 説明

このステートメントは、ごみ箱内のデータベースオブジェクトを削除するために使用され、データベース、テーブル、インデックスの削除をサポートします。

## 構文

```sql
 PURGE {DATABASE | TABLE | INDEX} object_name;

object_name:
    database_name
  | table_name
  | index_name
```

## パラメータの説明

|    **パラメータ**     |           **説明**      |
|---------------|---------|
| database_name | ごみ箱内の削除対象データベース名を指定します。データベース名の直接指定はサポートされていません。                                                                            |
| table_name    | ごみ箱内の削除対象テーブル名を指定します。テーブル名の直接指定はサポートされていません。                                                                                |
| index_name    | ごみ箱内の削除対象インデックス名を指定します。インデックス名の直接指定はサポートされていません。                                                                              |
