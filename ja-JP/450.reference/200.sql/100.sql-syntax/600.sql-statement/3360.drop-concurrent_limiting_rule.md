# DROP CONCURRENT_LIMITING_RULE

## 説明

このステートメントは、レート制限ルールを削除するために使用されます。

## 権限要件

`DROP CONCURRENT_LIMITING_RULE` ステートメントを実行するには、現在のユーザーがDROP権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
DROP CONCURRENT_LIMITING_RULE [ IF EXISTS ] `ccl_rule_name1` [, `ccl_rule_name2`, ...]
```

ここで、`ccl_rule_name` はレート制限ルールの名前を表します。

## 例

:::info
削除されたレート制限ルールは即時に無効となり、そのルールの待機キューにあるSQLステートメントはすべて正常に実行されます。
:::

以下のコマンドを実行して、レート制限ルール `sql1_keywords_ccl_rule` および `sql2_keywords_ccl_rule` を削除します。

```shell
DROP ONCURRENT_LIMITING_RULE `sql1_keywords_ccl_rule`，`sql2_keywords_ccl_rule`;
```
