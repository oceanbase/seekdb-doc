# SHOW JOB STATUS

## 説明

非同期タスクの状態を照会するために使用します。

:::tip
`root`ユーザーはすべてのユーザーが作成したジョブを確認できますが、通常のユーザーは自身が作成したジョブのみを確認できます。
:::

## 構文

```sql
SHOW JOB STATUS [WHERE job='job_id'];
```

## パラメータ説明

`job_id` は非同期タスクの一意のIDです。`SHOW JOB STATUS` を実行して、現在のユーザーが作成したすべてのタスクの状態を確認するか、`where` ステートメントで `job_id` を指定して単一のタスクの状態を確認できます。

## 例

* 現在のユーザーが作成したすべてのタスクの状態を確認します。

  ```shel
  show job status;
  +------------------------+-------------+-----------+----------+----------------------------+----------------------------+------------------+
  | job_id                 | schema_name | status    | fail_msg | create_time                | update_time                | definition       |
  +------------------------+-------------+-----------+----------+----------------------------+----------------------------+------------------+
  | 2010011125899906847397 | oceanbase   | FINISH    | SUCCESS  | 2024-08-02 17:56:19.441303 | 2024-08-02 17:56:30.529692 | select sleep(1); |
  | 2010011125899906847786 | oceanbase   | SUBMITTED | NULL     | 2024-08-02 17:58:11.814612 | 2024-08-02 17:58:11.815297 | select sleep(2); |
  | 2010011125899906847800 | oceanbase   | SUBMITTED | NULL     | 2024-08-02 17:58:14.885659 | 2024-08-02 17:58:14.886382 | select sleep(3); |
  +------------------------+-------------+-----------+----------+----------------------------+----------------------------+------------------+
  3 rows in set (0.012 sec)
  ```

* `where` 条件を使用してジョブIDを指定し、単一のタスクの状態を確認することもできます。

  ```shell
  show job status where job='2010011125899906847397';
  +------------------------+-------------+-----------+----------+----------------------------+----------------------------+------------------+
  | job_id                 | schema_name | status    | fail_msg | create_time                | update_time                | definition       |
  +------------------------+-------------+-----------+----------+----------------------------+----------------------------+------------------+
  | 2010011125899906847397 | oceanbase   | FINISH    | SUCCESS  | 2024-08-02 17:56:19.441303 | 2024-08-02 17:56:30.529692 | select sleep(1); |
  +------------------------+-------------+-----------+----------+----------------------------+----------------------------+------------------+
  1 rows in set (0.006 sec)
  ```

### フィールド説明

|        フィールド     |                説明         |
|----------------|-----------------------------|
|`job_id`|jobの一意のIDを示します。|
|`schema_name`|データベースの名前です。|
|`status`|jobの実行状態。<ul><li><code>SUBMITTED</code>:タスクが送信されたことを示します。</li><li><code>RUNNING</code>:タスクのスケジューリングが開始されたことを示します(実行が開始されているとは限りません)。</li><li><code>FINISH</code>:スケジュールされたタスクの実行が終了し、正常に戻ったことを示します。</li><li><code>FAILED</code>:スケジュールされたタスクの実行が終了し、失敗したことを示します。</li><li><code>CANCELLED</code>:タスクがキャンセルされたことを示します。</li></ul>。|
|`fail_msg`|job実行時のエラーメッセージです。|
|`create_time`|job作成時刻です。|
|`update_time`|jobの最終ステータス更新時刻です。|
|`definition`|jobで実行されるSQLステートメントです。|
