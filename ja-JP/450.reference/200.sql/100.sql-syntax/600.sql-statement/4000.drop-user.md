# DROP USER

## 説明

このステートメントは、1人または複数のデータベースユーザーを削除するために使用します。

  :::tip

  * `DROP USER` コマンドを使用するには、グローバルな `CREATE USER` 権限が必要です。

  * `mysql.user` テーブルは `DELETE` では削除できません。`DROP` コマンドを使用して削除する必要があります。

  * ユーザーの削除に成功すると、そのユーザーのすべての権限も同時に削除されます。

  :::

## 構文

```sql
DROP USER [IF EXISTS] user_name [, user_name...];
```

## パラメータの説明

|    パラメータ     |          説明           |
|-----------|-----------------------|
| IF EXISTS | オプションです。この句を使用すると、存在しないユーザーを削除した場合にエラーではなく警告が発生します。この句を使用しない場合、存在しないユーザーを削除するとエラーが発生します。|
| user_name | ユーザー名。複数のユーザーを同時に削除する場合は、「,」で区切ります。 |

## 例

`sqluser01` という名前のユーザーを削除します。

```sql
DROP USER sqluser01;
Query OK, 0 rows affected (0.001 sec)
```
