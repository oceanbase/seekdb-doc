# SHOW

## 説明

このステートメントは、データベースオブジェクトの情報を表示するために使用されます。

## 構文

```sql
SHOW {
    [EXTENDED] [FULL] TABLES [{FROM | IN} database_name] [like_or_where_clause]
   | {DATABASES | SCHEMAS} [STATUS] [like_or_where_clause]
   | [EXTENDED] [FULL] {COLUMNS | FIELDS} {FROM | IN} rel_name [{FROM | IN} database_name] [like_or_where_clause]
   | TABLE STATUS [{FROM | IN} database_name] [like_or_where_clause]
   | PROCEDURE STATUS [{FROM | IN} database_name] [like_or_where_clause]
   | FUNCTION STATUS [{FROM | IN} database_name] [like_or_where_clause]
   | {GLOBAL | SESSION | LOCAL} VARIABLES [like_or_where_clause]
   | {CHARSET | CHARACTER SET} [like_or_where_clause]
   | TRACE [FORMAT='JSON']
   | COLLATION [like_or_where_clause]
   | PARAMETERS [like_or_where_clause]
   | [EXTENDED] {INDEX | INDEXES | KEYS} {FROM | IN} table_name [{FROM | IN} database_name] WHERE opt_hint_value expr
   | [FULL] PROCESSLIST
   | {GLOBAL | SESSION | LOCAL} STATUS [like_or_where_clause]
   | CREATE {DATABASE | SCHEMA} [IF NOT EXISTS] database_name
   | CREATE TABLE table_name
   | CREATE VIEW view_name
   | CREATE PROCEDURE proc_name
   | CREATE FUNCTION func_name
   | WARNINGS [LIMIT N | LIMIT N,M]
   | ERRORS [LIMIT N | LIMIT N,M]
   | COUNT(*) WARNINGS
   | COUNT(*) ERRORS
   | GRANTS opt_for_grant_user
   | [STORAGE] ENGINES
   | PRIVILEGES
   | RECYCLEBIN
   | SEQUENCE [like_or_where_clause]
   | FUNCTION CODE func_name
   | PROCEDURE CODE proc_name
   | ENGIN engine_name {STATUS | MUTEX}
   | OPEN TABLES [{FROM | IN} db_name] [LIKE 'pattern' | WHERE expr]
   | CREATE CATALOG external_catalog_name
   | CATALOGS
};

like_or_where_clause:
    LIKE like_str [ESCAPE] esc_str
  | WHERE expr

opt_for_grant_user:
    FOR CURRENT USER
  | FOR user_name
```

## パラメータの説明

|     パラメータ          |     説明         |
|--------|--------|
|\[EXTENDED\] \[FULL\] TABLES \{FROM \| IN} database_name   | `database_name`データベース内のすべてのテーブルを表示します。 <ul><li>`EXTENDED` キーワードは隠れたテーブルを表示するために使用されます。seekdbの現在のバージョンでは隠れたテーブルは生成されないため、このパラメータには実際の効果はありません。</li><li>`FULL` キーワードはテーブルタイプを表示するために使用されます。</li></ul>|
| \{DATABASES \| SCHEMAS\} \[STATUS\]      | すべてのデータベースを表示します。`STATUS` キーワードはデータベースの読み書き属性を表示するために使用されます。   |
|\[EXTENDED\] \[FULL\] \{COLUMNS \| FIELDS\} \{FROM \| IN\} rel_name       | リレーショナルテーブル `rel_name` の列を表示します。 <ul><li>`EXTENDED` キーワードは、データベース内部で使用される隠れた列の情報を表示するために使用されます。</li><li>`FULL` キーワードは、列の照合順序、権限、コメントを表示するために使用されます。</li></ul>|
| TABLE STATUS \[\{FROM \| IN\} database_name\]  | `database_name` データベース内のすべてのテーブルの詳細情報を表示します。  |
| PROCEDURE STATUS \[\{FROM \| IN\} database_name\] | `database_name` データベース内のすべてのストアドプロシージャの詳細情報を表示します。     |
| FUNCTION STATUS \[\{FROM \| IN\} database_name\]   | `database_name` データベース内のすべての関数の詳細情報を表示します。   |
| \{GLOBAL \| SESSION \| LOCAL\} VARIABLES | システム変数を表示します。  |
| \{CHARSET \| CHARACTER SET\}   | サポートされている文字セットを表示します。    |
| TRACE [FORMAT='JSON']     | SQL文の実行状況を表示します。JSON形式で出力することもできます。|
| COLLATION              | サポートされている照合順序を表示します。 |
| PARAMETERS \[like_or_where_clause\]      | システム構成パラメータを表示します。                   |
|\[EXTENDED\] \{INDEX \| INDEXES \| KEYS\} \{FROM \| IN\} rel_name \[\{FROM \| IN\} database_name\] | リレーショナルテーブル `rel_name` 上のインデックスまたはキーを表示します。 `EXTENDED` キーワードは、データベース内部で使用される隠れたインデックスの情報を表示するために使用されます。 |
| \[FULL\] PROCESSLIST     | プロセスリストを表示します。詳細は以下のとおりです： <ul><li><code>SHOW PROCESSLIST</code> 簡略なプロセスリストを表示します。詳細は以下のとおりです：  <ul><li><code>Id</code>：プロセスのID、すなわち現在のセッションのクライアントセッションID。このIDはクライアント上のセッションを一意に識別するものです。</li><li><code>User</code>：接続されているユーザー名。</li><li><code>Host</code>：クライアント側のIPアドレスとポート。</li><li><code>db</code>：アクセスするデータベース名。</li><li><code>Command</code>：現在実行中のコマンドタイプ。<code>Query</code>、<code>Sleep</code>などが取り得ます。</li><li><code>Time</code>：現在のコマンド実行時間。単位は秒です。コマンドが再試行された場合、ゼロクリアされて再計算されます。</li><li><code>State</code>：現在のセッション状態。<code>SLEEP</code>、<code>ACTIVE</code>などが取り得ます。</li><li><code>Info</code>：現在実行中のコマンドを表示します。長さは100文字に制限され、それを超える部分は切り捨てられます。</li></ul>  </li><li><code>SHOW FULL PROCESSLIST</code>：各プロセスの詳細情報を含む完全なプロセスリストを表示します。詳細は以下のとおりです：  <ul><li><code>Id</code>：プロセスのID、すなわち現在のセッションのクライアントセッションID。このIDはクライアント上のセッションを一意に識別するものです。</li><li><code>User</code>：接続されているユーザー名。</li><li><code>Tenant</code>：接続されているテナント。</li><li><code>Host</code>：クライアント側のIPアドレスとポート。</li><li><code>db</code>：アクセスするデータベース名。</li><li><code>Command</code>：現在実行中のコマンドタイプ。<code>Query</code>、<code>Sleep</code>などが取り得ます。</li><li><code>Time</code>：現在のコマンド実行時間。単位は秒です。コマンドが再試行された場合、ゼロクリアされて再計算されます。</li><li><code>State</code>：現在のセッション状態。<code>SLEEP</code>、<code>ACTIVE</code>などが取り得ます。</li><li><code>Info</code>：現在実行中のコマンドを表示します。</li><li><code>Ip</code>：サーバーのIPアドレス。</li><li><code>Port</code>：SQLポート番号。</li></ul>  </li></ul>  |
| \{GLOBAL \| SESSION \| LOCAL\} STATUS  | セッションの状態を表示します。 |
| CREATE \{DATABASE \| SCHEMA\} \[IF NOT EXISTS\] database_name      | データベース作成文を確認します。`IF NOT EXISTS` キーワードは、作成文に `IF NOT EXISTS` を追加するために使用されます。  |
| CREATE TABLE table_name    | テーブル作成文を確認します。  |
| CREATE VIEW view_name   | ビュー作成文を確認します。       |
| CREATE PROCEDURE proc_name  | ストアドプロシージャ作成文を確認します。   |
| CREATE FUNCTION func_name  | 関数作成文を確認します。    |
| WARNINGS \[LIMIT N \| LIMIT N,M\]  | アラートを確認します。 |
| COUNT(\*) WARNINGS    | アラート数を確認します。  |
| ERRORS \[LIMIT N \| LIMIT N,M\]    | エラーを確認します。 |
| COUNT(\*) ERRORS    | エラー数を確認します。            |
| GRANTS opt_for_grant_user   | 指定ユーザーの権限を確認します。ユーザー名を指定しない場合、現在ユーザーの権限が表示されます。現在ユーザーは自身の権限を確認できます。他の指定ユーザーの権限を確認するには、`mysql.user` に対する `SELECT` 権限が必要です。 |
| \[STORAGE\] ENGINES     | ストレージエンジンを確認します。seekdbのストレージエンジンは`OceanBase`です。    |
| PRIVILEGES        | 各権限の説明を確認します。     |
| RECYCLEBIN    | ごみ箱を確認します。     |
| SEQUENCE | 作成されたシーケンスを確認します。|
| PROCEDURE CODE proc_name | ストアドプロシージャ<code>proc_name</code>の内部実装を確認します。 現在のバージョンではこのキーワード構文のみサポートしており、機能は有効ではありません。|
| FUNCTION CODE func_name | ストアドファンクション<code>func_name</code>の内部実装を確認します。 現在のバージョンではこのキーワード構文のみサポートしており、機能は有効ではありません。 |
| ENGIN engine_name | ストレージエンジンに関する操作情報を確認します。 現在のバージョンではこのキーワード構文のみサポートしており、機能は有効ではありません。 |
| OPEN TABLES | サーバーが現在開いているテーブルとその状態情報を確認するために使用されます。 現在のバージョンではこのキーワード構文のみサポートしており、機能は有効ではありません。 |
| CREATE CATALOG external_catalog_name | Catalog作成文を確認するために使用されます。  |
| CATALOGS | 現在のテナントのCatalogを確認するために使用されます。 |
