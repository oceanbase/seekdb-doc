# DROP ROLE

## 説明

このステートメントは、ロールを削除するために使用します。

## 使用上の制限と注意事項

* ロールを削除すると、システムはそのロールが付与されているすべてのユーザーおよびロールから自動的にロールを取り消し、データベースから削除します。
* システム変数 `mandatory_roles` に含まれるロールは削除できません。
* 複数のロールを同時に削除する場合、そのうち1つのロールでも削除に失敗すると、削除操作全体がロールバックされ、すべてのロールは削除されません。

## 権限要件

ロールを削除するには、現在のユーザーが `CREATE USER` 権限または `DROP ROLE` 権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
DROP ROLE role_name [, role_name ...];
```

## パラメータの説明

| **パラメータ** | **説明** |
|----------|----------|
| role_name | 削除するロール名を指定します。複数のロールを同時に削除する場合は、ロール名を半角カンマ（`,`）で区切ります。|

## 例

ロール `role001` を削除します。

```sql
DROP ROLE role001;
```
