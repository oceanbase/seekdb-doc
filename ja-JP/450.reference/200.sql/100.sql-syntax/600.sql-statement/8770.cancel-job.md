# CANCEL JOB

非同期タスクをキャンセルするために使用します。

:::tip
* `CANCEL JOB` を実行するには、`job_id` を指定する必要があります。
* 実行中のタスクは終了し、まだ開始されていないタスクは実行されません。
* 既に終了したタスクに対して `cancel job` を実行すると、`ERROR 4018 (HY000): Entry not exist` エラーが発生します。
* タスクをキャンセルしても、ジョブの状態は確認できます。
:::

## 構文

```sql
CANCEL JOB 'job_id';
```

## 例

```shel
CANCEL JOB '2010011125899906847397';
3 rows in set (0.012 sec)
```
