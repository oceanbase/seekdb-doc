# SET CHARSET

## 説明

このステートメントは、クライアントと結果の文字セットを設定します。

## 構文

```sql
SET {CHARSET | CHARACTER SET} {DEFAULT | charset_name};
```

## パラメータの説明

|      パラメータ      |      説明               |
|--------------|-----------------|
| charset_name | クライアントと結果の文字セットを指定します。使用可能な文字セットは以下のとおりです： <ul><li> `utf8`  </li> <li> `utf8mb4`   </li> <li> `gbk`   </li> <li> `utf16`   </li> <li> `gb18030`  </li></ul>  |
| DEFAULT      | システムのデフォルト文字セットを使用します。      |

## 例

クライアントの文字セットを `gbk` に設定します。

```sql
SET CHARSET 'gbk';
Query OK, 0 rows affected
```
