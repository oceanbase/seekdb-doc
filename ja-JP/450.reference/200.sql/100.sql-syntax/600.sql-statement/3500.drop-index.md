# DROP INDEX

## 説明

このステートメントは、インデックスを削除するために使用されます。インデックスが多すぎるとメンテナンスコストが増加するため、不要なインデックスを削除する必要があります。

## 構文

```sql
DROP INDEX index_name
   ON table_name;
```

## パラメータの説明

|   **パラメータ**   | **説明**  |
|------------|---------|
| index_name | インデックス名を指定します。 |
| table_name | テーブル名を指定します。   |

## 例

テーブル `tbl_test` のインデックス `idx_test` を削除します。

```sql
DROP INDEX idx_test ON tbl_test;
```
