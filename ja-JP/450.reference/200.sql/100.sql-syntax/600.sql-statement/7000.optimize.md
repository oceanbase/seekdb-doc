# OPTIMIZE

## 説明

このステートメントは、プログレッシブマージの1ラウンドを開始するために使用されます。

プログレッシブマージのラウンド数は、テーブルの `progressive_merge_num` によって決定されます。テーブルに `progressive_merge_num` が設定されていない場合は、デフォルト値が使用されます。

## 構文

```sql
OPTIMIZE {
     TABLE table_list
};

table_list:
   table_name [,table_name ...]
```

## パラメータの説明

|     パラメータ      |                    説明                     |
|-------------|-------------------------------------------|
| table_name  | プログレッシブマージを実行するテーブル名。                                |

## 例

`t1` テーブルに対してプログレッシブマージを実行します。

```sql
OPTIMIZE TABLE t1;
Query OK, 0 rows affected (0.001 sec)
```
