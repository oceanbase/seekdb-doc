# PURGE RECYCLEBIN

## 説明

このステートメントは、ごみ箱を空にするために使用します。

:::tip
`PURGE RECYCLEBIN` はごみ箱内のすべてのデータベースオブジェクトを削除します。このステートメントを実行できるのはrootユーザーのみですので、操作には十分ご注意ください。
:::

## 構文

```sql
 PURGE RECYCLEBIN;
```

## 例

ごみ箱を空にします。

```sql
PURGE RECYCLEBIN;
Query OK, 0 rows affected (0.231 sec)
```
