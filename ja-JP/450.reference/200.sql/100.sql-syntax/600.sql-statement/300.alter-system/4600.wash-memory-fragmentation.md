# WASH MEMORY FRAGMENTATION

## 説明

通常、システムがメモリ断片化によりメモリ割り当てに失敗した場合、システムは自動的にメモリ断片をクリーンアップして再試行します。また、`ALTER SYSTEM WASH MEMORY FRAGMENTATION` ステートメントを使用して手動でメモリ断片をクリーンアップすることもできます。このステートメントは、サーバー上のすべての空きブロックを解放します。

## 権限要件

`ALTER SYSTEM WASH MEMORY FRAGMENTATION` ステートメントは、`root` ユーザーのみが実行できます。

## 構文

```sql
ALTER SYSTEM WASH MEMORY FRAGMENTATION server;

server_or_zone：
    SERVER [=] 'ip:port'
```

## パラメータ説明

|         **パラメータ**       |         **説明**                                                              |
|------------------------|-------------------------------------------------------------------------------|
| server     | クリーンアップ範囲を指定します。                                            |
| ip:port                | クリーンアップ対象のseekdbインスタンスのIPアドレスとRPCポート番号を指定します。 |

## 例

seekdb上のメモリ断片をクリーンアップします。

  ```sql
  ALTER SYSTEM WASH MEMORY FRAGMENTATION SERVER = '10.10.10.1:2882';
  ```
