# MODULE DATA

## 説明

`MODULE DATA` ステートメントには、以下の2つの機能があります：

* `ALTER SYSTEM LOAD MODULE DATA ...`：このステートメントは、指定された機能をインポートするために使用されます。
* `ALTER SYSTEM CHECK MODULE DATA ...`：このステートメントは、指定された機能がインポートされているかどうかを確認するために使用されます。

## 使用上の制限と注意事項

* 現在のバージョンでは、`REDIS` モジュール機能のインポートのみをサポートしています。
* 現在のバージョンでは、インポートされた `REDIS` モジュール機能のチェック（`CHECK MODULE DATA`）のみをサポートしています。

## 権限要件

このステートメントを実行するユーザーは `ALTER SYSTEM` 権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
ALTER SYSTEM {LOAD | CHECK} MODULE DATA
    MODULE = module_value
    [INFILE = file_path];

module_value:
    REDIS
    | GIS
    | TIMEZONE
```

## パラメータ説明

|      パラメータ     |            説明            |
|---------------|---------------------------|
| LOAD \| CHECK | インポートするかチェックするかを指定します。詳細は以下のとおりです：<ul><li>`LOAD`：指定された機能をインポートします。</li><li>`CHECK`：指定された機能が既にインポートされているかどうかをチェックします。</li></ul>|
| module_value  | 操作対象の機能を指定するために使用されます。詳細については、以下の [module_value](#module_value) を参照してください。|
| file_path     | インポートするSQLファイルのパスを指定します。<br/>`TIMEZONE` と `GIS` には複数のバージョンのデータが存在する可能性があるため、対応するバージョンのSQLファイルを指定する必要があります。現在、`TIMEZONE` と `GIS` にはそれぞれ1つのバージョンしかないため、デフォルトの `INFILE` パラメータをサポートしています。現在のバージョンでは、`REDIS` モジュール機能は `INFILE` パラメータをサポートしていないため、`INFILE` パラメータのパスを指定するとエラーが発生します。|

### module_value

* `REDIS`：`REDIS` モジュール機能を操作します。
* `GIS`：`GIS` モジュール機能を操作します。
* `TIMEZONE`：`TIMEZONE` モジュール機能を操作します。

## 例

### LOAD MODULE DATAの例

1. `INFILE`パスを使用して`REDIS`モジュール機能をインポートします。現在、`REDIS`モジュール機能は`INFILE`パスの使用をサポートしていないため、エラーが発生します。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = REDIS
        INFILE = '/home/admin/test.sql';
    ```

    実行結果は次のとおりです：

    ```shell
    ERROR 4025 (HY000): loading redis module does not need to specify infile
    ```

2. `REDIS`モジュール機能をインポートします。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = REDIS
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

3. `GIS`モジュール機能をインポートします。`INFILE`パラメータは省略可能で、デフォルト値は`etc/`です。対応するファイルはデプロイメントディレクトリの`etc`ディレクトリにあります。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = GIS
        INFILE = 'etc/';
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

4. `TIMEZONE`モジュール機能をインポートします。`INFILE`パラメータは省略可能で、デフォルト値は`etc/`です。対応するファイルはデプロイメントディレクトリの`etc`ディレクトリにあります。

    ```sql
    ALTER SYSTEM LOAD MODULE DATA
        MODULE = TIMEZONE
        INFILE = 'etc/';
    ```

    実行結果は次のとおりです：

    ```shell
    Query OK, 0 rows affected
    ```

### CHECK MODULE DATAの例

:::tip

現在のバージョンでは、インポートされた`REDIS`モジュール機能のチェック(`CHECK MODULE DATA`)のみがサポートされています。

:::

* 機能がインポートされていない場合、`CHECK MODULE DATA`ステートメントを実行するとエラーが発生します。インポートされた`REDIS`モジュール機能の状況を確認します。

    ```sql
    ALTER SYSTEM CHECK MODULE DATA
        MODULE = REDIS
    ```

    実行結果は次のとおりです：

    ```shell
    ERROR 4025 (HY000): redis info is not complete，please retry loading
    ```

* 機能をインポートした後、インポートされた機能の状況を確認します。

    1. `REDIS`モジュール機能をインポートします。

        ```sql
        ALTER SYSTEM LOAD MODULE DATA
            MODULE = REDIS
        ```

        実行結果は次のとおりです：

        ```shell
        Query OK, 0 rows affected
        ```

    2. インポートされた`REDIS`モジュール機能の状況を確認します。

        ```sql
        ALTER SYSTEM CHECK MODULE DATA
            MODULE = REDIS
        ```

        実行結果は次のとおりです：

        ```shell
        Query OK, 0 rows affected
        ```
