# PARAMETER

## 説明

* `ALTER SYSTEM [SET] parameter_name = expression` ステートメントは、パラメータの値を変更するために使用します。

* `ALTER SYSTEM [RESET] parameter_name = expression` ステートメントは、パラメータの値をリセットするために使用します。

## 使用上の制限と注意事項

パラメータの有効化方法は、一般的に動的有効化と再起動後の有効化の2種類があります。ほとんどのパラメータは動的有効化方式であり、seekdbを再起動しなくても有効になります。パラメータを変更する前に、`SHOW PARAMETERS LIKE` ステートメントを使用して、そのパラメータの有効化方式を確認できます。パラメータの有効化方式の詳細な操作については、[パラメータ](../../../../../400.guides/500.manage/100.configuration-management/200.system-configuration-items/100.configuration-items-overview.md)を参照してください。

## 権限要件

`ALTER SYSTEM [SET | RESET] parameter_name = expression` ステートメントを実行するには、現在のユーザーが `ALTER SYSTEM` 権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

### パラメータ値の変更

```sql
ALTER SYSTEM [SET] alter_system_set_parameter_action [, alter_system_set_parameter_action...]

alter_system_set_parameter_action:
parameter_name = expression [COMMENT [=] 'text']
```

#### パラメータ説明

|     **パラメータ**    |     **説明**         |
|-----------------|-----------------------|
| parameter_name | 変更対象の構成パラメータ名を指定します。    |
| expression     | 変更後の構成パラメータ値を指定します。   |
| COMMENT        | この変更に関するコメントを追加します。このパラメータはオプションですが、省略しないことを推奨します。   |

### パラメータ値のリセット

```sql
ALTER SYSTEM [RESET] alter_system_set_parameter_action [, alter_system_set_parameter_action...]

alter_system_set_parameter_action:
parameter_name = expression
```

#### パラメータ説明

|     **パラメータ**    |     **説明**         |
|-----------------|-----------------------|
| parameter_name | リセットする構成パラメータ名を指定します。    |
| expression     | リセットする構成パラメータを指定します。   |

## 例

### パラメータの変更

パラメータ `connection_control_max_connection_delay` の値を変更します。

  ```sql
  ALTER SYSTEM SET connection_control_max_connection_delay = 2147483646;
  ```

### パラメータのリセット

`log_disk_utilization_threshold` パラメータをリセットする例は以下のとおりです：

  ```sql
  ALTER SYSTEM RESET log_disk_utilization_threshold;
  ```
