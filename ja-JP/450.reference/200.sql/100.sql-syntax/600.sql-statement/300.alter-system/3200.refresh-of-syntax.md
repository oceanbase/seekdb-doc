# REFRESH

## 説明

このステートメントシリーズは、各種キャッシュのリフレッシュを含むリフレッシュ操作をトリガーするために使用されます。

## 構文

```sql
alter_system_refresh_stmt:
  ALTER SYSTEM refresh_action;

refresh_action:
  | FLUSH KVCACHE
```

## パラメータの説明

|         **パラメータ**       |         **説明**          |
|------------------------|----------------------------|
| FLUSH KVCACHE          | 動的に拡張可能なメモリKVCacheをクリアします。 |

## 例

すべてのKVCacheをリフレッシュします。

  ```shell
  ALTER SYSTEM FLUSH KVCACHE;
  Query OK, 0 rows affected
  ```
