# LOAD INDEX INTO CACHE

## 説明

このステートメントは、クエリのパフォーマンスを向上させるためにインデックスをキャッシュにロードするために使用されます。各インデックスを個別にロードする代わりに、一度に複数のインデックスをキャッシュにロードできます。これにより、インデックスのロード時のシステムオーバヘッドが削減され、全体のパフォーマンスが向上します。

## 構文

```sql
LOAD INDEX INTO CACHE tbl_index_list [, tbl_index_list ...];

tbl_index_list:
    tbl_name [PARTITION (partition_list)] [{INDEX|KEY} (index_name[, index_name ...])] [IGNORE LEAVES]

partition_list:
    partition_name [, partition_name ...]
    | ALL
```

:::info
 現在のバージョンではこのステートメントの構文のみサポートされており、機能は有効ではありません。
:::
