# CREATE OUTLINE

## 説明

このステートメントは、アウトラインを作成するために使用します。作成方法は2通りあります。1つは `SQL_TEXT` を使用する方法（ユーザーが実行したパラメータ付きの元のステートメント）で、もう1つは `SQL_ID` を使用する方法です。

  :::info

  アウトラインを作成するには、対応するデータベースに入って実行する必要があります。

  :::

`SQL_ID` が同じ場合、`SQL_TEXT` を使用して作成したアウトラインは、`SQL_ID` を使用して作成したアウトラインを上書きします。`SQL_TEXT` を使用した方法の方が優先順位が高いです。

また、seekdbは `SQL_ID` によって異なるSQLを区別しますが、`SQL_ID` は `SQL_TEXT` のMD5ハッシュ値から得られます。同じSQLテキストでも、改行やタブが1文字でも違うと、MD5で得られる `SQL_ID` は異なります。実際の本番システムでは、`SQL_ID` を使用したアウトラインのバインドを推奨します。

## 構文

* `SQL_TEXT` を使用してアウトラインを作成します。

  ```sql
  CREATE [OR REPLACE] OUTLINE outline_name ON stmt [ TO target_stmt ]
  ```

* `SQL_ID` を使用してアウトラインを作成します。

  ```sql
  CREATE OUTLINE outline_name ON sql_id USING HINT hint;
  ```

## パラメータの説明

|     **パラメータ**     |    **説明**     |
|----------------|-----------------------|
| outline_name   | 作成するアウトライン名を指定します。    |
| OR REPLACE     | `OR REPLACE` を指定した場合、作成しようとするアウトラインが既に存在すると、既存のアウトラインは置き換えられます。   |
| stmt           | 一般的には、Hintと元のパラメータを含むDMLステートメントです。  |
| TO target_stmt | `TO target_stmt` を指定しない場合、データベースが受け付けるSQLがパラメータ化された後、`stmt` のHintパラメータ化テキストと同じである場合、そのSQLは `stmt` のHintで実行計画を生成してバインドされます。Hintを含むステートメントに対して固定計画を希望する場合は、`TO target_stmt` で元のSQLを指定する必要があります。 <br />**注意**  `target_stmt` を使用する場合、`stmt` と `target_stmt` がHintを除去した後完全に一致することが厳密に要求されます。 |
| sql_id         | `sql_id` に対応するSQLステートメントにすでにHintがある場合、アウトライン作成時に指定したHintが元のステートメント内のすべてのHintを上書きします。   |
| hint           | 形式は `/*+ xxx */` です。           |

## 例

* `SQL_TEXT` を使用してアウトラインを作成します。

  ```sql
  CREATE OUTLINE otl_idx_c2
  ON SELECT/*+ index(t1 idx_c2)*/ * FROM t1 WHERE c2 = 1;
  ```

* `SQL_ID` を使用してアウトラインを作成します。

  ```sql
  CREATE OUTLINE otl_idx_c2
  ON 'ED570339F2C856BA96008A29EDF04C74'
  USING HINT /*+ index(t1 idx_c2)*/ ;
  ```
