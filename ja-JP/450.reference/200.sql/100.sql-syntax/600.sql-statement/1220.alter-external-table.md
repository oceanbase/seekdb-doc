# ALTER EXTERNAL TABLE

## 説明

このステートメントは、外部テーブルのファイルを手動で更新するために使用します。単一ファイルのテーブルデータは自動的に更新できますが、外部テーブルデータがファイルリストから取得される場合は自動更新できず、手動でリフレッシュする必要があります。

## 構文

```sql
ALTER EXTERNAL TABLE table_name REFRESH;
```

## パラメータ説明

`table_name` は、リフレッシュする外部テーブル名を指定します。

## 例

```shell
ALTER EXTERNAL TABLE lineitem REFRESH;
```

```shell
Query OK, 0 rows affected
```
