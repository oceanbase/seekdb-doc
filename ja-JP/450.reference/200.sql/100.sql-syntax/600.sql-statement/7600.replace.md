# REPLACE

## 説明

このステートメントは、テーブル内の1つまたは複数のレコードを置き換えるために使用されます。主キーまたは一意キーとの競合がない場合はレコードを挿入し、競合が存在する場合は競合するレコードを削除してから新しいレコードを挿入します。

## 構文

```sql
replace_stmt:
    REPLACE [INTO] table_factor [PARTITION (partition_name_list)] [(column_name_list)]
    {VALUES | VALUE} column_value_lists;

partition_name_list:
        partition_name [, partition_name ...]

column_name_list:
    column_name [, column_name ...]

column_value_lists:
        (column_value_list) [, (column_value_list) ...]

column_value_list:
    column_value [, column_value ...]

column_value:
    {expression | DEFAULT}
```

## パラメータの説明

|       **パラメータ**        |   **説明**   |
|---------------------|------------|
| table_factor        | 置き換えるテーブル名。     |
| column_name_list    | 置き換えるデータの列を指定します。  |
| partition_name_list | 置き換えるテーブルの指定するパーティション名。 |

## 例

この例は、以下のテーブル定義に基づいています。

```sql
CREATE TABLE test (c1 INT PRIMARY KEY, c2 VARCHAR(40));
Query OK, 0 rows affected (0.547 sec)
```

1. `test` テーブルの行1と行2の値をそれぞれ `'hello alibaba'` と `'hello ob'` に置き換えます。

   ```sql
   REPLACE INTO test VALUES (1, 'hello alibaba'),(2, 'hello ob');
   Query OK, 2 rows affected (0.689 sec)
   Records: 2  Duplicates: 0  Warnings: 0
   ```

2. `test` テーブルの行1と行2の内容を確認します。

   ```sql
   SELECT * FROM test;
   +----+---------------+
   | c1 | c2            |
   +----+---------------+
   |  1 | hello alibaba |
   |  2 | hello ob      |
   +----+---------------+
   2 rows in set (0.001 sec)
   ```

3. テーブル `test` の行3の内容を行2の内容 `'hello alibaba'` に、行2の内容を `'hello oceanbase'` に置き換えます。

   ```sql
   REPLACE INTO test VALUES (3, 'hello alibaba'),(2, 'hello oceanbase');
   Query OK, 3 rows affected (0.767 sec)
   Records: 2  Duplicates: 1  Warnings: 0
   ```

4. `test` テーブルの行1、行2、行3の内容を確認します。

   ```sql
   SELECT * FROM test;
   +----+-----------------+
   | c1 | c2              |
   +----+-----------------+
   |  1 | hello alibaba   |
   |  2 | hello oceanbase |
   |  3 | hello alibaba   |
   +----+-----------------+
   3 rows in set (0.019 sec)
   ```
