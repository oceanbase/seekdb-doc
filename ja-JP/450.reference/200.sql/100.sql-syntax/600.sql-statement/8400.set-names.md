# SET NAMES

## 説明

クライアント、接続、および結果の文字セットと照合順序を設定します。

## 構文

```sql
SET NAMES charset_name [COLLATE collation_name]
```

## パラメータの説明

|       パラメータ       |   説明     |
|----------------|--------------------|
| charset_name   | テーブルの列のデフォルト文字セットを指定します。使用可能な文字セットは以下のとおりです： <ul><li> `binary`   </li><li> `utf8mb4`   </li><li> `gbk`   </li><li> `utf16`   </li><li> `gb18030` </li></ul>  |
| collation_name | テーブルの列のデフォルト照合順序を指定します。使用可能な照合順序は以下のとおりです： <ul><li> `binary`   </li><li> `gbk_bin`   </li><li> `gbk_chinese_ci`   </li><li> `utf8mb4_general_ci`   </li><li> `utf8mb4__general_cs`   </li><li> `utf8mb4_bin`   </li><li> `utf8mb4_unicode_ci`   </li><li> `utf16_general_ci`   </li><li> `utf16_bin`   </li><li> `utf16_unicode_ci`   </li><li> `gb18030_chinese_ci`   </li><li> `gb18030_bin`  </li></ul>  |

## 例

クライアント、接続、および結果の文字セットを `gbk`、照合順序を `gbk_bin` に指定します。

```sql
SET NAMES gbk COLLATE gbk_bin;
Query OK, 0 rows affected (0.126 sec)
```
