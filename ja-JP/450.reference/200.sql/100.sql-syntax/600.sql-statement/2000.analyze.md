# ANALYZE

## 説明

このステートメントは、テーブルまたはテーブルのパーティションの統計情報を収集するために使用されます。

## 構文

```sql
ANALYZE TABLE table_name UPDATE HISTOGRAM ON column_name_list WITH INT_NUM BUCKETS;
```

パラメータ `enable_sql_extension` が `TRUE` に設定されている場合、以下の構文を使用できます：

```sql
ANALYZE TABLE table_name [use_partition] COMPUTE STATISTICS [ for_clause ];

use_partition:
    PARTITION (parition_name [,partition_name,....])
   | SUBPARTITION(subpartition_name, [,subpartition_name,...])

analyze_statistics_clause:
    COMPUTE STATISTICS [analyze_for_clause]
    | ESTIMATE STATISTICS [analyze_for_clause] [SAMPLE INTNUM {ROWS | PERCENTAGE}]

analyze_for_clause:
    FOR TABLE
    | FOR ALL [INDEXED | HIDDEN] COLUMNS [size_clause]
    | FOR COLUMNS [size clause] column [size_clause] [,column [size_clause]...]

size_clause:
    SIZE integer
    | SIZE REPEAT
    | SIZE AUTO
    | SIZE SKEWONLY

column:
    column_name
    | (column_name [, column_name])

```

## パラメータの説明

| パラメータ             |       説明        |
|----------------------------|----------|
| table_name | 分析対象のテーブルを指定します。|
| INT_NUM | 整数。Bucketの数です。Bucketの取り得る値については、[method_opt](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002017252)を参照してください。|
| use_partition | パーティション名を指定します。テーブル名を指定した場合は、パーティション統計情報は収集されません。 |
| compute_statistics_clause  | `COMPUTE STATISTICS` を指定すると、分析対象の正確な統計情報を計算し、データディクショナリに格納できます。テーブルを分析する際には、テーブルと列の統計情報が同時に集計されます。 |
| for_clause                 | 全体のテーブルを分析するか、特定の列のみを分析するかを指定します。 <ul><li> `FOR TABLE`：テーブルの統計情報のみを収集することを指定します。  </li><li> `FOR COLUMNS`：指定された列とスカラーオブジェクトの属性列の統計情報のみを収集することを指定します。ここで、`attribute` はオブジェクト内の特定の列名を指定します。   </li><li> `FOR ALL COLUMNS`：すべての列とスカラーオブジェクトの属性列の統計情報を収集することを指定します。   </li><li> `FOR ALL INDEXED COLUMNS`：すべてのインデックス列の列統計情報を収集することを指定します。列統計情報は、完全な列に基づくことも、`SIZE` を指定してヒストグラムを使用することもできます。   </li><li> `FOR ALL HIDDEN COLUMNS`：すべての隠れた列の列統計情報を収集することを指定します。列統計情報は、完全な列に基づくことも、`SIZE` を指定してヒストグラムを使用することもできます。   </li><li> `SIZE`：ヒストグラム内の最大バケット数を指定します。取り得る範囲は \[1,2048\] で、デフォルト値は `256` です。 </li></ul>   |
| estimate_statistics_clause | `ESTIMATE STATISTICS` を指定すると、分析対象の統計情報を推定し、データディクショナリに格納できます。   |
| SAMPLE                     | 統計情報の推定に使用される分析対象内のサンプルデータ量を指定します。このパラメータを省略した場合、データベースオプティマイザーが適切な比率を自動的に選択してサンプリングを行います。 <ul><li> `ROWS`：テーブル内の `integer` 行をサンプリングします。   </li><li> `PERCENT`：テーブルの行の `integer` パーセンテージをサンプリングします。</li></ul> |

## 例

* `test` テーブルの統計情報を収集します。列のバケット数は30個です。

```sql
CREATE TABLE test (c1 NUMBER(30) PRIMARY KEY,c2 VARCHAR(50));
Query OK, 0 rows affected (0.001 sec)

ANALYZE TABLE test UPDATE HISTOGRAM ON c1,c2 with 30 buckets;
Query OK, 0 rows affected (0.001 sec)
```

* パラメータ `enable_sql_extension` が `TRUE` の場合、以下の構文を使用してユーザー `user01` のテーブル `test` の統計情報を収集します。すべての列のバケット数は128に設定されます。

```sql
ALTER SYSTEM SET enable_sql_extension = TRUE;
Query OK, 0 rows affected (0.001 sec)

ANALYZE TABLE test COMPUTE STATISTICS FOR ALL COLUMNS SIZE 128;
Query OK, 0 rows affected (0.001 sec)
```
