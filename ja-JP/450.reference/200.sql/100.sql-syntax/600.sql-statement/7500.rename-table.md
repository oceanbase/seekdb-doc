# RENAME TABLE

## 説明

このステートメントは、1つまたは複数のテーブルを名前変更するために使用します。

## 使用制限と注意事項

* テーブルの名前変更プロセス中、システムはこのプロセスを自動的にロックし、名前変更が完了するまで他のスレッドによるこれらのテーブルへの読み取り操作を阻止します。

* ターゲットテーブルに継続的にアクティブなトランザクションが存在する場合、名前変更操作は待機状態になります。すべてのアクティブなトランザクションがコミットまたはロールバックされるまで、テーブルの名前変更処理は進行できません。

* このステートメントを使用して複数のテーブルを名前変更する場合、名前変更操作は左から右の順に行われます。

* `RENAME TABLE` を実行する際には、ロックされたテーブルやアクティブな状態のトランザクションは存在してはなりません。

   :::info
   パラメータ [enable_lock_priority](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002973869) を有効にすると、`RENAME TABLE` は最も高いロック優先順位を持ちます。
   :::

* `RENAME TABLE` はビューに対して使用できますが、他のデータベースへの移動はサポートされていません。

* `RENAME TABLE` 操作中は、テーブルロックや読み書き防御策が追加されるため、操作時間が長くなります。他のユーザーのDDL操作に影響を与えないよう、一括で `RENAME TABLE` 操作を行うことは推奨されません。

## 権限要件

この操作には、元のテーブルに対する `ALTER` および `DROP` 権限と、新しいテーブルに対する `CREATE` および `INSERT` 権限が必要です。

## 構文

```sql
RENAME TABLE table_name TO [new_database_name.]new_table_name
   [, table_name2 TO [new_database_name.]new_table_name2 ...];
```

## パラメータの説明

|                               **パラメータ**                                |                                  **説明**                                   |
|---------------------------------------------------------------------|---------------------------------------------------------------------------|
| table_name                                                          | 元のテーブル名。                                                                      |
| new_table_name                                                      | 新しいテーブル名。                                                                      |
| table_name  TO \[new_database_name.\]new_table_name | 複数のテーブルを名前変更する場合は、カンマ（,）で区切ります。`new_database_name` を指定すると、テーブルを別のデータベースに移動できます。 |

## 例

1. テーブル `t1` と `t2` を作成します。

   ```sql
   CREATE TABLE t1(c1 INT);
   CREATE TABLE t2(c1 INT);
   ```

2. テーブル `t1` の名前を `t11` に変更します。

   ```sql
   RENAME TABLE t1 TO t11;
   ```

3. テーブル `t11` の名前を `t111` に、テーブル `t2` の名前を `t22` に変更します。

   ```sql
   RENAME TABLE t11 TO t111, t2 TO t22;
   ```

4. テーブル `t22` を `mysql` データベースに移動します。

   ```sql
   RENAME TABLE t22 TO mysql.t22;
   ```
