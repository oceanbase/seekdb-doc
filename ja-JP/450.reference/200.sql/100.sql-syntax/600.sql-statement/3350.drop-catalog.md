# DROP CATALOG

## 説明

このステートメントは、外部データカタログ(External Catalog)を削除するために使用されます。

## 権限要件

`DROP CATALOG` ステートメントを実行するには、現在のユーザーが `CREATE CATALOG` 権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
DROP CATALOG [IF EXISTS] external_catalog_name;
```

## パラメータ説明

|   **パラメータ**   | **説明** |
|--------------|----------|
| IF EXISTS    | オプションです。`IF EXISTS`を指定すると、削除対象の外部データカタログが存在しない場合でもエラーは報告されません。指定しない場合はエラーが報告されます。|
| external_catalog_name | 削除する外部データカタログの名前を指定します。|

## 例

```sql
DROP CATALOG test_odps_catalog;
```
