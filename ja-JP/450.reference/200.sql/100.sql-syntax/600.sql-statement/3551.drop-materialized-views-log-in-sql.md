# DROP MATERIALIZED VIEW LOG

## 説明

このステートメントは、マテリアライズドビューのログを削除するために使用します。

:::info
マテリアライズドビューのログを削除する際、ベーステーブルで実行中のトランザクション操作がある場合、そのトランザクションが終了するまで削除操作はブロックされます。
:::

## 権限要件

マテリアライズドビューのログを削除するには、`DROP TABLE` 権限が必要です。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
DROP MATERIALIZED VIEW LOG ON [database.] table;
```

## パラメータ説明

| **パラメータ**  |       **説明**           |
|-----------|--------------------------|
| database.   | オプションです。マテリアライズドビューのログに対応するベーステーブルが存在するデータベースを指定します。`database.` を省略した場合、デフォルトでベーステーブルは作成者自身のデータベースに配置されます。|
| table     | マテリアライズドビューのログに対応するベーステーブル名を指定します。|

## 例

テーブル `test_tbl1` のマテリアライズドビューのログを削除します。

```shell
DROP MATERIALIZED VIEW LOG ON test_tbl1;
```

結果は次のとおりです：

```shell
Query OK, 0 rows affected
```
