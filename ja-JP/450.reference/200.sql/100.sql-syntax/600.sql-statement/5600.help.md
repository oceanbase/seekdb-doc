# HELP

## 説明

ヘルプテーブルの検索結果を返します。検索文字列にはワイルドカードであるパーセント記号（`%`）とアンダースコア（`_`）を含めることができます。

  :::info

  `HELP` 機能を正常に使用するには、`help tables` をロードする必要があります。手順は以下のとおりです：

  1. `fill_help_tables-ob.sql` ファイルをクライアントマシンの `tmp` ディレクトリにコピーします。

  2. seekdbにログインし、`source /tmp/fill_help_tables-ob.sql` ステートメントを実行します。

  :::

検索文字列は、1つのカテゴリ、複数のトピック、または単一のトピックと一致することができます：

* トップレベルのヘルプカテゴリのリストを表示する：

  ```sql
  HELP 'contents';
  ```

* 各ヘルプカテゴリのトピックを表示する。例えば、データ型 `data types` を検索する：

  ```sql
  HELP 'data_types';
  ```

* 特定のヘルプトピックについては、関連する1つ以上のキーワードを使用できます：

  ```sql
  HELP 'create table'
  ```

  実行されたトピックには、以下の情報が含まれます：

  * `name`：トピック名。

  * `description`：そのトピックの説明的なヘルプテキスト。

## 構文

```sql
HELP 'search_string';

search_string:
   contents | data_types | theme
```

## パラメータの説明

|     パラメータ     |              説明               |
|------------|-------------------------------|
| contents   | すべてのヘルプ情報のディレクトリを表示します。ディレクトリ名でヘルプ情報をさらに検索できます。 |
| data_types | 指定したデータ型のヘルプ情報を表示します。                |
| theme      | 指定したテーマのヘルプ情報を表示します。                  |

## 例

* すべてのヘルプ情報のディレクトリを表示します。

  ```sql
  HELP 'contents';
  You asked for help about help category: "Contents"
  For more information, type 'help <item>', where <item> is one of the following
  categories:
     Data Types
     Functions
     Operator
     Escape character
     Data Definition
     Data Manipulation
     Transaction Statements
     Prepared Statements
     Compound Statements
     Administration
     Utility
  ```

* Numeric Typeに含まれるデータ型を確認します。

  ```sql
  HELP 'Numeric Types';
  You asked for help about help category: "Numeric Types"
  For more information, type 'help <item>', where <item> is one of the following
  topics:
     TINYINT
     BOOL,BOOLEAN
     SMALLINT
     MEDIUMINT
     INT
     INTEGER
     BIGINT
     FLOAT
     DOUBLE
     DOUBLE PRECISION
     FLOAT(p)
     DECIMAL
     NUMERIC
  ```

* `KILL` ステートメントの使い方を確認します。

  ```sql
  HELP 'KILL';
  Name: 'KILL'
  Description:

    構文：

    KILL [GLOBAL | LOCAL] [CONNECTION | QUERY] 'sessionid'

    OceanBaseとの各接続は独立したスレッドで実行されます。SHOW PROCESSLIST; ステートメントを使用して実行中のスレッドを確認し、KILL thread_id ステートメントを使用してスレッドを終了できます。

  • KILL CONNECTIONは、修飾子なしのKILLと同じです。指定されたthread_idとの接続を終了します。

  • KILL QUERYは、接続が現在実行しているステートメントを終了しますが、接続自体は維持されます。
  PROCESS権限があれば、すべてのスレッドを確認できます。SUPER権限があれば、すべてのスレッドとステートメントを終了できます。それ以外の場合は、自身のスレッドとステートメントのみを確認および終了できます。
  ```

* `SELECT` ステートメントの構文を確認します。

  ```sql
  HELP SELECT
  Name: 'SELECT'
  Description:

    このステートメントは、テーブルの内容を照会するために使用されます。

    基本的なクエリ

    構文：

    SELECT
      [ALL | DISTINCT]
        selectexpr [AS othername] [, selectexpr ...]
        [FROM table_references]
          [WHERE where_conditions]
      [GROUP BY group_by_list]
      [HAVING search_confitions]
      [ORDER BY order_list]
      [LIMIT {[offset,] rowcount | rowcount OFFSET offset}]
          [FOR UPDATE];
  ```
