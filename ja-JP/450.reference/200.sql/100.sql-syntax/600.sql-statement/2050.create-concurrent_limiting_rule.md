# CREATE CONCURRENT_LIMITING_RULE

## 説明

このステートメントは、レート制限ルールを作成し、特定のSQLの同時実行数を制限するためのレート制限範囲を指定します。

## 権限要件

`CREATE CONCURRENT_LIMITING_RULE` ステートメントを実行するには、現在のユーザーがCREATE権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
CREATE CONCURRENT_LIMITING_RULE [ IF NOT EXISTS ] `ccl_rule_name`
ON `database`.`table`
TO '<usename>'@'ip'
FOR { ALL | UPDATE | SELECT | INSERT | DELETE }
filter_options:
    [ FILTER BY KEYWORD('KEYWORD1', 'KEYWORD2',…) ]
 with_options:
    WITH MAX_CONCURRENCY = value1 [per sql]
```

## パラメータの説明

| パラメータ             |       説明        |
|----------------------------|----------|
|`ccl_rule_name`|必須。レート制限ルールの名前を表します。<br/> **説明** 名前がSQLキーワードと競合するのを避けるため、ルール名の前後にバッククォート(`)を付けることを推奨します。|
|`database`.`table`|必須。データベースとテーブルの名前を表します。アスタリスク(*)を使用して任意の文字列をマッチさせることができます。<br/> **説明** 名前がSQLキーワードと競合するのを避けるため、ルール名の前後にバッククォート(`)を付けることを推奨します。|
|`<usename>@<host>`|必須。アカウント名を表します。usernameには*を使用してすべてのユーザーを表すことができ、Host部分にはパーセント記号(%)を使用して任意の文字列をマッチさせることができます。|
|`ALL`\|`UPDATE \| SELECT \| INSERT\| DELETE`|必須。SQL文のタイプを表します。現在、`ALL`、`UPDATE`、`SELECT`、`INSERT`、`DELETE`タイプをサポートしています。<br/>**説明** 各レート制限ルールは、1種類のSQL文タイプのみをサポートします。|
|`[ filter_options ]`|オプション。レート制限のキーワードを表します。<br/> **説明** <ul><li>キーワード間はワイルドカード<code>%</code>で結合されます。例えば、3つのキーワード<code>'asdasd', 'c2 = 123', 'xxyyzz'</code>が与えられた場合、<code>'%asdasd%c2 = 123%xxyyzz%'</code>という文字列に組み合わされ、その後この文字列に基づいてSQLテキストのワイルドカード検索が行われます。</li><li>キーワードに<code>'_'</code>が含まれる場合、エスケープされます。例えば、<code>'table_t1'</code>は<code>'%table\_t1%'</code>として記録されます。</li><li> レート制限のキーワードに数の制限はありませんが、組み合わせた後の文字列の長さは <code>OB_MAX_VARCHAR_LENGTH=1048576</code> を超えてはなりません。</li></ul>|
|`with_options`|必須。レート制限の並列度を制御し、レート制限の統計粒度がルールレベルかFormat SQLID文レベルかを指定します。現在、`MAX_CONCURRENCY`パラメータのみをサポートしており、このレート制限ルールに一致するSQL文の最大並列度を表します。|

## 例

以下のコマンドを実行して、キーワードに対するレート制限を設定します：

```shell
CREATE CONCURRENT_LIMITING_RULE IF NOT EXISTS  `sql1_keywords_ccl_rule`
ON *.* TO '%'@'%' FOR SELECT
FILTER BY KEYWORD('table1', 'table2', 'c1') WITH MAX_CONCURRENCY 100;
```
