# SET ROLE

## 説明

このステートメントは、現在ログインしているユーザーが現在のセッションで付与されているロールを有効にするために使用します。

:::info
`SET ROLE` ステートメントで有効になるロールは、現在のセッションにのみ影響し、後のセッションには影響しません。
:::

## 構文

```sql
SET ROLE {
    DEFAULT
    | NONE
    | ALL
    | ALL EXCEPT role_name [, role_name ...]
    | role_name [, role_name ...]
};
```

## パラメータの説明

|       **パラメータ**      | **説明** |
|---------------------|----------|
| DEFAULT             | デフォルトのロール設定を維持するよう指定します。システムは、変数 `activate_all_roles_on_login` の値および `SET DEFAULT ROLE` ステートメントまたは `ALTER USER` ステートメントで設定されたデフォルトの有効なロールに基づいてロールを有効化します。<ul><li>変数 <code>activate_all_roles_on_login</code> の値が <code>on</code> の場合、セッションではユーザーに付与されたすべてのロールが有効になります。</li><li>変数 <code>activate_all_roles_on_login</code> の値が <code>off</code> の場合、セッションでは <code>SET DEFAULT ROLE</code> ステートメントまたは <code>ALTER USER</code> ステートメントで指定されたデフォルトの有効なロールが有効になります。</li></ul>|
| NONE                | ユーザーに付与されたすべてのロールを無効にするよう指定します。|
| ALL                 | ユーザーに付与されたすべてのロールを有効にするよう指定します。|
| ALL EXCEPT          | ユーザーに付与されたロールのうち、特定のロールを除くよう指定します。|
| role_name           | ロール名を指定します。複数のロールを有効にする場合は、ロール名を半角カンマ（`,`）で区切ります。|

## 例

* 現在のセッションで、ユーザーが付与されたロールのうち、`role001` を除くすべてのロールを有効にします。

  ```shell
  SET ROLE ALL EXCEPT role001;
  ```

* 現在のセッションで、ユーザーの `role001` と `role002` のロールを有効にします。

  ```shell
  SET ROLE role001, role002;
  ```
