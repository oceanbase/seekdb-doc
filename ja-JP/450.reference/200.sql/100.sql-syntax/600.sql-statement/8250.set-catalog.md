# SET CATALOG

## 説明

このステートメントは、カタログを切り替えるために使用されます。

:::info
seekdbは`SET CATALOG`ステートメントをサポートしています。
:::

## 権限要件

`SET CATALOG`ステートメントを実行するには、現在のユーザーが`USE CATALOG`権限を持っている必要があります。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
SET CATALOG {INTERNAL | external_catalog_name};
```

## パラメータ説明

|        **パラメータ**       | **説明** |
|-----------------------|----------|
| INTERNAL              | システム内部カタログに切り替えることを示します。|
| external_catalog_name | 外部データカタログに切り替える名前を指定します。|

:::info
`use internal.test`または`use odps_catalog.default`を使用すると、カタログとデータベースの切り替えを一度に完了できます。
:::

## 例

* 外部データカタログ`test_odps_catalog`に切り替えます。

  ```sql
  SET CATALOG test_odps_catalog;
  ```

* システム内部カタログに切り替えます。

  ```sql
  SET CATALOG INTERNAL;
  ```
