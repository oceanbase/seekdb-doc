# DROP MATERIALIZED VIEW

## 説明

このステートメントは、マテリアライズドビューを削除するために使用します。

## 権限要件

マテリアライズドビューのログを削除するには、`DROP TABLE` 権限が必要です。seekdb権限の詳細については、[seekdbの権限分類](../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/100.permission-classification.md)を参照してください。

## 構文

```sql
DROP MATERIALIZED VIEW [IF EXISTS] materialized_view_list [opt_drop_behavior];

materialized_view_list:
    [ database. ]materialized_view [,[ database. ]materialized_view]...

opt_drop_behavior:
    RESTRICT | CASCADE
```

## パラメータ説明

|       **パラメータ**    |       **説明**           |
|-------------------|--------------------------|
| IF EXISTS         | オプションです。`IF EXISTS` を指定すると、削除対象のマテリアライズドビューが存在しない場合でもエラーは報告されません。指定しない場合、削除対象のマテリアライズドビューが存在しないとエラーが発生します。 |
| database.         | オプションです。マテリアライズドビューが存在するデータベースを指定します。`database.` を省略した場合、デフォルトで自身のデータベースが使用されます。|
| materialized_view | マテリアライズドビューの名前を指定します。|
| RESTRICT \| CASCADE | オプションです。削除操作の動作を示します。<ul><li>CASCADE がデフォルト値であり、マテリアライズドビューを削除する際に、それに依存する他のオブジェクトも削除します。</li><li>RESTRICT は、他のオブジェクトがそのマテリアライズドビューに依存している場合、マテリアライズドビューの削除を許可しません。</li></ul>|

## 例

`test_db` データベース内の `mv_test_tbl1` という名前のマテリアライズドビューを削除します。

```sql
DROP MATERIALIZED VIEW mv_test_tbl1;
```

実行結果は次のとおりです：

```shell
Query OK, 0 rows affected (0.001 sec)
```
