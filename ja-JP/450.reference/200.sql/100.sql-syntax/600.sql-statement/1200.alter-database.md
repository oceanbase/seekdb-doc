# ALTER DATABASE

## 説明

このステートメントは、データベースのプロパティを変更するために使用します。

## 構文

```sql
ALTER {DATABASE|SCHEMA} [database_name] [SET] alter_specification [alter_specification ...];

alter_specification:
    [DEFAULT] {CHARACTER SET | CHARSET} [=] charset_name
  | [DEFAULT] COLLATE [=] collation_name
  | {READ ONLY | READ WRITE}
```

## パラメータの説明

| **パラメータ**   |    **説明**   |
|-------|---|
| database_name   | プロパティを変更するデータベースの名前を指定します。指定しない場合、現在のデータベースが変更されます。現在のデータベースが空の場合は、エラーが返されます。   |
| \[DEFAULT\] \{ CHARACTER SET \| CHARSET \} charset_name | データベースのデフォルト文字セットを指定します。`CHARACTER SET` と `CHARSET` は同義です。`DEFAULT` キーワードはオプションであり、意味に影響しません。                              |
| \[DEFAULT\] COLLATE collation_name  | データベースのデフォルト照合順序を指定します。`DEFAULT` キーワードはオプションであり、意味に影響しません。      |
| READ ONLY \| READ WRITE   | データベースレベルの読み取り専用または読み書き属性を設定します。    |

## 例

データベース `test2` の文字セットを `UTF8MB4`、照合順序を `UTF8MB4_BIN` に変更し、読み書き可能な属性に設定します。

```shell
ALTER DATABASE test2 DEFAULT CHARACTER SET utf8mb4;
```

```shell
ALTER DATABASE test2 DEFAULT COLLATE utf8mb4_bin;
```

```shell
ALTER DATABASE test2 READ WRITE;
```
