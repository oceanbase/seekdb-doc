# UNLOCK TABLES

## 説明

このステートメントは、現在のセッションが保持するすべてのテーブルロックを解除します。

## 使用上の制限と注意事項

`UNLOCK TABLES` は、トランザクションを自動的にコミットしません。

## 構文

```sql
UNLOCK {TABLE | TABLES};
```

## 構文の説明

|       **フィールド名**       | **説明** |
|--------------------------|----------|
| UNLOCK \{TABLE \| TABLES\} | 現在のセッションが保持するすべてのテーブルロックを解除します。`UNLOCK TABLE` は `UNLOCK TABLES` の同義語です。|

## 例

現在のセッションが保持するすべてのテーブルロックを解除します。

```sql
UNLOCK TABLES;
```
