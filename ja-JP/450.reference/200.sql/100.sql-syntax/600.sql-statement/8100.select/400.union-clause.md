# UNION句

## 説明

このステートメントは、複数の `SELECT` クエリの結果に対して集合演算を実行するために使用されます。

## 使用上の制限と注意事項

* 集合演算子はすべて同じ優先順位を持ちます。SQL文に複数の集合演算子が含まれる場合、seekdbは括弧で演算順序を明示的に指定しない限り、左から右の順に評価します。

* 各集合演算子は `SELECT` ステートメントの結果セットに対してのみ操作でき、各結果セットの列数とデータ型は同じでなければなりません。

## 構文

```sql
select_stmt
    {UNION | UNION ALL | MINUS | EXCEPT | INTERSECT} select_stmt
    [, {UNION | UNION ALL | MINUS | EXCEPT | INTERSECT} select_stmt ...]
    [ORDER BY order_by_condition_list]
    [LIMIT limit_clause];
```

## パラメータの説明

|                パラメータ              |                           説明                    |
|----------------------------------|--------------------------------------------------|
| select_stmt                      | 集合演算に使用される `SELECT` ステートメントです。`SELECT` ステートメントの詳細については、[SELECT](100.select.md)を参照してください。|
| UNION                            | 2つの `SELECT` ステートメントの結果セットを1つの集合に結合し、重複行を除去します。|
| UNION ALL                        | 2つの `SELECT` ステートメントの結果セットを1つの集合に結合し、重複行を除去しません。|
| MINUS \| EXCEPT                  | 前の `SELECT` ステートメントの結果セットに含まれ、後の `SELECT` ステートメントの結果セットには含まれない行を返します。`MINUS` は `EXCEPT` の同義語です。|
| INTERSECT                        | 2つの `SELECT` ステートメントの結果セットの共通部分を返し、重複を除去します。|
| ORDER BY order_by_condition_list | 集合演算後のソートを指定するために使用されます。|
| LIMIT limit_clause               | 集合演算後に返す行数を指定するために使用されます。|

## 例

1. テーブル `test_tbl1` と `test_tbl2` を作成します。

   ```sql
   CREATE TABLE test_tbl1 (col1 INT, col2 INT);
   CREATE TABLE test_tbl2 (col1 INT, col2 INT);
   ```

2. テーブル `test_tbl1` と `test_tbl2` にテストデータを挿入します。

   ```sql
   INSERT INTO test_tbl1 VALUES (1, 1), (2, 2), (4, 4);
   INSERT INTO test_tbl2 VALUES (2, 2), (3, 3), (5, 5);
   ```

* テーブル `test_tbl1` と `test_tbl2` から列 `col1` と `col2` のデータを選択し、`UNION ALL` 演算子を使用してそれらを結果セットに統合します。重複する行は保持されます。

  ```sql
  SELECT col1, col2 FROM test_tbl1
  UNION ALL
  SELECT col1, col2 FROM test_tbl2;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    1 |    1 |
  |    2 |    2 |
  |    4 |    4 |
  |    2 |    2 |
  |    3 |    3 |
  |    5 |    5 |
  +------+------+
  6 rows in set (0.023 sec)
  ```

* テーブル `test_tbl1` と `test_tbl2` から列 `col1` と `col2` のデータを選択し、`UNION` 演算子を使用してそれらを結果セットに統合します。重複する行は除外されます。

  ```sql
  SELECT col1, col2 FROM test_tbl1
  UNION
  SELECT col1, col2 FROM test_tbl2;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    1 |    1 |
  |    2 |    2 |
  |    4 |    4 |
  |    3 |    3 |
  |    5 |    5 |
  +------+------+
  5 rows in set (0.021 sec)
  ```

* テーブル `test_tbl1` と `test_tbl2` から列 `col1` と `col2` のデータを選択し、2つのテーブルの共通部分、つまり `test_tbl1` と `test_tbl2` の `col1` と `col2` 列のデータで重複する部分を返します。

  ```sql
  SELECT col1, col2 FROM test_tbl1
  INTERSECT
  SELECT col1, col2 FROM test_tbl2;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    2 |    2 |
  +------+------+
  1 row in set (0.013 sec)
  ```

* テーブル `test_tbl1` から列 `col1` と `col2` のデータを選択し、テーブル `test_tbl2` の同じ `col1` と `col2` 列のデータを除外します。つまり、`test_tbl1` にはあるが `test_tbl2` にはないデータ行を返します。

  ```sql
  SELECT col1, col2 FROM test_tbl1
  EXCEPT
  SELECT col1, col2 FROM test_tbl2;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    1 |    1 |
  |    4 |    4 |
  +------+------+
  2 rows in set (0.011 sec)
  ```

* テーブル `test_tbl1` と `test_tbl2` から列 `col1` と `col2` のデータを取得し、それらを結合します。その後、結合した結果を `col1` の降順でソートし、上位3件の結果のみを返します。

  ```sql
  SELECT col1, col2 FROM test_tbl1
  UNION
  SELECT col1, col2 FROM test_tbl2
  ORDER BY col1 DESC
  LIMIT 3;
  ```

  実行結果は次のとおりです：

  ```shell
  +------+------+
  | col1 | col2 |
  +------+------+
  |    5 |    5 |
  |    4 |    4 |
  |    3 |    3 |
  +------+------+
  3 rows in set (0.012 sec)
  ```
