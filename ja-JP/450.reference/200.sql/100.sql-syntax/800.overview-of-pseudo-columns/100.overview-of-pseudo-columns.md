# 仮想列の概要

仮想列（Pseudocolumn）は、テーブルの列と同じように動作しますが、具体的な値は格納されません。そのため、仮想列には読み取り専用の属性しかなく、挿入、更新、削除などの操作はできません。この章では、seekdbの現在のバージョンでサポートされている仮想列とその使用方法について説明します。

seekdbの現在のバージョンでサポートされている仮想列タイプは以下のとおりです：

* [PARTITIONID 仮想列](200.partititionid-pseudo-column.md)
* [シーケンス仮想列](300.sequence-pseudo-column.md)
