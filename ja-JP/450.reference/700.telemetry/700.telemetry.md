# テレメトリー

seekdbはテレメトリー機能を組み込んでおり、デフォルトで有効になっています。これは、製品の使用状況に関する匿名情報を収集するために使用されます。この情報により、ユーザーのseekdbの利用方法を理解し、一般的な質問を特定し、製品機能とユーザーエクスペリエンスを継続的に改善することができます。

## プライバシー保護

テレメトリー機能は、IPアドレスなどの機密情報をマスキング（ハッシュ処理）し、必要な技術指標のみを収集します。業務データやユーザーのプライバシー情報は一切収集しません。

## テレメトリー機能の管理

環境変数 `TELEMETRY_ENABLED` を使用して、テレメトリー機能の有効・無効を切り替えることができます。

テレメトリー機能を無効にする：

```bash
export TELEMETRY_ENABLED=false
```

テレメトリー機能を無効にした後、再び有効にする：

```bash
export TELEMETRY_ENABLED=true
```

:::tip
テレメトリー機能はデフォルトで有効になっており、この環境変数を手動で設定する必要はありません。無効にする必要がある場合にのみ、falseに設定してください。
:::

## テレメトリー機能が収集する情報

テレメトリー機能は、以下の匿名化された技術情報を収集します：

* バージョンとデプロイメント情報：seekdbのバージョン、デプロイメント方法。

* ホスト環境情報：OSのバージョン、CPU型番/コア数、メモリ容量。

* リソース仕様情報：seekdbに割り当てられたメモリ、データディスク、ログディスクの容量など。

## 収集情報の確認

テレメトリーデータはローカルにコピーが保存されます。デプロイメントディレクトリ配下の `run/telemetry.json` ファイルで、seekdbが収集した具体的な情報内容を確認できます。
