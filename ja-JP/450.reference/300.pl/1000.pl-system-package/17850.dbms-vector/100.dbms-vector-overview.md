# DBMS_VECTORの概要

`DBMS_VECTOR` システムパッケージは、ベクトルインデックスを管理するために使用されます。

## DBMS_VECTORサブプログラムの概要

次の表は、seekdbがサポートする`DBMS_VECTOR`サブプログラムとその簡潔な説明です。

| **サブプログラム** | **説明** |
| --- | --- |
| [REFRESH_INDEX](200.refresh-index.md) | ベクトルインデックスをリフレッシュします。 |
| [REBUILD_INDEX](300.rebuild-index.md) | ベクトルインデックスを再構築します。 |
| [INDEX_VECTOR_MEMORY_ESTIMATE](400.index-vector-memory-estimate.md) | ベクトルインデックスのメモリ使用状況を見積もります。 |
| [INDEX_VECTOR_MEMORY_ADVISOR](500.index-vector-memory-advisor.md) | ベクトルインデックスのメモリ使用状況を分析します。 |
