# ENABLE_RULE

`ENABLE_RULE` プロシージャは、カスタムリライトルールを有効にし、それらのルールを適用するために使用されます。

## 構文

```sql
PROCEDURE ENABLE_RULE (
    rule_name          VARCHAR(256));
```

## パラメータ説明

| パラメータ | 説明 |
| --- | --- |
| rule_name | ルール名。 |

## 例

```shell
CALL DBMS_UDR.ENABLE_RULE('rule1');
Query OK, 0 rows affected

SELECT 1 FROM DUAL;
+-------+
| ? + 1 |
+-------+
|     2 |
+-------+
1 row in set
```
