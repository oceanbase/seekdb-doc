# MANAGE_DYNAMIC_PARTITION

`MANAGE_DYNAMIC_PARTITION`は、動的パーティション管理タスクを1回実行し、動的パーティションテーブルの将来のパーティションを事前作成し、期限切れのパーティションを削除します。

## 構文

```sql
DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION (
    precreate_time VARCHAR(64) DEFAULT NULL,
    time_unit VARCHAR(64) DEFAULT NULL);
```

## パラメータ説明

|      パラメータ      |   説明     |
|----------------|-----------|
| precreate_time | オプション値。`n {hour \| day \| week \| month \| year}`。<ul><li>デフォルト値は `null` で、事前作成時間を別途指定しないことを意味します。</li><li>明示的に指定された場合、動的パーティションテーブルのパーティションを事前作成する際に、指定された `precreate_time` とテーブル上の `precreate_time` のうち大きい方の値を事前作成時間として使用します。</li></ul>|
| time_unit      | オプション値。`null \| hour \| day \| week \| month \| year`。<ul><li>デフォルト値は `null` で、すべての動的パーティションテーブルに対して動的パーティション管理タスクを実行することを意味します。</li><li>値が `hour` の場合、`time_unit` が `hour` のテーブルに対してのみ動的パーティション管理タスクを実行します。</li><li>値が `day` の場合、`time_unit` が `day` のテーブルに対してのみ動的パーティション管理タスクを実行します。</li><li>値が `week` の場合、`time_unit` が `week` のテーブルに対してのみ動的パーティション管理タスクを実行します。</li><li>値が `month` の場合、`time_unit` が `month` のテーブルに対してのみ動的パーティション管理タスクを実行します。</li><li>値が `year` の場合、`time_unit` が `year` のテーブルに対してのみ動的パーティション管理タスクを実行します。</li></ul>|

## 例

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION();
```

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION('3DAY');
```

```sql
CALL DBMS_PARTITION.MANAGE_DYNAMIC_PARTITION('3DAY', 'HOUR');
```
