# DBMS_PARTITIONの概要

`DBMS_PARTITION` システムパッケージは、動的パーティション管理インターフェースを提供します。

## サブプログラムの概要

次の表は、seekdbがサポートする `DBMS_PARTITION` サブプログラムとその簡潔な説明です。

|                                   サブプログラム                                 |           説明          |
|--------------------------------------------------------------------------|------------------------|
| [MANAGE_DYNAMIC_PARTITION](200.manage_dynamic_partition.md)| 動的パーティション管理タスクを1回実行し、動的パーティションテーブルの将来のパーティションを事前作成し、期限切れのパーティションを削除します。|
