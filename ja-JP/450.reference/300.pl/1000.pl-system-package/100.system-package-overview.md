# システムパッケージの概要

seekdbはPLシステムパッケージをサポートしており、データベース機能を拡張し、SQL機能へのPLアクセスを提供します。

アプリケーションの作成時や独自のストアドプロシージャの作成時に、提供されているシステムパッケージを使用できます。このマニュアルでは、seekdbがサポートするシステムパッケージについて説明します。

システムパッケージは、データベース内に格納された関連するプログラムオブジェクトのカプセル化された集合です。プログラムオブジェクトには、ストアドプロシージャ、関数、変数、定数、カーソル、例外が含まれます。

対応する権限がある場合、`oceanbase` スキーマで以下のステートメントを実行して、現在サポートされているシステムパッケージとその関連情報を照会できます：

```sql
USE oceanbase;
SELECT * FROM __all_package;
```

## PLシステムパッケージの構成

PLシステムパッケージは、パッケージヘッダー（`SPECIFICATION`）とパッケージボディ（`BODY`）の2つの部分で構成されています。パッケージヘッダーはアプリケーションのインターフェースであり、アプリケーションから参照可能な公開宣言を含みます。これには、使用可能な型、変数、定数、例外、カーソル、サブプログラムが宣言されています。パッケージボディには実装の詳細とアプリケーションから隠蔽されたプライベート宣言が含まれ、パッケージヘッダーの実装をサポートするためにカーソルとサブプログラムを完全に定義しています。

  :::info

  seekdbはユーザーによるシステムパッケージの変更をサポートしていません。

  :::

## PLシステムパッケージの使用

データベース作成時に、seekdbが提供するシステムパッケージが自動的にインストールされます。

## PLシステムパッケージの概要

次の表は、seekdbがサポートするPLシステムパッケージとその簡潔な説明を示しています。

|                      システムパッケージ                      |            説明                    |
|-------------------------------------------------|------------------------------------|
| [DBMS_RESOURCE_MANAGER](13300.dbms-resource-manager/100.dbms-resource-manager-overview.md)| リソース使用計画、リソース使用グループ、およびリソース計画の指示を管理するために使用されます。|
| [DBMS_STATS](15900.dbms-stats/100.dbms-stats-overview.md)        | オプティマイザーがデータベースオブジェクトに収集した統計情報を表示および変更します。                        |
| [DBMS_UDR](17800.dbms-udr/100.dbms-udr-overview.md)| 書き換えバインディング機能を提供し、SQL実行開始前にマッチングルールに基づいてデータベースが受信したSQL文を書き換えることができます。|
| [DBMS_VECTOR](17850.dbms-vector/100.dbms-vector-overview.md)|ベクトルインデックスを管理するために使用されます。|
| [DBMS_WORKLOAD_REPOSITORY](17900.dbms-workload-repository/100.dbms-workload-repository-overview.md)|  自動ワークロードリポジトリ(WR)を管理するために使用されます。 |
| [DBMS_MVIEW](9950.dbms-mview/100.dbms-mview-overview.md)  | 呼び出し元がマテリアライズドビューおよび潜在的マテリアライズドビューの機能を理解できるようにします。これには、クエリの書き換え可用性も含まれます。また、同じリフレッシュグループに属さないマテリアライズドビューをリフレッシュし、ログをクリアすることもできます。    |
| [DBMS_MVIEW_STAT](10050.dbms-mview-stat/100.dbms-mview-stat-overview.md)  | 呼び出し元がインターフェースを使用してマテリアライズドビューのリフレッシュ操作に関する統計情報の収集と保持を管理できるようにします。    |
| [DBMS_PARTITION](13200.dbms_partition/100.dbms_partition-overview.md)| 動的パーティション管理インターフェースを提供するために使用されます。|
