# DBMS_MVIEWの概要

`DBMS_MVIEW` システムパッケージは、マテリアライズドビューをリフレッシュし、マテリアライズドビューのログをクリアするために使用されます。

## DBMS_MVIEWサブプログラムの概要

次の表は、seekdbがサポートする`DBMS_MVIEW`サブプログラムとその簡潔な説明を示しています。

| サブプログラム     | 説明                                      |
| --------- | ----------------------------------------- |
| [PURGE_LOG](200.purge-log.md)	| マテリアライズドビューのログを削除するために使用します。マテリアライズドビューのログを削除すると、そのテーブルに関連するすべてのログレコードが削除されます。  |
| [REFRESH](300.refresh.md)	    | 指定した1つまたは複数のマテリアライズドビューを更新します。                   |
