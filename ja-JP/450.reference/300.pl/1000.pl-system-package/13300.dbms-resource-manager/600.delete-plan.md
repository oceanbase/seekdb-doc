# DELETE_PLAN

`DELETE_PLAN` プロシージャは、指定されたプランおよびそのプランが参照するすべてのプラン指示を削除するために使用されます。

## 構文

```sql
DBMS_RESOURCE_MANAGER.DELETE_PLAN (
    plan IN VARCHAR2);
```

## パラメータ説明

`plan` は、削除するリソースプランの名前を指定します。

## 例

```sql
CALL DBMS_RESOURCE_MANAGER.DELETE_PLAN('NIGHT');
Query OK, 0 rows affected
```
