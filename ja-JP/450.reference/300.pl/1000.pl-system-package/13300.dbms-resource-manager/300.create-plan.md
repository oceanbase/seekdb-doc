# CREATE_PLAN

`CREATE_PLAN` プロシージャは、リソースプランを作成するために使用されます。

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_PLAN (
    plan          IN   VARCHAR2,
    comment       IN   VARCHAR2 DEFAULT'');
```

## パラメータ説明

|   パラメータ    |    説明    |
|---------|----------|
| plan    | リソース計画の名前。 |
| comment | ユーザーコメント。    |

## 例

```sql
CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('DAY','このリソースプランはトランザクション処理に使用されます');
Query OK, 0 rows affected

CALL DBMS_RESOURCE_MANAGER.CREATE_PLAN('NIGHT','このリソースプランは日常的な運用保守に使用されます');
Query OK, 0 rows affected
```
