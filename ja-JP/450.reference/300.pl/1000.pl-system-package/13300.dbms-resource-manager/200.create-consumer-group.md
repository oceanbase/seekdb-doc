# CREATE_CONSUMER_GROUP

`CREATE_CONSUMER_GROUP` プロシージャは、リソースユーザーグループを定義するために使用されます。

## 構文

```sql
DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP (
    consumer_group  IN VARCHAR2,
    comment         IN VARCHAR2 DEFAULT NULL);
```

## パラメータ説明

|       パラメータ      |    説明     |
|----------------|-----------|
| consumer_group | リソースユーザーグループの名前。 |
| comment        | ユーザーコメント。     |

## 例

```sql
CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group1','トランザクション処理グループ');
Query OK, 0 rows affected

CALL DBMS_RESOURCE_MANAGER.CREATE_CONSUMER_GROUP('group2','日常運用保守グループ');
Query OK, 0 rows affected
```
