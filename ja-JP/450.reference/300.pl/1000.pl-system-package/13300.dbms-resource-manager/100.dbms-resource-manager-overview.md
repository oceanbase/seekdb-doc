# DBMS_RESOURCE_MANAGERの概要

`DBMS_RESOURCE_MANAGER` システムパッケージは、リソース使用計画、リソース使用グループ、およびリソース計画の指示を管理するために使用されます。

## 権限の説明

コーラーは `DBMS_RESOURCE_MANAGER` システムパッケージ内のプロシージャを実行するために `ADMINISTER_RESOURCE_MANAGER` システム権限を持っている必要があります。

## サブプログラムの概要

次の表は、seekdbがサポートする `DBMS_RESOURCE_MANAGER` サブプログラムとその簡潔な説明を示しています。

|                                   サブプログラム                                 |           説明           |
|--------------------------------------------------------------------------|------------------------|
| [CREATE_CONSUMER_GROUP](../13300.dbms-resource-manager/200.create-consumer-group.md)      | リソース使用グループを作成します。             |
| [CREATE_PLAN](../13300.dbms-resource-manager/300.create-plan.md)                | リソース計画を作成します。                |
| [CREATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager/400.create-plan-directive.md)      | リソース計画指示を作成します。              |
| [DELETE_CONSUMER_GROUP](../13300.dbms-resource-manager/500.delete-consume-group.md)      | リソース使用グループを削除します。               |
| [DELETE_PLAN](../13300.dbms-resource-manager/600.delete-plan.md)                | 指定された計画およびそれが参照するすべての計画指示を削除します。  |
| [DELETE_PLAN_DIRECTIVE](../13300.dbms-resource-manager/700.delete-plan-directive.md)      | リソース計画指示を削除します。              |
| [SET_CONSUMER_GROUP_MAPPING](../13300.dbms-resource-manager/800.set-consumer-group-mappingn-directive.md) | ログイン時および実行時のプロパティマッピングのエントリを追加、削除、または変更します。 |
| [UPDATE_PLAN_DIRECTIVE](../13300.dbms-resource-manager/900.update-plan-directive.md)      | リソース計画指示を更新します。              |
