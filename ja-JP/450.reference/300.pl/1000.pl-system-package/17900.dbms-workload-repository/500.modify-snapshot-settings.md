# MODIFY_SNAPSHOT_SETTINGS

`MODIFY_SNAPSHOT_SETTINGS` プロシージャは、WORKLOAD_REPOSITORY設定を変更するために使用されます。

## 構文

```sql
DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS(
   retention          INT    DEFAULT  NULL,
   interval           INT    DEFAULT  NULL);
```

## パラメータ説明

| **パラメータ** | **説明** |
| --- | --- |
| retention | スナップショットの保持時間です。この時間を超えるスナップショットは自動的に削除されます。単位は分です。[1440分（1日）、52560000分（100年）] の範囲です。<ul><li>値を0に設定すると、永続的に保持されます。保持時間は57816000分（110年）に設定されます。  </li><li>NULLを指定した場合、元の保持時間が維持されます。 </li></ul>|
| interval | 各スナップショット間の間隔を設定します。単位は分です。[10分、525600分（1年）] の範囲です。<ul><li>値を0に設定すると、自動および手動スナップショットが無効になり、保持時間としてより大きなシステム定義値（110年）が使用されます。</li><li>NULLを指定した場合、現在の間隔設定が維持されます。</li></ul>|

## 例

```shell
CALL DBMS_WORKLOAD_REPOSITORY.MODIFY_SNAPSHOT_SETTINGS('2265','16');
Query OK, 0 rows affected
```
