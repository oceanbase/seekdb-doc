# CREATE_SNAPSHOT

`CREATE_SNAPSHOT` プロシージャは、クラスタのスナップショット生成をトリガーするために使用されます。

## 構文

```sql
DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT(
    flush_level  VARCHAR(64) DEFAULT 'TYPICAL'
);
```

## パラメータ説明

| **パラメータ** | **説明** |
| --- | --- |
| flush_level | スナップショットタイプを指定します。現在、主に統計データを収集するために使用される定期スナップショットTYPICALのみがサポートされています。 |

## 使用方法

ユーザーが手動でスナップショットを作成すると、タイマーは再設定されます。例えば、デフォルトの間隔が1時間の場合：

```shell
12:21 タイマーが発生し、スナップショットを作成
13:21 タイマーが発生し、次のスナップショットを作成
13:45 ユーザーが手動でスナップショットを作成
14:45 タイマーが発生し、次のスナップショットを作成
```

## 例

```shell
CALL DBMS_WORKLOAD_REPOSITORY.CREATE_SNAPSHOT(flush_level => 'TYPICAL');
Query OK, 0 rows affected
```
