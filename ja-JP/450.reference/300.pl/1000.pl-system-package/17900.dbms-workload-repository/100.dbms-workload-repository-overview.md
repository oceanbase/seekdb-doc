# DBMS_WORKLOAD_REPOSITORYの概要

`DBMS_WORKLOAD_REPOSITORY` システムパッケージは、自動ワークロードリポジトリ（Workload Repository、WR）を管理するために使用されます。

## DBMS_WORKLOAD_REPOSITORY権限の説明

すべての `DBMS_WORKLOAD_REPOSITORY` システムパッケージのサブプログラムでは、ユーザーが `EXECUTE` 権限を持っている必要があります。

## DBMS_WORKLOAD_REPOSITORYサブプログラムの概要

次の表は、seekdbがサポートする `DBMS_WORKLOAD_REPOSITORY` サブプログラムとその簡潔な説明を示しています。

| **サブプログラム** | **説明** |
| --- | --- |
| [ASH_REPORT](200.ash-report.md) | ASHレポートをテキスト形式で表示します。 |
| [CREATE_SNAPSHOT](300.create-snapshot.md) | スナップショットの生成をトリガーします。 |
| [DROP_SNAPSHOT_RANGE](400.drop-snapshot-range.md) | 指定範囲内のスナップショットを削除します。 |
| [MODIFY_SNAPSHOT_SETTINGS](500.modify-snapshot-settings.md) | WORKLOAD_REPOSITORY設定を変更します。 |
