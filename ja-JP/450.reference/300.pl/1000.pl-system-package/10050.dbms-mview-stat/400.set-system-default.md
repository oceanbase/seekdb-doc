# SET_SYSTEM_DEFAULT

`SET_SYSTEM_DEFAULT`は、統計パラメータのリフレッシュに関するシステムのデフォルト値を設定します。

## 構文

```sql
PROCEDURE set_system_default(
    IN     parameter_name         VARCHAR(65535),
    IN     value                  VARCHAR(65535));
```

## パラメータの説明

| **パラメータ**         | **説明**                                                                                         |
|------------------|--------------------------------------------------------------------------------------------------|
| parameter_name   | パラメータ名。以下の2種類に設定できます：<ul><li>COLLECTION_LEVEL：統計情報収集レベル。システムのデフォルトはTYPICALです。</li><li>RETENTION_PERIOD：統計情報の保持日数。システムのデフォルトは31日です。</li></ul> |
| value | <p>parameter_nameがCOLLECTION_LEVELの場合：<ul><li>NONE：統計情報を収集しません。</li><li>TYPICAL：基本的なリフレッシュ統計情報を収集します。</li><li>ADVANCED：詳細なリフレッシュ統計情報を収集します。</li><li>NULL：システムのデフォルト値、すなわちTYPICALを使用します。</li></ul></p> <p>parameter_nameがRETENTION_PERIODの場合、パラメータ値は統計情報の保持日数です：1～365000。<ul><li>NULL：システムのデフォルト値を使用します。</li><li>-1：統計情報を永久に保持します。</li></ul> </p>|
