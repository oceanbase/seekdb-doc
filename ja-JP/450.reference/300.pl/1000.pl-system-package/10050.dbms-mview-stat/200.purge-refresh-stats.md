# PURGE_REFRESH_STATS

`PURGE_REFRESH_STATS`は、指定された保持期間を超えたマテリアライズドビューの更新統計データを強制的に自動削除するために使用します。

## 構文

```sql
PROCEDURE purge_refresh_stats(
    IN     mv_name                VARCHAR(65535),
    IN     retention_period       INT);
```

## パラメータ説明

| **パラメータ**           | **説明**                                            |
|------------------|-----------------------------------------------------|
| mv_name          | マテリアライズドビューの名前。<ul><li>値がNULLの場合、すべてのマテリアライズドビューに対して操作を実行します。</li></ul> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定された日数を超えると統計レコードは自動的に削除されます。システムのデフォルトは31日です。<ul><li>値がNULLの場合、自動統計情報クリーンアップメカニズムのデフォルトのクリーニングポリシーを採用します。</li><li>-1に設定した場合、すべての関連する統計情報レコードを削除します。</li></ul> |
