# SET_MVREF_STATS_PARAMS

`SET_MVREF_STATS_PARAMS`は、マテリアライズドビューの統計情報更新に関する収集レベルとデータ保持期間を設定します。

## 構文

```sql
PROCEDURE set_mvref_stats_params(
    IN     mv_name                VARCHAR(65535),
    IN     collection_level       VARCHAR(65535)     DEFAULT NULL,
    IN     retention_period       INT                DEFAULT NULL);
```

## パラメータ説明

| **パラメータ**           | **説明**                                                                                                                                          |
|------------------|---------------------------------------------------------------------------------------------------------------------------------------------------|
| mv_name         | マテリアライズドビューの名前。<ul><li>NULLの場合、すべてのマテリアライズドビューに対して操作を実行します。</li></ul>                                              |
| collection_level | 統計情報の収集レベルです。システムのデフォルトはTYPICALです。オプションは以下のとおりです：<ul><li>NONE：統計情報を収集しません。</li><li>TYPICAL：基本的な更新統計情報を収集します。</li><li>ADVANCED：詳細な更新統計情報を収集します。</li><li>NULL：システムのデフォルト値であるTYPICALを使用します。</li></ul> |
| retention_period | 統計情報の保持日数を指定します。値の範囲は1日から365,000日です。設定された日数を超えると統計レコードは自動的に削除されます。システムのデフォルトは31日です。<ul><li>NULLの場合、システムのデフォルト設定が適用されます。</li><li>-1に設定した場合、統計情報は永久に保持されます。</li></ul>                               |
