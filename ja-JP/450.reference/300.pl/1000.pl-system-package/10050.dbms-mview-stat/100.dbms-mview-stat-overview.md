# DBMS_MVIEW_STATSの概要

`DBMS_MVIEW_STATS` システムパッケージは、マテリアライズドビューのリフレッシュ操作に関する統計情報の収集と保持を管理するためのインターフェースをユーザーに提供します。

## DBMS_MVIEW_STATSサブプログラムの概要

次の表は、seekdbがサポートする `DBMS_MVIEW_STATS` サブプログラムとその簡潔な説明を示しています。

| サブプログラム                   | 説明                  |
| ----------------------- | --------------------- |
| [PURGE_REFRESH_STATS](200.purge-refresh-stats.md) |指定された保持期間を超えたマテリアライズドビューの更新統計データを強制的に自動削除するために使用されます。   |
| [SET_MVREF_STATS_PARAMS](300.set-mvref-stats-params.md) |マテリアライズドビューの更新統計情報収集レベルとデータ保持期間を設定するパラメータです。|
| [SET_SYSTEM_DEFAULT](400.set-system-default.md)  |更新統計パラメータのシステムデフォルト値を設定します。|
