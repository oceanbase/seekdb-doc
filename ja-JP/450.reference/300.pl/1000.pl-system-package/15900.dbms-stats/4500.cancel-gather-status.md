# CANCEL_GATHER_STATS

`CANCEL_GATHER_STATS`は、統計情報収集コマンドをキャンセルするために使用します。

## 構文

```sql
DBMS_STATS.cancel_gather_stats (
      taskid         VARCHAR2
    );
```

## パラメータの説明

|    パラメータ    |        説明         |
|----------|-----------------------|
|taskid|収集中のタスクIDを表します。<main id="notice" type='explain'><h4>説明</h4><p><code>taskid</code>は、<code>GV$OB_OPT_STAT_GATHER_MONITOR</code>ビューを照会することで取得できます。このビューの詳細については、<a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015081">GV\$OB_OPT_STAT_GATHER_MONITOR</a>を参照してください。</p></main>|

## 例

```sql
CALL DBMS_STATS.CANCEL_GATHER_STATS(taskid);
```

  :::info

  ここで、`taskid`は実際の値に置き換える必要があります。

  :::
