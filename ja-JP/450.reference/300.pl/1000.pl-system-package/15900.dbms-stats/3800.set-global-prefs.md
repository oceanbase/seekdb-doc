# SET_GLOBAL_PREFS

`SET_GLOBAL_PREFS` プロシージャは、グローバル統計のPreferencesを設定します。

## 構文

```sql
DBMS_STATS.SET_GLOBAL_PREFS (
  pname     IN   VARCHAR2,
  pvalue    IN   VARCHAR2);
```

## パラメータ説明

|   パラメータ   |     説明     |
|--------|------------|
| pname  | Prefsの名前。 |
| pvalue | Prefsの値。  |

## 例外状況

|    エラーコード    |     説明      |
|-----------|-------------|
| HY000     |  <ul><li>権限が不足しています。</li><li>無効な値または不正な入力値。</li></ul>     |

## 使用方法

* このプロシージャの2つのパラメータはどちらも `VARCHAR2` 型であり、その値は引用符で囲む必要があります。

## 例

グローバルレベルの `APPROXIMATE_NDV` のデフォルト値を `FALSE` に設定します。

```sql
CALL DBMS_STATS.SET_GLOBAL_PREFS ('APPROXIMATE_NDV', 'FALSE');
Query OK, 0 rows affected
```
