# ALTER_STATS_HISTORY_RETENTION

`ALTER_STATS_HISTORY_RETENTION` プロシージャは、履歴統計情報の保持間隔時間を変更するために使用されます。デフォルトの保持間隔時間は31日です。

## 構文

```sql
DBMS_STATS.ALTER_STATS_HISTORY_RETENTION (
    retention       IN     NUMBER);
```

## パラメータ説明

`retention` パラメータは、統計履歴記録の保持時間（日単位）を指定します。

## 例外状況

エラーコード `HY000` は権限不足を表します。

## 例

履歴統計情報の保持間隔時間を15日に変更します。

```sql
CALL DBMS_STATS.ALTER_STATS_HISTORY_RETENTION(15);
Query OK, 0 rows affected
```
