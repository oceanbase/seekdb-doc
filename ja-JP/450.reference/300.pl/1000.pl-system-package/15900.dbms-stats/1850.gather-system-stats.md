# GATHER_SYSTEM_STATS

`GATHER_SYSTEM_STATS` プロシージャは、システム統計情報を収集するために使用されます。

## 構文

```sql
DBMS_STATS.GATHER_SYSTEM_STATS();
```

## 例外

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000    | 入力されたシステム統計情報名が誤っています。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続している必要があります。

## 例

`DBMS_STATS.GATHER_SYSTEM_STATS` プロシージャを実行して、CPU速度、ディスクI/Oパフォーマンス、ネットワークスループットなどのシステム統計情報を収集します。

```sql
BEGIN
    -- システム統計情報を収集する
    DBMS_STATS.GATHER_SYSTEM_STATS();
END;
/
```
