# DELETE_SCHEMA_PREFS

`DELETE_SCHEMA_PREFS` プロシージャは、指定されたスキーマのすべてのテーブルの統計情報の優先順位を削除するために使用されます。

## 構文

```sql
DBMS_STATS.DELETE_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2);
```

## パラメータ説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | スキーマ名。 |
| pname   | Prefsの名前。 |

## 例外状況

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000     | スキーマが存在しないか、権限が不足しているか、無効な値または不正な入力値です。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとしてデータベースに接続している必要があります。

* このプロシージャのパラメータはすべて `VARCHAR2` 型であり、その値は引用符で囲む必要があります。

## 例

`hr` スキーマの優先順位 `DEGREE` を削除します。

```sql
CALL DBMS_STATS.DELETE_SCHEMA_PREFS('hr', 'DEGREE');
Query OK, 0 rows affected
```
