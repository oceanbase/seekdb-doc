# GET_PARAM

`GET_PARAM` 関数は、`DBMS_STATS` システムパッケージのプロシージャにおけるパラメータのデフォルト値を取得するために使用されます。

## 構文

```sql
DBMS_STATS.GET_PARAM (
   pname     IN   VARCHAR2)
 RETURN VARCHAR2;
```

## パラメータ説明

`pname` パラメータは、デフォルト値を取得するパラメータ名を指定します。

## 例外

エラーコード `HY000` は、無効な入力値を表します。

## 例

パラメータ `METHOD_OPT` のデフォルト値を取得します。

```sql
SELECT DBMS_STATS.GET_PARAM ('METHOD_OPT') FROM DUAL;
+-------------------------------------+
| DBMS_STATS.GET_PARAM ('METHOD_OPT') |
+-------------------------------------+
| FOR ALL COLUMNS SIZE AUTO           |
+-------------------------------------+
1 row in set
```
