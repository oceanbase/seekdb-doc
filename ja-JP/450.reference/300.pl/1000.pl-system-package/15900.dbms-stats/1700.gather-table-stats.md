# GATHER_TABLE_STATS

`GATHER_TABLE_STATS` プロシージャは、テーブルと列の統計情報を収集するために使用されます。

## 構文

```sql
DBMS_STATS.GATHER_TABLE_STATS (
  ownname             VARCHAR2,
  tabname             VARCHAR2,
  partname            VARCHAR2 DEFAULT NULL,
  estimate_percent    NUMBER DEFAULT AUTO_SAMPLE_SIZE,
  block_sample        BOOLEAN  DEFAULT FALSE,
  method_opt          VARCHAR2 DEFAULT DEFAULT_METHOD_OPT,
  degree              NUMBER   DEFAULT to_degree_type(get_param('DEGREE')),
  granularity         VARCHAR2 DEFAULT DEFAULT_GRANULARITY,
  cascade             BOOLEAN DEFAULT NULL,
  no_invalidate       BOOLEAN DEFAULT FALSE,
  stattype            VARCHAR2 DEFAULT 'DATA',
  force               BOOLEAN DEFAULT FALSE,
  hist_est_percent    NUMBER DEFAULT AUTO_SAMPLE_SIZE,
  hist_block_sample   BOOLEAN DEFAULT NULL
  );
```

## パラメータ説明

|        パラメータ       |      説明        |
|------------------|-------------------|
| ownname          | 分析対象のテーブルが存在するスキーマ。   |
| tabname          | テーブル名。       |
| partname         | パーティション名。       |
| estimate_percent | 行数の推定値の割合。\[0.000001,100\]の範囲で有効です。   |
| block_sample     | データベースがランダムブロックサンプリング(`TRUE`)を使用するか、ランダム行サンプリング(`FALSE`)を使用するかを指定します。デフォルト値は`FALSE`です。ランダムブロックサンプリングの方が効率的ですが、データがディスク上にランダムに分散していない場合、サンプル値に相関が生じる可能性があります。   |
| method_opt       | グローバル、スキーマ、データベース、またはディクショナリレベルで設定オプションを指定する場合、`FOR ALL`構文のみを使用できます。その他の場合、`method_opt`は以下のオプションのいずれか、またはその組み合わせのみとなります： <ul><li> `FOR ALL [INDEXED \| HIDDEN] COLUMNS [size_clause]`   </li>   <li> `FOR COLUMNS [column_clause]`    ここで、`size_clause`は`sizcehenz := SIZE {integer \| REPEAT \| AUTO \| SKEWONLY}`と定義されます。`column_clause`は`column_clause := column_name \| extension name \| extension`と定義されます。 </li>   <li> `integer`：ヒストグラムのバケット数。\[1,2048\]の範囲で有効です。   </li>   <li> `REPEAT`：既存のヒストグラムを持つ列についてのみヒストグラムを収集します。   </li>   <li> `AUTO`：SEEKDBオプティマイザーが列の使用状況に基づいて、列のヒストグラムを収集するかどうかを判断します。ヒストグラムのバケット数はデフォルト値の254を使用します。   </li>   <li> `SKEWONLY`：データ分布が不均一な列のヒストグラムのみを収集します。ヒストグラムのバケット数はデフォルト値の254を使用します。  </li>   <li> `column_name`：列名。   </li>   <li> `extension`：`(column_name, colume_name [, ...])`形式の列グループまたは式を指定できます。デフォルト値は`FOR ALL COLUMNS SIZE AUTO`です。</li>   </ul> |
| degree           | パラレル度。デフォルト値は`NULL`です。`NULL`は`CREATE TABLE`または`ALTER TABLE`ステートメントの`DEGREE`句で指定されたテーブルのデフォルト値を使用することを意味します。`DEGREE=>NULL`や`DEGREE=>n`を使用した場合、オブジェクトのサイズがパラレル実行を保証しない場合、`DBMS_STATS`はシリアル実行を使用する可能性があります。       |
| granularity      | 収集する統計情報の粒度（テーブルがパーティション化されている場合にのみ適用されます）。 <ul><li> `ALL`：すべて（サブパーティション、パーティション、グローバル）の統計情報を収集します。</li> <li> `APPROX_GLOBAL AND PARTITION`：`GLOBAL AND PARTITION`と同様ですが、この場合、グローバル統計情報はパーティションレベルの統計情報の合計です。このオプションは、異なる値の数と異なるキーのインデックスの数以外のすべての統計情報を集計します。ただし、統計情報を持つパーティションのみを集計します。`partname`が`NULL`であるか、集計が実行できない場合（例えば、いずれかのパーティションの統計情報が欠けている場合）、グローバル統計情報が収集されます。   </li> <li> `AUTO`：パーティションタイプに応じて粒度を決定します。デフォルト値です。   </li> <li> `DEFAULT`：グローバルおよびパーティションレベルの統計情報を収集します。このオプションは廃止されており、`GLOBAL AND PARTITION`の使用を推奨します。   </li> <li> `GLOBAL`：グローバル統計情報を収集します。   </li> <li> `GLOBAL AND PARTITION`：グローバルおよびパーティションレベルの統計情報を収集します。複合パーティションオブジェクトであっても、サブパーティションレベルの統計情報は収集されません。   </li> <li> `PARTITION`：パーティションレベルの統計情報を収集します。   </li> <li> `SUBPARTITION`：サブパーティションレベルの統計情報を収集します。</li>  </ul>  |
| cascade          | テーブルと列の統計情報に加え、インデックスに関する統計情報も収集します。これは、スキーマ内の各インデックスで `GATHER_INDEX_STATS` プロシージャを実行した場合と同等です。    |
| no_invalidate| 統計情報収集時にPlan Cacheをフラッシュするかどうか。`TRUE` に設定すると、統計情報収集時にPlan Cacheをフラッシュしません。|
| stattype         | 現在の統計情報が格納されている場所。    |
| force            | ロックの状態を無視して強制的に統計情報を収集するかどうか。デフォルトは `FALSE` です。`TRUE` に設定すると、統計情報がロックされていても収集されます。  |
| hist_est_percent | ヒストグラムのサンプリング比率を指定します。|
| hist_block_sample | ヒストグラムのサンプリング方法を指定します。|

## 異常時

|    エラーコード    |     説明     |
|-----------|------------|
| HY000     |  <ul><li>テーブルが存在しないか、権限が不足しています。</li><li>入力値が誤っています。</li></ul>     |

## 使用方法

このプロシージャを呼び出すには、テーブルの所有者である必要があります。

## 例

ユーザー `testUser01` の `tbl1` テーブルの統計情報を収集します。

```sql
CALL DBMS_STATS.GATHER_TABLE_STATS ('testUser01', 'tbl1', method_opt=>'FOR ALL COLUMNS SIZE
   5', granularity=>'ALL', degree=>4, no_invalidate=>FALSE);
Query OK, 0 rows affected
```
