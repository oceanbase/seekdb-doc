# DELETE_TABLE_PREFS

`DELETE_TABLE_PREFS` プロシージャは、指定されたユーザーが所有するテーブルの統計情報の設定を削除します。

## 構文

```sql
DBMS_STATS.DELETE_TABLE_PREFS (
  ownname    IN  VARCHAR2,
  tabname    IN  VARCHAR2,
  pname      IN  VARCHAR2);
```

## パラメータ説明

|   パラメータ    |                説明              |
|---------|-----------------------------------|
| ownname | ユーザー名。ユーザー名を`NULL`に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| tabname | テーブル名。                               |
| pname   | Prefsの名前。                       |

## 例外

|    エラーコード   |     説明     |
|-----------|-------------|
| HY000     | <ul><li>権限不足。</li> <li>無効な値または不正な入力値。</li></ul>  |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとしてデータベースに接続している必要があります。

* プロシージャ内のすべてのパラメータは `VARCHAR2` 型であり、その値は引用符で囲む必要があります。

## 例

`testUser01` ユーザーの `tbl1` テーブルの設定 `DEGREE` を削除します。

```sql
CALL DBMS_STATS.DELETE_TABLE_PREFS('testUser01', 'tbl1', 'DEGREE');
Query OK, 0 rows affected
```
