# DROP_STAT_TABLE

`DROP_STAT_TABLE` プロシージャは、ユーザーの統計テーブルを削除するために使用されます。

## 構文

```sql
DBMS_STATS.DROP_STAT_TABLE (
  ownname VARCHAR2,
  stattab VARCHAR2);
```

## パラメータ説明

|   パラメータ    |                説明                 |
|---------|-----------------------------------|
| ownname | ユーザー名。`NULL`に設定した場合、現在ログインしているユーザー名がデフォルトで使用されます。 |
| stattab | 削除するユーザー統計情報テーブルの名前。                   |

## 例外状況

エラーコード `HY000` は、該当するテーブルが存在しないか、権限が不足していることを示します。

## 使用方法

このプロシージャを呼び出すには、指定されたスキーマ内でそのテーブルを削除する権限が必要です。

## 例

ユーザー `testUser01` の統計情報ユーザーテーブル `test_stat` を削除します。

```sql
CALL DBMS_STATS.DROP_STAT_TABLE('testUser01', 'test_stat');
Query OK, 0 rows affected
```
