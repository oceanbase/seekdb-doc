# SET_SYSTEM_STATS

`SET_SYSTEM_STATS` プロシージャは、システム統計情報を設定するために使用されます。

## 構文

```sql
DBMS_STATS.SET_SYSTEM_STATS (
   pname          VARCHAR2,
   pvalue         NUMBER);
```

## パラメータ説明

|   パラメータ    |     説明     |
|---------|------------|
| pname   | パラメータ名。選択可能な値：`cpu_speed`、`disk_seq_read_speed`、`disk_rnd_read_speed`、`network_speed`。 |
| pvalue  | Prefs値。   |

## 例外状況

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000     | 入力したシステム統計情報名が誤っています。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続している必要があります。

## 例

`DBMS_STATS.SET_SYSTEM_STATS` ストアドプロシージャを使用してシステム統計情報を設定する例です。この例では、パラメータ名 `cpu_speed` のシステム統計パラメータを設定します。`pvalue` を5000に設定します。この値は実際の測定または推定に基づいており、現在のハードウェア環境で1秒間に実行可能なCPUサイクル数を表します。

```sql
BEGIN
    -- CPU速度を5000に設定します。ここでの5000は示唆的な数字であり、ある種の測定単位におけるCPU速度を表します。
    DBMS_STATS.SET_SYSTEM_STATS('cpu_speed', 5000);
END;
/
```

ハードディスクのシーケンシャルリード速度（`disk_seq_read_speed`）などを設定したい場合は、以下のように呼び出すことができます：

```sql
BEGIN
    -- ハードディスクのシーケンシャルリード速度を200に設定します。ここでの200は示唆的な数字であり、ある種の測定単位におけるハードディスク速度を表します。
    DBMS_STATS.SET_SYSTEM_STATS('disk_seq_read_speed', 200);
END;
/
```
