# DELETE_SYSTEM_STATS

`DELETE_SYSTEM_STATS` プロシージャは、システム統計情報を削除するために使用されます。

## 構文

```sql
DBMS_STATS.DELETE_SYSTEM_STATS();
```

## 例外

|    エラーコード    |        説明     |
|-----------|------------------|
| HY000     | 入力されたシステム統計情報名が間違っています。 |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続している必要があります。

## 例

`DBMS_STATS.DELETE_SYSTEM_STATS` ストアドプロシージャを使用してすべてのシステム統計情報を削除するのは非常に簡単です。パラメータは一切必要ないからです。

```sql
BEGIN
    -- すべてのシステム統計情報を削除します
    DBMS_STATS.DELETE_SYSTEM_STATS();
END;
/
```
