# SET_SCHEMA_PREFS

`SET_SCHEMA_PREFS` プロシージャは、指定されたスキーマの統計優先順位を設定します。

## 構文

```sql
DBMS_STATS.SET_SCHEMA_PREFS (
  ownname   IN   VARCHAR2,
  pname     IN   VARCHAR2,
  pvalue    IN   VARCHAR2);
```

## パラメータ説明

|   パラメータ    |     説明     |
|---------|------------|
| ownname | スキーマ名。 |
| pname   | Prefs名。  |
| pvalue  | Prefs値。   |

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| HY000     |  <ul><li>オブジェクトが存在しないか、権限が不足しています。</li><li>無効な値または不正な入力値。</li></ul>     |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続している必要があります。

* プロシージャ内のパラメータはすべて `VARCHAR2` 型であり、その値は引用符で囲む必要があります。

## 例

```sql
CALL DBMS_STATS.SET_SCHEMA_PREFS('hr', 'DEGREE','10');
Query OK, 0 rows affected
```
