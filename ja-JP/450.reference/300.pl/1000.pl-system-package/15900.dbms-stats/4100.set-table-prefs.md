# SET_TABLE_PREFS

`SET_TABLE_PREFS` プロシージャは、指定されたユーザーが所有するテーブルの統計情報の設定を変更します。

## 構文

```sql
DBMS_STATS.SET_TABLE_PREFS (
  ownname    IN  VARCHAR2,
  tabname    IN  VARCHAR2,
  pname      IN  VARCHAR2,
  pvalue     IN  VARCHAR2);
```

## パラメータ説明

|   パラメータ    |                説明                 |
|---------|-----------------------------------|
| ownname | ユーザー名。ユーザー名を`NULL`に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| tabname | テーブル名。                               |
| pname   | Prefsの名前。                        |
| pvalue  | Prefsの値。                         |

## 例外状況

|    エラーコード    |      説明      |
|-----------|--------------|
| HY000     |  <ul><li>オブジェクトが存在しないか、権限が不足しています。</li><li>無効な値または不正な入力値。</li></ul>     |

## 使用方法

* このプロシージャを実行するには、指定されたユーザーとして接続している必要があります。

* プロシージャ内のすべてのパラメータは `VARCHAR2` 型であり、その値は引用符で囲む必要があります。

## 例

ユーザー `testUser01` の `tbl1` の収集戦略の `DEGREE` デフォルト値を128に設定します。

```sql
CALL DBMS_STATS.SET_TABLE_PREFS('testUser01', 'tbl1', 'DEGREE', '128');
Query OK, 0 rows affected
```
