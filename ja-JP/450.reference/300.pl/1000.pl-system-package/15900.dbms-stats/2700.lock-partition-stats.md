# LOCK_PARTITION_STATS

`LOCK_PARTITION_STATS` プロシージャは、パーティションの統計情報をロックするために使用されます。

```sql
DBMS_STATS.LOCK_PARTITION_STATS (
  ownname      VARCHAR2,
  tabname      VARCHAR2,
  partname     VARCHAR2);
```

## パラメータの説明

|    パラメータ    |                説明              |
|----------|-----------------------------------|
| ownname  | ユーザー名。ユーザー名を`NULL`に設定した場合、デフォルトで現在ログインしているユーザー名が使用されます。 |
| tabname  | テーブル名。                              |
| partname | テーブル（サブ）パーティションの名前。                   |

## 使用方法

このプロシージャを呼び出すには、テーブルの所有者でなければなりません。

## 例

ユーザー `testUser01` のテーブル `t1` の `p0` パーティションの統計情報をロックします。

```sql
CALL DBMS_STATS.LOCK_PARTITION_STATS('testUser01', 't1', 'p0');
Query OK, 0 rows affected
```
