# INFORMATION_SCHEMA PARAMETERS

`INFORMATION_SCHEMA PARAMETERS` ディクショナリビューは、ストアドルーチン（ストアドプロシージャとストアド関数）のパラメータおよびストアド関数の戻り値に関する情報を提供しますが、組み込み（ローカル）関数やロード可能な関数は含まれません。

`INFORMATION_SCHEMA PARAMETERS` ディクショナリビューに含まれるフィールドは、次のテーブルのとおりです。

|         **フィールド名**     |         **説明**          |
|--------------------------|---------------------------|
| SPECIFIC_CATALOG         | パラメータを含むルーチンが属するディレクトリの名前。この値は常に `def` です。   |
| SPECIFIC_SCHEMA          | パラメータを含むルーチンが属するスキーマ（データベース）の名前。  |
| SPECIFIC_NAME            | パラメータを含むルーチンの名前。  |
| ORDINAL_POSITION         | ストアドプロシージャまたは関数のパラメータ位置を記録します。`ORDINAL_POSITION` の値は1、2、3などです。ストアド関数については、関数の戻り値に適用される行も必要です。戻り値を記述する行には、以下の特徴があります：<ul><li> `ORDINAL_POSITION` の値は0です。 </li> <li>  `PARAMETER_NAME` と `PARAMETER_MODE` の値は `NULL` です。 </li></ul>   |
| PARAMETER_MODE           | パラメータのモード。この値は `IN`、`OUT`、または `INOUT` です。ストアド関数の戻り値については、この値は `NULL` です。   |
| PARAMETER_NAME           | パラメータの名前。ストアド関数の戻り値については、この値は `NULL` です。   |
| DATA_TYPE                | パラメータのデータ型。`DATA_TYPE` の値は型名のみで、他の情報は含まれません。`DTD_IDENTIFIER` の値にはデータ型名および精度や長さなどのその他の情報が含まれます。  |
| CHARACTER_MAXIMUM_LENGTH | 文字列型パラメータの最大長（文字単位）。   |
| CHARACTER_OCTET_LENGTH   | 文字列型パラメータの最大長（バイト単位）。 |
| NUMERIC_PRECISION        | 数値型パラメータの数値精度。 |
| NUMERIC_SCALE            | 数値型パラメータの数値範囲。  |
| DATETIME_PRECISION       | 日付型パラメータの日付精度。  |
| CHARACTER_SET_NAME       | 文字列型パラメータの文字セット名。  |
| COLLATION_NAME           | 文字列型パラメータの照合規則。  |
| DTD_IDENTIFIER           | データ型の詳細情報を記録します。`DATA_TYPE` の値は型名のみで、他の情報は含まれません。`DTD_IDENTIFIER` の値には型名および精度や長さなどのその他の情報が含まれます。 |
| ROUTINE_TYPE             | ストアドルーチンのタイプ。ストアドプロシージャは `PROCEDURE`、ストアド関数は `FUNCTION` です。  |

例：

```sql
SELECT * FROM INFORMATION_SCHEMA.PARAMETERS
       WHERE SPECIFIC_SCHEMA='test' AND PARAMETER_NAME='c1'\G
*************************** 1. row ***************************
          SPECIFIC_CATALOG: def
           SPECIFIC_SCHEMA: test
             SPECIFIC_NAME: my_func
          ORDINAL_POSITION: 1
            PARAMETER_MODE: IN
            PARAMETER_NAME: c1
                 DATA_TYPE: char
  CHARACTER_MAXIMUM_LENGTH: 20
    CHARACTER_OCTET_LENGTH: 80
         NUMERIC_PRECISION: NULL
             NUMERIC_SCALE: NULL
        DATETIME_PRECISION: NULL
        CHARACTER_SET_NAME: utf8mb4
            COLLATION_NAME: utf8mb4_general_ci
            DTD_IDENTIFIER: char(20)
              ROUTINE_TYPE: FUNCTION
```
