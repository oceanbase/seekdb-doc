# LOOP

`LOOP` 文は、単純なループ文を構築するために使用されます。

```sql
[begin_label:] LOOP
    statement_list
END LOOP [end_label]
```

`LOOP` 文は、`statement_list` の繰り返し実行を許可します。`statement_list` は1つ以上の文で構成され、各文はセミコロン（;）で終わります。ループ内の文は、`LEAVE` でループを終了するまで繰り返し実行されます。ストアドファンクションでは、`RETURN` を使用して関数を完全に終了することもできます。ループ終了文を含めない場合、無限ループが発生します。`label` を使用して `LOOP` 文にラベルを付けることができます。

`LOOP` 文の例：

```sql
DELIMITER //

CREATE PROCEDURE iter_proc(p1 INT)
  BEGIN
    loop_label1: LOOP
      SET p1 = p1 + 10;
      IF p1 < 100 THEN
        ITERATE loop_label1;
      END IF;
      LEAVE loop_label1;
    END LOOP loop_label1;
    SET @x = p1;
  END //
Query OK, 0 rows affected
```
