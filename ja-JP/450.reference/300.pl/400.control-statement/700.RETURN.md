# RETURN

`RETURN` ステートメントはストアドファンクションの実行を終了し、結果を関数呼び出し元に返します。

`RETURN` ステートメントの構文は以下のとおりです：

```sql
RETURN expr
```

ストアドファンクションには少なくとも1つの `RETURN` ステートメントが必要です。関数に複数の終了ポイントがある場合、複数の `RETURN` ステートメントが存在する可能性があります。

ストアドプロシージャやトリガーでは `RETURN` ステートメントは使用せず、`LEAVE` ステートメントを使用してプログラムを終了します。
