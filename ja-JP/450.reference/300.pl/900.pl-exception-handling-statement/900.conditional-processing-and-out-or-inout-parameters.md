# 例外処理とOUT/INOUTパラメータ

例外を処理するシナリオの中には、ストアドプロシージャが `OUT` および `INOUT` パラメータの変更後の値を呼び出し元に返さない場合があります。

ストアドプロシージャが未処理の例外により終了した場合、その `OUT` および `INOUT` パラメータの変更後の値は呼び出し元に返されません。

例外のハンドラーが `RESIGNAL` ステートメントを含む `CONTINUE` または `EXIT` ハンドラーである場合、`RESIGNAL` の実行により診断エリアのスタックがポップアップ表示され、それによって例外シグナル（つまり、ハンドラーに入る前に存在していた情報）が発信されます。例外がエラーに該当する場合、`OUT` および `INOUT` パラメータの値は呼び出し元に返されません。
