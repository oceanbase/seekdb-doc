# DROP FUNCTION

`DROP FUNCTION` ステートメントは、ストアド関数を削除するために使用されます。

`DROP FUNCTION` ステートメントの構文は次のとおりです：

```sql
DROP FUNCTION [IF EXISTS] sp_name
```

ストアドルーチンを削除するには、ユーザーはそのルーチンに対して `ALTER ROUTINE` 権限を持っている必要があります。

ストアド関数が存在しない場合、`IF EXISTS` 句を使用することでエラーを防ぎ、警告を生成できます。この警告は `SHOW WARNINGS` コマンドで確認できます。

`DROP FUNCTION` の例は以下のとおりです：

```sql
DROP FUNCTION IF EXISTS my_func;
Query OK, 0 rows affected
```
