# PL構文

ストアドプログラムの構文は、主に `BEGIN ... END` ブロック、`DECLARE` 文、およびステートメントタグの3つの部分で構成されています。

## BEGIN ... END ブロック

`BEGIN ... END` ブロックは複合文をサポートしており、ストアドプログラム（ストアドプロシージャ、ストアド関数、トリガー）の作成に使用されます。

`BEGIN ... END` の複合文には複数の文を含めることができ、`BEGIN` と `END` キーワードで囲まれます。構文は以下のとおりです：

```sql
[begin_label:] BEGIN
    [statement_list]
END [end_label]
```

ここで、`statement_list` は1つ以上の文のリストを表し、各文はセミコロン（;）で終わります。`statement_list` はオプションなので、空の複合文 `BEGIN END` も有効です。

`BEGIN ... END` ブロックはネスト可能です。`BEGIN ... END` にはラベルを付けることもできます。詳細については、**文のラベル** を参照してください。

PL ストアドプログラムのデフォルトの区切り文字は "/" ですが、ユーザーは `delimiter` コマンドを使用してカスタム区切り文字を設定することができます。これにより、定義全体を単一の文としてサーバーに渡すことができます。区切り文字は1文字または複数の文字で構成できますが、エスケープ文字として一般的に使用されるバックスラッシュ（\\）の使用は避けてください。例：

```sql
DELIMITER $$

DELIMITER //
```

  :::info

  seekdb を使用して開発する場合、通常はカスタム区切り文字を設定する必要があります。PL ブロック内部の定義に `;` で区切られた文が含まれない場合は、区切り文字を使用する必要はありません。

  :::

## DECLARE 文

`DECLARE` 文は、プログラムのローカル変数、例外処理、およびカーソルを定義するために使用されます。詳細については、それぞれ [ストアドプログラムの変数](200.storage-object/200.variables-in-stored-programs.md)、[例外処理](900.pl-exception-handling-statement/100.exception-handling-statement.md)、および[カーソル](300.cursor/100.overview-of-cursors.md)を参照してください。

`DECLARE` は `BEGIN ... END` ブロック内でのみ使用でき、その開始位置、つまり他の文の前に記述する必要があります。

宣言は以下の順序で行う必要があります：

* カーソル宣言は例外処理プログラム宣言の前に記述する必要があります。

* 変数と条件宣言はカーソルまたは例外処理プログラム宣言の前に記述する必要があります。

## 文のラベル

ラベルは `BEGIN ... END` ブロック内の `LOOP`、`REPEAT`、`WHILE` 文で使用できます。構文は以下のとおりです：

```sql
[begin_label:] BEGIN
    [statement_list]
END [end_label]

[begin_label:] LOOP
    statement_list
END LOOP [end_label]

[begin_label:] REPEAT
    statement_list
UNTIL search_condition
END REPEAT [end_label]

[begin_label:] WHILE search_condition DO
    statement_list
END WHILE [end_label]
```

これらの文のラベルは以下のルールに従います：

* `begin_label` の後には必ずコロンを続けて記述する必要があります。

* `begin_label` は `end_label` なしでも記述できます。`end_label` が存在する場合は、`begin_label` と同じでなければなりません。

* `begin_label` がない場合、`end_label` を記述することはできません。

* 同一のネストレベルのラベルは互いに異なっている必要があります。

* ラベルは最大16文字までとします。

既に作成したラベルを参照するには、`ITERATE` または `LEAVE` 文を使用します。以下の例では、ラベルを使用して文を繰り返し続けるか、ループを終了することを示しています：

```sql
DELIMITER //

CREATE PROCEDURE doiterate()
    BEGIN
      DECLARE p1 INT DEFAULT 0;
      label1: LOOP
        SET p1 = p1 + 1;
        IF p1 < 10 THEN ITERATE label1; END IF;
        LEAVE label1;
      END LOOP label1;
    END //
Query OK, 0 rows affected
```

ブロック内の例外処理プログラムの宣言については、[DECLARE ... HANDLER](900.pl-exception-handling-statement/300.declare-handler.md)を参照してください。
