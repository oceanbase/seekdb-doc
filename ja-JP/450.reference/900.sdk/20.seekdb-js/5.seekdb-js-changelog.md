# seekdb-js 更新記録

## seekdb-js V1.1.1

* リリース日：2026年2月9日
* バージョン番号：V1.1.1

### 新機能

* `@seekdb/default-embed` 依存関係のインストール方法を変更し、seekdb-js のデフォルトインストールから手動インストールに変更しました。デフォルトの埋め込み関数を使用する前に、まず `npm install @seekdb/default-embed` を実行してください。詳細は [デフォルト埋め込み関数](60.embedding-funcations-of-seekdb-js/100.default-embedding-function-of-seekdb-js.md) を参照してください。

### バグ修正

* Embedding Function の逆シリアライズ時の Dimension 取得エラーを修正しました。
* Embedding Function の ESM と CJS での互換性問題を修正しました。

## seekdb-js V1.1.0

* リリース日：2026年1月30日
* バージョン番号：V1.1.0

### バージョンの主なポイント

* Collection の命名がより柔軟に：名前の最大長が64文字から **512文字** に延長され、より複雑なビジネスシナリオに対応します。
* 全文検索機能の強化：`FulltextAnalyzerConfig` を新規追加し、カスタム分かち書きとフィールドマッピングをサポートします。
* Embedding エコシステムの大幅な拡張：**11種類** の主流 Embedding プラットフォームを統合し、オープンソースと商用モデルを網羅します。
* メタデータ永続化のアップグレード：embedding 関数情報をシステムテーブルに永続化でき、開発者の利便性をさらに向上させます。
* table-fork 機能の新規追加（実験的機能）：Collection レベルのスナップショットコピーコピーをサポートし、データ実験とロールバックを簡素化します。

### 新機能

#### Collection 名前の長さの拡張

* 制限の緩和：collection 名前が **64～512文字** をサポートし、より長いビジネス命名規則に適応します。
* 互換性：旧バージョンで作成された短い名前の collection は影響を受けません。

#### 全文検索設定（FulltextAnalyzerConfig）

* 設定構造の新規追加：creatCollection/getOrCreateCollection インターフェースで configuration パラメータを渡すことができます。HNSW インデックス設定を指定できるほか、FulltextAnalyzerConfig 全文インデックス設定もカスタマイズできます。
* 公式ドキュメント参照：[全文インデックス設定ガイド](https://www.oceanbase.ai/docs/select-vector-index)

#### Embedding 関数エコシステムの拡張

* 11種類の embedding 関数を統合し、以下のプラットフォームをカバーします：
    * オープンソースモデル：`sentence-transformers`。
    * 商用サービス：OpenAI、Azure、AWS Bedrock など。
    * すべての統合プラットフォームについては、[埋め込み関数の概要](60.embedding-funcations-of-seekdb-js/50.ef-overview-js.md)を参照してください。

#### Table-Fork 機能（実験的機能）

:::tip
seekdb V1.1.0 バージョンでは、Fork Table（Collection のコピー）は実験的機能です。本番環境での使用は慎重に行ってください。今後のバージョンで正式な本番機能へと継続的に改善されます。
:::

* collection スナップショットのクイック作成**；
* 適用シナリオ：
    - A/B テストによる異なるインデックスパラメータの比較
    - データのロールバックと災害復旧
    - その他の適用シナリオについては、[Fork 表](../../../200.develop/200.design-database-schema/50.fork-table.md)を参照してください。
* パフォーマンスへの影響：fork 操作は基盤ストレージの **コピーオンライト（COW）** に基づいており、時間は < 1秒です（データ量に関係ありません）。
