# 演算子

演算子は通常、演算数やパラメータなどの単一のデータ項目を結合して結果を返すために使用されます。構文的には、演算子は演算数の前、演算数の後、または2つの演算数の間に配置することができます。

## 演算子の例

### データフィルタリング（where）

#### 等しい

`$eq` を使用して等しいことを表します。書き方は次のとおりです：

```js
where: { category: { $eq: "AI" } }
```

簡略化された形式も使用できます。書き方は次のとおりです：

```js
where: { category: "AI" }
```

#### 等しくない

`$ne` を使用して等しくないことを表します。書き方は次のとおりです：

```js
where: { category: { $ne: "ML" } }
```

#### 大于

`$gt` を使用して大なりを表します。書き方は次のとおりです：

```js
where: { score: { $gt: 80 } }
```

#### 大于または等しい

`$gte` を使用して大なりまたは等しいことを表します。書き方は次のとおりです：

```js
where: { score: { $gte: 90 } }
```

#### 小于

`$lt` を使用して小なりを表します。書き方は次のとおりです：

```js
where: { score: { $lt: 60 } }
```

#### 小なりまたは等しい

`$lte` を使用して小なりまたは等しいことを表します。書き方は次のとおりです：

```js
where: { score: { $lte: 50 } }
```

#### 含む

`$in` を使用して含むことを表します。書き方は次のとおりです：

```js
where: { tag: { $in: ["ml", "python", "ai"] } }
```

#### 含まない

`$nin` を使用して含まないことを表します。書き方は次のとおりです：

```js
where: { tag: { $nin: ["deprecated", "obsolete"] } }
```

#### 論理OR

`$or` を使用して論理ORを表します。書き方は次のとおりです：

```js
where: {
    $or: [
      { category: "AI" },
      { category: "ML" }
    ]
  }
```

#### 論理AND

`$and` を使用して論理ANDを表します。書き方は次のとおりです：

```js
where: {
    $and: [
      { category: { $eq: "AI" } },
      { score: { $gte: 90 } }
    ]
  }
```

### テキストフィルタリング（where_document）

#### 全文検索（部分文字列を含む）

`$contains` を使用して全文検索を表します。書き方は次のとおりです：

```js
whereDocument: { $contains: "機械学習" }
```

#### 正規表現

`$regex` を使用して正規表現を表します。書き方は次のとおりです：

```js
whereDocument: { $regex: "AI|ML|DL" }
```

#### 論理OR

`$or` を使用して論理ORを表します。書き方は次のとおりです：

```js
whereDocument: {
    $or: [
      { $contains: "AI" },
      { $contains: "人工知能" }
    ]
  }
```

#### 論理AND

`$and` を使用して論理ANDを表します。書き方は次のとおりです：

```js
whereDocument: {
    $and: [
      { $contains: "機械学習" },
      { $contains: "深層学習" }
    ]
  }
```
