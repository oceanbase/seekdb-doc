# get - 検索

`get()`は、ベクトル類似性検索を行わずに、collectionからdocumentsを検索するために使用されます。

ID、metadata、およびdocumentによるフィルタリングをサポートしています。

:::info

このインターフェースは、SeekdbClient接続を使用する場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール手順の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール手順の詳細については、[yum install による seekdb のデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* collectionを作成し、対応するデータを挿入済みであること。collectionの作成とデータの挿入の詳細な操作については、[createCollection - Collectionの作成](../200.collection-of-seekdb-js/100.create-collection-of-seekdb-js.md)および [add - データの挿入](../300.dml-of-seekdb-js/200.add-data-of-seekdb-js.md)を参照してください。

## リクエストパラメータ

```js
get()
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|string \| string\[\] |必須|検索する単一IDまたはIDリスト|['1', '2']|
|`where`|Where |オプション|Metadataフィルター条件。|`{ category: 'science' }`|
|`whereDocument`|WhereDocument|オプション|Documentフィルター条件。|`{"$contains": "machine"}`|
|`limit`|number |オプション|返す結果の最大数。|`{"category": {"$eq": "AI"}}`|
|`offset`|number|オプション| ページネーション時にスキップする結果数。|`{"$contains": "machine"}`|
|`include`|readonly ("documents" \| "metadatas" \| "embeddings")\[\]|オプション|含めるフィールドリスト：`["documents", "metadatas", "embeddings"]`。|["documents", "metadatas", "embeddings"]|

:::info

パラメータが指定されていない場合、すべてのデータを返します。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.getCollection({name: 'my_collection'});

const result = await collection.get({
  ids: ['1', '2']
});
```

## レスポンスパラメータ

* 単一のIDが指定された場合：そのIDを含むgetオブジェクトを返します。
* 複数のIDが指定された場合：各IDに対応するQueryResultオブジェクトをリストアップします。
* フィルターが指定された場合：一致するすべての結果を含むQueryResultオブジェクトを返します。
