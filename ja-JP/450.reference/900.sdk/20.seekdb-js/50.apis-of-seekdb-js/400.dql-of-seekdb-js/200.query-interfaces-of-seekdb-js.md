# query - ベクトルクエリ

`query()`は、ベクトル類似性検索を実行し、クエリベクトルに最も類似するドキュメントを見つけます。

:::info

このインターフェースは、SeekdbClient接続を使用する場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum install による seekdb のデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続の詳細な操作については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* collectionを作成し、対応するデータを挿入済みであること。collectionの作成とデータの挿入の詳細な操作については、[createCollection - Collectionの作成](../200.collection-of-seekdb-js/100.create-collection-of-seekdb-js.md)および [add - データの挿入](../300.dml-of-seekdb-js/200.add-data-of-seekdb-js.md)を参照してください。

## リクエストパラメータ

```js
query()
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`queryEmbeddings`|number\[\] \| number\[\]\[\] |必須|一括クエリ用の単一ベクトルまたはベクトルリストです。指定されている場合は、そのまま使用されます（embeddingFunctionは無視されます）。指定されていない場合は、`queryText`を指定する必要があり、`collection`には`embeddingFunction`が必要です。|`[1.0, 2.0, 3.0]`|
|`queryTexts`|string \| string\[\]|オプション|単一のベクトルまたはベクトルのリストです。指定されている場合は、そのまま使用されます（`embeddingFunction`は無視されます）。指定されていない場合は、`documents`を指定する必要があり、`collection`には`embeddingFunction`が必要です。|`["my query text"]`|
|`nResults`|number|必須|類似した結果の数を返します。デフォルト値は10です|`3|
|`where`|Where |オプション|Metadataのフィルター条件です。|`{"category": {"$eq": "AI"}}`|
|`whereDocument`|WhereDocument|オプション|Documentのフィルター条件です。|`{"$contains": "machine"}`|
|`include`|readonly ("documents" \| "metadatas" \| "embeddings" \| "distances")\[\][str]|オプション|含めるフィールドのリスト：`["documents", "metadatas", "embeddings"]`。|`["documents", "metadatas", "embeddings"]`|
|`distance`|DistanceMetric|オプション|距離の尺度です。||
|`approximate`|boolean|オプション|近似検索を使用するかどうかを示します。 | `true` |

:::info

* 使用される `embeddingFunction` は、collectionに関連付けられています (`createCollection()` または `getCollection()` の際に設定)。各操作ごとに上書きすることはできません。

* `queryEmbeddings` が指定された場合：ベクトルを直接使用し、`embeddingFunction` を呼び出しません。

* `queryEmbeddings` は指定されていないが `queryTexts` が指定されている場合：

  * コレクションに `embeddingFunction` がある場合、テキストからクエリベクトルが自動的に生成されます。

  * コレクションに `embeddingFunction` がない場合、ValueErrorがスローされます。

* `queryEmbeddings` と `queryTexts` の両方が指定されていない場合：ValueErrorがスローされます。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

// 1. Connect
const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

// 2. Create collection
const collection = await client.createCollection({ name: "my_collection" });

// 3. Add data (auto-vectorized)
await collection.add({
  ids: ["1", "2"],
  documents: ["Hello world", "seekdb is fast"],
});

// 4. Search
const results = await collection.query({
  queryTexts: "Hello",
  nResults: 5,
});
console.log(results);
```

## レスポンスパラメータ

|パラメータ|値の種類|必須|説明|
|---|---|---|---|
|`ids`|readonly (readonly string\[\])\[\] |必須|追加または変更するIDです。単一でも配列でもかまいません。|
|`embeddings`|[List[List[List[float]]]]|オプション|ベクトル。指定されている場合は、そのまま使用します (`embeddingFunction` は無視されます)。指定されていない場合は、ドキュメントを提供することで自動的にベクトルを生成できます。|
|`documents`|[List[List[Dict]]]|オプション|ドキュメント。`vectors` が指定されていない場合、`documents` はコレクションの `embeddingFunction` を使用してベクトルに変換されます。|
|`metadatas`|[List[List[Dict]]]|オプション|メタデータ。|
|`distances`|[List[List[Dict]]]|オプション| |
