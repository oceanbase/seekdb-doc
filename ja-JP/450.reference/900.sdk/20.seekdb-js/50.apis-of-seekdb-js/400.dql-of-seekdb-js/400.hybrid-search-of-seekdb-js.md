# hybridSearch - ハイブリッド検索

`hybridSearch()`は、全文検索とベクトル類似度検索を組み合わせてランキングを生成するために使用されます。

:::info

このインターフェースは、SeekdbClientを使用して接続した場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum install による seekdb のデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。
* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* コレクションを作成し、対応するデータを挿入済みであること。コレクションの作成とデータの挿入の詳細な操作については、[createCollection - コレクションの作成](../200.collection-of-seekdb-js/100.create-collection-of-seekdb-js.md)および [add - データの挿入](../300.dml-of-seekdb-js/200.add-data-of-seekdb-js.md)を参照してください。

## リクエストパラメータ

```js
hybrid_search(
    query={
        "whereDocument": ,
        "where": ,
        "nResults":
    },
    knn={
        queryEmbeddings
        "queryTexts":
        "where":
        "nResults":
    },
    rank=,
    nResults=,
    include=
)
```

* query：全文検索の設定。以下のパラメータが含まれます：

    |パラメータ|値の種類|必須|説明|値の例|
    |---|---|---|---|---|
    |`where`|Where |オプション|Metadataのフィルター条件。|`{"category": {"$eq": "AI"}}`|
    |`whereDocument`|WhereDocument|オプション|ドキュメント内容のフィルター条件（全文検索）|`{"$contains": "machine"}`|
    |`nResults`|number|オプション|全文検索の結果数||

* knn：Vector検索の設定。以下のパラメータが含まれます：

    |パラメータ|値の種類|必須|説明|値の例|
    |---|---|---|---|---|
    |`queryEmbeddings`|number\[\] \| number\[\]\[\] |オプション|一括クエリ用の単一ベクトルまたはベクトルリスト。指定されている場合は、そのまま使用します(embeddingFunctionは無視)。指定されていない場合は、`query_text`を指定する必要があり、`collection`には`embeddingFunction`が必要です。[1.0, 2.0, 3.0]|
    |`queryTexts`|string \| string\[\]|オプション|単一ベクトルまたはベクトルリスト。指定されている場合は、そのまま使用します(`embeddingFunction`は無視)。指定されていない場合は、`documents`を指定する必要があり、同時に`collection`には`embeddingFunction`が必要です。|["my query text"]|
    |`where`|Where |オプション|メタデータのフィルター条件。|`{"category": {"$eq": "AI"}}`|
    |`nResults`|number|オプション|ベクトル検索で返す結果数||

* その他のパラメータは以下のとおりです：

    |パラメータ|値の種類|必須|説明|値の例|
    |`rank`|HybridSearchRank |オプション|ランキングの設定。例：`{"rrf": {"rank_window_size": 60, "rank_constant": 60}}`|`{"category": {"$eq": "AI"}}`|
    |`nResults`|number|必須|類似する結果の数を返します。デフォルト値は10|3|
    |`include`|readonly ("documents" \| "metadatas" \| "embeddings" \| "distances")\[\]|オプション|含めるフィールドのリスト：`["documents", "metadatas", "embeddings"]`。|["documents", "metadatas", "embeddings"]|

:::info

* 使用される `embeddingFunction` はコレクションに関連付けられています（`createCollection()`または`getCollection()`時に設定）。各操作ごとに上書きすることはできません。
* query と knn のうち、少なくとも一方を指定してください。
* knn：
  * `queryEmbeddings` が存在する場合、`collection.Dimension` に基づいて次元が一致しているか確認されます。
  * `queryTexts`: string または string[]。コレクションの `embeddingFunction` を使用して自動的に埋め込みます（関数が欠けている場合、ValueErrorがスローされます）。
* `knn.queryTexts` を指定する場合は、`embeddingFunction` を設定する必要があります。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.getCollection({name: 'my_collection'});

const results = await  collection.hybridSearch({
    query: {
        whereDocument: {$contains: "machine learning"},
        nResults: 10
    },
        knn: {
        queryTexts: 'documents',
        nResults: 10
    },
    rank: {rrf: {}},
    nResults: 10
});

```

## レスポンスパラメータ

ID、distances、metadatas、document、embeddingsなどを含む検索結果の辞書。
