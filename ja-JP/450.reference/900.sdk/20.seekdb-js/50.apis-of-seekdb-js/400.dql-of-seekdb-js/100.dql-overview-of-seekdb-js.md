# DQLの概要

DQL（Data Query Language）操作を使用すると、さまざまなクエリ方法でcollectionsからデータを取得できます。

DQL操作では、以下のAPIを利用できます。

| API | 説明 | 関連ドキュメントのリンク |
|---|---|---|
| `query()` | ベクトル類似度検索メソッド。 | [ドキュメント](200.query-interfaces-of-seekdb-js.md) |
| `get()` | ID、document、metadata（非ベクトル）を使用してテーブルから特定のデータを照会します。 |[ドキュメント](300.get-interfaces-of-seekdb-js.md)|
| `hybrid_search()`  | 全文検索とベクトル類似度検索を組み合わせたランキング方式です。  |[ドキュメント](400.hybrid-search-of-seekdb-js.md)|
