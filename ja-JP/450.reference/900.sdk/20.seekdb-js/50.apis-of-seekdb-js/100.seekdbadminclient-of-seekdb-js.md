# SeekdbAdminClient

`SeekdbAdminClient` はデータベース管理操作を提供します。`SeekdbClient` と同じデータベース接続モードを使用しますが、データベース管理に関連する操作のみをサポートします。

## リモートサーバーへの接続

`SeekdbAdminClient` を使用してリモートサーバーに接続します。seekdbおよびOceanBaseデータベースへの接続をサポートしています。

:::tip

接続する前に、サーバーモードのseekdbまたはOceanBaseデータベースが既にデプロイされていることを確認してください。<br/>サーバーモードのseekdbのデプロイ方法については、[yum installでseekdbをデプロイする](../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。<br/>OceanBaseデータベースのデプロイ方法については、[デプロイの概要](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001970923)を参照してください。

:::

例：サーバーモードのseekdbに接続する

```js
import { SeekdbAdminClient } from "seekdb";

// リモートサーバーモード - データベース管理 (seekdb Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|インスタンスが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`port`|string|必須|インスタンスポート。デフォルトは2881。|`2881`|
|`user`|string|必須|ユーザー名。デフォルトはroot。|`root`|
|`password`|string|必須|ユーザーに対応するパスワード。`password`が指定されていない場合、または空文字列が入力されている場合、システムは`SEEKDB_PASSWORD`環境変数から取得します。||

例：OceanBaseデータベースに接続する

```js
import { SeekdbAdminClient } from "seekdb";

// リモートサーバーモード - データベース管理 (OceanBase Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  tenant: "sys",  // OceanBaseのデフォルトテナント
  user: "root",
  password: ""
});
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|データベースが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`port`|string|必須|OceanBaseデータベースのポート。デフォルトは2881。|`2881`|
|`tenant`|string|オプション|テナント名。seekdbではこのパラメータを指定する必要はありません。OceanBaseデータベースでのみ必要です。デフォルトはsysです。|`sys`|
|`user`|string|必須|テナントに対応するユーザー名。デフォルトはrootです。|`root`|
|`password`|string|必須|ユーザーに対応するパスワード。||

## SeekdbAdminClient接続でサポートされるインターフェース

`SeekdbAdminClient` を使用してデータベースに接続する場合、以下のAPIインターフェースを使用できます。

| API | 説明 |関連ドキュメント|
|---|---|---|
| `createDatabase` | 新しいデータベースを作成します。|[ドキュメント](110.database-of-seekdb-js/200.create-database-of-seekdb-js.md)|
| `getDatabase`    | 指定したデータベースを照会します。|[ドキュメント](110.database-of-seekdb-js/300.get-database-of-seekdb-js.md)|
| `deleteDatabase` | 指定したデータを削除します。 |[ドキュメント](110.database-of-seekdb-js/400.list-database-of-seekdb-js.md)|
| `listDatabases` |すべてのデータベースを一覧表示します。|[ドキュメント](110.database-of-seekdb-js/500.delete-database-of-seekdb-js.md)|
