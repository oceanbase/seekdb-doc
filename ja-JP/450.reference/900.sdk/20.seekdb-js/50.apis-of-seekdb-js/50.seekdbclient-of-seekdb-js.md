# SeekdbClient

`SeekdbClient`は、seekdbに接続するための統一インターフェースであり、seekdbのServerモードとOceanBaseモードをサポートしています。

:::tip
OceanBaseデータベースは、OceanBaseが提供する完全に独自開発されたエンタープライズ向けネイティブ分散型データベースです。一般的なハードウェア上で金融級の高可用性を実現し、「三地五中心」という都市レベルの障害に対する自動無損失ディザスタリカバリという新標準を確立しました。TPC-Cベンチマークテストで新記録を樹立し、単一クラスタで1,500ノードを超える規模をサポートします。クラウドネイティブ、強整合性、Oracle/MySQLとの高い互換性などの特徴を備えています。OceanBaseデータベースの詳細については、[OceanBaseデータベース](https://en.oceanbase.com/docs/oceanbase-database)を参照してください。
:::

## リモートサーバーへの接続

`SeekdbClient` を使用してリモートサーバーに接続します。seekdb および OceanBase データベースへの接続をサポートしています。

:::tip

接続する前に、サーバーモードの seekdb または OceanBase データベースがデプロイ済みであることを確認してください。<br/>サーバーモードの seekdb のデプロイ方法については、[yum install による seekdb のデプロイ](../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。<br/>OceanBase データベースのデプロイ方法については、[デプロイの概要](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001970923)を参照してください。

:::

例：サーバーモードの seekdb に接続する

```js
import { SeekdbClient } from "seekdb";

// 1. Connect
const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|インスタンスが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`port`|string|必須|インスタンスポート。デフォルトは2881。|`2881`|
|`database`|string|必須|データベース名。|`test`|
|`user`|string|必須|ユーザー名。デフォルトはroot。|`root`|
|`password`|string|必須|ユーザーのパスワード。`password`が指定されていない場合、または空文字列が入力されている場合、システムは`SEEKDB_PASSWORD`環境変数から取得します。||

例：OceanBase データベースに接続する

```js
import { SeekDBClient } from "seekdb";

const client = new SeekDBClient({
  host: "127.0.0.1",      // サーバーアドレス
  port: 2881,              // サーバーポート
  tenant: "sys",          // テナント名 (OceanBase データベース接続時)
  database: "demo",       // データベース名
  user: "root",           // ユーザー名
  password: "",           // パスワード
});
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|データベースが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`port`|string|必須|OceanBaseデータベースのポート。デフォルトは2881。|`2881`|
|`tenant`|string|オプション|テナント名。seekdbではこのパラメータを指定する必要はありません。OceanBaseデータベースでのみ必要です。デフォルトはsysです。|`sys`|
|`database`|string|必須|データベース名。|`demo`|
|`user`|string|必須|テナントに対応するユーザー名。デフォルトはrootです。|`root`|
|`password`|string|必須|ユーザーに対応するパスワード。||

## SeekdbClientを使用した接続でサポートされるインターフェース

`SeekdbClient` を使用してデータベースに接続する場合、以下のAPIインターフェースを使用できます。

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `createCollection()` | 新しいcollectionを作成します。 | [ドキュメント](200.collection-of-seekdb-js/100.create-collection-of-seekdb-js.md) |
| `getCollection()` | 指定されたcollectionを取得します。 |[ドキュメント](200.collection-of-seekdb-js/200.get-collection-of-seekdb-js.md)|
| `getOrCreateCollection()` | 指定されたcollectionを取得します。collectionが存在しない場合は、そのcollectionを作成します。|[ドキュメント](200.collection-of-seekdb-js/250.get-or-create-collection-of-seekdb-js.md)|
| `fork()` | 指定されたCollectionをコピーして、同じデータを持つ新しいCollectionを作成します。|[ドキュメント](200.collection-of-seekdb-js/260.fork-collection-of-seekdb-js.md)|
| `listCollections()`  | 現在のデータベース内のすべてのcollectionsを一覧表示します。|[ドキュメント](200.collection-of-seekdb-js/300.list-collection-of-seekdb-js.md)|
| `countCollection()` | 現在のデータベース内のすべてのcollectionの数を取得します。 |[ドキュメント](200.collection-of-seekdb-js/350.count-collection-of-seekdb-js.md)|
| `hasCollection()`  | 現在のデータベース内にcollectionsが存在するかどうかを確認します。|[ドキュメント](200.collection-of-seekdb-js/360.hascollection-collection-of-seekdb-js.md)|
| `deleteCollection()`  | 指定されたcollectionを削除します。  |[ドキュメント](200.collection-of-seekdb-js/400.delete-collection-of-seekdb-js.md)|
