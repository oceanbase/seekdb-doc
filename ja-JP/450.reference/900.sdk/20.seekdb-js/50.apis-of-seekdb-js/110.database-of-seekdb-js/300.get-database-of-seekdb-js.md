# getDatabase - 指定データベースの取得

`getDatabase()`は、指定されたデータベース情報を取得するために使用されます。

:::info

このインターフェースは、`SeekdbAdminClient`を使用して接続した場合にのみ利用できます。`SeekdbAdminClient`の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installでseekdbをデプロイする](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

## リクエストパラメータ

```js
getDatabase(name: string, tenant?: string)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のデータベース名を指定します。|`my_database`|
|`tenant`|string|オプション<ul><li>サーバーモードのseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータは必須です。</li></ul>|作成するデータベースが属するテナントを指定します。|`test_tenant`|

## リクエスト例

```js
import { SeekdbAdminClient } from "seekdb";

// リモートサーバーモード - データベース管理 (seekdb Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});

const db = await admin.getDatabase("my_database");
```

## レスポンスパラメータ

|パラメータ|戻り値の型|必須|説明|戻り値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のデータベース名。|`my_database`|
|`tenant`|string|オプション|クエリ対象のデータベースが属するテナント。<br/>seekdbを使用する場合は、このパラメータはありません。|`sys`|
|`charset`|string|オプション|クエリ対象のデータベースで使用されている文字セット。|`utf8mb4`|
|`collation`|string|オプション|クエリ対象のデータベースで使用されている照合順序。|`utf8mb4_bin`|
|`metadata`|dict|オプション|予約フィールドです。現在データはありません。| `{}` |

## レスポンス例

```js
Database {
  name: 'my_database',
  charset: 'utf8mb4',
  collation: 'utf8mb4_bin',
  metadata: {}
}
```
