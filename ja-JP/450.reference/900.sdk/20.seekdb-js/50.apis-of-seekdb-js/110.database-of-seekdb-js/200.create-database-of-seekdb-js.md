# createDatabase - データベースの作成

`createDatabase()`は、新しいデータベースを作成するために使用されます。

:::info

* このインターフェースは、`SeekdbAdminClient` を使用して接続した場合にのみ利用できます。`SeekdbAdminClient` の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

* 現在、`createDatabase` でデータベースを作成する際には、データベースのプロパティを指定することはサポートされていません。各種プロパティのデフォルト値に基づいてデータベースが作成されます。指定されたプロパティを持つデータベースを作成したい場合は、SQLを使用して作成することをお勧めします。SQLによるデータベースの作成方法の詳細については、[データベースの作成](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971662)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installによるseekdbのデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

* 接続しているユーザーが`CREATE`権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。この権限を持っていない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限に関する操作については、[直接権限付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

## データベース作成の制限

* seekdbインスタンスのデータベースでは、各データベース名はグローバルに一意である必要があります。

* データベース名の長さは128文字以下です。

* 大文字、小文字、数字、アンダースコア、ドル記号、および中国語文字のみを含みます。

* 予約語をデータベース名として使用することは避けてください。

  予約語の詳細については、[予約語](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001970988)を参照してください。

## データベース作成に関する推奨事項

* データベースには、その用途と内容を反映できるような意味のある名前を付けることを推奨します。例えば、`アプリケーション識別子_サブアプリケーション名(オプション)_db` をデータベース名として使用します。

* データベースと関連するユーザーをrootユーザーで作成し、データベースのセキュリティと制御性を確保するために必要な権限のみを付与することを推奨します。

* バッククォート(\`)で囲むことで、数字のみで構成されるデータベース名を作成できますが、この方法は推奨されません。数字のみで名付ける場合、明確な意味がなく、クエリや使用時には常にバッククォート(\`)が必要となり、不必要な複雑さと混乱を招く可能性があるためです。

## リクエストパラメータ

```js
createDatabase(name: string, tenant?: string)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|作成するデータベースの名前を指定します。|`my_database`|
|`tenant`|string|オプション<ul><li>サーバーモードのseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータは必須です。</li></ul>|作成するデータベースが属するテナントを指定します。|`test_tenant`|

## リクエスト例

```js
import { SeekdbAdminClient } from "seekdb";

// リモートサーバーモード - データベース管理 (seekdb Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});

await admin.createDatabase("my_database");
```
