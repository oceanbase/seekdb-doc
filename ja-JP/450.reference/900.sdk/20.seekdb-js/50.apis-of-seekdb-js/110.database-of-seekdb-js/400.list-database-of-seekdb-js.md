# listDatabases - データベースリストの取得

`listDatabases()`は、インスタンス内のデータベースリストを取得するために使用されます。

:::info

このインターフェースは、`SeekdbAdminClient`を使用して接続した場合にのみ利用できます。`SeekdbAdminClient`の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストールに関する詳細は、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストールに関する詳細は、[yum installでseekdbをデプロイする](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続の詳細な操作については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

## リクエストパラメータ

```js
listDatabases(limit?: number, offset?: number, tenant?: string)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`limit`|number|オプション| 結果の件数制限 |`2`|
|`offset`|number|オプション| 結果のオフセット量 | `3` |
|`tenant`|string|オプション<ul><li>サーバーモードのseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータは必須です。デフォルト値は`sys`です。</li></ul>|クエリ対象のデータベースが属するテナントを指定します。|`test_tenant`|

:::tip

limitとoffsetは非負の整数である必要があります。

:::

## リクエスト例

```js
import { SeekdbAdminClient } from "seekdb";

// リモートサーバーモード - データベース管理 (seekdb Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});

// すべてのデータベースを一覧表示
const databases = await admin.listDatabases();

```

## レスポンスパラメータ

|パラメータ|戻り値の型|必須|説明|戻り値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のデータベース名。|`my_database`|
|`tenant`|string|オプション|クエリ対象のデータベースが属するテナント。<br/>seekdbを使用する場合は、このパラメータはありません。|`sys`|
|`charset`|string|オプション|クエリ対象のデータベースで使用される文字セット。|`utf8mb4`|
|`collation`|string|オプション|クエリ対象のデータベースで使用される照合順序。|`utf8mb4_general_ci`|
|`metadata`|dict|オプション|予約フィールド。現在データなし| `{}` |
