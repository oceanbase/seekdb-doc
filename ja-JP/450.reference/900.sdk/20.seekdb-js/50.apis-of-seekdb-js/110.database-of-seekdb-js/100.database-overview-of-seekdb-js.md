# データベース管理

データベース（Database）には、複数のテーブルやインデックス、およびデータベースオブジェクトのメタデータ情報が含まれます。ユーザーは自身のニーズに応じて、データベースを作成、クエリ、削除することができます。

collectionの操作には、以下のAPIを利用できます。

| API | 説明 | 関連ドキュメント |
|---|---|---|
| `createDatabase()` | データベースを作成します。 | [ドキュメント](200.create-database-of-seekdb-js.md) |
| `getDatabase()` | 指定されたデータベースを取得します。 |[ドキュメント](300.get-database-of-seekdb-js.md)|
| `listDatabases()`  | インスタンス内のデータベースリストを取得します。  |[ドキュメント](400.list-database-of-seekdb-js.md)|
| `deleteDatabase()`  | 指定されたデータベースを削除します。|[ドキュメント](500.delete-database-of-seekdb-js.md)|
