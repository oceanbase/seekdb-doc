# deleteDatabase - データベースの削除

`deleteDatabase()`は、データベースを削除するために使用されます。

:::info

このインターフェースは、`SeekdbAdminClient`を使用して接続した場合にのみ利用できます。`SeekdbAdminClient`の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール手順の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール手順の詳細については、[yum installでseekdbをデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbAdminClient](../100.seekdbadminclient-of-seekdb-js.md)を参照してください。

* 接続しているユーザーが`DROP`権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。該当する権限を持っていない場合は、管理者に連絡し権限付与を依頼してください。ユーザー権限に関する操作については、[直接権限付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

## リクエストパラメータ

```js
deleteDatabase(name: string, tenant?: string)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|削除するデータベースの名前を指定します。|`my_database`|
|`tenant`|string|オプション<ul><li>サーバーモードでseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータが必要です。デフォルト値は`sys`です。</li></ul>|削除するデータベースが属するテナントを指定します。|`test_tenant`|

## リクエスト例

```js
import { SeekdbAdminClient } from "seekdb";

// リモートサーバーモード - データベース管理 (seekdb Server)
const admin = new SeekdbAdminClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: ""
});

await admin.deleteDatabase("my_database");
```
