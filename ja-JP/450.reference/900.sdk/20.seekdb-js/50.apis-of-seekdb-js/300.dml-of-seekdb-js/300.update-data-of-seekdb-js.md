# update - データの更新

`update()`は、collection内の既存レコードを更新するために使用します。レコードを更新する際には、そのレコードが存在している必要があります。存在しない場合は、エラーが発生します。

:::info

このインターフェースは、SeekdbClient接続を使用する場合にのみサポートされます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum install による seekdb のデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 接続したユーザーが操作対象のテーブルに対する `UPDATE` 権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。該当する権限がない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限に関する操作については、[直接権限の付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

## リクエストパラメータ

```js
update(
    ids: ids,
    embeddings: embeddings,
    documents: documents,
    metadatas: metadatas
)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|string \| string\[\] |必須|変更するID。単一のIDまたはIDの配列を指定できます。|item1|
|`embeddings`|number\[\] \| number\[\]\[\]|オプション|単一のベクトルまたはベクトルの配列です。このパラメータを指定しない場合、documentsが指定されていると、embeddingFunctionが自動的に生成されます。|[[0.9, 0.8, 0.7], [0.6, 0.5, 0.4]]|
|`documents`|string \| string\[\]|オプション|ドキュメントの内容です。単一の文字列または文字列の配列を指定できます。"New document text"|
|`metadatas`|Metadata \| Metadata\[\]|オプション|メタデータです。単一のオブジェクトまたはオブジェクトの配列を指定できます。|`{"category": "AI"}`|

:::info

* `embeddings`、`metadatas`、または `documents` のうち、少なくとも1つを指定してください。
* メタデータのみの更新を許可します(ベクトルなし、ドキュメントなし)。使用される `embeddingFunction` はコレクションに関連付けられた関数です。
* すべての配列パラメータの長さは、`ids` 配列の長さと一致している必要があります。
* 既存のレコードのみを更新します。存在しないIDは無視されます。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.getCollection({
  name: "my_collection"
});

await collection.update({
  ids: "item1",
  documents: "New document text",
  metadatas: { category: "AI" }
});
```
