# delete - データの削除

`delete()`は、コレクションからレコードを削除するために使用します。ID、メタデータフィルター、またはドキュメントフィルターで削除できます。

:::info

このインターフェースは、SeekdbClient接続時にのみ使用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installでseekdbをデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続の詳細な操作については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 接続しているユーザーが操作対象のテーブルに対する`DELETE`権限を持っていることを確認してください。現在のユーザー権限の確認に関する操作については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。該当する権限がない場合は、管理者に連絡し権限付与を依頼してください。ユーザー権限に関する操作については、[直接権限付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

## リクエストパラメータ

```js
delete(
    ids: ids,
    where=Metadata,
    whereDocument=documents,
)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|string \| string\[\] |オプション|削除するID。単一でも配列でも可能です。|item1|
|`where`|Where|オプション|Metadataのフィルター条件。|`{category: {$eq: "AI" }}`|
|`whereDocument`|WhereDocument|オプション|Documentのフィルター条件。|`{ $contains: "obsolete" }`|

:::info

`ids`、`where`、または`whereDocument`のうち、少なくとも1つは指定する必要があります。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.getCollection({
  name: "my_collection"
});

await collection.delete({
  ids: "item1"
});

await collection.delete({ where: { category: { $eq: "AI" } } });

await collection.delete({ whereDocument: { $contains: "obsolete" } });

```
