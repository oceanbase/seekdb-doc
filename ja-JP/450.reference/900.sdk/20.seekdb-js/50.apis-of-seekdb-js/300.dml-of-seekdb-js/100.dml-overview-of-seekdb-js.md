# DML操作

DML（Data Manipulation Language）操作を使用すると、コレクションにデータの挿入、更新、削除を行えます。

DML操作では、以下のAPIを利用できます。

| API | 説明 | 関連ドキュメントのリンク |
|---|---|---|
| `add()` | 新しいレコードをコレクションに挿入します。 | [ドキュメント](200.add-data-of-seekdb-js.md) |
| `update()` | コレクション内の既存レコードを更新します。 |[ドキュメント](300.update-data-of-seekdb-js.md)|
| `upsert()`  | 新規レコードを挿入するか、既存レコードを更新します。  |[ドキュメント](400.upsert-data-of-seekdb-js.md)|
| `delete()`  | コレクションからレコードを削除します。|[ドキュメント](500.delete-data-of-seekdb-js.md)|
