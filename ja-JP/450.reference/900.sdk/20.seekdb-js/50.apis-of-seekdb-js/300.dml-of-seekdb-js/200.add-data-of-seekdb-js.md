# add - データの挿入

`add()`は、collectionに新しいデータを挿入するために使用されます。レコードを追加する際、既に同じIDを持つレコードが存在する場合は、エラーが発生します。

:::info

このインターフェースは、SeekdbClient接続を使用する場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール手順の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール手順の詳細については、[yum install による seekdb のデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 接続しているユーザーに `Insert` 権限が付与されていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。この権限が付与されていない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限の付与操作については、[直接権限の付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

## リクエストパラメータ

```js
add(
    ids: ids,
    embeddings: embeddings,
    documents: documents,
    metadatas: metadatas
)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|stringまたはstring\[\] |必須|ドキュメントID。単一のIDまたはIDの配列を指定できます。|item1|
|`embeddings`|number\[\] \| number\[\]\[\] |オプション|単一のベクトルまたはベクトルの配列です。これを指定しない場合、documentsが指定されていると、`embeddingFunction` が自動的に生成します。|[0.1, 0.2, 0.3]|
|`documents`|string \| string\[\]|オプション|ドキュメントの内容です。単一の文字列または文字列の配列を指定できます。|"Hello world", "seekdb is fast"|
|`metadatas`|Metadata \| Metadata\[\]|オプション|メタデータです。単一のオブジェクトまたはオブジェクトの配列を指定できます。|`{ category: "test" }, { category: "db" }`|

:::info

* embeddingsが指定されている場合：ベクトルを直接使用し、embeddingFunction(指定されていても)は呼び出されません。

* embeddingsは指定されていないが documentsが指定されている場合：

  * コレクションにembeddingFunction(作成時または取得時に設定)がある場合、ドキュメントから自動的にベクトルが生成されます。

  * コレクションにembeddingFunctionがない場合、ValueErrorがスローされます。

* embeddingsもdocumentsも指定されていない場合：`ValueError`がスローされます。
* すべての配列パラメータの長さは一致している必要があります。
* IDは重複してはなりません。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.createCollection({
  name: "my_collection"
});

await collection.add({
  ids: ["item1", "item2"],
  documents: ["Hello world", "seekdb is fast"],
  metadatas: [{ category: "test" }, { category: "db" }]
});
```
