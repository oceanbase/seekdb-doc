# upsert - データの更新または挿入

`upsert()`は、新規レコードを挿入するか、既存のレコードを更新します。指定されたIDを持つレコードが存在する場合は、そのレコードを更新します。存在しない場合は、新規レコードを挿入します。

:::info

このインターフェースは、SeekdbClientを使用して接続した場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール手順の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール手順の詳細については、[yum install による seekdb のデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 接続しているユーザーが操作対象のテーブルに対する `INSERT` および `UPDATE` 権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。該当する権限がない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限に関する操作については、[直接権限付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

## リクエストパラメータ

```js
upsert(
    ids: ids,
    embeddings: embeddings,
    documents: documents,
    metadatas: metadatas
)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|string \| string\[\] |必須|変更するID。単一でも配列でもかまいません。|item1|
|`embeddings`|number\[\] \| number\[\]\[\]|オプション|単一のベクトルまたはベクトル配列です。指定しない場合で、documentsが指定されている場合は、embeddingFunctionを使用して自動的に生成されます。[0.1, 0.2, 0.3]|
|`documents`|string \| string\[\]|オプション|ドキュメントの内容です。単一の文字列または文字列配列でもかまいません。"document text"|
|`metadatas`|Metadata \| Metadata\[\]|オプション|メタデータです。単一のオブジェクトまたはオブジェクト配列でもかまいません。|`{"category": "AI"}`|

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.getCollection({
  name: "my_collection"
});

await collection.upsert({
  ids: "item1",
  documents: "document text",
  metadatas: { category: "AI" }
});
```
