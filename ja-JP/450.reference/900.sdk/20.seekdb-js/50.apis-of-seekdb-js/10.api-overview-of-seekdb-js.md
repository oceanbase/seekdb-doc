# APIリファレンス

seekdbは、APIを通じてプログラム的に利用できます。

## APIインターフェース

現在、以下のAPIインターフェースをサポートしています。

### Database

:::info
このインターフェースは、`SeekdbAdminClient` を使用して接続した場合にのみ利用できます。`SeekdbAdminClient` の詳細については、[SeekdbAdminClient](100.seekdbadminclient-of-seekdb-js.md)を参照してください。
:::

| API | 説明 | 関連ドキュメント |
|---|---|---|
| `createDatabase()` | データベースを作成します。 | [ドキュメント](110.database-of-seekdb-js/200.create-database-of-seekdb-js.md) |
| `getDatabase()` | 指定されたデータベースを取得します。 |[ドキュメント](110.database-of-seekdb-js/300.get-database-of-seekdb-js.md)|
| `listDatabases()`  | インスタンス内のデータベースリストを取得します。  |[ドキュメント](110.database-of-seekdb-js/400.list-database-of-seekdb-js.md)|
| `deleteDatabase()`  | 指定されたデータベースを削除します。|[ドキュメント](110.database-of-seekdb-js/500.delete-database-of-seekdb-js.md)|

### Collection

:::info
このインターフェースは、SeekdbClient を使用して接続した場合にのみ利用できます。SeekdbClient の詳細については、[SeekdbClient](50.seekdbclient-of-seekdb-js.md)を参照してください。
:::

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `createCollection()` | コレクションを作成します。 | [ドキュメント](200.collection-of-seekdb-js/100.create-collection-of-seekdb-js.md) |
| `getCollection()` | 指定されたコレクションを取得します。 |[ドキュメント](200.collection-of-seekdb-js/200.get-collection-of-seekdb-js.md)|
| `getOrCreateCollection()` | コレクションを作成またはクエリします。データベース内にコレクションが存在しない場合は作成し、存在する場合は対応する結果を取得します。 |[ドキュメント](200.collection-of-seekdb-js/250.get-or-create-collection-of-seekdb-js.md)|
| `fork()` | 指定されたコレクションを複製し、同じデータを持つ新しいコレクションを作成します。|[ドキュメント](200.collection-of-seekdb-js/260.fork-collection-of-seekdb-js.md)|
| `listCollections()`  | データベースのコレクションリストを取得します。  |[ドキュメント](200.collection-of-seekdb-js/300.list-collection-of-seekdb-js.md)|
| `countCollection()`  | データベース内のコレクション数を集計します  |[ドキュメント](200.collection-of-seekdb-js/350.count-collection-of-seekdb-js.md)|
| `hasCollection()`  | 指定されたコレクションがデータベース内に存在するかどうかを確認します  |[ドキュメント](200.collection-of-seekdb-js/360.hascollection-collection-of-seekdb-js.md)|
| `deleteCollection()`  | 指定されたコレクションを削除します。|[ドキュメント](200.collection-of-seekdb-js/400.delete-collection-of-seekdb-js.md)|

### DML

:::info
このインターフェースは、SeekdbClientを使用して接続した場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](50.seekdbclient-of-seekdb-js.md)を参照してください。
:::

| API | 説明 | 関連ドキュメント |
|---|---|---|
| `add()` | 新規レコードをコレクションに挿入します。 | [ドキュメント](300.dml-of-seekdb-js/200.add-data-of-seekdb-js.md) |
| `update()` | コレクション内の既存レコードを更新します。 |[ドキュメント](300.dml-of-seekdb-js/300.update-data-of-seekdb-js.md)|
| `upsert()`  | 新規レコードを挿入するか、既存レコードを更新します。  |[ドキュメント](300.dml-of-seekdb-js/400.upsert-data-of-seekdb-js.md)|
| `delete()`  | コレクションからレコードを削除します。|[ドキュメント](300.dml-of-seekdb-js/500.delete-data-of-seekdb-js.md)|

### DQL

:::info
このインターフェースは、SeekdbClientを使用して接続した場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](50.seekdbclient-of-seekdb-js.md)を参照してください。
:::

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `query()` | ベクトル類似度検索メソッド。 | [ドキュメント](400.dql-of-seekdb-js/200.query-interfaces-of-seekdb-js.md) |
| `get()` | ID、document、metadata（非ベクトル）を使用してテーブルから特定のデータを照会します。 |[ドキュメント](400.dql-of-seekdb-js/300.get-interfaces-of-seekdb-js.md)|
| `hybridSearch()`  | フルテキスト検索とベクトル類似度検索を組み合わせたランキング方式です。  |[ドキュメント](400.dql-of-seekdb-js/400.hybrid-search-of-seekdb-js.md)|
