# createCollection - コレクションの作成

`createCollection()`は、新しいコレクション、すなわちデータベース内のテーブルを作成するために使用されます。

:::info

このインターフェースは、SeekdbClient接続を使用する場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installによるseekdbのデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 接続しているユーザーが`CREATE`権限を持っていることを確認してください。現在のユーザー権限の確認方法については、[ユーザー権限の確認](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/400.view-user-permissions.md)を参照してください。該当する権限がない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限の付与方法については、[直接権限付与](../../../../../400.guides/500.manage/300.security/300.access-control/200.user-and-permission/200.direct-authority.md)を参照してください。

* 必要な埋め込み関数(`embeddingFunction`)がインストールまたは作成されていること。埋め込み関数は、テーブルの追加およびクエリ時のベクトル化を行います。埋め込み関数が指定されていない場合、デフォルトの埋め込み関数が使用されます。デフォルトの埋め込み関数を使用する前に、以下のコマンドを実行して`@seekdb/default-embed`をインストールしてください。詳細については、[デフォルトの埋め込み関数](../../60.embedding-funcations-of-seekdb-js/100.default-embedding-function-of-seekdb-js.md)を参照してください。

    ```bash
    npm install @seekdb/default-embed
    ```

## テーブル名の定義

テーブルを作成する際には、まずテーブルに名前を付ける必要があります。テーブル名を定義する際に従うべき要件は以下の通りです：

* seekdbでは、各テーブル名はデータベース内で一意である必要があります。

* テーブル名は64文字を超え、512文字未満の文字列をサポートします。

* テーブルには意味のある名前を付けることを推奨します。t1やtable1などの名前は使用しないでください。その他のテーブル名の命名規則については、[テーブル名の命名規則](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971368)を参照してください。

## リクエストパラメータ

```js
createCollection(options: CreateCollectionOptions)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|作成するコレクションの名前を指定します。|`my_collection`|
|`configuration`| Configuration \| HNSWConfiguration |オプション|コレクションの設定です。`Configuration`には`HNSWConfiguration`と`FulltextAnalyzerConfig`の2つのプロパティが含まれます。|`{hnsw: {dimension: 384, distance: 'cosine'}, fulltextConfig: {analyzer: 'ik', ik_mode: 'smart'}}`|
|`embeddingFunction`|EmbeddingFunction \| null|オプション|テキストをベクトルに変換するための埋め込み関数です。nullを指定すると、埋め込み関数は使用されません。|`DefaultEmbeddingFunction()`|

**HNSWConfiguration** パラメータは以下のとおりです：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`dimension`|number|オプション|ベクトル次元（embeddingFunctionが指定されている場合は、自動的に推定されます）|`dimension: 384,distance: 'cosine'`|
|`distance`| DistanceMetric |オプション|距離尺度:'l2'(ユークリッド距離)、'cosine'(コサイン類似度)、'inner_product'(内積)|`dimension: 384, distance: 'cosine'`|

:::info

* `embeddingFunction` を指定した場合、システムはこの関数を呼び出してベクトルの次元を自動的に計算します。`configuration.dimension` も指定されている場合、その次元は `embeddingFunction` の次元と一致している必要があります。一致しない場合は ValueError が発生します。

* `embeddingFunction` (EmbeddingFunction、オプション)：ドキュメントをベクトルに変換する関数です。指定された場合、次元は自動的に計算され、`configuration.dimension` と検証されます。

:::

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

// 1. Connect
const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

// 2. Create collection
const collection = await client.createCollection({ name: "my_collection" });
```
