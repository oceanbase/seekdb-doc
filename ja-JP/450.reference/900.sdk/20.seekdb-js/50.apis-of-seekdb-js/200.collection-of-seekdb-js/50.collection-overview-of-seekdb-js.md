# collection管理

collectionはseekdb-jsにおいて、データベースのテーブルに類似するコレクションであり、ユーザーは対応するコレクションを作成、クエリ、削除することができます。

collectionの操作には、以下のAPIを利用できます。

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `createCollection()` | コレクションを作成します。 | [ドキュメント](100.create-collection-of-seekdb-js.md) |
| `getCollection()` | 指定されたコレクションを取得します。 |[ドキュメント](200.get-collection-of-seekdb-js.md)|
| `getOrCreateCollection()` | コレクションを作成または取得します。データベース内にコレクションが存在しない場合は作成し、存在する場合は対応する結果を取得します。 |[ドキュメント](250.get-or-create-collection-of-seekdb-js.md)|
| `fork()` | 指定されたコレクションを複製し、同じデータを持つ新しいコレクションを作成します。|[ドキュメント](260.fork-collection-of-seekdb-js.md)|
| `listCollections()`  | データベースのコレクションリストを取得します。  |[ドキュメント](300.list-collection-of-seekdb-js.md)|
| `countCollection()`  | データベース内のコレクション数を集計します  |[ドキュメント](350.count-collection-of-seekdb-js.md)|
| `hasCollection()`  | 指定されたコレクションがデータベース内に存在するかどうかを確認します  |[ドキュメント](360.hascollection-collection-of-seekdb-js.md)|
| `deleteCollection()`  | 指定されたコレクションを削除します。|[ドキュメント](400.delete-collection-of-seekdb-js.md)|
