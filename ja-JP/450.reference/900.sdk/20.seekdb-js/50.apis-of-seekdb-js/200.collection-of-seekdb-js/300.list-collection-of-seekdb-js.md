# listCollections - Collectionsリストの取得

`listCollections()`は、すべてのCollectionを取得するために使用されます。

:::info

このインターフェースは、SeekdbClient接続を使用する場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installによるseekdbのデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続の詳細な操作については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 取得したCollectionが存在すること。Collectionが存在しない場合、エラーが表示されます。

## リクエストパラメータ

```js
listCollections()
```

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

// 1. Connect
const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collections = await client.listCollections();
```

## レスポンスパラメータ

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリで取得したコレクションの名前。|my_collection|
|`dimension`|int|オプション| | 384 |
|`embeddingFunction`|EmbeddingFunction|オプション | |embeddingFunction: DefaultEmbeddingFunction \{name: 'default-embed', pipe: null, modelName: 'Xenova/all-MiniLM-L6-v2', revision: undefined, dtype: undefined,  cacheDir: undefined,  localFilesOnly: undefined,  progressCallback: undefined   \}|
|`distance`|string|オプション| |cosine|
|`metadata`|dict|オプション|予約フィールドです。現在データはありません。| {} |
