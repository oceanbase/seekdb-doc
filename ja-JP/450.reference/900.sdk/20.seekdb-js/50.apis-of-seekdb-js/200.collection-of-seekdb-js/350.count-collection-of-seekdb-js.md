# countCollection - コレクション数を集計する

`countCollection()`は、データベース内のコレクション数を集計します。

:::info

このインターフェースは、SeekdbClientを使用して接続した場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installでseekdbをデプロイ](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* 取得しようとしているコレクションが存在すること。コレクションが存在しない場合、エラーが表示されます。

## リクエストパラメータ

```js
countCollection()
```

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

// 1. Connect
const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const count = await client.countCollection();
console.log(count);
```

## レスポンスパラメータ

なし

## レスポンス例

```js
2
```
