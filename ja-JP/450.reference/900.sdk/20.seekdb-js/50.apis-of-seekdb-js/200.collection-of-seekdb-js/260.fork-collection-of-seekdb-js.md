# fork - コレクションのコピー

`fork()`は、指定されたコレクションをコピーし、同じデータを持つ新しいコレクションを作成します。

:::info

* V1.1.0バージョンでは、Forkテーブルは実験的な機能です。本番環境での使用は慎重に行ってください。
* このインターフェースは、SeekdbClientを使用して接続した場合にのみ利用できます。SeekdbClientの詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

:::

## 前提条件

* seekdb-jsがインストール済みであること。seekdb-jsのインストール方法の詳細については、[クイックスタート](../../10.seekdb-js-get-started.md)を参照してください。

* seekdbサーバーモードがインストール済みであること。seekdbサーバーモードのインストール方法の詳細については、[yum installでseekdbをデプロイする](../../../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[SeekdbClient](../50.seekdbclient-of-seekdb-js.md)を参照してください。

* フォークするコレクションが存在すること。コレクションが存在しない場合、エラーメッセージが表示されます。

## リクエストパラメータ

```js
fork("forkCollection");
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string \| string\[\]|必須|新しいテーブルの名前。|`fork_collection`|

## リクエスト例

```js
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

const collection = await client.getCollection({name: 'my_collection'});

const forkCollection = await collection.fork('fork_collection');
```

## レスポンスパラメータ

フォークされたコレクションインスタンスを返します。
