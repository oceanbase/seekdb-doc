# クイックスタート

## seekdb-js

seekdb-jsは、OceanBaseが提供するNodeクライアントです。一連のAPIを基盤として実装されており、リモートサーバー(seekdbのサーバーモードおよびOceanBaseデータベース)への接続をサポートします。

:::tip
OceanBaseデータベースは、OceanBaseが提供する完全に独自開発されたエンタープライズ向けネイティブ分散型データベースです。一般的なハードウェア上で金融級の高可用性を実現し、「三地五中心」という都市レベルの障害に対する自動無損失ディザスタリカバリの新標準を確立しました。TPC-Cベンチマークテストで新記録を樹立し、単一クラスタで1,500ノードを超える規模をサポートします。クラウドネイティブ、強整合性、Oracle/MySQLとの高い互換性などの特徴を備えています。OceanBaseデータベースの詳細については、[OceanBaseデータベース](https://en.oceanbase.com/docs/oceanbase-database)を参照してください。
:::

## seekdb-jsのインストール

### 前提条件

環境が以下の要件を満たしていることを確認してください：

* Node.jsバージョン：Node.js 20以降のバージョン

* seekdbのサーバーモードがデプロイ済みで起動していること。seekdbの詳細なデプロイ方法については、[yum installによるseekdbのデプロイ](../../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

### インストール

```shell
npm install seekdb
```
