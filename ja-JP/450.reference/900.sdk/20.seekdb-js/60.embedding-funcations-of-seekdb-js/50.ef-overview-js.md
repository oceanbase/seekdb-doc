# 埋め込み関数の概要

seekdbでは、**埋め込み関数（Embedding Functions、EF）** は、テキストなどの入力をベクトルに変換し、意味検索（ベクトル類似性検索）などの機能をサポートするために使用されます。seekdbは、さまざまな主要プラットフォーム/モデルの埋め込み関数をカプセル化しており、組み込み実装を直接使用することも、インターフェース仕様に従ってカスタム埋め込み関数を実装することもできます。

## 動作原理

Collectionの作成時または取得時に `embeddingFunction` パラメータを使用してEFをバインドできます。バインド後、Collectionへの書き込みおよびクエリでは、以下のルールに従ってベクトルが自動生成されます：

- **書き込み**：`add` / `update` / `upsert` などのインターフェースを呼び出す際、`documents`（`embeddings` ではない）が渡された場合、EFを使用してテキストをベクトルに変換し、書き込みます。
- **クエリ**：`query` インターフェースを呼び出す際、`queryTexts`（`queryEmbeddings` ではない）が渡された場合、EFを使用してクエリテキストをクエリベクトルに変換し、検索を実行します。

:::tip
明示的に `embeddings` / `queryEmbeddings` を渡した場合、seekdbは提供されたベクトルを直接使用し、CollectionにバインドされたEFを無視します。
:::

## 典型的な使い方（Collectionへのバインド）

以下の例は、EFとCollectionを典型的にバインドする方法を示しています。ここで、`ef` は任意のプラットフォームの埋め込み関数インスタンスに置き換えることができます。`client` は既に作成された `SeekdbClient` インスタンスです。

```javascript
import { SeekdbClient } from "seekdb";
import { OpenAIEmbeddingFunction } from "@seekdb/openai";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

// 1. 埋め込み関数の初期化
const ef = new OpenAIEmbeddingFunction({
  modelName: "text-embedding-3-small",
});

// 2. Collection作成時に埋め込み関数をバインド
const collection = await client.createCollection({
  name: "my_collection",
  embeddingFunction: ef,
});

// 3. documentsの書き込み：ベクトルを自動生成して保存
await collection.add({
  ids: ["1", "2"],
  documents: ["Hello world", "How are you?"],
  metadatas: [{ id: 1 }, { id: 2 }],
});

// 4. queryTextsを使用したクエリ：クエリベクトルを自動生成して検索
const results = await collection.query({
  queryTexts: "How are you?",
  nResults: 1,
});
console.log(results);
```

## デフォルトの埋め込み関数：DefaultEmbeddingFunction（all-MiniLM-L6-v2）

Collection作成時に `embeddingFunction` を指定しなかった場合、seekdbはデフォルトの埋め込みロジック（ローカルモデル `Xenova/all-MiniLM-L6-v2`、次元384）を使用します。このモデルはローカルで実行され、APIキーは不要です。初回のベクトル化時にモデルファイルが自動的にダウンロードされます。

```javascript
// embeddingFunctionを指定しない場合、デフォルトの埋め込みロジックを使用
const collection = await client.createCollection({
  name: "default_collection",
});
```

明示的にデフォルトの埋め込み関数を使用する必要がある場合（例えば、常に `embeddingFunction` パラメータで渡す場合）、`@seekdb/default-embed` をインストールしてそのインスタンスを渡すことができます。

```javascript
import { DefaultEmbeddingFunction } from "@seekdb/default-embed";

const defaultEmbed = new DefaultEmbeddingFunction({
  // ダウンロードに失敗した場合は、region: 'intl' を設定してみてください。
});

const collection = await client.createCollection({
  name: "local_embed_collection",
  embeddingFunction: defaultEmbed,
});
```

詳細については、[デフォルトの埋め込み関数](100.default-embedding-function-of-seekdb-js.md)を参照してください。

## カスタム埋め込み関数

組み込みの埋め込み関数では要件を満たせない場合、`EmbeddingFunction` インターフェースを実装してカスタムEFを作成できます。カスタムEFは以下の制約を満たす必要があります：

- `generate` メソッドの実装：`string[]` を受け取り、`Promise<number[][]>` を返します。
- `name` プロパティの実装：この埋め込み関数の一意の名前を返します。
- `configs` メソッドの実装：現在のインスタンスの設定オブジェクトを返します（シリアライズ/復元用）。
- 静的メソッド `buildFromConfig` の実装：設定オブジェクトに基づいて新しいインスタンスを構築します。
- （推奨）`dimension` の提供：ベクトルの次元を返し、Collectionの作成時の一貫性検証を容易にします。

カスタム埋め込み関数を実装した後、シリアライズ/復元を実現するために、registerEmbeddingFunction を使用して登録する必要があります。以下は最小限の例です：

```javascript
import type { EmbeddingFunction } from "seekdb";
import { registerEmbeddingFunction } from "seekdb";

class MyCustomEmbeddingFunction implements EmbeddingFunction {
  readonly name = "my_custom_embedding";
  dimension = 3;

  async generate(texts: string[]) {
    // ここでベクトル化ロジックを実装します（例えば、内部モデルサービスを呼び出す）
    return texts.map(() => [0.1, 0.2, 0.3]);
  }
  getConfig() {
    return {};
  }
  static buildFromConfig() {
    return new MyCustomEmbeddingFunction();
  }
}

// カスタム関数を登録します
registerEmbeddingFunction("my_custom_embedding", MyCustomEmbeddingFunction);
```
