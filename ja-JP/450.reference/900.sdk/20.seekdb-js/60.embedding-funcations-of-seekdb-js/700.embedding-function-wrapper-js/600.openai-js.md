# OpenAI

OpenAI Embedding モデルは、自然言語処理分野における中核的なツールであり、テキスト（単語、文、段落）を効率的に高次元ベクトル（埋め込み）に変換することができます。これらのベクトルは、text-embedding-3-large などの高性能な事前学習済みモデルによって生成され、ユーザーが追加の訓練を行うことなく、テキストの意味情報を深く捉えることができます。その核心的な原理は、元のテキストを密ベクトル空間にマッピングし、ベクトル間の距離（例：コサイン類似度）を計算することで、テキスト間の意味的類似性を容易に測定できる点です。この技術は、セマンティック検索、インテリジェントQ&A、テキストのクラスタリングと分類、レコメンデーションシステムの強化、検索拡張生成（RAG）などのシナリオで広く利用されています。

:::tip
OpenAI サービスを使用するには、OpenAI の料金規則に従う必要があり、それに応じた費用が発生する場合があります。続行する前に、公式ウェブサイトをご覧いただくか、関連ドキュメントを参照して、その料金体系を確認し、同意してください。同意しない場合は、操作を続けないでください。
:::

## 依存関係と認証

* `@seekdb/openai` ソフトウェアパッケージと OpenAI 公式が提供する JavaScript SDK がインストール済みであること。ブラウザ環境で使用する場合は、追加のライブラリをインストールせずに、直接 `fetch` API を使用して呼び出すこともできます。

* [OpenAI Platform](https://platform.openai.com/) に登録し、API キーを作成しておく必要があります。

## 例：OpenAI Embedding Function の作成

`new OpenAIEmbeddingFunction()` コンストラクタを呼び出し、設定オブジェクトを渡して埋め込み関数を初期化します。

* 基本的な使い方

    モデル名を指定しない場合、デフォルトモデルと環境変数に設定されている API キーが使用されます。

    ```javascript
    import { OpenAIEmbeddingFunction } from "@seekdb/openai";

    const ef = new OpenAIEmbeddingFunction();
    ```

* 上級者向けの使い方とカスタム設定

    API キーを表す環境変数名をカスタマイズし、モデルのバージョンに応じて `modelName`、`baseURL` などのパラメータを設定します。

    ```javascript
    import { OpenAIEmbeddingFunction } from "@seekdb/openai";

    const ef = new OpenAIEmbeddingFunction({

    // text-embedding-3-small モデルを使用（低コスト）
    modelName: "text-embedding-3-small",
    // baseURL: "https://api.openai.com/v1",
    });
    ```

**パラメータ説明：**

* `apiKey`：オプション。API キー。環境変数から提供できます。

* `apiKeyEnvVar`：API キーの環境変数名。デフォルト値は `OPENAI_API_KEY` です。

* `modelName`：モデル名。デフォルト値は `text-embedding-3-small` です。

* `dimensions`：オプション。出力次元数。

* `organizationId`：オプション。組織ID。デフォルト値は `process.env.OPENAI_ORG_ID` です。

* `baseURL`：オプション。カスタムのベースURL。
