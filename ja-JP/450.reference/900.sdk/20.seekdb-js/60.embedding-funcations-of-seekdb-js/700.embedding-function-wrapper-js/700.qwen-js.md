# Qwen

Qwen Embedding モデルは、Qwen シリーズの最新の専用モデルであり、テキスト埋め込みおよびランキングタスク向けに設計されています。このシリーズは Qwen3 シリーズの高密度ベースモデルを基盤とし、0.6B から 8B までの異なるパラメータサイズのモデルを提供しており、軽量エッジデプロイから高性能データセンターまでのあらゆるシナリオニーズをカバーしています。その核心的な利点は、ベースモデルが備える優れた多言語対応（100 を超える言語と複数のプログラミング言語をサポート）、長文理解（最大 32K のコンテキストウィンドウ）、そして強力な論理推論能力を継承していることです。

:::tip
Qwen サービスの利用には、第三者プラットフォームの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式サイトをご確認いただくか、関連ドキュメントを参照し、その料金体系を確認・ご同意いただきますようお願いいたします。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

* `@seekdb/qwen` ソフトウェアパッケージがインストール済みであること。

* Qwen Embedding API を呼び出す権限が付与されていること。

## 例：Qwen Embedding Function の作成

`new QwenEmbeddingFunction()` コンストラクタを呼び出し、設定オブジェクトを渡して埋め込み関数を初期化します。

```javascript
import { QwenEmbeddingFunction } from "@seekdb/qwen";

const qwenEmbed = new QwenEmbeddingFunction({
  modelName: "text-embedding-v4",
});
```

**パラメータ説明：**

* **apiKey**：DashScope API キー（オプション。指定しない場合、環境変数から読み取る試みを行います）
* **apiKeyEnvVar**：API キーの環境変数名（デフォルト：`DASHSCOPE_API_KEY`）
* **modelName**：モデル名（デフォルト：`text-embedding-v4`）
* **dimensions**：出力次元（デフォルト：`1024`）
* **region**：API リージョン：`"cn"`（中国）または `"intl"`（国際）（デフォルト：`"cn"`）
