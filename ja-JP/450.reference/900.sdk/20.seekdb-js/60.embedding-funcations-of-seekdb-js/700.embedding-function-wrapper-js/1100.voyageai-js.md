# Voyage AI

Voyage AI EmbeddingFunctionは、seekdbが多様なAIエコシステムをサポートするために設計した埋め込みアダプターの一つです。seekdbはAIネイティブのハイブリッド検索データベースであり、ベクトル、全文、構造化データ、半構造化データのストレージと検索を統一的にサポートすることがその核心的な強みです。このような埋め込み関数を利用することで、開発者は外部の優れた埋め込みサービス（例えばVoyageAI）を容易に呼び出し、seekdbに強力な意味理解機能を注入することができます。これにより、より高精度なRAGシステムやエージェントメモリベースなどのアプリケーションを構築できます。

:::tip
Voyage AIサービスの利用には、Voyage AIの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認してご同意いただくようお願いいたします。同意されない場合は、操作を続けないでください。
:::

## 依存関係と認証

* `@seekdb/voyageai` パッケージがインストール済みであること。

* 有効な[Voyage AI APIキー](https://www.voyageai.com/)があり、認証に使用されます。

## 例：Voyage AI Embedding Functionの作成

`new VoyageAIEmbeddingFunction()` コンストラクターを呼び出し、設定オブジェクトを渡して埋め込み関数を初期化します。

環境変数の `VOYAGE_API_KEY` を使用してモデルを指定します。`voyage-4-large` モデルはVoyage AIのフラッグシップ汎用モデルで、長文脈と高精度検索をサポートしています。

```javascript
import { VoyageAIEmbeddingFunction } from "@seekdb/voyageai";

// voyage-4-large モデルの使用
const ef = new VoyageAIEmbeddingFunction({
modelName: "voyage-4-large",
// inputType: "document",
// truncation: true,
});
```

**パラメータ説明：**

* `modelName`：VoyageAIモデル名。デフォルト値は `voyage-4-large` です。

* `apiKey`：オプション。APIキーで、環境変数から提供できます。

* `apiKeyEnvVar`：API Keyが存在する環境変数名。デフォルト値は `VOYAGE_API_KEY` です。

* `input_type`：入力タイプのヒントで、検索結果を最適化するために使用されます。一般的な値：

  * `documents`：ドキュメントのインデックス作成（documents）に使用します。

  * `metadatas`：クエリ（query texts）に使用します。

* `truncation`：オプション。入力テキストがモデルのコンテキストウィンドウを超える場合（例えばvoyage-4-largeは32Kトークンをサポートします）、このパラメータは自動的に長すぎる部分を切り捨てるかどうかを決定します。
