# Jina AI

Jina AIは、セマンティック検索および関連する検索タスクに使用できるさまざまなEmbeddingモデルを提供しています。seekdbは`JinaEmbeddingFunction`パッケージを提供し、`documents`への書き込み時や`query_texts`でのクエリ実行時に、自動的にJinaを呼び出してベクトルを生成し、類似性検索を完了します。

:::tip
Jina AIサービスを利用するには、Jina AIの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認・ご了承ください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

このEmbedding Functionを使用するには、通常以下が必要です：

- Jina AI API Keyを取得し、対象のEmbeddingモデルを呼び出す権限を持っていること
- 認証は、パラメータでAPI Keyを渡すか、環境変数で提供することができます（デフォルトでは`JINA_API_KEY`を読み取ります）。他の環境変数名を使用する場合は、`apiKeyEnvVar`で指定できます。

## インストール

```bash
npm i seekdb @seekdb/jina
```

## 例：Jina Embedding Functionを作成する

```typescript
import { JinaEmbeddingFunction } from "@seekdb/jina";

const ef = new JinaEmbeddingFunction({
  modelName: "jina-clip-v2",
  // apiKeyEnvVar: "JINA_API_KEY",
});
```

**パラメータ説明：**

- **apiKey**：Jina API Key（オプション。指定しない場合、環境変数からの読み取りを試みます）
- **apiKeyEnvVar**：API Keyの環境変数名（デフォルト：`"JINA_API_KEY"`）
- **modelName**：Embeddingモデル名（デフォルト：`"jina-clip-v2"`）
