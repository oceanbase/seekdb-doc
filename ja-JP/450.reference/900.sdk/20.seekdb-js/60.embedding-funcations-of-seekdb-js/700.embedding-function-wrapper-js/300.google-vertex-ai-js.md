# Google Vertex AI

Google Vertex AIは、さまざまなテキスト埋め込みモデルを提供しています。seekdbは `GoogleVertexEmbeddingFunction` パッケージを提供し、`documents` の書き込み時や `query_texts` クエリの実行時に、Vertex AIを自動的に呼び出してベクトルを生成し、類似性検索を完了するために使用できます。

:::tip
Google Vertex AIサービスの利用には、Google Cloudの料金規則が適用され、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご確認いただくか、関連ドキュメントを参照して、その料金体系を確認し、同意してください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

この埋め込み関数を使用するには、通常、以下が必要です：

- Google Cloud / Vertex AIが有効になっており、対象の埋め込みモデルへの呼び出し権限を持っていること。
- Google Application Default Credentials（ADC）が設定されていること。

## インストール

```bash
npm i seekdb @seekdb/google-vertex
```

## 例：Google Vertex AI埋め込み関数の作成

```typescript
import { GoogleVertexEmbeddingFunction } from "@seekdb/google-vertex";

const ef = new GoogleVertexEmbeddingFunction({
  projectId: "your-gcp-project-id",
  modelName: "textembedding-gecko",
});
```

**パラメータ説明：**

- **projectId**：Google CloudプロジェクトID（必須）
- **location**：Vertex AIリージョン（デフォルト：`"us-central1"`）
- **modelName**：埋め込みモデル名（デフォルト：`"textembedding-gecko"`）
