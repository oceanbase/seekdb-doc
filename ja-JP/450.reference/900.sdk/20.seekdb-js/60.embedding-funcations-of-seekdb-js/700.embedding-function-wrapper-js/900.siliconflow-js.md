# SiliconFlow

SiliconFlowは、さまざまなトップクラスのオープンソース大規模言語モデルを集約したワンストップクラウドサービスプラットフォームです。そのEmbeddingサービスは、高性能なセマンティックベクトルモデルのシリーズを提供しており、大規模言語モデル検索拡張（RAG）、検索、推薦などのシナリオで広く利用されています。プラットフォーム上のモデル、例えばBGEシリーズやQwen Embeddingシリーズは、優れたセマンティック表現能力を備えており、一部のモデル、例えばQwen3-Embeddingは、精度とストレージコストのバランスを取るために出力次元を柔軟に調整することもサポートしています。

:::tip
SiliconFlowサービスを利用するには、SiliconFlowの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを参照し、その料金体系を確認し、同意してください。同意しない場合は、操作を続けないでください。
:::

## 依存関係と認証

* `@seekdb/siliconflow` パッケージがインストール済みであること。

* [SiliconFlowプラットフォーム](https://siliconflow.cn/)にアカウントを登録し、API管理ページでAPIキーを作成する必要があります。これは認証と課金に使用されます。

## 例：SiliconFlow Embedding Functionを作成する

`new SiliconFlowEmbeddingFunction()` コンストラクタを呼び出し、設定オブジェクトを渡して埋め込み関数を初期化します。モデル名を指定し、デフォルトの環境変数 `SILICONFLOW_API_KEY` を使用して初期化します。

```javascript
import { SiliconFlowEmbeddingFunction } from "@seekdb/siliconflow";

const ef = new SiliconFlowEmbeddingFunction({
modelName: "BAAI/bge-large-zh-v1.5",
});
```

**パラメータ説明：**

* **modelName**：SiliconFlow Embeddingモデル名（デフォルト：`BAAI/bge-large-zh-v1.5`）
* **api_key_env**：API Keyが存在する環境変数名（デフォルト：`SILICONFLOW_API_KEY`）
