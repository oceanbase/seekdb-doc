# Cohere

Cohereは、テキストの意味検索、クラスタリング、レコメンデーションなどのシナリオで利用できるさまざまなEmbeddingモデルを提供しています。seekdbは、`CohereEmbeddingFunction` パッケージを提供し、`documents` の書き込み時や `query_texts` によるクエリ実行時に、Cohereを自動的に呼び出してベクトルを生成し、類似性検索を完了するために使用されます。

:::tip
Cohereサービスを使用するには、Cohereの料金規則に従う必要があり、それに応じた費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認してご同意いただきますようお願いいたします。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

このEmbedding Functionを使用するには、通常以下が必要です：

- Cohere API Keyを取得し、対象のEmbeddingモデルを呼び出す権限を持っていること。
- 認証は、パラメータでAPI Keyを渡すか、環境変数で提供することができます（デフォルトでは `COHERE_API_KEY` を読み取ります）。他の環境変数名を使用する場合は、`apiKeyEnvVar` で指定できます。

## インストール

```bash
npm i seekdb @seekdb/cohere
```

## 例：Cohere Embedding Functionの作成

```typescript
import { CohereEmbeddingFunction } from "@seekdb/cohere";

const ef = new CohereEmbeddingFunction({
  modelName: "embed-english-v3.0",
  inputType: "search_document",
});
```

**パラメータ説明：**

- **apiKey**：Cohere API Key（オプション。指定しない場合、環境変数からの読み取りを試みます）
- **apiKeyEnvVar**：API Keyの環境変数名（デフォルト：`"COHERE_API_KEY"`）
- **modelName**：Embeddingモデル名（デフォルト：`"embed-english-v3.0"`）
- **inputType**：入力タイプのヒントで、検索結果を最適化するために使用されます。選択肢：`"search_document"` | `"search_query"` | `"classification"` | `"clustering"` | `"image"`（デフォルト：`"search_document"`）
- **truncate**：入力が長すぎる場合の切り捨て方針。選択肢：`"NONE"` | `"START"` | `"END"`（オプション）
- **embeddingType**：出力ベクトルのタイプ。選択肢：`"float"` | `"int8"` | `"uint8"` | `"binary"` | `"ubinary"`（オプション）
