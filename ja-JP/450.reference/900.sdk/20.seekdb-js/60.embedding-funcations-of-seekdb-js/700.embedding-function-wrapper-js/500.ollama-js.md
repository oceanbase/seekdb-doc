# Ollama

Ollamaは、オープンソースモデルのローカル実行と管理をサポートし、OpenAI互換のAPIを提供してEmbeddingの生成を行います。seekdbは`OllamaEmbeddingFunction`パッケージを提供しており、このインターフェースを通じてOllamaのEmbeddingモデルを呼び出すことができます。

:::tip
Ollamaサービスの利用には、Ollamaの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認してご同意いただきますようお願いいたします。同意されない場合は、操作を続けないでください。
:::

## 依存関係と環境

このEmbedding Functionを使用するには、通常以下が必要です：

- Ollamaがインストール済みで起動していること
- ターゲットモデルがローカルにプルされていること（使用前に`ollama pull <model_name>`を実行する必要があります）。例：

    ```shell
    ollama pull nomic-embed-text
    ```

## インストール

```bash
npm i seekdb @seekdb/ollama
```

## 例：Ollama Embedding Functionの作成

```typescript
import { OllamaEmbeddingFunction } from "@seekdb/ollama";

const ef = new OllamaEmbeddingFunction({
  url: "http://localhost:11434/v1",
  modelName: "nomic-embed-text",
  // apiKeyEnv: "OLLAMA_API_KEY",
});
```

**パラメータ説明：**

- **url**：Ollama APIのベースアドレス（デフォルト：`"http://localhost:11434/v1"`）
- **modelName**：ローカルにプルされたモデル名（デフォルト：`"nomic-embed-text"`）
- **apiKeyEnv**：API Keyの環境変数名（デフォルト：`"OLLAMA_API_KEY"`、オプション。Ollamaはこの値の検証をデフォルトで行いません）

:::tip
使用前に、Ollamaが実行中であり、ターゲットモデルが`ollama pull <model_name>`によってローカルにプルされていることを確認してください。
:::
