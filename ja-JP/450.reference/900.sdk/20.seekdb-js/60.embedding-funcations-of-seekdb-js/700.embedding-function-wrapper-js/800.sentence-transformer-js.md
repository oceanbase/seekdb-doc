# Sentence Transformer

Sentence Transformerは、文、フレーズ、または短文を高次元ベクトル（埋め込みとも呼ばれる）に変換するための深層学習フレームワークです。そのコアな考え方は、意味的に類似した文同士をベクトル空間上で近距離に配置し、意味的に異なる文同士を遠距離に配置することで、ベクトル間のコサイン類似度やユークリッド距離を計算することで文の意味的類似度を判断できるようにすることです。このフレームワークは、強力な事前学習済みTransformerモデル（BERT、RoBERTaなど）を基盤として構築されており、プーリング戦略（平均プーリング、CLSプーリングなど）を用いてすべての単語のベクトルを固定サイズの文レベルベクトルに統合します。意味検索、テキストクラスタリング、文分類、情報検索、検索増強生成（RAG）などのシナリオで広く利用されています。

## 依存関係と認証

使用する前に、`@seekdb/sentence-transformer` パッケージがインストールされていることを確認してください。

* `sentence-transformers` ライブラリは、モデルのロードやエンコードなどのコア機能をカプセル化しています。

* Sentence Transformerは通常ローカルで実行されます。初回使用時に特定のモデルを指定すると、その事前学習済み重みがHugging Face Hubから自動的にダウンロードされ、ローカルにキャッシュされるため、追加のAPIキー認証は不要です。

## 例：SentenceTransformer Embedding Functionを作成する

`new SentenceTransformerEmbeddingFunction()` コンストラクタを呼び出し、設定オブジェクトを渡して埋め込み関数を初期化します。

```javascript
import { SentenceTransformerEmbeddingFunction } from "@seekdb/sentence-transformer";

const ef = new SentenceTransformerEmbeddingFunction({

  // all-MiniLM-L6-v2 モデルは軽量で効率的な汎用モデルで、ほとんどのシナリオに適しています。
  modelName: "Xenova/all-MiniLM-L6-v2",
  device: "cpu",
  normalizeEmbeddings: false,
});
```

**パラメータ説明：**

* **modelName**：Sentence Transformerモデル名（デフォルト：`Xenova/all-MiniLM-L6-v2`）
* **device**：実行デバイス（デフォルト：`"cpu"`）
* **normalizeEmbeddings**：出力ベクトルを正規化するかどうか（デフォルト：`false`）
* **kwargs**：オプションです。タスクパイプラインのオプションで、JSON形式でシリアライズ可能です。
