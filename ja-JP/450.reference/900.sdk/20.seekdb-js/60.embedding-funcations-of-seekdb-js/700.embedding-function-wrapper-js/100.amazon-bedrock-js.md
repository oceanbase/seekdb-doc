# Amazon Bedrock

Amazon Bedrockは、AWSが提供するマネージド型の大規模言語モデルプラットフォームであり、さまざまな埋め込みモデルをサポートしています。seekdbは`AmazonBedrockEmbeddingFunction`パッケージを提供しており、`documents`への書き込み時や`query_texts`によるクエリ時に、自動的にBedrockを呼び出してベクトルを生成し、類似性検索を実行するために使用できます。

:::tip
Amazon Bedrockサービスの利用には、AWSの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認・同意してください。同意しない場合は、操作を続けないでください。
:::

## 依存関係と認証

使用する前に、AWSアカウントでAmazon Bedrockが有効になっており、対象の埋め込みモデルに対する呼び出し権限が付与されていることを確認してください。

## インストール

```bash
npm i seekdb @seekdb/amazon-bedrock
```

## 例：Amazon Bedrock Embedding Functionを作成する

```typescript
import { AmazonBedrockEmbeddingFunction } from "@seekdb/amazon-bedrock";

const ef = new AmazonBedrockEmbeddingFunction({
  region: "us-east-1",
  modelName: "amazon.titan-embed-text-v2",
});
```

**パラメータ説明：**

- **apiKey**：Bedrock APIキー（オプション。指定しない場合、環境変数から読み取ろうとします）
- **apiKeyEnv**：APIキーの環境変数名（デフォルト：`"AMAZON_BEDROCK_API_KEY"`）
- **region**：AWSリージョン（必須。例：`"us-east-1"`）
- **modelName**：埋め込みモデル名（デフォルト：`"amazon.titan-embed-text-v2"`）
