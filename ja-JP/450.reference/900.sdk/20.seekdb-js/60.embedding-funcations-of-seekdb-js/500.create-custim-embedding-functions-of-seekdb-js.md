# カスタム埋め込み関数の作成

EmbeddingFunctionインターフェースを実装することで、カスタムベクトル関数を作成できます。この関数には、以下の内容が含まれている必要があります。

* `name` プロパティ、`generate` メソッド、`getConfig` メソッド、`buildFromConfig` スタティックメソッドを実装する必要があります。
* その他のインターフェースメソッドをオプションで実装できます。
* カスタム埋め込み関数を登録するには、registerEmbeddingFunctionを使用して、シリアライズ/復元を実装する必要があります。

## 前提条件

カスタム埋め込み関数を作成する際は、以下の点を確認してください：

* `generate` メソッドの実装：

  * 引数: `string[]` (ドキュメントリスト)
  * 戻り値: `Promise<number[][]>` (ベクトルリスト)
  * 各ベクトルは同じ次元を持たなければなりません。

* `name` プロパティの設定：

  * `embeddingFunction` の名前で、一意であること。
  * 引数: `string` (`embeddingFunction` の名前)

* `getConfig` メソッドの設定：

  * 現在の `embeddingFunction` インスタンスが属する設定です。この `embeddingFunction` インスタンスを復元するために使用されます。これはSDK内部のロジックであり、使用方法については気にする必要はありません。
  * 戻り値：`Record<string: any>`

* `buildFromConfig` 静的メソッドの設定：

  * 必要な設定に基づいて、現在の `embeddingFunction` の新しいインスタンスを生成します。これはSDK内部のロジックであり、使用方法については気にする必要はありません。
  * 引数: `Record<string: any>` embeddingFunction インスタンス化に必要な設定。
  * 戻り値: `EmbeddingFunction`

* 端的ケースの処理：

  * 空の入力は空のリストを返す必要があります。
  * 出力されるすべてのベクトルは同じ次元を持たなければなりません。

* `dimension()`: 現在のインスタンスの次元を返します。これはSDK内部のロジックであり、使用方法については気にする必要はありません。

## 例1：文変換器のカスタム埋め込み機能

```js
import { registerEmbeddingFunction } from "seekdb";

interface MyCustomEmbeddingConfig {
  apiKeyEnv: string;
}
class MyCustomEmbeddingFunction implements EmbeddingFunction {
  readonly name = "my_custom_embedding"
  private apiKeyEnv: string;
  dimension: number;

  constructor(config: MyCustomEmbeddingConfig) {
    this.apiKeyEnv = config.apiKeyEnv;
    this.dimension = 384;
  }

  async generate(texts: string[]): Promise<number[][]> {
    // ご自身のベクトル生成ロジックを実装してください
    // 例えば、外部APIやローカルモデルを呼び出すなど
    const embeddings: number[][] = [];

    /**
     *  ここにご自身のベクトル生成コードを記述してください
     */

    return embeddings;
  }

  getConfig(): MyCustomEmbeddingConfig {
    return {
      apiKeyEnv: this.apiKeyEnv,
    };
  }

  static buildFromConfig(config: MyCustomEmbeddingConfig): EmbeddingFunction {
    return new MyCustomEmbeddingFunction(config);
  }
}

// カスタム埋め込み関数を登録します
registerEmbeddingFunction("my_custom_embedding", MyCustomEmbeddingFunction);

// カスタムベクトル関数を使用します
const customEmbed = new MyCustomEmbeddingFunction({
  apiKeyEnv: "MY_CUSTOM_API_KEY_ENV",
});

const collection = await client.createCollection({
  name: "custom_embed_collection",
  configuration: {
    dimension: 384,
    distance: "cosine"
  },
  embeddingFunction: customEmbed
});
```
