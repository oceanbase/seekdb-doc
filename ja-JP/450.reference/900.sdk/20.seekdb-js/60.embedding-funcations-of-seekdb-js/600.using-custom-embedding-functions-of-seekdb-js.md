# カスタム埋め込み関数の使用

カスタム埋め込み関数を作成して登録した後、collectionsの作成または取得時にそれを使用します。

例：

```javascript
import { SeekdbClient } from "seekdb";

const client = new SeekdbClient({
  host: "127.0.0.1",
  port: 2881,
  user: "root",
  password: "",
  database: "test",
});

// カスタムベクトル関数を持つコレクションの作成
const ef = new MyCustomEmbeddingFunction();

const collection = await client.createCollection({
  name: "my_collection",
  configuration: {
    dimension: 384,
    distance: "cosine"
  },
  embeddingFunction: ef
});

// カスタムベクトル関数を持つコレクションの取得
const collection = await client.getCollection({
  name: "my_collection",
  embeddingFunction: ef
});

// コレクションの使用 - ドキュメントは自動的に埋め込まれます
await collection.add({
  ids: ["doc1", "doc2"],
  documents: ["ドキュメント1", "ドキュメント2"],  // ベクトルは自動生成されます
  metadatas: [{ tag: "A" }, { tag: "B" }]
});

// テキストクエリを使用 - クエリベクトルは自動生成されます
const results = await collection.query({
  queryTexts: "私のクエリ",
  nResults: 10
});
```
