# デフォルト埋め込み関数

埋め込み関数は、テキスト文書をベクトル埋め込みに変換し、類似度検索に使用します。seekdb-jsは、組み込みの埋め込み関数とカスタム埋め込み関数をサポートしています。

デフォルトの埋め込み関数は、ローカルモデル（`Xenova/all-MiniLM-L6-v2`）を使用し、APIキーが不要なため、迅速な開発とテストに適しています。使用する前に、まず`@seekdb/default-embed`を手動でインストールする必要があります：

```bash
npm install @seekdb/default-embed
```

インストール完了後、以下の2つの方法でデフォルトの埋め込みロジックを使用できます：

* **方法1**：Collectionを作成する際に`embeddingFunction`を指定しない場合、システムはデフォルトの埋め込み関数を自動的に使用してベクトル化します。

    ```js
    // embeddingFunctionを指定しない場合、デフォルトの埋め込み関数が自動的に使用されます。
    const collection = await client.createCollection({
      name: "local_embed_collection",
    });
    ```

* **方法2**：`DefaultEmbeddingFunction`インスタンスを明示的に指定します（パラメータを通じて埋め込み関数を統一的に指定するのに便利です）。

    ```js
    import { DefaultEmbeddingFunction } from "@seekdb/default-embed";

    const defaultEmbed = new DefaultEmbeddingFunction({
      // ダウンロードに問題が発生した場合、リージョンを切り替えてみてください。デフォルトは'cn'です。
      // region: 'intl'
    });

    const collection = await client.createCollection({
      name: "local_embed_collection",
      embeddingFunction: defaultEmbed,
    });
    ```

初回のベクトル化時には、モデルが自動的にダウンロードされます。所要時間は約3～5分ですが、ネットワーク状況によって異なる場合がありますので、しばらくお待ちください。
