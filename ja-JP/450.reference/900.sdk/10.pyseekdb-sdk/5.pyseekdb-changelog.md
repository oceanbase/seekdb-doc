# pyseekdb 更新記録

## pyseekdb V1.1.0 バージョン

* リリース日：2026年1月30日
* バージョン番号：V1.1.0

### バージョンのハイライト

* Collection名の命名規則がより柔軟に：名称の最大長が64文字から **512文字** に拡張され、より複雑なビジネスシナリオに対応できます。
* 全文検索機能が強化されました：`FulltextIndexConfig`が追加され、カスタム分かち書きとフィールドマッピングをサポートします。
* Embeddingエコシステムが大幅に拡張されました：**11種類** の主流Embeddingプラットフォームが統合され、オープンソースおよび商用モデルをカバーしています。
* メタデータの永続化がアップグレードされました：embedding関数情報をシステムテーブルに永続化できるため、開発者の利便性がさらに向上します。
* table-fork機能（実験的機能）が追加されました：Collectionレベルでのスナップショットレプリケーションをサポートし、データ実験とロールバックを簡素化します。

### 新機能

#### Collection名の最大長の拡張

* 制限の緩和：collection名は **64～512文字** をサポートし、より長いビジネス命名規則に適応します。
* 互換性：以前のバージョンで作成された短い名前のcollectionは影響を受けません。

#### 全文検索の設定（FulltextIndexConfig）

* 新しい構造の設定：`create_collect/get_or_create_collection` インターフェースでは、configurationパラメータを使用してHNSWインデックスの設定だけでなく、全文インデックスの設定もカスタマイズできるようになりました。
* 公式ドキュメント参照：[全文インデックス設定ガイド](https://www.oceanbase.ai/docs/select-vector-index)

#### Embedding関数エコシステムの拡張

* 11種類のembedding関数が統合されました**、以下のプラットフォームをカバーしています：

    * オープンソースモデル：`sentence-transformers`。
    * 商用サービス：OpenAI、Azure、AWS Bedrockなど。
    * すべての統合プラットフォーム、[埋め込み関数](60.embedding-funcations/50.ef-overview-py.md)。

#### Table-Fork機能（実験的機能）

:::tip
seekdb V1.1.0バージョンでは、Fork Table（Collectionのレプリケーション）は実験的機能です。本番環境での使用は慎重に行ってください。今後のバージョンで正式な本番機能へと継続的に改善されます。
:::

* collectionのスナップショットを迅速に作成します。
* 適用シナリオ：
    * 異なるインデックスパラメータのA/Bテスト
    * データのロールバックと災害復旧
    * その他の適用シナリオについては、[Forkテーブル](../../../200.develop/200.design-database-schema/50.fork-table.md)を参照してください。
* パフォーマンスへの影響：fork操作は基盤ストレージの **コピーオンライト（COW）** に基づいており、時間は < 1秒です（データ量に関係ありません）。
