# 埋め込み関数の概要

seekdbでは、**埋め込み関数（Embedding Functions、EF）**は、テキストなどの入力をベクトルに変換し、意味検索（ベクトル類似性検索）などの機能をサポートするために使用されます。seekdbは、さまざまな主流プラットフォーム/モデルの埋め込み関数をカプセル化しており、組み込み実装をそのまま使用することも、インターフェース仕様に従ってカスタム埋め込み関数を実装することもできます。

## 動作方式

Collectionの作成時または取得時に`embedding_function`パラメータを使用してEFをバインドできます。バインド後、Collectionへの書き込みおよびクエリでは、以下のルールに従ってベクトルが自動生成されます：

- **書き込み**：`add` / `update` / `upsert` などのインターフェースを呼び出す際、渡される引数が `documents`（`embeddings` ではない場合）、EFを使用してテキストをベクトルに変換し、それを書き込みます。
- **クエリ**：`query` インターフェースを呼び出す際、渡される引数が `query_texts`（`query_embeddings` ではない場合）、EFを使用してクエリテキストをクエリベクトルに変換し、検索を実行します。

## 典型的な使い方（Collectionへのバインド）

以下の例は、EFとCollectionを典型的にバインドする方法を示しています。ここで `ef` は任意のプラットフォームの埋め込み関数インスタンスに置き換えることができます。

```python
import pyseekdb
# 実装済みのEFを例とします
from pyseekdb.utils.embedding_functions import SomePlatformEmbeddingFunction

# 1. 埋め込み関数の初期化
ef = SomePlatformEmbeddingFunction(api_key="your-api-key")

# 2. コレクション作成時にこの関数をバインド
db = pyseekdb.Client(path="./seekdb.db")
collection = db.create_collection(
    name="my_collection",
    embedding_function=ef
)

# 3. その後の操作では、ベクトル化が自動的に処理されます
# あなたが提供するのはドキュメントのみです。seekdbがefを呼び出して自動的にベクトルを生成し、保存します。
collection.add(
    ids=["1", "2"],
    documents=["Hello world", "How are you?"]
)

# クエリ時も同様に、クエリテキストのみを提供する必要があります
results = collection.query("How are you?", n_results=1)

```

## デフォルトの埋め込み関数：DefaultEmbeddingFunction (all-MiniLM-L6-v2)

Collection作成時に `embedding_function` を指定しなかった場合、seekdbはデフォルトで `DefaultEmbeddingFunction` を使用します。

デフォルトモデルは [Sentence Transformers](https://www.sbert.net/) の `all-MiniLM-L6-v2` (次元384) です。このモデルはローカルで実行され、初回使用時にモデルファイルが自動的にダウンロードされる可能性があります。

```python
import pyseekdb

db = pyseekdb.Client(path="./seekdb.db")

# embedding_functionが指定されていない場合、デフォルトでDefaultEmbeddingFunctionが使用されます
collection = db.create_collection(name="default_collection")

```

デフォルトの埋め込み関数の詳細については、[デフォルトの埋め込み関数](../60.embedding-funcations/100.default-embedding-function-of-api.md)を参照してください。

## カスタム埋め込み関数

組み込みの埋め込み関数では要件を満たせない場合、`EmbeddingFunction` プロトコルを実装してカスタムEFを作成できます。カスタムEFは以下の制約を満たす必要があります：

- `__call__` メソッドを実装する：入力は `str | List[str]`、戻り値は `List[List[float]]`
-（推奨）`dimension` プロパティを実装する：返されるベクトルの次元（`int`）を返し、collection作成時の一貫性検証に役立てる

以下は最小限の例です：

```python
from typing import List, Union
from pyseekdb import EmbeddingFunction

Documents = Union[str, List[str]]
Embeddings = List[List[float]]

@register_embedding_function
class MyCustomEmbeddingFunction(EmbeddingFunction[Documents]):
    def __init__(self, model_name: str = "my-model"):
        self.model_name = model_name

    def __call__(self, input: list[str] | str) -> list[list[float]]:
        # ここでベクトル化ロジックを実装します（例えば、内部モデルサービスを呼び出す）
        return [[0.1, 0.2, 0.3] for _ in (input if isinstance(input, list) else [input])]

    @property
    def dimension(self) -> int:
        return 3  # このモデルの次元に置き換えてください

    @staticmethod
    def name() -> str:
        return "my_custom_embedding"

    def get_config(self) -> Dict[str, Any]:
        return {"model_name": self.model_name}

    @staticmethod
    def build_from_config(config: Dict[str, Any]) -> "MyCustomEmbeddingFunction":
        return MyCustomEmbeddingFunction(model_name=config.get("model_name", "my-model"))

```
