# Google Vertex AI

Google Vertex AIは、さまざまなテキスト埋め込みモデルを提供しています。seekdbは `GoogleVertexEmbeddingFunction` パッケージを提供し、`documents` の書き込み時や `query_texts` でのクエリ実行時に、Vertex AIを自動的に呼び出してベクトルを生成し、類似性検索を完了するために使用されます。

:::tip
Google Vertex AIサービスの利用には、Google Cloudの料金規則が適用され、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご確認いただくか、関連ドキュメントを参照して、その料金体系を確認し、同意してください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

`GoogleVertexEmbeddingFunction` は、Google Vertex AIのSDKを通じて埋め込みインターフェースを呼び出します。通常、以下が必要です：

- Google Cloud / Vertex AIが有効になっており、埋め込みモデルを呼び出す権限が付与されていること。
- Python環境に `pyseekdb` と `google-cloud-aiplatform` がインストールされていること。
- Google Application Default Credentialsが設定されていること。

## 例：Google Vertex Embedding Functionを作成する

```python
from pyseekdb.utils.embedding_functions import GoogleVertexEmbeddingFunction

ef = GoogleVertexEmbeddingFunction(
    project_id="your-project-id",
    model_name="textembedding-gecko",
)
```

**パラメータ説明：**

* `project_id`：Google CloudプロジェクトID。
* `model_name`：Vertex AI埋め込みモデル名。例では `textembedding-gecko` です。ご利用のプロジェクトで利用可能なモデルを選択してください。
