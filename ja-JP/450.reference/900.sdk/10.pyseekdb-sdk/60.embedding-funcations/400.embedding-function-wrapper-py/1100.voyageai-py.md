# VoyageAI

VoyageAI EmbeddingFunctionは、seekdbが多様なAIエコシステムをサポートするために設計した埋め込みアダプターの一つです。seekdbはAIネイティブのハイブリッド検索データベースであり、ベクトル、全文、構造化データ、半構造化データのストレージと検索を統一的にサポートすることが最大の強みです。このような埋め込み関数を利用することで、開発者は外部の優れた埋め込みサービス（例：VoyageAI）を簡単に呼び出し、seekdbに強力な意味理解機能を付与することができます。これにより、より高精度なRAGシステムやエージェントメモリベースなどのアプリケーションを構築できます。

:::tip
VoyageAIサービスの利用には、VoyageAIの料金規則に従う必要があり、それに応じた費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認してご同意いただいてください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

* pyseekdbライブラリがインストール済みであること。

* 有効な[VoyageAI APIキー](https://www.voyageai.com/)があり、認証に使用されます。

## 例：VoyageAI Embedding Functionの作成

コード内で `VoyageAIEmbeddingFunction` をインポートして初期化します。通常、パラメータは環境変数を通じて管理し、本番環境での柔軟なデプロイを実現します。

* 基本的な使い方

    環境変数の `VOYAGE_API_KEY` を使用してモデルを指定します。`voyage-4-large` モデルはVoyage AIのフラッグシップ汎用モデルで、長文脈と高精度検索をサポートします。

    ```python
    from pyseekdb.utils.embedding_functions import VoyageaiEmbeddingFunction

    ef = VoyageaiEmbeddingFunction(
        model_name="voyage-4-large"  # 埋め込みモデルの指定
    )
    ```

* 上級者向けの使い方

    RAGシナリオでは、`input_type` を指定して検索シナリオを選択します。検索シナリオには「ドキュメント」と「クエリ」の2種類のベクトル化戦略があります。

    ```python
    from pyseekdb.utils.embedding_functions import VoyageaiEmbeddingFunction

    ef = VoyageaiEmbeddingFunction(
        model_name="voyage-4-large",
        input_type="document"  # "document"または"query"を指定可能。コレクション内のドキュメントを設定する際は通常 "document" を使用
    )
    ```

* カスタム設定

    `voyage-4-large` などのモデルを使用する場合、生成されるベクトルの次元を1024から512に削減できます。精度を維持しつつ、ストレージコストを大幅に削減し、検索速度を向上させることができます。

    ```python
    from pyseekdb.utils.embedding_functions import VoyageaiEmbeddingFunction

    ef = VoyageaiEmbeddingFunction(
        model_name="voyage-4-large",
        output_dimension=512  # 次元を削減してストレージと計算の効率を最適化
    )
    ```

**パラメータ説明：**

* `model_name`：VoyageAIモデル名。例：`voyage-3-large`、`voyage-4-large`。

* `api_key_env`：APIキーが存在する環境変数名。デフォルトは `VOYAGE_API_KEY`。

* `input_type`：入力タイプのヒントで、検索結果を最適化するために使用されます。一般的な値：

  * `documents`：ドキュメントのインデックス作成（documents）に使用されます。

  * `metadatas`：クエリ（query texts）に使用されます。
