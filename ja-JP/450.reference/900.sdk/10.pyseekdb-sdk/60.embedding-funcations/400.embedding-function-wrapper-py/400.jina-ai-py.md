# Jina AI

Jina AIはさまざまなEmbeddingモデルを提供しています。seekdbは、`JinaEmbeddingFunction`（LiteLLMベース）を提供し、`documents`への書き込み時や`query_texts`でのクエリ実行時に、自動的にベクトルを生成して類似性検索を完了します。

:::tip
Jina AIサービスを利用するには、Jina AIの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか関連ドキュメントを確認し、その料金体系を確認・同意してください。同意しない場合は、操作を続けないでください。
:::

## 依存関係と認証

`JinaEmbeddingFunction`はLiteLLMを基に、Jina AIのEmbeddingインターフェースを呼び出します。通常、以下が必要です：

- Jina AI API Key（Embeddingモデルを呼び出す権限を持つこと）
- Python環境に`pyseekdb`と`litellm`をインストール済みであること

認証は通常、環境変数によって提供されます（デフォルトでは`JINA_API_KEY`が読み取られます）。異なる環境変数名を使用している場合は、`api_key_env`で指定できます。

## 例：Jina Embedding Functionの作成

* 基本使用法

    ```python
    from pyseekdb.utils.embedding_functions import JinaEmbeddingFunction

    ef = JinaEmbeddingFunction(model_name="jina-embeddings-v2-base-en")
    ```

* 多言語モデル

    ```python
    from pyseekdb.utils.embedding_functions import JinaEmbeddingFunction

    ef = JinaEmbeddingFunction(model_name="jina-embeddings-v2-base-multilingual")
    ```

* API Key環境変数名の指定（api_key_env）

    API Keyがデフォルトの`JINA_API_KEY`環境変数に含まれていない場合、`api_key_env`で変数名を指定できます：

    ```python
    from pyseekdb.utils.embedding_functions import JinaEmbeddingFunction

    ef = JinaEmbeddingFunction(
        model_name="jina-embeddings-v2-base-en",
        api_key_env="JINA_API_KEY",
    )
    ```

**パラメータ説明：**

* `model_name`：Jina AI Embeddingモデル名。例：`jina-embeddings-v2-base-en`、`jina-embeddings-v2-base-multilingual`。
* `api_key_env`：API Keyが存在する環境変数名。デフォルトは`JINA_API_KEY`です。
