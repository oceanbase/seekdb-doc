# Qwen

Qwen Embedding モデルは、Qwen シリーズの最新の専用モデルであり、テキスト埋め込みとランキングタスク向けに設計されています。このシリーズは Qwen3 シリーズの密ベースモデルを基盤とし、0.6B から 8B までの異なるパラメータ規模のモデルを提供しており、軽量エッジデプロイから高性能データセンターまでのあらゆるシナリオニーズをカバーしています。その核心的な利点は、ベースモデルが備える優れた多言語対応（100 を超える言語と複数のプログラミング言語をサポート）、長文理解（最大 32K のコンテキストウィンドウ）、そして強力な論理推論能力を継承していることです。

:::tip
Qwen サービスの利用には、第三者プラットフォームの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式サイトをご覧いただくか関連ドキュメントを確認し、その料金体系を確認・ご同意いただきますようお願いいたします。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

* pyseekdb ライブラリがインストール済みであること。

* Dashscope API Key を作成し、認証に使用すること。

## 例：Qwen Embedding Function の作成

コード内で `QwenEmbeddingFunction` をインポートし、初期化します。通常、API Key は環境変数で管理されます。

* 基本的な使い方

    モデル名を指定し、デフォルトの環境変数 `DASHSCOPE_API_KEY` を使用して初期化します。

    ```python
    from pyseekdb.utils.embedding_functions import QwenEmbeddingFunction

    # text-embedding-v1 モデルを使用
    ef = QwenEmbeddingFunction(
        model_name="text-embedding-v1"
    )
    ```

* 上級者向けの使い方とカスタム設定

    API Key の環境変数名をカスタマイズし、モデルのバージョンに応じて `dimensions`、`timeout` などのパラメータを設定します。

    ```python
    from pyseekdb.utils.embedding_functions import QwenEmbeddingFunction

   # 環境変数名をカスタマイズし、タイムアウトを設定
    ef = QwenEmbeddingFunction(
        model_name="text-embedding-v1",
        api_key_env="DASHSCOPE_API_KEY",
        timeout=30
    )

    # 動的次元のモデルを使用し、出力次元を 512 に指定
    ef = QwenEmbeddingFunction(
        model_name="text-embedding-v3",
        dimensions=512  # デフォルトの 1024 から 512 に減らす
    )
    ```

**パラメータ説明：**

* `model_name`：Qwen Embedding モデル名。例：`text-embedding-v1`、`text-embedding-v3`。指定しない場合、デフォルトは `text-embedding-v1` です。
* `api_key_env`：API Key が存在する環境変数名。デフォルトは `DASHSCOPE_API_KEY` です。
* `timeout`：リクエストのタイムアウト時間（秒）。オプションです。
* `dimensions`：出力ベクトルの次元（モデルが動的次元をサポートする場合にのみ有効になります。例えば、`text-embedding-v3` はデフォルトの 1024 からより小さい値に調整できます）。オプションです。
