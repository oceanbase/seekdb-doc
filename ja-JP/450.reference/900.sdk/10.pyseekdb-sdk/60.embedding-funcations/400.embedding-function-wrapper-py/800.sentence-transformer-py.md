# Sentence Transformer

Sentence Transformerは、文、フレーズ、または短いテキストを高次元ベクトル（埋め込みとも呼ばれる）に変換するための深層学習フレームワークです。そのコアな考え方は、意味的に類似した文同士がベクトル空間上で近距離にあり、意味的に異なる文同士が遠距離にあるようにすることで、ベクトル間のコサイン類似度やユークリッド距離を計算することで文の意味的類似度を判断できるようにすることです。このフレームワークは、強力な事前学習済みTransformerモデル（BERT、RoBERTaなど）を基盤として構築されており、平均プーリングやCLSプーリングなどのプーリング戦略を用いて、すべての単語のベクトルを固定サイズの文レベルベクトルに統合します。これは、意味検索、テキストクラスタリング、文分類、情報検索、検索拡張生成（RAG）などのシナリオで広く利用されています。

## 依存関係と認証

使用する前に、pyseekdbとsentence-transformersライブラリがインストールされていることを確認してください。

* sentence-transformersライブラリは、モデルのロードやエンコードなどのコア機能をカプセル化しています。

* Sentence Transformerは通常ローカルで実行されます。初回使用時にモデルを指定すると、その事前学習済み重みがHugging Face Hubから自動的にダウンロードされ、ローカルにキャッシュされるため、追加のAPIキー認証は不要です。

## 例：SentenceTransformer Embedding Functionを作成する

コード内で`SentenceTransformerEmbeddingFunction`をインポートし、初期化します。モデル名を指定するだけで簡単に初期化できます。`all-MiniLM-L6-v2` モデルは軽量で効率的な汎用モデルで、ほとんどのシナリオに適しています。

```python
from pyseekdb.utils.embedding_functions import SentenceTransformerEmbeddingFunction

ef = SentenceTransformerEmbeddingFunction(model_name="all-MiniLM-L6-v2")
db = pyseekdb.Client(
    path="./seekdb.db"
)
collection = db.create_collection(name="my_collection", embedding_function=ef)
```

**パラメータ説明：**

* `model_name`：Sentence Transformerモデル名。例：`all-MiniLM-L6-v2`、`paraphrase-multilingual-MiniLM-L12-v2`。

* `name`：コレクションの名前。必須パラメータで、デフォルトは `my_collection` です。

* `embedding_function`：埋め込み関数。通常はテキストをベクトルに変換するモデル関数で、デフォルトは `ef` です。
