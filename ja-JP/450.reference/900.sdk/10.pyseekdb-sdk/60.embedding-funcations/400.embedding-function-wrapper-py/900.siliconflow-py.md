# SiliconFlow

SiliconFlowは、さまざまなトップクラスのオープンソース大規模言語モデルを集約したワンストップクラウドサービスプラットフォームです。そのEmbeddingサービスは、一連の高性能な意味ベクトルモデルを提供しており、大規模言語モデル検索拡張（RAG）、検索、レコメンデーションなどのシナリオで広く利用されています。プラットフォーム上のモデル、例えばBGEシリーズやQwen Embeddingシリーズは、優れた意味表現能力を備えており、一部のモデル、例えばQwen3-Embeddingは、精度とストレージコストのバランスを取るために出力次元を柔軟に調整することもサポートしています。

:::tip
SiliconFlowサービスを利用するには、SiliconFlowの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか関連ドキュメントを確認し、その料金体系を確認してご同意いただきますようお願いいたします。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

* pyseekdbライブラリがインストール済みであること。

* [SiliconFlowプラットフォーム](https://siliconflow.cn/)にアカウントを登録し、API管理ページでAPIキーを作成する必要があります。これは、認証および課金に使用されます。

## 例：SiliconFlow Embedding Functionの作成

コード内で `SiliconflowEmbeddingFunction` をインポートし、初期化します。通常、APIキーは環境変数で管理されます。

* 基本的な使い方

    モデル名を指定し、デフォルトの環境変数 `SILICONFLOW_API_KEY` を使用して初期化します。

    ```python
    from pyseekdb.utils.embedding_functions import SiliconflowEmbeddingFunction

    ef = SiliconflowEmbeddingFunction(
        model_name="BAAI/bge-large-zh-v1.5"
    )
    ```

* 上級者向けの使い方とカスタム設定

    `api_key_env` でカスタムの環境変数名を指定し、モデルの特性に応じて `dimensions`、`timeout` などのパラメータを設定します。

    ```python
    from pyseekdb.utils.embedding_functions import SiliconflowEmbeddingFunction

   # BGE-M3モデルを使用し、カスタム環境変数名を設定
    ef = SiliconflowEmbeddingFunction(
        model_name="BAAI/bge-m3",
        api_key_env="SILICONFLOW_API_KEY",
        timeout=30
    )

    # Qwen3-Embeddingモデルを使用し、出力次元を1024に指定
    ef = SiliconflowEmbeddingFunction(
        model_name="Qwen/Qwen3-Embedding-8B",
        dimensions=1024  # デフォルトの4096から1024に減らす
    )
    ```

**パラメータ説明：**

* `model_name`：SiliconFlow Embeddingモデル名。例：`BAAI/bge-large-zh-v1.5`、`Qwen/Qwen3-Embedding-0.6B`。
* `api_key_env`：API Keyが存在する環境変数名。デフォルトは `SILICONFLOW_API_KEY`。
* `timeout`：リクエストのタイムアウト時間（秒）。オプションです。
* `dimensions`：出力ベクトルの次元（モデルが動的次元をサポートする場合にのみ有効になります。例えば、`Qwen/Qwen3-Embedding-8B` はデフォルトの4096からより小さい値に調整できます）。オプションです。
