# OpenAI

OpenAI Embedding モデルは、自然言語処理分野における中核的なツールであり、テキスト（単語、文、段落）を高次元ベクトル（埋め込み）に効率的に変換することができます。これらのベクトルは、text-embedding-3-large などの高性能な事前学習済みモデルによって生成され、ユーザーが追加の訓練を行うことなく、テキストの意味情報を深く捉えることができます。その核心的な原理は、元のテキストを密なベクトル空間にマッピングし、ベクトル間の距離（例えばコサイン類似度）を計算することで、テキスト間の意味的類似性を容易に測定できる点です。この技術は、意味検索、インテリジェントQ&A、テキストクラスタリングと分類、レコメンデーションシステムの強化、検索拡張生成（RAG）などのシナリオで広く利用されています。

:::tip
OpenAI サービスの利用には、OpenAI の料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式ウェブサイトをご覧いただくか関連ドキュメントを確認し、その料金体系を確認してご同意いただくようお願いいたします。同意できない場合は、操作を続けないでください。

## 依存関係と認証

* pyseekdb と openai ライブラリがインストール済みであること。openai は OpenAI が公式に提供する Python SDK です。

* [OpenAI Platform](https://platform.openai.com/) に登録し、API キーを作成しておく必要があります。その後、このキーを環境変数に設定し、`OpenAIEmbeddingFunction` が読み取り使用できるようにします。

## 例：OpenAI Embedding Function を作成する

コード内で `OpenAIEmbeddingFunction` をインポートして初期化します。通常、API キーは環境変数で管理されます。

* 基本的な使い方

    モデル名を指定しない場合、デフォルトで `text-embedding-3-small` モデルが使用されます。

    ```python
    from pyseekdb.utils.embedding_functions import OpenAIEmbeddingFunction

    # デフォルトモデル text-embedding-3-small とデフォルト環境変数 OPENAI_API_KEY を使用
    ef = OpenAIEmbeddingFunction()
    ```

* 上級者向けの使い方とカスタム設定

    API キーの環境変数名をカスタマイズし、モデルのバージョンに応じて `dimensions`、`timeout` などのパラメータを設定します。

    ```python
    from pyseekdb.utils.embedding_functions import OpenAIEmbeddingFunction

    # 経済的なモデルを使用
    ef = OpenAIEmbeddingFunction(model_name="text-embedding-3-small")

    # 高精度モデルを使用し、タイムアウトとリトライ戦略を設定
    ef = OpenAIEmbeddingFunction(
        model_name="text-embedding-3-large",
        timeout=30,
        max_retries=3
    )

    # 動的次元モデルを使用し、出力次元を 512 に指定
    ef = OpenAIEmbeddingFunction(
        model_name="text-embedding-3-small",
        dimensions=512  # デフォルトの 1536 から 512 に減らす
    )
    ```

**パラメータ説明：**

* `model_name`：OpenAI Embedding モデル名。例：`text-embedding-3-small`、`text-embedding-3-large`。指定しない場合、デフォルトは `text-embedding-3-small` です。
* `api_key_env`：API Key が存在する環境変数名。デフォルトは `OPENAI_API_KEY` です。
* `timeout`：リクエストのタイムアウト時間（秒）。オプションです。
* `max_retries`：リクエスト失敗時の最大リトライ回数。オプションです。
* `dimensions`：出力ベクトルの次元（モデルが動的次元をサポートする場合にのみ有効。例えば `text-embedding-3-small` はデフォルトの 1536 からより小さい値に調整可能）。オプションです。
