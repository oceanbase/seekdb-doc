# Amazon Bedrock

Amazon Bedrockは、AWSが提供するマネージド型の大規模言語モデルプラットフォームであり、さまざまな埋め込みモデルをサポートしています。seekdbはAmazon BedrockのEmbedding Functionをカプセル化し、`documents`への書き込み時や`query_texts`によるクエリ実行時に、自動的にBedrockを呼び出してベクトルを生成し、類似性検索を完了できるようにします。

:::tip
Amazon Bedrockサービスの利用には、AWSの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか関連ドキュメントを確認し、その料金体系を確認・同意してください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

`AmazonBedrockEmbeddingFunction`は、`boto3`を通じてAmazon BedrockのEmbeddingインターフェースを呼び出すため、以下が必要です：

- AWSアカウントでAmazon Bedrockが有効になっており、対象のEmbeddingモデルに対する呼び出し権限が付与されていること。
- AWS認証情報が`boto3`のデフォルトの認証チェーン（環境変数、共有認証ファイル、IAMロールなど）に設定されていること。
- ローカルPython環境に`pyseekdb`と`boto3`がインストールされていること。

## 例：Amazon Bedrock Embedding Functionの作成

```python
import boto3
from pyseekdb.utils.embedding_functions import AmazonBedrockEmbeddingFunction

# boto3セッションを明示的に作成
session = boto3.Session(profile_name="profile", region_name="us-east-1")

ef = AmazonBedrockEmbeddingFunction(
    session=session,
    model_name="amazon.titan-embed-text-v2",
)
```

**パラメータ説明：**

- `session`：`boto3.Session`インスタンス。認証とリージョン設定に使用されます。
- `model_name`：Amazon BedrockのEmbeddingモデル名。例では`amazon.titan-embed-text-v2`を使用しています。アカウントの権限とモデルの可用性に応じて調整可能です。

:::tip
Amazon Bedrockで利用可能なモデルとリージョンサポートは、AWSの更新に伴って変更される場合があります。詳細については、Amazon Bedrockの公式ドキュメントを参照してください：`https://docs.aws.amazon.com/bedrock/`。
:::
