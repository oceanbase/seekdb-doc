# Ollama

Ollamaは、オープンソースモデルのローカル実行と管理をサポートし、Embeddingの生成に使用できるOpenAI互換のAPIを提供します。seekdbは`OllamaEmbeddingFunction`パッケージを提供しており、OpenAI互換インターフェースを通じてOllamaのembeddingモデルを呼び出すことができます。

:::tip
Ollamaサービスの利用には、Ollamaの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか関連ドキュメントを確認し、その料金体系を確認・同意してください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と環境

`OllamaEmbeddingFunction`はOpenAI互換インターフェースを通じてOllamaのembeddingモデルを呼び出します。通常、以下が必要です：

- Ollamaがインストールされ、起動していること。
- ターゲットモデルがローカルにプルされていること（使用前に`ollama pull <model_name>`が必要です）。例：

    ```shell
    ollama pull nomic-embed-text
    ```

- Python環境に`pyseekdb`と`openai`がインストールされていること。

## 例：Ollama Embedding Functionの作成

* 基本使用法

    ```python
    from pyseekdb.utils.embedding_functions import OllamaEmbeddingFunction

    ef = OllamaEmbeddingFunction(model_name="nomic-embed-text")
    ```

* リモートOllamaへの接続（カスタムapi_base）

    ```python
    from pyseekdb.utils.embedding_functions import OllamaEmbeddingFunction

    ef = OllamaEmbeddingFunction(
        model_name="nomic-embed-text",
        api_base="http://remote-server:11434/v1",
        timeout=30,
    )
    ```

* Dimensionsの指定（モデルがサポートする場合に使用可能）

    ```python
    from pyseekdb.utils.embedding_functions import OllamaEmbeddingFunction

    ef = OllamaEmbeddingFunction(
        model_name="nomic-embed-text",
        dimensions=512,
    )
    ```

**パラメータ説明：**

* `model_name`：ローカルにプルされたモデル名。例えば、`nomic-embed-text`などです。
* `api_base`：OpenAI互換のOllama APIベースアドレス。ローカルではデフォルトで`http://localhost:11434/v1`が使用されますが、リモートでは実際のアドレスに置き換える必要があります。
* `timeout`：リクエストのタイムアウト時間（秒）。
* `dimensions`：出力ベクトルの次元数（選択したモデルまたはサーバー側がサポートする場合にのみ有効）。
