# Cohere

Cohereは、テキストの意味検索、クラスタリング、レコメンデーションなどのシナリオで利用できるさまざまな埋め込みモデルを提供しています。seekdbは、LiteLLMに基づく`CohereEmbeddingFunction`パッケージを提供しており、`documents`への書き込み時や`query_texts`でのクエリ実行時に、自動的にCohereを呼び出してベクトルを生成し、類似性検索を完了します。

:::tip
Cohereサービスを利用するには、Cohereの料金規則に従う必要があり、それに伴う費用が発生する場合があります。続行する前に、公式Webサイトをご覧いただくか、関連ドキュメントを確認し、その料金体系を確認・ご承諾ください。同意できない場合は、操作を続けないでください。
:::

## 依存関係と認証

`CohereEmbeddingFunction`はLiteLLMをベースにCohereのEmbeddingインターフェースを呼び出します。通常、以下が必要です：

- Cohere APIキー（Embeddingモデルを呼び出す権限が付与されていること）
- Python環境に`pyseekdb`と`litellm`をインストールしていること

認証は通常環境変数によって提供されます（デフォルトでは`COHERE_API_KEY`が読み込まれます）。異なる環境変数名を使用している場合は、`api_key_env`で指定できます。

## 例：Cohere Embedding Functionの作成

* 基本使用法

    ```python
    from pyseekdb.utils.embedding_functions import CohereEmbeddingFunction

    ef = CohereEmbeddingFunction(model_name="embed-english-v3.0")
    ```

* 多言語モデル

    ```python
    from pyseekdb.utils.embedding_functions import CohereEmbeddingFunction

    ef = CohereEmbeddingFunction(model_name="embed-multilingual-v3.0")
    ```

* APIキーの環境変数名の指定（api_key_env）

    APIキーがデフォルトの`COHERE_API_KEY`環境変数にない場合は、`api_key_env`で変数名を指定できます：

    ```python
    from pyseekdb.utils.embedding_functions import CohereEmbeddingFunction

    ef = CohereEmbeddingFunction(
        model_name="embed-english-v3.0",
        api_key_env="YOUR_API_KEY_ENV",
    )
    ```

* input_typeの指定（検索シナリオでの使用を推奨）

    検索系のシナリオでは、`input_type`を使用してモデルに現在の入力の用途を示唆することで、検索により適したベクトル表現を得ることができます：

    ```python
    from pyseekdb.utils.embedding_functions import CohereEmbeddingFunction

    ef = CohereEmbeddingFunction(
        model_name="embed-english-v3.0",
        input_type="search_document",
    )

    # ef = CohereEmbeddingFunction(
    #     model_name="embed-english-v3.0",
    #     input_type="search_query",
    # )
    ```

**パラメータ説明：**

* `model_name`：Cohere Embeddingモデル名。例：`embed-english-v3.0`、`embed-multilingual-v3.0`。
* `api_key_env`：APIキーが存在する環境変数名。デフォルトは`COHERE_API_KEY`。
* `input_type`：入力タイプのヒント。検索結果を最適化するために使用されます。一般的な値：
  * `search_document`：ドキュメントのインデックス作成（documents）に使用されます。
  * `search_query`：クエリ（query texts）に使用されます。
