## pyseekdb

pyseekdbは、OceanBaseが提供するPythonクライアントです。一連のAPIを基盤として実装されており、2種類のデータベース接続モードを提供します。組み込みモードのseekdbへの接続や、リモートサーバーへの接続（サーバーモードのseekdbおよびOceanBaseデータベースへの接続）をサポートしています。

:::tip
OceanBaseデータベースは、OceanBaseが提供する完全に独自開発されたエンタープライズ向けネイティブ分散型データベースです。一般的なハードウェア上で金融級の高可用性を実現し、「三地五中心」という都市レベルの障害に対する自動無損失ディザスタリカバリの新標準を確立しました。TPC-Cベンチマークテストで新記録を樹立し、単一クラスタで1,500ノードを超える規模をサポートします。クラウドネイティブ、強整合性、Oracle/MySQLとの高い互換性などの特徴を備えています。OceanBaseデータベースの詳細については、[OceanBaseデータベース](https://en.oceanbase.com/docs/oceanbase-database)を参照してください。
:::

pyseekdbは現在、Linux、macOS、Windowsシステムでの使用をサポートしています。異なるOSでサポートされているデータベース接続モードは一部異なります。詳細は次の表を参照してください。

| システム | 埋め込み型seekdb | サーバー型seekdb | サーバー型OceanBaseデータベース |
| ---- | ------- | ------- | ------- |
| Linux | サポート | サポート | サポート |
| macOS | サポート | サポート | サポート |
| Windows | 現在はサポートされていません | サポート | サポート |

Linuxシステムにこのクライアントをインストールすると、組み込みモードのseekdbも同時にインストールされ、組み込みseekdbに直接接続してデータベース作成などの操作を実行できます。また、既にデプロイ済みのサーバーモードのseekdbやOceanBaseデータベースにリモート接続することも選択できます。

## pyseekdbのインストール

### 前提条件

環境が以下の要件を満たしていることを確認してください：

* OS：Linux (glibc >= 2.28)、macOS、Windows
* Pythonバージョン：Python 3.11以降
* システムアーキテクチャ：x86_64、aarch64

### インストール

pipを使用してインストールすると、デフォルトのPythonバージョンとプラットフォームが自動的に認識されます。

```shell
pip install -U pyseekdb
```

pipのバージョンが古い場合は、まずpipをアップグレードしてからインストールしてください。

```bash
pip install --upgrade pip
```
