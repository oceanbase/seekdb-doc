# delete - データの削除

`delete()`は、コレクションからレコードを削除するために使用します。ID、メタデータフィルター、またはドキュメントフィルターで削除できます。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール手順の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

* クライアントモードのseekdbまたはOceanBaseデータベースを使用している場合は、操作対象のテーブルに対する`DELETE`権限を持つユーザーであることを確認してください。現在のユーザー権限の確認方法については、[ユーザー権限の確認](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980135)を参照してください。該当する権限を持っていない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限の付与方法については、[直接権限付与](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980140)を参照してください。

## リクエストパラメータ

```python
Upsert(
    ids=ids,
    embeddings=embeddings,
    documents=documents,
    metadatas=metadatas
)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|stringまたはList[str] |オプション|削除するID。単一でも配列でも可能です。|item1|
|`where`|dict|オプション|Metadataのフィルター条件。|`{"category": {"$eq": "AI"}}`|
|`where_document`|dict|オプション|Documentのフィルター条件。|`{"$contains": "obsolete"}`|

:::info

`id`、`where`、または`where_document`のうち、少なくとも1つは指定する必要があります。

:::

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

collection = client.get_collection("my_collection")

# Delete by IDs
collection.delete(ids=["item1", "item2", "item3"])

# Delete by single ID
collection.delete(ids="item1")

# Delete by metadata filter
collection.delete(where={"category": {"$eq": "AI"}})

# Delete by comparison operator
collection.delete(where={"score": {"$lt": 50}})

# Delete by document filter
collection.delete(where_document={"$contains": "obsolete"})

# Delete with combined filters
collection.delete(
    where={"category": {"$eq": "AI"}},
    where_document={"$contains": "deprecated"}
)
```
