# update - データの更新

`update()`は、collection内の既存レコードを更新するために使用します。レコードを更新する際には、そのレコードが存在していなければなりません。存在しない場合は、エラーが発生します。

:::info

このインターフェースは、Client接続を使用する場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

* クライアントモードのseekdbまたはOceanBaseデータベースを使用している場合は、操作対象のテーブルに対する`UPDATE`権限を持つユーザーであることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980135)を参照してください。該当する権限を持っていない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限に関する操作については、[直接権限の付与](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980140)を参照してください。

## リクエストパラメータ

```python
update(
    ids=ids,
    embeddings=embeddings,
    documents=documents,
    metadatas=metadatas
)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`ids`|stringまたはList[str] |必須|変更するID。単一のIDでも、複数のIDを指定する配列でもかまいません。|item1|
|`embeddings`|List[float]またはList[List[float]]|オプション|新しいベクトル。指定されている場合は、そのベクトルが直接使用されます（`embedding_function`は無視されます）。指定されていない場合は、ドキュメントを提供することで自動的にベクトルが生成されます。|[[0.9, 0.8, 0.7], [0.6, 0.5, 0.4]]|
|`documents`|stringまたはList[str]|オプション|新しいドキュメント。`vectors`が指定されていない場合、`documents`はコレクションの`embedding_function`を使用してベクトルに変換されます。"New document text"|
|`metadatas`|dictまたはList[dict]|オプション|新しいメタデータ。|`{"category": "AI"}`|

:::info

メタデータのみの更新をサポートします。使用する`embedding_function`はコレクションに関連付けられている必要があります。

:::

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

collection = client.get_collection("my_collection")
collection1 = client.get_collection("my_collection1")

# Update single item
collection.update(
    ids="item1",
    metadatas={"category": "AI", "score": 98}  # Update metadata only
)

# Update multiple items
collection.update(
    ids=["item1", "item2"],
    embeddings=[[0.9, 0.8, 0.7], [0.6, 0.5, 0.4]],  # Update embeddings
    documents=["Updated document 1", "Updated document 2"]  # Update documents
)

# Update with documents only - embeddings auto-generated by embedding_function
# Requires: collection must have embedding_function set
collection1.update(
    ids="doc1",
    documents="New document text",  # Embeddings will be auto-generated
    metadatas={"category": "AI"}
)
```
