# データベース管理

データベース（Database）には、複数のテーブルやインデックス、およびデータベースオブジェクトのメタデータ情報が含まれます。ユーザーは自身のニーズに応じて、データベースを作成、クエリ、削除することができます。

collectionに対する操作では、以下のAPIを利用できます。

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `create_database()` | データベースを作成します。 | [ドキュメント](200.create-database-of-api.md) |
| `get_database()` | 指定したデータベースを取得します。 |[ドキュメント](300.get-database-of-api.md)|
| `list_databases()`  | インスタンス内のデータベースリストを取得します。  |[ドキュメント](400.list-database-of-api.md)|
| `delete_database()`  | 指定したデータベースを削除します。|[ドキュメント](500.delete-database-of-api.md)|
