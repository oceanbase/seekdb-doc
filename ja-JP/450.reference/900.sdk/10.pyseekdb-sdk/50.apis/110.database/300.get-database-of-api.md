# get_database - 指定データベースの取得

`get_database()`は、指定されたデータベース情報を取得するために使用されます。

:::info

このインターフェースは、`AdminClient`接続時にのみ使用できます。`AdminClient`の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続の詳細な操作については、[Admin Client](../100.admin-client.md)を参照してください。

## リクエストパラメータ

```python
get_database(name, tenant=DEFAULT_TENANT)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のデータベース名を指定します。|`my_database`|
|`tenant`|string|オプション<ul><li>組み込みseekdbおよびサーバーモードseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータは必須です。</li></ul>|作成するデータベースが属するテナントを指定します。|test_tenant|

## リクエスト例

```python
import pyseekdb

# Embedded mode
admin = pyseekdb.AdminClient(path="./seekdb")

# Get database
db = admin.get_database("my_database")
# print(f"Database: {db.name}, Charset: {db.charset}, collation:{db.collation}, metadata:{db.metadata}")
```

## レスポンスパラメータ

|パラメータ|戻り値の型|必須|説明|実行例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のデータベース名。|`my_database`|
|`tenant`|string|オプション<br/>組み込みseekdbおよびサーバーモードseekdbを使用する場合は、このパラメータはありません。|クエリ対象のデータベースが属するテナント。|`test_tenant`|
|`charset`|string|オプション|クエリ対象のデータベースで使用される文字セット。|`utf8mb4`|
|`collation`|string|オプション|クエリ対象のデータベースで使用される照合順序。|`utf8mb4_general_ci`|
|`metadata`|dict|オプション|予約フィールドです。現在データはありません。| {} |

## レスポンス例

```python
Database: my_database, Charset: utf8mb4, collation:utf8mb4_general_ci, metadata:{}
```
