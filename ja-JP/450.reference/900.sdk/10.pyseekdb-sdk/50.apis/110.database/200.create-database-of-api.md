# create_database - データベースの作成

`create_database()`は新しいデータベースを作成するために使用されます。

:::info
* このインターフェースは `AdminClient` 接続時にのみ使用できます。`AdminClient` の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

* 現在、`create_database` でデータベースを作成する際には、データベースのプロパティを指定することはサポートされていません。各種プロパティのデフォルト値に基づいて作成されます。指定したプロパティを持つデータベースを作成したい場合は、SQLを使用して作成することをお勧めします。SQLによるデータベース作成の詳細については、[データベースの作成](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003977077)を参照してください。
:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール手順の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

* サーバーモードのseekdbまたはOceanBaseデータベースを使用している場合は、接続ユーザーが `CREATE` 権限を持っていることを確認してください。現在のユーザー権限の確認方法については、[ユーザー権限の確認](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980135)を参照してください。該当する権限を持っていない場合は、管理者に連絡し権限付与を依頼してください。ユーザー権限の付与手順については、[直接権限付与](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980140)を参照してください。

## データベース作成の制限

* seekdbインスタンス/OceanBaseデータベース内では、各データベース名はグローバルに一意である必要があります。

* データベース名の長さは128文字以内です。

* 大文字、小文字、数字、アンダースコア、ドル記号、中国語文字のみ含みます。

* 予約語をデータベース名として使用することは避けてください。

  予約語の詳細については、[予約語](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003976774)を参照してください。

## データベース作成の推奨事項

* データベースには、その用途や内容を反映できるような意味のある名前を付けることを推奨します。例えば、`アプリケーション識別子_サブアプリケーション名(オプション)_db` をデータベース名として使用することができます。

* データベースと関連するユーザーの作成にrootユーザーを使用し、データベースのセキュリティと制御性を確保するために必要な権限のみを付与することを推奨します。

* バッククォート(\`)で囲むことで、数字のみで構成されるデータベース名を作成できますが、この方法は推奨されません。数字のみの命名には明確な意味がなく、クエリの実行や使用時には常にバッククォート(\`)が必要となるため、不必要な複雑さが生じ、混乱を招く可能性があります。

## リクエストパラメータ

```python
create_database(name, tenant=DEFAULT_TENANT)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|作成するデータベースの名前を指定します。|`my_database`|
|`tenant`|string|オプション<ul><li>組み込みseekdbおよびサーバーモードseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータが必須です。</li></ul>|作成するデータベースが属するテナントを指定します。|`test_tenant`|

## リクエスト例

```python
import pyseekdb

# Embedded mode
admin = pyseekdb.AdminClient(path="./seekdb")

# Create database
admin.create_database("my_database")
```
