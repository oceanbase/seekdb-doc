# list_databases - データベースリストの取得

`list_databases()`は、インスタンス内のデータベースリストを取得するために使用されます。

:::info

このインターフェースは、`AdminClient`接続時にのみ使用できます。`AdminClient`の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

## リクエストパラメータ

```python
list_databases(limit=None, offset=None, tenant=DEFAULT_TENANT)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`limit`|int|オプション|返されるデータベースの最大数。|2|
|`offset`|int|オプション|最初からスキップするデータベースの数。| 3|
|`tenant`|string|オプション<ul><li>組み込みseekdbおよびサーバーモードseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータは必須です。デフォルト値は`sys`です。</li></ul>|クエリ対象のデータベースが属するテナントを指定します。|test_tenant|

## リクエスト例

```python
# List all databases
import pyseekdb

# Embedded mode
admin = pyseekdb.AdminClient(path="./seekdb")

# list database
databases = admin.list_databases(2,3)
for db in databases:
        print(f"Database: {db.name}, Charset: {db.charset}, collation:{db.collation}, metadata:{db.metadata}")
```

## レスポンスパラメータ

|パラメータ|戻り値の型|必須|説明|戻り値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のデータベース名。|`my_database`|
|`tenant`|string|オプション<br/>組み込みSeekDBおよびサーバーモードSeekDBを使用する場合は、このパラメータはありません。|クエリ対象のデータベースが属するテナント。|`test_tenant`|
|`charset`|string|オプション|クエリ対象のデータベースで使用される文字セット。|`utf8mb4`|
|`collation`|string|オプション|クエリ対象のデータベースで使用される照合順序。|`utf8mb4_general_ci`|
|`metadata`|dict|オプション|予約フィールド。現在データなし| {} |

## レスポンス例

```python
Database: test, Charset: utf8mb4, collation:utf8mb4_general_ci, metadata:{}
Database: my_database, Charset: utf8mb4, collation:utf8mb4_general_ci, metadata:{}
```
