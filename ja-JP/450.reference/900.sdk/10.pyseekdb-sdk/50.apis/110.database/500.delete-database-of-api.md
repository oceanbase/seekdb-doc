# delete_database - データベースの削除

`delete_database()`は、データベースを削除するために使用されます。

:::info

このインターフェースは、`AdminClient`を使用して接続した場合にのみ利用できます。`AdminClient`の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Admin Client](../100.admin-client.md)を参照してください。

* サーバーモードのseekdbまたはOceanBaseデータベースを使用している場合は、接続しているユーザーが`DROP`権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980135)を参照してください。該当する権限を持っていない場合は、管理者に連絡し権限付与を依頼してください。ユーザー権限の付与に関する操作については、[直接権限付与](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980140)を参照してください。

## リクエストパラメータ

```python
delete_database(name,tenant=DEFAULT_TENANT)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|削除するデータベースの名前を指定します。|my_database|
|`tenant`|string|オプション<ul><li>組み込みseekdbおよびサーバーモードseekdbを使用する場合は、このパラメータを指定する必要はありません。</li><li>OceanBaseデータベースを使用する場合は、このパラメータが必須です。デフォルト値は`sys`です。</li></ul>|削除するデータベースが属するテナントを指定します。|test_tenant|

## リクエスト例

```python
import pyseekdb

# Embedded mode
admin = pyseekdb.AdminClient(path="./seekdb")

# Delete database
admin.delete_database("my_database")
```
