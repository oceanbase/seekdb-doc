# get_or_create_collection - コレクションの作成またはクエリ

`get_or_create_collection()`は、コレクションを作成またはクエリするために使用されます。データベース内にコレクションが存在しない場合は作成し、存在する場合は対応する結果を取得します。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

* サーバーモードのseekdbまたはOceanBaseデータベースを使用している場合は、接続ユーザーが`CREATE`権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980135)を参照してください。該当する権限を持っていない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限に関する操作については、[直接権限付与](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003980140)を参照してください。

## テーブル名の定義

テーブルを作成する際には、まずテーブルに名前を付ける必要があります。テーブル名を定義する際に従うべき要件は以下のとおりです：

* seekdbでは、各テーブル名はデータベース内で一意である必要があります。

* テーブル名は64文字を超え、512文字未満の長さがサポートされます。

* テーブルには意味のある名前を付けることを推奨します。t1やtable1などの名前は使用しないでください。その他のテーブル名の命名規則については、[テーブル名の命名規則](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971368)を参照してください。

## リクエストパラメータ

```python
get_or_create_collection(name = name,configuration = configuration, embedding_function = embedding_function )
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|作成するコレクションの名前を指定します。|my_collection|
|`configuration`|Configuration \| HNSWConfiguration|オプション|次元と距離尺度を持つインデックスの設定です。指定しない場合は、デフォルト値 `dimension=384, distance='cosine',analyzer=’ik’` が使用されます。`None` に設定すると、次元は `embedding_function` の値から計算されます。`embedding_function` も `None` の場合は、エラーが発生します。|HNSWConfiguration(dimension=384, distance='cosine')|
|`embedding_function`|EmbeddingFunction|オプション|convertをベクトルに変換する関数です。指定しない場合は、`DefaultEmbeddingFunction()()` が使用されます。`None` に設定すると、コレクションに埋め込み機能が含まれません。埋め込み機能を指定した場合は、`configuration.dimension` に基づいて自動的に計算されます。|DefaultEmbeddingFunction()|

その中で、パラメータ `configuration` 内の `Configuration` 型パラメータについては以下のとおりです：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`hnsw`|HNSWConfiguration|オプション| |HNSWConfiguration|
|`fulltext_config`|FulltextIndexConfig|オプション|全文検索インデックスの設定です。パラメータ`analyzer`と`properties`を含み、どちらも文字列型です。指定しない場合はデフォルト値が使用され、デフォルトは`analyzer=’ik’`です。詳細な設定については、[CREATE INDEX](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974165) の parser_properties を参照してください。|`FulltextIndexConfig(analyzer='ik', properties={'ik_mode':'max_words'}))`|

:::info

`embedding_function` を指定する場合、システムはこの関数を呼び出してベクトルの次元数を自動的に計算します。`configuration.dimension` も指定されている場合、それは `embedding_function` の次元数と一致している必要があります。一致しない場合は ValueError が発生します。

:::

## リクエスト例

```python
import pyseekdb
from pyseekdb import DefaultEmbeddingFunction, HNSWConfiguration

# Create a client
client = pyseekdb.Client()

# Get or create collection (creates if doesn't exist)
collection = client.get_or_create_collection(
    name="my_collection4",
    configuration=HNSWConfiguration(dimension=384, distance='cosine'),
    embedding_function=DefaultEmbeddingFunction()
)

config = Configuration(hnsw=HNSWConfiguration(dimension=384), fulltext_config=FulltextIndexConfig(analyzer='ik', properties={'ik_mode':'max_words'}))
collection = client.get_or_create_collection(
    name="my_collection5",
    configuration=config,
    embedding_function=None
)
```
