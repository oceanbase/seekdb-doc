# has_collection - 指定されたCollectionが存在するかどうかを確認する

`has_collection()`は、指定されたCollectionが存在するかどうかを確認するために使用されます。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

## リクエストパラメータ

```python
client.has_collection(name)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|確認するCollectionの名前を指定します。|my_collection|

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# Count collections in database
collection_has = client.has_collection("my_collection")
print(collection_has)
```

## レスポンスパラメータ

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|Promise`<boolean>`|必須|trueはコレクションが存在することを示し、falseは存在しないことを示します。|`true`|

## レスポンス例

```python
true
```
