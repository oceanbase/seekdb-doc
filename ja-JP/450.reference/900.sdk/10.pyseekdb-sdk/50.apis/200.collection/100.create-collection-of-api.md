# create_collection - コレクションの作成

`create_collection()`は、新しいコレクション、つまりデータベース内のテーブルを作成するために使用されます。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

* サーバーモードのseekdbまたはOceanBaseデータベースを使用している場合は、接続しているユーザーが`CREATE`権限を持っていることを確認してください。現在のユーザー権限を確認する操作については、[ユーザー権限の確認](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971368)を参照してください。この権限を持っていない場合は、管理者に連絡し権限の付与を依頼してください。ユーザー権限に関する操作については、[直接権限の付与](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974754)を参照してください。

## テーブル名の定義

テーブルを作成する際には、まずテーブル名を付ける必要があります。テーブル名を定義する際に従うべき要件は以下のとおりです：

* seekdbでは、各テーブル名はデータベース内で一意である必要があります。

* テーブル名は64文字を超え、512文字未満であることがサポートされています。

* テーブルには意味のある名前を付けることを推奨します。t1やtable1などの名前は使用しないでください。その他のテーブル名の命名規則については、[テーブル名の命名規則](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003977289)を参照してください。

## リクエストパラメータ

```python
create_collection(name = name,configuration = configuration, embedding_function = embedding_function )
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|作成するコレクションの名前を指定します。|my_collection|
|`configuration`|Configuration \| HNSWConfiguration|オプション|次元と距離尺度を持つインデックスの設定です。指定しない場合、デフォルト値（`dimension=384, distance='cosine',analyzer=’ik’`）が使用されます。`None`に設定した場合、次元は`embedding_function`の値から計算されます。`embedding_function`も`None`の場合はエラーが発生します。|HNSWConfiguration(dimension=384, distance='cosine')|
|`embedding_function`|EmbeddingFunction|オプション|convertをベクトルに変換する関数です。指定しない場合、`DefaultEmbeddingFunction()()`（384次元）が使用されます。`None`に設定した場合、コレクションに埋め込み機能は含まれません。埋め込み機能を指定した場合、`configuration.dimension`に基づいて自動的に計算されます。|DefaultEmbeddingFunction()|

ここで、パラメータ `configuration` 内の `Configuration` 型パラメータについて説明します。

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`hnsw`|HNSWConfiguration|オプション| |HNSWConfiguration|
|`fulltext_config`|FulltextIndexConfig|オプション|全文検索インデックスの設定です。パラメータ`analyzer`と`properties`を含み、どちらも文字列型です。指定しない場合は、デフォルト値が使用されます。デフォルトは`analyzer=’ik’`です。詳細な設定については、[CREATE INDEX](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974165)のparser_propertiesを参照してください。|`FulltextIndexConfig(analyzer='ik', properties={'ik_mode':'max_words'}))`|

:::info

`embedding_function` を指定すると、システムはこの関数を呼び出してベクトル次元を自動的に計算します。`configuration.dimension` も指定されている場合、その次元は `embedding_function` の次元と一致している必要があります。一致しない場合は ValueError が発生します。

:::

## リクエスト例

```python
import pyseekdb
from pyseekdb import DefaultEmbeddingFunction, HNSWConfiguration

# Create a client
client = pyseekdb.Client()

# Create a collection with default embedding function (auto-calculates dimension)
collection = client.create_collection(
    name="my_collection"
)

# Create a collection with custom embedding function
ef = UserDefinedEmbeddingFunction() // define your own Embedding function, See section.6
config = HNSWConfiguration(dimension=384, distance='cosine')  # Must match EF dimension
collection = client.create_collection(
    name="my_collection2",
    configuration=config,
    embedding_function=ef
)

# Create a collection without embedding function (vectors must be provided manually)
collection = client.create_collection(
    name="my_collection3",
    configuration=HNSWConfiguration(dimension=384, distance='cosine'),
    embedding_function=None  # Explicitly disable embedding function
)

config = Configuration(hnsw=HNSWConfiguration(dimension=384), fulltext_config=FulltextIndexConfig(analyzer='ik', properties={'ik_mode':'max_words'}))
collection = client.create_collection(
    name="my_collection4",
    configuration=config,
    embedding_function=None
)
```
