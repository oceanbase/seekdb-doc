# list_collections - Collectionsリストの取得

`list_collections()`は、すべてのCollectionを取得するために使用されます。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール手順の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

## リクエストパラメータ

```python
client.list_collections()
```

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# List all collections
collections = client.list_collections()
for coll in collections:
    print(f"Collection: {coll.name}, Dimension: {coll.dimension}, embedding_function: {coll.embedding_function}, distance: {coll.distance}, metadata: {coll.metadata}")
```

## レスポンスパラメータ

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ結果のコレクション名。|my_collection|
|`dimension`|int|オプション| | 384 |
|`embedding_function`|EmbeddingFunction|オプション|DefaultEmbeddingFunction(model_name='all-MiniLM-L6-v2')|
|`distance`|string|オプション| |cosine|
|`metadata`|dict|オプション|予約フィールド、現在データなし| {} |

## レスポンス例

```python
Collection: my_collection, Dimension: 384, embedding_function: DefaultEmbeddingFunction(model_name='all-MiniLM-L6-v2'), distance: cosine, metadata: {}
Database has 1 collections
```
