# collection管理

collectionはpyseekdbにおいて、データベースのテーブルに類似する集合であり、ユーザーは対応するcollectionを作成、クエリ、削除することができます。

collectionの操作には、以下のAPIを利用できます。

| API | 説明 | 関連ドキュメントのリンク |
|---|---|---|
| `create_collection()` | コレクションを作成します。 | [ドキュメント](100.create-collection-of-api.md) |
| `get_collection()` | 指定されたコレクションを取得します。 |[ドキュメント](200.get-collection-of-api.md)|
| `get_or_create_collection()` | コレクションを作成またはクエリします。データベース内にコレクションが存在しない場合は作成し、存在する場合は対応する結果を取得します。 |[ドキュメント](250.get-or-create-collection-of-api.md)|
| `list_collections()`  | データベースのコレクションリストを取得します。  |[ドキュメント](300.list-collection-of-api.md)|
| `count_collection()`  | データベース内のコレクション数を集計します  |[ドキュメント](350.count-collection-of-api.md)|
| `delete_collection()`  | 指定されたコレクションを削除します。|[ドキュメント](400.delete-collection-of-api.md)|
