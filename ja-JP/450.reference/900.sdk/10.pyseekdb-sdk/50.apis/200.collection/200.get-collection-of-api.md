# get_collection - コレクションの取得

`get_collection()`は、指定されたコレクションを取得するために使用されます。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続の詳細な操作については、[Client](../50.client.md)を参照してください。

* 取得したCollectionが存在すること。Collectionが存在しない場合、エラーが表示されます。

## リクエストパラメータ

```python
client.get_collection(name,configuration = configuration,embedding_function = embedding_function)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|取得するコレクションの名前を指定します。|my_collection|
|`configuration`|HNSWConfiguration|オプション|次元と距離尺度を持つインデックスの設定です。指定しない場合、デフォルト値が使用されます。デフォルトは`dimension=384, distance='cosine'`です。`None`に設定すると、次元は`embedding_function`の値から計算されます。|HNSWConfiguration(dimension=384, distance='cosine')|
|`embedding_function`|EmbeddingFunction|オプション|convertをベクトルに変換する関数です。指定しない場合、`DefaultEmbeddingFunction()()`が使用されます。`None`に設定すると、コレクションに埋め込み機能が含まれません。埋め込み機能が指定されている場合、`configuration.dimension`に基づいて自動的に計算されます。|DefaultEmbeddingFunction()|

:::info

documents/textsにvectorsが指定されていない場合、ここで設定されたembedding functionが、add、upsert、update、query、hybrid_searchを含む、このcollectionに対するすべての操作で使用されます。

:::

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# Get an existing collection (uses default embedding function if collection doesn't have one)
collection = client.get_collection("my_collection")
print(f"Database: {collection.name}, dimension: {collection.dimension}, embedding_function:{collection.embedding_function}, distance:{collection.distance}, metadata:{collection.metadata}")

# Get collection with specific embedding function
ef = UserDefinedEmbeddingFunction() // define your own Embedding function, See section.6
collection = client.get_collection("my_collection", embedding_function=ef)
print(f"Database: {collection.name}, dimension: {collection.dimension}, embedding_function:{collection.embedding_function}, distance:{collection.distance}, metadata:{collection.metadata}")

# Get collection without embedding function
collection = client.get_collection("my_collection", embedding_function=None)
# Check if collection exists
if client.has_collection("my_collection"):
    collection = client.get_collection("my_collection")
print(f"Database: {collection.name}, dimension: {collection.dimension}, embedding_function:{collection.embedding_function}, distance:{collection.distance}, metadata:{collection.metadata}")
```

## レスポンスパラメータ

|パラメータ|戻り値の型|必須|説明|戻り値の例|
|---|---|---|---|---|
|`name`|string|必須|クエリ対象のCollection名を指定します。|my_collection|
|`dimension`|int|オプション| |384|
|`embedding_function`|EmbeddingFunction|オプション|DefaultEmbeddingFunction(model_name='all-MiniLM-L6-v2')|
|`distance`|string|オプション| |cosine|
|`metadata`|dict|オプション|予約フィールドです。現在データはありません。| {} |

## レスポンス例

```python
Database: my_collection, dimension: 384, embedding_function:DefaultEmbeddingFunction(model_name='all-MiniLM-L6-v2'), distance:cosine, metadata:{}

```
