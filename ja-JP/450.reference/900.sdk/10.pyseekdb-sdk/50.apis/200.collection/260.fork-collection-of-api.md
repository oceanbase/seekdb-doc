# fork - コレクションのコピー

`fork()`は、指定されたコレクションをコピーし、同じデータを持つ新しいコレクションを作成します。

:::info

* このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

* このインターフェースは、seekdb（組み込みおよびサーバーモード）V1.1.0以降のバージョンでのみサポートされています。OceanBaseデータベースは現在対応していません。
* seekdb V1.1.0バージョンでは、Fork Table（コレクションのコピー）は実験的機能です。本番環境での使用は慎重に行ってください。今後のバージョンで正式な本番機能として継続的に改善される予定です。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

* コピーしたいコレクションが存在すること。コレクションが存在しない場合、エラーが表示されます。

## リクエストパラメータ

```python
fork(name)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|新しいコレクションの名前。|`my_collection_backup`|

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

original = client.get_collection("my_collection")
forked = original.fork("my_collection_backup")
```

## レスポンスパラメータ

なし
