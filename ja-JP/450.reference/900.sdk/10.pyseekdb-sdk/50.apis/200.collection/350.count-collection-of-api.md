# count_collection - コレクション数を集計する

`count_collection()`は、データベース内のコレクション数を集計します。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

## リクエストパラメータ

```python
client.count_collection()
```

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# Count collections in database
collection_count = client.count_collection()
print(f"Database has {collection_count} collections")
```

## レスポンスパラメータ

なし

## レスポンス例

```python
Database has 1 collections
```
