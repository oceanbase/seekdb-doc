# delete_collection - コレクションの削除

`delete_collection()`は、指定されたコレクションを削除するために使用します。

:::info

このインターフェースは、Client接続を使用している場合にのみ利用できます。Clientの詳細については、[Client](../50.client.md)を参照してください。

:::

## 前提条件

* pyseekdbがインストール済みであること。pyseekdbのインストール方法の詳細については、[クイックスタート](../../../10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。

* データベースに接続されていること。接続操作の詳細については、[Client](../50.client.md)を参照してください。

* 削除するコレクションが存在すること。コレクションが存在しない場合、エラーが表示されます。

## リクエストパラメータ

```python
client.delete_collection(name)
```

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`name`|string|必須|削除するコレクション名を指定します。|my_collection|

## リクエスト例

```python
import pyseekdb

# Create a client
client = pyseekdb.Client()

# Delete a collection
client.delete_collection("my_collection")
```

## レスポンスパラメータ

なし
