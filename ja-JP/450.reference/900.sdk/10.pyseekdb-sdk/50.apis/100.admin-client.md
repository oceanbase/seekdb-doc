# Admin Client

`AdminClient`はデータベース管理操作を提供します。`Client`と同じデータベース接続モードを使用しますが、データベース管理に関連する操作のみをサポートします。

## 埋め込み型seekdbへの接続

`AdminClient` を使用して、ローカルの埋め込み型seekdbインスタンスに接続します。

```python
import pyseekdb

# Embedded mode - Database management
admin = pyseekdb.AdminClient(path="./seekdb")
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`path`|string|オプション|seekdbデータディレクトリのパスです。seekdbはこのパス配下にデータベースファイルを保存し、起動時に読み込みます。|`./seekdb`|

## リモートサーバーへの接続

`AdminClient` を使用してリモートサーバーに接続します。seekdbおよびOceanBaseデータベースへの接続がサポートされています。

:::tip

接続する前に、サーバーモードのseekdbまたはOceanBaseデータベースが既にデプロイ済みであることを確認してください。<br/>サーバーモードのseekdbのデプロイ方法については、[デプロイの概要](../../../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。<br/>OceanBaseデータベースのデプロイ方法については、[デプロイの概要](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003976427)を参照してください。

:::

例：サーバーモードのseekdbに接続する

```python
import pyseekdb

# Remote server mode - Database management
admin = pyseekdb.AdminClient(
    host="127.0.0.1",
    port=2881,
    user="root",
    password=""  # Can be retrieved from SEEKDB_PASSWORD environment variable
)
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|インスタンスが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`prot`|string|必須|インスタンスポート。デフォルトは2881。|`2881`|
|`user`|string|必須|ユーザー名。デフォルトはroot。|`root`|
|`password`|string|必須|ユーザーのパスワード。`password`が指定されていない場合、または空文字列が入力されている場合、システムは`SEEKDB_PASSWORD`環境変数から取得します。||

例：OceanBaseデータベースに接続する

```python
import pyseekdb

# Remote server mode - Database management
admin = pyseekdb.AdminClient(
    host="127.0.0.1",
    port=2881,
    tenant="test"
    user="root",
    password=""  # Can be retrieved from SEEKDB_PASSWORD environment variable
)
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|データベースが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`prot`|string|必須|OceanBaseデータベースのポート。デフォルトは2881。|`2881`|
|`tenant`|string|オプション|テナント名。SEEKDBではこのパラメータを指定する必要はありませんが、OceanBaseデータベースでは必要です。デフォルトはsysです。|`test`|
|`user`|string|必須|テナントに対応するユーザー名。デフォルトはrootです。|`root`|
|`password`|string|必須|ユーザーに対応するパスワード。`password`が指定されていない場合、または空文字列が入力されている場合、システムは`SEEKDB_PASSWORD`環境変数から取得します。||

## AdminClientを使用した接続でサポートされるインターフェース

`AdminClient` を使用してデータベースに接続する場合、以下のAPIを利用できます。

| API | 説明 |関連ドキュメント|
|---|---|---|
| `create_database` | 新しいデータベースを作成します。|[ドキュメント](110.database/200.create-database-of-api.md)|
| `get_database`    | 指定したデータベースをクエリします。|[ドキュメント](110.database/300.get-database-of-api.md)|
| `delete_database` | 指定したデータベースを削除します。 |[ドキュメント](110.database/400.list-database-of-api.md)|
| `list_databases` |すべてのデータベースを一覧表示します。|[ドキュメント](110.database/500.delete-database-of-api.md)|
