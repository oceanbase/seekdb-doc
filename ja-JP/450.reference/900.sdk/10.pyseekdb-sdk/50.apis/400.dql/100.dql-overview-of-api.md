# DQLの概要

DQL（Data Query Language）操作により、さまざまなクエリ方法を使用してcollectionsからデータを取得できます。

DQL操作では、以下のAPIインターフェースを利用できます。

| API | 説明 | 関連ドキュメント |
|---|---|---|
| `query()` | ベクトル類似度検索メソッドです。 | [ドキュメント](200.query-interfaces-of-api.md) |
| `get()` | ID、document、metadata（非ベクトル）を使用してテーブルから特定のデータを照会します。 |[ドキュメント](300.get-interfaces-of-api.md)|
| `hybrid_search()`  | 全文検索とベクトル類似度検索を組み合わせたランキング方式です。  |[ドキュメント](400.hybrid-search-of-api.md)|
