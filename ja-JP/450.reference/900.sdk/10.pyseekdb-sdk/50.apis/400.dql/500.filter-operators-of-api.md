# 演算子

演算子は通常、演算数やパラメータなどの単一のデータ項目を結合して結果を返すために使用されます。構文的には、演算子は演算数の前、演算数の後、または2つの演算数の間に配置することができます。

## 演算子の例

### データフィルタリング（where）

#### 等しい

`$eq` を使用して等しいことを表します。書き方は次のとおりです：

```python
where={"category": {"$eq": "AI"}}
```

#### 等しくない

`$ne` を使用して等しくないことを表します。書き方は次のとおりです：

```python
where={"status": {"$ne": "deleted"}}
```

#### より大きい

`$gt` を使用してより大きいことを表します。書き方は次のとおりです：

```python
where={"score": {"$gt": 90}}
```

#### より大きいか等しい

`$gte` を使用してより大きいか等しいことを表します。書き方は次のとおりです：

```python
where={"score": {"$gte": 90}}
```

#### より小さい

`$lt` を使用してより小さいことを表します。書き方は次のとおりです：

```python
where={"score": {"$lt": 50}}
```

#### より小さいか等しい

`$lte` を使用してより小さいか等しいことを表します。書き方は次のとおりです：

```python
where={"score": {"$lte": 50}}
```

#### 含まれる

`$in` を使用して含まれることを表します。書き方は次のとおりです：

```python
where={"tag": {"$in": ["ml", "python", "ai"]}}
```

#### 含まれない

`$nin` を使用して含まれないことを表します。書き方は次のとおりです：

```python
where={"tag": {"$nin": ["deprecated", "old"]}}
```

#### 論理OR

`$or` を使用して論理ORを表します。書き方は次のとおりです：

```python
where={
    "$or": [
        {"category": {"$eq": "AI"}},
        {"tag": {"$eq": "python"}}
    ]
}
```

#### 論理AND

`$and` を使用して論理ANDを表します。書き方は次のとおりです：

```python
where={
    "$and": [
        {"category": {"$eq": "AI"}},
        {"score": {"$gte": 90}}
    ]
}
```

### テキストフィルタリング（where_document）

#### 全文検索（部分文字列を含む）

`$contains` を使用して全文検索を表します。書き方は次のとおりです：

```python
where_document={"$contains": "machine learning"}
```

#### 正規表現

`$regex` を使用して正規表現を表します。書き方は次のとおりです：

```python
where_document={"$regex": "pattern.*"}
```

#### 論理OR

`$or` を使用して論理ORを表します。書き方は次のとおりです：

```python
where_document={
    "$or": [
        {"$contains": "machine learning"},
        {"$contains": "artificial intelligence"}
    ]
}
```

#### 論理AND

`$and` を使用して論理ANDを表します。書き方は次のとおりです：

```python
where_document={
    "$and": [
        {"$contains": "machine"},
        {"$contains": "learning"}
    ]
}
```
