# クライアント

`Client`は異なるモードのデータベース、すなわち組み込みモードとサーバーモードに接続するために使用され、提供されたパラメータに基づいて適切な接続モードを自動選択します。

:::tip
OceanBaseデータベースは、OceanBaseが提供する完全に独自開発されたエンタープライズ向けネイティブ分散型データベースです。一般的なハードウェア上で金融級の高可用性を実現し、「三地五中心」という都市レベルの障害に対する自動無損失ディザスタリカバリという新標準を確立しました。TPC-Cベンチマークテストで新記録を樹立し、単一クラスタで1,500ノードを超える規模をサポートします。クラウドネイティブ、強整合性、Oracle/MySQLとの高い互換性などの特徴を備えています。OceanBaseデータベースの詳細については、[OceanBaseデータベース](https://en.oceanbase.com/docs/oceanbase-database)を参照してください。
:::

## 埋め込みseekdbへの接続

`Client` を使用して、ローカルの埋め込みseekdbインスタンスに接続します。

```python
import pyseekdb

# Create embedded client
client = pyseekdb.Client(
    #path="./seekdb",      # Path to seekdb data directory
    #database="test"        # Database name
)
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`path`|string|オプション|seekdbデータディレクトリのパスです。seekdbはこのパスにデータベースファイルを格納し、起動時に読み込みます。|`./seekdb`|
|`database`|string|オプション|データベース名。|`test`|

## リモートサーバーへの接続

`Client` を使用してリモートサーバーに接続します。seekdb および OceanBase データベースへの接続をサポートしています。

:::tip

接続する前に、サーバーモードの seekdb または OceanBase データベースが既にデプロイされていることを確認してください。<br/>サーバーモードの seekdb のデプロイ方法については、[デプロイの概要](../../../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。<br/>OceanBase データベースのデプロイ方法については、[デプロイの概要](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000003976427)を参照してください。

:::

例：サーバーモードの seekdb に接続する

```python
import pyseekdb

# Create remote server client (seekdb Server)
client = pyseekdb.Client(
    host="127.0.0.1",      # Server host
    port=2881,              # Server port
    database="test",        # Database name
    user="root",            # Username
    password=""             # Password (can be retrieved from SEEKDB_PASSWORD environment variable)
)
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|インスタンスが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`prot`|string|必須|インスタンスのポート。デフォルトは2881。|`2881`|
|`database`|string|必須|データベース名。|`test`|
|`user`|string|必須|ユーザー名。デフォルトはroot。|`root`|
|`password`|string|必須|ユーザーのパスワード。`password`が指定されていない場合、または空文字列が入力されている場合、システムは`SEEKDB_PASSWORD`環境変数から取得します。||

例：OceanBase データベースに接続する

```python
import pyseekdb

# Create remote server client (OceanBase Server)
client = pyseekdb.Client(
    host="127.0.0.1",      # Server host
    port=2881,              # Server port (default: 2881)
    tenant="test",         # Tenant name
    database="test",       # Database name
    user="root",           # Username (default: "root")
    password=""             # Password (can be retrieved from SEEKDB_PASSWORD environment variable)
)
```

パラメータ説明：

|パラメータ|値の種類|必須|説明|値の例|
|---|---|---|---|---|
|`host`|string|必須|データベースが配置されているサーバーのIPアドレス。|`127.0.0.1`|
|`prot`|string|必須|OceanBaseデータベースのポート。デフォルトは2881。|`2881`|
|`tenant`|string|オプション|テナント名。SEEKDBではこのパラメータを指定する必要はありません。OceanBaseデータベースでのみ必要です。デフォルトはsysです。|`test`|
|`database`|string|必須|データベース名。|`test`|
|`user`|string|必須|テナントに対応するユーザー名。デフォルトはrootです。|`root`|
|`password`|string|必須|ユーザーに対応するパスワード。`password`が指定されていない場合、または空文字列が入力されている場合、システムは`SEEKDB_PASSWORD`環境変数から取得します。||

## Clientによる接続でサポートされているインターフェース

`Client` を使用してデータベースに接続する場合、以下のAPIを使用できます。

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `create_collection()` | 新しいcollectionを作成します。 | [ドキュメント](200.collection/100.create-collection-of-api.md) |
| `get_collection()` | 指定されたcollectionを照会します。 |[ドキュメント](200.collection/200.get-collection-of-api.md)|
| `delete_collection()`  | 指定されたcollectionを削除します。  |[ドキュメント](200.collection/400.delete-collection-of-api.md)|
| `list_collections()`  | 現在のデータベース内のすべてのcollectionsを一覧表示します。|[ドキュメント](200.collection/300.list-collection-of-api.md)|
| `get_or_create_collection()` | 指定されたcollectionを照会します。そのcollectionが存在しない場合は、そのcollectionを作成します。|[ドキュメント](200.collection/250.get-or-create-collection-of-api.md)|
| `count_collection()` | 現在のデータベース内のすべてのcollectionの数を照会します。 |[ドキュメント](200.collection/350.count-collection-of-api.md)|
