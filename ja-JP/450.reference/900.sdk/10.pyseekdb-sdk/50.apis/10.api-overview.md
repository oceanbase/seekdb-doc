# APIリファレンス

seekdbは、APIを通じてプログラム的に利用できます。

## APIインターフェース

現在、以下のAPIインターフェースをサポートしています。

### Database

:::info
このインターフェースは、`AdminClient` 接続を使用する場合にのみ利用できます。`AdminClient` の詳細については、[Admin Client](../50.apis/100.admin-client.md)を参照してください。
:::

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `create_database()` | データベースを作成します。 | [ドキュメント](110.database/200.create-database-of-api.md) |
| `get_database()` | 指定されたデータベースを取得します。 |[ドキュメント](110.database/300.get-database-of-api.md)|
| `list_databases()`  | インスタンス内のデータベースリストを取得します。  |[ドキュメント](110.database/400.list-database-of-api.md)|
| `delete_database()`  | 指定されたデータベースを削除します。|[ドキュメント](110.database/500.delete-database-of-api.md)|

### Collection

:::info
このインターフェースは、`Client` 接続を使用する場合にのみ利用できます。`Client` の詳細については、[Client](../50.apis/50.client.md)を参照してください。
:::

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `create_collection()` | コレクションを作成します。 | [ドキュメント](200.collection/100.create-collection-of-api.md) |
| `get_collection()` | 指定されたコレクションを取得します。 |[ドキュメント](200.collection/200.get-collection-of-api.md)|
| `get_or_create_collection()` | コレクションを作成またはクエリします。データベース内にコレクションが存在しない場合は作成し、存在する場合は対応する結果を取得します。 |[ドキュメント](200.collection/250.get-or-create-collection-of-api.md)|
| `list_collections()`  | データベースのコレクションリストを取得します。  |[ドキュメント](200.collection/300.list-collection-of-api.md)|
| `count_collection()`  | データベース内のコレクション数を集計します  |[ドキュメント](200.collection/350.count-collection-of-api.md)|
| `delete_collection()`  | 指定されたコレクションを削除します。|[ドキュメント](200.collection/400.delete-collection-of-api.md)|

### DML

:::info
このインターフェースは、`Client` 接続を使用する場合にのみ利用できます。`Client` の詳細については、[Client](../50.apis/50.client.md)を参照してください。
:::

| API | 説明 | 関連ドキュメントのリンク |
|---|---|---|
| `add()` | 新しいレコードをコレクションに挿入します。 | [ドキュメント](300.dml/200.add-data-of-api.md) |
| `update()` | コレクション内の既存レコードを更新します。 |[ドキュメント](300.dml/300.update-data-of-api.md)|
| `upsert()`  | 新規レコードを挿入するか、既存レコードを更新します。  |[ドキュメント](300.dml/400.upsert-data-of-api.md)|
| `delete()`  | コレクションからレコードを削除します。|[ドキュメント](300.dml/500.delete-data-of-api.md)|

### DQL

:::info
このインターフェースは、`Client` 接続を使用する場合にのみ利用できます。`Client` の詳細については、[Client](../50.apis/50.client.md)を参照してください。
:::

| API | 説明 | 関連ドキュメントリンク |
|---|---|---|
| `query()` | ベクトル類似度検索メソッド。 | [ドキュメント](400.dql/200.query-interfaces-of-api.md) |
| `get()` | ID、document、metadata（非ベクトル）を使用してテーブルから特定のデータを照会します。 |[ドキュメント](400.dql/300.get-interfaces-of-api.md)|
| `hybrid_search()`  | 全文検索とベクトル類似度検索を組み合わせたランキング方式です。  |[ドキュメント](400.dql/400.hybrid-search-of-api.md)|
