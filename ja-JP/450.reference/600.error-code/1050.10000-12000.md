# 10000 ~ 12000

この範囲には、OBKVエラーコードやクライアントエラーコードなどが含まれます。

## ERROR 10500 (HY000) : incorrect route for obkv global index, client router should refresh.

* seekdb エラーコード：10500

* エラー原因：OBKVグローバルインデックスのルートが正しくありません。クライアントのルーターを更新してください。
* 解決策：クライアントの接続とルーティング情報を確認してください。

## ERROR 10501 (HY000) : TTL feature is not enabled

* seekdb エラーコード：10501

* エラー原因：TTL機能が有効になっていません。

* 解決策：TTL機能が正しく有効になっていることを確認してください。

## ERROR 10502 (HY000) : TTL column '%.*s' not exists

* seekdb エラーコード：10502

* エラー原因：TTL列が存在しません。

* 解決策：指定されたTTL列がデータベーステーブルに存在するかどうかを確認してください。

## ERROR 10503 (HY000) : Column type of '%.*s' is not supported for TTL definition

* seekdb エラーコード：10503

* エラー原因：指定された列タイプはTTL定義に使用できません。

* 解決策：指定された列タイプがTTL定義に使用できるかどうかを確認してください。

## ERROR 10504 (HY000) : TTL command is not allowed, current TTL status is '%s'

* seekdb エラーコード：10504

* エラー原因：現在のTTLステータスが特定の値であるため、TTLコマンドの実行は許可されません。

* 解決策：現在のステータスが期待通りかどうかを確認し、適切なTTLコマンドを使用してステータスを切り替えてください。

## ERROR 10505 (HY000) : No TTL task is running, please try trigger a new TTL task

* seekdb エラーコード：10505

* エラー原因：実行中のTTLタスクがありません。新しいTTLタスクをトリガーしてみてください。

## ERROR 10507 (HY000) : Time to live of hbase table must be greater than 0

* seekdb エラーコード：10507

* エラー原因：HBaseテーブルのTTLは0より大きくする必要があります。

* 解決策：現在のテーブルの`KV_ATTRIBUTES`属性を確認し、定義されたTimeToLiveが0より大きいことを確認してください。

## ERROR 10508 (HY000) : MaxVersions of hbase table must be greater than 0

* seekdb エラーコード：10508

* エラー原因：HBaseテーブルのMaxVersionsは0より大きくする必要があります。

* 解決策：現在のテーブルの`KV_ATTRIBUTES`属性を確認し、定義されたMaxVersionsが0より大きいことを確認してください。

## ERROR 10509 (HY000) : Access denied, credential '%.*s' not match '%.*s'

* seekdb エラーコード：10509

* エラー原因：アクセスが拒否されました。認証資格『%.*s』が『%.*s』と一致しません。

* 解決策：正しい資格情報を再入力してください。ユーザー名とパスワードが正しいこと、および入力ミスがないことを確認してください。

## ERROR 10510 (HY000) : Rowkey column count not match, schema rowkey count is '%ld', input rowkey count is '%ld'

* seekdb エラーコード：10510

* エラー原因：操作を実行する際、入力された行キーの列数がデータベーステーブルの行キーの列数と一致しません。

* 解決策：操作を実行する際、指定された行キーの列数がテーブルの行キーの列数と一致することを確認してください。

## ERROR 10511 (HY000) : Column type for '%.*s' not match, schema column type is '%.*s', input column type is '%.*s'

* seekdb エラーコード：10511

* エラー原因：入力された列タイプがデータベーステーブルの列タイプと一致しません。これにより、データ変換エラーや操作の正しい実行ができない可能性があります。

* 解決策：操作を実行する際、入力された列タイプがテーブルの列タイプと一致することを確認してください。

## ERROR 10512 (HY000) : Collation type for '%.*s' not match, schema collation type is '%.*s', input collation type is '%.*s'

* seekdb エラーコード：10512

* エラー原因：文字セットの種類が一致しません。

* 解決策：操作を実行する際に、入力された文字セットの種類がテーブルの文字セットの種類と一致していることを確認してください。

## ERROR 10513 (HY000) : Scan range missing, input scan range cell count is '%ld', which should equal to rowkey count '%ld'

* seekdb エラーコード：10513

* エラー原因：スキャン操作を実行する際、スキャン範囲の列数とテーブルの主キー列数が一致しません。

* 解決策：スキャン操作を実行する際、スキャン範囲の列数と主キー列数が等しいことを確認してください。

## ERROR 10515 (HY000) : Redis protocol parse error, the input redis string is: '%.*s'

* seekdb エラーコード：10515

* エラー原因：Redisプロトコルの解析エラーです。

* 解決策：クライアントがseekdbデータベースでサポートされていないカスタムRedisコマンドを送信した可能性があります。または、コマンドの形式が誤っています。

## ERROR 10518 (HY000) : Check failed in %.*s"

* seekdb エラーコード：10518

* エラー原因：OBKV [checkAndInsertupインターフェース](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002025908)のrollbackWhenCheckFailedパラメータが`true`に設定されている場合、チェックに失敗するとこのエラーコードがスローされます。

* 解決策：このエラーがスローされた場合、チェックに失敗したことを意味します。業務の実際の状況に応じて、無視するか、他の処理を行ってください。

## ERROR 10519 (HY000) : '%.*s' is not disabled

* seekdb エラーコード：10519

* エラー原因：現在のテーブルの状態が無効（DISABLED）状態ではないため、HBase Adminの`enableTable()`または`deleteTable()`インターフェースを使用できません。

* 解決策：HBase Adminの`disableTable()`インターフェースを呼び出してテーブルの状態を無効（DISABLED）状態に設定し、再度試行してください。

## ERROR 10520 (HY000) : '%.*s' is not enabled

* seekdb エラーコード：10520

* エラー原因：現在のテーブルの状態が使用可能（ENABLED）状態ではないため、そのテーブルにアクセスできません。

* 解決策：HBase Adminの`enableTable()`インターフェースを呼び出してテーブルの状態を使用可能（ENABLED）状態に設定し、再度試行してください。

## ERROR 10521 (HY000) : namespace '%.*s' is not found

* seekdb エラーコード：10521

* エラー原因：指定されたHBaseテーブルスペースが存在しません。

* 解決策：OBKV-HBaseデータベースで対応するHBaseテーブルスペースを作成し、再度試行してください。

## ERROR 10522 (HY000) : table '%.*s' already exists

* seekdb エラーコード：10522

* エラー原因：指定されたHBaseテーブルが既に存在します。

* 解決策：既に作成されたテーブルが要件を満たしているか確認してください。そうでない場合は、必要なHBaseテーブルを削除してから再作成することができます。

## ERROR 10523 (HY000) : table '%.*s' not found

* seekdb エラーコード：10523

* エラー原因：指定されたHBaseテーブルが存在しません。

* 解決策：対応するHBaseテーブルを作成してください。

## ERROR 11081 (HY000) : skip_header and parse_header cannot be used at the same time

* seekdb エラーコード：11081

* エラー原因：`PARSE_HEADER` と `SKIP_HEADER` を同時に使用することはできません。意味上の競合が生じます。

* 解決策：外部ファイル形式に関連するプロパティを指定する際は、`PARSE_HEADER` と `SKIP_HEADER` パラメータを同時に使用しないでください。

## ERROR 11082 (HY000) : DDL operations on the internal catalog are not allowed

* seekdb エラーコード：11082

* エラーの原因：内部カタログ（Internal Catalog）に対するDDL操作は許可されていません。

* 解決策：操作対象のカタログのタイプを確認します。

## ERROR 11083 (HY000) : Command denied to user '%.*s'@'%.*s' for catalog '%.*s'

* seekdb エラーコード：11083

* エラーの原因：ユーザーにはカタログ（Catalog）の操作権限がありません。

* 解決策：ユーザーがカタログの権限を持っているかどうかを確認し、該当するカタログの操作権限をユーザーに付与します。

## ERROR 11088 (HY000) : reject limit %ld reached

* seekdb エラーコード：11088

* エラーの原因：拒否制限 %ld に達しました。

* 解決策：診断エラー制限情報を確認します。

## ERROR 11094 (HY000) : Sensitive rule '%.*s' exists

* seekdb エラーコード：11094

* エラーの原因：同名の既存の機密ルールが存在します。通常、DDLステートメントで機密ルールを新規作成する際、新規ルールと既存ルールが名前が重複する場合に発生します。

* 解決策：既存の機密ルールを削除してから、再試行します。

## ERROR 11095 (HY000) : Sensitive rule '%.*s' does not exist

* seekdb エラーコード：11095

* エラーの原因：指定された名前の機密ルールは存在しません。通常、DDLステートメントで機密ルールを削除する際、存在しないルール名を指定した場合に発生します。

* 解決策：機密ルールが存在するかどうかを確認してから、再試行します。

## ERROR 11096 (HY000) : Sensitive column %.*s(%.*s) exists

* seekdb エラーコード：11096

* エラーの原因：指定された名前の列は既に機密列です。通常、DDLステートメントで機密ルールを新規作成または変更する際、他の機密ルールでカバーされている列に対して機密ルールを適用しようとした場合に発生します。

* 解決策：その列が他の機密ルールでカバーされていないかどうかを確認します。もしそうであれば、既存の機密ルールを削除するか、他の未カバーの列を選択して新しい機密ルールを適用する必要があります。

## ERROR 11097 (HY000) : Sensitive column %.*s(%.*s) does not exist

* seekdb エラーコード：11097

* エラーの原因：指定された名前の機密列は存在しません。通常、DDLステートメントで機密ルールを変更する際、機密列ではない列を削除しようとした場合に発生します。

* 解決策：削除する列が実際に機密列であるかどうかを確認し、機密ルールの設定を確認して、指定された列名とテーブル名が正しいことを確認します。

## ERROR 11098 (HY000) : Access sensitive field protected by sensitive rule '%.*s' denied to user '%.*s'@'%.*s

* seekdb エラーコード：11098

* エラーの原因：対応する機密ルールへのアクセス権限がありません。

* 解決策：データベース管理者に連絡し、現在のユーザーにその機密ルールへのアクセス権限を付与してもらうか、対応する権限を持つユーザーアカウントを使用して操作を実行します。

## ERROR 11099 (HY000) : Invalid sensitive rule name '%.*s'

* seekdb エラーコード：11099

* エラーの原因：無効な機密ルール名です。

* 解決策：機密ルール名が命名規則に適合しているかどうかを確認し、名前に特殊文字が含まれていないこと、長さが許容範囲内であること、既存のルールと名前が重複していないことを確認します。
