# 8000 ~ 8999

この範囲は重大なエラーを示すエラーコードです。クライアントが8xxxエラーを受信した場合、SQL接続を閉じる必要があります。

## ERROR 8001 (08004) : Server is initializing

* seekdb エラーコード：8001

* エラー原因：seekdb の起動中に RPC リクエストを受信しました。

* 解決策：seekdb の再起動完了を待ちます。

## ERROR 8002 (08004) : Server is stopping

* seekdb エラーコード：8002

* エラー原因：seekdb の終了中に RPC リクエストを受信しました。

* 解決策：seekdb が正常に終了するのを待ちます。または、`kill -9` を実行して seekdb プロセスを強制的に終了します。

## ERROR 8003 (08004) : Packet checksum error

* seekdb エラーコード：8003

* エラー原因：seekdb が RPC パケットの `checksum` 検証に失敗しました。一般的な原因はバージョン互換性の問題です。

* 解決策：テクニカルサポートにお問い合わせいただき、調査のご協力をお願いいたします。
