# エラーメッセージの概要

この章では、seekdbにおけるエラーメッセージについて説明します。

## エラーメッセージの形式

seekdbはMySQLと高い互換性を持っています。これは、一般的なMySQL機能やMySQLのプロキシ/クライアントプロトコルだけでなく、seekdb固有のエラーメッセージもMySQLと互換性があることを意味します。そのため、seekdbのエラーメッセージ形式はMySQLと一致しています。

エラーメッセージの形式は以下のとおりです：

```shell
ERROR <err_num> (<sql_stat>) : err_msg
```

パラメータの説明：

* `err_num` はエラーコードを表します。

* `sql_stat` はSQL STATEを表します。

* `err_msg` はエラーメッセージを表します。

## エラーメッセージ内の変数

エラーの特定と解決を支援するため、seekdbはエラーメッセージにパラメータを埋め込んでいます。この章では、これらのパラメータはパーセント記号（%）で表示されます。

例：

```shell
ERROR 5235 (HY000) : The table \'%.*s.%.*s\' is read only so it cannot execute this statement
```

上記のメッセージは、実際には次のように表示される可能性があります：

```shell
ERROR 5235 (HY000) : The table 'testdb' is read only so it cannot execute this statement
```
