## ERROR 4403 (HY000) : OS params check failed, because the operating system has improper parameter configurations

* seekdb エラーコード：4403

* エラー原因：seekdbは、オペレーティングシステムのパラメータ設定が不適切であることを検出しました。

* 解決方法：ERRORログを確認して、どのパラメータの設定が不適切かを特定し、ドキュメントでそのパラメータの正しい範囲を確認して修正します。
