# seekdbコンテナ環境のデプロイ

本記事では、Dockerコンテナを使用してseekdbをデプロイする方法について説明します。

## はじめに

`seekdb` Dockerイメージは、[dockerhub](https://hub.docker.com/r/oceanbase/seekdb)、[quay.io](https://quay.io/repository/oceanbase/seekdb)および[ghcr.io](https://ghcr.io/oceanbase/seekdb)から入手できます。ユーザーが迅速にseekdb環境を構築してテストを行うことを目的としています。

:::tip

* macOSおよびIntelチップ上でこのイメージを実行する場合、Dockerのバージョンが4.9.0より高いと既知の問題が発生します。必要なバージョンの[Docker](https://desktop.docker.com/mac/main/amd64/81317/Docker.dmg?_gl=17jelfd_gcl_auOTk5Nzk0MDUwLjE3MTE4ODMyNzM._gaNDQyMjE1MDE5LjE3MTE4ODMyNzQ._ga_XJWPQMJYHQ*MTcxOTIxOTEwMy4xMS4xLjE3MTkyMjEwMTAuNjAuMC4w)をこちらからダウンロードできます。

* このイメージはテスト専用です。本番環境では使用しないでください。
:::

## 前提条件

`seekdb`をデプロイする前に、以下の要件を満たしていることを確認してください：

* Dockerをインストールし、Dockerサービスを起動していること。詳細な操作については[Dockerドキュメント](https://docs.docker.com/get-docker/)を参照してください。

* マシンに少なくとも1つの物理コアと2GBのメモリが搭載されていること。

## seekdbインスタンスの起動

seekdbインスタンスを起動するには、以下のコマンドを使用します：

```shell
docker run -d -p 2881:2881 oceanbase/seekdb
```

:::info

* Dockerイメージの取得に失敗した場合は、quay.ioまたはghcr.ioリポジトリからイメージを取得することもできます。その場合は、上記のコマンドにおいて`oceanbase/seekdb`を`quay.io/oceanbase/seekdb`または`ghcr.io/oceanbase/seekdb`に置き換えて実行します。例：`sudo docker run -d -p 2881:2881 quay.io/oceanbase/seekdb`はquay.ioからイメージを取得します。

* 上記のコマンドはデフォルトで最新バージョンを取得しますが、必要に応じて[dockerhub](https://hub.docker.com/r/oceanbase/seekdb)、[quay.io](https://quay.io/repository/oceanbase/seekdb)または[ghcr.io](https://ghcr.io/oceanbase/seekdb)からバージョンを選択できます。

:::

起動後に初期化SQLスクリプトを実行したい場合は、初期化スクリプトを含むディレクトリをマウントし、環境変数`INIT_SCRIPTS_PATH`でコンテナ内のマウントディレクトリを指定する必要があります。例：

```shell
docker run -d -p 2881:2881 -v {init_sql_folder_path}:/root/boot/init.d -e INIT_SCRIPTS_PATH=/root/boot/init.d oceanbase/seekdb
```
  コマンド内の`{init_sql_folder_path}`は、ホスト上にある初期化SQLスクリプトのパスです。

:::tip
  SQLスクリプト内でrootユーザーのパスワードを変更しないでください。rootユーザーのパスワードを変更する必要がある場合は、環境変数<code>ROOT_PASSWORD</code>を使用してください。例：<code>docker run -d -p 2881:2881 -e ROOT_PASSWORD="******" oceanbase/seekdb</code>。
:::

サポートされている環境変数は以下のとおりです：

| 変数名 | 説明 | デフォルト値 |
|-----------|-------------|-------|
| ROOT_PASSWORD           | rootユーザーのパスワード。 | デフォルトは空 |
| CPU_COUNT               | cpu_countの値。| 4 |
| MEMORY_LIMIT            | memory_limitの値。| 2G |
| LOG_DISK_SIZE           | log_disk_sizeの値。| 2G |
| DATAFILE_SIZE           | datafile_sizeの値。| 2G |
| DATAFILE_NEXT           | datafile_nextの値。| 2G |
| DATAFILE_MAXSIZE        | datafile_maxsizeの値。| 50G |
| INIT_SCRIPTS_PATH       | コンテナ内に含まれる初期化スクリプトのパス。| \ |

seekdbのパラメータをさらに変更したい場合は、設定ファイルを使用してseekdbをデプロイできます。

設定ファイルをコンテナ内の`/etc/oceanbase/seekdb.cnf`にマウントできます。

1. ホストサーバー上に設定ファイルを作成します。デフォルトの設定ファイルは以下のとおりです。

    ```shell
    datafile_size=2G
    datafile_next=2G
    datafile_maxsize=50G
    cpu_count=4
    memory_limit=8G
    log_disk_size=2G
    # config the parameter in the following format
    # key=value
    ```

2. seekdbを起動します。

    ```shell
    docker run -d -p 2881:2881 -v {config_file}:/etc/oceanbase/seekdb.cnf oceanbase/seekdb
    ```

    コマンド内の`{config_file}`は、ホスト上にある設定ファイルのパスです。

    :::tip
      設定ファイルの使用を決定した場合は、リソース関連の環境変数を指定しないでください。
    :::

## データの永続化

seekdbは `/var/lib/oceanbase` ディレクトリにデプロイされます。ホストサーバーにデータを永続化したい場合は、ホストサーバー上の空のディレクトリをこのパスにマウントしてください。

```shell
mkdir -p seekdb
docker run -d -p 2881:2881 -v $PWD/seekdb:/var/lib/oceanbase --name seekdb oceanbase/seekdb
```

## seekdbインスタンスへの接続

ホストのローカルMySQLクライアントを使用して、seekdbインスタンスに接続できます。

```shell
[admin@test001 ~]$ mysql -uroot -h127.0.0.1 -P2881 -p
```

:::info
  seekdbインスタンス起動時に環境変数でパスワードが設定されていない場合、インスタンス内で作成されたユーザーはデフォルトで空のパスワードを使用します。
:::

接続成功後、端末には以下の内容が表示されます：


## obshellダッシュボードへのアクセス

コンテナはobshellも起動し、ユーザーフレンドリーなWebインターフェースを提供します。obshellダッシュボードにアクセスしたい場合は、obshellダッシュボードのポートをマッピングすることもできます。

```shell
# 2886はobshellダッシュボードのポートです
docker run -d -p 2881:2881 -p 2886:2886  oceanbase/seekdb
```

ブラウザで `http://${server_ip}:2886` にアクセスし、ログインパスワードはrootユーザーのパスワードと同じです。`ROOT_PASSWORD` が設定されていない場合は、パスワードフィールドを空のままにしてください。
