# パッケージ管理ツールを使用したseekdbのデプロイ

本記事では、パッケージ管理ツールを使用してseekdbをデプロイする方法について説明します。

## 前提条件

本記事の操作を実行する前に、以下の事項を確認してください：

* お使いの環境がRPMプラットフォームシステムであること。現在サポートされているシステムは以下の通りです。

  * Anolis OS 8.X バージョン（カーネル Linux 4.19 バージョン以上）

  * Anolis OS 23.X バージョン（カーネル Linux 6.6 バージョン以上）

  * Centos Linux 7.X、9.X バージョン（カーネル Linux 4.19 バージョン以上）

  * Debian 11、12、13 バージョン（カーネル Linux 4.19 バージョン以上）

  * openEuler 22.03 および 24.03 バージョン（カーネル Linux 5.10.0 バージョン以上）

  * Ubuntu 20.04、22.04、24.04 バージョン（カーネル Linux 4.19 バージョン以上）

* 現在の環境におけるCPUの最低要件は1コアです。

* 現在の環境における利用可能なメモリの最低容量は2GBです。

* お使いの環境にはjqコマンドラインツールがインストールされており、systemdがシステムおよびサービスマネージャーとして正しく設定されています。

* お使いの環境にはデータベース接続ツール（MySQLクライアント）がインストールされています。

* お使いのユーザーにはsudoコマンドを実行する権限が付与されています。

## seekdbのデプロイ

### ステップ１：seekdbのインストール

使用環境が外部ネットワークに接続できるかどうかに応じて、オンラインインストールとオフラインインストールの2種類のインストール方法があります。

#### オンラインインストール

```shell
curl -fsSL https://obportal.s3.ap-southeast-1.amazonaws.com/download-center/opensource/seekdb/seekdb_install.sh | sudo bash
```

:::tip

オンラインでインストールされるseekdbは最新バージョンです。他のバージョンをインストールする必要がある場合は、**オフラインインストール**を使用してください。

:::

#### オフラインインストール

1. [OceanBaseソフトウェアダウンロードセンター](https://en.oceanbase.com/softwarecenter)から必要なバージョンのseekdbをダウンロードします。ダウンロード完了後、インストーラーファイルをお使いのマシンにコピーします。最新バージョンのインストーラーファイルを使用することを推奨します。

2. インストーラーファイルがあるディレクトリで、rpmコマンドを実行してseekdbをインストールします。

   ```shell
   sudo rpm -ivh seekdb-*.rpm
   ```

### ステップ2：seekdbを起動する

seekdbをインストールした後、以下の手順に従ってseekdbを起動できます。

1. （オプション）設定ファイルを変更する

   この手順に従って設定ファイルを変更できます。変更しない場合は、設定ファイル内のデフォルト設定がデプロイに使用されます。

   ```shell
   sudo vim /etc/oceanbase/seekdb.cnf
   ```

   このファイルに含まれるパラメータの内容は以下のとおりです：

   ```shell
   port=2881
   data-dir=/var/lib/oceanbase/store
   redo-dir=/var/lib/oceanbase/store/redo
   datafile_size=2G
   datafile_next=2G
   datafile_maxsize=50G
   cpu_count=4
   memory_limit=2G
   log_disk_size=2G
   ```

   設定ファイル内のパラメータの説明は以下の表のとおりです：

   |  パラメータ  |  必須    |  デフォルト値  |  説明     |
   |----------|-----------|----------|----------|
   | port | オプション     | 2881    | seekdbのSQLサービスプロトコルポート番号。  |
   | redo_dir  | オプション      | /var/lib/oceanbase/store/redo      | clog、ilogおよびslogのディレクトリです。独立したディスクに設定することを推奨します。<main id="notice" type='explain'><h4>説明</h4><p>データディスク（デフォルトは <code>/var/lib/oceanbase/</code>）の利用可能なディスク容量は15GB以上である必要があります。</p></main> |
   | data_dir  | オプション      | /var/lib/oceanbase/store       | SSTableなどのデータを格納するディレクトリを設定します。独立したディスクに設定することを推奨します。<main id="notice" type='explain'><h4>説明</h4><p>データディスク（デフォルトは <code>/var/lib/oceanbase/</code>）の利用可能なディスク容量は15GB以上である必要があります。</p></main> |
   | datafile_size  | オプション      | 2G        | データファイル（block_file）のサイズを指定します。設定されていない場合は`datafile_disk_percentage`パラメータに準じます。詳細については、[datafile_size](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971955)および[datafile_disk_percentage](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971961)を参照してください。 |
   | datafile_next  | オプション      | 2G        | データファイルの増分サイズを指定します。 |
   | datafile_maxsize  | オプション      | 50G        | データファイルの最大サイズを指定します。 |
   | cpu_count  | オプション   | 4  |  seekdbが使用できるCPUの総数です。0に設定した場合は自動検出されます。   |
   | memory_limit  | オプション      | 2G       | seekdbが環境から取得できる最大メモリです。 |
   | log_disk_size  | オプション      | 2G        | Redoログディスクのサイズを設定します。設定されていない場合は`log_disk_percentage`パラメータに準じます。詳細については、[log_disk_size](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971764)および"log_disk_percentage"(https://en.oceanbase.com/docs/common-oceanbase-database-10000000001971945)を参照してください。|

2. seekdbを起動する

   ```shell
   sudo systemctl start seekdb
   ```

3. seekdbの起動状態を確認する

   ```shell
   sudo systemctl status seekdb
   ```

   状態が `Service is ready` と表示されたら、seekdbが正常に起動したことを意味します。

### ステップ3：seekdbに接続する

ここでは、MySQLクライアントを使用してseekdbに接続する例を示します。コマンドは以下のとおりです：

```shell
mysql -h127.0.0.1 -uroot -P2881 -A test
```

パラメータの説明：

```shell
mysql -h<IP> -uroot -P<Port> -p<Passwd> -A test
```

* -h：seekdbの接続IPを指定します。systemdで起動したseekdbのデフォルトIPは`127.0.0.1`です。

* -u：seekdbの接続アカウントを指定します。形式は`ユーザー名`です。seekdbインスタンスのデフォルトユーザー名は`root`です。

* -P：seekdbの接続ポートを指定します。これは`/etc/oceanbase/seekdb.cnf`ファイル内の`port`の値です。

* -p：seekdbの接続パスワードを指定します。デフォルトは空です。

* -A：MySQLクライアントがデータベースに接続する際に統計情報を自動取得しないことを示します。

* test：アクセスするデータベースの名前です。業務用データベース名に変更できます。

## seekdbの管理

現在、seekdbの起動(start)、停止(stop)、およびステータス(status)の確認は、systemdを介してのみサポートされています。

### seekdbのステータスの確認

以下のコマンドを実行して、seekdbのステータスを確認できます。

```shell
sudo systemctl status seekdb
```

seekdbのステータスには、以下のような状況があります：

* `Active`が`active (running)`と表示され、`Status`が`seekdb is ready and running`と表示されている場合、seekdbは正常に起動されています。

* `Active`が`inactive (dead)`と表示されている場合、サービスは停止されており、つまりseekdbは停止しています。

* `Active`が`failed`と表示されている場合、サービスでエラーが発生しています。ログを確認してトラブルシューティングを行う必要があります。

### seekdbのクリーンアップ

systemdで起動したseekdbをクリーンアップする手順は以下のとおりです。

1. seekdbを停止する

   ```shell
   sudo systemctl stop seekdb
   ```

2. seekdbをアンインストールする

   1. seekdbデータベースソフトウェアパッケージを削除する

      オンラインインストールの場合、以下のコマンドを実行します：

      ```shell
      sudo yum erase seekdb
      ```

      `package`は削除するソフトウェアパッケージ名に置き換えてください。パッケージ名は`yum list | grep seekdb`コマンドで確認できます。

      オフラインインストールの場合、以下のコマンドを実行します：

      ```shell
      sudo rpm -e seekdb
      ```

      `package`は削除するソフトウェアパッケージ名に置き換えてください。パッケージ名は`rpm -qa | grep seekdb`コマンドで確認できます。

   2. seekdbデータを削除する

      最初の手順を実行すると、実行結果に`To clean OceanBase : bash /var/lib/oceanbase/oceanbase_clean.sh`が表示されます。このコマンドを実行することで、seekdbを完全に削除できます。

      この手順でseekdbデータを削除すると、デプロイされたseekdbは完全にアンインストールされます。

      ```shell
      sudo bash /var/lib/oceanbase/oceanbase_clean.sh
      ```
