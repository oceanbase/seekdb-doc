# パッケージ管理ツールによるseekdbのデプロイ

本記事では、パッケージ管理ツールを使用してseekdbをデプロイする方法について説明します。

      ## 前提条件

      本記事の操作を実行する前に、以下の情報を確認してください：

      * お使いの環境がRPMプラットフォームシステムであること。現在サポートされているシステムは以下の通りです。

      * Anolis OS 8.X系（Linuxカーネル4.19バージョン以上）

      * Anolis OS 23.X系（Linuxカーネル6.6バージョン以上）

      * Centos Linux 7.X、9.X系（Linuxカーネル4.19バージョン以上）

      * openEuler 22.03および24.03バージョン（Linuxカーネル5.10.0バージョン以上）

      * 現在の環境でCPUが1コア以上あること。

      * 現在の環境で利用可能なメモリが2GB以上あること。

      * お使いの環境にjqコマンドラインツールがインストールされており、systemdがシステムおよびサービスマネージャーとして正しく設定されていること。

      * お使いの環境にデータベース接続ツール（MySQLクライアント）がインストールされていること。

      * お使いのユーザーがsudoコマンドを実行する権限を持っていること。

      ## seekdbのデプロイ

      ### ステップ１：seekdbのインストール

      使用環境が外部ネットワークに接続できるかどうかに応じて、オンラインインストールとオフラインインストールの2種類のインストール方法があります。

      #### オンラインインストール

      ```shell
      curl -fsSL https://obportal.s3.ap-southeast-1.amazonaws.com/download-center/opensource/seekdb/seekdb_install.sh | sudo bash
      ```

      :::tip

      オンラインでインストールされたseekdbは最新バージョンです。他のバージョンをインストールする必要がある場合は、**オフラインインストール**を使用してください。

      :::

      #### オフラインインストール

      1. [seekdbソフトウェアダウンロードセンター](https://www.oceanbase.ai/download)にアクセスし、**seekdb**を見つけて、ダウンロードしたいバージョン、OS、CPUアーキテクチャを選択して、**ダウンロード**をクリックします。または、**リンクをコピー**をクリックして、サーバー上で直接`wget`コマンドを使用してダウンロードできます。

         :::tip

         CentOS公式ではel8システムのメンテナンスを終了しているため、seekdbはel8版のrpmパッケージを提供していません。お使いのシステムがel8システムの場合は、el7版のrpmパッケージの使用を推奨します。

         :::

      2. インストールパッケージがあるディレクトリで、rpmコマンドを実行してseekdbをインストールします。

         ```shell
         sudo rpm -ivh seekdb-*.rpm
         ```

      ### ステップ2：seekdbの起動

      seekdbのインストール後、以下の手順に従ってseekdbを起動できます。

      1. （オプション）設定ファイルの変更

         この手順を参考に設定ファイルを変更できます。変更しない場合は、設定ファイル内のデフォルト設定を使用してデプロイされます。

         ```shell
         sudo vim /etc/seekdb/seekdb.cnf
         ```

         このファイルに含まれるパラメータの内容は以下の通りです：

         ```shell
         port=2881
         data-dir=/var/lib/oceanbase/store
         redo-dir=/var/lib/oceanbase/store/redo
         cpu_count=4
         memory_limit=2G
         ```

         設定ファイル内のパラメータの紹介は以下の表の通りです：

         |  パラメータ  |  必須      |  デフォルト値  |  説明     |
         |----------|-----------|----------|----------|
         | port     | オプション     | 2881    | seekdbのSQLサービスプロトコルポート番号。  |
         | redo_dir  | オプション      | /var/lib/oceanbase/store/redo      | clog、ilog、slogのディレクトリです。独立したディスクに設定することを推奨します。<main id="notice" type='explain'><h4>説明</h4><p>データディスク（デフォルトは<code>/var/lib/oceanbase/</code>）の利用可能なディスク容量は15GB以上である必要があります。</p></main> |
         | data_dir  | オプション      | /var/lib/oceanbase/store       | SSTableなどのデータを格納するディレクトリです。独立したディスクに設定することを推奨します。<main id="notice" type='explain'><h4>説明</h4><p>データディスク（デフォルトは<code>/var/lib/oceanbase/</code>）の利用可能なディスク容量は15GB以上である必要があります。</p></main> |
         | cpu_count  | オプション   | 4        | seekdbが使用できるCPUの総数です。0に設定すると自動的に検出されます。   |
         | memory_limit | オプション      | 2G        | seekdbが環境から取得できる最大メモリです。 |

      2. seekdbの起動

         ```shell
         sudo systemctl start seekdb
         ```

      3. seekdbの起動状態の確認

         ```shell
         sudo systemctl status seekdb
         ```

         状態が`Service is ready`と表示されたら、seekdbが正常に起動したことを意味します。

      ### ステップ3：seekdbへの接続

      ここではMySQLクライアントを使用してseekdbに接続する例を示します。コマンドは以下の通りです：

      ```shell
      mysql -h<IP> -uroot -P<Port> -p<Passwd> -A -Dtest
      ```

      パラメータの説明：

      * -h：seekdbの接続IPを指定します。systemdで起動したseekdbのデフォルトIPは`127.0.0.1`です。

      * -u：seekdbの接続アカウントを指定します。形式：`ユーザー名`。seekdbインスタンスのユーザー名はデフォルトで`root`です。

      * -P：seekdbの接続ポートを指定します。これは`/etc/oceanbase/seekdb.cnf`の`port`の値で、デフォルト値は2881です。

      * -p：seekdbの接続パスワードを指定します。デフォルトは空です。

      * -A：MySQLクライアントがデータベースに接続する際に統計情報を自動取得しないことを示します。

      * -D：アクセスするデータベースの名前です。業務データベース名に変更できます。

      **例：**

      ```shell
      mysql -h127.0.0.1 -uroot -P2881 -p****** -A -Dtest
      ```

      ## seekdbの管理

      現在、systemdを使用してseekdbを起動(start)、停止(stop)、および状態(status)を確認する操作のみがサポートされています。

      ### seekdbの状態の確認

      以下のコマンドを実行してseekdbの状態を確認できます。

      ```shell
      sudo systemctl status seekdb
      ```

      seekdbの状態を確認すると、以下のような状況があります：

      * `Active`が`active (running)`と表示され、`Status`が`seekdb is ready and running`と表示されている場合、seekdbが正常に起動したことを意味します。

      * `Active`が`inactive (dead)`と表示されている場合、サービスが停止したことを意味します。つまり、seekdbが停止したことを意味します。

      * `Active`が`failed`と表示されている場合、サービスにエラーが発生したことを意味します。ログを確認して調査する必要があります。

      ### seekdbのクリーンアップ

      以下の手順に従って、systemdで起動したseekdbをクリーンアップできます。

      1. seekdbを停止します。

         ```shell
         sudo systemctl stop seekdb
         ```

      2. seekdbをアンインストールします。

         1. seekdbデータベースソフトウェアパッケージの削除

            オンラインインストールの場合、以下のコマンドを実行します：

            ```shell
            sudo yum erase seekdb
            ```

            `package`は削除するソフトウェアパッケージ名に置き換えてください。`yum list | grep seekdb`コマンドでパッケージ名を確認できます。

            オフラインインストールの場合、以下のコマンドを実行します：

            ```shell
            sudo rpm -e seekdb
            ```

            `package`は削除するソフトウェアパッケージ名に置き換えてください。`rpm -qa | grep seekdb`コマンドでパッケージ名を確認できます。

         2. seekdbデータの削除

            最初のステップを実行すると、実行結果に`To clean OceanBase : bash /var/lib/seekdb/seekdb_clean.sh`と表示されます。このコマンドを使用して、seekdbを完全に削除できます。

            このステップでseekdbデータを削除すると、デプロイしたseekdbは完全にアンインストールされます。

            ```shell
            sudo bash /var/lib/seekdb/seekdb_clean.sh
            ```
