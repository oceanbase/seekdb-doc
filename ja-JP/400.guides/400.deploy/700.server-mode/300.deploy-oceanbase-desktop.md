# OceanBase Desktopのデプロイ

本記事では、WindowsおよびmacOSオペレーティングシステムにOceanBase Desktopをデプロイする方法について説明します。

## 背景

OceanBase Desktopは、seekdbを管理および操作するためのデスクトップアプリケーションです。グラフィカルインターフェースを提供し、ユーザーがデータベース管理、クエリ実行、データのインポート・エクスポートなどの操作を容易に行えるようにします。

OceanBase Desktopには以下の特徴があります：

* **グラフィカルインターフェース：** 直感的で使いやすいグラフィカルインターフェースにより、データベース管理タスクが簡素化されます。

* **データベース管理：** データベースインスタンスの作成と管理をサポートします。

* **クエリ実行：** SQLクエリのコマンドラインを提供します。

* **監視とログ：** データベースの状態をリアルタイムで監視します。

    ## 設定の確認

    以下の手順を実行する前に、WindowsオペレーティングシステムにOceanBase Desktopをインストールする前に、使用しているマシンが以下の要件を満たしていることを確認する必要があります：

    * オペレーティングシステムはWindows（x86-64チップ）であること。WSL 2を使用する場合は、Windows 10 バージョン1903以降（ビルド18362以上）またはWindows 11が必要です。

    * 少なくとも1vCPU、2GBのメモリ、5GBのディスク空き容量が必要です。

    以下の手順で、ご使用のマシンが要件を満たしているか確認できます。

    * Windowsバージョンの確認

      キーボードの[Win]キーと[Q]キーを同時に押し、**設定**を検索し、クリックして**設定**画面に入ります。**設定**画面で**システム**をクリックし、スクロールして**詳細情報**を見つけると、Windowsオペレーティングシステムのビルド番号を確認できます。

      <!-- ![バージョン](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-01.png) -->

    * メモリとCPUの確認

      キーボードの[Win]キーと[Q]キーを同時に押し、**タスクマネージャー**を検索し、クリックして開きます。**パフォーマンス**画面に入ります。**パフォーマンス**画面で**CPU**タブに切り替えるとCPUのコア数を確認できます。**メモリ**タブに切り替えるとメモリの使用状況を確認できます。

      <!-- ![CPU](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-03.png) -->

    * ディスクの確認

      キーボードの[Win]キーと[Q]キーを同時に押し、**ファイルエクスプローラー**を検索し、クリックして開きます。**ファイルエクスプローラー**で左側の**このコンピュータ**をクリックし、**デバイスとドライブ**に表示されているディスクの状況を確認します。

    ## 手順

    1. 依存関係のインストール

        WindowsオペレーティングシステムにOceanBase Desktopをインストールするには、WSL（Windows Subsystem for Linux、Linux用Windowsサブシステム）が必要です。WSLはMicrosoft社が2016年にWindows 10プラットフォームでリリースした機能で、ユーザーがWindowsオペレーティングシステム上でELF形式のLinux実行可能ファイルを実行できるようにします。

        WSLには現在、WSL 1とWSL 2の2つの世代があります。WSL 1はLinux互換レイヤーを実装し、LinuxシステムコールをWindows NTシステムコールに変換します。一方、WSL 2はWindowsのHyper-V機能を利用し、仮想化技術を通じてLinux仮想マシンを直接実行するため、よりネイティブなLinuxオペレーティングシステムの体験に近づいています。

        :::tip
        WSL 2はWSL 1のアップグレード版ではないため、WSL 2をインストールするにはWSL 1を先にインストールする必要はありません。OceanBase DesktopイメージはWSL 2のみを使用できます。
        :::

        1. 仮想化が有効になっているか確認する

            キーボードの[Win]キーと[Q]キーを同時に押し、**タスクマネージャー**を検索し、クリックして開きます。**パフォーマンス**画面に入り、**CPU**を確認します。以下の図のように、仮想化が有効になっている場合、**仮想化**列には**有効**と表示されます。**仮想化**列に**無効**と表示されている場合は、以下の手順を参照してBIOSの仮想化機能を有効にしてください。

            <!-- ![仮想化](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-08.png) -->

        2. マザーボードの仮想化を有効にする

            このセクションでは、ThinkPad（レノボのブランド）を例に、BIOSにアクセスしてマザーボードの仮想化を有効にする方法を説明します。コンピュータのブランドによって、BIOSへのアクセス方法やマザーボードの仮想化を有効にする手順は若干異なります。具体的な操作については、各ブランドの公式ウェブサイトをご覧ください。例：[Dell](https://www.dell.com/support/kbdoc/en-us/000195978/how-to-enable-or-disable-hardware-virtualization-on-dell-systems)、[Lenovo](https://support.lenovo.com/us/zc/solutions/ht500006-how-to-enable-virtualization-technology-on-lenovo-computers)、[ThinkPad（レノボのブランド）](https://support.lenovo.com/us/zc/solutions/ht500006-how-to-enable-virtualization-technology-on-lenovo-computers)、[HP](https://support.hp.com/us-en/search?q=enable+virtualization)、[Huawei](https://consumer.huawei.com/en/support/content/en-us15777885/)。または、ブラウザでお使いのコンピュータの型番を検索して操作してください。

            1. **スタート**メニューを開き、**電源**ボタンをクリックし、**再起動**をクリックします。

            2. コンピュータが再起動したら、すぐにキーボードの**F1**キーを押してBIOS設定にアクセスします。

            3. BIOS画面で**Security**オプションをクリックし、**Security**画面で**Security Virtualization**をクリックします。

            4. 対応する設定画面に入ったら、**Virtualization Technology**の後ろのボタンを**on**に調整します。

            5. 調整後、**Save and Exit**をクリックして変更を保存し、BIOS設定を終了します。システムの再起動を待ちます。

            :::info
            有効になった後、前の手順を参照して仮想化が有効になっているか再度確認できます。
            :::

    2. OceanBase Desktopのインストール

        1. インストーラーのダウンロード

            [seekdbソフトウェアダウンロードセンター](https://www.oceanbase.ai/download)にアクセスし、**OceanBase Desktop**を見つけます。ダウンロードするバージョン、オペレーティングシステム、CPUアーキテクチャを選択し、**ダウンロード**をクリックしてダウンロードします。

        2. アプリケーションのインストール

            1. ダウンロードした`OceanBase-Desktop-Setup-x.x.x.exe`ファイルをダブルクリックします。

            2. 表示された**ユーザーアカウント制御**ウィンドウで**はい**をクリックし、アプリケーションがデバイスに変更を加えることを許可します。

            3. 表示された`Installer Language`ページでインストール言語を選択します。デフォルトは中国語(簡体字)です。

              <!-- ![Installer Language](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/deploy/deploy-oceanbase-desktop/installer-language.png) -->

            4. アプリケーションのインストール先を選択します。デフォルトではCドライブにインストールされます。**参照**をクリックして他のフォルダを選択してインストールし、確認後に**インストール**をクリックします。

              <!-- ![インストールディレクトリ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-12.png) -->

            5. インストール完了後、**完了**をクリックすると、OceanBase Desktopが自動的に起動します。

              <!-- ![インストール完了](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-13.png) -->

      3. OceanBase Desktopの起動

          インストール完了後、デスクトップ版を開くと、obshell Dashboardへのログイン画面が表示されます。ログインパスワードはデフォルトで空のままなので、**ログイン**をクリックするだけで入ることができます。

          <!-- ![ログイン](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/deploy/deploy-oceanbase-desktop/oceanbase-desktop-01.png) -->

          obshell Dashboardのページに入ると、インスタンスが自動的に起動します。このページでインスタンスの情報を確認したり、インスタンスを管理したりできます。

          <!-- ![起動](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/deploy/deploy-oceanbase-desktop/oceanbase-desktop-02.png) -->

    4. OceanBase Desktopへの接続

        OceanBase Desktopが正常に起動した後、CLIを使用してOceanBase Desktopに接続できます。接続文字列の例は以下のとおりです：

        ```shell
        wsl.exe -d oceanbase-desktop --exec bash -c "mysql -h127.0.0.1 -P2881 -uroot -Doceanbase -A"
        ```

    ## 設定の確認

    以下の手順を実行する前に、macOSオペレーティングシステムにOceanBase Desktopをインストールする前に、使用しているマシンが以下の要件を満たしていることを確認する必要があります：

    * オペレーティングシステムはmacOS（Apple SiliconチップおよびIntelチップ）であること。

    * 少なくとも1vCPU、2GBのメモリ、5GBのディスク空き容量が必要です。

    以下の手順で、ご使用のマシンが要件を満たしているか確認できます。

    * CPUとメモリの確認

      Finderを開き、**アプリケーション**をクリックします。**アプリケーション**モジュールで**ユーティリティ**フォルダを選択し、その後ダブルクリックして**アクティブモニター**を開きます。アクティブモニターの**CPU**タブでCPUの使用状況を確認できます。**メモリ**タブに切り替えるとメモリの使用状況を確認できます。

      <!-- ![アクティブモニター](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-07.png) -->

    * ディスクの確認

      コンピュータの左上にあるアップルアイコンをクリックし、**このMacについて**をクリックします。表示されたウィンドウで**詳細を見る**をクリックし、**ストレージ**に表示されているディスク情報を確認します。

      <!-- ![ディスク](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-06.png) -->

    ## 手順

    macOSオペレーティングシステムでは、dmgインストーラーパッケージを使用してインストールできます。

    1. デスクトップ版のインストーラーパッケージをダウンロードします。

        [seekdbソフトウェアダウンロードセンター](https://www.oceanbase.ai/download)にアクセスし、**OceanBase Desktop**を見つけます。ダウンロードするバージョン、オペレーティングシステム、CPUアーキテクチャを選択し、**ダウンロード**をクリックしてダウンロードします。

    2. デスクトップ版をインストールします。

        ダウンロードしたインストーラーパッケージをダブルクリックし、指示に従ってインストールを完了します。

    3. デスクトップ版を起動します。

        インストール完了後、デスクトップで**seekdbデスクトップ版**アイコンを見つけてクリックして開きます。

    ## OceanBase Desktopへの接続

    seekdb接続文字列の例は以下のとおりです：

    ```shell
    mysql -h127.0.0.1 -P2881 -uroot -Dtest -A
    ```
