# OceanBase Desktopのデプロイ

本記事では、WindowsおよびmacOSオペレーティングシステムにOceanBase Desktopをデプロイする方法について説明します。

## 背景

OceanBase Desktopは、seekdbを管理および操作するためのデスクトップアプリケーションです。グラフィカルインターフェースを提供し、ユーザーがデータベース管理、クエリ実行、データのインポート・エクスポートなどの操作を容易に行えるようにします。

OceanBase Desktopには以下の特徴があります：

* **グラフィカルインターフェース：** 直感的で使いやすいグラフィカルインターフェースにより、データベース管理タスクが簡素化されます。

* **データベース管理：** データベースインスタンスの作成と管理をサポートします。

* **クエリ実行：** SQLクエリのコマンドラインを提供します。

* **監視とログ：** データベースの状態をリアルタイムで監視します。

## 設定の確認

### Windows オペレーティングシステム

Windows オペレーティングシステムに OceanBase デスクトップをインストールする前に、使用しているマシンが以下の要件を満たしていることを確認してください：

* オペレーティングシステムは Windows（x86-64 チップ）であること。WSL 2 を使用する場合は、Windows 10 バージョン 1903 以降（ビルド 18362 以上）または Windows 11 が必要です。

* 少なくとも 1vCPU、2 GB のメモリ、5 GB のディスク空き容量が必要です。

以下の手順で、お使いのマシンが要件を満たしているかどうか確認できます。

* Windows バージョンの確認

  キーボードの [Win] + [Q] キーを同時に押し、**設定** を検索し、クリックして **設定** ページに入ります。**設定** ページで **システム** をクリックし、スクロールして **詳細情報** を見つけると、Windows オペレーティングシステムのビルド番号を確認できます。

  <!-- ![バージョン](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-01.png) -->

* メモリと CPU の確認

  キーボードの [Win] + [Q] キーを同時に押し、**タスクマネージャー** を検索し、クリックして開きます。**パフォーマンス** タブに移動すると CPU コア数を確認できます。**メモリ** タブに移動するとメモリ使用状況を確認できます。

  <!-- ![CPU](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-03.png) -->

* ディスクの確認

  キーボードの [Win] + [Q] キーを同時に押し、**ファイルエクスプローラー** を検索し、クリックして開きます。**ファイルエクスプローラー** の左側の **このコンピューター** をクリックし、**デバイスとドライブ** に表示されているディスクの状況を確認します。

### macOS オペレーティングシステム

macOS オペレーティングシステムに OceanBase デスクトップをインストールする前に、使用しているマシンが以下の要件を満たしていることを確認してください：

* オペレーティングシステムは macOS（Apple Silicon チップおよび Intel チップ）であること。

* 少なくとも 1vCPU、2 GB のメモリ、5 GB のディスク空き容量が必要です。

以下の手順で、お使いのマシンが要件を満たしているかどうか確認できます。

* CPU とメモリの確認

  Finder を開き、**アプリケーション** をクリックし、**アプリケーション** モジュールで **ユーティリティ** フォルダを選択し、ダブルクリックして **アクティビティモニター** を開きます。アクティビティモニターの **CPU** タブで CPU 使用状況を確認できます。**メモリ** タブに切り替えるとメモリ使用状況を確認できます。

  <!-- ![アクティビティモニター](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-07.png) -->

* ディスクの確認

  コンピューターの左上にある Apple アイコンをクリックし、**この Mac について** をクリックします。表示されたウィンドウで **詳細を見る** をクリックし、**ストレージ** に表示されているディスク情報を確認します。

  <!-- ![ディスク](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-06.png) -->

## 手順

### Windows オペレーティングシステム

1. 依存関係のインストール

   Windows オペレーティングシステムに OceanBase Desktop をインストールするには、WSL（Windows Subsystem for Linux、Linux 用 Windows サブシステム）が必要です。WSL は Microsoft が 2016 年に Windows 10 プラットフォームでリリースした機能で、ユーザーが Windows オペレーティングシステム上で ELF 形式の Linux 実行可能ファイルを実行できるようにします。

   WSL には現在、WSL 1 と WSL 2 の 2 つの世代があります。WSL 1 は Linux 互換レイヤーを実装し、Linux システムコールを Windows NT システムコールに変換します。一方、WSL 2 は Windows の Hyper-V 機能を利用し、仮想化技術を通じて Linux 仮想マシンを直接実行するため、よりネイティブな Linux オペレーティングシステムの体験に近づいています。

   :::tip
   WSL 2 は WSL 1 のアップグレード版ではないため、WSL 2 をインストールするには WSL 1 を先にインストールする必要はありません。OceanBase Desktop イメージは WSL 2 のみで使用できます。
   :::

   1. 仮想化が有効になっているか確認する

      キーボードの [Win] + [Q] キーを同時に押して **タスクマネージャー** を検索し、開いた後に **パフォーマンス** ウィンドウに移動して **CPU** を確認します。以下の図のように、仮想化が有効になっている場合、**仮想化** 列には **有効** と表示されます。**仮想化** 列に **無効** と表示されている場合は、以下を参照して BIOS 内の仮想化機能を有効にしてください。

      <!-- ![仮想化](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-08.png) -->

   2. マザーボードの仮想化を有効にする

      このセクションでは、ThinkPad（レノボ傘下ブランド）での操作を例に、BIOS にアクセスしてマザーボードの仮想化を有効にする方法を説明します。コンピュータのブランドによって、BIOS へのアクセス方法やマザーボードの仮想化を有効にする手順は若干異なります。具体的な操作については、各ブランドの公式 Web サイトをご覧ください。例えば、[Dell](https://www.dell.com/support/kbdoc/zh-cn/000195978/how-to-enable-or-disable-hardware-virtualization-on-dell-systems?lang=en)、[Lenovo](https://support.lenovo.com/us/en/solutions/ht500006-how-to-enable-virtualization-technology-on-lenovo-computers)、[ThinkPad（レノボ傘下ブランド）](https://support.lenovo.com/us/en/solutions/ht500006-how-to-enable-virtualization-technology-on-lenovo-computers)、[HP](https://support.hp.com/us-en/search?q=enable%20virtualization)、[Huawei](https://en.oceanbase.com/softwarecenter) などです。または、ブラウザでお使いのコンピュータの型番を検索して操作を行ってください。

      1. **スタート** メニューを開き、**電源** ボタンをクリックし、**再起動** をクリックします。

      2. コンピュータが再起動したら、すぐにキーボードの **F1** キーを押して BIOS 設定にアクセスします。

      3. BIOS ページで **Security** オプションをクリックし、**Security** ページで **Security Virtualization** をクリックします。

      4. 対応する設定ページに進んだら、**Virtualization Technology** の後ろのボタンを **no** に調整します。

      5. 調整後、**Save and Exit** をクリックして変更を保存し、BIOS 設定を終了します。システムの再起動を待ちます。

      :::info
      有効になった後は、前の手順を参照して仮想化が有効になっているか再度確認できます。
      :::

2. OceanBase Desktop のインストール

   1. インストーラーのダウンロード

      [OceanBase ソフトウェアダウンロードセンター](https://en.oceanbase.com/softwarecenter) にアクセスし、**OceanBaseデスクトップ版ワンクリックデプロイインストーラーパッケージ** を見つけて、**Windows版-1.3** をダウンロードします。

   2. アプリケーションのインストール

      1. ダウンロードした `OceanBase-Desktop-Setup-x.x.x.exe` ファイルをダブルクリックします。

      2. 表示された **ユーザーアカウント制御** ウィンドウで **はい** をクリックし、アプリケーションがデバイスに変更を加えることを許可します。

      3. 表示された `Installer Language` ページでインストール言語を選択します。デフォルトは中国語(簡体字)です。

         <!-- ![Installer Language](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/deploy/deploy-oceanbase-desktop/installer-language.png) -->

      4. アプリケーションのインストール先を選択します。デフォルトでは C ディスクにインストールされます。**参照** をクリックして他のフォルダを選択してインストールすることもできます。確認後、**インストール** をクリックします。

         <!-- ![インストールディレクトリ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-12.png) -->

      5. インストール完了後、**完了** をクリックすると、OceanBase Desktop が自動的に起動します。

         <!-- ![インストール完了](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-13.png) -->

   3. OceanBase Desktop の起動

      インストール完了後、デスクトップ版を開くと、obshell Dashboard へのログイン画面が表示されます。ログインパスワードはデフォルトで空のままなので、**ログイン** をクリックすると直接入室できます。

      <!-- ![ログイン](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/deploy/deploy-oceanbase-desktop/oceanbase-desktop-01.png) -->

      obshell Dashboard ページに入ると、インスタンスが自動的に起動します。このページでインスタンスの情報を確認したり、インスタンス管理を行ったりできます。

      <!-- ![起動](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/deploy/deploy-oceanbase-desktop/oceanbase-desktop-02.png) -->

3. OceanBase Desktop への接続

   OceanBase Desktop が正常に起動した後、CLI を使用して OceanBase Desktop に接続できます。接続文字列の例は以下のとおりです：

   ```shell
   wsl.exe -d oceanbase-desktop --exec bash -c "mysql -h127.0.0.1 -P2881 -uroot -Doceanbase -A"
   ```

### macOS オペレーティングシステム

macOS オペレーティングシステムでは、Homebrew によるインストールと dmg インストーラーによるインストールの 2 種類の方法が提供されています。このセクションでは、それぞれについて説明します。

* Homebrew によるインストール

  1. Homebrew のインストール

     現在の環境に Homebrew がインストールされていない場合は、以下のコマンドを実行してインストールします。

     ```shell
     /bin/bash -c "$(curl -fsSL https://gitee.com/cunkai/HomebrewCN/raw/master/Homebrew.sh)"
     ```

  2. OceanBase Desktop の Tap を追加する

     OceanBase Desktop の Tap を Homebrew に追加すると、`brew install` コマンドで SeekDB が提供する公式パッケージをインストールできるようになります。

     ```shell
     brew tap oceanbase/homebrew-oceanbase-desktop https://gitee.com/oceanbase/homebrew-oceanbase-desktop.git
     ```

  3. OceanBase Desktop のインストール

     ```shell
     brew install --cask oceanbase-desktop
     ```

     コマンドを実行すると、最新バージョンの OceanBase Desktop が自動的にダウンロードされます。また、依存関係として OrbStack もインストールされます（環境内にまだインストールされていない場合）。インストールが完了すると、アプリケーションはアプリケーションフォルダに配置されます。

  4. アプリケーションの起動

     アプリケーションフォルダ内で `OceanBase Desktop` を見つけるか、Spotlight で `OceanBase Desktop` を検索し、ダブルクリックして起動します。アプリケーションを初めて起動する際は、プログラムがバックグラウンドで初期化を行うため、しばらくお待ちください。アプリケーションに入ったら、ページ内の **起動** ボタンをクリックすると seekdb が起動します。

  :::info
    OceanBase Desktop をアンインストールする必要がある場合は、<code>brew uninstall --cask oceanbase-desktop</code> コマンドを実行します。このコマンドは、アプリケーションファイル、アプリケーションサポートデータ、保存されたアプリケーション状態、およびアプリケーション仮想マシンを同時にクリーンアップします。
  :::

* dmg インストーラーによるインストール

  1. 依存関係のインストール

      macOS に OceanBase Desktop をインストールするには、OrbStack が必要です。OrbStack は、macOS ユーザー向けに設計された、現代的なコンテナおよび仮想マシン管理ツールです。効率的なコンテナの実行（Docker コンテナなど）と軽量級仮想マシンのサポートを提供することを目的としています。その目標は、Docker Desktop やその他の複雑な仮想化ツールを置き換え、性能を大幅に向上させ、システムリソースを節約し、開発者の使い勝手を簡素化することです。

      :::info
         OrbStack の公式チュートリアルでは、インストール方法としてインストーラーのダウンロードと brew コマンドの実行の 2 種類が紹介されています。ここではインストーラーのダウンロードによるインストールを例に説明します。その他の方法については、[公式チュートリアル](https://docs.orbstack.dev/quick-start)を参照してください。
      :::

     1. インストーラーのダウンロード

        [公式サイトのダウンロードリンク](https://orbstack.dev/download)からインストーラーをダウンロードします。リンクは、オペレーティングシステムで使用されているチップ（Apple Silicon チップと Intel チップ）に応じて、2 つのインストーラーに分かれています。コンピュータの左上の Apple アイコンをクリックし、次に **この Mac について** をクリックすると、コンピュータで使用されているチップの種類を確認できます。

        ![プロセッサ](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.oceanbase-desktop/800.deploy-oceanbase-desktop-10.png)

     2. インストール

        対応する dmg インストーラーをダブルクリックし、アイコンを Applications フォルダにドラッグしてインストールします。

        :::tip
          初回インストールの場合は、必ず OrbStack の初期ガイドプロセスを完了してください。そうでないと、イメージを正常にインポートできません。
        :::

        <!-- ![インストール](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.deploy-oceanbase-desktop/800.deploy-oceanbase-desktop-06.png) -->

     3. （オプション）インストールの成功を確認する

        Machines（仮想マシン）セクションを選択し、最新の Ubuntu イメージをインストールします。このプロセスでは長時間待機する必要があるため、しばらくお待ちください。

        <!-- ![ubuntu](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.deploy-oceanbase-desktop/800.deploy-oceanbase-desktop-07.png) -->

        インストール完了後、対応する仮想マシンをダブルクリックします。コマンドラインのリンク画面にアクセスできれば、OrbStack が正常にインストールされたことを意味します。

        <!-- ![検証](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/400.deploy/800.deploy-oceanbase-desktop/800.deploy-oceanbase-desktop-08.png) -->

  2. OceanBase Desktop のインストール

      1. インストーラーのダウンロード

         [OceanBase ソフトウェアダウンロードセンター](https://www.oceanbase.com/softwarecenter)にアクセスし、**OceanBaseデスクトップ版ワンクリックデプロイインストーラー**を見つけて、**Mac版-1.3**をダウンロードします。

      2. アプリケーションのインストール

         対応するインストーラーをクリックし、アイコンを Applications フォルダにドラッグしてインストールします。

      3. OceanBase Desktop の起動

         インストール完了後、`停止` 状態の seekdb が自動的にデプロイされます。グラフィカルページの **起動** ボタンをクリックすると seekdb が起動します。
