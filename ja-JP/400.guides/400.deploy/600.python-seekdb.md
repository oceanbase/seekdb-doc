# 埋め込みモード

seekdbは埋め込みデプロイメント方式を提供しており、「データベース」としてアプリケーション内部で動作させることができます。これにより、様々な「エンドポイント」上で簡単に実行でき、モバイルアプリケーション開発、デスクトップアプリケーション開発、IoT（Internet of Things）およびエッジデバイス上のアプリケーション開発に適しています。

pyseekdb（seekdbが提供するPython SDK）を使用して、埋め込み型seekdbをデプロイできます。

## 環境要件

* サポートOS：Linux（glibc >= 2.28）

* サポートPythonバージョン：

  * pyseekdbを使用したseekdbのデプロイ：Python 3.11 ～ 3.13

  * Pythonを使用したseekdbのデプロイ：CPython 3.8 ～ 3.14

* サポートシステムアーキテクチャ：x86_64、aarch64

以下のコマンドを実行して、環境が要件を満たしているか確認できます。

```python
python3 -c 'import sys;import platform; print(f"Python: {platform.python_implementation()} {platform.python_version()}, System: {platform.system()} {platform.machine()}, {platform.libc_ver()[0]}: {platform.libc_ver()[1]}");'
```

結果は次のとおりです：

```python
Python: CPython 3.8.17, System: Linux x86_64, glibc: 2.32
```

## pyseekdbを使用したseekdbのデプロイ

pipを使用してインストールすると、埋め込み型seekdbが自動的にロードされます。具体的なコマンドは以下のとおりです。

```shell
pip install -U pyseekdb
# または、インストールソースを指定して高速化
pip install -U pyseekdb -i https://pypi.tuna.tsinghua.edu.cn/simple
```

## 注意事項

seekdbのデプロイ時にpipバージョンが低すぎるというエラーが表示された場合は、まずpipをアップグレードしてからインストールしてください。

```bash
pip install --upgrade pip
```
