# サーバーの準備

このセクションでは、seekdbをデプロイするために必要なサーバーの台数と仕様、およびオペレーティングシステムやBIOS設定などのソフトウェア・ハードウェア要件について説明します。

## サーバー構成要件

サーバーが満たすべき最低構成要件は、次の表のとおりです。

| デプロイする製品 | サーバー数 | 最低構成 | ディスクタイプ |
|---------|-----------|-------------|-------------|
| seekdb | 1台 | 最低要件：CPU 1コア、使用可能メモリ2GB |  SSDストレージ |

:::info
  <ul>
    <li>ディスクでは、ログディスクはメモリの1倍以上が必要であり、データディスクは対象データ量を格納できる容量が必要です。</li>
    <li>ここで記載されているリソース要件は、seekdb用に予約されたリソースを指し、サーバー自体の全リソースを指すものではありません。</li>
  </ul>
:::

## ハードウェア環境要件

### メモリ

以下のコマンドを実行して、メモリ使用量を確認します：

```shell
free -g
```

実行結果は次のとおりです：

```shell
              total        used        free      shared  buff/cache   available
Mem:            174          38           6           0         129         123
Swap:             0           0           0
```

ここでは、availableのMem値が上記の**サーバー構成要件**で定められた構成を満たす十分な値であることを保証する必要があります。不足している場合は、キャッシュをクリーンアップしてリソースの一部を解放するか、サーバーを交換してください。

以下のコマンドを実行して、キャッシュをクリーンアップします：

```shell
sudo sysctl -w vm.drop_caches=3
# または
sudo echo 3 > /proc/sys/vm/drop_caches
```

#### カーネルの確認

サーバーのカーネル情報を確認し、オペレーティングシステムが3.10.0以上であることを確認します。また、カーネル情報に基づいて、対応するデプロイメントインストールパッケージを選択します。

以下のコマンドを実行して、カーネル情報を確認します：

```shell
uname -a
```

### seekdbサーバーのBIOS設定

#### BIOSでオフにする必要があるオプション

* Cstate

* Pstate

* EIST

* Power saving

#### BIOSで設定する必要があるオプション

* Automatic Power on After Power Loss: Always on

* Intel Virtualization Technology：有効

* Hyper-threading：有効

* Hardware prefetcher：有効

* VT-d：有効

* SR-IOV：有効

* Turbo Mode：有効

* Energy performance：最大パフォーマンスを有効にする

  :::info
    サーバーによってBIOSの変更方法は異なります。具体的な操作手順については、サーバーのマニュアルを参照してください。
  :::
