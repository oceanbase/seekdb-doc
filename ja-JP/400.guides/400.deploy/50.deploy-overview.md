# デプロイの概要

seekdbは2つのデプロイモードを提供しており、ビジネスシナリオに応じて適切なモードを選択できます。

* 埋め込みモード：seekdbは「データベース」としてアプリケーション内部で動作し、さまざまな「エンド」で簡単に稼働できます。モバイルアプリケーション開発、デスクトップアプリケーション開発、IoTおよびエッジデバイス上のアプリケーション開発に適しています。このモードでは、PythonスクリプトまたはSDKを使用してseekdbに接続し、管理と利用を行えます。

* サーバーモード：単一サーバーでのデプロイが可能で、CI/CDやテストに適しています。シンプルで運用コストが低く、サーバーの起動も速いです。このモードでは、MySQLクライアントまたはSDKを使用してseekdbに接続し、管理と利用を行えます。

## デプロイ方法

異なるデプロイモードでは多様なデプロイ方法が提供されており、ニーズに合わせて選択できます。

* 埋め込みモード：

   * seekdbが提供するpyseekdb SDKを使用してseekdbをデプロイします。

      詳細なデプロイ手順については、[埋め込みモード](600.python-seekdb.md)を参照してください。

* サーバーモード：

  * yum installを使用してseekdbをデプロイします。

      詳細なデプロイ手順については、[yum installを使用したseekdbのデプロイ](700.server-mode/100.deploy-by-systemd.md)を参照してください。

  * seekdbコンテナ環境をデプロイします。

      詳細なデプロイ手順については、[seekdbコンテナ環境のデプロイ](700.server-mode/200.deploy-by-docker.md)を参照してください。

  * OceanBase Desktopをデプロイします。

      OceanBase Desktopは、seekdbを管理および操作するためのデスクトップアプリケーションです。グラフィカルインターフェースを提供し、ユーザーがデータベース管理、クエリ実行、データのインポート・エクスポートなどの操作を容易に行えるようにします。

      詳細なデプロイ手順については、[OceanBase Desktopのデプロイ](700.server-mode/300.deploy-oceanbase-desktop.md)を参照してください。
