# デプロイ前の設定概要

seekdbをより良く利用するためには、オペレーティングシステムとインストール環境を設定する必要があります。それぞれ以下の通りです。

| パラメータ | パーソナル試用シナリオ | 本番環境 | 説明 |
| ------ | ------- | ------- | ---- |
| [ユーザーの作成](300.create-regular-user.md) | rootユーザーを使用できます。 | sudo権限を持つユーザーの使用を推奨します。 | sudo権限を持つ一般ユーザーを使用できます。 |
| [ディスクの計画](400.plan-disks.md) | 設定は不要です | 設定を推奨します | 本番環境では、ログ保存ディレクトリとデータ保存ディレクトリを異なるディスクに配置することを推奨します。これにより、高負荷シナリオで両ディレクトリが同一ディスクに配置されている場合に発生する可能性のあるパフォーマンス問題を回避できます。|
| [limits.confの設定](500.configure-limits-conf.md) | 設定は不要です | 設定を推奨します | 実行時の安定性とパフォーマンスを向上させます。 |
| [sysctl.confの設定](600.configure-sysctl-conf.md) | 設定は不要です | 設定を推奨します | Linuxシステムのパフォーマンスを向上させ、seekdbのパフォーマンスも向上させます。 |
| [ファイアウォールとSELinuxの無効化](700.disable-firewall-and-selinux.md) | 設定を推奨します | 設定を推奨します | データベースへのアクセスがファイアウォールやSELinuxによって遮断されるのを防ぎます。 |
