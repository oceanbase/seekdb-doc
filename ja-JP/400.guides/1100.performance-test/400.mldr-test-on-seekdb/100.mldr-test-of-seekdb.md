# seekdb MLDRテスト

本記事では、MLDRを使用してseekdbのパフォーマンステストを行う方法について説明します。

## MLDRとは

MLDRはMulti-Lingual Document Retrievalの略であり、多言語文書検索システムの性能を評価・テストするためのデータセットテストフレームワークです。複数のクエリタイプ（BM25、Dense Vector、ハイブリッド検索など）をサポートしています。

### サポートされているクエリタイプ

| クエリタイプ | 説明 | 対応バックエンド |
|---------|------|---------|
| `bm25` | BM25全文検索 | OceanBaseデータベース、seekdb |
| `dense` | Denseベクトル検索 | OceanBaseデータベース、seekdb |
| `hybrid_dense_bm25` | Dense+BM25ハイブリッド検索 | OceanBaseデータベース、seekdb |

### 評価指標

* **Recall@10**：上位10件の結果に対する再現率。
* **NDCG@10**：正規化損失累積利得。
* **平均クエリ時間**：単一クエリの平均応答時間。

## 環境の準備

テストを開始する前に、以下の要件に従ってテスト環境を準備してください：

* Pythonは3.11以降のバージョンが必要です。

* JDK：pyseriniを使用するため、11以降のバージョンが必要です。

* seekdb：サーバーモードのseekdbを使用します。詳細なデプロイ操作については、[yum installでseekdbをデプロイする](../../400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* デプロイされたseekdbに対応するログディスク、clogディスク、dataディスクの3つのディスクを使用し、パフォーマンスレベルはPL1に設定します。seekdb起動時に、`/etc/oceanbase/seekdb.cnf` ファイルに以下のパラメータを設定する必要があります：

   ```shell
   port=2881
   base-dir=/data/1/seekdb
   data-dir=/data/2/seekdb
   redo-dir=/data/3/seekdb
   ```

## テスト計画

* 本テストでは2台のマシンを使用します。MLDRは1台のマシンに、seekdbはもう1台のマシンにデプロイします。seekdbの仕様は4C8Gで、ログディスク、clogディスク、dataディスクの3つのディスクに分かれており、パフォーマンスレベルはPL1です。

* テストデータ量：200,000件。

* MLDRデータセットを使用して、seekdbのリコール率を評価します。

## MLDRツールを使用したMLDRテストの手動実行

### ステップ１：seekdb接続文字列を取得する

```shell
mysql -hxx.xx.xx.xx -P2881 -uroot -p**** -A
```

### ステップ２：Java環境をインストールする

```bash
sudo dnf install java-11-openjdk-devel -y
export JAVA_HOME=/usr/lib/jvm/java-11-openjdk
export JVM_PATH=$JAVA_HOME/lib/server/libjvm.so
```

### ステップ３：Python仮想環境を作成する

1. Condaをダウンロードしてインストールします。

   ```bash
   mkdir -p ~/miniconda3
   wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O ~/miniconda3/miniconda.sh
   bash ~/miniconda3/miniconda.sh -b -u -p ~/miniconda3
   rm ~/miniconda3/miniconda.sh
   ```

2. ターミナルを再起動し、Condaを初期化します。

   ```bash
   source ~/miniconda3/bin/activate
   conda init --all
   ```

3. MLDRに必要なPython環境を新規作成して初期化します。

   ```bash
   conda create -n test python=3.11
   conda activate test
   ```

### ステップ４：MLDRをダウンロードする

```bash
git clone https://github.com/oceanbase/ob-mldr-test
cd ob-mldr-test
```

### ステップ５：Python依存関係をインストールする

1. pipをアップグレードします。

   ```bash
   pip install --upgrade pip
   ```

2. 依存関係をインストールします。

   ```bash
   pip install -r requirements.txt
   ```

### ステップ６：データベース情報を設定する

1. サンプル設定ファイルをコピーします。

   ```shell
   cp config.yaml.example config.yaml
   ```

2. 設定ファイルを編集し、データベース情報をご自身の設定に置き換えます。

   ```shell
   vim config.yaml
   ```

   主に変更が必要なパラメータは以下のとおりです：

   ```shell
   oceanbase.host：データベースホストアドレス
   oceanbase.port：データベースポート番号
   oceanbase.user：データベースユーザー名
   oceanbase.password：データベースパスワード
   oceanbase.database：データベース名
   embedding.vector_download_url：ベクトルファイルのダウンロードURL（ベクトル検索を使用する場合）
   ```

### ステップ7：ワンクリックで完全なテストを実行する

```bash
# 英語のハイブリッド検索テスト
python mldr_test_runner.py --lang en --query-type hybrid_dense_bm25

# データ挿入をスキップ（データは既に存在する）
python mldr_test_runner.py --lang en --query-type hybrid_dense_bm25 --skip-insert
```

パラメータの詳細は以下のとおりです：

| パラメータ | 型 | デフォルト値 | 説明 |
|------|------|--------|------|
| `--lang` | str | `en` | テスト言語（例：`en`、`zh`など） |
| `--backend` | str | `oceanbase` | データベースのバックエンド（現在は `oceanbase` のみサポート） |
| `--query-type` | str | `bm25` | クエリタイプ。選択可能な値：`hybrid_dense_bm25`（ハイブリッド検索）、`dense`（ベクトル検索）、`bm25`（全文検索） |
| `--skip-insert` | flag | `False` | データ挿入ステップをスキップします（データが既に存在する場合に使用） |
| `--result-dir` | str | `一時ディレクトリ` | 結果保存ディレクトリ |
| `--config` | str | `None` | 設定ファイルパス（YAML形式）。デフォルトでは現在のディレクトリ配下の `config.yaml` を使用します |

### テストプロセスの説明

テストフレームワークは、以下の手順を自動的に実行します：

1. **データ挿入**：200,000件のテストデータを挿入し、インデックスを作成します。
2. **ウォームアップテスト**（オプション）：検索のウォームアップを1回実行します。
3. **本番テスト**：指定された回数の検索と評価を実行します。
4. **結果出力**：平均Recall@10、NDCG@10、平均遅延を表示します。
