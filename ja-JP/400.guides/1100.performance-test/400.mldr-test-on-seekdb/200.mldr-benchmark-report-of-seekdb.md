# seekdb MLDRテストレポート

本記事では、MLDRテストのテスト環境、テスト計画、および詳細なテストデータ結果について説明します。

## テスト計画

* 今回のテストでは、2台のマシンを使用します。MLDRは1台のマシンに、seekdbはもう1台のマシンにデプロイされます。seekdbの仕様は4C8Gで、ログディスク、clogディスク、dataディスクの3つのディスクに分かれており、パフォーマンスレベルはPL1です。

* テストデータ量：200,000件。

* MLDRデータセットを使用して、seekdbのリコール率を評価します。

テスト手順の詳細については、[seekdb MLDRテスト](100.mldr-test-of-seekdb.md)を参照してください。

## テスト環境

Alibaba Cloud ECSをデプロイ環境として例にすると、テストで使用されるseekdbの仕様は4C8Gです。

* seekdbの仕様が4C8Gの場合、対応するハードウェア構成とソフトウェアバージョンは以下のとおりです：

  * ハードウェア構成

    | サービスタイプ | ECSタイプ | インスタンス数 | マシンコア数 | メモリ |
    | ------- | -------- | ----- | --------- | ---- |
    | seekdb | ecs.c8i.xlarge  | 1 | 4C | 8G |

  * ソフトウェアバージョン

    | サービスタイプ | ソフトウェアバージョン |
    | ------- | ------- |
    | seekdb | seekdb 1.1.0 |
    | OS              | CentOS Linux 7 (Core) |

## テスト結果

今回のMLDRテストでは、すべて単一スレッドでのウォームアップ後の最適RTデータを採用しており、返されるデータはlimit 1000で取得されます。

テスト結果は以下のとおりです：

| seekdb      |    dense+bm25  |
|------------|-------------|
| seekdb   | ndcg@10: 0.6329 <br/> recall@10: 0.7425 <br/> rt: 150.39ms |
