# seekdb Sysbenchテストレポート

本記事では、Sysbenchテストのテスト環境、テスト計画、および詳細なテストデータ結果について説明します。

## テスト計画

* 本テストでは2台のマシンを使用します。Sysbenchは1台のマシンに、seekdbはもう1台のマシンにデプロイします。seekdbの構成は4C8Gまたは1C2Gで、ログディスク、clogディスク、dataディスクの3つのディスクに分かれており、パフォーマンスレベルはPL1です。

* Sysbenchを使用して30個のテーブルをインポートします。各テーブルには1万行のデータがあります。

* Sysbenchクライアントを起動し、`point_select`、`read_write`、`read_only`、`insert`、`update`、`write_only` テストを実行します。

* 各テストラウンドの `--time` を10秒に設定し、スレッド数は `10/50/100/200/400` などに設定できます。

テスト手順の詳細については、[seekdb Sysbenchテスト](100.use-sysbench-to-test-the-performance-of-seekdb.md)を参照してください。

## テスト環境

Alibaba Cloud ECSをデプロイ環境として例にすると、テストで使用されるseekdbの構成は1C2Gと4C8Gです。

* seekdbの構成が4C8Gの場合、対応するハードウェア構成とソフトウェアバージョンは以下のとおりです：

    * ハードウェア構成

        | サービスタイプ | ECSタイプ | インスタンス数 | マシンのコア数 | メモリ |
        | ------- | -------- | ----- | --------- | ---- |
        | seekdb | ecs.c8i.xlarge  | 1 | 4C | 8G |
        | Sysbench          | ecs.g8i.4xlarge   | 1 | 16C | 64G |

    * ソフトウェアバージョン

        | サービスタイプ | ソフトウェアバージョン |
        | ------- | ------- |
        | seekdb | SeekDB 1.0.0.0 |
        | Sysbench        | 1.1.0 |
        | OS              | CentOS Linux 7 (Core) |

* seekdbの構成が1C2Gの場合、対応するハードウェア構成とソフトウェアバージョンは以下のとおりです：

    * ハードウェア構成

        | サービスタイプ | ECSタイプ | インスタンス数 | マシンのコア数 | メモリ |
        | ------- | -------- | ----- | --------- | ---- |
        | seekdb | ecs.c8i.large  | 1 | 2C(購入時にアクティブvCPUを1に設定) | 4G(利用可能メモリ3G)、`memory_limit`を2Gに設定 |
        | Sysbench          | ecs.g8i.4xlarge   | 1 | 16C | 64G |

    * ソフトウェアバージョン

        | サービスタイプ | ソフトウェアバージョン |
        | ------- | ------- |
        | seekdb | SeekDB 1.0.0.0 |
        | Sysbench        | 1.1.0 |
        | OS              | CentOS Linux 7 (Core) |
