# seekdb TPC-H ベンチマークレポート

本記事では、TPC-H ベンチマークのテスト環境、テスト計画、および詳細なテストデータ結果について説明します。

## テスト計画

* 今回のテストでは、2台のマシンを使用します。TPC-Hは1台のマシンに、seekdbはもう1台のマシンにデプロイされます。seekdbの仕様は4C8Gで、ログディスク、clogディスク、dataディスクの3つのディスクに分かれており、パフォーマンスレベルはPL1です。

* テストデータ量：10G。

テスト手順の詳細については、[seekdb TPC-H ベンチマークテスト](200.tpc-h-benchmark-report-of-seekdb.md)を参照してください。

## テスト環境

Alibaba Cloud ECS をデプロイ環境として例にすると、テストで使用される seekdb の仕様は4C8G です。

* seekdb の仕様が4C8G の場合、対応するハードウェア構成とソフトウェアバージョンは以下のとおりです：

  * ハードウェア構成

    | サービスタイプ | ECSタイプ | インスタンス数 | マシンコア数 | メモリ |
    | ------- | -------- | ----- | --------- | ---- |
    | seekdb | ecs.c8i.xlarge  | 1 | 4C | 8G |

  * ソフトウェアバージョン

    | サービスタイプ | ソフトウェアバージョン |
    | ------- | ------- |
    | seekdb | seekdb 1.1.0 |
    | TPC-H        | V3.0.0 |
    | OS              | CentOS Linux 7 (Core) |
