# seekdb VectorDBBench テストレポート

本記事では、VectorDBBenchテストのテスト環境、テスト計画、および詳細なテストデータ結果について説明します。

## テスト環境

Alibaba Cloud ECSをデプロイ環境として例に挙げると、テストで使用されるseekdbの仕様は1C2Gと4C8Gです。

* seekdbの仕様が4C8Gの場合、対応するハードウェア構成とソフトウェアバージョンは以下の通りです：

    * ハードウェア構成

        | サービスタイプ | ECSタイプ | インスタンス数 | マシンコア数 | メモリ |
        | ------- | -------- | ----- | --------- | ---- |
        | seekdb | ecs.c8i.xlarge  | 1 | 4C | 8G |
        | VectorDBBench  | ecs.g8i.4xlarge   | 1 | 16C | 64G |

    * ソフトウェアバージョン

        | サービスタイプ | ソフトウェアバージョン |
        | ------- | ------- |
        | seekdb | seekdb 1.1.0 |
        | VectorDBBench     | 1.0.14 |
        | OS              | CentOS Linux 7 (Core) |

* seekdbの仕様が1C2Gの場合、対応するハードウェア構成とソフトウェアバージョンは以下の通りです：

    * ハードウェア構成

        | サービスタイプ | ECSタイプ | インスタンス数 | マシンのコア数 | メモリ |
        | ------- | -------- | ----- | --------- | ---- |
        | seekdb | ecs.c8i.large  | 1 | 2C(購入時にアクティブvCPUを1に設定) | 4G(利用可能メモリ3G)、`memory_limit`を2Gに設定 |
        | VectorDBBench          | ecs.g8i.4xlarge   | 1 | 16C | 64G |

    * ソフトウェアバージョン

        | サービスタイプ | ソフトウェアバージョン |
        | ------- | ------- |
        | seekdb | seekdb 1.1.0 |
        | VectorDBBench    | 1.0.14 |
        | OS              | CentOS Linux 7 (Core) |

## テスト計画

* 今回のテストでは2台のマシンを使用し、VectorDBBenchを1台のマシンに、seekdbをもう1台のマシンにデプロイします。seekdbの仕様は4C8Gまたは1C2Gで、ログディスク、clogディスク、dataディスクの3つのディスクに分かれており、パフォーマンスレベルはPL1です。

* 使用するデータセットはPerformance1536D50K、インデックスタイプはHNSWで、VectorDBBenchを用いてseekdbのqps、latency(p99)、リコール率をテストします。

テスト手順の詳細は[seekdb VectorDBBenchテスト](100.ob-vector-search-bench-test.md)を参照してください。

## テスト結果

リコール率0.98でテストを実施しました。

* seekdbの仕様が4C8Gの場合、対応するパフォーマンスデータは以下の通りです：

    | ef_search | qps | serial_latency_p99 | 召回率 |
    |----------------------|----------------------|---------------|--------------|--------------|
    | 180 | 2342.3263 | 0.0022 | 0.9801 |

* seekdbの仕様が1C2Gの場合、対応するパフォーマンスデータは以下の通りです：

    | ef_search | qps | serial_latency_p99 | 召回率 |
    |----------------------|----------------------|---------------|--------------|--------------|
    | 180 | 811.2516 | 0.0025 | 0.9802 |
