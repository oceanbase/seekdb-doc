# seekdb VectorDBBenchテスト

VectorDBBenchは、主要なベクトルデータベースとクラウドサービスのベンチマーク結果を提供するツールです。このドキュメントでは、VectorDBBenchを使用してseekdbの性能をテストします。VectorDBBenchは使いやすさを重視して設計されており、結果の再現や新しいシステムのテストを容易に行えます。

## 前提条件

* seekdb：サーバーモードのseekdbを使用します。詳細なデプロイ操作については、[yum installでseekdbをデプロイする](../../400.deploy/700.server-mode/100.deploy-by-systemd.md)を参照してください。

* デプロイされたseekdbに対応するログディスク、clogディスク、dataディスクの3つのディスクを使用し、パフォーマンスレベルはPL1です。seekdb起動時に、`/etc/oceanbase/seekdb.cnf`に以下のパラメータを設定する必要があります。

   ```shell
   port=2881
   base-dir=/data/1/seekdb
   data-dir=/data/2/seekdb
   redo-dir=/data/3/seekdb
   ```

   :::tip

   テストするseekdbの仕様が1C2Gの場合、パラメータ`memory_limit=2G`を設定する必要があります。

   :::

* Python 3.11以降のバージョンをインストールします。例ではCondaを使用してインストールします。

  ```bash
  # Condaをダウンロードしてインストール
  mkdir -p ~/miniconda3
  wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -O ~/miniconda3/miniconda.sh
  bash ~/miniconda3/miniconda.sh -b -u -p ~/miniconda3
  rm ~/miniconda3/miniconda.sh

  # ターミナルを再起動し、Condaを初期化
  source ~/miniconda3/bin/activate
  conda init --all

  # VectorDBBenchに必要なPython環境を新規作成して初期化
  conda create -n vdb python=3.11
  conda activate  vdb
  ```

## テスト計画

* 今回のテストでは2台のマシンを使用します。VectorDBBenchは1台のマシンに、seekdbはもう1台のマシンにデプロイします。seekdbの仕様は4C8Gまたは1C2Gで、ログディスク、clogディスク、dataディスクの3つのディスクを使用し、パフォーマンスレベルはPL1です。

* 使用するデータセットはPerformance1536D50K、インデックスタイプはHNSWです。VectorDBBenchを使用して、seekdbのQPS、latency(p99)、リコール率をテストします。

## テスト方法

### VectorDBBenchコードのクローン

:::tip

CPUリソースの競合を避け、テスト結果の信頼性を高めるため、VectorDBBenchとseekdbは異なるマシンにデプロイすることを推奨します。

:::

テストツールVectorDBBenchのコードをローカルにクローンします。

```bash
git clone https://github.com/zilliztech/VectorDBBench.git
```

### 依存関係のインストール

VectorDBBenchディレクトリに移動して依存関係をインストールします。

```bash
cd VectorDBBench
pip install .
```

### テストの実行

VectorDBBenchを実行します。ここではHNSWインデックスを使用してテストします。

#### HNSWインデックス

```bash
# $host、$port、$userは実際のseekdb接続情報に置き換えてください。
vectordbbench oceanbasehnsw --host $host  --port $port --user root --database test --m 16 --ef-construction 200 --case-type Performance1536D50K --index-type HNSW --ef-search 180 --k 100
```

より詳細なパラメータ情報は以下のコマンドで確認できます：

```bash
vectordbbench oceanbasehnsw --help
```

主なオプションの説明は以下の通りです：

* `--num-concurrency`：並列度を調整するために使用します。VectorDBBenchは指定された並列度でベクトルクエリを実行し、最大のQPS（Queries Per Second、1秒あたりのクエリ数）を最終結果として選択します。
* `--skip-drop-old`/`--skip-load`：古いデータの削除とデータロードのステップをスキップします。コマンドラインにこれら2つのオプションを追加すると、コマンドはベクトルクエリ操作のみを実行し、古いデータを削除して再度データをロードすることはありません。
* `--k`：ベクトルクエリで返す最近傍結果の個数Kを指定します。
* `--ef-search`：HNSWクエリパラメータで、クエリ時の候補集合のサイズを表します。
* `--index-type`：インデックスタイプを指定します。現在、`HNSW`、`HNSW_SQ`、`HNSW_BQ`をサポートしています。
