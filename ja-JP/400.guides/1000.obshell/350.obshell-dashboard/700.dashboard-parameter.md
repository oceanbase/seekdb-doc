# パラメータ管理

obshell Dashboardコンソールにログインし、左側のナビゲーションバーにある **パラメータ管理** をクリックすると、**パラメータ管理** ページに移動します。本記事では、obshell Dashboardを使用してseekdbインスタンスのパラメータを確認および変更する方法について説明します。

**パラメータ管理** ページには、seekdbの **パラメータ名**、**現在の値**、**説明** が表示され、パラメータに対して実行できる操作も示されます。カーソルを対応するパラメータの **説明** 列に合わせると、そのパラメータの詳細な説明を見ることができます。特定の構成パラメータを見たい場合は、ページの右上にある検索ボックスで検索することができます。

![パラメータ概要](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/700.dashboard-parameter-01.png)

**操作** 列の **値の変更** フィールドをクリックすると、対応する構成パラメータの値を変更できます。変更後、**送信** ボタンをクリックし、二度目の確認を経て、パラメータの変更を完了できます。

![パラメータの変更](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/700.dashboard-parameter-02.png)
