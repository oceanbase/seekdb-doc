# アラート管理

obshell Dashboardコンソールにログインし、左側のナビゲーションバーで**アラートセンター**をクリックすると、**アラートセンター**ページにアクセスできます。

**アラートセンター**ページは、seekdbインスタンス内のアラートイベントを一元的に管理および監視するために使用されます。このページでは、アラートイベントの表示と管理、アラートミュート、アラートルールの設定が可能です。これにより、異常状態への迅速な対応と処理を実現し、システムの安定稼働を確保できます。

:::info
   アラートセンターページに初めてログインする際は、Alertmanagerのアドレス、ユーザー名、パスワードなどの情報を入力する必要があります。Alertmanagerがインストールされていない場合は、[モニタリングコンポーネントの設定](../900.configure-monitor.md)の記事を参照してインストールすることを推奨します。
:::

## 絞り込み

**アラートイベント**、**アラートミュート**、**アラートルール**の各タブでは、条件を指定して検索し、リスト内で一致する内容を表示できます。各タブでサポートされている条件は異なり、主に以下の条件が含まれます。設定後はこれらの条件に基づいて正確に検索できます。**クリア**ボタンをクリックすると、検索内容がクリアされ、再度入力できます。

| パラメータ | 説明 |
| --- | --- |
| アラートレベル | ドロップダウンリストからアラートレベルを選択します。**重大**、**警告**、**注意**、**リマインダー** の4つのレベルがあります。<ul><li><b>重大</b>：システムの可用性が低下し、完全に使用不能になるのを防ぐために緊急に修正が必要です。</li><li><b>警告</b>：システムはまだ使用可能ですが、すぐに使用不能状態になります。可用性の低下を防ぐための措置を講じる必要があります。</li><li><b>注意</b>：傾向から判断すると、システムの主要なパフォーマンス指標が低下していますが、警告が発生するレベルには達していません。この時点で調査を行うことで、潜在的な問題を発見し、警告の発生を防ぐことができます。</li><li><b>リマインダー</b>：操作のリマインダーです。本質的にはアラートではなく、通常は管理者が重要な操作を実行する際に表示されます。</li></ul> |
| キーワード | アラートのキーワードです。カスタム入力が必要で、キーワードに基づいて対応するアラートイベントを検索できます。 |
| 開始時間 | アラートイベントの開始時間を設定します。 |
| 終了時間 | アラートイベントの終了時間を設定します。 |

## アラートイベント

アラートイベントリストでは、**アラートイベント**、**アラートレベル**、**アラートステータス**、**発生時間**、**終了時間**などの詳細情報を確認できます。また、イベントに対して実行できる操作も表示されます。**アラートレベル**、**アラートステータス**、**発生時間**、**終了時間**でのソートもサポートされています。

![アラートイベント](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-01.png)

### アラートイベントのミュート

気にしないアラートイベントがある場合、該当するアラートイベントの**操作**列の**ミュート**をクリックすると、そのアラートメッセージをすばやくミュートできます。

**ミュート**をクリックすると、ページは**アラートミュート**タブに移動し、**ミュート条件**のドロップダウンパネルが表示されます。**ミュート条件**パネルでは、選択したアラートイベントに応じて、**アラートミュートルール**と**タグ**の情報が自動的に入力されます。あとは**ミュート終了時間**を選択し、**備考**を入力するだけです。**ミュート終了時間**の設定方法は以下の2つです：

* チェックボックスをクリックし、時間セレクターで終了時間をカスタマイズします。

* チェックボックスの後ろの時間をクリックして、固定のミュート時間を設定します。例えば、**6時間**をクリックすると、システムは現在時刻に6時間を加算してボックスに入力します。

アラートをミュートすると、**アラートミュート**タブに対応する新しいミュート情報が追加されます。**アラートイベント**タブでは、該当するアラートイベントのステータスが**アクティブ**から**抑制**に変更されます。設定された終了時間まで、ミュートされたアラートは送信されません。このアラートを事前に送信する必要がある場合は、**アラートミュート**タブで対応するミュート情報を変更するか、**ミュート解除**を行うことができます。詳細については、以下の[ミュートの編集](#編集ミュート)および[ミュートの解除](#解除ミュート)を参照してください。

![ミュート](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-02.png)

## アラートのブロック

ブロックリストで、ブロック条件の **アラートブロックルール**、**ブロック終了時間**、**作成者**、**状態**、**作成時間**、**備考**、および実行可能な操作を確認できます。**ブロック終了時間**、**状態**、**作成時間** でソートでき、指定したブロック内容に対して **編集** および **ブロック解除** 操作を実行できます。**アラートブロックルール** 列にカーソルを合わせると、完全なアラートルールの内容を確認できます。

![アラートのブロック](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-03.png)

### ブロックの新規作成

**アラートのブロック** タブで、**ブロックの新規作成** をクリックします。**ブロック条件** ドロップダウンパネルでブロック条件を設定し、設定完了後に **送信** をクリックすると、システムは **ブロックリスト** に戻り、リストに新しいブロック情報が追加されます。

| パラメータ | 説明 |
| --- | --- |
| アラートをマスクするルール | ドロップダウンリストからマスクしたいアラートを選択します。複数選択が可能です。アラートルールは、**アラートルール**タブの**ルール一覧**と一致しています。詳細はそのタブで確認できます。 |
| タグ | オプションです。タグによるマッチング条件でアラートをマスクします。値の一致または正規表現をサポートしており、すべての条件を満たした場合にのみアラートがマスクされます。<main id="notice" type="explain"><p>通常はこのパラメータを追加で設定する必要はありません。</p></main>  |
| マスク終了時間 | アラートマスクの終了時間を設定します。終了時間まで、マスクされたアラートは送信されません。マスク終了時間の設定方法は以下の2通りです：<ul><li>選択ボックスをクリックし、時間セレクターで終了時間をカスタム設定します。</li><li>選択ボックスの後ろの時間をクリックして固定のマスク時間を設定します。例えば、<b>6時間</b>をクリックすると、システムが現在時刻に6時間を加算してボックスに表示します。</li></ul> |
| 備考 | マスクルールの説明を追加することができます。これにより、後の参照や再利用が容易になります。 |

:::info
   特定のアラートをブロックする必要がある場合は、<b>アラートイベント</b> タブで指定したアラートイベントをブロックすることを推奨します。<b>操作</b> 列の <b>ブロック</b> フィールドをクリックすると、自動的に <b>アラートのブロック</b> タブに移動し、<b>ブロック条件</b> ドロップダウンパネルが表示されます。このパネルには、対応するアラートイベントに関連付けられた <b>アラートブロックルール</b> と <b>タグ</b> の情報がデフォルトで自動入力されています。アラートのブロック終了時間を設定し、備考情報を追加するだけで、該当するアラートを正常にブロックできます。
:::

![アラートの新規作成](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-04.png)

### ブロックの編集

**アラートのブロック** タブの **ブロックリスト** モジュールで、**操作** 列の **編集** をクリックすると、ポップアップ表示された **ブロック条件** ドロップダウンパネルで対応するブロック情報を編集できます。

**ブロック条件** パネルには、対応するブロックの **アラートブロックルール**、**タグ**、**ブロック終了時間**、**備考情報** が自動入力されており、実際の状況に応じて変更できます。具体的なパラメータの説明については、上記の [ブロックの新規作成](#ブロックの新規作成) を参照してください。変更完了後に **送信** をクリックすると、ブロックの編集が完了します。

ブロックを編集すると、**ブロックリスト** に新しいブロック情報が追加され、変更前の元のブロック情報の状態は **アクティブ** から **期限切れ** に変更され、それ以上の操作はできなくなります。

![ブロックの編集](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-05.png)

### ブロックの解除

**アラートのブロック** タブの **ブロックリスト** モジュールで、**操作** 列の **ブロック解除** をクリックし、表示された確認ダイアログで **解除** をクリックすると、対応するアラートルールのブロックが解除されます。ブロック解除後、対応するブロック情報の状態は **アクティブ** から **期限切れ** に変更され、それ以上の操作はできなくなります。

:::tip
   ブロックの解除は元に戻りませんので、ご注意ください。
:::

![ブロックの解除](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-06.png)

## アラートルール

ルールリストでは、**アラートルール名**、**トリガールール**、**継続時間**、**オブジェクトタイプ**、**アラートレベル**、**タイプ**などの情報を確認できます。**アラートレベル**でソートしたり、**タイプ**で**カスタム**または**デフォルト**タイプのアラートルールをフィルタリングしたりできます。

:::info
   現在、obshell Dashboardはカスタムアラートルールをサポートしていません。obd <a href="https://github.com/oceanbase/obdeploy/blob/master/plugins/prometheus/2.37.1/prometheus_rules.yaml">GitHubリポジトリ</a>にアクセスすると、OceanBaseが提供するPrometheusアラートルールファイルを確認できます。
:::

![アラートルール](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-07.png)
