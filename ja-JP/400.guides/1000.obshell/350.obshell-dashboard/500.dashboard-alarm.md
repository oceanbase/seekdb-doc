# アラート管理

obshell Dashboardコンソールにログインし、左側のナビゲーションバーで**アラートセンター**をクリックすると、**アラートセンター**ページにアクセスできます。

**アラートセンター**ページは、seekdbインスタンス内のアラートイベントを一元的に管理および監視するために使用されます。このページでは、アラートイベントの表示と管理、アラートミュート、アラートルールの設定ができ、異常状態への迅速な対応と処理を通じてシステムの安定稼働を確保できます。

:::info
   アラートセンターページに初めてログインする際は、Alertmanagerのアドレス、ユーザー名、パスワードなどの情報を入力する必要があります。Alertmanagerがインストールされていない場合は、[モニタリングコンポーネントの設定](../900.configure-monitor.md)の記事を参照してインストールすることを推奨します。
:::

## 絞り込み

**アラートイベント**、**アラートマスク**、**アラートルール**の各タブでは、条件を指定して検索し、条件に合致する内容を表示できます。各タブでサポートされている条件は異なり、具体的には以下の条件が含まれます。設定後は、これらの条件に基づいて正確に検索できます。**リセット**ボタンをクリックすると、検索内容がクリアされ、再度入力できます。

| パラメータ | 説明 |
| --- | --- |
| アラートレベル | ドロップダウンリストからアラートレベルを選択します。**重大**、**警告**、**注意**、**リマインダー** の4つのレベルがあります。<ul><li><b>重大</b>：システムの可用性が低下し、緊急に修正する必要があります。これにより、システムが完全に利用不能になるのを防ぎます。</li><li><b>警告</b>：システムはまだ利用可能ですが、間もなく利用不能状態に達するため、可用性の低下を防ぐ措置を講じる必要があります。</li><li><b>注意</b>：傾向から判断すると、システムの主要なパフォーマンス指標が低下していますが、警告をトリガーするレベルには達していません。この時点で調査を行うことで、潜在的な問題を発見し、警告の発生を回避できます。</li><li><b>リマインダー</b>：操作のリマインダーです。本質的にはアラートではなく、通常は管理者が重要な操作を実行する際に表示されます。</li></ul> |
| キーワード | アラートのキーワードです。カスタム入力が必要で、キーワードに基づいて対応するアラートイベントを検索できます。 |
| 開始時間 | アラートイベントの開始時間を設定します。 |
| 終了時間 | アラートイベントの終了時間を設定します。 |

## アラートイベント

アラートイベントリストでは、**アラートイベント**、**アラートレベル**、**アラート状態**、**発生時間**、**終了時間**などの詳細情報を確認できます。また、イベントに対して実行できる操作も表示されます。**アラートレベル**、**アラート状態**、**発生時間**、**終了時間**でのソートがサポートされています。

![アラートイベント](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-01.png)

### アラートイベントのマスク

気にしないアラートイベントがある場合、該当するアラートイベントの**操作**列の**マスク**をクリックすると、そのアラートメッセージをすぐにマスクできます。

**マスク**をクリックすると、ページが**アラートマスク**タブにジャンプし、**マスク条件**のドロップダウンパネルが表示されます。**マスク条件**パネルでは、選択したアラートイベントに応じて、**アラートマスクルール**と**タグ**の情報が自動的に入力されています。あとは**マスク終了時間**を選択し、**備考**を入力するだけです。**マスク終了時間**の設定方法は以下の2つです：

* チェックボックスをクリックし、時間セレクターで終了時間をカスタマイズします。

* チェックボックスの後ろの時間をクリックして、固定のマスク時間を設定します。例えば、**6時間**をクリックすると、システムが現在時刻に6時間を加算してボックスに入力します。

アラートをマスクすると、**アラートマスク**タブに新しいマスク情報が追加されます。**アラートイベント**タブでは、該当するアラートイベントの状態が**アクティブ**から**抑制**に変更されます。設定された終了時間まで、マスクされたアラートは送信されません。このアラートをそれより早く送信する必要がある場合は、**アラートマスク**タブで対応するマスク情報を変更するか、**マスク解除**を行うことができます。詳細については、以下の[マスクの編集](#編集マスク)および[マスクの解除](#解除マスク)を参照してください。

![マスク](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-02.png)

## アラートのミュート

ミュートリストでは、ミュート条件の **アラートミュートルール**、**ミュート終了時間**、**作成者**、**ステータス**、**作成日時**、**備考**、および実行可能な操作を確認できます。**ミュート終了時間**、**ステータス**、**作成日時** でソートでき、指定したミュート内容に対して **編集** および **ミュート解除** 操作を実行できます。カーソルを **アラートミュートルール** 列に合わせると、完全なアラートルールの内容を確認できます。

![アラートのミュート](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-03.png)

### ミュートの新規作成

**アラートのミュート** タブで、**ミュートの新規作成** をクリックします。**ミュート条件** ドロップダウンパネルでミュート条件を設定し、設定完了後に **送信** をクリックすると、システムは **ミュートリスト** に戻り、リストに新しいミュート情報が追加されます。

| パラメータ | 説明 |
| --- | --- |
| アラートをマスクするルール | ドロップダウンリストからマスクしたいアラートを選択します。複数選択可能です。アラートルールは、**アラートルール**タブの**ルール一覧**と一致します。詳細はそのタブで確認できます。 |
| タグ | オプションです。タグによるマッチング条件でアラートをマスクします。値の一致または正規表現をサポートしており、すべての条件を満たした場合にのみアラートがマスクされます。<main id="notice" type="explain"><p>通常、このパラメータは追加で設定する必要はありません。</p></main>  |
| マスク終了時間 | アラートマスクの終了時間を設定します。終了時間まで、マスクされたアラートは送信されません。マスク終了時間の設定方法は以下の2通りです：<ul><li>選択ボックスをクリックし、時間セレクターで終了時間をカスタマイズします。</li><li>選択ボックスの後ろの時間をクリックして固定のマスク時間を設定します。例えば、<b>6時間</b>をクリックすると、システムは現在時刻に6時間を加算してボックスに表示します。</li></ul> |
| 備考 | マスクルールの説明を追加することができます。これにより、後の参照や識別、再利用が容易になります。 |

:::info
   特定のアラートをミュートする必要がある場合は、<b>アラートイベント</b> タブで指定したアラートイベントをミュートすることをお勧めします。<b>操作</b> 列の <b>ミュート</b> フィールドをクリックすると、自動的に <b>アラートのミュート</b> タブにジャンプし、<b>ミュート条件</b> ドロップダウンパネルが表示されます。このパネルには、対応するアラートイベントに関連付けられた <b>アラートミュートルール</b> と <b>タグ</b> の情報がデフォルトで自動入力されています。ミュートの終了時間を設定し、備考情報を追加するだけで、該当するアラートを正常にミュートできます。
:::

![アラートの新規作成](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-04.png)

### ミュートの編集

**アラートのミュート** タブの **ミュートリスト** モジュール内で、**操作** 列の **編集** をクリックすると、ポップアップ表示された **ミュート条件** ドロップダウンパネルで対応するミュート情報を編集できます。

**ミュート条件** パネルには、対応するミュートの **アラートミュートルール**、**タグ**、**ミュート終了時間**、**備考情報** が自動入力されており、実際の状況に応じて変更できます。具体的なパラメータの説明については、上記の [ミュートの新規作成](#ミュートの新規作成) を参照してください。変更完了後に **送信** をクリックすると、ミュートの編集が完了します。

ミュートを編集すると、**ミュートリスト** に新しいミュート情報が追加され、変更前の元のミュート情報のステータスは **アクティブ** から **期限切れ** に変更され、それ以上の操作はできなくなります。

![ミュートの編集](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-05.png)

### ミュートの解除

**アラートのミュート** タブの **ミュートリスト** モジュール内で、**操作** 列の **ミュート解除** をクリックし、ポップアップ表示された確認ダイアログで **解除** をクリックすると、対応するアラートルールのミュートが解除されます。ミュート解除後、対応するミュート情報のステータスは **アクティブ** から **期限切れ** に変更され、それ以上の操作はできなくなります。

:::tip
   ミュートを解除すると元には戻りませんので、ご注意ください。
:::

![ミュートの解除](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-06.png)

## アラートルール

ルールリストでは、**アラートルール名**、**トリガールール**、**継続時間**、**オブジェクトタイプ**、**アラートレベル**、**タイプ**などの情報を確認できます。**アラートレベル**でソートしたり、**タイプ**で**カスタム**または**デフォルト**タイプのアラートルールをフィルタリングしたりできます。

:::info
   現在、obshell Dashboardはカスタムアラートルールをサポートしていません。obd <a href="https://github.com/oceanbase/obdeploy/blob/master/plugins/prometheus/2.37.1/prometheus_rules.yaml">GitHubリポジトリ</a>にアクセスして、OceanBaseが提供するPrometheusアラートルールファイルをご覧ください。
:::

![アラートルール](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/500.dashboard-alarm-07.png)
