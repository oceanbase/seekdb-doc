# データベース管理

obshell Dashboardコンソールにログインし、左側のナビゲーションバーで**データベース管理**をクリックすると、**データベース管理**ページに移動します。この記事では、**データベース管理**ページの情報と、そのページで実行できる操作について説明します。

## 基本情報

**データベース管理**ページには、インスタンス内に含まれるデータベースの**データベース名**、**文字セット**、**照合順序**、**JDBC接続文字列**、**作成日時**、**読み取り専用**かどうか、および実行可能な操作が表示されます。**JDBC接続文字列**列の接続文字列の後ろにある<span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style={{ height: '20px' }}/></span> アイコンをクリックすると、対応するデータベースの接続文字列をコピーして後の使用に備えることができます。

**作成日時**の後ろにあるソートアイコンをクリックすると、データベースを昇順または降順で表示できます。複数のデータベースが存在する場合、特定のデータベース情報を検索するには、ページの右上隅にある検索バーにデータベース名を入力して検索することもできます。

![概要](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/300.dashboard-db-01.png)

## データベースの新規作成

**データベース管理**ページの右上隅にある**データベースの新規作成**ボタンをクリックし、**データベースの新規作成**ポップアップウィンドウで**データベース名**、**文字セット**、**照合順序**、および読み取り専用かどうかを設定します。設定完了後、**送信**をクリックすると新規作成が完了します。

![データベースの新規作成](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/300.dashboard-db-02.png)

| パラメータ  | 説明  |
|-------|------|
| データベース名 | 新規作成するデータベースの名前を設定します。データベース名は以下の要件を満たす必要があります。<ul><li>長さは2～128文字です。</li><li>英字の小文字、数字、アンダースコアを含めることができますが、英字で始まる必要があります。</li></ul> |
| 文字セット | デフォルトは`utf8mb4`です。ドロップダウンリストから文字セットを選択できます。 |
| 照合順序  | ドロップダウンリストから適切な照合順序を選択できます。 |
| 読み取り専用 | このチェックボックスをオンにすると、新規作成するデータベースを読み取り専用データベースに設定します。  |

## データベースの変更

**操作**列の**編集**フィールドをクリックすると、対応するデータベースの**文字セット**、**照合順序**、および読み取り専用かどうかを変更できます。変更後、**送信**をクリックするとデータベースの変更が完了します。

![データベースの編集](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/300.dashboard-db-03.png)

## データベースの削除

**操作**列の**削除**フィールドをクリックし、ポップアップウィンドウの入力欄に `delete` と入力してから **削除** ボタンをクリックすると、対応するデータベースを削除できます。

![データベースの削除](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/300.dashboard-db-04.png)
