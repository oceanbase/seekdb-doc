# obshell Dashboard

obshell Dashboardは、OceanBaseが提供するWebベースの可視化管理ページであり、seekdbのリソース管理をサポートします。重要なリソースとパフォーマンス指標の監視機能を備えており、ユーザーがseekdbを効率的に管理するのに役立ちます。

obshell Dashboardサービスはobshellプロセスに完全に統合されており、ユーザーはobshellがデプロイされている任意のサービスアドレスにアクセスすることでseekdbを管理できます。この設計により、管理プロセスが簡素化されるだけでなく、極めて低いリソース消費を保証し、ユーザーにシンプルで使いやすい管理体験を提供します。

## 機能紹介

obshell Dashboardは現在、seekdb管理において以下の機能をサポートしています：

* インスタンス管理：インスタンス情報を確認できます。状態情報、デプロイメント仕様、作成/起動時間、作業ディレクトリなどのコア情報が含まれ、インスタンスの起動・停止、インスタンスのホワイトリスト変更などの機能を提供します。詳細については、[インスタンス管理](200/dashboard-instance.md)を参照してください。

* データベース管理：インスタンス内のデータベースを管理します。[データベース管理](300/dashboard-db.md)を参照してください。

* ユーザー管理：インスタンス内のユーザーを管理します。[ユーザー管理](400/dashboard-user.md)を参照してください。

* アラートセンター：インスタンスのアラートルールとアラートイベントを確認でき、アラートのミュートもサポートしています。[アラート管理](500/dashboard-alarm.md)を参照してください。

* パフォーマンス監視：seekdbインスタンスの**パフォーマンスとSQL**、**トランザクション**、**ストレージとキャッシュ**、および**ホストパフォーマンス**指標をリアルタイムで監視します。[パフォーマンス監視](600/dashboard-monitor.md)を参照してください。

* パラメータ管理：seekdbインスタンスのパラメータを確認および変更します。[パラメータ管理](700/dashboard-parameter.md)を参照してください。

* ソフトウェアパッケージ管理：ソフトウェアパッケージをアップロードします。obshellをアップグレードするには、対象バージョンのソフトウェアパッケージをアップロードしておく必要があります。[ソフトウェアパッケージ管理](800/dashboard-package.md)を参照してください。

* タスクセンター：インスタンスの実行過程で生成されたタスクを確認および管理します。[タスク管理](900.ob-dashboard-task.md)を参照してください。

## ログインとログアウト

obshellは、seekdbの可視化管理をグラフィカルインターフェースでサポートしています。obshellを正常にインストールした後、obshellノードのIPアドレスとobshellポートを使用してobshell Dashboard（obshellの可視化管理ページ）にアクセスできます。アクセス時はデフォルトでrootユーザーが使用され、パスワードはインスタンス内のrootユーザーパスワードです。rootユーザーパスワードが空の場合は、**ログイン**ボタンを直接クリックしてログインできます。

obshell Dashboardコンソールにログインした後、ページの右上隅にある<span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-overview-01.png" alt="ユーザー" style={{ height: '20px' }}/></span> アイコンにカーソルを合わせ、表示された**ログインを終了する**をクリックし、ポップアップウィンドウで**OK**をクリックするとログインを終了できます。

## バージョンの確認

obshell Dashboardコンソールにログインした後、ページの右上隅にある**ヘルプ** > **obshell Dashboardについて**をクリックすると、obshell Dashboardのバージョンを確認できます。
