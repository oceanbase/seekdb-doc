# ソフトウェアパッケージ管理

obshell Dashboardコンソールにログインし、左側のナビゲーションバーの **システム管理** > **ソフトウェアパッケージ管理** をクリックして **ソフトウェアパッケージ** ページに移動します。本記事では、obshell Dashboardを使用してソフトウェアパッケージを表示またはアップロードする方法について説明します。

## ソフトウェアパッケージの表示

ソフトウェアパッケージページには、obshell Dashboardにアップロードされたソフトウェアパッケージの **パッケージ名**、**バージョン**、**ハードウェアアーキテクチャ**、**サイズ(MB)**、**MD5**、**アップロード日時** および実行可能な操作が表示されます。対応するソフトウェアパッケージの **MD5** 列にカーソルを合わせると、そのソフトウェアパッケージのMD5情報を確認できます。

**バージョン** と **ハードウェアアーキテクチャ** の後ろにある <span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-02.png" alt="フィルター" style={{ height: '20px' }}/></span> アイコンを使用して、バージョンやハードウェアアーキテクチャでソフトウェアパッケージをフィルタリング・表示できます。また、**パッケージ名** と **アップロード日時** の後ろにある <span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-03.png" alt="ソート" style={{ height: '20px' }}/></span> アイコンをクリックすると、昇順または降順でソフトウェアパッケージを並べ替えることができます。アップロード済みのソフトウェアパッケージが多すぎる場合は、ページ右上の検索ボックスで指定したソフトウェアパッケージが存在するかどうか検索できます。

![表示](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/800.dashboard-package-01.png)

## ソフトウェアパッケージのアップロード

**ソフトウェアパッケージ** ページの右上にある **ソフトウェアパッケージをアップロード** ボタンをクリックし、**ソフトウェアパッケージの選択** をクリックしてローカルからインストールパッケージをアップロードします。ソフトウェアパッケージをアップロードする前に、ローカルに要件を満たすインストールパッケージが存在することを確認してください。ローカルに必要なインストールパッケージがない場合は、**RPMパッケージのダウンロードURL** フィールドをクリックしてオープンソースミラーソースにアクセスし、必要なインストールパッケージを取得できます。

![ソフトウェアパッケージのアップロード](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/800.dashboard-package-02.png)

## ソフトウェアパッケージの削除

対応するソフトウェアパッケージの **操作** 列の **削除** フィールドをクリックし、ポップアップウィンドウで **確認** ボタンをクリックすると、指定したソフトウェアパッケージを削除できます。

![削除](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/800.dashboard-package-03.png)
