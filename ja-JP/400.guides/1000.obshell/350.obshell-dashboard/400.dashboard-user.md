# ユーザー管理

obshell Dashboardコンソールにログインし、左側のナビゲーションバーで**ユーザー管理**をクリックすると、**ユーザー管理**ページに移動します。

**ユーザー管理**ページには、現在のインスタンスに含まれるすべてのユーザーが表示されます。**ログイン接続文字列**列の接続文字列の後ろにある<span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style={{ height: '20px' }}/></span> アイコンをクリックして、対応するユーザーの接続文字列をコピーし、後で使用できます。ユーザーが多すぎる場合は、ページの右上隅にある検索バーにユーザー名を入力して検索し、特定のユーザー情報を確認できます。

![概要](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/400.dashboard-user-01.png)

## ユーザーの作成

**ユーザー管理**ページの右上にある**新規ユーザー**ボタンをクリックし、**データベースユーザーの作成**ページで**ユーザー名**、**パスワード**、**グローバル権限**、**データベース権限**を設定します。設定が完了したら**送信**をクリックすると作成は完了です。

![新規ユーザー](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/400.dashboard-user-02.png)

| パラメータ  | 説明  |
|-------|------|
| ユーザー名 | 新規ユーザーの名前を設定します。ユーザー名は以下の要件を満たす必要があります。<ul><li>長さは2～64文字です。</li><li>小文字の英字、数字、アンダースコアを含めることができますが、英字で始まる必要があります。</li></ul> |
| パスワード | パスワードの複雑さは以下の要件を満たす必要があります。<ul><li>長さは8～32文字です。</li><li>少なくとも以下の4種類の文字をそれぞれ2つ含む必要があります：数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）</li></ul> 設定後、**パスワードのコピー**をクリックして、後の使用のために設定したパスワードを保存することができます。 |
| パスワードの確認 | 設定したパスワードを再度入力して二重確認します。入力した2つのパスワードが一致しない場合、`入力された新しいパスワードが一致しません。再入力してください`というメッセージが表示されます。 |
| グローバル権限（オプション） | ドロップダウンリストからユーザーが持つことができる権限を選択できます。設定された権限はすべてのデータベースに適用されます。各権限の詳細については、[MySQLモードの権限分類](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001974758)を参照してください。設定しない場合、デフォルトでこのユーザーにはいかなる権限も付与されません。  |
| データベース権限 | 新規作成するユーザーの各データベースに対する権限を設定します。これは指定されたデータベース内のすべてのターゲットに適用されます。設定方法は以下のとおりです：<ol><li>左側のリストボックスで1つまたは複数のデータベースを選択します。左側のリストボックスには、現在のインスタンスで利用可能なすべてのデータベースが表示されます。データベースが多すぎる場合は、左側のリストボックスの検索ボックスで特定のデータベースを検索することもできます。</li><li>中央の **>** ボタンをクリックします。これにより、選択されたデータベースが右側のリストボックスに移動します。</li><li>右側のリストボックスで、指定したデータベース内でユーザーが持つことができる権限を選択します。対応するデータベースの右上にある**全部**を選択すると、ユーザーにそのデータベースのすべての権限を設定できます。</li><li>1、2、3の操作を繰り返し、異なるデータベースに対してユーザー権限を設定します。右側のリストボックスに移動したデータベースが多すぎる場合は、右側の検索ボックスで特定のデータベースを検索することもできます。</li><li>指定したデータベースのユーザー権限を解除する必要がある場合は、右側のリストボックスでデータベースの右上にある**削除**をクリックして、該当するデータベースを左側のリストボックスに戻します。または、右側のリストボックスの右上にある**全部削除**フィールドをクリックし、ポップアップウィンドウで**OK**をクリックすると、右側のリストボックスにあるすべてのデータベースが左側のリストボックスに戻ります。</li></ol>  |

## ユーザーのロック

**ロック** 列のスイッチアイコンをクリックすると、ユーザーのロック状態を切り替えることができます。ユーザーがロックされていない場合、<span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/400.ob-dashboard-tenant-user-01.png" alt="スイッチ" style={{ height: '20px' }}/></span> をクリックし、表示されたウィンドウで **OK** をクリックすると、現在のユーザーをロックできます。ロックされたユーザーはログインできなくなりますので、ご注意ください。ユーザーがロックされている場合、<span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/400.ob-dashboard-tenant-user-02.png" alt="スイッチ" style={{ height: '20px' }}/></span> をクリックし、表示されたウィンドウで **OK** をクリックすると、現在のユーザーのロックを解除できます。ロックが解除されたユーザーはログインできるようになります。

![ユーザーのロック](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/400.dashboard-user-03.png)

## パスワードの変更

**操作** 列の **パスワードの変更** ボタンをクリックし、表示されたウィンドウで **新しいパスワード** と **パスワードの確認** を入力します。入力後、**OK** をクリックすると、ユーザーのパスワード変更が完了します。パスワードの複雑さは以下の要件を満たす必要があります：

* 長さは8文字から32文字です。

* 数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）の4種類の文字をそれぞれ2つ以上含む必要があります。

設定後、**パスワードのコピー** をクリックして、後の使用のために設定したパスワードを保存できます。

![パスワードの変更](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/400.dashboard-user-04.png)

## 権限の変更

**操作** 列の **権限の変更** ボタンをクリックすると、対応するユーザーのグローバル権限とデータベース権限を変更できます。グローバル権限はドロップダウンリストから直接変更できます。データベース権限の変更手順は以下のとおりです：

1. 左側のリストボックスで、1つまたは複数のデータベースを選択します。左側のリストボックスには、現在のインスタンスで利用可能なすべてのデータベースが表示されます。データベースが多すぎる場合は、左側の検索ボックスで特定のデータベースを検索することもできます。

2. 中央の **>** ボタンをクリックします。選択したデータベースは、右側のリストボックスに移動します。

3. 右側のリストボックスで、指定したデータベース内でユーザーが持つことができる権限を選択します。対応するデータベースの右上隅の **すべて** を選択すると、ユーザーにそのデータベースのすべての権限を設定できます。

4. 1、2、3の操作を繰り返し、異なるデータベースに対してユーザー権限を設定します。右側のリストボックスに移動したデータベースが多すぎる場合は、右側の検索ボックスで特定のデータベースを検索することもできます。

5. 指定したデータベースのユーザー権限を取り消す必要がある場合は、右側のリストボックスでデータベースの右上隅にある **削除** をクリックして、該当するデータベースを左側のリストボックスに戻します。または、右側のリストボックスの右上隅にある **すべて削除** ボタンをクリックし、表示されたウィンドウで **OK** をクリックすると、右側のリストボックスにあるすべてのデータベースが左側のリストボックスに戻ります。

6. 設定が完了したら、**送信** をクリックして変更を完了します。

![権限の変更](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/400.dashboard-user-05.png)

## ユーザーの削除

**操作** 列の **削除** ボタンをクリックし、表示されたウィンドウの入力欄に `delete` と入力してから **削除** ボタンをクリックすると、該当するユーザーを削除できます。ユーザーを削除すると、そのユーザー配下のすべてのオブジェクトとデータも削除されますので、ご注意ください。

![ユーザーの削除](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/400.dashboard-user-06.png)
