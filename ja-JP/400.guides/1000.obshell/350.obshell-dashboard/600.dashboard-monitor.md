# パフォーマンス監視

obshell Dashboardコンソールにログインし、左側のナビゲーションバーで**パフォーマンス監視**をクリックすると、**パフォーマンス監視**ページでseekdbの各種パフォーマンス指標のアイコン情報を確認できます。

:::info
   初回ログイン時は、Prometheusのアドレス、ユーザー名、パスワードを入力する必要があります。Prometheusがインストールされていない場合は、[モニタリングコンポーネントの設定](../900.configure-monitor.md)の記事を参照してインストールすることをお勧めします。
:::

**パフォーマンス監視**ページでは、seekdbインスタンスの**パフォーマンスとSQL**、**トランザクション**、**ストレージとキャッシュ**、および**ホスト性能**の指標をリアルタイムで監視できます。これにより、パフォーマンスボトルネックを迅速に特定し、システムリソースの使用を最適化するのに役立ちます。

**パフォーマンス監視**ページにアクセスすると、デフォルトで**パフォーマンスとSQL**の監視情報が表示されます。異なるタブでは、表示可能な監視指標が異なります。詳細は以下の表を参照してください。

| タブ | モニタリング項目 |
| --- | --- |
| パフォーマンスとSQL | このタブは、以下のパフォーマンス指標のグラフ変化を表示します：**QPS**、**応答時間**、**SQL実行計画カテゴリ**、**SQL実行時間**、**セッション数**、**待機イベント**、**待機イベント時間**、**リクエスト待機キュー**、**リクエスト待機キュー時間**、**CPU消費**、**スレッド利用率**、**メモリ利用率**、**MemStore使用率**、**オープンカーソル数**、**GTSリクエスト数**。 |
| トランザクション | このタブは、以下のパフォーマンス指標のグラフ変化を表示します：**TPS**、**トランザクション応答時間**、**トランザクション応答時間詳細**、**トランザクションロールバック比率**、**トランザクションログ数**、**トランザクションログ量**、**トランザクションログ時間**、**トランザクションロック待機回数**、**トランザクションロック平均待機時間**、**トランザクション数**、**MemStoreロック申請成功率**。 |
| ストレージとキャッシュ | このタブは、以下のパフォーマンス指標のグラフ変化を表示します：**MemStore**、**物理I/O回数**、**物理I/O時間**、**物理I/Oスループット**、**キャッシュサイズ**、**キャッシュヒット率**、**キャッシュリクエスト回数**、**ログディスク**、**ログディスク割合**、**Vectorメモリ**、**Vectorメモリ割合**。 |
| ホストパフォーマンス | このタブは、以下のパフォーマンス指標のグラフ変化を表示します：**Linuxシステム負荷**、**CPU利用率**、**メモリ**、**メモリ利用率**、**IOPS**、**I/O時間**、**I/Oスループット**、**ネットワークスループット**。 |

## 手順

1. ページ上部で、実際のニーズに応じてリフレッシュ頻度と時間間隔をカスタマイズできます。

   ![リフレッシュ](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/600.dashboard-monitor-01.png)

   * パフォーマンスデータはデフォルトで更新されません。[パフォーマンス監視] の後ろにある更新ボタンをクリックすると、[パフォーマンス監視] ページ全体が更新され、[パフォーマンスとSQL] モジュールの監視情報が表示されます。[更新] フィールドをクリックすると、更新アイコンが表示され、現在のモジュールに留まります。

   * リフレッシュ頻度はカスタマイズ可能です。[オフ] フィールドにカーソルを合わせ、表示されたドロップダウンリストからリフレッシュ頻度を選択します。リフレッシュ頻度のオプションは `Off`、`5s`、`10s`、`30s` で、デフォルトは `Off` です。

   * 時間セレクターを使用して、表示する監視範囲をカスタマイズ設定できます。左側をクリックすると、現在時刻から最も近い期間内の監視情報を選択できます。例えば、[過去30分] をクリックすると、現在時刻の30分前の監視情報が表示されます。デフォルトでは過去1時間のデータが表示されますが、必要に応じて選択できます。右側には日付と時間が含まれており、日付は手動入力または下部のカレンダーから選択でき、時間も手動入力またはマウススライドで選択できます。
      ![時間選択](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/600.dashboard-monitor-02.png)

2. 各監視項目の後ろにある疑問符アイコンにカーソルを合わせると、その監視項目の紹介を見ることができます。監視チャート上の任意の場所にカーソルを合わせると、折れ線グラフの詳細情報を見ることができます。アイコンの右上にある ▲ と ▼ をクリックすると、前後のページに移動できます。

   ![表示](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/600.dashboard-monitor-03.png)

3. 特定の監視指標に対する操作をサポートしています。

   対応する監視指標にカーソルを合わせると、<span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/obshell/600.dashboard-monitor-05.png" alt="focus" style={{ height: '20px' }}/></span> アイコンが表示されます。このアイコンをクリックすると、その監視指標の折れ線トレンドのみが表示され、他の色の折れ線はグレーアウトされます。再度このアイコンをクリックすると、すべての監視指標情報が表示されます。

   下図の赤枠部分をクリックすると、対応する色の折れ線が表示されなくなり、その監視指標の表示がグレーアウトされます。再度クリックすると、対応する色の折れ線が再表示されます。

   ![操作](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/600.dashboard-monitor-04.png)
