# インスタンス管理

obshell Dashboardコンソールにログインすると、デフォルトで **インスタンス管理** ページが表示されます。本記事では、**インスタンス管理** ページに表示される情報と実行可能な操作について説明します。

**インスタンス管理** ページには、seekdbの基本情報、ホワイトリスト情報、インスタンス状態、および最終マージの開始時刻と終了時刻が表示されます。また、**インスタンス管理** ページからseekdbの起動・停止・再起動、obshellのアップグレード、およびインスタンスへのマージ操作を実行できます。

## 基本情報

**基本情報** モジュールには、インスタンスの状態、seekdbバージョン番号、インスタンス仕様、含まれるデータベースとユーザー数、ポート、作成日時、作業ディレクトリなどの情報が表示されます。具体的な表示内容は以下の図を参照してください。

**インスタンス管理** の後ろの更新アイコンをクリックすると、インスタンスの最新情報に基づいて **基本情報** モジュールが更新されます。**データベース数** または **ユーザー数** の横の数字をクリックすると、対応する **データベース管理** または **ユーザー管理** ページに移動し、データベースまたはユーザー情報を確認できます。**接続文字列** の後ろの <span style={{ verticalAlign: 'middle' }}><img src="https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.3.5/700.reference/1500.Components-and-Tools/100.obshell/500.icon/100.ob-dashboard-tenant-01.png" alt="コピー" style={{ height: '20px' }}/></span> アイコンをクリックすると、接続文字列をコピーして後の使用に備えることができます。

![基本情報](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/200.dashboard-instance-01.png)

## インスタンスの起動と停止

:::info
   obshell Dashboardは、systemdで管理されているseekdbインスタンスの起動と停止を現在サポートしていません。現在のseekdbインスタンスがsystemdで起動されている場合は、<code>systemctl stop seekdb</code>/<code>systemctl start seekdb</code> コマンドを実行してseekdbインスタンスを停止/起動してください。
:::

インスタンスの状態が **正常に実行** されている場合、**インスタンス管理** ページの右上にある **停止** ボタンをクリックし、確認ダイアログで **停止** をクリックします。obshell Dashboardはインスタンス停止タスクを送信し、タスクIDを表示します。表示されたタスクIDをクリックすると、タスクの実行状況を確認できます。

:::tip
   インスタンスを停止すると業務が中断されます。関連するリスクを確認したうえで操作を実行してください。
:::

![インスタンスの起動と停止](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/200.dashboard-instance-02.png)

インスタンス停止タスクが完了すると、インスタンスの状態は **停止済み** に変わります。**インスタンス管理** ページの右上にある **起動** ボタンをクリックし、確認ダイアログで **起動** をクリックします。obshell Dashboardはインスタンス起動タスクを送信し、タスクIDを表示します。表示されたタスクIDをクリックすると、タスクの実行状況を確認できます。

## インスタンスの再起動

インスタンスの状態が **正常に実行** されている場合、**インスタンス管理** ページの右上にある **再起動** ボタンをクリックし、確認ダイアログで **再起動** をクリックします。obshell Dashboardはインスタンス再起動タスクを送信し、タスクIDを表示します。表示されたタスクIDをクリックすると、タスクの実行状況を確認できます。

:::tip
   インスタンスを再起動すると業務が中断されます。関連するリスクを確認したうえで操作を実行してください。
:::

![インスタンスの再起動](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/200.dashboard-instance-03.png)

## obshellのアップグレード

カーソルを右上の **···** の後ろに合わせ、表示された **obshellをアップグレード** ボタンをクリックします。

表示された **Agent アップグレードバージョン** ウィンドウで **obshell Agent バージョン** を設定します。バージョンは、現在アップロードされているobshellソフトウェアパッケージから選択します。現在のobshell Dashboardに現在のバージョンより高いバージョンのobshellソフトウェアパッケージがない場合は、ドロップダウンボックスの **+ ソフトウェアパッケージをアップロード** をクリックしてアップロードします。

:::info
   ローカルに必要なインストールパッケージが存在することを確認してください。ローカルに対応するインストールパッケージがない場合は、<b>ソフトウェアパッケージをアップロード</b> ページの <b>RPMパッケージのダウンロードURL</b> フィールドをクリックして、オープンソースミラーサイトから対応するソフトウェアパッケージをダウンロードできます。
:::

設定完了後、**アップグレード** をクリックし、ポップアップウィンドウで **OK** をクリックします。obshell Dashboardはobshellのアップグレードタスクを送信します。ポップアップウィンドウの **タスクの表示** ボタンをクリックすると、タスクの実行状況を確認できます。

![obshellのアップグレード](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/200.dashboard-instance-04.png)

## アローリスト

**アローリスト** モジュールは、インスタンスに接続できるアドレスのリストを表示します。モジュールの右側にある変更アイコンをクリックすると、アローリストを変更できます。

![アローリストの変更](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/200.dashboard-instance-05.png)

アクセス可能なIPをカスタマイズ設定するか、すべてのIPがアクセス可能に設定できます。カスタム設定を選択した場合、**カスタムIP** の下の入力ボックスに、ログインを許可するクライアントのリストを指定できます。IPを入力した後、キーボードのEnterキーを押すか、英字のカンマ（`,`）を入力すると、複数のノードIPを設定できます。**設定説明を見る** にカーソルを合わせると、IP設定の説明を確認できます。IP設定でサポートされている形式は以下のとおりです：

* IPアドレス、例：127.0.0.10,127.0.0.11
* サブネット/マスク、例：127.0.0.0/24
* あいまい一致、例：127.0.0.% または 127.0.0._
* 複数形式の混合、例：127.0.0.10,127.0.0.2,127.0.0.%,127.0.0._,127.0.0.1/24

:::info
   <code>%</code> に設定すると、すべてのクライアントが接続できることを意味し、アクセスのセキュリティリスクが伴います。慎重に操作してください。
:::

## マージ管理

**マージ管理** モジュールは、現在のインスタンスの **状態**、**直近1回のマージ開始時間**、**直近1回のマージ終了時間** を表示します。**状態** の後ろの **マージの開始** をクリックし、ポップアップウィンドウで **OK** をクリックすると、マージを開始できます。

![マージの開始](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/200.dashboard-instance-06.png)
