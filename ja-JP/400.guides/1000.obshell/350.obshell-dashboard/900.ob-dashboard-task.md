# タスク管理

**タスクセンター** ページでは、obshell Dashboard内のすべてのタスクを確認できます。本記事では、**タスクセンター** ページの情報と実行可能な操作について説明します。

以下の2つのエントリから **タスクセンター** ページにアクセスできます：

* エントリ1：obshell Dashboardコンソールにログインした後、ページの右上隅にある **タスク** フィールドをクリックすると、**タスクセンター** ページに入ります。

* エントリ2：obshell Dashboardコンソールにログインした後、左側のナビゲーションバーの **システム管理** > **タスクセンター** をクリックして **タスクセンター** ページに入ります。

タスクは状態でフィルタリングしたり、検索ボックスで特定のタスクを検索したりできます。対応するタスク名をクリックするとタスクの詳細を見ることができます。

![タスクセンター](https://obportal.s3.ap-southeast-1.amazonaws.com/doc/img/SeekDB-EN/900.ob-dashboard-task-01.png)

タスクが **実行中** の状態にある場合、対応するタスク名をクリックしてタスクの詳細に入り、ページの右上隅にある **タスクのキャンセル** ボタンをクリックし、再確認の後にタスク全体をキャンセルできます。

タスクが **失敗** の状態にある場合、失敗したタスクに対して、以下の操作を選択できます：

* **現在の進捗状況の特定** ボタンをクリックすると、ページは失敗したサブタスクのページにジャンプし、タスク詳細ページの右側に表示されるログ情報に基づいてトラブルシューティングを行います。

* **タスクのロールバック** ボタンをクリックし、確認ウィンドウで **ロールバック** をクリックします。ロールバック操作は、失敗した箇所から実行済みのすべてのタスクをロールバックします。

* **タスクのスキップ** ボタンをクリックし、確認ウィンドウで **スキップ** をクリックします。スキップ操作は、タスク全体をスキップします。

* **再試行** ボタンをクリックし、確認ウィンドウで **確認** をクリックします。再試行操作は、すべての失敗したノードを再試行し、失敗したノードから下への実行を続けます。

* 右側のログ情報ページの右上隅にある **ログのダウンロード** をクリックし、現在の段階のログをダウンロードします。公式サイトの[Q&Aセクション](https://open.oceanbase.com/)にアクセスして投稿すると、当社の当直エンジニアが問題解決をお手伝いします。
