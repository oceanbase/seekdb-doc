# obshell seekdbコマンド群

本記事では、obshellのseekdbコマンド群について説明します。seekdbコマンド群は、seekdbを管理するために使用できます。コマンドに `-h`/`--help` オプションを設定すると、コマンドのヘルプ情報を表示できます（例：`obshell seekdb start -h`）。また、コマンドに `-v`/`--verbose` を設定すると、コマンドの詳細な実行プロセスを確認できます。

:::info
   seekdbコマンド群は、seekdbインスタンスの管理を目的として設計されています。このコマンド群を実行する際には、<code>--seekdb</code> オプションを明示的に指定する必要はありません。
:::

## obshell seekdb start

このコマンドを使用して、seekdbを起動します。

```shell
obshell seekdb start [--port] [--seekdb] [-6]

# example
obshell seekdb start --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、コマンドがseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、IPv6を使用します。  |

## obshell seekdb restart

このコマンドを使用して、seekdbを再起動します。

```shell
obshell seekdb restart [-t] [--port] [--seekdb] [-6] [-y]

# example
obshell seekdb restart -t --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -t/--terminate | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドでこのオプションを設定すると、seekdbを再起動する前に`MINOR FREEZE`コマンドが実行されます。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellのポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけで、コマンドがseekdbに適用されることを意味します。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけでIPv6を使用することを意味します。  |
| -y/--yes  | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドでこのオプションを設定すると、再起動操作の確認をスキップします。 |

## obshell seekdb stop

このコマンドを使用して、seekdbを停止します。

```shell
obshell seekdb stop [-t] [--port] [--seekdb] [-6] [-y]

# example
obshell seekdb stop -t --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -t/--terminate | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドでの設定は、seekdbプロセスを停止する前に`MINOR FREEZE`コマンドを実行することを意味します。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、コマンドはseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、IPv6を使用します。  |
| -y/--yes  | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドでの設定は、停止操作の再確認をスキップすることを意味します。 |

## obshell seekdb show

このコマンドを使用すると、seekdbの関連設定とステータスを確認できます。

```shell
obshell seekdb show [-d] [--port] [--seekdb] [-6]

# example
obshell seekdb show
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -d/--show_detail | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、seekdbの詳細情報が表示されます。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、コマンドがseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、IPv6を使用します。  |
