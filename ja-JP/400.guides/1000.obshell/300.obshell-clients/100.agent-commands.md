# obshellエージェントコマンドグループ

本記事では、obshellのエージェントコマンドグループについて説明します。エージェントコマンドグループはobshellの管理に使用できます。コマンド内で`-h`/`--help`オプションを設定することで、コマンドのヘルプ情報を表示できます。例えば、`obshell agent start -h --seekdb` のようにします。ここで、`--seekdb` はseekdbに適用されるヘルプ情報を表示することを意味します。

## obshell agent start

このコマンドを使用して、obshellを起動します。

```shell
obshell agent start [-P] [--password] [--seekdb] [--base-dir] [-6]

# example
obshell agent start -P 2886 --base-dir /var/lib/oceanbase
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -P/--port | いいえ | int | 2886 | obshellがバインドするポート番号を設定します。 |
| --password | いいえ | string | なし | このオプションはseekdbインスタンスの乗っ取り時にのみ使用されます。乗っ取り時には、このオプションを使用してseekdbインスタンスのrootユーザーパスワードを指定する必要があります。環境変数`OB_ROOT_PASSWORD`を使用してrootユーザーパスワードを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定すると、コマンドがseekdbに適用されることを意味します。`--base-dir`を設定した場合は`--seekdb`を指定しなくてもかまいません。 |
| --base-dir | いいえ | string | なし | obshellの作業ディレクトリを指定します。対応するseekdbインスタンスの作業ディレクトリと一致させる必要があります。設定しない場合、デフォルトはコマンド実行時の現在ディレクトリです。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定すると、IPv6を使用することを意味します。  |

## obshell agent stop

このコマンドを使用して、obshellを停止します。

```shell
obshell agent stop [--port] [--seekdb] [-6]

# example
obshell agent stop --seekdb --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、コマンドがseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、IPv6を使用します。  |

## obshell agent restart

このコマンドを使用して、obshellを再起動します。

```shell
obshell agent restart [-P] [--password] [--seekdb] [-6]

# example
 obshell agent restart --seekdb --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -P/--port | いいえ | int | 2886 | obshellがバインドするポート番号を設定します。 |
| --password | いいえ | string | なし | このオプションはseekdbインスタンスの乗っ取り時にのみ使用されます。乗っ取り時には、このオプションでseekdbインスタンスのrootユーザーパスワードを指定する必要があります。rootユーザーパスワードは、環境変数`OB_ROOT_PASSWORD`でも指定できます。  |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、コマンドはseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、IPv6を使用します。  |

## obshell agent upgrade

このコマンドを使用して、obshellをアップグレードできます。

```shell
obshell agent upgrade -d [-V] [-t] [--port] [--seekdb] [-6] [-y] [-v]

# example
obshell agent upgrade -d /home/oceanbase/upgrade/ -V 4.2.2.0-20231224224959 --port 2886 --seekdb
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -d/--pkg_directory | はい | string | なし | アップグレードパッケージの保存先を設定します。 |
| -V/--target_version | いいえ | string | なし | ターゲットバージョンを指定します。形式は `4.2.2.0` または `4.2.2.0-20231224224959` のように正確である必要があります。指定しない場合、`-d` オプションで設定されたディレクトリ内の最も高いバージョンのobshell RPMパッケージが選択されます。 |
| -t/--tmp_directory | いいえ | string | `${home_path}/upgrade` | アップグレードプロセス中の一時ディレクトリを指定します。ダウンロードしたインストールパッケージや解凍・インストールプロセスで生成されるすべてのファイルを格納するために使用されます。絶対パスで設定する必要があります。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数 `OBSHELL_PORT_FOR_SEEKDB` を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけで、コマンドがseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけでIPv6が使用されます。  |
| -y/--yes | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけで、アップグレード操作の再確認がキャンセルされます。 |
| -v/--verbose | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけで、実行プロセスの詳細情報が出力されます。 |
