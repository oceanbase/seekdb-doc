# obshellタスクコマンドグループ

このドキュメントでは、obshellのタスクコマンドグループについて説明します。タスクコマンドグループは、obshellタスクを管理するために使用できます。コマンドで `-h`/`--help` オプションを設定することで、ヘルプ情報を表示できます。例えば、`obshell task show -h --seekdb` のようにします。ここで、`--seekdb` は seekdb に適用されるヘルプ情報を表示することを意味します。

## obshell task show

このコマンドを使用すると、指定したタスクの情報を表示できます。

```shell
obshell task show [-i] [-d] [--port] [--seekdb] [-6] [-v]

# example
obshell task show --seekdb --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -i/--id | いいえ | string | なし | 対象となるタスクのIDを指定します。指定しない場合、現在実行中のタスクがデフォルトで表示されます。現在タスクがない場合は、タスク情報は表示されません。 |
| -d/--show_detail | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドに含めるだけでタスクの詳細情報を表示することを意味します。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけで、コマンドがseekdbに適用されることを意味します。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定するだけでIPv6を使用することを意味します。  |
| -v/--verbose | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドに含めるだけで、実行プロセスの詳細な情報を出力することを意味します。 |

## obshell task cancel

このコマンドを使用すると、未完了のタスクをキャンセルできます。

```shell
obshell task cancel -i [--port] [--seekdb] [-6] [-y]

# example
obshell task cancel -i 11 --seekdb
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -i/--id | はい | string | なし | キャンセルするタスクのIDを指定します。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションには値を指定する必要はありません。設定されている場合、コマンドはseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションには値を指定する必要はありません。設定されている場合、IPv6が使用されます。  |
| -y/--yes | いいえ | なし | なし | このオプションには値を指定する必要はありません。コマンドに設定されている場合、二度の確認をスキップします。 |
