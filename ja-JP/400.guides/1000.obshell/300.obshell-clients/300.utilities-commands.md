# obshellタスクコマンドグループ

このドキュメントでは、obshellのタスクコマンドグループについて説明します。タスクコマンドグループは、obshellタスクを管理するために使用できます。コマンドのヘルプ情報を表示するには、コマンドに`-h`/`--help`オプションを設定します。例：`obshell task show -h --seekdb`。ここで、`--seekdb`はseekdbに適用されるヘルプ情報を表示することを意味します。

## obshell task show

このコマンドを使用すると、指定したタスクの情報を表示できます。

```shell
obshell task show [-i] [-d] [--port] [--seekdb] [-6] [-v]

# example
obshell task show --seekdb --port 2886
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -i/--id | いいえ | string | なし | 対象となるタスクのIDを指定します。指定しない場合、現在実行中のタスクがデフォルトで表示されます。現在タスクがない場合は、タスク情報は表示されません。 |
| -d/--show_detail | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンド内で設定することで、タスクの詳細情報を表示します。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定することで、コマンドがseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定することで、IPv6を使用します。  |
| -v/--verbose | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンド内で設定することで、実行プロセスの詳細情報を出力します。 |

## obshell task cancel

このコマンドを使用すると、未完了のタスクをキャンセルできます。

```shell
obshell task cancel -i [--port] [--seekdb] [-6] [-y]

# example
obshell task cancel -i 11 --seekdb
```

オプションの説明は以下の表を参照してください：

| オプション名 | 必須 | データ型 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- |
| -i/--id | はい | string | なし | キャンセルするタスクのIDを指定します。 |
| --port | いいえ | int | 2886 | obshellのポート番号を指定します。このオプションでポートを指定したくない場合は、環境変数`OBSHELL_PORT_FOR_SEEKDB`を使用してobshellポートを指定することもできます。 |
| --seekdb | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、コマンドはseekdbに適用されます。 |
|  -6/--use-ipv6 | いいえ | なし | なし | このオプションに値を指定する必要はありません。設定されている場合、IPv6を使用します。  |
| -y/--yes | いいえ | なし | なし | このオプションに値を指定する必要はありません。コマンドに設定されている場合、二度目の確認をスキップします。 |
