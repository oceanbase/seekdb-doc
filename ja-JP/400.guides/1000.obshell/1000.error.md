# エラーコード

本記事では、obshellの使用中に発生する可能性のあるエラーメッセージとその解決策について説明します。

obshellのエラーコードは、文字通りの意味を持つ文字列を採用しており、ユーザーが理解しやすいようになっています。操作上の問題が発生した場合は、<code>obshell.log</code> ログを確認して対応するエラーコードを取得し、下表の <b>解決策</b> に従って処理してください。

:::info
   obshell Dashboardの使用中にエラーが発生した場合は、ブラウザの開発者ツールを使用してHTTPリクエストの応答結果を確認し、エラーコード(<code>errCode</code>)を取得することもできます。
:::
