# セキュリティ権限の概要

データベースシステムにおける重要な指標の一つは、システムのセキュリティを確保することであり、データベース管理システムを通じてデータベースの不正使用を防ぎ、データベースのファイルとデータを保護します。本記事では、seekdbのセキュリティ体系について紹介します。

seekdbはデータの最終的な媒体として、常にデータのセキュリティ保護に注力しています。seekdbは、アイデンティティ認証、アクセス制御、監視・アラートといった、比較的完全なエンタープライズレベルのセキュリティ機能をサポートしており、ユーザーのデータセキュリティを効果的に保証します。

* アイデンティティ認証

  seekdbは、アイデンティティ識別と認証、ユーザー管理、ロール管理をサポートし、データベースのセキュリティを強化します。詳細については、[アイデンティティ認証](200.identification-and-authentication/100.identification.md)を参照してください。

* アクセス制御

 seekdbは、さまざまなシステム権限、オブジェクト権限、ロールを定義することで、ユーザーによるデータへのアクセスを制御します。詳細については、[アクセス制御](300.access-control/100.access-control-overview.md)を参照してください。

* データ暗号化

  seekdbは、データ転送プロセスにおいてデータの暗号化をサポートします。詳細については、[データ転送の暗号化](400.data-transfer-encryption/100.data-transfer-encryption-overview.md)を参照してください。
