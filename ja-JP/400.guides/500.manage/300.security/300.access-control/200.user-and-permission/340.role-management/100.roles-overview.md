# ロール管理の概要

seekdbはユーザーロール管理機能をサポートしています。

ロールは権限の集合です。ロールを使用することで、ユーザーの権限を簡単に管理できます。

seekdbでは、ロールには以下の機能があります：

* 通常のユーザーと同様に、ロールにも権限を付与できます。

* ロールには他のロールを含めることができます。つまり、ロールは階層構造を持つことが可能です。

* 1人のユーザーに複数のロールを付与でき、1つのロールを複数のユーザーに付与することもできます。

現在、seekdbはデフォルトのシステムロールをサポートしていません。
