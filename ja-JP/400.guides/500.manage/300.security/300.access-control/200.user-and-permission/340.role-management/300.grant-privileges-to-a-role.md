# ロールに権限を追加する

ロールを作成した後、ユーザーがそのロールを通じて権限を使用できるように、ロールに権限を追加する必要があります。

## 前提条件

ロールに権限を追加する際、現在のユーザーは付与される権限を持っている必要があり、かつ `GRANT OPTION` 権限も持っていなければなりません。現在のユーザーが持っている権限を確認する操作については、[ユーザー権限の確認](../400.view-user-permissions.md)を参照してください。関連する権限がない場合は、管理者に連絡し、ユーザーに権限を追加してもらってください。ユーザーに直接権限を付与する操作については、[直接権限の付与](../200.direct-authority.md)を参照してください。

## 手順例

* `ALTER SYSTEM` 権限をロール `role1` に付与します。

  ```shell
  GRANT ALTER SYSTEM ON *.* TO role1;
  ```

* データベース `dbtest` のすべてのオブジェクトに対する `SELECT` 権限をロール `role1` に付与します。

  ```shell
  GRANT SELECT ON dbtest.* TO role1;
  ```

  1つまたは複数の権限を複数のロールに同時に追加することができます。

  ```shell
  GRANT SELECT,UPDATE ON dbtest.* TO role1,role2;
  ```

* テーブル `test1.tbl1` の `SELECT` オブジェクト権限をロール `role1` に付与します。

  ```shell
  GRANT SELECT ON test1.tbl1 TO role1;
  ```

* テーブル `test1.tbl1` の `c1` 列に対する `SELECT` 権限をロール `role1` に付与します。

  ```shell
  GRANT SELECT(c1) ON test1.tbl1 TO role1;
  ```
