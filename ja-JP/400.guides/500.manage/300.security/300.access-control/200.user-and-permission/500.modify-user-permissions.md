# 権限の取り消し

権限を付与した後、ユーザーの権限を取り消すことができます。

## 前提条件

* 現在のユーザーは、取り消す権限を持っている必要があります（例えば、`test1` が `test2` のテーブル `t1` に対する `SELECT` 権限を取り消す場合、`test1` はテーブル `t1` に対する `SELECT` 権限を持っている必要があります）。また、`GRANT OPTION` 権限も持っている必要があります。

* `ALL PRIVILEGES` および `GRANT OPTION` 権限を取り消す場合、現在のユーザーはグローバルな `GRANT OPTION` 権限、または権限テーブルに対する `UPDATE` および `DELETE` 権限を持っている必要があります。

## 注意事項

* あるユーザーから複数の権限を同時に取り消す場合、権限タイプは半角カンマ（,）で区切ります。

* 複数のユーザーの権限を同時に取り消す場合、ユーザー名は半角カンマ（,）で区切ります。

* 取り消し操作は連鎖しません。例えば、ユーザー `test1` が `test2` に特定の権限を付与した場合、`test1` の権限を取り消しても、`test2` の対応する権限は自動的に取り消されません。

## 操作例

* グローバル権限の取り消し

  ユーザー `test` がすべてのデータベースのすべてのテーブルに対する `INSERT`、`SELECT` 権限を取り消します。

  ```shell
  REVOKE SELECT, INSERT ON *.* FROM 'test';
  ```

* データベースレベルの権限の取り消し

  ユーザー `test` がデータベース `db1` のすべてのテーブルに対する `INSERT`、`SELECT` 権限を取り消します。

  ```shell
  REVOKE SELECT, INSERT ON db1 FROM 'test';
  ```

* テーブルレベルの権限の取り消し

  ユーザー `test` がデータベース `db1` のテーブル `tb1_name` に対する `INSERT`、`SELECT` 権限を取り消します。

  ```shell
  REVOKE SELECT, INSERT ON db1.tb1_name FROM 'test';
  ```

* テーブル内の列の権限の取り消し

  ユーザー `test` がデータベース `db1` のテーブル `tb1_name` の列 `c1` に対する `SELECT` 権限、および列 `c1` と `c2` に対する `INSERT` 権限を取り消します。

  ```shell
  REVOKE SELECT(c1), INSERT (c1, c2) ON db1.tb1_name FROM test;
  ```

`REVOKE` ステートメントの詳細については、[REVOKE](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002017006)を参照してください。
