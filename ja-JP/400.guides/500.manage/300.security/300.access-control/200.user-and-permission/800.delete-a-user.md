# ユーザーの削除

`DROP USER` ステートメントを使用して、不要になったユーザーを削除できます。

## 前提条件

現在のユーザーがグローバルな `CREATE USER` 権限を持っている必要があります。`DROP USER` コマンドを実行するには、この権限が必要です。現在のユーザーがこの権限を持っているかどうかを確認するには、[ユーザー権限の確認](../200.user-and-permission/400.view-user-permissions.md)を参照してください。該当する権限を持っていない場合は、管理者に連絡し、適切な権限を付与してもらってください。ユーザー権限の付与に関する操作については、[直接権限付与](200.direct-authority.md)を参照してください。

## 使用上の制限

`mysql.user` テーブルに対しては、`DELETE` を使用した権限管理はできません。

## 手順

1. ユーザーがseekdbにログインします。

2. 以下のステートメントを実行して、1人または複数のユーザーを削除します。

   ステートメントは次のとおりです：

   ```sql
   DROP USER user_name [, user_name...];
   ```

   ここで、`user_name` は削除するユーザーのユーザー名です。複数のユーザーを同時に削除する場合は、ユーザー名を半角カンマ（,）で区切ります。

   ユーザーの削除に成功すると、そのユーザーが作成したデータベースオブジェクトは削除されませんが、そのユーザーのすべての権限は削除されます。

   `sqluser02` ユーザーを削除する例を以下に示します：

   ```shell
   DROP USER sqluser02;
   ```

   ```shell
   Query OK, 0 rows affected
   ```
