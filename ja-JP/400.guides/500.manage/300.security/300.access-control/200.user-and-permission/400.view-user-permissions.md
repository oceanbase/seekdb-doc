# ユーザー権限の確認

ユーザー作成後、必要に応じてそのユーザーの権限を確認できます。

## 前提条件

* `SHOW GRANTS`ステートメントを使用してユーザー権限を照会する場合、現在のユーザーを照会する場合は特別な権限は必要ありません。他のユーザーを照会する場合は、グローバルな`SELECT`権限が必要です。

* ユーザー権限をビューで確認する場合、対応するビューに対する`SELECT`権限が必要です。

## 手順

1. 管理者 `root` でseekdbにログインします。

2. 以下の方法でユーザー権限を確認します。

   * `SHOW GRANTS` ステートメントを使用して、ユーザーに付与された権限を確認します。

      現在のユーザーに付与された権限を確認するには、以下のいずれかのステートメントを使用できます：

      ```shell
      SHOW GRANTS;
      ```

      ```shell
      SHOW GRANTS FOR CURRENT_USER;
      ```

      ```shell
      SHOW GRANTS FOR CURRENT_USER();
      ```

      指定したユーザーに付与された権限を確認する必要がある場合は、`FOR` 句を追加します。ステートメントは次のとおりです：

      ```shell
      SHOW GRANTS FOR test;
      ```

      クエリ結果の例は以下のとおりです。

      ```shell
      +----------------------------------------+
      | Grants for test@%                      |
      +----------------------------------------+
      | GRANT INSERT, SELECT ON *.* TO 'test'  |
      | GRANT SELECT ON `db1`.* TO 'test'      |
      +----------------------------------------+
      2 rows in set
      ```

   * ユーザーが持つグローバル権限を確認します。

     `mysql.user` ビューを使用して、ユーザーが持つグローバル権限を確認できます。

     例：

     ```shell
     SELECT * FROM mysql.user WHERE user='test'\G
     ```

     ```shell
     *************************** 1. row ***************************
                       host: %
                       user: test
     ```

     `mysql.user` ビューのフィールドと説明の詳細については、[mysql.user](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015251)を参照してください。

   * ユーザーが持つデータベースレベルの権限を確認します。

     `mysql.db` ビューを使用して、特定のユーザーが持つデータベースレベルの権限を確認できます。

     ```shell
     SELECT * FROM mysql.db WHERE user='test'\G
     ```

     ```shell
     *************************** 1. row ***************************
                      host: %
                        db: test
                      user: test
               select_priv: Y
               insert_priv: Y
               update_priv: Y
               delete_priv: N

     ```

     `mysql.db` ビューのフィールドと説明の詳細については、[mysql.db](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002014749)を参照してください。

   * ユーザーに付与された列権限を確認します。

      ビュー `mysql.columns_priv` または `information_schema.COLUMN_PRIVILEGES` を使用して、ユーザーに付与された列権限を確認できます。

      * ビュー `mysql.columns_priv` のクエリ

        ```shell
        SELECT * FROM mysql.columns_priv;
        ```

        クエリ結果は次のとおりです：

        ```shell
        +------+-------+-------+------------+-------------+-------------+---------------------+
        | Host | Db    | User  | Table_name | Column_name | Column_priv | Timestamp           |
        +------+-------+-------+------------+-------------+-------------+---------------------+
        | %    | test1 | user2 | tbl1       | c1          | Insert      | 2025-12-15 15:02:57 |
        | %    | test1 | user1 | tbl1       | c1          | Select      | 2025-12-15 11:05:21 |
        +------+-------+-------+------------+-------------+-------------+---------------------+
        2 rows in set
        ```

      * ビュー `information_schema_COLUMN_PRIVILEGES` のクエリ

        ```shell
        SELECT * FROM information_schema.COLUMN_PRIVILEGES;
        ```

        クエリ結果は次のとおりです：

        ```shell
        +-------------+---------------+--------------+------------+-------------+----------------+--------------+
        | GRANTEE     | TABLE_CATALOG | TABLE_SCHEMA | TABLE_NAME | COLUMN_NAME | PRIVILEGE_TYPE | IS_GRANTABLE |
        +-------------+---------------+--------------+------------+-------------+----------------+--------------+
        | 'user2'@'%' | def           | test1        | tbl1       | c1          | INSERT         | YES          |
        | 'user1'@'%' | def           | test1        | tbl1       | c1          | SELECT         | NO           |
        +-------------+---------------+--------------+------------+-------------+----------------+--------------+
        2 rows in set
        ```

        `information_schema_COLUMN_PRIVILEGES` ビューのフィールドと説明の詳細については、[information_schema_COLUMN_PRIVILEGES](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015215)を参照してください。
