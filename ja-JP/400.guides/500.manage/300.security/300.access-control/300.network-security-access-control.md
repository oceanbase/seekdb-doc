# ネットワークセキュリティアクセス制御

seekdbは、ネットワークセキュリティアクセス制御を実現するためのホワイトリストポリシーを提供します。ホワイトリスト機能を使用して、どのクライアントがseekdbにアクセスできるかを設定できます。

ホワイトリストはシステム変数 `ob_tcp_invited_nodes` によって制御され、グローバルなホワイトリスト制限パラメータです。デフォルト値は `127.0.0.1,::1` で、ローカルのIPアドレスへの接続のみを許可することを意味します。この変数はリスト形式の値をサポートし、リスト内の値は半角カンマ（,）で区切られます。例：A,B,C,D。ユーザーがログインする際、seekdbはユーザーのIPアドレスをA、B、C、Dと順次照合検証します。すべて一致しない場合はアクセスを拒否します。いずれか一つでも一致すれば、ホワイトリストを通過したことになります。

リスト値では、以下の値の代入をサポートします：

* IPアドレス。例：`192.168.1.1`。一致時は等価一致を採用し、ユーザーClient IPがそのIP値と等しい場合に一致とみなします。
* パーセント記号（%）またはアンダースコア（_）を含むIPアドレス。例：`192.168.1.%` または `192.168.1._`。一致時はあいまい一致を採用し、LIKE構文に似ています。
* IP/NETMASKアドレス。例：`192.168.1.0/24` または `192.168.1.0/255.255.255.0`。一致時はマスク一致を採用し、Client_IP & NetMask == IP を満たす場合にのみ一致成功とみなされます。MySQLのマスク一致に類似しています。

:::tip
ホワイトリストを変更しても、既に作成された `session` には影響しません。
:::

## ホワイトリストの確認と設定

1. `root` ユーザーでseekdbにログインします。

   ```shell
   mysql -h127.0.0.1 -uroot -P2881
   ```

2. 以下のステートメントを実行して、ホワイトリストを確認します。

   ```shell
   SHOW VARIABLES LIKE 'ob_tcp_invited_nodes';
   ```

   ```shell
   +----------------------+-------+
   | Variable_name        | Value |
   +----------------------+-------+
   | ob_tcp_invited_nodes | %     |
   +----------------------+-------+
   ```

   ここで、値が `%` の場合は、任意のクライアントIP接続を許可することを意味します。

3. ホワイトリストの設定を変更する必要がある場合は、以下のステートメントを実行して、ホワイトリストを再設定できます。

   例：

   ```shell
   SET GLOBAL ob_tcp_invited_nodes='%';
   ```

   ```shell
   SET GLOBAL ob_tcp_invited_nodes='10.10.10.%';
   ```
