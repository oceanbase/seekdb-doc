# パスワードの複雑さ

悪意のあるパスワード攻撃を防ぐために、seekdbユーザーは必要に応じてパスワードの複雑さ関数を設定し、ユーザーログインの身元を検証することで、データベースのセキュリティを向上させることができます。本記事では、seekdbログインユーザーのパスワード複雑さを設定する方法について説明します。

## 関連変数の紹介

seekdbでは、一連のシステム変数を設定することでパスワードの複雑さルールを定義できます。ユーザー作成時やユーザーのパスワード変更時に、システム変数の設定に基づいてパスワードが検証され、検証に失敗した場合はエラーが報告されます。関連するシステム変数は以下の表のとおりです。

|   変数名   |    機能  |   使用方法    |
|------------|---------|--------------|
|   validate_password_check_user_name   |ユーザーのパスワードがユーザー名と同じであるかどうかをチェックします。|<ul><li>`on`：ユーザーのパスワードはユーザー名と同じにできません。</li><li>`off`：ユーザーのパスワードはユーザー名と同じにできます。デフォルト値は`off`です。</li></ul>|
|validate_password_length|ユーザーパスワードの最小長を設定します。|デフォルト値は0です。|
|validate_password_mixed_case_count|ユーザーパスワードに含まれる大文字と小文字の最小数を設定します。|デフォルト値は0です。|
|validate_password_number_count|ユーザーパスワードに含まれる数字の最小数を設定します。|デフォルト値は0です。|
|validate_password_policy|パスワードチェックポリシーを設定します。| <ul><li>`low`：パスワード長のみの検出を表します。</li><li>`medium`：パスワード長の検出、大文字数の検出、小文字数の検出、数字数の検出、特殊文字数の検出、ユーザー名とパスワードが同じかどうかの検出を含みます。</li></ul>|
|validate_password_special_char_count|ユーザーパスワードに含まれる特殊文字の最小数を設定します。|デフォルト値は0です。|

## パスワードの複雑さの設定

:::tip
本番環境では、パスワードの長さを20文字に設定し、数字、大文字、小文字、特殊文字を含めることを推奨します。パスワードの複雑さが低いほど、例えばユーザー名を含む場合や繰り返しの文字を使用する場合など、解読される可能性が高くなります。セキュリティ上の理由から、ユーザーのパスワードは高い複雑さを持たせる必要があります。
:::

このセクションでは、パスワードの複雑さルールを最小長8文字、大文字3文字以上、小文字3文字以上、特殊文字1文字以上、ユーザーパスワードはユーザー名と同じにできない、およびチェックポリシーを`medium`に設定した場合を例に、パスワードの複雑さを設定する操作手順を説明します。

1. `root`ユーザーでseekdbにログインします。

    ```shell
    mysql -h127.0.0.1 -uroot -P2881
    ```

2. システム変数を使用してパスワードの複雑さを設定します。

    ```shell
    SET GLOBAL validate_password_check_user_name=on;
    SET GLOBAL validate_password_length=8;
    SET GLOBAL validate_password_mixed_case_count=3;
    SET GLOBAL validate_password_special_char_count=1;
    SET GLOBAL validate_password_policy='medium';
    ```

3. 終了後再ログインし、変数が有効になっているか確認します。

    ```shell
    SHOW VARIABLES LIKE 'validate%';
    ```

    ```shell
    +--------------------------------------+--------+
    +--------------------------------------+--------+
    | VARIABLE_NAME                        | VALUE  |
    +--------------------------------------+--------+
    | validate_password_check_user_name    | off     |
    | validate_password_length             | 8      |
    | validate_password_mixed_case_count   | 3      |
    | validate_password_number_count       | 0      |
    | validate_password_policy             | medium |
    | validate_password_special_char_count | 1      |
    +--------------------------------------+--------+
    6 rows in set (0.00 sec)
    ```

4. パスワードの複雑さを検証します。

    2つのユーザーを作成し、それぞれ要件を満たすパスワードと満たさないパスワードを設定します。

    ```shell
    CREATE USER sectest1 IDENTIFIED BY '******';
    ```

    ```shell
    ERROR 1819 (HY000): Your password does not satisfy the current policy
    requirements
    ```

    ```shell
    CREATE USER sectest1 IDENTIFIED BY '***1_%';
    ```

    ```shell
    Query OK, 0 rows affected
    ```

    設定したパスワードの複雑さが要件を満たしていない場合、ユーザーの作成は失敗します。
