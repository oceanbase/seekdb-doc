# ごみ箱オブジェクトの表示

`SHOW RECYCLEBIN` ステートメントを使用して、ごみ箱オブジェクトを確認できます。

## 背景

データベースオブジェクトにDROP操作を実行すると：

* ごみ箱が有効な場合、そのオブジェクトはごみ箱に移動し、ごみ箱でそのオブジェクトを検索できます。

* ごみ箱が無効な場合、そのオブジェクトはごみ箱に移動せず、ごみ箱ではそのオブジェクトを検索できません。

## 手順

1. 管理者 `root` でseekdbにログインします。

   接続例は以下の通りです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   mysql -h127.0.0.1 -uroot -P2881
   ```

2. 以下のステートメントを実行して、ごみ箱オブジェクトを確認します。

   ```shell
   SHOW RECYCLEBIN;
   ```

   ```shell
   +--------------------------------+---------------+----------+----------------------------+
   | OBJECT_NAME                    | ORIGINAL_NAME | TYPE     | CREATETIME                 |
   +--------------------------------+---------------+----------+----------------------------+
   | __recycle_$_1_1765784426825016 | test_db       | DATABASE | 2025-12-15 15:40:26.825340 |
   +--------------------------------+---------------+----------+----------------------------+
   1 row in set (0.003 sec)
   ```

   実行結果の関連フィールドの説明は以下の通りです：

   * `OBJECT_NAME`：ごみ箱内のオブジェクト名を表します。

   * `ORIGINAL_NAME`：元のオブジェクト名を表します。

   * `TYPE`：ごみ箱オブジェクトのタイプを表します。`INDEX`、`TABLE`、`DATABASE` の3種類をサポートしています。

   * `CREATETIME`：オブジェクトがごみ箱に移動した時間を表します。
