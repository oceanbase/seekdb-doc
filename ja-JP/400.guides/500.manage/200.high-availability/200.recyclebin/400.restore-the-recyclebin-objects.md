# ごみ箱オブジェクトの復元

削除されたオブジェクトはごみ箱に移動し、その後 `FLASHBACK` ステートメントを使用してごみ箱から復元できます。

## 注意点

* テーブルを復元する際、Flashbackオブジェクトの順序は従属関係に従う必要があります。つまり、データベースを先にFlashbackし、その後テーブルをFlashbackします。

* インデックスの直接復元はサポートされていません。`FLASHBACK` ステートメントでテーブルを復元すると、そのテーブル上のインデックスも自動的に復元されます。

* ごみ箱からオブジェクトを復元する際、復元対象の名前を変更できますが、既存のオブジェクト名と重複してはなりません。重複するとシステムはエラーを返します。

* ごみ箱からテーブルを復元する前に、そのテーブルが属するデータベースが削除されている場合は、データベースを先に復元し、その後テーブルを復元する必要があります。

## データベースの復元

復元時にデータベース名を変更できますが、既存のデータベース名と重複してはなりません。重複するとシステムはエラーを返します。

1. 管理者 `root` がseekdbにログインします。

   接続例は以下の通りです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   mysql -h127.0.0.1 -uroot -P2881
   ```

2. `SHOW RECYCLEBIN` ステートメントを実行し、ごみ箱内のオブジェクト名を取得します。

   ```shell
   SHOW RECYCLEBIN;
   ```

   ```shell
   +--------------------------------+---------------+----------+----------------------------+
   | OBJECT_NAME                    | ORIGINAL_NAME | TYPE     | CREATETIME                 |
   +--------------------------------+---------------+----------+----------------------------+
   | __recycle_$_1_1765784426825016 | test_db       | DATABASE | 2025-12-15 15:40:26.825340 |
   +--------------------------------+---------------+----------+----------------------------+
   1 row in set (0.003 sec)
   ```

3. 業務ニーズに応じて、適切なシナリオを選択し、ごみ箱内のデータベースを復元します。

   * ごみ箱からデータベースを復元した場合、復元後のデータベース名はごみ箱に入る前の名前になります。

     ```sql
     FLASHBACK DATABASE object_name TO BEFORE DROP;
     ```

     ここで、`object_name` はデータベースオブジェクトがごみ箱内で持つ名前を表します。元の名前の使用はサポートされていません。

     このステートメントを実行した後、復元対象のデータベース名が既存のデータベース名と重複する場合、システムはエラーを返します。

     例：

     ```shell
     FLASHBACK DATABASE __recycle_$_1_1765784426825016 TO BEFORE DROP;
     ```

   * ごみ箱からデータベースを復元して名前を変更します。

     ```sql
     FLASHBACK DATABASE object_name TO BEFORE DROP RENAME TO new_database_name;
     ```

     ここで：

     * `object_name` はデータベースオブジェクトがごみ箱内で持つ名前を表します。元の名前の使用はサポートされていません。

     * `new_database_name`：ごみ箱から復元後のデータベース名を表します。

     例：

     ```shell
     FLASHBACK DATABASE __recycle_$_1_1765784426825016 TO BEFORE DROP RENAME TO new_infotest;
     ```

## テーブルの復元

復元時にテーブル名を変更できますが、既存のテーブル名と重複してはなりません。重複するとシステムはエラーを返します。

1. 管理者 `root` が seekdb にログインします。

   接続例は以下の通りです。データベースへの接続時は、実際の環境に合わせてください。

   ```shell
   mysql -h127.0.0.1 -uroot -P2881
   ```

2. `SHOW RECYCLEBIN` ステートメントを実行し、ゴミ箱内のオブジェクト名を取得します。

   ```shell
   SHOW RECYCLEBIN;
   ```

    ```shell
    +--------------------------------+---------------+-------+----------------------------+
    | OBJECT_NAME                    | ORIGINAL_NAME | TYPE  | CREATETIME                 |
    +--------------------------------+---------------+-------+----------------------------+
    | __recycle_$_1_1765785669490408 | tbl1          | TABLE | 2025-12-15 16:01:09.491488 |
    +--------------------------------+---------------+-------+----------------------------+
    1 row in set (0.002 sec)
    ```

3. 業務ニーズに応じて、適切なシナリオを選択し、ゴミ箱からテーブルを復元します。

   * ゴミ箱からテーブルを復元します。復元後のテーブル名は、ゴミ箱に入る前のテーブル名になります。

     ```sql
     FLASHBACK TABLE object_name TO BEFORE DROP;
     ```

     ここで、`object_name` はゴミ箱内のテーブルオブジェクト名を表します。元の名前を使用することもできますが、ゴミ箱内の名前はグローバルに一意であるため、ゴミ箱内の名前の使用を推奨します。

     例：

     ```shell
     FLASHBACK TABLE __recycle_$_1_1765785669490408 TO BEFORE DROP;
     ```

     このステートメントを実行すると、復元後のテーブル名はゴミ箱に入る前の名前になり、そのテーブルが属するデータベースまたはスキーマオブジェクトは、テーブル削除前に属していたデータベースまたはスキーマオブジェクトのままになります。このテーブルがゴミ箱に入る前の名前が既存のテーブル名と重複する場合、システムはエラーを返します。

   * ゴミ箱からテーブルを復元して名前を変更します。

     ```sql
     FLASHBACK TABLE object_name TO BEFORE DROP RENAME To new_table_name;
     ```

     ここで、`object_name` はゴミ箱内のテーブルオブジェクト名を表します。元の名前を使用することもできますが、ゴミ箱内の名前はグローバルに一意であるため、ゴミ箱内の名前の使用を推奨します。`new_table_name` はテーブル復元後の新しい名前を表します。

     例：

     ```shell
     FLASHBACK TABLE __recycle_$_1_1765785669490408 TO BEFORE DROP RENAME To infotable;
     ```

     このステートメントを実行すると、復元後のテーブル名は新しい名前になり、そのテーブルが属するデータベースまたはスキーマオブジェクトは、テーブル削除前に属していたデータベースまたはスキーマオブジェクトのままになります。名前を変更したテーブル名が既存のテーブル名と重複する場合、システムはエラーを返します。

   * ゴミ箱からテーブルを指定されたデータベースまたはスキーマオブジェクトに復元して名前を変更します。

     ```sql
     FLASHBACK TABLE object_name TO BEFORE DROP RENAME To database_name.new_table_name;
     ```

     ここで、`object_name` はゴミ箱内のテーブルオブジェクト名を表します。元の名前を使用することもできますが、ゴミ箱内の名前はグローバルに一意であるため、ゴミ箱内の名前の使用を推奨します。`database_name.new_table_name` はテーブル復元後の新しい名前およびそれが属するデータベースまたはスキーマオブジェクトを表します。

     例：

     ```shell
     FLASHBACK TABLE __recycle_$_1_1765785669490408 TO BEFORE DROP RENAME To test.infotable;
     ```

     このステートメントを実行すると、復元後のテーブル名は新しい名前になり、そのテーブルが属するデータベースまたはスキーマオブジェクトは指定されたデータベースまたはスキーマオブジェクトになります。名前を変更したテーブル名が既存のテーブル名と重複する場合、システムはエラーを返します。
