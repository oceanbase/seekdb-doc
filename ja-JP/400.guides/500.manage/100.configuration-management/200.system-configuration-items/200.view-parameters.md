# 構成パラメータの確認

構成パラメータを確認する主な方法は以下のとおりです：

* `SHOW`ステートメントで構成パラメータを確認する

  seekdbに格納されている隠れたパラメータ（`_xx_xx`形式のパラメータ）を除くすべての構成パラメータとそのすべてのプロパティの説明を確認できます。また、隠れたパラメータの値がデフォルト値以外に変更されている場合も、`SHOW`ステートメントを使用して確認できます。

* `GV$OB_PARAMETERS`ビューで構成パラメータを確認する

  `SHOW`ステートメントとは異なり、`GV$OB_PARAMETERS`ビューを使用すると、seekdbに格納されているすべての構成パラメータ（隠れたパラメータ、つまり`_xx_xx`形式のパラメータを含む）とそのすべてのプロパティの説明を確認できます。

## SHOWステートメントでパラメータを確認する

SHOWステートメントを使用して、パラメータの値を確認できます。

1. seekdbにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に合わせてください。

   ```shell
   mysql -h127.xx.xx.xx -P2881 -uroot -p***** -A
   ```

2. 以下のコマンドを実行して、パラメータを確認します。

   ステートメントは以下のとおりです：

   ```sql
   SHOW PARAMETERS [SHOW_PARAM_OPTS];
   ```

   ここで：

   * `[SHOW_PARAM_OPTS]` は `[LIKE 'pattern' | WHERE expr]` と指定できます。`WHERE expr` で指定できる列属性は、`SHOW PARAMETERS` の実行結果に含まれる列属性と一致します。

   パラメータのクエリ例は以下のとおりです。

      ```sql
      SHOW PARAMETERS LIKE '%syslog_level%';
      ```

      クエリ結果は以下のとおりです。

      ```shell
      +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
      | name         | data_type | value | info                                                                                                                         | edit_level        | default_value | isdefault |
      +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
      | syslog_level | STRING    | WDIAG | specifies the current level of logging. There are DEBUG, TRACE, WDIAG, EDIAG, INFO, WARN, ERROR, seven different log levels. | DEFAULT | DYNAMIC_EFFECTIVE | WDIAG         |         1 |
      +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
      1 row in set
      ```

   クエリ結果の各列の意味は、次の表のとおりです。

   |     プロパティ    |  意味                             |
   |------------|-----------------------------------|
   | name       | パラメータ名。                         |
   | data_type  | パラメータのデータ型。`STRING`、`CAPACITY`などが含まれます。              |
   | value      | パラメータの値。 |
   | info       | パラメータの説明情報。           |
   | edit_level | この構成パラメータの変更動作を定義します。 <ul><li>`READONLY`：このパラメータは変更できないことを示します。</li> <li>`STATIC_EFFECTIVE`：このパラメータは変更可能ですが、seekdbを再起動しないと変更が有効になりません。</li>   <li>`DYNAMIC_EFFECTIVE`：このパラメータは変更可能で、変更後は動的に反映されます。</li></ul>          |
   | default_value | パラメータのデフォルト値。 |
   | isdefault  | 現在の値がデフォルト値かどうかを示します。<ul><li>0：現在の値がデフォルト値ではないことを示します。</li><li>1：現在の値がデフォルト値であることを示します。</li></ul> |

## GV$OB_PARAMETERSビューでパラメータを確認する

1. seekdbにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に合わせてください。

   ```shell
   mysql -h127.xx.xx.xx -P2881 -uroot -p***** -A
   ```

2. 以下のコマンドを実行して、`oceanbase` データベースに入ります。

   ```sql
   USE oceanbase;
   ```

3. 以下のコマンドを実行して、パラメータを確認します。

   クエリ例は以下のとおりです：

   ```sql
   SELECT * FROM GV$OB_PARAMETERS WHERE NAME LIKE '%syslog_level%';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   | NAME         | DATA_TYPE | VALUE | INFO                                                                                                                         | EDIT_LEVEL        | DEFAULT_VALUE | ISDEFAULT |
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   | syslog_level | STRING    | WDIAG | specifies the current level of logging. There are DEBUG, TRACE, WDIAG, EDIAG, INFO, WARN, ERROR, seven different log levels. | DYNAMIC_EFFECTIVE | WDIAG         | YES       |
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   1 row in set
   ```

  `GV$OB_PARAMETERS` ビューの詳細については、[GV$OB_PARAMETERS(MySQLモード)](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015150)を参照してください。
