# 構成パラメータの変更

構成パラメータを変更することで、seekdbの動作をビジネス要件に合わせることができます。seekdbの構成パラメータはパラメータとも呼ばれ、動的に反映されるものと再起動後に反映されるものの2種類があります。構成パラメータの設定により、seekdbのモジュールスイッチなどの機能を制御できます。

構成パラメータの詳細については、[構成管理の紹介](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002013267)を参照してください。

## 手順

1. seekdbにログインします。

   接続例は以下のとおりですが、データベースへの接続時は実際の環境に合わせてください。

   ```shell
   mysql -h127.xx.xx.xx -P2881 -uroot -p***** -A
   ```

2. 以下のコマンドを実行して、パラメータの値を確認します。

   例：

   ```sql
   SHOW PARAMETERS LIKE '%syslog_level%';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   | name         | data_type | value | info                                                                                                                         | edit_level        | default_value | isdefault |
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   | syslog_level | STRING    | WDIAG | specifies the current level of logging. There are DEBUG, TRACE, WDIAG, EDIAG, INFO, WARN, ERROR, seven different log levels. | DYNAMIC_EFFECTIVE | WDIAG         |         1 |
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   1 row in set
   ```

   詳細なパラメータの確認方法については、[パラメータの確認](200.view-parameters.md)を参照してください。

3. 以下のコマンドを実行して、パラメータの値を変更します。

   ステートメントは次のとおりです：

   ```sql
   ALTER SYSTEM [SET] parameter_name = expression
       [SCOPE = {SPFILE | BOTH}]
   ```

   関連パラメータの説明は以下のとおりです：

   * `expression`は、変更後のパラメータ値を指定するために使用されます。

   * `SCOPE`は、このパラメータ変更の有効範囲を指定するために使用されます。デフォルト値は`BOTH`です。詳細は以下のとおりです：

     * `SPFILE`：構成テーブル内のパラメータ値のみを変更します。seekdbを再起動した後に有効になります。

     * `BOTH`：構成テーブルとメモリ内の値を変更します。変更は即時に反映され、seekdbを再起動した後も設定値が有効になります。

   パラメータ変更の例は以下のとおりです：

    ```sql
    ALTER SYSTEM SET syslog_level='ERROR' SCOPE = SPFILE;
    ```

    ```sql
    ALTER SYSTEM SET syslog_io_bandwidth_limit = '5M';
    ```

4. 変更が成功した後、実際の状況（seekdbを再起動するかどうか）に応じて、`SHOW PARAMETERS`ステートメントを使用してパラメータの値が正常に変更されたかどうかを検証できます。

   ```sql
   SHOW PARAMETERS LIKE '%syslog_level%';
   ```

   クエリ結果は次のとおりです：

   ```shell
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   | name         | data_type | value | info                                                                                                                         | edit_level        | default_value | isdefault |
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   | syslog_level | STRING    | ERROR | specifies the current level of logging. There are DEBUG, TRACE, WDIAG, EDIAG, INFO, WARN, ERROR, seven different log levels. | DYNAMIC_EFFECTIVE | WDIAG         |         0 |
   +--------------+-----------+-------+------------------------------------------------------------------------------------------------------------------------------+-------------------+---------------+-----------+
   1 row in set
   ```
