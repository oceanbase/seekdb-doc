# システム変数の変更

システム変数の設定により、seekdbの動作をビジネス要件に合わせることができます。本記事では、システム変数の変更方法について説明します。

システム変数は`SET`ステートメントを使用して変更できます。

* セッションレベルの変数を設定しても、その変更は現在のセッション内でのみ有効であり、他のセッションには反映されません。
* グローバルレベルの変数を設定しても、現在のセッションには無効です。変更を有効にするには、再ログインして新しいセッションを確立する必要があります。

以下の例で使用されているシステム変数`ob_query_timeout`は、SQL文のクエリ操作におけるタイムアウト時間を設定するために使用されます。単位はマイクロ秒です。大規模データのクエリ操作時に、システム変数`ob_query_timeout`の値を大きく設定することで、クエリのタイムアウトによる文の実行失敗を防ぐことができます。

## セッションレベルのシステム変数を変更する

1. seekdbにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に準じてください。

   ```shell
   mysql -h127.xx.xx.xx -P2881 -uroot -p***** -A
   ```

2. セッションレベルのシステム変数を確認します。

    ```shell
    SHOW VARIABLES LIKE 'ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 10000000 |
    +------------------+----------+
    1 row in set
    ```

3. `SET` を使用してセッションレベルの変数値を変更します。

    ```shell
    SET ob_query_timeout = 20000000;
    ```

4. 変更結果を確認します。

    ```shell
    SHOW VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
    ```

    結果は次のとおりです：

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 20000000 |
    +------------------+----------+
    1 row in set
    ```

## グローバルレベルのシステム変数の変更

1. seekdbにログインします。

   接続例は以下のとおりです。データベースへの接続時は、実際の環境に合わせてください。

   ```shell
   mysql -h127.xx.xx.xx -P2881 -uroot -p***** -A
   ```

2. グローバル変数を確認します。

    ```shell
    SHOW GLOBAL VARIABLES WHERE variable_name LIKE  'ob_query_timeout';
    ```

    結果は次のとおりです。

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 10000000 |
    +------------------+----------+
    1 row in set
    ```

3. `SET` を使用してグローバル変数の値を変更します。

    ```shell
    SET GLOBAL ob_query_timeout = 20000000;
    ```

4. 変更結果を確認します。

    ```shell
    SHOW GLOBAL VARIABLES WHERE variable_name LIKE 'ob_query_timeout';
    ```

    結果は次のとおりです。

    ```shell
    +------------------+----------+
    | Variable_name    | Value    |
    +------------------+----------+
    | ob_query_timeout | 20000000 |
    +------------------+----------+
    1 row in set
    ```

    変更が成功した後、ビュー `DBA_OB_SYS_VARIABLES` を使用して `ob_query_timeout` 変数の詳細な変更履歴とデフォルト値を確認することもできます。ステートメントは以下のとおりです。

    ```shell
    SELECT * FROM oceanbase.DBA_OB_SYS_VARIABLES WHERE NAME='ob_query_timeout';
    ```

    結果は次のとおりです。

    ```shell
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    | CREATE_TIME                | MODIFY_TIME                | NAME             | VALUE    | MIN_VALUE | MAX_VALUE | SCOPE            | INFO                             | DEFAULT_VALUE | ISDEFAULT |
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    | 2025-11-19 16:55:28.311760 | 2025-12-11 15:50:59.153465 | ob_query_timeout | 20000000 |           |           | GLOBAL | SESSION | Query timeout in microsecond(us) | 10000000      | NO        |
    +----------------------------+----------------------------+------------------+----------+-----------+-----------+------------------+----------------------------------+---------------+-----------+
    1 row in set
    ```

## ブール型変数の変更

`SHOW VARIABLES` コマンドでON/OFFとして表示される変数は、以下のいずれかの方法で変数値を設定できます。

```sql
SET foreign_key_checks = ON;
SET foreign_key_checks = TRUE;
SET foreign_key_checks = 1;

SET GLOBAL foreign_key_checks = OFF;
SET GLOBAL foreign_key_checks = FALSE;
SET GLOBAL foreign_key_checks = 0;
```

:::info

ON/OFF、TRUE/FALSE、または1/0の3つの方法でブール型変数を設定することは、同じ効果があります。

:::
