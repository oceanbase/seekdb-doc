# LangChainとの連携

seekdbは、ベクトル型データの格納、ベクトルインデックス、そしてembeddingベクトル検索機能を提供します。これにより、ベクトル化したデータをseekdbに保存し、次の検索処理で利用することが可能です。

LangChainは、言語モデルを活用したアプリケーションを開発するためのフレームワークです。これにより、アプリケーションは以下の機能を備えることができます：

* コンテキスト認識：言語モデルをコンテキストソース（プロンプト指示、少量の例、応答が必要な内容など）に接続します。
* 推論機能：言語モデルに推論を依存させます（提供されたコンテキストに基づいてどのように回答するか、どのようなアクションを取るかなど）。

このチュートリアルでは、通義千問APIを組み合わせて、seekdbの[ベクトル検索の概要](../../200.develop/600.search/300.vector-search/100.vector-search-intro.md)、[通義千問](https://www.alibabacloud.com/en/solutions/generative-ai/qwen?_p_lc=1)と[LangChain](https://python.langchain.com/)を統合し、ドキュメント質問応答を実現する方法を説明します。

## 前提条件

* seekdbデータベースのデプロイが完了していること。
* 環境に使用可能なデータベースとアカウントが存在し、データベースアカウントに対して読み書き権限が付与されていること。
* Python 3.9以降のバージョンをインストールしていること。
* 依存関係をインストールしていること。

    ```shell
    python3 -m pip install -U langchain-oceanbase
    python3 -m pip install langchain_community
    python3 -m pip install dashscope
    ```

* ベクトル検索機能を有効にするには、`ob_vector_memory_limit_percentage`構成パラメータを設定できます。デフォルト値の`0`（適応モード）を維持することを推奨します。この構成パラメータをより正確に設定する必要がある場合は、関連する設定ドキュメントを参照してください。

## ステップ１：データベース接続情報を取得する

seekdbデータベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbデータベースへの接続IPアドレス。
* `$port`：seekdbデータベースへの接続ポート。デフォルトは`2881`で、デプロイ時にカスタマイズ可能です。
* `$database_name`：アクセス対象のデータベース名。

    :::tip

    データベースに接続するユーザーは、そのデータベースに対する`CREATE`、`INSERT`、`DROP`、および`SELECT`権限を持っている必要があります。ユーザー権限の詳細については、[MySQLモードの権限分類](https://www.alibabacloud.com/help/en/model-studio/get-api-key?spm=a2c63.l28256.help-menu-2400256.d_2.47db1b76nM44Ut)を参照してください。

    :::

* `$user_name`：データベース接続アカウント。形式：`ユーザー名`。
* `$password`：アカウントのパスワード。

## ステップ2：AIアシスタントを構築する

### Qwen APIキーの環境変数を設定する

[Qwen APIキー](https://www.alibabacloud.com/help/en/model-studio/configure-api-key-through-environment-variables?spm=a2c63.p38356.help-menu-2400256.d_2_0_1.56069f6b3m576u)を取得し、[APIキーを環境変数に設定します](https://raw.githubusercontent.com/GITHUBear/langchain/refs/heads/master/docs/docs/how_to/state_of_the_union.txt)。

```shell
export DASHSCOPE_API_KEY="YOUR_DASHSCOPE_API_KEY"
```

### ドキュメントの読み込みと分割

サンプルデータをダウンロードし、`CharacterTextSplitter`を使用して約1000文字ごとのブロックに分割します。

```python
from langchain_community.document_loaders import TextLoader
from langchain_community.embeddings import DashScopeEmbeddings
from langchain_text_splitters import CharacterTextSplitter
from langchain_oceanbase.vectorstores import OceanbaseVectorStore
import os
import requests

DASHSCOPE_API = os.environ.get("DASHSCOPE_API_KEY", "")
embeddings = DashScopeEmbeddings(
    model="text-embedding-v1", dashscope_api_key=DASHSCOPE_API
)

url = "https://raw.githubusercontent.com/GITHUBear/langchain/refs/heads/master/docs/docs/how_to/state_of_the_union.txt"
res = requests.get(url)
with open("state_of_the_union.txt", "w") as f:
    f.write(res.text)

loader = TextLoader('./state_of_the_union.txt')

documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
docs = text_splitter.split_documents(documents)
```

### データをseekdbに挿入する

```python
connection_args = {
    "host": "127.0.0.1",
    "port": "2881",
    "user": "root",
    "password": "",
    "db_name": "test",
}
DEMO_TABLE_NAME = "demo_ann"
ob = OceanbaseVectorStore(
    embedding_function=embeddings,
    table_name=DEMO_TABLE_NAME,
    connection_args=connection_args,
    drop_old=True,
    normalize=True,
)
res = ob.add_documents(documents=docs)
```

### ベクトル検索

この手順では、ドキュメント `state_of_the_union.txt` から `“What did the president say about Ketanji Brown Jackson”` を検索する方法を示します。

```python
query = "What did the president say about Ketanji Brown Jackson"
docs_with_score = ob.similarity_search_with_score(query, k=3)

for doc, score in docs_with_score:
    print("-" * 80)
    print("Score: ", score)
    print(doc.page_content)
    print("-" * 80)
```
