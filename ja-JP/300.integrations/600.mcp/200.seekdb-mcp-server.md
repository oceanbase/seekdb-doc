# seekdb MCP Server

seekdb MCP Serverは、Anthropicが提案したMCP（Model Context Protocol）プロトコルに基づき、AIアシスタントがseekdbデータベースと直接やり取りし、「自然言語」を「データベース操作」に変換できるようにするサーバーです。自然言語で要件を記述するだけで、AIが自動的にデータベース操作を代行してくれます。ドキュメントコレクションの作成、データの挿入、複雑なクエリの実行、さらには完全なナレッジベースアプリケーションの構築まで可能です。

本記事では主にseekdb MCP Serverの機能と使用方法について説明します。seekdbデータベースの詳細については、[seekdbデータベース](../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。

## 機能アーキテクチャ

### コア機能

seekdb MCP Serverは、AIツールがデータベースを直接呼び出す機能をサポートしています。

| 機能分類 | ツール一覧 | 機能説明 |
|----------|---------|----------|
| ベクトルコレクション管理 | create_collection、query_collection、add_data_to_collection など | ベクトルコレクションの作成、セマンティック検索、ドキュメント管理 |
| 高級検索 | full_text_search、hybrid_search | 全文検索、ハイブリッド検索（BM25 + ベクトル） |
| AI関数 | ai_complete、ai_rerank、create_ai_model など | LLMを呼び出してテキストを生成、検索結果の再ランキング |
| AIメモリシステム | seekdb_memory_query、seekdb_memory_insert など | セッション間でメモリを永続化し、AIに「覚えてもらう」 |
| データのインポートとエクスポート | import_csv_file_to_seekdb、export_csv_file_from.seekdb | CSVファイルとデータベーステーブル/ベクトルコレクションの相互変換 |

### ベクトル集合管理

| ツール | 機能 |
|------|------|
| create_collection | ベクトルコレクションを作成します |
| list_collections | すべてのコレクションを一覧表示します |
| has_collection | コレクションが存在するかどうかを確認します |
| peek_collection | コレクション内のドキュメントをプレビューします |
| add_data_to_collection | ドキュメントを追加します(ベクトルは自動生成されます) |
| update_collection | ドキュメントを更新します |
| delete_documents | ドキュメントを削除します |
| query_collection | ベクトル類似性検索 |
| delete_collection | コレクションを削除します |

### 高級検索

| ツール | 機能 |
|------|------|
| full_text_search | 全文検索（キーワードに基づく）|
| hybrid_search | 混合検索（全文検索とベクトル検索を組み合わせたもの）|

### AIモデルツール

| ツール | 機能 |
|------|------|
| create_ai_model | AIモデル（埋め込み、テキスト生成、再ランキング）を登録します。|
| create_ai_model_endpoint | モデルをAPIサービスに接続するエンドポイントを作成します。 |
| drop_ai_model | 登録済みのAIモデルを削除します。 |
| drop_ai_model_endpoint | AIモデルエンドポイントを削除します。 |
| ai_complete | LLMを呼び出してテキスト生成を行います。 |
| ai_rerank | AIモデルを使用して、関連性に基づいてドキュメントの順序を変更します。 |
| get_registered_ai_models | 登録済みのすべてのAIモデルを一覧表示します。 |
| get_ai_model_endpoints | すべてのAIモデルエンドポイントを一覧表示します。 |

### AIメモリシステム

seekdb MCP Serverは強力なAIメモリ機能を提供し、AIアシスタントがセッション間で情報を記憶できるようにします：

| ツール | 機能 |
|------|------|
| seekdb_memory_query | セマンティック検索メモリ |
| seekdb_memory_insert | 新しいメモリの保存 |
| seekdb_memory_update | メモリの更新 |
| seekdb_memory_delete | メモリの削除 |

ユースケース：

* AIがあなたの技術スタックの好みを覚えておく（例：「私はPythonを使うのが好きです」）
* AIがプロジェクト情報を覚えておく（例：「このプロジェクトではFastAPIを使用しています」）
* AIが個人的な好みを覚えておく（例：「私はシンプルなコードスタイルが好きです」）

### データのインポートとエクスポート

| ツール | 機能 |
|------|------|
| import_csv_file_to_seekdb | CSVファイルをベクトルコレクションにインポートする |
| export_csv_file_from_seekdb | ベクトルコレクションからCSVにデータをエクスポートする |

### SQL操作

| ツール | 機能 |
|------|------|
| execute_sql | SQLクエリの実行 |
| get_current_time | データベースの現在時刻を取得する |

## インストールと設定

### seekdbデータベースのインストール

seekdb MCP Serverを使用する前に、まずseekdbを準備しておく必要があります。seekdbは2つのデプロイメントモードを提供しています。seekdbの詳細なデプロイについては、[seekdbのデプロイ](../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。

* 埋め込みモード(ゼロコンフィグ、Linux限定)

  埋め込みモードを選択した場合、seekdbを別途インストールする必要はありません。seekdb MCP Server起動時にローカルの埋め込みデータベースが自動的に初期化され、すぐに使用できます。

  適用シナリオ：個人学習、迅速なプロトタイプ開発、エッジデバイスの運用。

    :::tip

    現在の埋め込みモードのseekdbはLinuxシステムのみをサポートしています。macOSおよびWindowsを使用するユーザーはサーバーモードのseekdbを使用する必要があり、事前にseekdbをデプロイする必要があります(Docker方式の使用を推奨します)。

    :::

* サーバーモード(本番環境推奨)

    サーバーモードのseekdbデプロイに関する詳細は、[yum installによるseekdbのデプロイ](../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md)および[seekdbコンテナ環境のデプロイ](../../400.guides/400.deploy/700.server-mode/200.deploy-by-docker.md)を参照してください。

### seekdb MCP Serverのインストール

#### uvパッケージマネージャーのインストール

```shell
# uvパッケージマネージャーをインストール
curl -LsSf https://astral.sh/uv/install.sh | sh
```

#### AIツール接続の設定

##### Stdioモード

Cursorを例にすると、**設定** → **Tools & MCP** → **New MCP Server** を開き、オペレーティングシステムに応じて設定方法を選択します：

* Linuxユーザー（組み込みモード）

    ```shell
    {
      "mcpServers": {
        "seekdb": {
          "command": "uvx",
          "args": ["seekdb-mcp-server"]
        }
      }
    }
    ```

    サーバー起動時にローカルのseekdbデータベースが自動的に初期化されます。

* macOS / Windowsユーザー（サーバーモード）

    macOSとWindowsは組み込みモードをサポートしていないため、まずseekdbデータベースをデプロイする必要があります（Dockerの使用を推奨します）。その後、接続パラメータを設定します：

    ```shell
    {
      "mcpServers": {
        "seekdb": {
          "command": "uvx",
          "args": ["seekdb-mcp-server"],
          "env": {
            "SEEKDB_HOST": "127.0.0.1",
            "SEEKDB_PORT": "2881",
            "SEEKDB_USER": "root",
            "SEEKDB_PASSWORD": "",
            "SEEKDB_DATABASE": "test"
          }
        }
      }
    }
    ```

    パラメータ説明：

    | パラメータ | 説明 | デフォルト値 |
    | ----- | -- | ------- |
    | SEEKDB_HOST | seekdbサーバーのアドレス | 127.0.0.1 |
    | SEEKDB_PORT | seekdbサービスポート | 2881 |
    | SEEKDB_USER | データベースユーザー名 | root |
    | SEEKDB_PASSWORD | データベースパスワード | なし |
    | SEEKDB_DATABASE | データベース名 | test |

##### SSEモード

* Linuxユーザー（組み込みモード）

    SSEサーバーを直接起動します：

    ```shell
    uvx seekdb-mcp-server --transport sse --port 6000
    ```

* macOS / Windowsユーザー（サーバーモード）

    1. 環境変数を設定してからサーバーを起動します：

        ```shell
        # seekdb接続情報を設定
        export SEEKDB_HOST=127.0.0.1
        export SEEKDB_PORT=2881
        export SEEKDB_USER=root
        export SEEKDB_PASSWORD=
        export SEEKDB_DATABASE=test
        ```

    2. SSEサーバーを起動します。

        ```shell
        uvx seekdb-mcp-server --transport sse --port 6000
        ```

    3. クライアントで以下の情報を設定します。

        ```shell
        {
          "sse-seekdb": {
            "type": "sse",
            "url": "http://127.0.0.1:6000/sse"
          }
        }
        ```

## 適用シナリオ

seekdb MCP Serverは豊富な機能を提供しており、さまざまなシナリオに適しています。

### ナレッジベースの構築

ドキュメント、ノート、コードスニペットをベクトルコレクションに格納し、セマンティック検索で関連するコンテンツを迅速に見つけることができます。

```shell
"このReact Hooksに関する記事をナレッジベースに追加"
"以前保存した状態管理に関するノートを検索"
```

### RAGアプリケーションのプロトタイピング

複雑なバックエンドを構築することなく、RAG（検索拡張生成）アプリケーションのアイデアを迅速に検証できます。

```shell
"製品ドキュメントのコレクションを作成し、これらのドキュメントをインポート"
"これらのドキュメントに基づいてユーザーの質問に答える"
```

### データ分析

CSVデータをインポートし、自然言語で分析します。

```shell
"この販売データのCSVファイルをインポート"
"先月の販売傾向を分析"
```

### AIプログラミングアシスタントの拡張

AIプログラミングアシスタントに永続的な記憶を持たせます。

```shell
"覚えておいて：このプロジェクトではPostgreSQLをメインデータベースとして使用する"
"覚えておいて：私はJavaScriptよりもTypeScriptを好む"
```
