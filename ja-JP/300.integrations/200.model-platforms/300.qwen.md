# Qwenとの連携

[Qwen](https://tongyi.aliyun.com/)は、Alibaba Cloudが開発した大規模言語モデルであり、ユーザーの入力を理解・分析するために使用されます。Alibaba Cloudの[Model Experience Center](https://bailian.console.aliyun.com/?spm=a2c4g.11186623.0.0.41f9253anP7UgA#/efm/model_experience_center/text)でQwenモデルのAPIサービスを利用できます。

seekdbは、ベクトル型データの格納、ベクトルインデックス、そしてembeddingベクトル検索機能を提供します。QwenのAPIを利用して、ベクトル化したデータをseekdbに格納し、seekdbのベクトル検索機能を用いて関連するデータを検索することが可能です。

## 前提条件

* seekdbのデプロイが完了していること。
* 環境に使用可能なMySQLデータベースとアカウントが存在し、データベースアカウントに読み書き権限が付与されていること。
* [Python 3.9以降のバージョン](https://www.python.org/downloads/)および対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストール済みであること。
* [poetry](https://python-poetry.org/docs/)、[seekdb](https://github.com/oceanbase/seekdb)およびDashScope SDKをインストール済みであること。

    ```shell
    python3 -m pip install pyseekdb dashscope pandas cffi
    ```

* [Qwen APIキー](https://help.aliyun.com/zh/model-studio/developer-reference/get-api-key)を準備しておくこと。

## ステップ１：seekdb接続文字列を取得する

seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレス。
* `$port`：seekdbへの接続ポート。デフォルトは`2881`です。
* `$database_name`：アクセスするデータベース名。

    :::tip
        接続するユーザーは、データベースに対する<code>CREATE</code>、<code>INSERT</code>、<code>DROP</code>、および<code>SELECT</code>権限を持っている必要があります。
    :::

* `$user_name`：データベース接続アカウント。
* `$password`：アカウントのパスワード。

## ステップ2：OpenAI APIキーとseekdb接続情報を環境変数に設定する

Unixベースのシステム（UbuntuやMacOSなど）では、ターミナルで以下のコマンドを実行します：

```shell
export DASHSCOPE_API_KEY="YOUR_DASHSCOPE_API_KEY"

export SEEKDB_DATABASE_DB_NAME=YOUR_SEEKDB_DATABASE_DB_NAME
```

## ステップ3：ベクトルデータをseekdbに格納する

1. テストデータの準備
事前にベクトル化されたデータを含む[CSV](https://help-static-aliyun-doc.aliyuncs.com/file-manage-files/zh-CN/20240827/srxyhu/fine_food_reviews.csv)ファイルをダウンロードします。このCSVファイルには1000件のグルメレビューデータセットが含まれており、最終列は既にベクトル化された値であるため、再度ベクトルを計算する必要はありません。以下のコードを使用して、embedding列（つまりベクトル列）を再計算し、新しいCSVファイルを生成することもできます。

    ```shell
    import dashscope
    import pandas as pd
    from dashscope import TextEmbedding

    input_datapath = "./fine_food_reviews.csv"
    # ここではtext_embedding_v1埋め込みモデルを使用しています。必要に応じて調整可能です。
    def generate_embeddings(text):
        rsp = dashscope.TextEmbedding.call(model=TextEmbedding.models.text_embedding_v1, input=text)
        embeddings = [record['embedding'] for record in rsp.output['embeddings']]
        return embeddings if isinstance(text, list) else embeddings[0]

    df = pd.read_csv(input_datapath, index_col=0)
    # 実際の生成には数分かかります。DQAI Embedding APIを行ごとに呼び出します。
    df["embedding"] = df.combined.apply(generate_embeddings)
    output_datapath = './fine_food_reviews_self_embeddings.csv'
    df.to_csv(output_datapath)
    ```

2. 以下のスクリプトを実行して、テストデータをseekdbに挿入します。スクリプトがあるディレクトリは、テストデータがあるディレクトリと同じである必要があります。

    ```shell
    import os,csv,json
    import pyseekdb
    from pyseekdb import HNSWConfiguration

    ids = []
    embeddings = []
    documents = []
    metadatas = []
    file_name = "fine_food_reviews_self_embeddings.csv"
    file_path = os.path.join("./", file_name)
    # CSVファイルを開いて読み込みます。
    with open(file_name, mode='r', newline='', encoding='utf-8') as csvfile:
        csvreader = csv.reader(csvfile)
        headers = next(csvreader)
        print("Headers:", headers)
        for i, row in enumerate(csvreader):
            if not row or len(row) < 9:
                print(f"行 {i+2} をスキップ：データが不完全")
                continue

            ids.append(row[0])
            embeddings.append(json.loads(row[8]))
            documents.append(row[6])
            metadata = {
                "product_id": str(row[1]),
                "user_id": str(row[2]),
                "score": str(row[3]),
                "summary": str(row[4]),
                "n_tokens": str(row[7])
            }
            metadatas.append(metadata)

    # pyseekdbを使用してseekdbに接続します。
    client = pyseekdb.Client(
        host=os.getenv('SEEKDB_DATABASE_HOST'),
        port=int(os.getenv('SEEKDB_DATABASE_PORT', 2881)),
        database=os.getenv('SEEKDB_DATABASE_DB_NAME'),
        user=os.getenv('SEEKDB_DATABASE_USER'),
        password=os.getenv('SEEKDB_DATABASE_PASSWORD')
    )

    table_name = 'fine_food_reviews'
    config = HNSWConfiguration(dimension=1536, distance='cosine')
    collection = client.create_collection(
        name=table_name,
        configuration=config,
        embedding_function=None
    )

    # 毎回10行を挿入します。
    batch_size = 100
    total_records = len(ids)

    for i in range(0, total_records, batch_size):
        end_idx = min(i + batch_size, total_records)
        batch_ids = ids[i:end_idx]
        batch_embeddings = embeddings[i:end_idx]
        batch_documents = documents[i:end_idx]
        batch_metadatas = metadatas[i:end_idx]

        try:
            collection.add(
                ids=batch_ids,
                embeddings=batch_embeddings,
                documents=batch_documents,
                metadatas=batch_metadatas
            )
            print(f"Batch {i//batch_size + 1} が正常に挿入されました!")
        except Exception as e:
            print(f"Batch {i//batch_size + 1} の挿入に失敗しました: {e}")
            break

    print("すべてのデータ挿入が完了しました!")
    ```

## ステップ4：seekdbデータをクエリする

1. 以下のPythonスクリプトを`query.py`という名前で保存します。

    ```shell
    import os,csv,json,sys
    import pyseekdb
    import dashscope
    from pyseekdb import HNSWConfiguration
    from dashscope import TextEmbedding

    # Obtain command-line options.
    if len(sys.argv) != 2:
        print("Enter a query statement." )
        sys.exit()
    queryStatement = sys.argv[1]

    # Connect to seekdb by using pyseekdb
    client = pyseekdb.Client(
        host=os.getenv('SEEKDB_DATABASE_HOST'),
        port=int(os.getenv('SEEKDB_DATABASE_PORT', 2881)),
        database=os.getenv('SEEKDB_DATABASE_DB_NAME'),
        user=os.getenv('SEEKDB_DATABASE_USER'),
        password=os.getenv('SEEKDB_DATABASE_PASSWORD')
    )

    # Define the function for generating text vectors.
    def generate_embeddings(text):
        rsp = dashscope.TextEmbedding.call(model=TextEmbedding.Models.text_embedding_v1, input=text)
        embeddings = [record['embedding'] for record in rsp.output['embeddings']]
        return embeddings if isinstance(text, list) else embeddings[0]

    def query_ob(query, tableName, top_k=1):
        query_embedding = generate_embeddings(query)
        collection = client.get_collection(name=tableName)
        res = collection.query(
            query_embeddings=query_embedding,
            n_results=top_k
        )
        print('- The Most Relevant Document and Its Distance to the Query:')
        for i, (doc_id, document, distance) in enumerate(zip(
            res['ids'][0],
            res['documents'][0],
            res['distances'][0]
        )):
            print(f'  - ID: {doc_id}')
            print(f'    content: {document}')
            print(f'    distance: {distance:.6f}')

    # Specify the table name.
    table_name = 'fine_food_reviews'
    query_ob(queryStatement,table_name,1)
    ```

2. 質問を入力し、関連する回答を出力します。

    ```shell
    python3 query.py 'pet food'
    ```

    期待される結果は次のとおりです：

    ```shell
    - The Most Relevant Document and Its Distance to the Query:
      - ID: 444
        content: Title: Healthy Dog Food; Content: This is a very healthy dog food. Good for their digestion. Also good for small puppies. My dog eats her required amount at every feeding.
        distance: 0.509108
    ```
