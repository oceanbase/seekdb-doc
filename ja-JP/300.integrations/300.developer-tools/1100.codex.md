# Codexとの連携

[Codex](https://developers.openai.com/codex/cli)は、OpenAIが開発したRustで構築されたオープンソースのAIプログラミングエージェントで、ターミナルで実行できます。コードを読み取り、変更し、実行することができ、開発者がアイデアを高品質なコードに素早く変換するのを支援します。CodexはCLI、IDE拡張機能、およびCodex Appの3つの利用方法をサポートしています。

本記事では、Codex上でseekdb Agent Skillを利用して、AIが自動的に呼び出せるナレッジパッケージ＋ワークフローを迅速に構築する方法、およびseekdb MCP Serverを利用してバックエンドアプリケーションを迅速に構築する方法について説明します。

    [Agent Skills](https://agentskills.io/home)は、Anthropicが主導して設計し、現在ではオープンスタンダードとして公開されているAIスキル拡張形式です。そのコアコンセプトは、指示、スクリプト、リソースを1つのフォルダにパッケージ化し、AI Agentが必要に応じてこれらの「スキル」を検出してロードすることで、より正確かつ効率的にタスクを完了できるようにすることです。

    seekdb Agent Skillsは、このスタンダードに基づいて構築された「AIが自動的に呼び出せるナレッジパッケージ＋ワークフロー」です。Codexにインストール後、seekdbに関する質問をすると、Codexはスキルの説明に従ってseekdbのドキュメントを参照したり、データのインポート・エクスポートなどの操作を自動的に実行します。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要がなく、コーディング中にseekdbの公式ドキュメントサポートと実践的な機能を利用できます。Agent Skillの詳細については、[seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)を参照してください。

    ## サポートされているスキル

    | スキル | 説明 | 典型的な質問例 |
    | --- | --- | --- |
    | **seekdb**（デフォルトインストール） | seekdbの公式ドキュメント（クイックスタート、開発ガイド、SDK/API、マルチモデルデータ、統合と運用など）をカバーしています。AIがあなたの質問に基づいて対応するドキュメントを自動的に特定し、答えや例を提供します。 | seekdbはどのようにデプロイしますか？ / seekdbのベクトル検索の使い方は？ |
    | **importing-to-seekdb** | データをseekdbのコレクション（Collection）にインポートし、指定した列のベクトル化をサポートします。インポート前にExcel/CSVの構造とサンプルデータをプレビューできます。 | sample_products.xlsxをseekdbにインポートし、Details列をベクトル化します。 |
    | **querying-from-seekdb** | メタデータ条件によるフィルタリングでスカラー検索を行い、全文検索と意味検索のハイブリッド検索（RRFソート）をサポートします。結果はCSVまたはExcel形式でエクスポートできます。 | 4.3以上の評価を受けた、AMOLED画面のスマートフォンを2機種推薦します。 |

    ## Codexへのseekdb Agent Skillsのインストール

    Codexは、プロジェクトのルートディレクトリ配下にある`.agents/skills`ディレクトリを認識し、Agent Skillを読み込みます。以下の手順でインストールを完了してください：

    1. スキルをインストールしたいプロジェクトのルートディレクトリに移動します。

        ```shell
        cd /path/to/your/project
        ```

    2. インタラクティブインストーラーをインストールします。

        ```shell
        pip install seekdb-agent-skills
        ```

    3. インタラクティブインストーラーを実行します。

        ```shell
        seekdb-agent-skills
        ```

    4. ツールを選択します。

        キーボードの**↑↓**キーで**Codex**を選択し、**Enter**キーで確定します。

        ```shell
        🚀 seekdb Agent Skills Installer
        ==================================================

        📋 Select tool to install to:
        ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
          Claude Code
          OpenClaw
          Cursor
        » Codex
          OpenCode
          GitHub Copilot
          Qoder
          Trae
        ```

    5. インストール先を確認します。

        ```shell
        📁 Project root: /path/to/your/project
        (Skills will be installed under .agents/skills)
        ? Install skills to this directory? (Y/n)
        ```

        `Y`と入力して確認し、`n`と入力してインストーラーを終了します。

    6. インストールするスキルを選択します。

        AIがseekdbのドキュメントを参照するだけであれば、そのままEnterキーを押すだけで済みます。Excel/CSVファイルをseekdbにインポートまたはエクスポートする必要がある場合は、**importing-to-seekdb**と**querying-from-seekdb**の両方のスキルを選択できます。キーボードの**↑↓**キーでスキルを選択し、**Space**キーで複数選択し、**Enter**キーでインストールを確定します。

        ```shell
        📦 Select skills to install:
        ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
        » ● seekdb
          ○ importing-to-seekdb
          ○ querying-from-seekdb
        ```

    ## Codexでのseekdb Agent Skillsの使用

    インストール完了後、スキルをインストールしたプロジェクトのルートディレクトリでCodexを開き、直接質問するだけで済みます。AIは対応するスキルを自動的に呼び出し、ドキュメントやスキルの能力に基づいて回答します。

    質問例：

    * Macでseekdbをデプロイするにはどうすればよいですか？
    * seekdbのベクトル検索の使い方を教えてください。
    * seekdbでハイブリッド検索を実装するにはどうすればよいですか？

    [MCP（Model Context Protocol）](https://modelcontextprotocol.io/docs/getting-started/intro)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルで、大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

    [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにするサーバーです。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

    ## 前提条件

    * seekdbのデプロイが完了していること。

    * [Python 3.11以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以上の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    * Pythonパッケージマネージャuvをインストールしていること。公式の独立インストーラの使用を推奨します。インストール完了後、`uv --version`で検証できます：

      * macOSおよびLinux (curlを使用)：

            ```shell
            curl -LsSf https://astral.sh/uv/install.sh | sh
            ```

            curlがない場合は、wgetを使用できます：

            ```shell
            wget -qO- https://astral.sh/uv/install.sh | sh
            uv --version
            ```

      * Windows (PowerShellを使用)：

            ```shell
            powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
            uv --version
            ```

        その他のインストール方法（Homebrew、pipx、pipなど）については、[uv公式インストールドキュメント](https://docs.astral.sh/uv/getting-started/installation/)を参照してください。

    * Codex CLIのインストール：

      1. Node.js 18以上とGitがインストールされていることを確認してください。
      2. 以下のコマンドを実行してCodex CLIをインストールします：

            ```shell
            npm install -g @openai/codex
            ```

      3. OpenAI APIキーを設定します：

            ```shell
            export OPENAI_API_KEY=YOUR_API_KEY
            ```

      4. `codex`コマンドを実行して、インストールが成功したかどうかを確認します。

    ## ステップ1：データベース接続情報を取得する

    seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

    ```sql
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

    **パラメータの説明：**

    * `$host`：seekdbへの接続IPアドレスを指定します。
    * `$port`：seekdbへの接続ポートを指定します。デフォルトは`2881`です。
    * `$database_name`：アクセスするデータベース名を指定します。

        :::tip
        接続するユーザーには、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限が付与されていなければなりません。
        :::

    * `$user_name`：データベース接続アカウントを指定します。
    * `$password`：アカウントのパスワードを指定します。

    ## ステップ2：seekdb MCP Serverを設定する

    ### seekdb MCP Serverのインストール

    以下のコマンドを実行してインストールします。

    ```shell
    pip install seekdb-mcp-server
    ```

    ### seekdbサーバーの環境変数を.envファイルに設定する

    現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します。

    ```shell
    SEEKDB_HOST=localhost
    SEEKDB_PORT=2881
    SEEKDB_USER=your_username
    SEEKDB_PASSWORD=your_password
    SEEKDB_DATABASE=your_database
    ```

    ### Streamable-HTTPモードで起動する

    ```shell
    env $(cat .env | xargs) uvx seekdb-mcp-server --transport streamable-http --port 8000 --host 127.0.0.1
    ```

    ### Codexにseekdb MCP Serverを追加する

    Codexは`config.toml`ファイルを通じてMCP Serverの設定を管理します。以下のいずれかの方法で設定を行うことができます：

    #### 方法1：CLIコマンドを使用して追加する

    ターミナルで以下のコマンドを実行し、seekdb MCP ServerをCodexに追加します：

    ```shell
    codex mcp add streamable-http-seekdb --url http://ip:port/mcp
    ```

    `ip`と`port`をseekdb MCP Serverが実際に稼働しているアドレスとポートに置き換えてください（例：http://127.0.0.1:8000/mcp）。

    #### 方法2：設定ファイルを手動で編集する

    `~/.codex/config.toml`（グローバル設定）またはプロジェクトルートディレクトリ配下の`.codex/config.toml`（プロジェクトレベル設定）を編集し、以下の内容を追加します。

    ```shell
    [mcp_servers.streamable-http-seekdb]
    url = "http://ip:port/mcp"
    startup_timeout_sec = 30
    tool_timeout_sec = 60
    enabled = true
    ```

    `ip`と`port`をseekdb MCP Serverが実際に稼働しているアドレスとポートに置き換えてください。

    ### MCP Server接続の検証

    プロジェクトディレクトリでCodexを起動します：

    ```shell
    codex
    ```

    CodexのTUI内で、`/mcp`コマンドを使用して設定済みのMCP Serverの状態を確認できます。

    `How many tables in the test database?`と入力すると、Codexは実行予定のSQL文を表示し、クエリ結果を出力します。Codexが現在のtestデータベース内のテーブル数を正しく表示していれば、seekdbへの接続が正常であることを意味します。

    ## ステップ3：FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

    FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

    1. customerテーブルを作成する

        ダイアログボックスに次のプロンプトを入力します：`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`。

        <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/codex/2.png) -->

    2. テストデータを挿入する

        ダイアログボックスに次のプロンプトを入力します：`Insert 10 pieces of data into the customer table`。

        <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/codex/3.png) -->

    3. FastAPIプロジェクトを作成する

        ダイアログボックスに次のプロンプトを入力します：`Create a FastAPI project on the customer table`。これにより、複数のファイルが自動生成されます。問題がある場合は、後から修正できます。

        <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/codex/4.png) -->

        このステップでは、複数のファイルが自動生成されます。AIが生成するファイルの内容は不確定な場合があるため、後から実際のニーズに合わせて調整できます。

    4. FastAPIプロジェクトのデータベース接続情報を設定する

        Codexが生成したプロジェクトのデータベース接続情報を確認します。誤っている場合は、設定を変更する必要があります。

        <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/codex/5.png) -->

    5. プロジェクトの依存関係をインストールする

        以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

        ```shell
        pip install -r requirements.txt
        ```

    6. FastAPIプロジェクトを起動する

        以下のコマンドを実行して、FastAPIプロジェクトを起動します：

        ```shell
        source .env
        uvicorn app.main:app --reload --host 127.0.0.1 --port 3000
        ```

    7. テーブル内のデータを確認する

        コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

        ```shell
        curl http://127.0.0.1:3000/customers
        ```
