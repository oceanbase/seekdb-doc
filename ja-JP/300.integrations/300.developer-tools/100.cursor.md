# Cursorとの連携

[Cursor](https://cursordocs.com)は、AI技術を統合したコードエディタであり、Windows、macOS、Linuxなど、さまざまなOSに対応しています。

本記事では、Cursorとseekdb Agent Skillを連携させる方法を紹介します。これにより、AIが自動的に呼び出せるナレッジパッケージとワークフローを迅速に構築できます。また、Cursorとseekdb MCP Serverを連携させて、バックエンドアプリケーションを迅速に構築する方法も紹介します。

    [Agent Skills](https://agentskills.io/home)は、Anthropicが主導して設計し、現在ではオープンスタンダードとして公開されているAI能力拡張フォーマットです。そのコアコンセプトは、指示、スクリプト、リソースを1つのフォルダにパッケージ化し、AI Agentが必要に応じてこれらの「スキル」を検出してロードすることで、より正確かつ効率的にタスクを完了できるようにすることです。

    seekdb Agent Skillsは、このスタンダードに基づいて構築された、「AIが自動的に呼び出せるナレッジパッケージとワークフロー」です。Cursorにインストール後、seekdbに関する質問をすると、CursorのAIが自動的にスキルの説明に従ってseekdbのドキュメントを参照したり、データのインポートやエクスポートなどの操作を実行したりします。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要がなく、コーディング中にseekdbの公式ドキュメントサポートと実践的な機能を利用できます。Agent Skillの詳細については、[seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)を参照してください。

    ## 対応スキル

    | スキル | 説明 | 典型的な質問例 |
    | --- | --- | --- |
    | **seekdb**（デフォルトインストール） | seekdbの公式ドキュメント（クイックスタート、開発ガイド、SDK/API、マルチモデルデータ、統合と運用保守など）をカバーしています。AIがユーザーの質問に基づいて対応するドキュメントを自動的に特定し、答えや例を提示します。 | seekdbのデプロイ方法は？ / seekdbのベクトル検索の使い方は？ |
    | **importing-to-seekdb** | データをseekdbのコレクション（Collection）にインポートし、指定された列のベクトル化をサポートします。インポート前にExcel/CSVの構造とサンプルデータをプレビューできます。 | sample_products.xlsxをseekdbにインポートし、Details列をベクトル化します。 |
    | **querying-from-seekdb** | メタデータ条件によるフィルタリングでスカラー検索を実行し、全文検索と意味検索のハイブリッド検索（RRFソート）をサポートします。結果はCSVまたはExcel形式でエクスポート可能です。 | スコア4.3以上のAMOLED画面のスマートフォンを2機種推薦します。 |

    ## Cursorへのseekdb Agent Skillsのインストール

    Cursorは、プロジェクトのルートディレクトリ配下にある`.cursor/skills`ディレクトリを認識し、Agent Skillを読み込みます。以下の手順でインストールを完了してください：

    1. スキルをインストールしたいプロジェクトのルートディレクトリに移動します。

        ```shell
        cd /path/to/your/project
        ```

    2. インタラクティブインストーラーをインストールします。

        ```shell
        pip install seekdb-agent-skills
        ```

    3. インタラクティブインストーラーを実行します。

        ```shell
        seekdb-agent-skills
        ```

    4. ツールを選択します。

        キーボードの**↑↓**キーで**Cursor**を選択し、**Enter**キーで確定します。

        ```shell
        🚀 seekdb Agent Skills Installer
        ==================================================

        📋 Select tool to install to:
        ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
          Claude Code
          OpenClaw
        » Cursor
          Codex
          OpenCode
          GitHub Copilot
          Qoder
          Trae
        ```

    5. インストール先を確認します。

        ```shell
        📁 Project root: /path/to/your/project
        (Skills will be installed under .cursor/skills)
        ? Install skills to this directory? (Y/n)
        ```

        `Y`と入力して確認し、`n`と入力してインストーラーを終了します。

    6. インストールするスキルを選択します。

        AIがseekdbのドキュメントを参照するだけであれば、そのままEnterキーを押すだけで済みます。Excel/CSVファイルをseekdbにインポートまたはエクスポートする必要がある場合は、**importing-to-seekdb**と**querying-from-seekdb**の両方のスキルを選択できます。キーボードの**↑↓**キーでスキルを選択し、**Space**キーで複数選択し、**Enter**キーでインストールを確定します。

        ```shell
        📦 Select skills to install:
        ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
        » ● seekdb
          ○ importing-to-seekdb
          ○ querying-from-seekdb
        ```

    ## Cursorでのseekdb Agent Skillsの使用

    インストール完了後、Cursorを使用してスキルがインストールされたプロジェクトのルートディレクトリを開き、チャットまたはエディターで直接質問するだけです。AIが対応するスキルを自動的に呼び出し、ドキュメントやスキルの能力に基づいて回答します。

    質問例：

    * Macでseekdbをデプロイするにはどうすればよいですか？
    * seekdbのベクトル検索の使い方を教えてください。
    * seekdbでハイブリッド検索を実装するにはどうすればよいですか？

    [MCP（Model Context Protocol）](https://modelcontextprotocol.io/introduction)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルです。大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

    [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにするサーバーです。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

    ## 前提条件

    * seekdbのデプロイが完了していること。

    * [Python 3.11以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以上の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    * Pythonパッケージマネージャuvをインストールしていること。インストール完了後、`uv --version`コマンドを実行してインストールが成功したか確認できます：

        ```shell
        pip install uv
        uv --version
        ```

    * [Cursor](https://cursor.com/cn/downloads)をダウンロードし、ご自身のOSに合ったバージョンを選択してインストールしてください。初めてCursorを使用する際は、新規アカウントを登録するか、既存のアカウントでログインする必要があります。ログイン後、新規プロジェクトを作成するか、既存のプロジェクトを開くことができます。

    ## ステップ１：データベース接続情報を取得する

    seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

    ```sql
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

    **パラメータ説明：**

    * `$host`：seekdbへの接続IPアドレスを指定します。
    * `$port`：seekdbへの接続ポートを指定します。デフォルトは`2881`です。
    * `$database_name`：アクセスするデータベース名を指定します。

        :::tip
        接続するユーザーは、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限を持っている必要があります。
        :::

    * `$user_name`：データベース接続アカウントを指定します。
    * `$password`：アカウントのパスワードを指定します。

    ## ステップ2：seekdb MCP Serverを設定する

    ### seekdb MCP Serverのインストール

    以下のコマンドを実行してインストールします。

    ```shell
    pip install seekdb-mcp-server
    ```

    ### seekdbサーバーの環境変数を.envファイルに設定する

    現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します。

    ```shell
    vi .env

    SEEKDB_HOST=localhost      # データベースホスト
    SEEKDB_PORT=2881           # データベースポート（デフォルト：2881）
    SEEKDB_USER=your_username
    SEEKDB_PASSWORD=your_password
    SEEKDB_DATABASE=your_database
    ```

    ### SSEモードでseekdb MCP Serverを起動する

    ```shell
    env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 0.0.0.0
    ```

    ### Cursorクライアントの作業ディレクトリを作成し、seekdb MCP Serverを設定する

    手動でCursorの作業ディレクトリを作成し、Cursorで開きます。今後Cursorが生成するファイルは、このディレクトリに配置されます。例として、ディレクトリ名を`cursor`とします。

    ショートカットキー`Ctrl + L`(Windows)または`Command + L`(MacOS)を使用してチャットダイアログを開き、右上の歯車アイコンをクリックして`MCP Tools`を選択します。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/1.png)

    #### MCP Serverの追加と設定

    1. `Add Custom MCP`をクリックして設定ファイルを記入します。

        ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/2.png)

    2. 設定ファイルに記入し、確認をクリックします。

        ```json
        {
        "mcpServers": {
            "sse-seekdb": {
            "autoApprove": [],
            "disabled": false,
            "timeout": 60,
            "type": "sse",
            "url": "http://ip:port/sse"
            }
        }
        }
        ```

    3. 設定が成功すると、`使用可能`状態が表示されます。

        ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/3.png)

    #### MCP Serverのテスト

    ダイアログにプロンプト`How many tables in the test database?`と入力します。Cursorクライアントは、実行予定のSQL文を表示します。確認後、`Run tool`ボタンをクリックして実行します。Cursorクライアントは`test`データベース内のすべてのテーブル名を表示します。これにより、seekdbへの接続に成功したことが確認できます。

    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/4.png)

    ### FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

    FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

    1. customerテーブルを作成する

        ダイアログにプロンプト`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`と入力します。SQL文を確認した後、`Run tool`ボタンをクリックして実行します。

        ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/5.png)

    2. テストデータを挿入する

        ダイアログにプロンプト`Insert 10 pieces of data into the customer table`と入力します。SQL文を確認した後、`Run tool`ボタンをクリックして実行します。挿入が成功すると、`Done! Here are the 10 customer records inserted:`というプロンプトが表示されます。

        ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/6.png)

    3. FastAPIプロジェクトを作成する

        ダイアログにプロンプト`Create a FastAPI project on the customer table`と入力し、`Run tool`ボタンをクリックして実行します。

        ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/7.png)

        このステップでは、複数のファイルが自動生成されます。AIが生成するファイルの内容は不確定な場合があるため、初回使用時は`すべて受け入れる`を選択し、後から実際のニーズに合わせて調整することを推奨します。

    4. FastAPIプロジェクトのデータベース接続情報を設定する

        .envファイル内にseekdb接続情報を設定します。

        ![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cursor/8.png)

    5. プロジェクトの依存関係をインストールする

        以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

        ```shell
        pip install -r requirements.txt
        ```

    6. FastAPIプロジェクトを起動する

        以下のコマンドを実行して、FastAPIプロジェクトを起動します：

        ```shell
        source .env
        uvicorn main:app --reload
        ```

    7. テーブル内のデータを確認する

        コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

        ```shell
        curl http://127.0.0.1:8000/customers
        ```

        実行結果は次のとおりです：
