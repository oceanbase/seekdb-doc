# Continueとの連携

[MCP（Model Context Protocol）](https://modelcontextprotocol.io/introduction)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルです。大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

[MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにします。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

[Continue](https://continue.dev)は、MCP Serverと連携可能なIDEプラグインで、Visual Studio CodeおよびIntelliJ IDEAをサポートしています。

本記事では、Continueとseekdb MCP Serverを連携させて、バックエンドアプリケーションを迅速に構築する方法を紹介します。

## 前提条件

* seekdbのデプロイが完了していること。

* [Python 3.11以降のバージョン](https://www.python.org/downloads/)および対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。マシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以降の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

* Pythonパッケージマネージャーuvをインストールしていること。インストール完了後、`uv --version`コマンドを実行してインストールが成功したかどうか確認できます。

    ```shell
    pip install uv
    uv --version
    ```

* Visual Studio CodeまたはIntelliJ IDEAに、`Continue`という名前のContinueプラグインをインストールしていること。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/1.png)

## ステップ１：データベース接続情報を取得する

seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレスを指定します。
* `$port`：seekdbへの接続ポートを指定します。デフォルトは`2881`です。
* `$database_name`：アクセスするデータベース名を指定します。

    :::tip
    接続するユーザーには、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限が付与されていなければなりません。
    :::

* `$user_name`：データベース接続アカウントを指定します。
* `$password`：アカウントのパスワードを指定します。

## ステップ2：seekdb MCP Serverの設定

ここではVisual Studio Codeを例に、seekdb MCP Serverの設定方法を説明します。

### seekdb MCP Serverのインストール

以下のコマンドを実行してインストールします：

```shell
pip install seekdb-mcp-server
```

### seekdbサーバーの環境変数を.envファイルに設定する

現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します：

```shell
vi .env

SEEKDB_HOST=localhost      # データベースホスト
SEEKDB_PORT=2881           # データベースポート（デフォルト：2881）
SEEKDB_USER=your_username
SEEKDB_PASSWORD=your_password
SEEKDB_DATABASE=your_database
```

### SSEモードで起動

```shell
env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 0.0.0.0
```

### Continueプラグインで大規模言語モデルとseekdb MCP Serverを設定する

ローカルにVisual Studio Codeの作業ディレクトリを手動で作成し、Visual Studio Codeで開きます。今後、Continueが生成するファイルはこのディレクトリに配置されます。例として、ディレクトリ名を`Continue`とします。

#### 大規模言語モデルの設定

サイドバーの`Continueアイコン`をクリックして`Continue`ダイアログを開き、設定をクリックして`Add Models`に入り、Continueのために大規模言語モデルを設定します：

![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/2.png)

`config.yaml`での大規模言語モデル設定例は以下のとおりです：

```shell
name: Local Config
version: 1.0.0
schema: v1
models:
  - name: Qwen Plus
    provider: openai
    model: qwen-plus
    apiKey: ***********
    apiBase: "https://dashscope.aliyuncs.com/compatible-mode/v1"
```

#### seekdb MCP Serverの設定

MCPはContinueのAgentモードとPlanモードでのみ使用できます。

！[3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/3.png)

`config.yaml`でのseekdb MCPServer設定例は以下のとおりです：

```shell
mcpServers:
  - name: sse-seekdb
    type: sse
    url: "http://ip:port/sse"
    timeout: 60
    autoApprove: []
    disabled: false
```

#### MCP Serverのテスト

以下のようにContinueのセッションボックスを開き、プロンプト`How many tables in the test database?`に入力します。Continueは実行予定のSQL文を表示します。問題がなければ`Accept`をクリックします。Continueが現在のtestデータベース内のテーブル名を表示すれば、seekdbへの接続は正常であることを意味します。

![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/4.png)

### FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

1. customerテーブルを作成する

    ダイアログボックスに次のプロンプトを入力します：`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`。SQL文を確認した後、`Accept`ボタンをクリックして実行します。

    ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/5.png)

2. テストデータを挿入する

    ダイアログボックスに次のプロンプトを入力します：`Insert 10 pieces of data into the customer table`。SQL文を確認した後、Acceptボタンをクリックして実行します：

    ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/6.png)

3. FastAPIプロジェクトを作成する

    ダイアログボックスに次のプロンプトを入力します：`Create a FastAPI project on the customer table`。Acceptボタンをクリックして実行します。

    ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/7.png)

    この手順では複数のファイルが自動生成されます。AIが生成するファイルの内容は不確定な場合があるため、初回使用時は`すべて受け入れる`を選択し、後から実際のニーズに合わせて調整することをお勧めします。

4. FastAPIプロジェクトのデータベース接続情報を設定する

    ![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/continue/8.png)

5. プロジェクトの依存関係をインストールする

    以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

    ```shell
    pip install -r requirements.txt
    ```

6. FastAPIプロジェクトを起動する

    以下のコマンドを実行して、FastAPIプロジェクトを起動します：

    ```shell
    source .env
    uvicorn main:app --reload
    ```

7. テーブル内のデータを確認する

    コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

    ```shell
    curl http://127.0.0.1:8000/customers
    ```
