# Claude Codeとの連携

[Claude Code](https://docs.claude.com/en/home)は、Anthropic社が提供するAIプログラミングツールです。ターミナル上で動作するインテリジェントなコーディングアシスタントであり、開発者がアイデアを高品質なコードに素早く変換するのを支援します。

本記事ではClaude Codeを使用し、seekdb Agent Skillを通じてAIが自動的に呼び出せるナレッジパッケージ＋ワークフローを迅速に構築する方法、およびseekdb MCP Serverを使用してバックエンドアプリケーションを迅速に構築する方法を紹介します。

   [Agent Skills](https://agentskills.io/home)は、Anthropicが主導して設計し、現在オープンスタンダードとして公開されているAI能力拡張フォーマットです。その核となる考え方は、指示、スクリプト、リソースを1つのフォルダにパッケージ化し、AI Agentが必要に応じてこれらの「スキル」を検出・ロードすることで、より正確かつ効率的にタスクを完了できるようにすることです。

   seekdb Agent Skillsは、このスタンダードに基づいて構築された「AIが自動的に呼び出せるナレッジパッケージ＋ワークフロー」です。Claude Codeにインストール後、seekdbに関する質問をすると、Claude Codeはスキルの説明に従ってseekdbのドキュメントを参照したり、データのインポート・エクスポートなどの操作を自動的に実行します。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要がなく、コーディング中にseekdbの公式ドキュメントサポートと実践的な機能を利用できます。Agent Skillの詳細については、[seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)を参照してください。

   ## 対応スキル

   | スキル | 説明 | 典型的な質問例 |
   | --- | --- | --- |
   | **seekdb**（デフォルトインストール） | seekdbの公式ドキュメント（クイックスタート、開発ガイド、SDK/API、マルチモデルデータ、統合と運用など）をカバーしています。AIがあなたの質問に基づいて対応するドキュメントを自動的に特定し、答えや例を提供します。 | seekdbはどのようにデプロイしますか？ / seekdbのベクトル検索の使い方は？ |
   | **importing-to-seekdb** | データをseekdbのコレクション（Collection）にインポートし、指定した列のベクトル化をサポートします。インポート前にExcel/CSVの構造とサンプルデータをプレビューできます。 | sample_products.xlsxをseekdbにインポートし、Details列をベクトル化します。 |
   | **querying-from-seekdb** | メタデータ条件によるフィルタリングでスカラー検索を行い、全文検索と意味検索のハイブリッド検索（RRFソート）をサポートします。結果はCSVまたはExcel形式でエクスポートできます。 | 4.3以上の評価を受けた、AMOLED画面のスマートフォンを2機種推薦します。 |

   ## Claude Codeへのseekdb Agent Skillsのインストール

   Claude Codeは、プロジェクトのルートディレクトリ配下にある`.claude/skills`ディレクトリを認識し、Agent Skillを読み込みます。以下の手順でインストールを完了してください：

   1. スキルをインストールしたいプロジェクトのルートディレクトリに移動します。

      ```shell
      cd /path/to/your/project
      ```

   2. インタラクティブインストーラーをインストールします。

      ```shell
      pip install seekdb-agent-skills
      ```

   3. インタラクティブインストーラーを起動します。

      ```shell
      seekdb-agent-skills
      ```

   4. ツールを選択します。

      キーボードの**↑↓**キーで**Claude Code**を選択し、**Enter**キーで確定します。

      ```shell
      🚀 seekdb Agent Skills Installer
      ==================================================

      📋 Select tool to install to:
      ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
      » Claude Code
        OpenClaw
        Cursor
        Codex
        OpenCode
        GitHub Copilot
        Qoder
        Trae
      ```

   5. インストール先を確認します。

      ```shell
      📁 Project root: /path/to/your/project
      (Skills will be installed under .claude/skills)
      ? Install skills to this directory? (Y/n)
      ```

      `Y`と入力して確認し、`n`と入力してインストーラーを終了します。

   6. インストールするスキルを選択します。

      AIがseekdbのドキュメントを参照するだけであれば、そのままEnterキーを押すだけで済みます。Excel/CSVファイルをseekdbにインポートまたはエクスポートする必要がある場合は、**importing-to-seekdb**と**querying-from-seekdb**の両方のスキルを選択できます。キーボードの**↑↓**キーでスキルを選択し、**Space**キーで複数選択し、**Enter**キーでインストールを確定します。

      ```shell
      📦 Select skills to install:
      ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
      » ● seekdb
        ○ importing-to-seekdb
        ○ querying-from-seekdb
      ```

   ## Claude Codeでのseekdb Agent Skillsの使用

   インストール完了後、スキルをインストールしたプロジェクトのルートディレクトリでClaude Codeを開き、直接質問するだけで使用できます。AIは対応するスキルを自動的に呼び出し、ドキュメントやスキルの能力に基づいて回答します。

   質問例：

   * Macでseekdbをデプロイするにはどうすればよいですか？
   * seekdbのベクトル検索の使い方を教えてください。
   * seekdbでハイブリッド検索を実装するにはどうすればよいですか？

   [MCP（Model Context Protocol）](https://modelcontextprotocol.io/introduction)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルです。大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

   [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにするサーバーです。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

   ## 前提条件

   * seekdbのデプロイが完了していること。

   * [Python 3.11以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)のインストールが完了していること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以上の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

   * Pythonパッケージマネージャuvのインストールが完了していること。インストール後、`uv --version`コマンドを実行してインストールが成功したか確認できます：

      ```shell
      pip install uv
      uv --version
      ```

   * Claude Codeのインストール：

   ## ステップ１：データベース接続情報を取得する

   seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

   ```sql
   mysql -h$host -P$port -u$user_name -p$password -D$database_name
   ```

   **パラメータ説明：**

   * `$host`：seekdbの接続IPアドレスを指定します。
   * `$port`：seekdbの接続ポートを指定します。デフォルトは2881です。
   * `$database_name`：アクセスするデータベース名を指定します。

      :::tip

      接続するユーザーは、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限を持っている必要があります。

      :::

   * `$user_name`：データベース接続アカウントを指定します。
   * `$password`：アカウントのパスワードを指定します。

   ## ステップ2：seekdb MCP Serverを設定する

   ここではVisual Studio Codeを例に、seekdb MCP Serverの設定方法を説明します。

   ### seekdb MCP Serverのインストール

   以下のコマンドを実行してインストールします：

   ```shell
   pip install seekdb-mcp-server
   ```

   ### seekdbサーバーの環境変数を.envファイルに設定する

   現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します：

   ```shell
   vi .env

   SEEKDB_HOST=localhost      # データベースホスト
   SEEKDB_PORT=2881           # データベースポート（デフォルト：2881）
   SEEKDB_USER=your_username
   SEEKDB_PASSWORD=your_password
   SEEKDB_DATABASE=your_database
   ```

   ### SSEモードで起動する

   ```shell
   env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 0.0.0.0
   ```

   ### VS Codeのツールターミナルを開き、claude mcp add-jsonコマンドを実行する

   ```shell
   claude mcp add-json sse-seekdb '{
      "autoApprove": [],
      "disabled": false,
      "timeout": 60,
      "type": "sse",
      "url": "http://ip:port/sse"
   }'
   ```

   ### Claude Codeクライアントの作業ディレクトリを作成し、seekdb MCP Serverを設定する

   手動でローカルにVisual Studio Codeの作業ディレクトリを作成し、Visual Studio Codeで開きます。今後Claude Codeが生成するファイルはこのディレクトリに配置されます。例としてのディレクトリ名は`claudecode`です。

   データベースへの接続が可能か確認します。`How many tables in the test database?`というプロンプトを入力すると、Claude Codeは実行予定のSQL文を表示し、クエリ結果を出力します：

      ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/claude-code/4.png)

      Claude Codeは現在のtestデータベース内のテーブル数を表示します。これにより、seekdbへの接続が正常に行われていることが確認できます。

   ## ステップ3：FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

   FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

   1. テーブルを作成します。

      `Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`というプロンプトを入力します。

      ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/claude-code/5.png)

   2. テストデータを挿入します。

      `Insert 10 pieces of data into the customer table`というプロンプトを入力します。

      ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/claude-code/6.png)

   3. FastAPIプロジェクトを作成します。

      `Create a FastAPI project on the customer table`というプロンプトを入力すると、複数のファイルが自動生成されます。問題があれば、その後修正します。

      ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/claude-code/7.png)

   4. FastAPIプロジェクトのデータベース接続情報を設定します。

      ![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/claude-code/8.png)

   5. プロジェクトの依存関係をインストールします。

      以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

      ```shell
      cd customer_api
      pip install -r requirements.txt
      ```

   6. FastAPIプロジェクトを起動します。

      以下のコマンドを実行して、FastAPIプロジェクトを起動します：

      ```shell
      source .env
      uvicorn main:app --reload
      ```

   7. テーブル内のデータを確認します。

      コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します。

      ```shell
      curl http://127.0.0.1:8000/customers
      ```
