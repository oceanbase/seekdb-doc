# GitHub Copilotとの連携

[GitHub Copilot](https://github.com/features/copilot)は、GitHubが提供するAIプログラミングアシスタントで、Visual Studio Codeに深く統合されています。コード補完、チャット対話、Agentモードなどの機能をサポートし、開発者がより効率的にコードを記述できるよう支援します。

本記事では、GitHub Copilot上でseekdb Agent Skillを利用して、AIが自動的に呼び出せるナレッジパッケージ＋ワークフローを迅速に構築する方法、およびseekdb MCP Serverを利用してバックエンドアプリケーションを迅速に構築する方法について説明します。

    [Agent Skills](https://agentskills.io/home)は、Anthropicが主導して設計し、現在ではオープンスタンダードとして公開されたAI能力拡張フォーマットです。その核となる考え方は、指示、スクリプト、リソースを一つのフォルダにパッケージ化し、AI Agentが必要に応じてこれらの「スキル」を検出してロードすることで、より正確かつ効率的にタスクを完了できるようにすることです。

    seekdb Agent Skillsは、このスタンダードに基づいて構築された「AIが自動的に呼び出せるナレッジパッケージ＋ワークフロー」です。GitHub Copilotにインストールすると、seekdbに関する質問をした際に、GitHub Copilotが自動的にスキルの説明に従ってseekdbのドキュメントを参照したり、データのインポート・エクスポートなどの操作を実行したりします。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要がなく、コーディング中にseekdbの公式ドキュメントサポートと実践的な能力を得ることができます。Agent Skillの詳細については、[seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)を参照してください。

    ## 対応スキル

    ## GitHub Copilotへのseekdb Agent Skillsのインストール

    GitHub Copilotは、プロジェクトのルートディレクトリ配下にある`.github/skills`ディレクトリを認識し、Agent Skillを読み込みます。以下の手順でインストールを完了してください：

    1. スキルをインストールしたいプロジェクトのルートディレクトリに移動します。

        ```shell
        cd /path/to/your/project
        ```

    2. インタラクティブインストーラーをインストールします。

        ```shell
        pip install seekdb-agent-skills
        ```

    3. インタラクティブインストーラーを実行します。

        ```shell
        seekdb-agent-skills
        ```

    4. ツールを選択します。

        キーボードの**↑↓**キーで**GitHub Copilot**を選択し、**Enter**キーで確定します。

        ```shell
        🚀 seekdb Agent Skills Installer
        ==================================================

        📋 Select tool to install to:
        ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
          Claude Code
          OpenClaw
          Cursor
          Codex
          OpenCode
        » GitHub Copilot
          Qoder
          Trae
        ```

    5. インストール先を確認します。

        ```shell
        📁 Project root: /path/to/your/project
        (Skills will be installed under .github/skills)
        ? Install skills to this directory? (Y/n)
        ```

        `Y`と入力して確認し、`n`と入力してインストーラーを終了します。

    6. インストールするスキルを選択します。

        AIがseekdbのドキュメントを参照するだけであれば、そのままEnterキーを押すだけで済みます。Excel/CSVファイルをseekdbにインポートまたはエクスポートする必要がある場合は、**importing-to-seekdb**と**querying-from-seekdb**の両方のスキルを選択できます。キーボードの**↑↓**キーでスキルを選択し、**Space**キーで複数選択し、**Enter**キーでインストールを確定します。

        ```shell
        📦 Select skills to install:
        ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
        » ● seekdb
          ○ importing-to-seekdb
          ○ querying-from-seekdb
        ```

    ## GitHub Copilotでseekdb Agent Skillsを使用する

    インストールが完了したら、VS Codeを使用してスキルがインストールされたプロジェクトのルートディレクトリを開き、Copilot Chatで直接質問するだけです。AIは対応するスキルを自動的に呼び出し、ドキュメントやスキルの能力に基づいて回答します。また、チャット入力ボックスに `/skills` と入力すると、読み込まれているスキルのリストを確認できます。

    質問例：

    * Macでseekdbをデプロイするにはどうすればよいですか？
    * seekdbのベクトル検索の使い方を教えてください。
    * seekdbでハイブリッド検索を実装するにはどうすればよいですか？

    [MCP（Model Context Protocol）](https://modelcontextprotocol.io/docs/getting-started/intro)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルで、大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

    [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにするサーバーです。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

    ## 前提条件

    * seekdbのデプロイが完了していること。

    * [Python 3.11以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以降の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    * Pythonパッケージマネージャuvをインストールしていること。公式の独立インストーラーの使用を推奨します。インストール完了後、`uv --version`で検証できます：

      * macOSとLinux（curlを使用）：

            ```shell
            curl -LsSf https://astral.sh/uv/install.sh | sh
            ```

            curlがない場合は、wgetを使用できます：

            ```shell
            wget -qO- https://astral.sh/uv/install.sh | sh
            uv --version
            ```

      * Windows（PowerShellを使用）：

            ```shell
            powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
            uv --version
            ```

        その他のインストール方法（Homebrew、pipx、pipなど）については、[uv公式インストールドキュメント](https://docs.astral.sh/uv/getting-started/installation/)を参照してください。

    * [Visual Studio Code](https://code.visualstudio.com/Download)をダウンロードし、ご使用のOSに合わせたバージョンを選択してインストールします。VS Codeの拡張ストアでGitHub Copilot拡張機能を検索してインストールします。

    ## ステップ１：データベース接続情報を取得する

    seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

    ```sql
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

    **パラメータ説明：**

    * `$host`：seekdbへの接続IPアドレスを指定します。
    * `$port`：seekdbへの接続ポートを指定します。デフォルトは`2881`です。
    * `$database_name`：アクセスするデータベース名を指定します。

        :::tip
        接続するユーザーには、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限が付与されていなければなりません。
        :::

    * `$user_name`：データベース接続アカウントを指定します。
    * `$password`：アカウントのパスワードを指定します。

    ## ステップ2：seekdb MCP Serverを設定する

    ### seekdb MCP Serverのインストール

    以下のコマンドを実行してインストールします。

    ```shell
    pip install seekdb-mcp-server
    ```

    ### seekdbサーバーの環境変数を.envファイルに設定する

    現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します。

    ```shell
    SEEKDB_HOST=localhost
    SEEKDB_PORT=2881
    SEEKDB_USER=your_username
    SEEKDB_PASSWORD=your_password
    SEEKDB_DATABASE=your_database
    ```

    ### Streamable-HTTPモードでseekdb MCP Serverを起動する

    ```shell
    env $(cat .env | xargs) uvx seekdb-mcp-server --transport streamable-http --port 8000 --host 127.0.0.1
    ```

    ### VS Codeの作業ディレクトリを作成し、seekdb MCP Serverを設定する

    手動でVS Codeの作業ディレクトリを作成し、VS Codeで開きます。今後GitHub Copilotが生成するファイルは、このディレクトリに配置されます。ディレクトリ名の例は`copilot-generate`です。

    VS Codeで、ショートカットキー`Ctrl + Shift + P`（Windows / Linux）または`Command + Shift + P`（macOS）を使用してコマンドパネルを開き、`MCP: Add Server`と入力します。`HTTP/SSE`タイプを選択し、表示されたプロンプトに従って設定情報を入力します。

    または、プロジェクトのルートディレクトリに`.vscode/mcp.json`ファイルを手動で作成し、以下の設定を追加することもできます。

    #### MCPServersの追加と設定

    ```json
    {
      "servers": {
        "streamable-http-seekdb": {
          "url": "http://ip:port/mcp",
          "type": "http"
        }
      },
      "inputs": []
    }
    ```

    `ip`と`port`をseekdb MCP Serverが実際に稼働しているアドレスとポートに置き換えます（例：http://127.0.0.1:8000/mcp）。

    設定完了後、VS Codeは自動的にMCP Serverを検出して起動します。コマンドパネルの`MCP: List Servers`コマンドを使用して、MCP Serverの接続状態を確認できます。

    #### MCP Serverのテスト

    ショートカットキー`Ctrl + Alt + I`（Windows / Linux）または`Ctrl + Command + I`（macOS）を使用してCopilot Chatを開き、**Agentモード**に切り替えます。ダイアログボックスにプロンプト`How many tables in the test database?，GitHub Copilot`を入力すると、GitHub Copilotは実行予定のSQL文を表示します。確認後、**Allow**ボタンをクリックして実行します。GitHub Copilotは`test`データベース内のすべてのテーブル名を表示します。これにより、seekdbへの接続に成功したことが確認できます。

    ## ステップ3：FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

    FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

    1. customerテーブルの作成

        ダイアログボックスにプロンプト`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`を入力します。SQL文を確認した後、**Allow**ボタンをクリックして実行します。

        <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/2.png) -->

    2. テストデータの挿入

        ダイアログボックスにプロンプト`Insert 10 pieces of data into the customer table`を入力します。SQL文を確認した後、**Allow**ボタンをクリックして実行します。

        <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/3.png) -->

    3. FastAPIプロジェクトの作成

        ダイアログボックスにプロンプト`Create a FastAPI project on the customer table`を入力し、**Allow**ボタンをクリックして実行します。このステップでは、複数のファイルが自動生成されます。

        <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/4.png) -->

        このステップでは、複数のファイルが自動生成されます。初回使用時は、`すべて受け入れる`を選択することを推奨します。AIが生成するファイルの内容は不確定な場合があるため、後から実際のニーズに合わせて調整できます。

    4. FastAPIプロジェクトのデータベース接続情報の設定

        GitHub Copilotが生成したプロジェクトのデータベース接続情報を確認します。不正確な場合は、設定を変更する必要があります。

        <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/5.png) -->

    5. プロジェクト依存関係のインストール

        以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

        ```shell
        cd fastapi_app
        pip install -r requirements.txt
        ```

    6. FastAPIプロジェクトの起動

        以下のコマンドを実行して、FastAPIプロジェクトを起動します：

        ```shell
        uvicorn fastapi_app.main:app --reload --host 127.0.0.1 --port 3000
        ```

    7. テーブル内のデータの確認

        コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

        ```shell
        curl http://127.0.0.1:3000/customers/
        ```

        実行結果は次のとおりです：
