# OpenCodeとの連携

[OpenCode](https://opencode.ai/)は、オープンソースのAIプログラミングエージェントであり、開発者がアイデアを迅速にコードに変換するのを支援します。

本記事では、OpenCode上でseekdb Agent Skillを利用して、AIが自動的に呼び出せるナレッジパッケージとワークフローを迅速に構築する方法、およびseekdb MCP Serverを利用してバックエンドアプリケーションを迅速に構築する方法について説明します。

    [Agent Skills](https://agentskills.io/home)は、Anthropicが主導して設計され、現在はオープンスタンダードとして公開されているAI能力拡張形式です。そのコアコンセプトは、指示、スクリプト、リソースを1つのフォルダにパッケージ化し、AI Agentが必要に応じてこれらの「スキル」を検出してロードすることで、より正確かつ効率的にタスクを完了できるようにすることです。

    seekdb Agent Skillsは、このスタンダードに基づいて構築された、「AIが自動的に呼び出せるナレッジパッケージ+ワークフロー」です。OpenCodeにインストール後、seekdbに関する質問をすると、OpenCodeはスキルの説明に従ってseekdbのドキュメントを参照したり、データのインポート・エクスポートなどの操作を自動的に実行します。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要がなく、コーディング中にseekdbの公式ドキュメントサポートと実践的な機能を利用できます。Agent Skillの詳細については、[seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)を参照してください。

    ## 対応スキル

    | スキル | 説明 | 典型的な質問例 |
    | --- | --- | --- |
    | **seekdb**（デフォルトインストール） | seekdbの公式ドキュメント（クイックスタート、開発ガイド、SDK/API、マルチモデルデータ、統合と運用保守など）をカバーしています。AIがユーザーの質問に基づいて対応するドキュメントを自動的に特定し、答えや例を提示します。 | seekdbのデプロイ方法は？ / seekdbのベクトル検索の使い方は？ |
    | **importing-to-seekdb** | データをseekdbのコレクション（Collection）にインポートし、指定された列のベクトル化をサポートします。インポート前にExcel/CSVの構造とサンプルデータをプレビューできます。 | sample_products.xlsxをseekdbにインポートし、Details列をベクトル化します。 |
    | **querying-from-seekdb** | メタデータ条件によるフィルタリングでスカラー検索を実行し、全文検索と意味検索のハイブリッド検索（RRFソート）をサポートします。結果はCSVまたはExcel形式でエクスポート可能です。 | スコア4.3以上のAMOLED画面のスマートフォンを2機種推薦します。 |

    ## OpenCodeへのseekdb Agent Skillsのインストール

    OpenCodeは、プロジェクトのルートディレクトリ配下にある`.opencode/skills`ディレクトリを認識し、Agent Skillを読み込みます。以下の手順でインストールを完了してください：

    1. スキルをインストールしたいプロジェクトのルートディレクトリに移動します。

        ```shell
        cd /path/to/your/project
        ```

    2. インタラクティブインストーラーをインストールします。

        ```shell
        pip install seekdb-agent-skills
        ```

    3. インタラクティブインストーラーを実行します。

        ```shell
        seekdb-agent-skills
        ```

    4. ツールを選択します。

        キーボードの**↑↓**キーで**OpenCode**を選択し、**Enter**キーで確定します。

        ```shell
        🚀 seekdb Agent Skills Installer
        ==================================================

        📋 Select tool to install to:
        ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
          Claude Code
          OpenClaw
          Cursor
          Codex
        » OpenCode
          GitHub Copilot
          Qoder
          Trae
        ```

    5. インストール先を確認します。

        ```shell
        📁 Project root: /path/to/your/project
        (Skills will be installed under .opencode/skills)
        ? Install skills to this directory? (Y/n)
        ```

        `Y`と入力して確認し、`n`と入力してインストーラーを終了します。

    6. インストールするスキルを選択します。

        AIがseekdbのドキュメントを参照するだけであれば、そのままEnterキーを押すだけで済みます。Excel/CSVファイルをseekdbにインポートまたはエクスポートする必要がある場合は、**importing-to-seekdb**と**querying-from-seekdb**の両方のスキルを選択できます。キーボードの**↑↓**キーでスキルを選択し、**Space**キーで複数選択し、**Enter**キーでインストールを確定します。

        ```shell
        📦 Select skills to install:
        ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
        » ● seekdb
          ○ importing-to-seekdb
          ○ querying-from-seekdb
        ```

    ## OpenCodeでのseekdb Agent Skillsの使用

    インストール完了後、スキルをインストールしたプロジェクトのルートディレクトリでOpenCodeを起動し、直接質問するだけで済みます。AIは対応するスキルを自動的に呼び出し、ドキュメントやスキルの能力に基づいて回答します。

    質問例：

    * Macでseekdbをデプロイするにはどうすればよいですか？
    * seekdbのベクトル検索の使い方を教えてください。
    * seekdbでハイブリッド検索を実装するにはどうすればよいですか？

    [MCP（Model Context Protocol）](https://modelcontextprotocol.io/docs/getting-started/intro)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルで、大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

    [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにするサーバーです。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

    ## 前提条件

    * seekdbのデプロイが完了していること。

    * [Python 3.11以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)のインストールが完了していること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以上の環境を作成できます。詳細については[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    * Pythonパッケージマネージャーuvのインストール。公式の独立インストーラーの使用を推奨します。インストール完了後、`uv --version`で検証できます：

      * macOSとLinux（curlを使用）：

            ```shell
            curl -LsSf https://astral.sh/uv/install.sh | sh
            ```

            curlがない場合は、wgetを使用できます：

            ```shell
            wget -qO- https://astral.sh/uv/install.sh | sh
            uv --version
            ```

      * Windows（PowerShellを使用）：

            ```shell
            powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
            uv --version
            ```

        その他のインストール方法（Homebrew、pipx、pipなど）については、[uv公式インストールドキュメント](https://docs.astral.sh/uv/getting-started/installation/)を参照してください。

    * OpenCodeのインストール：

      以下のコマンドを実行してOpenCodeをインストールします：

            ```shell
            curl -fsSL https://opencode.ai/install | bash
            ```

      他の方法でもインストールできます：

            ```shell
            # npmを使用する場合
            npm install -g opencode-ai

            # Homebrewを使用する場合（macOS / Linux）
            brew install anomalyco/tap/opencode
            ```

        インストール完了後、`opencode`コマンドを実行してインストールが成功したかどうかを確認します。

    ## ステップ1：データベース接続情報を取得する

    seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

    ```sql
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

    **パラメータ説明：**

    * `$host`：seekdbへの接続IPアドレスを指定します。
    * `$port`：seekdbへの接続ポートを指定します。デフォルトは`2881`です。
    * `$database_name`：アクセスするデータベース名を指定します。

        :::tip
        接続するユーザーは、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限を持っている必要があります。
        :::

    * `$user_name`：データベース接続アカウントを指定します。
    * `$password`：アカウントのパスワードを指定します。

    ## ステップ2：seekdb MCP Serverを設定する

    ### seekdb MCP Serverのインストール

    以下のコマンドを実行してインストールします。

    ```shell
    pip install seekdb-mcp-server
    ```

    ### seekdbサーバーの環境変数を.envファイルに設定する

    現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します。

    ```shell
    SEEKDB_HOST=localhost
    SEEKDB_PORT=2881
    SEEKDB_USER=your_username
    SEEKDB_PASSWORD=your_password
    SEEKDB_DATABASE=your_database
    ```

    ### SSEモードで起動する

    ```shell
    env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 127.0.0.1
    ```

    ### OpenCodeでseekdb MCP Serverを設定する

    OpenCodeは、プロジェクトのルートディレクトリにあるopencode.json設定ファイルを通じてMCP Serverを管理します。プロジェクトのルートディレクトリにopencode.jsonファイルを作成または編集し、seekdb MCP Serverの設定を追加します。

    ```json
    {
      "$schema": "https://opencode.ai/config.json",
      "mcp": {
        "sse-seekdb": {
          "type": "remote",
          "url": "http://ip:port/sse",
          "enabled": true
        }
      }
    }
    ```

    `ip`と`port`をseekdb MCP Serverが実際に稼働しているアドレスとポート（例：http://127.0.0.1:8000/sse）に置き換えます。

    ### MCP Server接続の検証

    プロジェクトのルートディレクトリでOpenCodeを起動します：

    ```shell
    opencode
    ```

    ダイアログボックスにプロンプト`How many tables in the test database?`と入力すると、OpenCodeはseekdb MCP Serverを使用してSQLクエリを実行し、結果を出力します。テーブル数が正しく返されれば、seekdbへの接続に成功したことを意味します。

    ## ステップ3：FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

    FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

    1. customerテーブルを作成する

        ダイアログボックスにプロンプトを入力します：`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`。

        <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/OpenCode/2.png) -->

    2. テストデータを挿入する

        ダイアログボックスにプロンプトを入力します：`Insert 10 pieces of data into the customer table`。

        <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/OpenCode/3.png) -->

    3. FastAPIプロジェクトを作成する

        ダイアログボックスにプロンプトを入力します：`Create a FastAPI project on the customer table`。OpenCodeは複数のファイルを自動生成します。問題があれば、後から修正できます。

        <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/OpenCode/4.png) -->

        このステップでは、複数のファイルが自動生成されます。AIが生成するファイルの内容は不確定な場合があるため、後から実際のニーズに合わせて調整できます。

    4. FastAPIプロジェクトのデータベース接続情報を設定する

        OpenCodeが生成したプロジェクトのデータベース接続情報を確認し、誤っている場合は設定を変更する必要があります。

        <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/OpenCode/5.png) -->

    5. プロジェクトの依存関係をインストールする

        以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

        ```shell
        cd fastapi_customer_app
        pip install -r requirements.txt
        ```

    6. FastAPIプロジェクトを起動する

        以下のコマンドを実行して、FastAPIプロジェクトを起動します：

        ```shell
        uvicorn main:app --reload --host 127.0.0.1 --port 3000
        ```

    7. テーブル内のデータを確認する

        コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

        ```shell
        curl http://127.0.0.1:3000/customers
        ```

        実行結果は次のとおりです：
