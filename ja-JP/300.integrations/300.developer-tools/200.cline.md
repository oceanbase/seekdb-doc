# Clineとの連携

seekdbは、ベクトル型データの格納、ベクトルインデックス、そしてembeddingベクトル検索機能を提供します。これにより、ベクトル化したデータをseekdbに保存し、次の検索処理で利用できるようになります。

[Cline](https://cline.bot/)は、MCPプロトコルをサポートするオープンソースのAIコーディングアシスタントです。

本記事では、Clineを用いて、seekdb MCP Serverを通じてバックエンドアプリケーションを迅速に構築する方法を紹介します。

## 前提条件

* seekdbデータベースのデプロイが完了していること。

* [Python 3.11以降のバージョン](https://www.python.org/downloads/)および対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。マシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以降の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

* Pythonパッケージマネージャーuvをインストールしていること。インストール完了後、`uv --version`コマンドを実行してインストールが成功したかどうか確認できます：

    ```shell
    pip install uv
    uv --version
    ```

* Clineをインストールしていること：

  * Visual Studio Code IDEを使用している場合は、**拡張機能**バーで検索し、`Cline`という名前のプラグインをインストールします。

  * IDEを使用しない場合は、[Clineインストールガイド](https://docs.cline.bot/getting-started/installing-cline)を参照し、ダウンロード先は[Cline](https://cline.bot/)です。

## ステップ１：データベース接続情報を取得する

seekdbデータベースのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```shell
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレスを指定します。
* `$port`：seekdb接続ポートを指定します。デフォルトは`2881`です。
* `$database_name`：アクセス対象のデータベース名を指定します。

    :::tip
    接続するユーザーには、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限が付与されていなければなりません。
    :::

* `$user_name`：データベース接続アカウントを指定します。
* `$password`：アカウントのパスワードを指定します。

## ステップ2：seekdb MCP Serverの設定

ここではVisual Studio Codeを例に、seekdb MCP Serverの設定方法を説明します。

### seekdb MCP Serverのインストール

以下のコマンドを実行してインストールします：

```shell
pip install seekdb-mcp-server
```

### seekdbサーバーの環境変数を.envファイルに設定

現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します：

```shell
vi .env

SEEKDB_HOST=localhost      # データベースホスト
SEEKDB_PORT=2881           # データベースポート（デフォルト：2881）
SEEKDB_USER=your_username
SEEKDB_PASSWORD=your_password
SEEKDB_DATABASE=your_database
```

### SSEモードで起動

```shell
env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 0.0.0.0
```

### Visual Studio Codeの作業ディレクトリの作成

ローカルにVisual Studio Codeの作業ディレクトリを手動で作成し、Visual Studio Codeで開きます。後でClineが生成するファイルはこのディレクトリに配置されます。例としてのディレクトリ名は`cline-generate`です。

#### 大規模言語モデルの設定

サイドバーの`Clineアイコン`をクリックしてClineダイアログを開き、Clineのための大規模言語モデルを設定します：

![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/2.png)

#### seekdb MCP Serverの設定

1. 下図に示す`MCP Serversアイコン`をクリックします。

    ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/3.png)

2. 設定ファイルに入力し、確認をクリックします。

    ```sehll
    {
      "mcpServers": {
        "sse-seekdb": {
          "autoApprove": [],
          "disabled": false,
          "timeout": 60,
          "type": "sse",
          "url": "http://ip:port/sse"
        }
      }
    }
    ```

3. 設定が成功した場合、`使用可能`状態が表示され、`MCP tools`と`resources`の情報が表示されます。例：

    ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/4.png)

#### MCP Serverのテスト

以下のようにClineダイアログを開き、プロンプト`How many tables in the test database?`に入力します。Clineは実行予定のSQLステートメントを表示します。問題がなければ`Approve`をクリックします。Clineが現在のtestデータベース内のテーブル名を表示すれば、seekdbへの接続は正常であることを意味します。

![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/5.png)

### FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

1. customerテーブルを作成する

    ダイアログボックスに次のプロンプトを入力します：`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`。SQL文を確認した後、`Approve`ボタンをクリックして実行します。

    ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/6.png)

2. テストデータを挿入する

    ダイアログボックスに次のプロンプトを入力します：`Insert 10 pieces of data into the customer table`。SQL文を確認した後、`Approve`ボタンをクリックして実行します。

    ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/7.png)

3. FastAPIプロジェクトを作成する

    FastAPIプロジェクトを作成する ダイアログボックスに次のプロンプトを入力します：`Create a FastAPI project on the customer table`。`Approve`ボタンをクリックして実行します。

    ![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/8.png)

    このステップでは、複数のファイルが自動生成されます。AIが生成するファイルの内容は不確定な場合があるため、初回使用時は「すべて受け入れる」を選択し、後から実際のニーズに合わせて調整することをお勧めします。

4. FastAPIプロジェクトのデータベース接続情報を設定する

    ![9](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/cline/9.png)

5. プロジェクトの依存関係をインストールする

    以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

    ```shell
    pip install -r requirements.txt
    ```

6. FastAPIプロジェクトを起動する

    以下のコマンドを実行して、FastAPIプロジェクトを起動します：

    ```shell
    source .env
    uvicorn main:app --reload
    ```

7. テーブル内のデータを確認する

    コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

    ```shell
    curl http://127.0.0.1:8000/customers
    ```
