# Augment Codeとの連携

[MCP（Model Context Protocol）](https://modelcontextprotocol.io/introduction)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルです。大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

[MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにします。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

[Augment Code](https://www.augmentcode.com/)は、開発者向けのAIプラットフォームです。コードの理解、問題のデバッグ、そしてコードベースを理解しているためより迅速なリリースを支援します。チャット、次の編集、コード補完を活用して、より多くの作業を効率的に進めることができます。

本記事では、Augment Codeを使用し、seekdb MCP Serverを通じてバックエンドアプリケーションを迅速に構築する方法を紹介します。

## 前提条件

* seekdbのデプロイが完了していること。

* [Python 3.11以降のバージョン](https://www.python.org/downloads/)および対応する[pip](https://pip.pypa.io/en/stable/installation/)をインストールしていること。マシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以降の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

* Pythonパッケージマネージャuvをインストールしていること。インストール完了後、`uv --version`コマンドを実行してインストールが成功したかどうか確認できます：

    ```shell
    pip install uv
    uv --version
    ```

* Visual Studio CodeにAugment Codeプラグインをインストールしていること。プラグイン名は`Augment Code`です。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/augment-code/1.png)

## ステップ１：データベース接続情報を取得する

seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレスを指定します。
* `$port`：seekdbへの接続ポートを指定します。デフォルトは2881です。
* `$database_name`：アクセスするデータベース名を指定します。

    :::tip

    接続するユーザーは、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限を持っている必要があります。

    :::

* `$user_name`：データベース接続アカウントを指定します。
* `$password`：アカウントのパスワードを指定します。

## ステップ2：seekdb MCP Serverの設定

ここでは、Visual Studio Codeを例に、seekdb MCP Serverの設定方法を説明します。

### seekdb MCP Serverのインストール

以下のコマンドを実行してインストールします：

```shell
pip install seekdb-mcp-server
```

### seekdbサーバーの環境変数を.envファイルに設定する

現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します：

```shell
vi .env

SEEKDB_HOST=localhost      # データベースホスト
SEEKDB_PORT=2881           # データベースポート（デフォルト：2881）
SEEKDB_USER=your_username
SEEKDB_PASSWORD=your_password
SEEKDB_DATABASE=your_database
```

### SSEモードで起動する

```shell
env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 0.0.0.0
```

### MCP Serversの追加と設定

1. Augment Codeにログインします。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/augment-code/2.png)

2. Augment Codeでseekdb MCP Serverを設定します。

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/augment-code/3.png)

3. Import from jsonをクリックし、mcp設定ファイルを入力します。

   ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/augment-code/4.png)

   ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/augment-code/5.png)

4. 設定ファイルに入力し、確認をクリックします。

   ```json
   {
     "mcpServers": {
       "seekdb": {
         "autoApprove": [],
         "disabled": false,
         "timeout": 60,
         "type": "sse",
         "url": "http://ip:port/sse"
       }
     }
   }
   ```

   Augment Codeが現在のseekdb mcp server内のツールを表示すれば、設定は成功です。
