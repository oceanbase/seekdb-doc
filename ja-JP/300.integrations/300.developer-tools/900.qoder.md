# Qoderとの連携

[Qoder](https://qoder.com/)は、AIネイティブのインテリジェントなプログラミングプラットフォームであり、AI-Native IDE、CLI、JetBrainsプラグインの3つの形態をサポートしています。Agentic Chatや自律エージェント(Questモード)などの機能を提供し、開発者がアイデアを迅速にコードに変換するのを支援します。

本記事では、Qoder上でseekdb Agent Skillを利用して、AIが自動的に呼び出せるナレッジパッケージ+ワークフローを迅速に構築する方法、およびseekdb MCP Serverを利用してバックエンドアプリケーションを迅速に構築する方法について説明します。

    [Agent Skills](https://agentskills.io/home)は、Anthropicが主導して設計され、現在オープンスタンダードとして公開されているAI能力拡張形式です。そのコアコンセプトは、指示、スクリプト、リソースを1つのフォルダにパッケージ化し、AI Agentが必要に応じてこれらの「スキル」を検出してロードすることで、より正確かつ効率的にタスクを完了できるようにすることです。

    seekdb Agent Skillsは、このスタンダードに基づいて構築された「AIが自動的に呼び出せるナレッジパッケージ+ワークフロー」です。Qoderにインストール後、seekdbに関する質問をすると、QoderのAIが自動的にスキルの説明に従ってseekdbのドキュメントを参照したり、データのインポート・エクスポートなどの操作を実行したりします。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要がなく、コーディング中にseekdbの公式ドキュメントサポートと実践能力を得ることができます。Agent Skillの詳細については、[seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)を参照してください。

    ## 対応スキル

    | スキル | 説明 | 典型的な質問例 |
    | --- | --- | --- |
    | **seekdb**（デフォルトインストール） | seekdbの公式ドキュメント（クイックスタート、開発ガイド、SDK/API、マルチモデルデータ、統合と運用保守など）をカバーしています。AIがユーザーの質問に基づいて対応するドキュメントを自動的に特定し、答えや例を提示します。 | seekdbのデプロイ方法は？ / seekdbのベクトル検索の使い方は？ |
    | **importing-to-seekdb** | データをseekdbのコレクション（Collection）にインポートし、指定された列のベクトル化をサポートします。インポート前にExcel/CSVの構造とサンプルデータをプレビューできます。 | sample_products.xlsxをseekdbにインポートし、Details列をベクトル化します。 |
    | **querying-from-seekdb** | メタデータ条件によるフィルタリングでスカラー検索を実行し、全文検索と意味検索のハイブリッド検索（RRFソート）をサポートします。結果はCSVまたはExcel形式でエクスポート可能です。 | スコア4.3以上のAMOLED画面のスマートフォンを2機種推薦します。 |

    ## Qoderへのseekdb Agent Skillsのインストール

    Qoderは、プロジェクトのルートディレクトリ配下にある`.qoder/skills`ディレクトリを認識し、Agent Skillを読み込みます。以下の手順でインストールを完了してください：

    1. スキルをインストールしたいプロジェクトのルートディレクトリに移動します。

        ```shell
        cd /path/to/your/project
        ```

    2. インタラクティブインストーラーをインストールします。

        ```shell
        pip install seekdb-agent-skills
        ```

    3. インタラクティブインストーラーを実行します。

        ```shell
        seekdb-agent-skills
        ```

    4. ツールを選択します。

        キーボードの**↑↓**キーで**Qoder**を選択し、**Enter**キーで確定します。

        ```shell
        🚀 seekdb Agent Skills Installer
        ==================================================

        📋 Select tool to install to:
        ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
          Claude Code
          OpenClaw
          Cursor
          Codex
          OpenCode
          GitHub Copilot
        » Qoder
          Trae
        ```

    5. インストール先を確認します。

        ```shell
        📁 Project root: /path/to/your/project
        (Skills will be installed under .qoder/skills)
        ? Install skills to this directory? (Y/n)
        ```

        `Y`と入力して確認し、`n`と入力してインストーラーを終了します。

    6. インストールするスキルを選択します。

        AIがseekdbのドキュメントを参照するだけであれば、そのままEnterキーを押すだけで済みます。Excel/CSVファイルをseekdbにインポートまたはエクスポートする必要がある場合は、**importing-to-seekdb**と**querying-from-seekdb**の両方のスキルを選択できます。キーボードの**↑↓**キーでスキルを選択し、**Space**キーで複数選択し、**Enter**キーでインストールを確定します。

        ```shell
        📦 Select skills to install:
        ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
        » ● seekdb
          ○ importing-to-seekdb
          ○ querying-from-seekdb
        ```

    ## Qoderでのseekdb Agent Skillsの使用

    インストール完了後、Qoderを使用してスキルがインストールされたプロジェクトのルートディレクトリを開き、チャットで直接質問するだけです。AIが対応するスキルを自動的に呼び出し、ドキュメントやスキルの能力に基づいて回答します。

    質問例：

    * Macでseekdbをデプロイするにはどうすればよいですか？
    * seekdbのベクトル検索の使い方を教えてください。
    * seekdbでハイブリッド検索を実装するにはどうすればよいですか？

    [MCP（Model Context Protocol）](https://modelcontextprotocol.io/docs/getting-started/intro)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルで、大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

    [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにするサーバーです。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

    ## 前提条件

    * seekdbのデプロイが完了していること。

    * [Python 3.11以降のバージョン](https://www.python.org/downloads/)と対応する[pip](https://pip.pypa.io/en/stable/installation/)のインストールが完了していること。お使いのマシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以降の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

    * Pythonパッケージマネージャーuvのインストールが完了していること。公式の独立インストーラーの使用を推奨します。インストール完了後、`uv --version`で検証できます：

      * macOSとLinux（curlを使用）：

            ```shell
            curl -LsSf https://astral.sh/uv/install.sh | sh
            ```

            curlが利用できない場合は、wgetを使用できます：

            ```shell
            wget -qO- https://astral.sh/uv/install.sh | sh
            uv --version
            ```

      * Windows（PowerShellを使用）：

            ```shell
            powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
            uv --version
            ```

        その他のインストール方法（Homebrew、pipx、pipなど）については、[uv公式インストールドキュメント](https://docs.astral.sh/uv/getting-started/installation/)を参照してください。

    * [Qoder](https://qoder.com/)をダウンロードし、ご自身のOSに合ったバージョンを選択してインストールしてください。初めてQoderを使用する際は、新規アカウントを登録するか、既存のアカウントでログインする必要があります。

    ## ステップ1：データベース接続情報を取得する

    seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

    ```sql
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

    **パラメータ説明：**

    * `$host`：seekdbへの接続IPアドレスを指定します。
    * `$port`：seekdbへの接続ポートを指定します。デフォルトは`2881`です。
    * `$database_name`：アクセスするデータベース名を指定します。

        :::tip
        接続するユーザーは、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限を持っている必要があります。
        :::

    * `$user_name`：データベース接続アカウントを指定します。
    * `$password`：アカウントのパスワードを指定します。

    ## ステップ2：seekdb MCP Serverを設定する

    ### seekdb MCP Serverのインストール

    以下のコマンドを実行してインストールします。

    ```shell
    pip install seekdb-mcp-server
    ```

    ### seekdbサーバーの環境変数を.envファイルに設定する

    現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します。

    ```shell
    SEEKDB_HOST=localhost
    SEEKDB_PORT=2881
    SEEKDB_USER=your_username
    SEEKDB_PASSWORD=your_password
    SEEKDB_DATABASE=your_database
    ```

    ### SSEモードでseekdb MCP Serverを起動する

    ```shell
    env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 127.0.0.1
    ```

    ### Qoderクライアントの作業ディレクトリを作成し、seekdb MCP Serverを設定する

    Qoderの作業ディレクトリを手動で作成し、Qoderで開きます。今後Qoderが生成するファイルはこのディレクトリに配置されます。例のディレクトリ名は`qoder-generate`です。

    Qoderの左上にあるユーザーアイコンをクリックするか、ショートカットキー`Ctrl + Shift + ,` (Windows)または`⌘ + ⇧ + ,` (MacOS)を使用して`Qoder Settings`を選択し、左側のナビゲーションバーで`MCP Server`をクリックします。

    #### MCPServersの追加と設定

    1. My Serversタブで、右上の+ Addボタンをクリックします。

    2. 設定ファイルに情報を入力し、確認をクリックします。

        ```json
        {
          "mcpServers": {
            "sse-seekdb": {
              "url": "http://ip:port/sse",
              "type": "sse"
            }
          }
        }
        ```

        `ip`と`port`をseekdb MCP Serverが実際に稼働しているアドレスとポートに置き換えてください（例：http://127.0.0.1:8000/sse）。

    3. 設定を保存します。設定が成功すると、MCPサーバーリストにリンクアイコンが表示され、接続成功を示します。

    #### MCP Serverのテスト

    Qoderが**Agentモード**であることを確認します（MCPツールはAgentモードでのみ利用可能です）。ダイアログボックスにプロンプト`How many tables in the test database?`と入力すると、Qoderは実行予定のSQL文を表示し、クエリ結果を出力します。Qoderが`test`データベース内のすべてのテーブル名を表示したら、seekdbへの接続に成功したことを意味します。

    ## ステップ3：FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

    FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

    4. customerテーブルを作成します

        ダイアログボックスにプロンプトと入力します：`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`。

        <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/qoder/2.png) -->

    5. テストデータを挿入します

        ダイアログボックスにプロンプトと入力します：`Insert 10 pieces of data into the customer table`。

        <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/qoder/3.png) -->

    6. FastAPIプロジェクトを作成します

        ダイアログボックスにプロンプトと入力します：`Create a FastAPI project on the customer table`。このステップでは、複数のファイルが自動生成されます。

        <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/qoder/4.png) -->

        このステップでは、複数のファイルが自動生成されます。AIが生成するファイルの内容は不確定な場合があるため、後から実際のニーズに合わせて調整できます。

    7. FastAPIプロジェクトのデータベース接続情報を設定します

        Qoderが生成したプロジェクトのデータベース接続情報を確認します。間違っている場合は、設定を変更する必要があります。

        <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/qoder/5.png) -->

    8. FastAPIプロジェクトを起動します

        以下のコマンドを実行して、FastAPIプロジェクトを起動します：

        ```shell
        sh run.sh
        ```
