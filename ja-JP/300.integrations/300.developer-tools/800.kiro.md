# Kiroとの連携

[MCP（Model Context Protocol）](https://modelcontextprotocol.io/introduction)は、Anthropic社が2024年11月に発表し、オープンソース化したプロトコルです。大規模言語モデルと外部ツールやデータソースとの連携を実現することを目的としています。MCPを利用することで、ユーザーは大規模言語モデルの出力を手動でコピーして実行する必要がなく、モデルが直接ツールに指示を出して対応するアクションを実行させることができます。

[MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server)は、MCPプロトコルを通じて大規模言語モデルとseekdbの連携を提供し、SQL文を実行できるようにします。適切なクライアントを利用することでプロジェクトのプロトタイプを迅速に構築でき、GitHub上でオープンソースとして公開されています。

[Kiro](https://kiro.dev/)は、Amazon Web Services(AWS)がAI Agent専用に開発した統合開発環境(agentic IDE)です。これは人工知能機能を備えたプログラミングツールであり、開発者がコンセプト段階から本番デプロイまでの全プロセスを支援することを目的としています。

本記事ではKiroを使用し、seekdb MCP Serverを通じてバックエンドアプリケーションを迅速に構築する方法を紹介します。

## 前提条件

* seekdbのデプロイが完了していること。

* [Python 3.11以降のバージョン](https://www.python.org/downloads/)および対応する[pip](https://pip.pypa.io/en/stable/installation/)がインストールされていること。マシンのPythonバージョンが低い場合は、Minicondaを使用して新しいPython 3.11以降の環境を作成できます。詳細については、[Minicondaインストールガイド](https://docs.anaconda.com/miniconda/install/)を参照してください。

* Pythonパッケージマネージャuvがインストールされていること。インストール完了後、`uv --version`コマンドを実行してインストールが成功したかどうか確認できます：

   ```shell
   pip install uv
   uv --version
   ```

* Kiroクライアント：

  [kiroダウンロードページ](https://kiro.dev/downloads/)から、ご使用のOSに合ったバージョンを選択してインストールできます。

## ステップ1：データベース接続情報を取得する

seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。例：

```sql
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレス。
* `$port`：seekdbへの接続ポート。デフォルトは2881です。
* `$database_name`：アクセスするデータベース名。

    :::tip

    接続するユーザーは、データベースに対する`CREATE`、`INSERT`、`DROP`、`SELECT`権限を持っている必要があります。

    :::

* `$user_name`：データベース接続アカウント。
* `$password`：アカウントのパスワード。

## ステップ2：seekdb MCP Serverの設定

ここでは、Visual Studio Codeを例に、seekdb MCP Serverの設定方法を説明します。

### seekdb MCP Serverのインストール

以下のコマンドを実行してインストールします：

```shell
pip install seekdb-mcp-server
```

### seekdbサーバーの環境変数を.envファイルに設定する

現在のディレクトリに`.env`という名前のファイルを作成し、以下の内容を追加します：

```shell
vi .env

SEEKDB_HOST=localhost      # データベースホスト
SEEKDB_PORT=2881           # データベースポート（デフォルト：2881）
SEEKDB_USER=your_username
SEEKDB_PASSWORD=your_password
SEEKDB_DATABASE=your_database
```

### SSEモードで起動する

```shell
env $(cat .env | xargs) uvx seekdb-mcp-server --transport sse --port 8000 --host 0.0.0.0
```

### Kiroでseekdb MCP Serverを設定する

1. ショートカットキーCommand + L (MacOS)を使用してチャットダイアログを開き、左下または右上の歯車アイコンをクリックして、Kiro Settingsを選択します。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/1.png)

2. Open User MCP Config (JSON)/Open Workspace MCP Config (JSON)をクリックし、mcp設定ファイルを入力します。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/2.png)

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/3.png)

   以下の設定ファイルに入力し、確認をクリックします。

   ```json
   {
     "mcpServers": {
       "seekdb": {
         "command": "uvx",
         "args": ["seekdb-mcp-server"],
         "env": {
           "SEEKDB_HOST": "127.0.0.1",
           "SEEKDB_PORT": "2881",
           "SEEKDB_USER": "root",
           "SEEKDB_PASSWORD": "",
           "SEEKDB_DATABASE": "test"
         }
       }
     }
   }
   ```

3. データベースへの接続が可能かどうかを確認します。

   `How many tables in the test database?` というプロンプトを入力すると、Kiroは実行されるSQLステートメントを表示し、クエリ結果を出力します：

   ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/4.png)

   Kiroが現在のtestデータベース内のテーブル数を表示すれば、seekdbへの接続は正常です。

## ステップ3：FastAPIを使用してRESTful APIスタイルのプロジェクトを迅速に作成する

FastAPIを使用して、RESTful APIスタイルのプロジェクトを迅速に作成できます。FastAPIは、PythonでRESTful APIを迅速に構築できるWebフレームワークです。

1. customerテーブルを作成する

    プロンプト`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`を入力します：

    ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/5.png )

2. テストデータを挿入する

    プロンプト`Insert 10 pieces of data into the customer table`を入力します：

    ![6](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/6.png)

3. FastAPIプロジェクトを作成する

    プロンプト`Create a FastAPI project on the customer table`を入力すると、複数のファイルが自動生成されます。まずはすべて受け入れをクリックします。問題があれば後から修正します。AIが生成するファイルは毎回異なる場合があるため、ここでは変更の手順は示しません。

    ![7](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/7.png)

    このステップでは複数のファイルが自動生成されます。初回使用時は`すべて受け入れ`を選択することをお勧めします。AIが生成するファイルの内容は不確定な場合があり、後から実際のニーズに合わせて調整できます。

4. FastAPIプロジェクトでデータベース接続情報を設定する

    ![8](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/kiro/8.png)

5. プロジェクトの依存関係をインストールする

    以下のコマンドを実行して、プロジェクトの依存関係をインストールします：

    ```shell
    pip install -r requirements.txt
    ```

6. FastAPIプロジェクトを起動する

    以下のコマンドを実行して、FastAPIプロジェクトを起動します：

    ```shell
    source .env
    uvicorn main:app --reload
    ```

7. テーブル内のデータを確認する

    コマンドラインで以下のコマンドを実行するか、他のリクエストツールを使用して、テーブル内のデータを確認します：

    ```shell
    curl http://127.0.0.1:8000/customers
    ```
