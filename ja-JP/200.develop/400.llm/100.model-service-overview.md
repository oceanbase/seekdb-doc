# モデルサービスの概要

このドキュメントでは、seekdbにおけるモデルサービスの関連機能について説明します。モデルサービスはAIモデルおよびエンドポイントの登録と管理をサポートし、AI関数呼び出しサービスの基盤となります。

## モデルサービスとは

モデルサービスは、seekdbにおいてAIモデルおよびエンドポイントを管理するための機能であり、`DBMS.AI_SERVICE`システムパッケージを通じてモデルの登録、変更、削除などの操作を実現します。

以下はモデルサービスにおけるコアコンセプトです：

| 概念 | 説明 |
|-----|------|
| AIモデル（AI Model） | AIモデルはseekdbにおける抽象オブジェクトであり、データベース内で特定のAIモデルを識別し参照するために使用されます。`CREATE_AI_MODEL` でモデルオブジェクトを作成した後、AI関数内で `model_key` を用いてそのモデルを参照できます。 |
| AIモデルエンドポイント（AI Model Endpoint） | AIモデルエンドポイントとは、外部のAIモデルサービスに接続するための具体的な設定であり、URL、APIキー、要求するモデル名、プロバイダーなどの情報を含みます。エンドポイントは外部モデルサービスとの通信方法を定義します。 |
| モデルタイプ（Model Type） | モデルタイプとはAIモデルの機能分類を指します。seekdbでは以下のタイプをサポートしています：<ul><li>テキスト生成モデル(LLM)：`AI_COMPLETE` 関数に使用され、テキスト内容を生成します。</li><li>埋め込みモデル(Embedding)：`AI_EMBED` 関数に使用され、テキストをベクトル埋め込み処理します。</li><li>再ランキングモデル(Rerank)：`AI_RERANK` 関数に使用され、ドキュメントの検索結果を再ランキングします。</li></ul> |
| プロバイダー（Provider） | プロバイダーとは、OpenAIやDeepSeekなど、AIモデルサービスを提供する事業者です。異なるプロバイダーのAPI形式やパラメータは異なる場合があるため、seekdbは `provider` パラメータにより異なるプロバイダーのインターフェース仕様に対応します。 |

## AI関数サービスとの関係

:::tip
ハイブリッド検索（Hybrid Search）はAIモデル管理とAI_EMBED関数機能に依存しています。AIモデルを削除する際には、潜在的な問題を避けるために、それがハイブリッド検索で参照されていないか確認する必要があります。
:::

**AIモデル管理サービスはAI関数呼び出しサービスの基盤です**。seekdbでは、AIモデル及びそのエンドポイントを正常に登録・管理した後でなければ、SQLレベルで各種AI関数（例：AI_COMPLETE、AI_EMBED、AI_RERANKなど）を呼び出し、データベースが備えるテキスト生成、ベクトル埋め込み、検索の再ランキングなどのインテリジェントな処理能力を実現することはできません。詳細なAI関数の呼び出し方法については、[AI関数の概要](../700.ai-function/0.ai-function-overview.md)を参照してください。
