# モデルの登録と管理

このドキュメントでは、seekdbにAIモデルおよびエンドポイントを登録し、管理する方法について説明します。

## 前提条件

* AIモデルに関する権限を保有していること。詳細については、[モデル権限の管理](200.model-service-permission.md)を参照してください。
* サードパーティモデルサービスのAPIキーを取得済みであること。

## システムパッケージによるモデルとエンドポイントの登録および管理

`DBMS.AI_SERVICE` パッケージは、AIモデルとエンドポイントの管理機能を提供し、以下の操作をサポートします：

| **操作** | **説明** |
| ------ | ------ |
| CREATE_AI_MODEL | AIモデルオブジェクトを作成します。 |
| DROP_AI_MODEL | AIモデルオブジェクトを削除します。 |
| CREATE.AI_MODEL_ENDPOINT | AIモデルサービスエンドポイントオブジェクトを作成します。 |
| ALTER_AI_MODEL_ENDPOINT | AIモデルサービスエンドポイントオブジェクトを変更します。 |
| DROP_AI_MODEL_ENDPOINT | AIモデルサービスエンドポイントオブジェクトを削除します。 |

このシステムパッケージを呼び出すことで、seekdb内部で直接AIモデルとエンドポイントを管理でき、外部サービスに依存する必要がありません。詳細なパラメータと構文については、[DBMS_AI_SERVICE](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018307) パッケージの関連ドキュメントを参照してください。

:::tip
現在サポートされているモデルプロバイダーと対応するURLの詳細情報については、[CREATE_AI_MODEL_ENDPOINT](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004479800) を参照してください。
:::

## モデルとエンドポイントテンプレートの登録

`CREATE_AI_MODEL` を使用してモデルを登録し、次に `CREATE.AI_MODEL_ENDPOINT` を使用してそのモデルのアクセスエンドポイントを登録します。以下の例では、テキスト生成（`AI_COMPLETE`）、ベクトル埋め込み（`AI_EMBED`）、および再ランキング（`AI_RERANK`）にそれぞれ対応する3つのモデルキー `ob_complete`、`ob_embed`、`ob_rerank` を登録します。`access_key` は実際のAPI Keyに置き換えてください。

:::info

特定の種類のAI関数のみを使用する場合は、対応するモデルとエンドポイントのみを登録すれば十分です。例えば、`AI_COMPLETE` のみを使用する場合は、以下の「テキスト生成モデルとエンドポイントの登録」の手順を実行するだけで済みます。

:::

## モデルとエンドポイント情報の確認

seekdbでは、ビューを通じてAIモデルとエンドポイントの情報を確認できます。

| ビュー | 説明 |
|-----|------|
| [CDB/DBA_OB_AI_MODELS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018318) | AIモデル情報を表示します。 |
| [CDB/DBA_OB_AI_MODEL_ENDPOINTS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018317) | AIモデルエンドポイント情報を表示します。 |
