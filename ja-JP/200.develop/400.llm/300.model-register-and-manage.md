# モデルの登録と管理

このドキュメントでは、seekdbにAIモデルおよびエンドポイントを登録し、管理する方法について説明します。

## システムパッケージによるモデルとエンドポイントの登録と管理

`DBMS.AI_SERVICE` パッケージは、AIモデルとエンドポイントの管理機能を提供し、以下の操作をサポートしています：

| **操作** | **説明** |
| ------ | ------ |
| CREATE_AI_MODEL | AIモデルオブジェクトを作成します。 |
| DROP_AI_MODEL | AIモデルオブジェクトを削除します。 |
| CREATE_AI_MODEL_ENDPOINT | AIモデルサービスエンドポイントオブジェクトを作成します。 |
| ALTER.AI_MODEL_ENDPOINT | AIモデルサービスエンドポイントオブジェクトを変更します。 |
| DROP_AI_MODEL_ENDPOINT | AIモデルサービスエンドポイントオブジェクトを削除します。 |

このシステムパッケージを呼び出すことで、外部サービスに依存することなく、seekdb内部で直接AIモデルとエンドポイントを管理できます。詳細なパラメータと構文については、[DBMS_AI_SERVICE](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018307) パッケージの関連ドキュメントを参照してください。

:::tip
現在サポートされているモデルベンダーと対応するURLの詳細情報については、[CREATE_AI_MODEL_ENDPOINT](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004479800) を参照してください。
:::

## モデルとエンドポイント情報の確認

seekdbは、ビューを通じてAIモデルとエンドポイントの情報を確認できるようにしています：

| ビュー | 説明 |
|-----|------|
| [CDB/DBA_OB_AI_MODELS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018318) | AIモデル情報を表示します。 |
| [CDB/DBA_OB_AI_MODEL_ENDPOINTS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018317) | AIモデルエンドポイント情報を表示します。 |
