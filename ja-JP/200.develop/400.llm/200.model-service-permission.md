# モデル権限管理

AI MODEL関連権限は、AIモデルを管理するために使用され、`CREATE AI MODEL`、`ALTER AI MODEL`、`DROP AI MODEL` の3つの権限が含まれます。このドキュメントでは、AI MODEL関連権限について説明します。

## AI関数呼び出し権限との関係

`AI MODEL` 関連権限は、AIモデルおよびエンドポイントの登録と管理に使用されます。一方、`ACCESS AI MODEL` 関連権限はSQLでAI関数を呼び出すために使用されます。モデルやエンドポイントの登録・管理を行う際には `AI MODEL` 権限のみが必要であり、`ACCESS AI MODEL` 権限は不要です。しかし、SQLでAI関数を正常に呼び出すには、モデルとエンドポイントの登録（`AI MODEL` 権限が必要）が完了していることに加えて、`ACCESS AI MODEL` 呼び出し権限も必要です。つまり、**モデル登録とAI関数の呼び出しはそれぞれ異なる権限に対応しており、実際のシナリオでは通常両方の権限が同時に必要となります**。

## 構文

権限付与の構文は以下のとおりです：

```sql
-- AIモデル作成権限の付与
GRANT CREATE AI MODEL ON *.* TO 'username'@'host';

-- AIモデル変更権限の付与
GRANT ALTER AI MODEL ON *.* TO 'username'@'host';

-- AIモデル削除権限の付与
GRANT DROP AI MODEL ON *.* TO 'username'@'host';

GRANT CREATE AI MODEL, ALTER AI MODEL, DROP AI MODEL ON *.* TO 'username'@'host';
```

権限の取り消し構文は以下のとおりです：

```sql
-- AIモデル作成権限の取り消し
REVOKE CREATE AI MODEL ON *.* FROM 'username'@'host';

-- AIモデル変更権限の取り消し
REVOKE ALTER AI MODEL ON *.* FROM 'username'@'host';

-- AIモデル削除権限の取り消し
REVOKE DROP AI MODEL ON *.* FROM 'username'@'host';

-- 権限の確認
SHOW GRANTS FOR 'username'@'host';
```

## 例

1. ユーザーの作成

    ```sql
    CREATE USER test_ai_user@'%' IDENTIFIED BY '123456';
    ```

2. test_ai_userユーザーへのログイン

    ```sql
    mysql -h 127.0.0.1 -P 2881 -u test_ai_user -p *** -A -D test;
    ```

3. `CREATE_AI_MODEL_ENDPOINT`プログラムの呼び出し

    ```sql
    CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
        ->   'user_ai_model_endpoint_1', '{
        '>     "ai_model_name": "my_model1",
        '>     "url": "https://https://api.deepseek.com",
        '>     "access_key": "sk-xxxxxxxxxxxx",
        '>     "request_model_name": "deepseek-chat",
        '>     "provider": "deepseek"
        '>   }');
    ```

    `CREATE AI MODEL`権限がないため、エラーが発生します。

    ```shell
    ERROR 42501: Access denied; you need (at least one of) the create ai model endpoint privilege(s) for this operation
    ```

4. `test_ai_user`ユーザーに`CREATE AI MODEL`権限の付与

    ```sql
    GRANT CREATE AI MODEL ON *.* TO test_ai_user@'%';
    ```

5. 権限の確認

    ```sql
    CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
        ->   'user_ai_model_endpoint_1', '{
        '>     "ai_model_name": "my_model1",
        '>     "url": "https://https://api.deepseek.com",
        '>     "access_key": "sk-xxxxxxxxxxxx",
        '>     "request_model_name": "deepseek-caht",
        '>     "provider": "deepseek"
        '>   }');
    ```

    実行は成功しました。
