# MySQLクライアントを使用してseekdbに接続する

このセクションでは、MySQLクライアントを使用してseekdbに接続するための前提条件、接続操作、および例について説明します。

## 前提条件

MySQLクライアントを使用してデータベースに接続する前に、以下の情報を確認してください：

* ローカル環境にMySQLクライアントが正しくインストールされていることを確認してください。seekdbの現在のバージョンでサポートされているMySQLクライアントのバージョンは、V5.5、V5.6、V5.7です。

* 環境変数`PATH`に、MySQLクライアントコマンドが存在するディレクトリが含まれていることを確認してください。

* インスタンスに接続する前に、現在のクライアントがインスタンスのホワイトリストに含まれていることを確認してください。ホワイトリストの設定については、[ネットワークセキュリティアクセス制御](../../../400.guides/500.manage/300.security/300.access-control/300.network-security-access-control.md)を参照してください。

## 接続操作

MySQLクライアントコマンドを使用してseekdbに接続する形式は次のとおりです：

```shell
mysql -h$host -P$port -u$user_name -p****** [-c] [-A] [$database_name]
```

**パラメータ説明：**

* `-h`：seekdbの接続IPを指定します。`$host`は実際のIPに置き換えてください。ローカルIPや127.0.0.1も使用できます。
* `-P`：seekdbの接続ポートを指定します。`$port`は実際のポート番号に置き換えてください。デフォルトは2881ですが、seekdbのデプロイ時にカスタマイズ可能です。
* `-u`：seekdbの接続アカウントを指定します。`$user_name`の形式は`ユーザー名`です。インスタンスのデフォルトユーザー名は`root`です。
* `-p`: seekdbへの接続パスワードを指定します。`******`は実際のパスワード文字列に置き換えてください。

   :::info

   セキュリティ上の理由から、特にスクリプトや履歴が参照可能な環境では、コマンドラインに直接パスワードを入力することは推奨されません。このオプションを省略し、プロンプトが表示されたときにパスワードを入力することをお勧めします。

   :::

* `-c`：オプションです。MySQLの実行環境でコメントを無視しないことを意味します。

   :::info

   Hintは特殊なコメントであり、`-c`の影響を受けません。

   :::

* `-A`: オプションです。MySQLがデータベースに接続する際に統計情報を自動取得しないことを意味します。
* `$database_name`：オプションです。seekdbに接続した後に使用するデフォルトのデータベースを指定します。指定しない場合、デフォルトではどのデータベースにも直接入らず、接続後に手動で選択する必要があります。

**例：**

```shell
mysql -h127.0.0.1 -uroot -P2881 -p****** -c -A test
```

## 接続例

1. コマンドラインターミナルを開きます。
2. MySQLクライアントを使用してseekdbに直接接続します。

   ```shell
   mysql -hxxx.xx.xxx.xxx -P2881 -uroot -p****** -A test
   ```

   実行結果は次のとおりです：

   ```shell
   Welcome to the MariaDB monitor.  Commands end with ; or \g.
   Your MySQL connection id is 3221614856
   Server version: 5.7.25 OceanBase 4.3.5.3 SeekDB (r1.0.0.0) (Built 100000262025111218-5343637512e28c346f938516af53b7879d4d5974 Nov 12 2025)

   Copyright (c) 2000, 2018, Oracle, MariaDB Corporation Ab and others.

   Type 'help;' or '\h' for help. Type '\c' to clear the current input statement.

   MySQL [(test)]>
   ```

3. MySQLコマンドラインを終了する必要がある場合は、`exit`と入力してEnterキーを押すか、**Ctrl** + **D** のショートカットキーを押します。

## 詳細を見る

MySQLクライアントを使用してseekdbに接続する際に問題が発生した場合は、MySQLクライアントの公式ドキュメントを参照することをお勧めします。
