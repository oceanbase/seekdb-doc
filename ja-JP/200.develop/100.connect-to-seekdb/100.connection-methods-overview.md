# 接続方法の概要

このセクションでは、seekdbへの接続およびアクセス方法について説明します。現在、主にクライアント、ドライバー、ORMフレームワーク、または接続プールを介してseekdbに接続することができます。

## クライアントを選択してseekdbに接続する

seekdbに接続する際、サポートされているクライアントは以下のとおりです：

* MySQLクライアント（mysql）

  mysqlはMySQLデータベースのコマンドラインクライアントであり、別途インストールが必要です。

  seekdbに接続後、mysqlのコマンドライン環境で、mysqlの運用コマンドやSQLステートメントを実行し、以下のタスクを実行できます：

  * クエリ結果の計算、保存、出力。

  * データベースオブジェクトの作成、オブジェクト定義の確認と変更。

  * データベース管理やパラメータの変更など。

  MySQLクライアントを使用してseekdbに接続する具体的な操作例については、[MySQLクライアントを使用してseekdbに接続する](200.use-client-connect-seekdb/100.connect-to-seekdb-by-using-a-mysql-client.md)を参照してください。

## ドライバまたはORMフレームワークを使用してseekdbに接続する

### C

* Cドライバー(OceanBase Connector/C)

  OceanBase Connector/Cは、C/C++ベースのOceanBaseクライアント開発コンポーネントであり、C API Libライブラリをサポートしています。

  OceanBase Connector/Cにより、C/C++プログラムは比較的低レベルな方法でseekdbにアクセスし、データベース接続、データアクセス、エラー処理、およびプリペアドステートメント処理などの操作を実行できます。

  OceanBase Connector/CはLibOBClientとも呼ばれ、アプリケーションが独立したサーバープロセスとしてネットワーク接続を介してデータベースサーバーseekdbノードと通信するために使用されます。クライアントプログラムはコンパイル時にC APIヘッダーファイルを参照し、同時にC APIライブラリファイルに接続できます。

  :::info

  LibOBClientが生成するsoファイルは`libobclient.so`です(MySQLの`libmysqlclient.so`に対応)。

  :::

  Cアプリケーションを使用してseekdbに接続する具体的な操作例については、[MySQL Connector/Cによるseekdb接続サンプルプログラム](300.sample-program/300.c/100.connect-to-the-seekdb-through-mysql-connector-c.md)を参照してください。

### Golang

* Golangドライバー

  * Go-SQL-Driver/MySQL

    Go-SQL-Driver/MySQLは、Go言語で実装されたMySQLドライバーであり、Goのdatabase/sql標準インターフェースに準拠しており、Goアプリケーションとの統合が容易です。Go-SQL-Driver/MySQLを使用してアプリケーションからseekdbに接続する具体的な操作例については、[Go-SQL-Driver/MySQLによるseekdb接続サンプルプログラム](300.sample-program/400.go/100.go-sql-driver-mysql-connection-seekdb-sample-program.md)を参照してください。

* Golang ORM

  * GORM

    GORMは、Go言語向けの優れたORM（オブジェクト関係マッピング）ライブラリであり、豊富な機能を提供し、開発者がデータベースとのやり取りをより容易に行えるよう支援します。GORMを使用してseekdbに接続する具体的な操作例については、[GORMによるseekdb接続サンプルプログラム](300.sample-program/400.go/200.gorm-connection-seekdb-example-program.md)を参照してください。

### PHP

* PHPドライバー

  * EXT

    EXT（PHP Extension）は、PHPの拡張機能であり、さまざまなデータベースへの接続とやり取りを可能にします。開発者がデータベースをより効果的に操作し、データを処理できるようにするための多様な機能を提供します。EXTを使用してseekdbに接続する具体的な操作例については、[EXTドライバーでseekdbに接続するサンプルプログラム](300.sample-program/500.php/100.ext-driver-connects-to-seekdb.md)を参照してください。

  * MySQLi

    MySQLi（MySQL Improved）は、PHPが公式に提供する拡張機能であり、MySQLデータベースとのやり取りに使用されます。オブジェクト指向および手続き型のプログラミングをサポートし、プリペアドステートメント、トランザクションサポート、複数クエリなどの機能を備え、パフォーマンスとセキュリティの向上を目指しています。MySQLiを使用してseekdbに接続する具体的な操作例については、[MySQLiドライバーを使用してseekdbに接続する](300.sample-program/500.php/200.use-mysqli-driver-to-connect-seekdb.md)を参照してください。

  * PDO

    PDO（PHP Data Objects）は、データベースアクセス抽象化レイヤーであり、開発者が統一された方法でさまざまなデータベースとやり取りできるようにします。PDOはプリペアドステートメントをサポートしており、セキュリティの向上に寄与するとともに、異なるデータベース間でのコード移行を容易にします。PDOを使用してseekdbに接続する具体的な操作例については、[PDOドライバーを使用してseekdbに接続する](300.sample-program/500.php/300.use-pdo-driver-to-connect-seekdb.md)を参照してください。

### Python

* Pythonドライバー（PyMySQL）

  * PyMySQL

    PyMySQLは、Python3.xバージョンでMySQLサーバーに接続するためのライブラリです。PythonデータベースAPI v2.0仕様に準拠しており、pure-Python MySQLクライアントライブラリを含んでいます。seekdbでは、ユーザーはPyMySQLドライバーを使用して、Pythonアプリケーションとseekdbとの接続を提供できます。Pythonアプリケーションを使用してseekdbに接続する具体的な操作例については、[PyMySQLによるseekdb接続サンプルプログラム](300.sample-program/200.python/200.pymysql-connection-to-seekdb-sample-program.md)を参照してください。

  * mysqlclient

    mysqlclientは、MySQLデータベースのPythonクライアントライブラリであり、MySQL公式C APIのカプセル化です。mysqlclientアプリケーションを使用してseekdbに接続する具体的な操作例については、[mysqlclientによるseekdb接続サンプルプログラム](300.sample-program/200.python/100.mysqlclient-connection-to-seekdb-sample-program.md)を参照してください。

  * MySQL-connector-python

    MySQL-connector-pythonは、Oracleが公式に提供するPython専用のMySQLデータベースドライバーです。PythonデータベースAPI v2.0仕様に準拠し、PythonコードからMySQLデータベースとやり取りするための完全な機能セットを提供します。このライブラリはクロスプラットフォームで、Python 2と3をサポートしており、純粋なPython実装であるため外部ライブラリに依存しません。seekdbでは、MySQL-connector-pythonもseekdbへの接続の確立、クエリの実行、データの管理に使用できます。MySQL-connector-pythonアプリケーションを使用してseekdbに接続する具体的な操作例については、[MySQL-connector-pythonによるseekdb接続サンプルプログラムの作成](300.sample-program/200.python/300.mysql-connector-py-connection-to-seekdb-sample-program.md)を参照してください。
