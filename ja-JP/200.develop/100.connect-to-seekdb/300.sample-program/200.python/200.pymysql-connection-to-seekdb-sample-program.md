# PyMySQL 接続 seekdb サンプルプログラム

本記事では、PyMySQLライブラリとseekdbを使用してアプリケーションを構築し、テーブルの作成、データの挿入、データのクエリ、テーブルの削除など、基本的なデータベース操作を実現する方法について説明します。

[python-pymysql サンプルプロジェクトをダウンロード](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/observer-enterprise/V4.2.0/3.develop/demo/python/python-pymysql.zip)

## 前提条件

* Python 3.xとpipがインストール済みであること。
* seekdbがインストール済みであること。

## 手順

1. `Python` と `pip` のバージョンを確認します。
2. PyMySQLライブラリをインストールします。
3. seekdbの接続情報を取得します。
4. `config.py` ファイル内のデータベース接続情報を修正します。
5. `main.py` ファイルを実行します。

### ステップ１：Pythonとpipのバージョンを確認する

コマンドプロンプトまたはPowerShellターミナルを開き、`python --version` と `pip --version` コマンドを実行して、Pythonとpipが正常にインストールされていることを確認します。

**例：**

```shell
PS C:\Windows\system32> python --version
Python 3.7.0
PS C:\Windows\system32> pip --version
pip 22.3.1 from d:\python\python37\lib\site-packages\pip (python 3.7)
```

### ステップ2：PyMySQLライブラリをインストールする

PyMySQLは、純粋なPythonで実装されたMySQLクライアントライブラリです。インストールが簡単でコンパイルも不要であり、クロスプラットフォームでの互換性に優れています。MySQLデータベースとやり取りするためのインターフェースを提供し、Python 3.x系をサポートしています。

コマンドプロンプトまたはPowerShellターミナルを開き、以下のコマンドを実行してPyMySQLライブラリをインストールします。

1. 以下のコマンドを実行して、コードの `python-pymysql` ディレクトリに移動します。

    **例：**

    ```shell
    cd python-pymysql
    ```

2. 以下のコマンドを実行して、プロジェクトに必要なPythonライブラリをインストールします。

    **例：**

    ```shell
    pip install -r requirements.txt
    ```

:::info

コマンドプロンプトまたはPowerShellターミナルを直接開き、`pip install pymysql` コマンドを実行してPyMySQLライブラリをインストールすることもできます。PyMySQLは純粋なPythonで実装されたライブラリで、インストールが簡単でコンパイルも不要であり、開発環境やテスト環境での使用に適しています。

:::

### ステップ3：seekdb接続情報を取得する

seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。

```shell
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレス。実際のIPアドレスに置き換えてください。ローカルIPアドレスや127.0.0.1を使用することも可能です。
* `$port`：seekdbの接続ポート。実際のポート番号に置き換えてください。デフォルトは2881ですが、seekdbのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセス対象のデータベース名。
* `$user_name`：接続アカウント。形式：`ユーザー名`。
* `$password`：アカウントのパスワード。

接続文字列の詳細については、[MySQLクライアントを使用したseekdbへの接続](../../200.use-client-connect-seekdb/100.connect-to-seekdb-by-using-a-mysql-client.md)を参照してください。

**例：**

```shell
mysql -hxxx.xxx.xxx.xxx -P2881 -uroot -p****** -Dtest
```

### ステップ4：config.pyファイル内のデータベース接続情報を修正する

**ステップ3：seekdb接続情報を取得する** の情報に基づいて、プロジェクトファイル `python-pymysql/config.py` 内のデータベース接続情報を修正します。

1. `python-pymysql` プロジェクトフォルダに移動します。

2. `config.py` ファイル内のデータベース接続情報を修正します。

   * Windows環境では、テキストエディタを使用して `config.py` ファイルを開き、ファイル内のデータベース接続情報を修正し、実際の状況と一致させます。
   * Linux環境では、`vi config.py` または `vim config.py` コマンドを使用して `config.py` ファイルを編集し、ファイル内のデータベース接続情報を修正し、実際の状況と一致させます。

   **`config.py` ファイル内のデータベース接続情報の例：**

   ```python
   DB_CONFIG = {
       'host': '10.10.10.1',
       'port': 2881,
       'user': 'root',
       'password': '******',
       'database': 'test',
       'charset': 'utf8mb4'
   }
   ```

### config.pyコードの紹介

本記事で取得した`config.py`ファイル内のコードは、データベース接続情報を定義しています。データベース接続情報には主に以下の部分が含まれます：

データベースに接続するためのIPアドレス、ポート番号、ユーザー名、パスワード、データベース名、文字セットを指定します。

**コード：**

```python
DB_CONFIG = {
    'host': '$host',
    'port': $port,
    'user': '$user_name',
    'password': '$password',
    'database': '$database_name',
    'charset': 'utf8mb4'
}
```

**パラメータの説明：**

* `$host`：seekdbへの接続IPアドレス。実際のIPアドレスに置き換えてください。ローカルIPアドレスや127.0.0.1も使用できます。
* `$port`：seekdbの接続ポート。実際のポート番号に置き換えてください。デフォルトは2881ですが、seekdbのデプロイ時にカスタマイズ可能です。
* `$user_name`：データベースに接続するためのユーザー名。
* `$password`：データベースに接続するためのパスワード。
* `$database_name`：接続するデータベース名。
* `charset`：データベース接続時に使用する文字セット。

    :::tip

    ここでのパラメータ値は、具体的な環境とデータベース設定に基づいて決定されるため、実際の状況に応じて修正する必要があります。

    :::

### test_sql.pyコードの紹介

本記事で取得した `test_sql.py` ファイル内のコードは、テーブルの作成、データの挿入、データのクエリ、テーブルの削除を含むデータベース操作のSQLステートメントを定義しています。これらのSQLステートメントは、PyMySQLでデータベースに接続した後に実行することで、対応する機能を実現できます。

このファイル内のコードは、主に以下の部分で構成されています：

1. テーブルを作成するSQLステートメント。

    テーブル `test_pymysql` を作成するSQLステートメントを定義します。テーブルには `id`、`name`、`age` の3つのフィールドを定義し、`id` は自動インクリメントの主キーです。

    **コード：**

    ```python
    CREATE_TABLE_SQL = '''
    CREATE TABLE test_pymysql (
    id INT(11) NOT NULL AUTO_INCREMENT,
    name VARCHAR(128) NOT NULL,
    age INT(11) NOT NULL,
    PRIMARY KEY (id)
    )
    '''
    ```

2. データを挿入するSQLステートメント。

    `test_pymysql` テーブルにデータを挿入するSQLステートメントを定義します。挿入するデータは3行で、各行には `name` と `age` の2つのフィールドが含まれます。各フィールドの値は、SQLステートメントを実行する際にプレースホルダー `%s` を通じて渡されます。

    **コード：**

    ```python

    '''
    ```

3. データをクエリするSQLステートメント。

    **コード：**

    ```python

    '''
    ```

4. テーブルを削除するSQLステートメント。

    テーブルを削除するSQLステートメントを定義し、`test_pymysql` テーブルを削除します。

    **コード：**


### main.pyコードの紹介

本記事で取得した `main.py` ファイル内のコードは、`pymysql` モジュールを呼び出してMySQLデータベースに接続し、`logging` モジュールを呼び出してログ情報を出力することで、テーブルの作成、データの挿入、データのクエリ、テーブルの削除の操作を実現します。

`main.py` ファイル内のコードは、主に以下の部分で構成されています：

1. 必要なモジュールをインポートします。

    1. `logging` モジュールをインポートします。
    2. `pymysql` モジュールをインポートします。
    3. データベース接続情報を定義した `config.py` モジュールをインポートします。
    4. データベース操作のSQLステートメントを定義した `test_sql.py` モジュールをインポートします。

    **コード：**

    ```python
    import logging
    import pymysql
    from config import DB_CONFIG
    from test_sql import CREATE_TABLE_SQL, INSERT_DATA_SQL, SELECT_DATA_SQL, DROP_TABLE_SQL
    ```

2. ログ記録のレベルと形式を設定し、INFOレベルのログ情報を出力して、スクリプトの実行開始を示します。

    **コード：**

    ```python
    logging.basicConfig(level=logging.INFO, format='%(asctime)s - %(levelname)s - %(message)s')
    logging.info('Start executing the script')
    ```

3. テーブルを作成する関数を定義します。

    `create_table()` という名前の関数を定義し、INFOレベルのログ情報を出力して、テーブルの作成開始を示します。`with` ステートメントを使用してデータベース接続とカーソルオブジェクトのライフサイクルを管理することで、データベース接続とカーソルオブジェクトの安全なクローズを保証し、メモリリークなどの問題を回避します。テーブル作成のSQLステートメントを実行し、トランザクションをコミットしてログ情報を出力するか、トランザクションをロールバックしてエラーログ情報を出力します。

    **コード：**

    ```python
    def create_table():
        logging.info('Start creating the table')
        with pymysql.connect(**DB_CONFIG) as conn:
            with conn.cursor() as cursor:
                try:
                    cursor.execute(CREATE_TABLE_SQL)
                    conn.commit()
                    logging.info('Table creation successful')
                except Exception as e:
                    conn.rollback()
                    logging.error('Table creation failed, Reason：%s' % e)
    ```

4. データを挿入する関数を定義します。

    `insert_data()` という名前の関数を定義し、INFOレベルのログ情報を出力して、データの挿入開始を示します。`with` ステートメントを使用してデータベース接続とカーソルオブジェクトのライフサイクルを管理することで、データベース接続とカーソルオブジェクトの安全なクローズを保証し、メモリリークなどの問題を回避します。データ挿入のSQLステートメントを実行し、トランザクションをコミットしてログ情報を出力するか、トランザクションをロールバックしてエラーログ情報を出力します。

    **コード：**

    ```python
    def insert_data():
        logging.info('Start inserting data')
        with pymysql.connect(**DB_CONFIG) as conn:
            with conn.cursor() as cursor:
                try:
                    data = [('John', 20), ('Lucy', 25), ('Tom', 30)]
                    flattened_data = [d for item in data for d in item]
                    cursor.executemany(INSERT_DATA_SQL, [flattened_data])
                    conn.commit()
                    logging.info('Data insertion successful')
                except Exception as e:
                    conn.rollback()
                    logging.error('Data insertion failed, Reason：%s' % e)
    ```

5. データをクエリする関数を定義します。

    `select_data()` という名前の関数を定義し、データベースからデータをクエリするために使用します。`with` ステートメントを使用してデータベース接続とカーソルオブジェクトのライフサイクルを管理することで、データベース接続とカーソルオブジェクトの安全なクローズを保証し、メモリリークなどの問題を回避します。`execute()` メソッドを使用して `SELECT_DATA_SQL` で定義されたSQLステートメントを実行してデータをクエリします。`fetchall()` メソッドを使用してクエリ結果を取得し、`for` ループを使用して結果を行ごとに出力します。

    **コード：**

    ```python
    def select_data():
        with pymysql.connect(**DB_CONFIG) as conn:
            with conn.cursor() as cursor:
                cursor.execute(SELECT_DATA_SQL)
                result = cursor.fetchall()
                for row in result:
                    print(row)
    ```

6. テーブルを削除する関数を定義します。

    `drop_table()` という名前の関数を定義します。この関数は、事前に定義されたデータベース接続情報（`DB_CONFIG`）とテーブル削除のSQLステートメント（`DROP_TABLE_SQL`）を使用します。関数はテーブル削除操作を実行し、操作の成功または失敗を示す対応するログ情報を出力します。テーブル削除操作が失敗した場合、エラー情報を出力します。

    **コード：**

    ```python
    def drop_table():
        logging.info('Start dropping the table')
        with pymysql.connect(**DB_CONFIG) as conn:
            with conn.cursor() as cursor:
                try:
                    cursor.execute(DROP_TABLE_SQL)
                    conn.commit()
                    logging.info('Table dropped successfully')
                except Exception as e:
                    conn.rollback()
                    logging.error('Table drop failed, Reason：%s' % e)
    ```

7. プログラムのエントリポイントを定義します。これは主にデータベース操作を実行する関数です。

    まず、現在のモジュールがメインプログラムとして実行されているかどうかを判断します。もしそうであれば、以下の操作を実行します：

    1. `create_table()` 関数を呼び出して、データベーステーブルを作成します。
    2. `insert_data()` 関数を呼び出して、テーブルにデータを挿入します。
    3. `select_data()` 関数を呼び出して、テーブルからデータをクエリします。
    4. `drop_table()` 関数を呼び出して、データベーステーブルを削除します。

    **コード：**

    ```python
    if __name__ == '__main__':
        create_table()
        insert_data()
        select_data()
        drop_table()
    ```

8. スクリプトの実行完了を示すINFOレベルのログ情報を出力します。

    **コード：**

    ```python
    logging.info('Script execution completed')
    ```

## エラー処理

PyMySQLを使用してseekdbに接続する際、さまざまなエラーが発生する可能性があります。以下は一般的なエラーとその対処方法です：

1. **接続エラー**：データベースに接続できない場合は、ホスト名、ポート、ユーザー名、パスワード、データベース名を含む接続パラメータが正しいかどうか確認してください。

2. **権限エラー**：権限に関連するエラーが発生した場合は、ユーザーが必要な操作を実行するための十分な権限を持っていることを確認してください。

3. **SQL構文エラー**：SQLステートメントに構文エラーがある場合は、SQLステートメントの構文が正しいかどうか確認してください。

4. **データ型エラー**：挿入したデータ型がテーブル定義とマッチしない場合は、挿入したデータ型が正しいことを確認してください。

コード内では、`try-except` ステートメントを使用してこれらのエラーをキャッチし、処理することで、エラー発生時にプログラムがクラッシュすることなく適切に対処できるようにします。同時に、`logging` モジュールを使用してエラー情報を記録し、デバッグや問題の調査を容易にします。
