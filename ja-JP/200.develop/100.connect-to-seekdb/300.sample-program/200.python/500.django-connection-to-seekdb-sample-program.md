# Djangoでseekdbに接続するサンプルプログラム

本記事では、Djangoを使用してseekdbに接続し、テーブルの作成、データの挿入、更新、クエリなどの基本的なデータベース操作を実装する方法を紹介します。

## 前提条件

* Python 3.xとpipがインストール済みであること。
* seekdbがインストール済みであること。

## 手順

1. seekdb接続文字列を取得します。
2. DjangoとMySQLクライアントライブラリをインストールします。
3. Djangoプロジェクトとアプリケーションを作成します。
4. データベース接続を設定します。
5. モデルを作成します。
6. 移行を実行します。
7. ビューとURLの設定を作成します。
8. 開発サーバーを起動します。

### ステップ１：seekdb接続文字列を取得する

seekdbのデプロイ担当者または管理者から、該当するデータベース接続文字列を取得します。

```shell
mysql -h$host -P$port -u$user_name -p$password -D$database_name
```

**パラメータ説明：**

* `$host`：seekdbへの接続IPアドレス。実際のIPに置き換えてください。ローカルIPや127.0.0.1も使用できます。
* `$port`：seekdbの接続ポート。実際のポート番号に置き換えてください。デフォルトは2881ですが、seekdbのデプロイ時にカスタマイズ可能です。
* `$database_name`：アクセスするデータベース名。
* `$user_name`：接続アカウント。形式：`ユーザー名`。
* `$password`：アカウントのパスワード。

接続文字列の詳細については、[MySQLクライアントを使用してseekdbに接続する](../../200.use-client-connect-seekdb/100.connect-to-seekdb-by-using-a-mysql-client.md)を参照してください。

**例：**

```shell
mysql -hxxx.xxx.xxx.xxx -P2881 -uroot -p****** -Dtest
```

### ステップ2：DjangoとMySQLクライアントライブラリをインストールする

Djangoは高度なPython Webフレームワークであり、ORM（オブジェクト関係マッピング）システムを提供し、データベース操作を簡素化できます。Djangoは、MySQL、PostgreSQL、SQLiteなど、さまざまなデータベースバックエンドをサポートしています。

コマンドプロンプトまたはPowerShellターミナルを開き、以下のコマンドを実行して、DjangoとMySQLクライアントライブラリをインストールします。

```shell
pip install django mysqlclient
```

インストール完了後、以下のコマンドでインストールが成功したかどうか確認できます：

```shell
pip list | grep -i django
```

:::info

Djangoは強力なWebフレームワークであり、ORMシステムを提供し、データベース操作を簡素化できます。DjangoのORMシステムは、MySQL、PostgreSQL、SQLiteなど、さまざまなデータベースバックエンドをサポートしています。

:::

### ステップ3：Djangoプロジェクトとアプリケーションを作成する

1. `seekdb_demo` という名前のDjangoプロジェクトを作成します。

    ```shell
    django-admin startproject seekdb_demo
    ```

2. プロジェクトのディレクトリに移動します。

    ```shell
    cd seekdb_demo
    ```

3. `users` という名前のアプリケーションを作成します。

    ```shell
    python manage.py startapp users
    ```

### ステップ4：データベース接続を設定する

1. `seekdb_demo/settings.py` ファイルを開き、データベース設定を変更します。

    ```python
    DATABASES = {
        'default': {
            'ENGINE': 'django.db.backends.mysql',
            'NAME': 'test',
            'USER': 'root',
            'PASSWORD': '******',
            'HOST': 'xxx.xxx.xxx.xxx',
            'PORT': '2881',
            'OPTIONS': {
                'charset': 'utf8mb4',
            },
        }
    }
    ```

2. `INSTALLED_APPS` に `users` アプリケーションを追加します。

    ```python
    INSTALLED_APPS = [
        'django.contrib.admin',
        'django.contrib.auth',
        'django.contrib.contenttypes',
        'django.contrib.sessions',
        'django.contrib.messages',
        'django.contrib.staticfiles',
        'users',
    ]
    ```

### ステップ5：モデルを作成する

1. `users/models.py` ファイルを開き、`User` モデルを作成します。

    ```python
    from django.db import models

    class User(models.Model):
        name = models.CharField(max_length=50)
        age = models.IntegerField()

        def __str__(self):
            return f"{self.name} ({self.age})"
    ```

### ステップ6：マイグレーションを実行する

1. マイグレーションファイルを作成します。

    ```shell
    python manage.py makemigrations
    ```

2. マイグレーションを適用します。

    ```shell
    python manage.py migrate
    ```

### ステップ7：ビューとURLの設定を作成する

1. `users/views.py` ファイルを開き、ビュー関数を作成します。

    ```python
    from django.shortcuts import render
    from django.http import HttpResponse
    from .models import User

    def index(request):
        # データの挿入
        User.objects.create(name='John', age=20)
        User.objects.create(name='Lucy', age=25)
        User.objects.create(name='Tom', age=30)

        # データの更新
        user = User.objects.get(name='Lucy')
        user.age = 26
        user.save()

        # データのクエリ
        users = User.objects.all()
        result = "<h1>Users</h1><ul>"
        for user in users:
            result += f"<li>{user}</li>"
        result += "</ul>"

        return HttpResponse(result)
    ```

2. `seekdb_demo/urls.py` ファイルを開き、URLを設定します。

    ```python
    from django.contrib import admin
    from django.urls import path
    from users import views

    urlpatterns = [
        path('admin/', admin.site.urls),
        path('', views.index, name='index'),
    ]
    ```

### ステップ8：開発サーバーを起動する

1. 開発サーバーを起動します。

    ```shell
    python manage.py runserver
    ```

2. ブラウザで `http://127.0.0.1:8000/` にアクセスして、結果を確認します。

    実行結果は次のとおりです：

    ```html
    <h1>Users</h1>
    <ul>
        <li>John (20)</li>
        <li>Lucy (26)</li>
        <li>Tom (30)</li>
    </ul>
    ```

## エラー処理

Djangoを使用してseekdbに接続する際、さまざまなエラーが発生する可能性があります。以下は一般的なエラーとその対処方法です：

1. **接続エラー**：データベースに接続できない場合は、ホスト名、ポート、ユーザー名、パスワード、データベース名を含む接続パラメータが正しいかどうか確認してください。

2. **権限エラー**：権限に関連するエラーが発生した場合は、ユーザーが必要な操作を実行するために十分な権限を持っていることを確認してください。

3. **SQL構文エラー**：SQLステートメントに構文エラーがある場合は、SQLステートメントの構文が正しいかどうか確認してください。

4. **データ型エラー**：挿入したデータ型がテーブル定義とマッチしない場合は、挿入したデータ型が正しいことを確認してください。

Djangoでは、`try-except` ステートメントを使用してこれらのエラーをキャッチし、処理することで、プログラムがエラーに遭遇した際にクラッシュすることなく適切に対処できるようにします。同時に、Djangoのログシステムを使用してエラー情報を記録することで、デバッグや問題の調査を容易にします。
