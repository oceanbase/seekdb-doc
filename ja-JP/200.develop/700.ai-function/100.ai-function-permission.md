# AI関数呼び出し権限

このドキュメントでは、`ACCESS AI MODEL` モデル呼び出し権限について説明します。`ACCESS AI MODEL` 権限はAI関数を呼び出すために使用され、`AI_COMPLETE`、`AI_EMBED`、`AI_RERANK`、`AI_PROMPT` の4つの関数が含まれます。

## 前提条件

AI関数を呼び出すには、ユーザーが `AI MODEL` 関連の権限を持っていることを確認する必要があります。AIモデルとエンドポイントの登録は `AI MODEL` 関連の権限に依存しているため、対応するAIモデルとエンドポイントを登録してからでないとAI関数を呼び出せません。`AI MODEL` 関連の権限の説明と使用方法については、[モデル権限管理](../400.llm/200.model-service-permission.md)を参照してください。モデルの登録と管理方法については、[モデル登録と管理](../400.llm/300.model-register-and-manage.md)を参照してください。

## 構文

権限付与の構文は次のとおりです：

```sql
GRANT ACCESS AI MODEL ON *.* TO 'username'@'host';
```

権限剥奪の構文は次のとおりです：

```sql
REVOKE ACCESS AI MODEL ON *.* FROM 'username'@'host';
```

## 例

1. `AI_COMPLETE` 関数の呼び出し

    ```sql
    SELECT AI_COMPLETE("ob_complete","あなたは翻訳の達人です。以下のテキストを英語に翻訳してください：{{Hello world.}}。出力は翻訳結果のみを含めてください") as ans;
    ```

    `ACCESS AI MODEL` 権限がないため、エラーが発生します。

    ```shell
    ERROR 42501: Access denied; you need (at least one of) the access ai model endpoint privilege(s) for this operation
    ```

2. `test_ai_user` ユーザーに `ACCESS AI MODEL` 権限の付与

    ```sql
    GRANT ACCESS AI MODEL ON *.* TO test_ai_user@'%';
    ```

3. 権限の検証

    ```sql
    SELECT AI_COMPLETE("ob_complete","あなたは翻訳の達人です。以下のテキストを英語に翻訳してください：{{Hello world.}}。出力は翻訳結果のみを含めてください") as ans;
    ```

    実行は成功しました。

    ```sql
    ```shell
    +----------------+
    | ans            |
    +----------------+
    | "Hello world." |
    +----------------+
    1 row in set
    ```
