# テキスト生成系AI関数

このドキュメントでは、seekdbでサポートされているテキスト生成系AI関数の関連機能について説明します。

AI関数はSQL式を通じて、AIモデルの能力をデータベース内のデータ処理に直接統合します。これにより、AI大規模モデルを用いたデータの抽出、分析、要約、保存などの操作が大幅に簡素化され、現在のデータベースおよびデータウェアハウス分野における重要な新機能となっています。seekdbは`DBMS_AI_SERVICE`パッケージを通じてAIモデルとエンドポイントの管理を提供し、いくつかの組み込みAI関数式を追加しており、ビューを通じてAIモデルの呼び出し状況を監視することもサポートしています。

## 前提条件

* テキスト生成系のAI関数を使用する前に、関連する権限が付与されていることを確認してください。詳細な権限については、[AI関数サービスの権限](100.ai-function-permission.md)を参照してください。
* テキスト生成系のAI関数を使用する前に、AIモデルおよびエンドポイント情報が登録済みであることを確認してください。詳細については、[AIモデル管理](../400.llm/100.model-service-overview.md)を参照してください。

## AI_COMPLETEとAI_PROMPT

`AI_COMPLETE` 関数は、`model_key` で登録済みのテキスト生成大規模言語モデル(LLM)を指定し、ユーザーが提供するプロンプトとデータを処理して、大規模言語モデルが生成したテキスト情報を返します。ユーザーは `prompt` パラメータで、組織のプロンプトとデータベース内のデータ形式をカスタマイズできます。この方法は、テキストデータの多様な処理をサポートするだけでなく、データベース内部でのバッチ処理も可能にし、データベースと大規模言語モデル間でのデータのやり取りによるコピーオーバーヘッドを効果的に回避します。

多くのAIアプリケーションシナリオでは、プロンプトは高度に構造化されており、具体的なデータを動的に挿入する必要があることが多いです。しかし、毎回 `CONCAT` などの関数を使って手動でプロンプトと入力内容を連結すると、開発コストが高くなるだけでなく、誤って書くことで形式上の問題が生じやすいという課題がありました。プロンプトの再利用とプロンプトとデータの動的組み合わせを支援するため、seekdbは `AI_PROMPT` 関数を提供しています。`AI_PROMPT` は、プロンプトを「静的テキスト」から「再利用可能でパラメータ化可能な」関数テンプレートへと昇格させ、`AI_COMPLETE` 内で `prompt` パラメータの代わりに直接使用できるようにします。これにより、プロンプトの構築プロセスが大幅に簡素化され、開発効率と正確性が向上します。

### AI_PROMPT 関数

`AI_PROMPT` 関数は、プロンプトを構築し、フォーマットするために使用され、動的なデータの挿入をサポートします。

#### 構文

`AI_PROMPT` 関数の構文は以下のとおりです：

```sql
AI_PROMPT('template', expr0 [ , expr1, ... ]);
```

パラメータ説明：

| パラメータ | 説明 | 型 | NULL許容 |
|------|------|------|----------|
| template | ユーザーが入力するプロンプトのテンプレートです。 | VARCHAR(max_length) | No |
| expr | ユーザーが入力するデータです。 | VARCHAR(max_length) | No |

パラメータ `template` と `expr` は必須であり、空ではなくする必要があります。ここで、`expr` パラメータは `VARCHAR` 型のみをサポートし、`JSON` 型はサポートしません。

戻り値：

* JSON形式のフォーマット済みプロンプト文字列。

#### 例

`AI_PROMPT` 関数は、テンプレート文字列と動的データをJSON形式で整理します：
* 最初のパラメータ（テンプレート文字列 template）は、返されるJSONの `template` フィールドに配置されます。
* 次のパラメータ（データ値 expr0、expr1、...）は、返されるJSONの `args` アレイに配置されます。
* テンプレート内のプレースホルダー `{0}`、`{1}` などは、インデックスに従って `args` アレイ内のデータに対応し、`AI_COMPLETE` 関数で使用される際に自動的に置き換えられます。

例：

```sql
SELECT AI_PROMPT('Recommend {0} of the most popular {1} to me.', 'ten', 'mobile phones');
```

戻り結果は次のとおりです：

```json
{
  "template": "Recommend {0} of the most popular {1} to me.",
  "args": ["ten", "mobile phones"]
}
```

前の例に基づいて、`AI_COMPLETE` 関数内で `AI_PROMPT` 関数を使用します：

```sql
SELECT AI_COMPLETE("ob_complete",AI_PROMPT('Recommend {0} of the most popular {1} to me.just output name in json array format', 'two', 'mobile phones')) AS ans;
```

戻り結果は次のとおりです：

```json
+--------------------------------------------------+
| ans                                              |
+--------------------------------------------------+
| ["iPhone 15 Pro Max","Samsung Galaxy S24 Ultra"] |
+--------------------------------------------------+
```

### AI_COMPLETE 関数

#### 構文

`AI_COMPLETE` 関数の構文は次のとおりです：

```sql
AI_COMPLETE(model_key, prompt[, parameters])
-- AI_PROMPT 関数を使用する場合は、prompt パラメータを AI_PROMPT 関数に置き換えます。例については AI_PROMPT 関数を参照してください。
AI_COMPLETE(model_key, AI_PROMPT(prompt_template, data))
```

パラメータ説明：

| パラメータ | 説明 | 型 | 空値許容 |
|------|------|------|----------|
| model_key | データベースに登録されたモデル。 | VARCHAR(128) | No |
| prompt | ユーザーが入力するプロンプト情報。 | VARCHAR/TEXT(LONGTEXT) | No |
| parameters | APIで提供されるオプションを設定するために使用されます。モデルのオプションフィールドは、生成されるメッセージボディに直接含まれます。ベンダーによって若干の違いがあります。一般的に、よく見られるオプションには、`temperature`、`top_p`、`max_tokens`があります。通常はデフォルト設定で十分なので、指定する必要はありません。 | JSON | Yes |

`model_key` と `prompt` は必ず指定する必要があります。どちらか一方が `NULL` の場合、関数はエラーを返します。

戻り値：

* text、大規模言語モデルがプロンプトに基づいて生成したテキスト。

#### 例

1. 感情分析の例

    ```sql
    SELECT AI_COMPLETE("ob_complete","あなたのタスクは、提供されたテキストに対して感情分析を行い、その感情の傾向がポジティブかネガティブかを判断することです。
    以下が分析対象のテキストです：
    <text>
    今日は本当にいい天気だね
    </text>
    判断基準は以下のとおりです：
    テキストがポジティブな感情を表現している場合は1を出力し、ネガティブな感情を表現している場合は-1を出力します。他のものは出力しないでください。\n") AS ans;
    ```

    実行結果は次のとおりです：

    ```sql
    +-----+
    | ans |
    +-----+
    | 1   |
    +-----+
    ```

2. 翻訳の例

    ```sql
    CREATE TABLE comments (
        id INT AUTO_INCREMENT PRIMARY KEY,
        content TEXT
    );

    INSERT INTO comments (content) VALUES ('hello world!');

    -- concat 式を使用して処理したデータをデータベースのテーブル列名に置き換えることで、データをデータベースから大規模言語モデルにコピーし、その結果を再びデータベースにコピーする必要なく、データベース内のデータを一括処理できます。
    SELECT AI_COMPLETE("ob_complete",
    concat("あなたは翻訳の達人です。以下の英語を中国語に翻訳してください。以下が翻訳対象のテキストです：<text>",
        content,
        "</text>")) AS ans FROM comments;
    ```
    実行結果は次のとおりです：

    ```sql
    +-------------+
    | ans         |
    +-------------+
    | 你好，世界！  |
    +-------------+
    ```

3. 分類の例

    ```sql
    SELECT AI_COMPLETE("ob_complete","あなたは分類の達人です。一連の質問テキストを受け取り、それらの質問が属するカテゴリを区別する必要があります。カテゴリのリストは[\"ハードウェア部\",\"ソフトウェア部\",\"その他\"]です。以下が分析対象のテキストです：
    <text>
    この画面の品質は本当に悪い
    </text>") AS res;
    ```

    実行結果は次のとおりです：

    ```sql
    +--------+
    | res    |
    +--------+
    | ハードウェア部 |
    +--------+
    ```
