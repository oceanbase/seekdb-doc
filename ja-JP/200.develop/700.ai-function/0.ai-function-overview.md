# AI関数の概要

AI関数サービスは、seekdbが提供するAIのネイティブ機能であり、SQL式を通じてAIモデルの能力をデータベース内のデータ処理に直接統合します。

## 機能構成

AI関数サービスは、以下の部分で構成されています：

| モジュール | 説明 |
|-----|------|
| **権限管理** | `AI_MODEL` 権限と `ACCESS AI MODEL` 権限を含み、それぞれAIモデルの管理とAI関数の呼び出しに使用されます。詳細は [AI関数サービス権限](100.ai-function-permission.md)および [モデル権限管理](../400.llm/200.model-service-permission.md)を参照してください。|
| **モデル管理** | AIモデルとエンドポイントの登録、設定、管理を行います。これはAI関数を呼び出すための前提条件です。詳細は [モデルの登録と管理](../400.llm/300.model-register-and-manage.md)を参照してください。|
| **AI関数** | SQLでAI機能を呼び出すための関数式。`AI_COMPLETE`、`AI_EMBED`、`AI_RERANK`、`AI_PROMPT` などの関数が含まれます。|

:::tip
AI関数呼び出しサービスを使用する前に、AIモデルとエンドポイント情報が登録済みであることを確認してください。
:::

現在、seekdbがサポートするAI関数式は以下のとおりです：

| 名前 | 説明 |
|-----|------|
|`AI_COMPLETE`|指定されたテキストを呼び出して大規模言語モデルを生成し、プロンプトとデータ情報を処理し、処理結果を解析します。詳細については、[テキスト生成AI関数](200.text-generation-function.md)を参照してください。|
| `AI_PROMPT` |プロンプトの構築とフォーマットに使用され、動的なデータ挿入をサポートします。詳細については、[テキスト生成AI関数](200.text-generation-function.md)を参照してください。|
|`AI_EMBED`|埋め込みモデル(Embedding Model)を呼び出して、テキストデータをベクトルデータに変換します。詳細については、[AI_EMBED 関数の使用](../500.vector-embedding/200.ai-embed-function.md)を参照してください。|
|`AI_RERANK`|再ランキングモデル(Rerank Model)を呼び出して、プロンプトに基づいてテキストの類似度をソートします。詳細については、[再ランキング検索](../600.search/600.ai-rerank.md)を参照してください。|

AI関数サービスの利用手順：

1. ユーザーにAIモデルの管理とAI関数の呼び出し権限を付与します。
2. AIモデルとエンドポイントを登録します。
3. SQLでAI関数を呼び出します。
