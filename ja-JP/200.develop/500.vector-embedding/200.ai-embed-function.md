# AI_EMBED 関数の使用

このドキュメントでは、AI関数サービスの `AI_EMBED` 関数を使用して、seekdbにテキスト生成ベクトル埋め込みを行う方法について説明します。

## 概要

:::tip
AI_EMBED 関数は現在、テキストデータからのベクトル埋め込みの生成のみをサポートしています。
:::

:::tip
ハイブリッド検索（Hybrid Search）は、AI モデル管理と AI_EMBED 関数の機能に依存しています。AI モデルを削除する際は、潜在的な問題を避けるために、それがハイブリッド検索で参照されていないか確認する必要があります。
:::

seekdb は、AI 関数サービスの `AI_EMBED` 関数を使用してベクトル埋め込みを生成することをサポートしています。ユーザーは追加の依存関係をインストールする必要はなく、モデル情報を登録すれば、seekdb 内で AI 関数サービスを利用してベクトル埋め込みを生成できます。

`AI_EMBED` 関数は、`model_key` を使用して登録済みの埋め込みモデル（Embedding Model）を指定し、ユーザーが提供するテキストデータをベクトルデータに変換します。モデルが複数の次元をサポートする場合、`dim` パラメータを使用して出力するベクトルの次元を指定できます。

## 前提条件

### 権限付与

`AI_EMBED` 関数などの AI 関数サービスを使用する前に、関連する権限を保有していることを確認する必要があります。詳細な権限については、[AI 関数呼び出し権限](../700.ai-function/100.ai-function-permission.md)を参照してください。

### モデル登録

`AI_EMBED` 関数を使用する前に、システムパッケージ `DBMS.AI_SERVICE` 内のサブプログラムを使用してモデル情報を登録していることを確認する必要があります。以下は登録の例です：

```sql
CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('ob_embed');
CALL DBMS_AI_SERVICE.DROP_AI_MODEL_ENDPOINT ('ob_embed_endpoint');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL(
'ob_embed', '{
    "type": "dense_embedding",
    "model_name": "BAAI/bge-m3"
}');

CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
'ob_embed_endpoint', '{
    "ai_model_name": "ob_embed",
    "url": "https://api.siliconflow.cn/v1/embeddings",
    -- 実際の access_key に置き換える必要があります
    "access_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "provider": "siliconflow"
}};
```

サポートされているすべてのモデルベンダーと、対応する URL の詳細については、[CREATE_AI_MODEL_ENDPOINT](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004479800)を参照してください。

## 構文

```sql
AI_EMBED(model_key, input, [dim])
```

パラメータ説明：

| パラメータ | 説明 | 型 | NULL許容 |
|------|------|------|----------|
| model_key | データベースに登録されたモデル。 | VARCHAR(128) | No |
| input | ユーザーが変換したいテキストデータ。 | VARCHAR | No |
| dim | 出力に関連する次元のベクトルを指定します。一部の大規模言語モデルベンダーが提供するAPIでは、複数の次元を設定できます。 | INT64 | Yes |

`model_key` と `input` の両方を指定する必要があります。いずれか一方が `NULL` の場合、関数はエラーを返します。

戻り値の説明は以下のとおりです：

* ベクトル形式の文字列。これは、テキストを変換した埋め込みモデルのベクトルです。

## 例

### 単一行データの埋め込み

```sql
SELECT AI_EMBED("ob_embed","Hello world") AS embedding;
```

実行結果は次のとおりです：

```sql
+----------------+
| embedding      |
+----------------+
| [0.1, 0.2, 0.3]|
+----------------+
```

### テーブル上の列の埋め込み

```sql
CREATE TABLE comments (
    id INT AUTO_INCREMENT PRIMARY KEY,
    content TEXT
);

INSERT INTO comments (content) VALUES ('hello world!');

SELECT AI_EMBED("ob_embed",content) AS embedding FROM comments;
```

実行結果は次のとおりです：

```sql
+----------------+
| embedding      |
+----------------+
| [0.1, 0.2, 0.3]|
+----------------+
```
