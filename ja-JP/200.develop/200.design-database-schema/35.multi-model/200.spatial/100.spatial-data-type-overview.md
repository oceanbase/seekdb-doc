# 空間データ型の概要

seekdbの地理情報システム（Geographic Information System、GIS）機能には、以下の空間データ型が含まれます：

* `GEOMETRY`

* `POINT`

* `LINESTRING`

* `POLYGON`

* `MULTIPOINT`

* `MULTILINESTRING`

* `MULTIPOLYGON`

* `GEOMETRYCOLLECTION`

その中で、`POINT`、`LINESTRING`、`POLYGON` の3つは最も基本的なタイプであり、単一の空間データを格納するために使用されます。これらはそれぞれ `MULTIPOINT`、`MULTILINESTRING`、`MULTIPOLYGON` の3つの集合タイプへと拡張され、空間データの集合を格納するために使用されますが、指定された基本型の集合しか表現できません。`GEOMETRY` は仮想型であり、任意の基本型を表すことができます。`GEOMETRYCOLLECTION` は任意の `GEOMETRY` 型の集合です。
