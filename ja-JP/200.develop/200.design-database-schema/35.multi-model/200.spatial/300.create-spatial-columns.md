# 空間列の作成

seekdbでは、`CREATE TABLE` または `ALTER TABLE` を使用して空間列を作成できます。

`CREATE TABLE` ステートメントを使用して空間列を含むテーブルを作成する構文例は以下のとおりです：

```sql
CREATE TABLE geom (g GEOMETRY);
```

`ALTER TABLE` ステートメントを使用して既存のテーブルに空間列を追加または削除する構文例は以下のとおりです：

```sql
ALTER TABLE geom ADD pt POINT;
ALTER TABLE geom DROP pt;
```

例：

```sql
CREATE TABLE geom (
    p POINT SRID 0,
    g GEOMETRY NOT NULL SRID 4326
);
Query OK, 0 rows affected
```

空間列の作成に関連する制約事項は以下のとおりです：

* 空間列を定義する際に、SRIDを明示的に指定できます。列にSRIDが定義されていない場合、クエリ時にオプティマイザーは空間インデックスを選択しませんが、挿入/更新時にはインデックスレコードが生成されます。

* 空間列に `NOT NULL` 制約を指定し、さらにSRIDを指定した後、その空間列に空間インデックスを定義できます。つまり、SRIDが定義された列であれば、空間インデックスを使用できます。

* 空間列にSRIDを定義した後、他のSRID値を挿入するとエラーが発生します。

`SRID` に関連する制約事項は以下のとおりです：

* 空間列に `SRID` が明示的に指定されていること。

* 列上のすべてのオブジェクトの `SRID` が同じでなければなりません。
