# 空間参照システム (SRS)

空間データの空間参照システム (Spatial Reference System、SRS) は、座標に基づく地理的位置システムです。SeekDB の現在のバージョンでは、システムがデフォルトでサポートする SRS のみをサポートしています。

空間参照システムには一般的に以下のタイプが含まれます：

* 投影 SRS。投影 SRS は地球の平面への投影であり、つまり平面地図です。この平面上の座標系はデカルト座標系であり、長さ単位（メートル、フィートなど）を使用し、経度や緯度ではありません。

* 地理 SRS。地理 SRS は非投影 SRS であり、任意の角度単位で楕円体上の経度・緯度（または緯度・経度）座標を表します。

さらに、`SRID 0` で表される無限に平坦なデカルト平面もあります。その軸には単位が割り当てられていません。投影 SRS とは異なり、これは抽象的な平面であり、地理的な参照がなく、必ずしも地球を表すわけではありません。`SRID 0` は空間データのデフォルト `SRID` です。

SRS の内容は `INFORMATION_SCHEMA ST_SPATIAL_REFERENCE_SYSTEMS` テーブルから取得できます。以下の例を参照してください：

```sql
SELECT *  FROM INFORMATION_SCHEMA.ST_SPATIAL_REFERENCE_SYSTEMS
     WHERE SRS_ID = 4326\G
*************************** 1. row ***************************
                SRS_NAME: WGS 84
                  SRS_ID: 4326
            ORGANIZATION: EPSG
ORGANIZATION_COORDSYS_ID: 4326
              DEFINITION: GEOGCS["WGS 84",DATUM["World Geodetic System 1984",SPHEROID["WGS 84",6378137,298.257223563,AUTHORITY["EPSG","7030"]],AUTHORITY["EPSG","6326"]],PRIMEM["Greenwich",0,AUTHORITY["EPSG","8901"]],UNIT["degree",0.017453292519943278,AUTHORITY["EPSG","9122"]],AXIS["Lat",NORTH],AXIS["Lon",EAST],AUTHORITY["EPSG","4326"]]
             DESCRIPTION: NULL
1 row in set
```

上記の例は GPS システム用の SRS を説明しており、その名前 (SRS_NAME) は WGS 84、ID (SRS_ID) は 4326 です。

`DEFINITION` 列の SRS 定義は `WKT` 値です。WKT は EBNF (Extended Backus Naur Form) に基づいて定義されています。WKT はデータ形式（本記事では WKT-Data と呼ぶ）としても、GIS における SRS 定義としても使用できます。

`SRS_ID` 値は、幾何値の `SRID` と同じタイプの値を表すか、空間関数に `SRID` パラメータとして渡されます。`SRID 0`（無単位デカルト平面）は特殊な、有効な空間参照システム ID であり、`SRID` 値に依存するあらゆる空間データ計算に使用できます。

複数の幾何値の計算においては、すべての値が同じ SRID を持っている必要があります。そうでない場合、エラーが発生します。
