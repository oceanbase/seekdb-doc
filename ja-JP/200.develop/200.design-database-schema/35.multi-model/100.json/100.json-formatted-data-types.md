# JSONデータ型の概要

seekdbは、RFC 7159標準に準拠するJSON（JavaScript Object Notation）データ型をサポートしており、ユーザーは半構造化されたJSONデータを保存し、JSONドキュメント内のデータにアクセスおよび変更できます。

JSONデータ型には以下の利点があります：

* JSON列に格納されるJSONドキュメントは自動的に検証され、無効なドキュメントはエラーとして報告されます。

* JSON列に格納されるJSONドキュメントは、高速な読み取りとアクセスを容易にする形式に変換できます。サーバーがバイナリ形式で保存されたJSON値を読み取る必要がある場合、テキストからその値を解析する必要はありません。

* 半構造化エンコードの使用をサポートし、ストレージコストをさらに削減します。これにより、1つのJSONデータを複数のサブ列に分割して保存し、各サブ列を個別にエンコードすることで、エンコード圧縮率を高め、そのJSONデータのストレージ容量を削減できます。使用方法と例については、[JSON値の作成](200.create-a-json-value.md)および[半構造化エンコード](600.json-semi-struct.md)を参照してください。
