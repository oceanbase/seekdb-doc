# 再ランキング検索

再ランキング検索（Rerank Search）は、AI再ランキングモデル（Rerank Model）を基に検索結果を2次元でソートする技術です。深層学習モデルを用いてクエリ語と候補文書間の意味的関連性を精密に評価し、検索結果の順序付けを最適化することで、検索精度とユーザーエクスペリエンスを向上させます。

検索拡張生成（RAG）アプリケーションにおいて、AI再ランキングは重要なプロセスです。seekdbは `AI_RERANK` 関数を提供しており、SQL内で直接AI再ランキングモデルを呼び出すことができます。これにより、追加のコードを記述することなく検索結果のインテリジェントな最適化を実現できます。`AI_RERANK` 関数は、`model_key` を使用して登録済みの再ランキングモデル（Rerank Model）を指定し、ユーザーが提供したクエリ語と文書リストをベンダーのルールに従ってメッセージとして組織して指定されたモデルに送信します。そして、モデルから返されたソート結果を解析して返します。

## AI_RERANK 関数の使用

`AI_RERANK` 関数は、`model_key` を使用して登録済みの再ランキングモデルを指定し、ユーザーが提供するクエリ語句とドキュメントリストをモデルに送信して解析し、モデルのランキング結果を返します。

### 構文

```sql
AI_RERANK(model_key, query, documents[, document_key])
```

パラメータ説明：

| パラメータ | 説明 | 型 | NULL許容 |
|------|------|------|----------|
| model_key | データベースに登録されているモデル。 | VARCHAR(128) | No |
| query | ユーザーが入力した検索テキスト。 | VARCHAR(1024) | No |
| documents | ユーザーが入力したドキュメントのリスト。 | JSON ARRAY、例：`['apple', 'banana']` | No |

`model_key`、`query`、`documents` のうちいずれか一方が `NULL` の場合、関数はエラーメッセージを表示します。

戻り値：

* JSON配列。再ランキングモデルが返したドキュメントとその関連性スコアを含み、関連性スコアの降順で並べ替えられています。

## 例

```sql
SELECT AI_RERANK("ob_rerank", "Apple", '["apple", "banana", "fruit", "vegetable"]');
```
