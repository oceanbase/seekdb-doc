# ベクトル検索よくある質問

本記事では、ベクトル検索の使用中によくある質問とその原因および解決策について説明します。

## ベクトル列において、各行のデータ次元は同じでなければなりませんか？

必須です。ベクトル列を定義する際には次元を指定する必要があり、ベクトルデータを書き込む際にも次元が一致しているか検証されます。

## 最大で何行のベクトルデータの書き込みをサポートしますか？

制限はありません。データベースのメモリリソースに依存します。

## 4096次元を超えるベクトルに対するインデックス付け方法は何ですか？

データを4096次元以内に圧縮した後、インデックスを作成する必要があります。
