# ベクトル検索の概要

このドキュメントでは、ベクトルデータベースとベクトル検索のコアコンセプトについて説明します。

seekdbは最大16,000次元のFloat型の密ベクトルをサポートし、疎ベクトルもサポートしています。マンハッタン距離、ユークリッド距離、内積、コサイン距離など、さまざまなベクトル距離の計算に対応しており、HNSW/IVFベクトルインデックスに基づく作成、増分更新・削除をサポートしています。また、これらの操作は再現率に影響を与えません。

## 主な機能

seekdbは、Embeddingベクトルデータの格納、インデックス作成、検索機能を提供します。具体的には以下のような機能が含まれます：

|**コア機能**|**説明**|
|---|---|
| ベクトルデータ型 | <ul><li>最大16,000次元のfloat型密ベクトルデータの格納をサポートします。</li><li>疎ベクトルデータの格納をサポートします。</li></ul> |
| ベクトルインデックス | <ul><li>厳密検索と近似最近傍探索をサポートします。</li><li>L2距離、内積、コサイン類似度の計算をサポートします。</li><li>HNSW/HNSW_SQ/HNSW_BQインデックスをサポートし、インデックス列の最大次元は4096です。HNSW_BQインデックスはV4.4.0バージョンからサポートされます。</li><li>IVF/IVF_PQインデックスをサポートし、インデックス列の最大次元は4096です。</li></ul> |
| ベクトル検索SQL演算子 | ベクトルの加算、減算、乗算、比較、集約などの基本的な演算子をサポートします。 |

利用制限と注意事項は以下の通りです：

* seekdbはデフォルトでNULL first比較モードを採用しているため、NULL値を含む列をソートするとNULL値が先頭に配置されます。クエリ実行時には`NOT NULL`条件を追加することを推奨します。

## 重要な概念

### 非構造化データ

非構造化データとは、明確に定義されたデータ形式や構造を持たないデータのことです。一般的に、テキスト、画像、音声、動画などの形式のデータや、ソーシャルメディアのコンテンツ、電子メール、ログファイルなどが含まれます。非構造化データは複雑かつ多様であるため、自然言語処理、画像認識、機械学習などの特定のツールや技術を用いて処理する必要があります。

### ベクトル

ベクトルとは、本質的にはオブジェクトが高次元空間に投影されたものです。数学的には、ベクトルは浮動小数点数の配列であり、以下の2つの特徴があります：

* 配列の各要素はベクトルの各次元を表し、各要素は浮動小数点数です。

* ベクトル配列のサイズ（要素数）は、ベクトル空間全体の次元を表します。

### ベクトル埋め込み(Embedding)

ベクトル埋め込み(Embedding)とは、深層学習ニューラルネットワークを用いて非構造化データから内容と意味を抽出し、画像や動画などを特徴ベクトルに変換するプロセスです。Embedding技術は、元のデータを高次元空間から低次元空間へとマッピングし、豊富な特徴を持つマルチモーダルデータを多次元ベクトルデータに変換します。

### ベクトル類似性検索

情報が溢れる現代では、ユーザーは膨大なデータの中から必要な情報を迅速に検索する必要があります。例えば、オンライン文献データベース、eコマースプラットフォームの商品カタログ、そして増え続けるマルチメディアコンテンツライブラリなどでは、ユーザーの興味に合致するコンテンツを素早く特定するための効率的な検索システムが求められています。データ量が急増する中、従来のキーワードベースの検索手法では、検索精度と速度に対するユーザーの要求を満たせなくなりました。そこで登場したのがベクトル検索技術です。ベクトル類似性検索は、特徴抽出とベクトル化技術を用いて、テキスト、画像、音声など異なる種類の非構造化データをベクトルに変換し、類似性尺度を用いてそれらの類似度を比較することで、データの深層的な意味情報を捉え、より正確で効率的な検索結果を提供します。
