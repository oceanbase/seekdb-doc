# ベクトルデータ型の概要

seekdbは、AIベクトル検索関連のアプリケーションをサポートするためにベクトルデータ型を提供します。ベクトルデータ型を使用することで、例えば`[0.1, 0.3, -0.9, ...]`のような浮動小数点数の配列を格納およびクエリできます。ベクトルデータを使用する前に、以下の点をご確認ください：

* 密ベクトルと疎ベクトルがサポートされており、どちらもデータ要素は単精度浮動小数点数です。

* ベクトルデータの要素値は、非数値(NaN)や無限大(Inf)を許容しません。これらを含む場合は、ランタイムエラーがスローされます。

* ベクトル列を作成する際には、ベクトルの次元を指定する必要があります。例：`VECTOR(3)`。

* 密ベクトルインデックスと疎ベクトルインデックスの作成がサポートされています。詳細については、[密ベクトルインデックス](200.vector-index/300.dense-vector-index/100_dense-vector-index-overview.md)を参照してください。

* seekdbのベクトルデータは配列形式で格納されます。

* 密ベクトルと疎ベクトルはどちらも[ハイブリッド検索](https://en.oceanbase.com/docs/common-oceanbase-database-10000000001970893)をサポートします。

## 構文

密ベクトル値は、16000個以内の任意の数の浮動小数点数を含むことができます。構文は以下のとおりです：

```sql
-- 密ベクトル
'[<float>, <float>, ...]'
```

疎ベクトルはMAPデータ型に基づいており、順序のないキーと値のペアを含みます。構文は以下のとおりです：

```sql
-- 疎ベクトル
'{<uint:float>, <uint:float>...}'
```

ベクトル列とインデックスの作成例は以下のとおりです：

```sql
-- 密ベクトル列とインデックスの作成
CREATE TABLE t1(
    c1 INT,
    c2 VECTOR(3),
    PRIMARY KEY(c1),
    VECTOR INDEX idx1(c2) WITH (distance=L2, type=hnsw)
    );
```

```sql
-- 疎ベクトル列の作成
CREATE TABLE t2 (
    c1 INT,
    c2 SPARSEVECTOR
    );
```
