# RIGHT JOIN

右結合（RIGHT JOIN）とは、右外部結合を示します。このステートメントを使用すると、右テーブルのすべてのレコードと、左テーブルと右テーブルの結合フィールドが一致するレコードを返します。

## 背景

外部結合（OUTER JOIN）は、比較演算子を使用して2つのテーブルのデータを比較します。結合結果には結合条件に合致する行だけでなく、条件に合致しない行も含まれます。

外部結合には、完全結合（FULL JOIN）、左結合（LEFT JOIN）、右結合（RIGHT JOIN）が含まれます。外部結合は結合条件を満たすすべての行を返し、一方のテーブルから未使用の行を返すときは、もう一方のテーブルの対応する位置に`NULL`を埋めます。

本記事では主に右結合の例を説明します。完全結合に関連する例については、[完全結合](200.full-join.md) を参照してください。左結合に関連する例については、[左結合](300.left-join.md)を参照してください。

## RIGHT JOIN構文

外部結合ステートメントには通常、左テーブルと右テーブルが含まれます。`JOIN` 句の一番左側に記述されているテーブルが左テーブル、`JOIN` 句の一番右側に記述されているテーブルが右テーブルです。

RIGHT JOINの構文は以下のとおりです：

```sql
SELECT select_list FROM table_name1 RIGHT JOIN table_name2 ON join_condition
[ WHERE query_condition ]
[ ORDER BY column_list ];
```

ここで、`table_name1` が左テーブル、`table_name2` が右テーブルです。

## 例

サンプルテーブルを作成し、適切なデータを挿入します。

```sql
CREATE TABLE tbl_a(id INT NOT NULL PRIMARY KEY, name VARCHAR(50));
Query OK, 0 rows affected

CREATE TABLE tbl_b(number INT NOT NULL PRIMARY KEY, value INT);
Query OK, 0 rows affected

CREATE TABLE tbl_c(id INT NOT NULL , name VARCHAR(50));

```

### シンプルな右結合クエリ

`JOIN` が返すデータが結合条件やフィルタ条件に合致するデータのほか、右テーブルのフィルタ条件には合致するものの結合条件を満たさないデータも含まれる場合、右外部結合（`RIGHT OUTER JOIN`）を使用できます。これは略して右結合（`RIGHT JOIN`）とも呼ばれます。右結合で返される結果において、左テーブルに属するデータが存在しない場合、その列は `NULL` を返します。

例1：テーブル `tbl_a` とテーブル `tbl_b` に対して右結合クエリを実行し、実行結果を取得します。

```sql
SELECT * FROM tbl_a;
+------+------+
| id   | name |
+------+------+
|    1 | ab   |
|    2 | cd   |
|    3 | ef   |
|    4 | gh   |
+------+------+
4 rows in set

SELECT * FROM tbl_b;
+--------+-------+
| number | value |
+--------+-------+
|      1 |  1001 |
|      3 |  1003 |
|      5 |  1005 |
+--------+-------+
3 rows in set

SELECT * FROM tbl_a RIGHT JOIN tbl_b ON tbl_a.id=tbl_b.number;
+------+------+--------+-------+
| id   | name | number | value |
+------+------+--------+-------+
|    1 | ab   |      1 |  1001 |
|    3 | ef   |      3 |  1003 |
| NULL | NULL |      5 |  1005 |
+------+------+--------+-------+
3 rows in set
```

### 複雑な右結合クエリ

例：

```sql
SELECT * FROM tbl_a a INNER JOIN tbl_b b RIGHT JOIN tbl_c c ON c.id=b.number ON a.name=c.name;
Empty set (0.009 sec)
```

### 右結合とWHERE句の組み合わせ使用

右結合を使用して結合結果を取得した後、`WHERE` 句を使用して結合結果をフィルタリングできます。

例2：テーブル `tbl_a` とテーブル `tbl_b` に対して右結合クエリを実行した後、`tbl_b` テーブルの `value=1003` のデータを返します。

```sql
SELECT * FROM tbl_a;
+------+------+
| id   | name |
+------+------+
|    1 | ab   |
|    2 | cd   |
|    3 | ef   |
|    4 | gh   |
+------+------+
4 rows in set

SELECT * FROM tbl_b;
+--------+-------+
| number | value |
+--------+-------+
|      1 |  1001 |
|      3 |  1003 |
|      5 |  1005 |
+--------+-------+
3 rows in set

SELECT * FROM tbl_a RIGHT JOIN tbl_b ON tbl_a.id=tbl_b.number WHERE tbl_b.value=1003;
+------+------+--------+-------+
| id   | name | number | value |
+------+------+--------+-------+
|    3 | ef   |      3 |  1003 |
+------+------+--------+-------+
1 row in set
```
