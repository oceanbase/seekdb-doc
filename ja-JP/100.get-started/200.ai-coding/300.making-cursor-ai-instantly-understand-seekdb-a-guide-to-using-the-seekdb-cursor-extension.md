# Cursor AIアシスタントがseekdbを一瞬で理解する

AIによるプログラミング支援の時代において、開発者はコーディング効率を向上させるためにスマートツールにますます依存しています。しかし、Cursor内でseekdbに関する質問をしたとき、AIは正確な回答を提供できない可能性があります。なぜなら、AIはこの新興のAIネイティブ検索データベースであるseekdbを理解していないからです。

本記事では、AIアシスタントを使用してseekdbハイブリッド検索アプリケーションを作成する例を通じて、seekdb Cursor Extensionを利用することで、Cursor AIアシスタントにseekdbの専門知識を付与し、開発プロセスにおいて正確な技術的指導を得る方法を紹介します。

## seekdb Cursor Extensionの紹介

**seekdb Cursor Extension**は、Cursor拡張機能です。`.cursor/rules`ディレクトリにルールを追加することで、Cursor AIアシスタントがseekdbの公式ドキュメントを検索し、seekdbデータベースの知識を理解できるようにします。これにより、以下の機能を実現します：

* seekdbデータベースの概念を理解する：ベクトル検索、ハイブリッド検索、AI関数など
* 正確なコード提案を提供する：公式ドキュメントに基づいて、ベストプラクティスに準拠したコードを生成する
* seekdbに関する質問に答える：エディタ内で直接技術サポートを受ける
* 開発プロセスを加速する：ドキュメントの参照時間を短縮し、ビジネスロジックに集中する

### 主な特徴

* クリック一発でインストール：Cursor拡張マーケットからすばやくインストールできます。
* 全文書：seekdb公式ドキュメントのナレッジベースを検索し、ベクトル検索、ハイブリッド検索、AI関数など、包括的な技術ドキュメントを網羅しています。
* ダブルモードサポート：最新のドキュメントは優先的にGitHubから取得し、ローカルドキュメントをバックアップとして使用します。

### 動作原理

seekdb Cursor Extensionの動作原理は非常にシンプルです：

* ルールファイルの挿入：拡張機能は、seekdb公式ドキュメントと`.mdc`ルールファイルを`.cursor/rules`ディレクトリに追加します。
* AIコンテキストの強化：Cursorは自動的に`.cursor/rules`ディレクトリの内容を読み取り、AIアシスタントのコンテキスト知識とします。
* インテリジェントな検索：seekdbに関する質問をしたとき、AIアシスタントはこれらのドキュメントに基づいて正確な回答を提供します。

## ステップ１：拡張機能をインストールする

1. Cursorで拡張マーケットを開きます(Ctrl+Shift+XまたはCmd+Shift+X)。
2. "seekdb"と検索します。
3. Installをクリックして拡張機能をインストールします。

## ステップ２：seekdbドキュメントを追加する

1. Cursorを使用してプロジェクトディレクトリを開きます(ドキュメントはこのディレクトリに追加されます)。

2. コマンドパネルを開きます：

   * Windows/Linux: `Ctrl+Shift+P`を押します。
   * macOS: `Cmd+Shift+P`を押します。

3. コマンドを入力して選択します：

   * "seekdb"または"Add seekdb Docs"と入力します。
   * `Add seekdb Docs`コマンドを選択します。

4. ドキュメントは自動的に追加されます：

   * `.cursor/rules/seekdb-docs`ディレクトリ(公式ドキュメント)
   * `.cursor/rules/seekdb.mdc`ファイル(ルールファイル)

5. ルールを有効にするためにウィンドウを再読み込みします。

インストール完了！これで、Cursor AIアシスタントにseekdbに関する質問を直接することができます。

## ステップ3：AIアシスタントを使用してseekdbハイブリッド検索アプリケーションを作成する

拡張機能をインストールし、ドキュメントを追加した後、Cursorで新しいダイアログを開き、以下の質問を入力します：

```shell
Pythonを使用して、ドキュメントのハイブリッド検索機能を実現する簡単なseekdbアプリケーションを作りたいです。コードを書いてください。
```

Cursor AIアシスタントは正確な回答を提供します：

```shell
"""
seekdbハイブリッド検索クイックスタート例

これは最も簡略化されたハイブリッド検索の例で、すぐに使い始めることができます。
"""

import pyseekdb

# 1. クライアントの作成（組み込みモード、データベースのデプロイは不要）
client = pyseekdb.Client()

# 2. コレクションの作成
collection = client.get_or_create_collection(name="my_docs")

# 3. ドキュメントの追加
documents = [
    "機械学習は人工知能の核心技術です",
    "Pythonは最も広く使われている機械学習プログラミング言語です",
    "深層学習には大量の訓練データが必要です",
    "自然言語処理により、コンピュータは人間の言葉を理解できるようになります",
    "ベクトルデータベースはベクトルデータの格納と検索に使用されます",
]

metadatas = [
    {"category": "AI", "year": 2024},
    {"category": "Programming", "year": 2024},
    {"category": "AI", "year": 2023},
    {"category": "AI", "year": 2024},
    {"category": "Database", "year": 2024},
]

ids = [f"doc_{i}" for i in range(len(documents))]

collection.add(ids=ids, documents=documents, metadatas=metadatas)
print(f"{len(documents)} 個のドキュメントを追加しました")

# 4. ハイブリッド検索の実行
# 全文検索（「機械学習」を含む）とベクトル意味検索（「AI技術」と類似する内容を検索する）を組み合わせる
results = collection.hybrid_search(
    query={
        "where_document": {"$contains": "機械学習"},  # 全文検索：キーワードを含む
        "n_results": 10,
    },
    knn={
        "query_texts": ["AI技術"],  # ベクトル検索：意味的類似性
        "n_results": 10,
    },
    rank={"rrf": {}},  # RRFアルゴリズムを使用して結果を統合する
    n_results=3,
    include=["documents", "metadatas"],
)

# 5. 結果の出力
print("\nハイブリッド検索結果:")
for i, (doc_id, doc, meta) in enumerate(
    zip(results["ids"][0], results["documents"][0], results["metadatas"][0]), 1
):
    print(f"  [{i}] {doc}")
    print(f"      メタデータ: {meta}\n")

# 6. クリーンアップ（オプション）
# client.delete_collection("my_docs")
```

## ステップ4：サンプルを実行する

1. pyseekdbをインストールします

    ```shell
    pip install -U pyseekdb
    ```

2. ファイルを作成して実行します

    上記のコードを `quick_start_hybrid_search.py` という名前で保存し、次に実行します：

    ```shell
    python quick_start_hybrid_search.py
    ```

3. 結果を確認します

    ```shell
    5件のドキュメントが追加されました

    ハイブリッド検索結果:
      [1] 機械学習は人工知能の核心技術です
          メタデータ: {'year': 2024, 'category': 'AI'}

      [2] 深層学習には大量の訓練データが必要です
          メタデータ: {'year': 2023, 'category': 'AI'}

      [3] Pythonは最も広く使われている機械学習プログラミング言語です
          メタデータ: {'year': 2024, 'category': 'Programming'}
    ```

    ハイブリッド検索は、**キーワードマッチング**（"機械学習" を含むドキュメント）と **セマンティック検索**（"AI 技術" と意味的に近いドキュメント）を組み合わせ、RRF（Reciprocal Rank Fusion）アルゴリズムで2つの検索結果を統合し、最も関連性の高いドキュメントを返します。

## ステップ5：ドキュメントを削除する

seekdbのドキュメントが不要になった場合、簡単に削除できます：

1. コマンドパネルを開きます（`Ctrl+Shift+P` または `Cmd+Shift+P`）。
2. `Remove seekdb Docs` と入力します。
3. このコマンドを選択して実行します。

ドキュメントは `.cursor/rules` ディレクトリから削除されます。
