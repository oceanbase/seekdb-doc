# seekdb MCP Serverを使用してAI対話による個人ノート知識ベースを構築する

seekdb MCP ServerはMCPプロトコルに基づき、Cursor、Windsurf、ClineなどのAIプログラミングツールで自然言語対話を通じてseekdbベクトルデータベースを直接操作できるようにします。本記事では、seekdbの組み込みモードを利用して、seekdb MCP Serverを用いて個人ノート知識ベースを構築する方法を紹介します。

個人ノート知識ベースは以下の機能を実現します：

* 自然言語でのノートの保存
* 関連コンテンツのセマンティック検索
* ハイブリッド検索による高精度な位置付け
* AIインテリジェントQ&A

seekdb MCP Serverの詳細については、[seekdb MCP Server](../../300.integrations/600.mcp/200.seekdb-mcp-server.md)を参照してください。

## シナリオ設定

あなたが技術者であり、普段からさまざまな学習ノートや仕事の心得を記録していると仮定します。今、AIにこれらのノートを管理してもらい、自然言語で必要な内容をすばやく見つけたいと思っています。

## 前提条件

* この例では、組み込みモードを使用して説明します。組み込みモードでは、seekdbを別途インストールする必要はありません。seekdb MCP Server起動時にローカルの組み込みデータベースが自動的に初期化され、すぐに使用できます。
* 現在、組み込みモードのseekdbはLinuxプラットフォーム（glibc >= 2.28、x86_64 / aarch64アーキテクチャ）およびmacOS 15以降をサポートしています。ご使用のシステムが要件を満たしていることを確認してください。
* MCPプロトコルをサポートするCursorまたはその他のツール（Windsurf、Qoderなど）をインストール済みであること。
* Python環境（バージョン3.11～3.13）をインストール済みであること。
* Pythonインストールパッケージは[Python公式サイト](https://www.python.org/downloads/)からダウンロードできます。

## ステップ１：uvをインストールする

uvはPythonパッケージマネージャーであり、uvxコマンドを使用するとPythonツールを直接実行できます。

```sql
# Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# またはpipでインストールする
pip install uv
```

## ステップ2：AIプログラミングツールを設定する

以下の操作はCursorを例に説明しますが、MCPをサポートする他のツール（Windsurf、Cline、Continue、Traeなど）でも設定方法は同様です。

[Add to Cursor](https://cursor.com/en/install-mcp?name=seekdb&config=eyJjb21tYW5kIjogInV2eCIsICJhcmdzIjogWyJzZWVrZGItbWNwLXNlcnZlciJdfQ==)をクリックし、Cursorに直接インストールします。

または、以下の手順に従って手動で設定することもできます：

1. Cursorの設定を開きます（右上の歯車アイコンをクリック）。
2. Tools & MCPを選択します。
3. Add Custom MCPをクリックします。
4. mcp.json設定ファイルを編集します：

    ```java
    {
      "mcpServers": {
        "seekdb": {
          "command": "uvx",
          "args": ["seekdb-mcp-server"]
        }
      }
    }
    ```

    ネットワークに問題が発生した場合は、Alibaba Cloudのミラーソースを使用するよう設定できます：

    ```java
    {
      "mcpServers": {
        "seekdb": {
          "command": "uvx",
          "args": ["seekdb-mcp-server"],
          "env": {
            "UV_DEFAULT_INDEX": "https://mirrors.aliyun.com/pypi/simple/"
          }
        }
      }
    }
    ```

    保存後、約1分待機すると、Cursorはseekdb MCP Serverを自動的に起動します。

## ステップ3：ノートコレクションを作成する

AIツール（Cursorなど）のダイアログボックスに次のように入力します：

```shell
「my_notes」という名前のナレッジベースコレクションを作成してください
```

AIの応答例：

```shell
「my_notes」という名前のコレクションを正常に作成しました：
    * 次元: 384（ベクトルサイズ）
    * 距離尺度: L2（ユークリッド距離）
```

これで、セマンティック検索をサポートするベクトルコレクションが作成されました！

## ステップ5：セマンティック検索

では、自然言語でメモを検索してみましょう：

```shell
my_notesで「AIアプリケーション開発」に関連するメモを検索してください
```

AIの応答例：

```shell
以下は「AIアプリケーション開発」に関連するメモです。関連性の高い順に並べました：
```

| ランキング | 内容 | 関連度 |
|------|------|--------|
| 1 | RAG（Retrieval-Augmented Generation）は、現在最も流行っているAIアプリケーションアーキテクチャです... | 最高 |
| 2 | MCPプロトコルは、Anthropicが2024年11月に提案したものです... | 高 |
| 3 | seekdbは、ベクトル検索と全文検索を組み合わせたハイブリッド検索をサポートしています... | 中 |

:::tip

私たちが検索したのは「AIアプリケーション開発」ですが、メモにはこの正確な単語は含まれていません。seekdbのベクトル検索はセマンティック類似性を理解し、関連する内容を自動的に見つけ出します！

:::

## ステップ6：ハイブリッド検索

ハイブリッド検索はキーワードマッチングとセマンティックスマートを組み合わせることで、より正確な結果を提供します：

```shell
my_notesでハイブリッド検索を実行します：
- 全文キーワード："Python"
- セマンティッククエリ："非同期プログラミングと並列処理"
```

AIの応答例：

ハイブリッド検索の結果：

| ランキング | 内容 |
| ---- | ---- |
| 1 | Pythonのasyncioモジュールは非同期プログラミング機能を提供し、I/O集約型タスクに適しています。 |
| 2 | Dockerコンテナ化技術により、アプリケーションの迅速なデプロイと環境の分離が実現できます。 |

ハイブリッド検索は **RRF（逆ランキング融合）** アルゴリズムを使用し、キーワードマッチング（BM25）とベクトル類似度スコアを統合して評価するため、より正確なランキング結果が得られます。

## ステップ7：AIにあなたの好みを覚えてもらう

seekdb MCP Serverは、AIがセッションを越えてあなたの情報を記憶できるAIメモリシステムも提供しています：

```shell
私はPython開発者であり、主にseekdbを使用してベクトル検索アプリケーションを開発していることを覚えておいてください
```

AIの応答例：

```shell
記録しました！私は次のことを覚えておきます：
  * あなたはPython開発者です
  * 主にseekdbを使用してベクトル検索アプリケーションを開発しています
```

次回の対話時には、直接次のように尋ねることができます：

```shell
私の技術的背景に基づいて、学習リソースをいくつか推薦してください
```

AIはあなたの好みを自動的に検索し、パーソナライズされた推薦を提供します！
