# seekdb + Claude CodeでベクトルDB対応AIアシスタントを作る

Claude CodeはAnthropicが提供するAIプログラミングアシスタントで、優れたコードの理解と生成能力により、ますます多くの開発者にとって強力なツールとなっています。しかし、Claude Codeでseekdbに関する質問をした場合、AIは正確な回答を提供できない可能性があります。これは、seekdbという新興のAIネイティブ検索データベースについての理解が限られているためです。

本記事では、seekdbハイブリッド検索アプリケーションの作成を例に、seekdb Claude Codeプラグインを使用してClaude Codeにseekdbの専門知識を付与し、開発プロセスで正確な技術的指導を得る方法を紹介します。

## seekdb Claude Codeプラグインの紹介

**seekdb Claude Code** プラグインはAgent Skillプラグインであり、Claude Codeがseekdbの公式ドキュメントを検索し、seekdbデータベースの知識の文脈を理解できるようにすることで、以下の機能を提供します：

* seekdbデータベースの概念を理解する：ベクトル検索、ハイブリッド検索、AI関数など。
* 正確なコード提案を提供する：公式ドキュメントに基づいて、ベストプラクティスに準拠したコードを生成する。
* seekdb関連の質問に回答する：ターミナル上で直接技術サポートを受ける。
* 開発プロセスを加速する：ドキュメントの参照時間を短縮し、ビジネスロジックに集中する。

## 前提条件

* Node.js環境：Node.js 18以降が必要です。

* ネットワークアクセス：GitHubへのアクセスが可能である必要があります（プラグインのインストールと最新ドキュメントの取得に使用されます）。

* seekdbプラグインをインストールする前に、Claude Codeがインストール済みであることを確認してください。まだインストールしていない場合は、[Claude Code公式ドキュメント](https://code.claude.com/docs/en/overview#native-install-recommended)を参照してインストールしてください。公式では **Native Install** 方法の使用を推奨しています。例えば、macOS、Linux、またはWSLでは実行可能です：

    ```shell
    curl -fsSL https://claude.ai/install.sh | bash
    ```

    その他のプラットフォーム（Windowsなど）およびHomebrew、WinGetなどのインストール方法の詳細は、上記ドキュメントを参照してください。

    インストール完了後、APIキーを設定します：

    ```shell
    export ANTHROPIC_API_KEY="your-api-key-here"

    # API Base URLの設定（プロキシやカスタムエンドポイントを使用する場合）
    export ANTHROPIC_BASE_URL="https://api.anthropic.com"
    ```

## ステップ1：ネットワーク設定を構成する

seekdbスキルプラグインはGitHubから最新のドキュメントを取得するため、Claude Codeがネットワークリクエストを許可するように設定する必要があります。

プロジェクトのルートディレクトリに`.claude/settings.local.json`ファイルを作成または編集します：

```shell
{
  "skipWebFetchPreflight": true
}
```

:::info

`skipWebFetchPreflight` を `true` に設定すると、ネットワークリクエストのプリフライトがスキップされます。プラグインは**ローカルドキュメントを優先的に使用**します。ローカルに対応するドキュメントがない場合、GitHubからリモートドキュメントを取得するため、この時点でネットワークアクセスが許可されている必要があります。

:::

## ステップ3：Claude Codeを使用してseekdbハイブリッド検索アプリケーションを作成する

プラグインをインストールした後、Claude Codeで新しい対話を開始し、以下の質問を入力します：

```shell
Pythonを使用して、ドキュメントのハイブリッド検索機能を実装するシンプルなseekdbアプリケーションを作成したいです。コードを書いてください。
```

Claude Codeは正確な回答を提供します：

```shell
import pyseekdb

# ==================== コレクションの作成 ====================
# 埋め込みクライアントの作成
client = pyseekdb.Client(path="./seekdb.db")
# コレクションの作成
collection = client.create_collection(
    name="hybrid_search_demo"
)

# ==================== データの追加 ====================
# ドキュメントの定義
documents = [
    "Machine learning is revolutionizing artificial intelligence and data science",
    "Python programming language is essential for machine learning developers",
    "Deep learning neural networks enable advanced AI applications",
    "Data science combines statistics, programming, and domain expertise",
    "Natural language processing uses machine learning to understand text",
    "Computer vision algorithms process images using deep learning techniques",
    "Reinforcement learning trains agents through reward-based feedback",
    "Python libraries like TensorFlow and PyTorch simplify machine learning",
    "Artificial intelligence systems can learn from large datasets",
    "Neural networks mimic the structure of biological brain connections"
]

# メタデータの定義
metadatas = [
    {"category": "AI", "topic": "machine learning", "year": 2023, "popularity": 95},
    {"category": "Programming", "topic": "python", "year": 2023, "popularity": 88},
    {"category": "AI", "topic": "deep learning", "year": 2024, "popularity": 92},
    {"category": "Data Science", "topic": "data analysis", "year": 2023, "popularity": 85},
    {"category": "AI", "topic": "nlp", "year": 2024, "popularity": 90},
    {"category": "AI", "topic": "computer vision", "year": 2023, "popularity": 87},
    {"category": "AI", "topic": "reinforcement learning", "year": 2024, "popularity": 89},
    {"category": "Programming", "topic": "python", "year": 2023, "popularity": 91},
    {"category": "AI", "topic": "general ai", "year": 2023, "popularity": 93},
    {"category": "AI", "topic": "neural networks", "year": 2024, "popularity": 94}
]

ids = [f"doc_{i+1}" for i in range(len(documents))]
# データの挿入
collection.add(ids=ids, documents=documents, metadatas=metadatas)

# ==================== ハイブリッド検索の実行 ====================
# ハイブリッド検索の実行
hybrid_result = collection.hybrid_search(
    query={"where_document": {"$contains": "machine learning"}, "n_results": 10},
    knn={"query_texts": ["AI research"], "n_results": 10},
    rank={"rrf": {}},
    n_results=5
)

# ==================== クエリ結果の出力 ====================
print("\nハイブリッド検索結果:")
print(f"  ids: {hybrid_result['ids'][0]}")
print(f"  Document: {hybrid_result['documents'][0]}")
```

## ステップ4：サンプルを実行する

1. pyseekdbをインストールします。

    ```shell
    pip install -U pyseekdb
    ```

2. ファイルを作成して実行します。

    上記のコードを `hybrid_search_demo.py` という名前で保存し、次に実行します：

    ```shell
    python hybrid_search_demo.py
    ```

3. 結果を確認します。

    ハイブリッド検索の結果は以下のとおりです：

    ```shell
    ids: ['doc_1', 'doc_5', 'doc_2', 'doc_8', 'doc_3']
    Document: ['Machine learning is revolutionizing artificial intelligence and data science', 'Natural language processing uses machine learning to understand text', 'Python programming language is essential for machine learning developers', 'Python libraries like TensorFlow and PyTorch simplify machine learning', 'Deep learning neural networks enable advanced AI applications']
    ```

    ハイブリッド検索は、**キーワードマッチング**（"machine learning" を含むドキュメント）と **セマンティック検索**（"AI research" と意味的に近いドキュメント）を組み合わせ、RRF（Reciprocal Rank Fusion）アルゴリズムを用いて二つの検索結果を統合し、最も関連性の高いドキュメントを返します。
