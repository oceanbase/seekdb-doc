# SDKを使用したハイブリッド検索のクイック体験

この例では、Linux環境を例に、OceanBaseが提供するPythonクライアントであるpyseekdbの組み込みseekdbを使用して、ハイブリッド検索をクイックに体験する方法を説明します。

:::tip
Linuxシステム以外にも、macOSおよびWindowsシステムでpyseekdbを使用することができます。ただし、現在のところWindowsシステムではサーバーモードのseekdbのみがサポートされています。macOSおよびWindowsシステムでの使用方法については、[pyseekdb クイックスタート](../../450.reference/900.sdk/10.pyseekdb-sdk/10.pyseekdb-sdk-get-started.md)を参照してください。
:::

この例では、以下の操作を行います：

1. pyseekdbと組み込みseekdbをデプロイします。
2. seekdbに接続し、データベースを作成します。
3. データベースに接続し、Embedding Functionsを持つcollectionを作成します。
4. documentsを使用してデータを追加します（ベクトルは自動生成されます）。
5. ハイブリッド検索を実行します（ベクトルは自動生成されます）し、クエリ結果を出力します。
6. 環境をクリーンアップします。

## 背景

### pyseekdb

pyseekdbは、OceanBaseが提供するPythonクライアントです。単一のAPIセットに基づき、3種類のデータベース接続モードを実装しており、組み込みモードのseekdb、サーバーモードのseekdb、およびOceanBaseデータベースへの接続をサポートしています。

このクライアントをインストールすると、組み込みモードのseekdbも同時にインストールされるため、組み込みseekdbに直接接続してデータベースの作成などの操作を実行できます。または、既にデプロイ済みのサーバーモードのseekdbまたはOceanBaseデータベースにリモート接続することも選択できます。

### seekdbのデプロイメントモード

seekdbは、迅速なプロトタイプ開発から大量ユーザーのサポートまで、あらゆるアプリケーションニーズに対応する、多様で柔軟なデプロイメントモードを提供しています。

* 組み込みモード

    seekdbは軽量ライブラリとしてアプリケーションに組み込まれ、pipワンクリックでのインストールをサポートします。個人学習、迅速なプロトタイプ開発に適しており、さまざまなエンドデバイス上で効率的に動作します。

* サーバーモード

    テストおよび本番環境でのデプロイメントモードとして推奨されており、軽量で使いやすく、安定した高効率なサービス提供に適しています。

    サーバーモードの使用方法については、[SQLを通じてサーバーモードのseekdbを体験する](../100.use-seekdb-with-sql/10.deploy-seekdb-testing-environment.md)を参照してください。

## ステップ1：pyseekdbをインストールし、組み込みseekdbをデプロイ

### 前提条件

環境が以下の要件を満たしていることを確認してください：

* オペレーティングシステム：Linux (glibc >= 2.28)
* Pythonバージョン：Python 3.11以降のバージョン
* システムアーキテクチャ：x86_64、aarch64

### インストール

pipを使用してインストールすると、デフォルトのPythonバージョンとプラットフォームが自動的に検出されます。

```shell
pip install -U pyseekdb
```

pipのバージョンが古い場合は、先にpipをアップグレードしてからインストールしてください。

```bash
pip install --upgrade pip
```

pyseekdbをインストールすると同時に、組み込みモードのseekdbもインストールされるため、組み込みseekdbに直接接続してデータベースの作成などの操作を実行できます。

## ステップ2：seekdbに接続し、データベースを作成

Admin Clientを使用してseekdbに接続し、hybrid_search_testという名前のデータベースを作成します。

:::tip

* Admin Clientの詳細については、[Admin Client](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/100.admin-client.md)を参照してください。

* データベース作成の詳細については、[create_database - データベースの作成](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/110.database/200.create-database-of-api.md)を参照してください。

:::

```python
import pyseekdb

# Create embedded admin client
admin = pyseekdb.AdminClient(path="./seekdb.db")
# Create database
admin.create_database("hybrid_search_test")
```

## ステップ3：データベースに接続し、Embedding Functionsを含むcollectionを作成する

`Client` を使用して `hybrid_search_test` データベースに接続し、collectionを作成します。

:::tip

* Clientの詳細については、[Client](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/50.client.md)を参照してください。
* collectionの作成方法の詳細については、[create_collection - Collectionの作成](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/200.collection/100.create-collection-of-api.md)を参照してください。

:::

```python
import pyseekdb

# Create embedded client
client = pyseekdb.Client(path="./seekdb.db", database="hybrid_search_test")
# Create collection
collection = client.create_collection(
    name="hybrid_search_demo"
)
```

## ステップ4：データの挿入

`add` メソッドを使用して、コレクションにデータを挿入します。

:::tip

データの挿入に関する詳細は、[add - データの挿入](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/300.dml/200.add-data-of-api.md)を参照してください。

```python
import pyseekdb

client = pyseekdb.Client(path="./seekdb.db", database="hybrid_search_test")

collection = client.get_collection("hybrid_search_demo")

    {"category": "Programming", "topic": "python", "year": 2023, "popularity": 88},
    {"category": "AI", "topic": "deep learning", "year": 2024, "popularity": 92},
    {"category": "Data Science", "topic": "data analysis", "year": 2023, "popularity": 85},

```

## ステップ5：ハイブリッド検索を実行し、クエリ結果を出力する

`hybrid_search` メソッドを使用してハイブリッド検索クエリを実行し、クエリ結果を出力します。

:::tip

ハイブリッド検索の詳細については、[hybrid_search - ハイブリッド検索](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/400.dql/400.hybrid-search-of-api.md)を参照してください。

:::

```python
import pyseekdb

# Create embedded client
client = pyseekdb.Client(path="./seekdb.db", database="hybrid_search_test")
# get collection
collection = client.get_collection("hybrid_search_demo")

# Perform hybrid search
hybrid_result = collection.hybrid_search(
    query={"where_document": {"$contains": "machine learning"}, "n_results": 10},
    knn={"query_texts": ["AI research"], "n_results": 10},
    rank={"rrf": {}},
    n_results=5
)

# Print results
print("\nhybrid_search() Results:")
print(f"  ids: {hybrid_result ['ids'][0]}")
print(f"  Document: {hybrid_result ['documents'][0]}")
```

## ステップ6：環境をクリーンアップ

上記のサンプルデータベースとコレクションが不要になった場合は、`delete_collection` メソッドでコレクションを削除し、`delete_database` メソッドでデータベースを削除できます。

:::tip

* コレクションの削除に関する詳細については、[delete_collection - コレクションの削除](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/200.collection/400.delete-collection-of-api.md)を参照してください。

* データベースの削除に関する詳細については、[delete_database - データベースの削除](../../450.reference/900.sdk/10.pyseekdb-sdk/50.apis/110.database/500.delete-database-of-api.md)を参照してください。

:::

```python
import pyseekdb

# Create embedded client
admin = pyseekdb.AdminClient(path="./seekdb.db")
client = pyseekdb.Client(path="./seekdb.db", database="hybrid_search_test")

# Delete collection
client.delete_collection("hybrid_search_demo")
print(f"\nDeleted collection")

# Delete database
admin.delete_database("hybrid_search_test")
print(f"\nDeleted database")
```
