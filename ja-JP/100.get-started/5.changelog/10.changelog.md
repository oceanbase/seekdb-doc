# プロダクトニュース

## 2026.8.27: seekdb V1.4.0 リリース

seekdb V1.4.0は軽量化を中核に、エンジンを体系的に最適化・再構築しました。V1.3.0と比較して、バイナリサイズを63.9%、定常稼働時の平均メモリ使用量を73.6%、平均CPU使用量を70.3%削減しました。組み込みモードは、MySQLプロトコルで通信する独立したバックグラウンドプロセスへと刷新され、複数のアプリケーションで同一のデータベースインスタンスを共有できるようになりました。また、macOSの安定性を向上し、PL実行フレームワークをLLVM JITコンパイルからツリーウォーキングインタプリタへ再構築しました。

本バージョンでは、seekdbの技術スタックにRustを初めて導入し、MySQLプロトコルスタックとネットワークI/O層をRustで再実装しました。さらに、Bazelネイティブモジュール（Bzlmod）によるビルドをPreviewとしてサポートします。また、ベクトルインデックス、SQL実行、Windowsプラットフォーム、トランザクション、およびプライマリ・スタンバイ構成に関する問題を修正しました。

V1.0.x、V1.1.0、V1.2.0、V1.3.0からV1.4.0へのインプレースアップグレードはサポートされていません。アップグレードする場合は、OBDUMPER/OBLOADERまたはmysqldumpを使用して論理移行を行ってください。

詳細は、[seekdb V1.4.0 Release Notes](https://docs.seekdb.ai/seekdb/ja/releasenote-v1.4.0/)を参照してください。

## 2026.5.25: seekdb V1.3.0、pyseekdb V1.3.0、および seekdb-js V1.3.0 リリース

### seekdb V1.3.0

このリリースでは、Change Stream パイプライン上での非同期インデックス機能が追加されました（VectorDBBench における1000万件の混合ワークロードで、同期方式と比較して約22倍の同時クエリQPSを達成）。また、Windows および Android 向けの実験的なネイティブビルド、ベクトル Diff & Merge、非同期インデックスとのフォーク整合性対応、さらに小規模インスタンスにおけるアイドル時リソース使用量の削減が含まれています。V1.0.x、V1.1.0、V1.2.0 からのインプレースアップグレードはサポートされていないため、論理的なマイグレーションを使用してください。

### pyseekdb V1.3.0

pyseekdb V1.3.0 は、seekdb の非同期ベクトルインデックス構築との完全な統合を提供します。大量のベクトル書き込みはインデックス構築によってブロックされず、インデックス作成はバックグラウンドで実行されるため、書き込み性能が向上します。新しく **`Collection.refresh_index()`** が追加され、クライアントはデータベース側でインデックス更新が完了したことを確認するまでブロックします。これにより、書き込み後に refresh を実行した場合、データの強い整合性と即時検索可能性が保証されます。

* **適用シーン：** seekdb は 1.3.0 以降、非同期インデックスがデフォルトです。`add()`、`upsert()`、`update()` の後、かつ `query()` または `hybrid_search()` の前に、即時検索結果が必要な場合に呼び出します。
* **互換性：** On seekdb ≥ 1.3.0, `refresh_index()` はインデックス更新完了まで待機します。呼び出さない場合でも、一定時間後にバックグラウンド更新によりデータは検索可能になります。seekdb < 1.3.0 または OceanBase では `refresh_index()` は no-op（何も行いません）。

その他の変更については、以下を参照してください：[pyseekdb changelog](https://www.oceanbase.ai/docs/pyseekdb-changelog)。

### seekdb-js V1.3.0

seekdb-js V1.3.0 は、seekdb 1.3.0 の非同期ベクトルインデックス構築に対応し、新しい `collection.refresh_index()` API を追加しました。データ書き込み後にこのメソッドを呼び出すと、インデックス更新が完了するまで待機し、その後にドキュメントが検索可能になります。

* `collection.refresh_index()` を追加（インデックス更新完了まで待機）
* **When to use it:** seekdb は 1.3.0 以降、非同期インデックスがデフォルトです。`add()`、`upsert()`、`update()` の後、かつ `query()` または `hybrid_search()` の前に呼び出すことで、非同期構築されたベクトルインデックスが利用可能であることを保証します。
* **Compatibility:** On seekdb ≥ 1.3.0, `collection.refresh_index()` はインデックス更新を手動でトリガーします。呼び出さなくても一定時間後にデータは反映されます。seekdb < 1.3.0 または OceanBase では `collection.refresh_index()` は no-op です。

その他の変更については、以下を参照してください：[seekdb-js changelog](https://www.oceanbase.ai/docs/seekdb-js-changelog)。

## 2026.3.25 seekdb V1.2.0 リリース、pyseekdb および seekdb-js V1.2.0 リリース

### seekdb V1.2.0 リリース

seekdb V1.2.0 は、seekdbが単一マシンデータベースから高可用性アーキテクチャへと移行するための重要なステップを示す、マイルストーンとなる機能強化バージョンです。このバージョンでは、プライマリ/スタンバイデータベースによる高可用性ソリューションが導入され、データベースの災害復旧能力が大幅に向上しています。また、Fork Databaseをサポートし、データベース全体のデータを複数のバージョンで管理するニーズに対応しています。さらに、Diff & Merge構文が追加され、Gitに似たデータブランチの比較とマージ機能を提供しています。同時に、内部アーキテクチャの最適化とベクトル/全文検索のパフォーマンス最適化により、エンタープライズ向けアプリケーションシナリオに対して、より信頼性が高く効率的なデータベースサービスを提供します。

このバージョンの詳細については、[seekdb V1.2.0 Release Notes](../../450.reference/1300.release-notes/997.V1.2.0.md)を参照してください。

### pyseekdb V1.2.0 リリース

pyseekdb V1.2.0 では、以下の機能強化が行われました：

* 疎ベクトルインデックス：キーワードマッチングやテキスト検索などのシナリオのパフォーマンスを最適化するために、疎ベクトルインデックスをサポートしています。([#172](https://github.com/oceanbase/pyseekdb/pull/172))
* インデックス設定の強化：より多くのHNSWインデックス設定オプションと全文検索設定オプションをサポートしています。([#166](https://github.com/oceanbase/pyseekdb/pull/166))
* Embeddingモデルのサポート：
  * Text2Vec Embedding関数のサポートが追加されました。([#142](https://github.com/oceanbase/pyseekdb/pull/142))
  * Mistral Embedding関数のサポートが追加されました。([#153](https://github.com/oceanbase/pyseekdb/pull/153))
  * Morph Embedding関数のサポートが追加されました。([#143](https://github.com/oceanbase/pyseekdb/pull/143))

### seekdb-js V1.2.0 リリース

seekdb-js V1.2.0 では、以下の機能強化が行われました：

* 組み込みモード：組み込みモードの使用をサポートしています。
* 疎ベクトルインデックス：キーワードベースの検索能力を強化するために、疎ベクトルインデックスをサポートしています。
* インデックス設定の強化：より多くのHNSWインデックス設定オプションと全文検索設定オプションをサポートしています。
* ORM対応：Prisma、Drizzleアダプターをサポートし、組み込みモードでのseekdbのクエリと統合能力を拡張しています。

## 2026.1.30 seekdb V1.1.0 リリース、pyseekdb および seekdb-js V1.1.0 リリース

### seekdb V1.1.0 リリース

* seekdb は、MacOS 15 以降のシステムでネイティブコンパイルおよびローカル開発デバッグをサポートするようになりました。
Mac への seekdb インストールの詳細については、[パッケージ管理ツールによる seekdb のデプロイ](https://www.oceanbase.ai/docs/deploy-by-systemd)を参照してください。
* Fork Table 機能が追加されました。従来の CTAS の全量データコピーとは異なり、Fork Table はデータ量に関係なく高速な複製方法を提供します。テーブルレベルのストレージ再利用とコピーオンライト技術に基づき、一貫性のあるセマンティクスを満たしつつ、既存のデータ構成とストレージ構造を可能な限り再利用し、全量コピーを回避することで、作成時間とリソース消費を大幅に削減します。
* ストレージ容量が最適化されました。データストレージ、Clog ストレージ、システムログストレージについて、最小リソース仕様を全面的に最適化し、開発者のハードルをさらに下げました。
* メモリ管理戦略が最適化され、異なるデプロイ環境（例：大/小メモリ仕様、独立/非独立デプロイ）の要件に対応できるようになりました。

このバージョンの詳細については、[seekdb V1.1.0 Release Note](https://www.oceanbase.ai/docs/releasenote-v1.1.0)を参照してください。

### pyseekdb V1.1.0 リリース

pyseekdb V1.1.0 では、以下の機能強化が行われました：

* Collection の命名がより柔軟になりました：名前の最大長が 64 文字から **512 文字** に引き上げられ、より複雑なビジネスシナリオに対応できるようになりました。
* 全文検索機能が強化されました：`FulltextIndexConfig` が追加され、カスタム分かち書きとフィールドマッピングをサポートします。
* Embedding エコシステムが大幅に拡張されました：**11 種類** の主流 embedding プラットフォームが統合され、オープンソースおよび商用モデルをカバーしています。
* メタデータ永続化がアップグレードされました：embedding 関数情報をシステムテーブルに永続化できるようになり、開発者の利便性がさらに向上しました。
* table-fork 機能が新規追加されました：Collection レベルのスナップショットコピーをサポートし、データ実験とロールバックを簡素化します。(実験的機能)

このバージョンの詳細については、[pyseekdb 更新履歴](https://www.oceanbase.ai/docs/pyseekdb-changelog)を参照してください。

## 2025.11.14 seekdb V1.0.0とpyseekdb V1.0.0のリリース

### seekdb V1.0.0のリリース

seekdbはAIネイティブのハイブリッド検索データベースであり、ベクトル、テキスト、構造化データおよび半構造化データの機能を単一のデータベースに統合し、組み込みAI Functionsによりマルチモーダルなハイブリッド検索とインテリジェントな推論をサポートします。

このバージョンの詳細については、[seekdb V1.0.0 Release Note](https://www.oceanbase.ai/docs/releasenote-v1.0.0)を参照してください。

seekdbは以下のコアな利点を備えています：

* 迅速な構築

  数行のPythonコードでAIアプリケーションを構築できます。軽量なアーキテクチャで、1C2GのリソースでVectorDBBenchを実行できます。

* ハイブリッド検索

  ベクトル、全文、スカラーのフィルタリングを1つのクエリで完了し、粗選別 + 細選別の多段階検索パスをサポートします。

* マルチモーダルデータとインデックス

  単一のエンジン内で、スカラー、ベクトル、テキスト、JSON、GISなどのマルチモーダルデータとインデックスを同時にサポートします。

* AIの組み込み

  データベース内でベクトル埋め込み、推論、プロンプト管理、再配置を完了し、document-in/data-outの完全なRAGプロセスをサポートします。

* SQLネイティブ

  成熟したOceanBaseエンジンに基づいており、リアルタイム書き込み、リアルタイムクエリをサポートし、ACIDトランザクションを保証し、MySQLエコシステムと互換性があります。

### pyseekdb V1.0.0のリリース

pyseekdbはOceanBaseが提供するPythonクライアントです。一連のAPIを基盤として実装されており、2種類のデータベース接続モードを提供し、組み込みモードのseekdbへの接続や、リモートサーバーへの接続（サーバーモードのseekdbおよびOceanBaseデータベースへの接続）をサポートします。

pyseekdbの詳細と使用例については、[pyseekdb クイックスタート](https://www.oceanbase.ai/docs/pyseekdb-sdk-get-started)を参照してください。
