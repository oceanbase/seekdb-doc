# seekdb Agent Skills

seekdb Agent Skillsは、「AIが自動的に呼び出せるナレッジパッケージ + ワークフロー」と理解できます。seekdbに関する質問をした場合、AIはスキルの説明に従って自動的にドキュメントを検索し、操作を実行します。コマンドを覚えたり、ドキュメントを手動でコピーしたりする必要はありません。Cursor、Claude Code、OpenClaw、その他の対応しているAIツールを使用している場合でも、これらのスキルをインストールすることで、AIにseekdbのドキュメントの参照やデータのインポート・エクスポートなどの操作を自動化させ、より効率的にseekdbを利用できます。

## サポートされているAIプログラミングツール

| ツール | スキルインストールディレクトリ |
| --- | --- |
| Claude Code | `.claude/skills` |
| OpenClaw | `~/.openclaw/workspace/skills` |
| Cursor | `.cursor/skills` |
| Codex | `.codex/skills` |
| OpenCode | `.opencode/skills` |
| GitHub Copilot | `.github/skills` |
| Qoder | `.qoder/skills` |
| Trae | `.trae/skills` |

上記の表に記載されていないツールを使用している場合は、Claude Codeをインストール時に選択することができます。インストーラーはスキルを`.claude/skills`ディレクトリにコピーします。その後、ディレクトリ名をご使用のツールの要件に合わせて変更するか、対応するディレクトリに移動するだけで、スキル自体は汎用的に利用できます。

## サポートされているスキル

### seekdb：ドキュメントナレッジベース

seekdbの公式ドキュメント（クイックスタート、開発ガイド、SDK/API、マルチモデルデータ、統合と運用保守、チュートリアルとリファレンスなど）を網羅しています。AIはあなたの質問に基づいて対応するドキュメントを自動的に特定し、答えや例を提示します。

典型的な質問例：

* seekdbのデプロイ方法は？
* seekdbのベクトル検索の使い方は？
* seekdbでハイブリッド検索を実装するにはどうすればよいですか？

### importing-to-seekdb：データインポート + ベクトル化

データをseekdbのコレクション(Collection)にインポートし、指定した列のベクトル化をサポートします。インポート前にExcel/CSVの構造とサンプルデータ(sample_products.csv/ sample_products.xlsx)をプレビューできます。

典型的な使用例：

* まず、importing-to-seekdbスキル内のサンプルExcelをプレビューします。
* sample_products.xlsxをseekdbにインポートし、Details列をベクトル化します。

### querying-from-seekdb：クエリとエクスポート

メタデータ条件（評価、ブランド、価格など）でフィルタリングし、スカラー検索を実行します。全文検索と意味解析を組み合わせたハイブリッド検索を行い、結果はRRF（逆ランキング融合）でソートされます。結果をCSVまたはExcel形式でエクスポートし、分析やレポート作成に活用できます。

典型的な使用例：

* 評価が4.3以上でAMOLEDディスプレイのスマートフォンを2機推薦してください。
* 評価が4.3以上でAMOLEDディスプレイのスマートフォンを検索し、Excelにエクスポートしてください。

## seekdb Agent Skillsのインストール

対話型インストーラを使用してseekdb Agent Skillsをインストールします。

1. インストールディレクトリを選択します。

    対話型インストーラは、スキルをインストーラコマンドを実行した現在のディレクトリにインストールします（OpenClawは除く）。インストールディレクトリを変更する場合は、まずインストールディレクトリに移動してから、インストール操作を実行してください。OpenClawのスキルはユーザーディレクトリ`~/.openclaw/workspace/skills`にインストールされます。

2. プラグインパッケージをインストールします。

    ```python
    pip install seekdb-agent-skills
    ```

3. 対話型インストーラを実行します。

    ```shell
    seekdb-agent-skills
    ```

4. ツールを選択します。

    対話型インストーラでは、インストールするツールを選択できます。

    キーボードの**↑↓**キーでツールを選択し、**Enter**キーでインストールを確定、**Ctrl+C**でインストールをキャンセルします。

    ```shell
    🚀 seekdb Agent Skills Installer
    ==================================================

    📋 Select tool to install to:
    ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
    » Claude Code
    OpenClaw
    Cursor
    Codex
    OpenCode
    GitHub Copilot
    Qoder
    Trae
    ```

5. インストール先を確認します。

    ```shell
    🚀 seekdb Agent Skills Installer
    ==================================================

    📋 Select tool to install to:
    ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): Cursor

    📁 Project root: /home/admin
    (Skills will be installed under .cursor/skills)
    ? Install skills to this directory? (Y/n)
    ```

    ここで`Y`を選択すると次のステップに進みます。`n`を選択するとインストーラが終了します。

6. インストールするスキルを選択します

    AIツールの参照のみが必要な場合は、seekdbのドキュメントを参照してください。seekdbにExcel/CSVファイルをインポートおよびエクスポートする必要がある場合は、`importing-to-seekdb`と`querying-from-seekdb`の両方のスキルを選択できます。

    キーボードの**↑↓**キーでツールを選択し、**スペース**キーで複数選択し、**Enter**キーでインストールを確定、**Ctrl+C**でインストールをキャンセルします。

    ```shell
    📦 Select skills to install:
    ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
    » ● seekdb
      ○ importing-to-seekdb
      ○ querying-from-seekdb
    ```

## 例

サポートされているAIツールの使い方は似ています。以下では、Cursor、Claude Code、OpenClawツールを使用した例を示します：

* Cursorでの使用

  1. Cursorを使用して、スキルがインストールされているプロジェクトのルートディレクトリを開きます。
  2. Cursorで質問します。例：

        ```shell
        Macでseekdbをデプロイするにはどうすればよいですか？
        ```

* Claude Codeでの使用

  1. スキルがインストールされているプロジェクトのルートディレクトリでClaude Codeを開きます。
  2. Claude Codeで質問します。例：

        ```shell
        seekdbのベクトル検索の使い方を教えてください。
        ```

* OpenClawでの使用

  1. 任意のディレクトリでOpenClawを開きます。

        ```shell
        openclaw tui
        ```

  2. OpenClawで質問します。例：

        ```shell
        seekdbでハイブリッド検索を実装するにはどうすればよいですか？
        ```
