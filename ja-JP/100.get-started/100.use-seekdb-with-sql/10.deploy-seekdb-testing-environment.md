# SQLによるハイブリッド検索のクイック体験

seekdbはSDKまたはSQLを介して使用できます。本記事では、SQLを使用してハイブリッド検索をクイックに体験する方法を紹介します。

:::info
SDKを使用したseekdbの利用方法については、[Python SDKによる組み込みseekdbの体験](../50.use-seekdb-with-sdk/25.using-seekdb-in-python-sdk.md)を参照してください。
:::

この例では、以下の操作を行います：

1. サーバーモードのseekdbをデプロイします。
2. seekdbに接続します。
3. データベースを作成します。
4. テーブルを作成し、データを挿入します。
5. ハイブリッド検索を実行します。
6. 検索を最適化します。
7. 環境をクリーンアップします。

## デプロイメントモード

seekdbは、迅速なプロトタイプ開発から大量ユーザーのサポートまで、多様で柔軟なデプロイメントモードを提供し、あらゆるアプリケーションニーズに対応します。

* 埋め込みモード

    seekdbは軽量ライブラリとしてアプリケーションに埋め込まれ、pipでワンクリックでインストールできます。個人学習や迅速なプロトタイプ開発に適しており、さまざまなエンドデバイス上で効率的に動作します。

* サーバーモード

    テスト環境および本番環境へのデプロイメントに推奨されるモードです。軽量で使いやすく、安定して効率的なサービス提供に適しています。

:::info
seekdbのより詳細で包括的なデプロイ方法については、[デプロイの概要](../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。
:::

## ステップ2：seekdbに接続する

MySQLクライアントを使用してseekdbに接続します。具体的な接続コマンドは以下のとおりです：

```shell
mysql -h127.0.0.1 -uroot -P2881 -p****** -A
```

## ステップ3：データベースを作成する

`my_test` という名前のデータベースを作成します。seekdbのデフォルトデータベースであるtestを使用して体験することもできます。

1. データベースを作成します。

    ```sql
    create database my_test;
    ```

2. カスタムデータベースに切り替えます。

    ```sql
    use my_test;
    ```

## ステップ4：サンプルテーブルを作成し、データを挿入する

1. スカラーカラム、ベクトルカラム、全文インデックスカラムを含むドキュメントテーブルを作成し、スカラー条件とハイブリッド検索を伴う全文検索をデモンストレーションします。

    ```sql
    CREATE TABLE doc_table(
        c1 INT,
        vector VECTOR(3),
        query VARCHAR(255),
        content VARCHAR(255),
        VECTOR INDEX idx1(vector) WITH (distance=l2, type=hnsw, lib=vsag),
        FULLTEXT INDEX idx2(query),
        FULLTEXT INDEX idx3(content)
    )
    ORGANIZATION HEAP;
    ```

2. データを挿入します。

    ```sql
    INSERT INTO doc_table VALUES
    (1, '[1,2,3]', "hello world", "seekdb Elasticsearch database"),
    (2, '[1,2,1]', "hello world, what is your name", "seekdb database"),
    (3, '[1,1,1]', "hello world, how are you", "seekdb mysql database"),
    (4, '[1,3,1]', "real world, where are you from", "postgres mysql database"),
    (5, '[1,3,2]', "real world, how old are you", "redis mysql database"),
    (6, '[2,1,1]', "hello world, where are you from", "starrocks seekdb database");
    ```

## ステップ5：ハイブリッド検索を実行する

1. 検索パラメータを設定します。

    ```sql
    SET @parm = '{
        "query": {
            "query_string": {
                "fields": ["query", "content"],
                "query": "hello oceanbase"
            }
        },
        "knn" : {
            "field": "vector",
            "k": 5,
            "query_vector": [1,2,3]
        }
    }';
    ```

2. クエリを実行し、クエリ結果を返します。

    ```sql
    SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
    ```

## ステップ6：検索の最適化を行う

ハイブリッド検索では、`boost` パラメーターを使用してフルテキスト検索とベクトル検索の重み比率を調整し、検索結果を最適化できます。例えば、フルテキスト検索の重みを高めるには、次のようにします：

1. 検索パラメーターを設定します。

    ```sql
    SET @parm = '{
        "query": {
            "query_string": {
                "fields": ["query", "content"],
                "query": "hello oceanbase",
                "boost": 2.0
            }
        },
        "knn" : {
            "field": "vector",
            "k": 5,
            "query_vector": [1,2,3],
            "boost": 1.0
        }
    }';
    ```

2. クエリを実行して、クエリ結果を返します。

    ```sql
    SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
    ```

    実行結果は次のとおりです：

    ```sql
    +----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
    | json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
    +----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
    | [
      {
        "c1": 1,
        "query": "hello world",
        "_score": 1.7432432432432434,
        "vector": "[1,2,3]",
        "content": "seekdb Elasticsearch database"
      },
      {
        "c1": 3,
        "query": "hello world, how are you",
        "_score": 1.0096539326751595,
        "vector": "[1,1,1]",
        "content": "seekdb mysql database"
      },
      {
        "c1": 2,
        "query": "hello world, what is your name",
        "_score": 0.9959839324096386,
        "vector": "[1,2,1]",
        "content": "seekdb database"
      },
      {
        "c1": 6,
        "query": "hello world, where are you from",
        "_score": 0.7006369426751594,
        "vector": "[2,1,1]",
        "content": "starrocks seekdb database"
      },
      {
        "c1": 5,
        "query": "real world, how old are you",
        "_score": 0.41421356,
        "vector": "[1,3,2]",
        "content": "redis mysql database"
      },
      {
        "c1": 4,
        "query": "real world, where are you from",
        "_score": 0.30901699,
        "vector": "[1,3,1]",
        "content": "postgres mysql database"
      }
    ] |
    +----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
    1 row in set
    ```

`boost` パラメーターを調整することで、キーワード検索とセマンティック検索の最終的なランキングにおける重みを制御できます。例えば、キーワードの一致に重点を置く場合は `query_string` の `boost` 値を高め、意味的類似性に重点を置く場合は `knn` の `boost` 値を高めることができます。

## ステップ7：環境のクリーンアップ

上記のサンプルデータベースとテーブルが不要になった場合は、以下の操作を実行して削除できます。

1. サンプルテーブルを削除します。

    ```sql
    DROP TABLE doc_table;
    ```

2. カスタムデータベースを削除します。

    ```sql
    DROP DATABASE my_test;
    ```
