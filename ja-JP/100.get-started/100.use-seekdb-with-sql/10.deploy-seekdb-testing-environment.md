# SQLを使用してサーバーモードのseekdbを体験する

seekdbはSDKまたはSQLのいずれかの方法で使用できます。この記事では、SQLを使用してサーバーモードのseekdbを手早く体験する方法について説明します。

:::info
SDKを使用したseekdbの使用方法については、[Python SDKを使用した組み込みseekdbの体験](../50.use-seekdb-with-sdk/25.using-seekdb-in-python-sdk.md)を参照してください。
:::

この例では、以下の操作を実行します：

1. サーバーモードのseekdbをデプロイします。
2. seekdbに接続します。
3. データベースを作成します。
4. テーブルを作成し、データを挿入します。
5. ハイブリッド検索を実行します。
6. 検索の最適化を行います。
7. 環境をクリーンアップします。

## デプロイメントモード

seekdbは、迅速なプロトタイプ開発から大量ユーザーのサポートまで、あらゆるアプリケーションニーズに対応する多様で柔軟なデプロイメントモードを提供します。

* 埋め込みモード

    seekdbは軽量ライブラリとしてアプリケーションに埋め込まれ、pipを使ったワンクリックインストールをサポートします。個人学習や迅速なプロトタイプ開発に適しており、さまざまなエンドデバイス上で効率的に動作します。

* サーバーモード

    テスト環境および本番環境へのデプロイメントに推奨されるモードです。軽量で使いやすく、安定した高効率なサービス提供に適しています。

:::info
seekdbのより詳細で包括的なデプロイ方法については、[デプロイの概要](../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。
:::

## ステップ１：サーバーモードのseekdbをデプロイする

### 前提条件

デプロイを開始する前に、環境が以下の要件を満たしていることを確認してください：

* お使いの環境はRPMプラットフォームシステムであること。現在、サポートされているシステムは以下の通りです。

  * Anolis OS 8.X バージョン（カーネル Linux 3.10.0 バージョン以上）
  * Alibaba Cloud Linux 2/3 バージョン（カーネル Linux 3.10.0 バージョン以上）
  * Red Hat Enterprise Linux Server 7.X バージョン、8.X バージョン（カーネル Linux 3.10.0 バージョン以上）
  * CentOS Linux 7.X バージョン、8.X バージョン（カーネル Linux 3.10.0 バージョン以上）
  * Debian 9.X バージョン以上（カーネル Linux 3.10.0 バージョン以上）
  * Ubuntu 20.X バージョン以上（カーネル Linux 3.10.0 バージョン以上）
  * SUSE / OpenSUSE 15.X バージョン以上（カーネル Linux 3.10.0 バージョン以上）
  * openEuler 22.03 および 24.03 バージョン（カーネル Linux 5.10.0 バージョン以上）
  * KylinOS V10 バージョン
  * 統信 UOS 1020a/1021a/1021e/1001c バージョン
  * 中科方德 NFSChina 4.0 バージョン以上
  * 浪潮 Inspur kos 5.8 バージョン

* 現在の環境におけるCPUの最低要件は1コアです。

* 現在の環境における利用可能なメモリの最低要件は2GBです。

* お使いの環境にMySQLクライアントがインストール済みであること。

* お使いのユーザーがsudoコマンドを実行する権限を持っていること。

* yum install を使用したデプロイに必要な条件

  * お使いの環境にjqコマンドラインツールがインストールされており、systemdがシステムおよびサービスマネージャーとして正しく設定されていること。

* docker を使用したデプロイに必要な条件

  * Dockerがインストールされており、Dockerサービスが起動していること。

### yum install を使用したseekdbのクイックデプロイ

1. seekdbをインストールします。

    ```shell
    curl -fsSL https://obportal.s3.ap-southeast-1.amazonaws.com/download-center/opensource/seekdb/seekdb_install.sh | sudo bash
    ```

    :::tip

    オンラインでインストールされるseekdbは最新バージョンです。他のバージョンをインストールする場合は、[パッケージ管理ツールを使用したseekdbのデプロイ](../../400.guides/400.deploy/700.server-mode/100.deploy-by-systemd.md) の**オフラインデプロイ**を参照してください。

    :::

2. seekdbを起動します。

    ```shell
    sudo systemctl start seekdb
    ```

3. seekdbの起動状態を確認します。

    ```shell
    sudo systemctl status seekdb
    ```

    状態が `Service is ready` と表示されたら、seekdbが正常に起動したことを意味します。

4. seekdbに接続します。

    ```shell
    mysql -h127.0.0.1 -uroot -P2881 -A test
    ```

### seekdbコンテナ環境のクイックデプロイ

お使いの環境にDockerがインストールされ、Dockerサービスが起動している場合は、Dockerコンテナを使用してseekdbをデプロイすることもできます。Dockerデプロイの詳細については、[seekdbコンテナ環境のデプロイ](../../400.guides/400.deploy/700.server-mode/200.deploy-by-docker.md)を参照してください。

seekdbインスタンスを直接起動します。

```shell
sudo docker run -d -p 2881:2881 oceanbase/seekdb
```

:::info
Dockerイメージの取得に失敗した場合は、quay.ioまたはghcr.ioリポジトリからイメージを取得することもできます。上記の取得コマンドの `oceanbase/seekdb` を `quay.io/oceanbase/seekdb` または `ghcr.io/oceanbase/seekdb` に置き換えるだけです。例えば、`sudo docker run -d -p 2881:2881 quay.io/oceanbase/seekdb` を実行してquay.ioからイメージを取得します。
:::

## ステップ2：seekdbに接続する

MySQLクライアントを使用してseekdbに接続します。具体的な接続コマンドは以下のとおりです：

```shell
mysql -h127.0.0.1 -uroot -P2881 -p****** -A
```

## ステップ3：データベースを作成する

`my_test` という名前のデータベースを作成します。seekdbのデフォルトデータベースであるtestを使用して体験することもできます。

1. データベースを作成します。

    ```sql
    create database my_test;
    ```

2. カスタムデータベースに切り替えます。

    ```sql
    use my_test;
    ```

## ステップ4：サンプルテーブルを作成し、データを挿入する

1. スカラーカラム、ベクトルカラム、全文インデックスカラムを含むドキュメントテーブルを作成し、スカラー条件とハイブリッド検索を伴う全文検索をデモンストレーションします。

    ```sql
    CREATE TABLE doc_table(
        c1 INT,
        vector VECTOR(3),
        query VARCHAR(255),
        content VARCHAR(255),
        VECTOR INDEX idx1(vector) WITH (distance=l2, type=hnsw, lib=vsag),
        FULLTEXT INDEX idx2(query),
        FULLTEXT INDEX idx3(content)
    )
    ORGANIZATION HEAP;
    ```

2. データを挿入します。

    ```sql
    INSERT INTO doc_table VALUES
    (1, '[1,2,3]', "hello world", "seekdb Elasticsearch database"),
    (2, '[1,2,1]', "hello world, what is your name", "seekdb database"),
    (3, '[1,1,1]', "hello world, how are you", "seekdb mysql database"),
    (4, '[1,3,1]', "real world, where are you from", "postgres mysql database"),
    (5, '[1,3,2]', "real world, how old are you", "redis mysql database"),
    (6, '[2,1,1]', "hello world, where are you from", "starrocks seekdb database");
    ```

## ステップ5：ハイブリッド検索を実行する

1. 検索パラメータを設定します。

    ```sql
    SET @parm = '{
        "query": {
            "query_string": {
                "fields": ["query", "content"],
                "query": "hello oceanbase"
            }
        },
        "knn" : {
            "field": "vector",
            "k": 5,
            "query_vector": [1,2,3]
        }
    }';
    ```

2. クエリを実行し、クエリ結果を返します。

    ```sql
    SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
    ```

## ステップ6：検索の最適化を行う

ハイブリッド検索では、`boost`パラメータを使用して全文検索とベクトル検索の重み比率を調整し、検索結果を最適化できます。例えば、全文検索の重みを高めるには、次の手順を実行します。

1. 検索パラメータを設定します。

    ```sql
    SET @parm = '{
        "query": {
            "query_string": {
                "fields": ["query", "content"],
                "query": "hello oceanbase",
                "boost": 2.0
            }
        },
        "knn" : {
            "field": "vector",
            "k": 5,
            "query_vector": [1,2,3],
            "boost": 1.0
        }
    }';
    ```

2. クエリを実行し、クエリ結果を返します。

    ```sql
    SELECT json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm));
    ```

    結果は次のとおりです：

    ```sql
    +----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
    | json_pretty(DBMS_HYBRID_SEARCH.SEARCH('doc_table', @parm))                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
    +----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------+
    | [
      {
        "c1": 1,
        "query": "hello world",
        "_score": 1.7432432432432434,
        "vector": "[1,2,3]",
        "content": "seekdb Elasticsearch database"
      },
      {
        "c1": 3,
        "query": "hello world, how are you",
        "_score": 1.0096539326751595,
        "vector": "[1,1,1]",
        "content": "seekdb mysql database"
      },
      {
        "c1": 2,
        "query": "hello world, what is your name",
        "_score": 0.9959839324096386,
        "vector": "[1,2,1]",
        "content": "seekdb database"
      },
      {
        "c1": 6,
        "query": "hello world, where are you from",
        "_score": 0.7006369426751594,

        "content": "starrocks seekdb database"
      },
      {
        "c1": 5,
        "query": "real world, how old are you",
        "_score": 0.41421356,
        "vector": "[1,3,2]",
        "content": "redis mysql database"
      },
      {
        "c1": 4,
    ```

`boost`パラメータを調整することで、キーワード検索と意味検索の最終的なランキングにおける重みを制御できます。例えば、キーワードの一致に重点を置く場合は、`query_string`の`boost`値を高めることができます。意味的類似性に重点を置く場合は、`knn`の`boost`値を高めることができます。

## ステップ7：環境のクリーンアップ

上記のサンプルデータベースとテーブルが不要になった場合は、以下の操作を実行して削除できます。

1. サンプルテーブルを削除します。

    ```sql
    DROP TABLE doc_table;
    ```

2. カスタムデータベースを削除します。

    ```sql
    DROP DATABASE my_test;
    ```
