# SQLを使用したベクトル検索のクイック体験

seekdbはSDKまたはSQLのいずれかの方法で使用できます。本記事では、SQLを使用してベクトル検索を手軽に試す方法を紹介します。

:::info
SDKを使用したseekdbの利用方法については、[Python SDKを使用した組み込みseekdbの体験](../50.use-seekdb-with-sdk/25.using-seekdb-in-python-sdk.md)を参照してください。
:::

この例では、以下の操作を行います：

1. サーバーモードのseekdbをデプロイします。
2. seekdbに接続します。
3. データベースを作成します。
4. テーブルを作成し、データを挿入します。
5. ベクトル検索を実行します。
6. 環境をクリーンアップします。

## デプロイメントモード

seekdbは、迅速なプロトタイプ開発から大量ユーザーのサポートまで、あらゆるアプリケーションニーズに対応する多様で柔軟なデプロイメントモードを提供します。

* 埋め込みモード

    seekdbは軽量ライブラリとしてアプリケーションに埋め込まれ、pipを使ったワンクリックインストールが可能です。個人学習や迅速なプロトタイプ開発に適しており、さまざまなエンドデバイス上で効率的に動作します。

* サーバーモード

    テスト環境および本番環境へのデプロイメントに推奨されるモードです。軽量で使いやすく、安定した高効率なサービス提供に適しています。

:::info
seekdbのより詳細で包括的なデプロイ方法については、[デプロイの概要](../../400.guides/400.deploy/50.deploy-overview.md)を参照してください。
:::

## ステップ2：seekdbに接続する

MySQLクライアントを使用してseekdbに接続します。具体的な接続コマンドは以下のとおりです：

```shell
mysql -h127.0.0.1 -uroot -P2881 -p****** -A
```

## ステップ3：データベースを作成する

`my_test` という名前のデータベースを作成します。seekdbのデフォルトデータベースであるtestを使用して体験することもできます。

1. データベースを作成します。

    ```sql
    create database my_test;
    ```

2. カスタムデータベースに切り替えます。

    ```sql
    use my_test;
    ```

## ステップ4：サンプルテーブルを作成し、データを挿入する

1. ベクトル列とインデックスを作成する

    テーブル作成時に、`VECTOR(dim)` データ型を使用して、特定の列をベクトル列として宣言し、その次元数を指定できます。ベクトルインデックスはベクトル列に作成する必要があり、少なくとも `type` と `distance` の2つのパラメータを指定する必要があります。

    例では、ベクトル列 `embedding` を作成し、ベクトルデータの次元を `3` に設定します。また、`embedding` 列にHNSWインデックスを作成し、距離アルゴリズムをL2と指定します。

    ```sql
    CREATE TABLE t1(
        id INT PRIMARY KEY,
        doc VARCHAR(200),
        embedding VECTOR(3),
        VECTOR INDEX idx1(embedding) WITH (distance=L2, type=hnsw)
        );
    ```

2. データを挿入します。

    ```sql
    INSERT INTO t1
    VALUES (1, 'リンゴ', '[1.2,0.7,1.1]'),
            (2, 'バナナ', '[0.6,1.2,0.8]'),
            (3, 'オレンジ','[1.1,1.1,0.9]'),
            (4, 'ニンジン', '[5.3,4.8,5.4]'),
            (5, 'ほうれん草', '[4.9,5.3,4.8]'),
            (6, 'トマト','[5.2,4.9,5.1]');
    ```

## ステップ5：ベクトル検索を実行する

ベクトル検索を実行するには、検索条件としてベクトルを提供する必要があります。例えば、すべての `'果物'` に対応するベクトルが `[0.9, 1.0, 0.9]` である場合、対応するSQLは次のとおりです：

```sql
SELECT id, doc FROM t1
ORDER BY l2_distance(embedding, '[0.9, 1.0, 0.9]')
APPROXIMATE LIMIT 3;
```

期待される実行結果は次のとおりです：

```shell
+----+--------+
| id | doc    |
+----+--------+
|  3 | 橙子   |
|  2 | 香蕉   |
|  1 | 苹果   |
+----+--------+
3 rows in set
```

## ステップ6：環境をクリーンアップする

上記のサンプルデータベースとテーブルが不要になった場合、以下の操作を実行して削除できます。

1. サンプルテーブルを削除します。

    ```sql
    DROP TABLE t1;
    ```

2. カスタムデータベースを削除します。

    ```sql
    DROP DATABASE my_test;
    ```
