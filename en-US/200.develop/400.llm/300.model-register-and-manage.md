# Register and manage AI models and endpoints

This topic describes how to register and manage AI models and endpoints in seekdb.

## Prerequisites

* You have the required permissions for AI models. For more information, see [Manage AI model permissions](200.model-service-permission.md).
* You have obtained the API key for the third-party model service.

## Register and manage AI models and endpoints by using the system package

The `DBMS_AI_SERVICE` package provides the ability to manage AI models and endpoints. It supports the following operations:

| **Operation** | **Description** |
| ------ | ------ |
| CREATE_AI_MODEL | Creates an AI model object. |
| DROP_AI_MODEL | Drops an AI model object. |
| CREATE_AI_MODEL_ENDPOINT | Creates an AI model endpoint object. |
| ALTER_AI_MODEL_ENDPOINT | Modifies an AI model endpoint object. |
| DROP_AI_MODEL_ENDPOINT | Drops an AI model endpoint object. |

You can call this system package to directly manage AI models and endpoints in seekdb without relying on external services. For more information about the parameters and syntax, see [DBMS_AI_SERVICE](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018307).

:::tip
For more information about the supported AI model providers and their corresponding URLs, see [CREATE_AI_MODEL_ENDPOINT](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004479800).
:::

## Register Model and endpoint templates

Register the model and the endpoint of the model by executing the `CREATE_AI_MODEL` and `CREATE_AI_MODEL_ENDPOINT` statements, respectively. The following example registers three model keys `ob_complete`, `ob_embed`, and `ob_rerank` to be used for text generation (`AI_COMPLETE`), vector embedding (`AI_EMBED`), and reranking (`AI_RERANK`). Replace `access_key` with your actual API key.

:::info

If you want to use only a specific category of AI function, you can register only the model and endpoint corresponding to the function. For example, if you want to use only `AI_COMPLETE`, you only need to complete the `Register Text Generation Model and Endpoint` step below.

:::

### Register an embedded model and endpoint

Used with `AI_EMBED`.

import Tabs from '@theme/Tabs';
import TabItem from '@theme/TabItem';

<Tabs>
  <TabItem value="Aliyun" label="Aliyun" default>

    This example shows how to register an embedding model and endpoint for Alibaba Cloud (compatible with the OpenAI format).

    ```shell
    CALL DBMS_AI_SERVICE.DROP_AI_MODEL ('ob_embed');
    CALL DBMS_AI_SERVICE.DROP_AI_MODEL_ENDPOINT ('ob_embed_endpoint');

    CALL DBMS_AI_SERVICE.CREATE_AI_MODEL(
    'ob_embed', '{
        "type": "dense_embedding",
        "model_name": "BAAI/bge-m3"
    }');

    CALL DBMS_AI_SERVICE.CREATE_AI_MODEL_ENDPOINT (
    'ob_embed_endpoint', '{
        "ai_model_name": "ob_embed",
        "url": "https://dashscope.aliyuncs.com/compatible-mode/v1/embeddings",
        -- Replace this with the actual access key
        "access_key": "sk-xxxxxxxxxxxxxxxxxxxxxxxxxxx",
        "provider": "aliyun-openAI"
    }');
    ```

## View information about AI models and endpoints

seekdb allows you to view information about AI models and endpoints by using views:

| View | Description |
|-----|------|
| [CDB/DBA_OB_AI_MODELS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018318) | Views information about AI models. |
| [CDB/DBA_OB_AI_MODEL_ENDPOINTS](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004018317) | Views information about AI model endpoints. |
