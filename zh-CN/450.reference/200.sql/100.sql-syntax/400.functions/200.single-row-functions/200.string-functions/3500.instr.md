# INSTR

## 声明

```sql
INSTR(str,substr)
```

## 说明

返回字符串 `str` 中子字符串的第一个出现位置。这和 `LOCATE()` 的双参数形式相同，除非参数的顺序被颠倒。

## 示例

```sql
SELECT INSTR('foobarbar', 'bar'), INSTR('xbar', 'foobar');
+---------------------------+-------------------------+
| INSTR('foobarbar', 'bar') | INSTR('xbar', 'foobar') |
+---------------------------+-------------------------+
|                         4 |                       0 |
+---------------------------+-------------------------+
1 row in set (0.001 sec)
```
