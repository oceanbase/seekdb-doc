# V1.4.0

## 版本信息
+ 发布时间：2026 年 8 月 27 日
+ 版本号：V1.4.0
+ RPM 版本号：seekdb-1.4.0-100000172026082615

## 版本概览
seekdb V1.4.0 以轻量化为核心主线，通过系统性瘦身与重构，资源占用大幅下降；嵌入式接入架构升级，支持多应用共享同一实例；macOS 稳定性提升。同时首次引入 Rust 技术栈、Bazel 构建支持（Preview），推进开发者生态。

## 重点改进
### 资源开销大幅收敛
V1.4.0 对引擎进行系统性资源瘦身，面向嵌入式与端侧场景显著降低资源占用。

**二进制体积**

| 指标 | V1.3.0 | V1.4.0 | 降幅 |
| --- | --- | --- | --- |
| 二进制 | 366.2 MiB | 132.4 MiB | 63.9% |
| Python 包 | 160.0 MiB | 50.0 MiB | 68.8% |


**稳态运行资源**

| 指标 | V1.3.0 | V1.4.0 | 降幅 |
| --- | --- | --- | --- |
| 稳态 CPU 均值 | 0.05 核 | 0.01 核 | 70.3% |
| 稳态内存均值 | 630.6 MiB | 166.3 MiB | 73.6% |


**构建时间（macOS / M4）**

| 指标 | V1.3.0 | V1.4.0 | 降幅 |
| --- | --- | --- | --- |
| 编译耗时 | 16:31.7 | 6:16.4 | 62.0% |
| 编译 CPU 时间 | 7080.5s | 2482.9s | 64.9% |


关键优化方向：

+ **分配器优化**：集成 jemalloc，降低内存碎片。
+ **空闲态常驻内存收敛**：回收 memstore、plan cache、kv cache 等空闲态内存，显著降低常驻占用。
+ **线程与栈开销精简**：精简冗余后台线程，下调默认线程栈尺寸。
+ **二进制体积收敛**：清除冗余代码与依赖，代码段大幅下降。

### macOS 稳定性提升
V1.4.0 对 macOS 平台运行时质量做了系统性提升。GIS 计算、排序、数值类型转换、浮点运算、PL 等关键路径在 macOS 上的行为偏差被收敛，日志时间戳格式化性能得到改善。

## 新特性
### 嵌入式接入架构升级
V1.4.0 将嵌入式模式从原先在宿主进程内执行，升级为后台独立进程 + MySQL 协议通信。

+ **多语言接入收口**：各语言不再各自编译独立的内核产物，统一通过 [seekdb-bindings](https://github.com/oceanbase/seekdb-bindings) 提供的共享底层接入。
+ **支持多应用共享同一实例**：多个嵌入式应用可同时访问同一数据库实例，改变以往各应用无法共享数据的局面。

## 特性优化
### PL 执行框架重构
V1.4.0 将 PL 执行框架从基于 LLVM-JIT 的即时编译重构为 tree-walking 解释执行，构建依赖更少、执行更轻量，跨平台一致性更好；多数场景下执行性能得以保持，兼顾轻量化与可用性能。

## 开发者生态
### Rust 技术栈引入
V1.4.0 首次引入 Rust 语言进入 seekdb 开发技术栈，将 MySQL 协议栈与网络 IO 层整体重写为 Rust 实现，seekdb 从单一 C++ 迈向 C++ 与 Rust 并存的混合栈。Rust 的内存安全与类型系统为底层模块的长期演进提供更稳健的基座，也拓宽了开发者生态——熟悉 Rust 的开发者可直接参与核心模块共建，无需跨越纯 C++ 大型工程的参与门槛。

### Bazel 构建支持（Preview）
V1.4.0 引入 Bazel 原生模块（Bzlmod）作为构建体系的预览支持，面向开发者与社区贡献者。Bazel 提供增量编译与构建结果缓存能力，并支持对大型 C++ 工程的模块依赖边界进行约束与可视化分析，降低跨模块耦合的构建与维护成本。该能力当前为 Preview，后续作为构建与依赖治理的长期演进方向。
