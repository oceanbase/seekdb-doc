# V1.3.0

## 版本信息

* 发布时间：2026 年 5 月 25 日

* 版本号：V1.3.0

* RPM 版本号：seekdb-1.3.0.0-100000092026051510

## 版本概览

seekdb V1.3.0 版本是一个面向多平台与高性能的重要版本。该版本引入了异步索引（Async Index）能力，通过全新的 Change Stream 增量计算框架，实现数据写入与索引构建的解耦，为 AI Agent 场景提供极致的实时写入与检索体验；新增 Windows 和 Android 平台原生编译与部署支持，实现跨平台全覆盖；同时完成了 Diff & Merge 对向量类型的支持以及 Fork Table/Database 与异步索引的正交适配，进一步增强了数据多版本管理能力。

## 新特性

### 异步索引

seekdb V1.3.0 版本引入异步索引（Async Index）能力，提供一种全新的向量索引维护模式。不同于传统的同步索引，异步索引将数据写入与索引构建解耦：DML 操作仅同步写入主表，主表始终持有最新数据并支持 MVCC 并发控制与唯一索引校验；后台通过 Change Stream 增量计算框架消费 CLOG 日志，异步维护向量索引。用户查询时通过异步索引进行相似性检索，实现极致的入库性能与稳定高效的检索性能。

**核心架构：Change Stream 增量计算框架**

* **Fetcher**：单线程消费 CLOG 日志，按事务粒度组装与定序，按事务提交顺序提供数据增量变更。
* **Dispatcher**：消费事务数据进行任务切片，按 rowkey hash 打散数据，构建执行上下文后下发到 Worker 队列。
* **Worker**：多线程并行执行子任务，同一 rowkey 的数据在同一 Worker 线程中串行处理，整体实现并行执行、串行提交的模型。

Change Stream 框架采用插件化设计，一期接入 HNSW 向量索引，后续可扩展支持全文索引、JSON 索引、Binlog 等多种场景，使 seekdb 从数据"存储引擎"扩展为"实时增量计算引擎"。

**产品行为：**

用户创建 HNSW 向量索引时，通过 `sync_mode` 选项指定索引维护模式：

* `immediate`：同步刷新，强一致。
* `async`（默认）：自动刷新，最终一致。

```sql
-- 创建异步向量索引
CREATE TABLE t1(c1 INT, c2 VECTOR(3), c3 VARCHAR(256),
PRIMARY KEY(c1),
VECTOR INDEX idx1(c2) WITH (distance=l2, type=hnsw, lib=vsag,
sync_mode=async))
ORGANIZATION HEAP;

-- INSERT：数据同步写入主表，异步写入索引，等待后台刷新后可检索
INSERT INTO t1 VALUES(1, '[1.0, 2.0, 3.0]', 'seekdb 1.3');

-- 通过异步索引检索
SELECT c1, c3 FROM t1
ORDER BY l2_distance(c2, '[1.0, 2.0, 3.0]') APPROXIMATE LIMIT 5;

-- 手动刷新，确保已写入的数据可检索
CALL dbms_index_manager.refresh();
```

### Windows 编译与部署支持（实验特性）

自 V1.3.0 版本起，seekdb 支持在 Windows 平台（64 位，x86 架构）上进行原生编译、部署与运行。提供完整的 MSI 安装包与可视化配置向导（Configurator），支持一键安装、服务管理与密码配置。同时支持通过 Named Pipe 方式处理 MySQL 协议，适配 Windows 本地开发与生产环境。

**功能亮点：**

* MSI 安装包：提供标准 Windows 安装体验，支持自定义安装目录。
* Configurator 配置向导：安装完成后自动拉起，支持数据目录、网络端口、密码等可视化配置。
* Named Pipe 支持：支持通过 Windows Named Pipe 处理 MySQL 协议连接。
* VSAG 向量引擎支持：Windows 平台完整支持 VSAG 向量索引库。

**功能限制：**

* 暂仅支持 Windows 11 64 位系统（x86_64 架构）。

### Android 编译与部署支持（实验特性）

自 V1.3.0 版本起，seekdb 支持在 Android 平台上进行原生编译与运行，可构建 APK 安装包，适用于移动端嵌入式数据库场景。

**功能亮点：**

* 支持 Android NDK 编译，集成 gRPC 和 SQLite 依赖。
* 支持构建独立 APK 安装包。
* 适配 Android 平台特有的系统调用与数据类型行为差异。

## 特性优化

### 异步索引检索性能优化

对异步索引的检索路径进行多项深度优化：优化 HNSW 检索跳过读取 4 号表的逻辑，减少不必要的 I/O 开销；优化日志回收与超时机制，降低后台维护对前台检索的影响。

### 向量 Diff & Merge 支持

V1.2.0 版本引入的 Diff & Merge 功能在 V1.3.0 版本中扩展支持向量类型。Fork 出的数据副本中的向量列变更，可通过 DIFF 进行对比、通过 MERGE 进行合并，进一步完善了向量数据的多版本管理能力。

### Fork Table/Database 与异步索引正交适配

Fork Table 和 Fork Database 功能在 V1.3.0 版本中与异步索引完成正交适配。Fork 操作能够正确处理包含异步索引的表，确保目标表/库中的异步索引状态与源端保持一致，支持 Fork 后独立进行索引刷新与检索。

### 备库读性能优化

优化备库的读性能，降低备库场景下的查询延迟。

### 资源优化

对后台定时器策略及冗余模块进行了系统性精简，小规格空载线程数降低约 30%，CPU 占用降低约 40%。
