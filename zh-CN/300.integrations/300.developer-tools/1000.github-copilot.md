# 与 GitHub Copilot 集成

[GitHub Copilot](https://github.com/features/copilot) 是 GitHub 推出的 AI 编程助手，深度集成在 Visual Studio Code 中，支持代码补全、聊天对话、Agent 模式等功能，帮助开发者更高效地编写代码。

本文介绍如何在 GitHub Copilot 上通过 seekdb Agent Skill 快速构建可被 AI 自动调用的知识包 + 工作流，以及如何通过 seekdb MCP Server 快速构建一个后端应用程序。

    [Agent Skills](https://agentskills.io/home) 是由 Anthropic 主导设计、现已作为开放标准发布的 AI 能力扩展格式。其核心思想是：将指令、脚本和资源打包成一个文件夹，AI Agent 可以按需发现并加载这些「技能」，从而更准确、更高效地完成任务。

    seekdb Agent Skills 是基于该标准构建的「可被 AI 自动调用的知识包 + 工作流」。在 GitHub Copilot 中安装后，当你提问 seekdb 相关问题时，GitHub Copilot 会自动按技能说明查阅 seekdb 文档或执行数据导入导出等操作，无需记住命令或手动复制文档，即可在编码过程中获得 seekdb 的官方文档支持与实操能力。更多关于 Agent Skill 的信息，请参考 [seekdb Agent Skills](../../100.get-started/110.use-seekdb-with-skill/100.agent-skills.md)。

    ## 支持的技能

    | 技能 | 说明 | 典型问题示例 |
    | --- | --- | --- |
    | **seekdb**（默认安装） | 覆盖 seekdb 官方文档（快速入门、开发指南、SDK/API、多模型数据、集成与运维等），AI 会根据你的问题自动定位到对应文档并给出答案或示例。 | 如何部署 seekdb？ / seekdb 的向量搜索怎么用？ |
    | **importing-to-seekdb** | 将数据导入 seekdb 的集合（Collection），支持指定列做向量化。导入前可预览 Excel/CSV 结构和样例数据。 | 把 sample_products.xlsx 导入 seekdb，Details 列向量化。 |
    | **querying-from-seekdb** | 按元数据条件过滤进行标量搜索，支持全文 + 语义混合搜索（RRF 排序），结果可导出为 CSV 或 Excel。 | 推荐 2 款评分 4.3 以上、AMOLED 屏的手机。 |

    ## 在 GitHub Copilot 中安装 seekdb Agent Skills

    GitHub Copilot 通过项目根目录下的 `.github/skills` 目录识别并加载 Agent Skill。按以下步骤完成安装：

    1. 进入你希望安装技能的项目根目录。

        ```shell
        cd /path/to/your/project
        ```

    2. 安装交互式安装器。

        ```shell
        pip install seekdb-agent-skills
        ```

    3. 运行交互式安装器。

        ```shell
        seekdb-agent-skills
        ```

    4. 选择工具。

        通过键盘上的 **↑↓** 键选择 **GitHub Copilot**，**Enter** 键确认。

        ```shell
        🚀 seekdb Agent Skills Installer
        ==================================================

        📋 Select tool to install to:
        ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
          Claude Code
          OpenClaw
          Cursor
          Codex
          OpenCode
        » GitHub Copilot
          Qoder
          Trae
        ```

    5. 确认安装位置。

        ```shell
        📁 Project root: /path/to/your/project
        (Skills will be installed under .github/skills)
        ? Install skills to this directory? (Y/n)
        ```

        输入 `Y` 确认，输入 `n` 退出安装器。

    6. 选择需要安装的技能。

        如果仅需要 AI 参考 seekdb 文档，直接回车即可。如果需要向 seekdb 中导入导出 Excel/CSV 文件，可以同时选择 **importing-to-seekdb** 和 **querying-from-seekdb** 技能。通过键盘上的 **↑↓** 键选择技能，**空格** 进行多选，**Enter** 键确认安装。

        ```shell
        📦 Select skills to install:
        ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
        » ● seekdb
          ○ importing-to-seekdb
          ○ querying-from-seekdb
        ```

    ## 在 GitHub Copilot 中使用 seekdb Agent Skills

    安装完成后，使用 VS Code 打开安装了技能的项目根目录，在 Copilot Chat 中直接提问即可。AI 会自动调用对应技能并基于文档或技能能力作答。你也可以在聊天输入框中输入 `/skills` 查看已加载的技能列表。

    示例提问：

    * 怎么在 Mac 上部署 seekdb？
    * seekdb 的向量搜索怎么用？
    * 在 seekdb 中如何实现混合搜索？

    [MCP（Model Context Protocol）](https://modelcontextprotocol.io/docs/getting-started/intro) 是 Anthropic 公司于 2024 年 11 月推出并开源，旨在实现大语言模型与外部工具或数据源交互的协议。通过 MCP，用户不需要将大模型的输出手动复制执行，大模型可以直接指挥工具执行相应的动作（Action）。

    [MCP Server](https://github.com/oceanbase/awesome-oceanbase-mcp/tree/main/src/seekdb_mcp_server) 通过 MCP 协议提供了大模型与 seekdb 交互的能力，可以执行 SQL 语句。通过合适的客户端可以快速搭建项目原型，已在 github 上开源。

    ## 前提条件

    * 您已完成部署 seekdb。

    * 安装 [Python 3.11 及以上版本](https://www.python.org/downloads/) 和相应 [pip](https://pip.pypa.io/en/stable/installation/)。如果您的机器上 Python 版本较低，可以使用 Miniconda 来创建新的 Python 3.11 及以上的环境，具体可参考 [Miniconda 安装指南](https://docs.anaconda.com/miniconda/install/)。

    * 安装 Python 包管理器 uv。推荐使用官方独立安装器，安装完成后可使用 `uv --version` 验证：

      * macOS 和 Linux （使用 curl）：

            ```shell
            curl -LsSf https://astral.sh/uv/install.sh | sh
            ```

            若无 curl，可使用 wget：

            ```shell
            wget -qO- https://astral.sh/uv/install.sh | sh
            uv --version
            ```

      * Windows （使用 PowerShell）：

            ```shell
            powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
            uv --version
            ```

        其他安装方式（如 Homebrew、pipx、pip）请参见 [uv 官方安装文档](https://docs.astral.sh/uv/getting-started/installation/)。

    * 下载 [Visual Studio Code](https://code.visualstudio.com/Download)，根据自己的操作系统选择合适的版本进行安装。在 VS Code 扩展商店中搜索并安装 GitHub Copilot 扩展。

    ## 步骤一：获取数据库连接信息

    联系 seekdb 部署人员或者管理员获取相应的数据库连接串，例如：

    ```sql
    mysql -h$host -P$port -u$user_name -p$password -D$database_name
    ```

    **参数说明：**

    * `$host`：提供 seekdb 连接 IP 地址。
    * `$port`：提供 seekdb 连接端口，默认是 `2881`。
    * `$database_name`：需要访问的数据库名称。

        :::tip
        连接的用户需要拥有该数据库的 `CREATE`、`INSERT`、`DROP` 和 `SELECT` 权限。
        :::

    * `$user_name`：提供数据库连接账户。
    * `$password`：提供账户密码。

    ## 步骤二：配置 seekdb MCP Server

    ### 安装 seekdb MCP Server

    执行下面的命令进行安装

    ```shell
    pip install seekdb-mcp-server
    ```

    ### 配置 seekdb 服务器环境变量到 .env 文件中

    在当前目录下创建一个名为 `.env` 的文件，并添加以下内容：

    ```shell
    SEEKDB_HOST=localhost
    SEEKDB_PORT=2881
    SEEKDB_USER=your_username
    SEEKDB_PASSWORD=your_password
    SEEKDB_DATABASE=your_database
    ```

    ### 以 Streamable-HTTP 模式启动 seekdb MCP Server

    ```shell
    env $(cat .env | xargs) uvx seekdb-mcp-server --transport streamable-http --port 8000 --host 127.0.0.1
    ```

    ### 创建 VS Code 工作目录并配置 seekdb MCP Server

    手动创建一个 VS Code 的工作目录，并用 VS Code 打开，后面 GitHub Copilot 生成的文件将放在这个目录下，示例的目录名为 `copilot-generate`。

    在 VS Code 中，使用快捷键 `Ctrl + Shift + P`（Windows / Linux）或 `Command + Shift + P`（macOS）打开命令面板，输入 `MCP: Add Server`，选择 `HTTP/SSE` 类型，按提示填写配置信息。

    也可以手动在项目根目录下创建 `.vscode/mcp.json` 文件，添加以下配置：

    #### 添加并配置 MCP Servers

    ```json
    {
      "servers": {
        "streamable-http-seekdb": {
          "url": "http://ip:port/mcp",
          "type": "http"
        }
      },
      "inputs": []
    }
    ```

    将 `ip` 和 `port` 替换为 seekdb MCP Server 实际运行的地址和端口（例如 `http://127.0.0.1:8000/mcp`）。

    配置完成后，VS Code 会自动检测并启动 MCP Server。可以使用命令面板中的 `MCP: List Servers` 命令查看 MCP Server 的连接状态。

    #### 测试 MCP Server

    使用快捷键 `Ctrl + Alt + I`（Windows / Linux）或 `Ctrl + Command + I`（macOS）打开 Copilot Chat，切换到 **Agent 模式**。在对话框中输入提示：`How many tables in the test database?，GitHub Copilot` 会展示即将执行的 SQL 语句。确认无误后，点击 **Allow** 按钮执行。GitHub Copilot 会展示 `test` 库中的所有表名称，这表明我们已经成功连接到 seekdb。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/1.png)

    ## 步骤三：使用 FastAPI 快速创建 RESTful API 风格的项目

    你可以使用 FastAPI 快速创建 RESTful API 风格的项目。FastAPI 是一个 Python 的 Web 框架，可以快速构建 RESTful API。

    1. 创建 customer 表

        在对话框中输入提示：`Create a "customer" table with "ID" as the primary key and containing fields such as "name", "age", "telephone", and "location"`，确认 SQL 语句后，点击 **Allow** 按钮执行。

        ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/2.png)

    2. 插入测试数据

        在对话框中输入提示：`Insert 10 pieces of data into the customer table`，确认 SQL 语句后，点击 **Allow** 按钮执行。

        ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/3.png)

    3. 创建 FastAPI 项目

        在对话框中输入提示：`Create a FastAPI project on the customer table`，点击 **Allow** 按钮执行。此步骤将自动生成多个文件。

        ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/4.png)

        此步骤将自动生成多个文件。建议首次使用时选择 `全部接受`，因为 AI 生成的文件内容可能具有不确定性，后续可根据实际需求进行调整。

    4. FastAPI 项目配置数据库连接信息

        查看 GItHub Copilot 生成项目的数据库连接信息，如果不正确，需要更改配置。

        ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/SeekDB/integrations/developer-tools/github-copilot/5.png)

    5. 安装项目依赖

        执行如下命令，安装项目依赖：

        ```shell
        cd fastapi_app
        pip install -r requirements.txt
        ```

    6. 启动 FastAPI 项目

        执行如下命令，启动 FastAPI 项目：

        ```shell
        uvicorn fastapi_app.main:app --reload --host 127.0.0.1 --port 3000
        ```

    7. 查看表中数据

        在命令行中运行如下命令，或者使用其他请求工具，查看表中的数据：

        ```shell
        curl http://127.0.0.1:3000/customers/
        ```
