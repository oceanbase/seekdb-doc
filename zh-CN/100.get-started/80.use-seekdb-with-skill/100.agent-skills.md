# seekdb Agent Skills

seekdb Agent Skills 可以理解为「可被 AI 自动调用的知识包 + 工作流」，如果你提问 seekdb 相关的问题，AI 会自动按技能说明去查文档及执行操作，无需记住命令或手动复制文档。无论你使用 Cursor、Claude Code、OpenClaw 还是其他支持的 AI 工具，都可以通过安装这些技能，让 AI 自动查阅 seekdb 文档、执行数据导入导出等操作，从而更高效地使用 seekdb。

## 支持的 AI 编程工具

| 工具 | 技能安装目录 |
| --- | --- |
| Claude Code | `.claude/skills` |
| OpenClaw | `~/.openclaw/workspace/skills` |
| Cursor | `.cursor/skills` |
| Codex | `.codex/skills` |
| OpenCode | `.opencode/skills` |
| GitHub Copilot | `.github/skills` |
| Qoder | `.qoder/skills` |
| Trae | `.trae/skills` |

如果你使用的工具不在上表中，可以尝试安装时选择 Claude Code，安装器会把技能复制到 `.claude/skills`；之后只需把目录名改成你所使用的工具要求的名字或挪到对应的目录即可，技能本身是通用的。

## 支持的技能

### seekdb：文档知识库

覆盖 seekdb 官方文档（快速入门、开发指南、SDK/API、多模型数据、集成与运维、教程与参考等）。 AI 会根据你的问题自动定位到对应文档并给出答案或示例。

典型问题示例:

* 如何部署 seekdb？
* seekdb 的向量搜索怎么用？
* 在 seekdb 中如何实现混合搜索？

### importing-to-seekdb：数据导入 + 向量化

将数据导入 seekdb 的集合（Collection），支持指定列做向量化。导入前可预览 Excel/CSV 结构和样例数据(sample_products.csv/ sample_products.xlsx)。

典型用法示例：

* 先预览一下 importing-to-seekdb 技能里的示例 Excel。
* 把 sample_products.xlsx 导入 seekdb，Details 列向量化。

### querying-from-seekdb：查询与导出

按元数据条件过滤（如评分、品牌、价格）进行标量搜索。全文 + 语义一起混合搜索，结果用 RRF（倒数排名融合）排序。可以将结果导出为 CSV 或 Excel，便于分析或汇报。

典型用法示例：

* 推荐 2 款评分 4.3 以上、AMOLED 屏的手机。
* 找评分 4.3 以上、AMOLED 屏的手机，导出成 Excel。

## 安装 seekdb Agent Skills

使用交互式安装器安装 seekdb Agent Skills。

1. 选择安装目录。

    交互式安装器会把技能安装到当前执行安装器命令的目录下（OpenClaw 除外），如果想要更换安装目录，请先进入至安装目录，再执行安装操作。OpenClaw 的技能安装在用户目录 `~/.openclaw/workspace/skills` 下。

2. 安装插件包。

    ```python
    pip install seekdb-agent-skills
    ```

3. 运行交互式安装器。

    ```shell
    seekdb-agent-skills
    ```

4. 选择工具。

    在交互式安装器中，你可以选择需要安装的工具。

    通过键盘上的 **↑↓** 键选择工具，**Enter** 键确认安装，**Ctrl+C** 取消安装。

    ```shell
    🚀 seekdb Agent Skills Installer
    ==================================================

    📋 Select tool to install to:
    ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): (Use arrow keys)
    » Claude Code
    OpenClaw
    Cursor
    Codex
    OpenCode
    GitHub Copilot
    Qoder
    Trae
    ```

5. 确认安装位置。

    ```shell
    🚀 seekdb Agent Skills Installer
    ==================================================

    📋 Select tool to install to:
    ? Select one tool (use ↑↓ to navigate, Enter to confirm, Ctrl+C to cancel): Cursor

    📁 Project root: /home/admin
    (Skills will be installed under .cursor/skills)
    ? Install skills to this directory? (Y/n)
    ```

    此处选择 `Y` 则进入下一步，如果选择 `n` ，则会退出安装器。

6. 选择需要安装的技能

    如果仅需要 AI 工具参考 seekdb 文档，直接回车即可。如果需要向 seekdb 中导入导出 Excel/CSV 文件，可以同时选择 `importing-to-seekdb` 和 `querying-from-seekdb` 技能。

    通过键盘上的 **↑↓** 键选择工具，**空格** 进行多选，**Enter** 键确认安装，**Ctrl+C** 取消安装。

    ```shell
    📦 Select skills to install:
    ? Select skills (use ↑↓ to navigate, Space to select, Enter to confirm, Ctrl+C to cancel): (Select multiple with Space)
    » ● seekdb
      ○ importing-to-seekdb
      ○ querying-from-seekdb
    ```

## 示例

支持的 AI 工具使用方式类似，以下使用 Cursor、Claude Code 和 OpenClaw 工具进行举例：

* 在 Cursor 中使用

  1. 使用 Cursor 打开安装了技能的项目根目录。
  2. 在 Cursor 中提问，例如：

        ```shell
        怎么在 Mac 上部署 seekdb？
        ```

* 在 Claude Code 中使用

  1. 在安装了技能的项目根目录下打开 Claude Code。
  2. 在 Claude Code 中提问，例如：

        ```shell
        seekdb 的向量搜索怎么用？
        ```

* 在 OpenClaw 中使用

  1. 在任意目录打开 OpenClaw。

        ```shell
        openclaw tui
        ```

  2. 在 OpenClaw 中提问，例如：

        ```shell
        在 seekdb 中如何实现混合搜索？
        ```
