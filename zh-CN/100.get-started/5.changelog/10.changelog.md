# 产品动态

## 2026.3.25 seekdb V1.2.0 发布，pyseekdb 和 seekdb-js V1.2.0 发布

### seekdb V1.2.0 发布

seekdb V1.2.0 版本是一个里程碑式的功能增强版本，标志着 seekdb 从单机数据库向高可用架构迈出了关键一步。该版本引入了主备库高可用解决方案，大幅提升了数据库的容灾能力；支持 Fork Database，满足整库数据多版本管理的需求；新增 Diff & Merge 语法，提供了类似 Git 的数据分支对比和合并能力；同时通过内部架构优化和向量/全文性能优化，为企业级应用场景提供更加可靠和高效的数据库服务。

有关该版本的详细信息，参见 [seekdb V1.2.0 Release Notes](https://www.oceanbase.ai/docs/zh-CN/releasenote-v1.2.0)。

### pyseekdb V1.2.0 发布

pyseekdb 在 V1.2.0 版本进行了以下能力增强：

* 稀疏向量索引: 支持稀疏向量索引，可用于优化关键词匹配、文本搜索等场景的性能。([#172](https://github.com/oceanbase/pyseekdb/pull/172))
* 索引配置增强: 支持更多 HNSW 索引配置选项与全文检索配置选项。([#166](https://github.com/oceanbase/pyseekdb/pull/166))
* Embedding 模型支持
  * 新增 Text2Vec Embedding 函数支持。([#142](https://github.com/oceanbase/pyseekdb/pull/142))
  * 新增 Mistral Embedding 函数支持。([#153](https://github.com/oceanbase/pyseekdb/pull/153))
  * 新增 Morph Embedding 函数支持。([#143](https://github.com/oceanbase/pyseekdb/pull/143))

### seekdb-js V1.2.0 发布

seekdb-js 在 V1.2.0 版本进行了以下能力增强：

* 内嵌模式：支持使用内嵌模式。
* 稀疏向量索引: 支持稀疏向量索引，用于增强基于关键词的检索能力。
* 索引配置增强: 支持更多 HNSW 索引配置选项与全文检索配置选项。
* ORM 适配：支持 Prisma、Drizzle 适配器，扩展内嵌模式下 seekdb 的查询与集成能力。

## 2026.1.30 seekdb V1.1.0 发布，pyseekdb 和 seekdb-js V1.1.0 发布

### seekdb V1.1.0 发布

* seekdb 新增支持在 MacOS 15 及以上系统版本进行原生编译与本地开发调试。
关于 Mac 下安装 seekdb 的详细介绍，参见 [通过包管理工具部署 seekdb](https://www.oceanbase.ai/docs/zh-CN/deploy-by-systemd)。
* 新增 Fork Table 功能。不同于传统 CTAS 的全量数据拷贝，Fork Table 提供一种与数据量无关的快速复制方式。基于表级别存储复用和写时复制的技术，在满足一致性语义的前提下，尽可能复用既有的数据组织与存储结构，避免全量拷贝，从而显著降低创建耗时与资源消耗。
* 优化了存储空间。针对数据存储、Clog 存储、系统日志存储，全面优化了最低资源规格，进一步降低开发者使用门槛。
* 优化了内存管理策略，以适应不同部署环境（如大/小内存规格、独立/非独立部署）的需求。

有关该版本的详细信息，参见 [seekdb V1.1.0 Release Note](https://www.oceanbase.ai/docs/zh-CN/releasenote-v1.1.0)。

### pyseekdb V1.1.0 发布

pyseekdb 在 V1.1.0 版本进行了以下能力增强：

* Collection 命名更加灵活：名称长度上限从 64 字符提升至 **512 字符**，满足更复杂的业务场景。
* 全文检索能力增强：新增 `FulltextIndexConfig`，支持自定义分词器与字段映射。
* Embedding 生态大幅扩展：集成 **11 种**主流 embedding 平台，覆盖开源与商用模型。
* 元数据持久化升级：embedding 函数信息可持久化到系统表，进一步提升开发者使用便捷度。
* 新增 table-fork 能力：支持 Collection 级别的快照复制，简化数据实验与回滚。(实验特性)

有关该版本的详细信息，参见 [pyseekdb 更新记录](https://www.oceanbase.ai/docs/zh-CN/pyseekdb-changelog)

## 2025.11.14 seekdb V1.0.0 发布，pyseekdb V1.0.0 发布

### seekdb V1.0.0 发布

seekdb 是一款 AI 原生混合搜索数据库，在一个数据库中融合向量、文本、结构化与半结构化数据能力，并通过内置 AI Functions 支持多模混合搜索与智能推理。

有关该版本的详细信息，参见 [seekdb V1.0.0 Release Note](https://www.oceanbase.ai/docs/zh-CN/releasenote-v1.0.0)。

seekdb 具备以下核心优势：

* 快速构建

  数行 Python 代码即可构建 AI 应用，轻量架构在 1C2G 上即可跑 VectorDBBench。

* 混合搜索

  向量、全文与标量过滤在一次查询中完成，支持粗排 + 精排的多阶段搜索链路。

* 多模数据与索引

  在一个引擎内同时支持标量、向量、文本、JSON、GIS 等多模数据及索引。

* AI 内置

  在数据库内完成向量嵌入、推理、提示词管理与重排，支持 document-in/data-out 的完整 RAG 流程。

* SQL 原生

  源于成熟的 OceanBase 引擎，支持实时写入、实时可查， ACID 事务保证，兼容 MySQL 生态。

### pyseekdb V1.0.0 发布

pyseekdb 是 OceanBase 提供的 Python 客户端。实现了基于一套 API 接口，提供两种数据库连接模式，支持连接到嵌入式模式的 seekdb 和连接到远程服务器（支持服务器模式的 seekdb 和 OceanBase 数据库）。

有关 pyseekdb 的详细介绍和使用示例，参见 [pyseekdb 快速开始](https://www.oceanbase.ai/docs/zh-CN/pyseekdb-sdk-get-started/)。
